# വിജ്ഞാന പരിശോധനയുടെ ഉത്തറുകൾ

## ചോദ്യം 1

**ഉത്തരം: A2.** ഒരു ജോലി വ്യക്തമായ വിദഗ്ധ ഉള്ളടക്കം, വേരിട്ട ഉപകരണങ്ങൾ അല്ലെങ്കിൽ അനുമതികൾ, കൂടാതെ ഏകോപനം ആവശ്യമായ വ്യക്തമായ കൈമാറ്റങ്ങൾ ഉള്ളപ്പോൾ ബഹുജന ഏജന്റുമാർ ഉപകരിക്കും. ഒരു ലളിതമായ സഹായ ബോട്ട് സാധാരണയായി ഒരേ ഏജന്റായി തുടരാം. ഒരു ഉയർന്ന അളവിലുള്ള സമാനമായ അഭ്യർത്ഥനകൾ പ്രധാനമായും സ്കെയിലിംഗ് പ്രശ്നമാണ്, അത് തന്നെ ബഹുജന ഏജന്റ് ഡിസൈൻ ആവശ്യമായില്ല.

## ചോദ്യം 2

**ഉത്തരം: A1.** ഒരു ജോലിയെ കൈകാര്യം ചെയ്യാൻ ഒരേ നിർദേശംകളും ഉപകരണങ്ങളും ഉപയോഗിക്കാൻ കഴിയുമ്പോൾ ഒറ്റ ഏജന്റ് സാധാരണയായി പരീക്ഷിക്കാൻ, നിരീക്ഷിക്കാൻ, പ്രവർത്തിപ്പിക്കാനും എളുപ്പമാണ്. പല ഉപകരണങ്ങളിലേക്കുള്ള ആക്‌സസ് പല ഏജന്റുകളെ നിർബന്ധമാക്കുന്നില്ല. വ്യത്യസ്ത അനുമതികളും ഓഡിറ്റ് ആവശ്യകതകളും ഉള്ള വേറിട്ട റോളുകൾ ബഹുജന ഏജന്റ് ഡിസൈൻ നിർബന്ധമാക്കാം.
