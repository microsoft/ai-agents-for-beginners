# ⏩ Azure OpenAI (Responses API) ഉപയോഗിച്ച് അനുക്രമ ശൈലിയിലുള്ള ഏജന്റ് വർക്‌ഫ്ലോകൾ (.NET)

## 📋 പരിരീട്ട അനുക്രമ പ്രോസസ്സിങ് ട്യൂട്ടോറിയൽ

ഈ നോട്ട്‌ബുക്ക് Microsoft Agent Framework for .NET និង Azure OpenAI (Responses API) ഉപയോഗിച്ച് **അനൂകരമാകുന്ന വർക്‌ഫ്ലോ മാതൃകകൾ** പ്രദർശിപ്പിക്കുന്നു. ഏജന്റുകൾ ഒരു നിശ്ചിത നിരയിൽ പ്രവർത്തിക്കുന്ന സങ്കീർണ്ണമായ ഘട്ടം ഘട്ടമായ പ്രോസസ്സിങ് പൈപ്പ്ലൈനുകൾ നിങ്ങൾ എങ്ങനെ നിർമ്മിക്കാമെന്ന് നിങ്ങൾക്ക് പഠിപ്പിക്കും, ഓരോ ഘട്ടവും മുമ്പത്തെ ഘട്ടത്തിന്റെ ഫലങ്ങളെ അടിസ്ഥാനമാക്കി നിർമ്മിക്കുന്നു.

- **സ്ഥിതി മാനേജ്മെന്റ്** : അനുക്രമ വർക്‌ഫ്ലോ ഘട്ടങ്ങളിലെ ആശയവിനിമയവും ഡാറ്റാ പ്രവാഹവും പരിപാലിക്കുക

## ⚙️ മുൻ‌അവശ്യംകൾ & സെറ്റപ്പ്

### 📦 **ആവശ്യമാണ് NuGet പാക്കേജുകൾ**

.NET അനുക്രമ വർക്‌ഫ്ലോകൾക്കായി അനിവാര്യമായ പാക്കേജുകൾ:

```xml
<!-- Core AI Framework -->
<PackageReference Include="Microsoft.Extensions.AI" Version="9.9.0" />

<!-- Azure OpenAI (Responses API) -->
<PackageReference Include="Azure.AI.OpenAI" Version="2.1.0" />

<!-- Azure Identity and Async LINQ Support -->
<PackageReference Include="Azure.Identity" Version="1.15.0" />
<PackageReference Include="System.Linq.Async" Version="6.0.3" />

<!-- Local Agent Framework References -->
<!-- Microsoft.Agents.AI.dll - Core agent abstractions -->
<!-- Microsoft.Agents.AI.OpenAI.dll - Azure OpenAI (Responses API) integration -->
```

### 🔑 **Azure OpenAI കോൺഫിഗറേഷൻ**

**പരിസ്ഥിതി ക്രമീകരണം (.env ഫയൽ):**
```env
AZURE_OPENAI_ENDPOINT=https://<your-resource>.openai.azure.com
AZURE_OPENAI_DEPLOYMENT=gpt-4o-mini
```

**കോണഫിഗറേഷൻ മാനേജ്മെന്റ്:**
```csharp
// Load environment variables securely
Env.Load("../../../.env");
var azureEndpoint = Environment.GetEnvironmentVariable("AZURE_OPENAI_ENDPOINT");
var deployment = Environment.GetEnvironmentVariable("AZURE_OPENAI_DEPLOYMENT");
```

### 🎯 യാഥാർത്ഥిక പ്രയോഗങ്ങൾ

ഈ അനുക്രമ മാതൃക അനുയോജ്യമാണ്:
- **ഇ-കൊമേഴ്സ്** : ഉൽപ്പന്ന വിശകലനം → വില നിർണ്ണയം → വാചകം ജനറേഷൻ
- **റിയൽ എസ്റ്റേറ്റ്** : വീട് വിശകലനം → മൂല്യനിർണ്ണയം → ലിസ്റ്റിംഗ് സൃഷ്ടികരണം
- **ഇൻഷുറൻസ്** : ക്ലയിം വിശകലനം → വിലയിരുത്തൽ → വാചകം ജനറേഷൻ
- **ഉള്ളടക്കം സൃഷ്ടിക്കൽ** : ഗവേഷണം → എഴുത്ത് → എഡിറ്റിംഗ് → പ്രസിദ്ധീകരണം
