# 🔄 അടിസ്ഥാന ഏജന്റ് വർക്‌ഫ്ലേകൾ സഹിതം Azure OpenAI (Responses API) (.NET)

## 📋 വർക്‌ഫ്ലോ ഓർക്കസ്ട്രേഷൻ ട്യൂട്ടോറിയൽ

ഈ നോട്ട്ബുക്ക് സൂക്ഷ്മമായ **ഏജന്റ് വർക്‌ഫ്ലേകൾ** നിർമ്മിക്കുന്നതിനുള്ള മാർഗ്ഗങ്ങൾ കാണിക്കുന്നു, .NET-ക്കായി Microsoft Agent Framework-ഉം Azure OpenAI (Responses API) യും ഉപയോഗിച്ച്. സങ്കീർണ ജോലികൾ പൂർത്തീകരിക്കാൻ AI ഏജന്റുകൾ ചേർന്ന് പ്രവർത്തിക്കുന്ന നിരവധി ഘട്ട ബിസിനസ്സ് പ്രോസസുകൾ സൃഷ്‌ടിക്കുന്ന കാര്യങ്ങളിൽ നിങ്ങൾ പഠിക്കുന്നതാണ്.

## 🎯 പഠന ലക്ഷ്യങ്ങൾ

### 🏗️ **വർക്‌ഫ്ലോ ആർക്കിടെക്ചർ അടിസ്ഥാനങ്ങൾ**
- **Workflow Builder**: സങ്കീർണ ബഹുഘട്ട AI പ്രോസസുകൾ രൂപകൽപ്പന ചെയ്യുക, ഓർക്കസ്ട്രേറ്റ് ചെയ്യുക
- **Agent Coordination**: വർക്‌ഫ്ലോകളുടെ ভিতরে നിരവധി പ്രത്യേക ഏജന്റുകൾക്ക് ഏകോപനം നൽകുക
- **Azure OpenAI (Responses API)**: വർക്‌ഫ്ലോമുകളിൽ Azure OpenAI Responses API യുടെ പ്രയോജനം
- **Visual Workflow Design**: വർക്‌ഫ്ലോ ഘടനകൾ സൃഷ്ടിച്ച് ദൃശ്യമാക്കുക മെച്ചപ്പെട്ട മനസിലാക്കലിനായി

### 🔄 **പ്രോസസ് ഓർക്കസ്ട്രേഷൻ പാറ്റേണുകൾ**
- **Sequential Processing**: പല ഏജന്റ് ടാസ്കുകളും തർക്കരഹിത ക്രമത്തിൽ ബന്ധിപ്പിക്കുക
- **State Management**: വർക്‌ഫ്ലോ ഘട്ടങ്ങൾക്കിടയിലെ contexteum Data flow നുക്ഷേപിക്കുക
- **Error Handling**: ദൃഢമായ പിശക് പരിഹാരവും വർക്‌ഫ്ലോ പ്രതിരോധവും നടപ്പിലാക്കുക
- **Performance Optimization**: എന്റർപ്രൈസ്-തലമുറ പ്രവർത്തനങ്ങൾക്ക് ഫലപ്രദമാക്കുക

### 🏢 **എന്റർപ്രൈസ് വർക്‌ഫ്ലോ അപ്ലിക്കേഷനുകൾ**
- **Business Process Automation**: സങ്കീർണ സംഘടനാ വർക്‌ഫ്ലോകൾ ഓട്ടോമേറ്റ് ചെയ്യുക
- **Content Production Pipeline**: പരിശോധിക്കൽ, അംഗീകാരം ഘട്ടങ്ങളോടെ എഡിറ്റോറിയൽ വർക്‌ഫ്ലോകൾ
- **Customer Service Automation**: ബഹുഘട്ട ഉപഭോക্তা അന്വേഷണം പരിഹാരം
- **Data Processing Workflows**: AI-പ്രേരിത മാറ്റം സഹിതം ETL വർക്‌ഫ്ലോകൾ

## ⚙️ മുൻ‌അവസരങ്ങളും ക്രമീകരണവും

### 📦 **ആവശ്യമായ NuGet പാക്കേജുകൾ**

ഈ വർക്‌ഫ്ലോ പ്രദർശനത്തിൽ പ്രധാനമായ .NET പാക്കേജുകൾ പലതും ഉപയോഗിക്കുന്നു:

```xml
<!-- Core AI Framework -->
<PackageReference Include="Microsoft.Extensions.AI" Version="9.9.0" />

<!-- Azure OpenAI (Responses API) -->
<PackageReference Include="Azure.AI.OpenAI" Version="2.1.0" />
<PackageReference Include="Azure.Identity" Version="1.13.1" />

<!-- Agent Framework (Local Development) -->
<!-- Microsoft.Agents.AI.dll - Core agent abstractions -->
<!-- Microsoft.Agents.AI.OpenAI.dll - Azure OpenAI (Responses API) integration -->

<!-- Configuration and Environment -->
<PackageReference Include="DotNetEnv" Version="3.1.1" />
```

### 🔑 **Azure OpenAI കോൺഫിഗറേഷൻ**

**Environment Setup (.env ഫയൽ):**
```env
AZURE_OPENAI_ENDPOINT=https://<your-resource>.openai.azure.com
AZURE_OPENAI_DEPLOYMENT=gpt-4o-mini
```

**Azure OpenAI പ്രവേശനം:**
1. Azure പോർട്ടലിൽ Azure OpenAI റിസോർസ് സൃഷ്‌ടിക്കുക
2. ഒരു മോഡൽ (ഉദാഹരണത്തിന്, `gpt-4o-mini`) ഡിപ്ലോയുചെയ്യുകയും ഡിപ്ലോയ്മെന്റ് പേര് ശ്രദ്ധിക്കുക
3. `az login` ഉപയോഗിച്ച് സൈൻ ഇൻ ചെയ്ത് മുകളിലുള്ളതുപോലെ എൻവയോൺമെന്റ് വേരിയബിളുകൾ ക്രമീകരിക്കുക

### 🏗️ **Workflow Architecture അവലോകനം**

```mermaid
graph TD
    A[വർക്ക്‌ഫ്ലോ നിർമ്മാതാവ്] --> B[ഏജന്റ് രജിസ്റ്റർ]
    B --> C[വർക്ക്‌ഫ്ലോ നടപ്പാക്കൽ എൻജിൻ]
    C --> D[Agent 1: ഉള്ളടക്കം ജനകന
    C --> E[Agent 2: ഉള്ളടക്കം അവലോകനക്കാരൻ 
    D --> F[വർക്ക്‌ഫ്ലോ ഫലങ്ങൾ]
    E --> F
    G[അസ്യൂർ ഓപ്പൺഎഐ (പ്രതിനിധാനങ്ങൾ API)] --> D
    G --> E
```

**പ്രധാന ഘടകങ്ങൾ:**
- **WorkflowBuilder**: വർക്‌ഫ്ലോകൾ രൂപകൽപ്പന ചെയ്യുന്നതിനുള്ള മുഖ്യ ഓർക്കസ്ട്രേഷൻ എൻജിൻ
- **AIAgent**: പ്രത്യേക കഴിവുകൾ ഉള്ള വ്യക്തിഗത ഏജന്റുകൾ
- **Azure OpenAI Client**: Azure OpenAI Responses API ഇന്റെഗ്രേഷൻ
- **Execution Context**: വർക്‌ഫ്ലോ ഘട്ടങ്ങൾക്കിടയിലെ സ്ഥിതി, ഡാറ്റ ഫ്ലോ മാനേജ് ചെയ്യുന്നു

## 🎨 **എന്റർപ്രൈസ് Workflow ഡിസൈൻ പാറ്റേണുകൾ**

### 📝 **ഉള്ളടക്ക നിർമ്മാണ വർക്‌ഫ്ലോ**
```
User Request → Content Generation → Quality Review → Final Output
```

### 🔍 **ഡോക്യുമെന്റ് പ്രോസസിംഗ് പൈപ്പ്ലൈൻ**
```
Document Input → Analysis → Extraction → Validation → Structured Output
```

### 💼 **ബിസിനസ്സ് ഇന്‍റലിജൻസ് വർക്‌ഫ്ലോ**
```
Data Collection → Processing → Analysis → Report Generation → Distribution
```

### 🤝 **ഉപഭോക്തൃ സേവന ഓട്ടോമേഷൻ**
```
Customer Inquiry → Classification → Processing → Response Generation → Follow-up
```

## 🏢 **എന്റർപ്രൈസ് ഗുണങ്ങൾ**

### 🎯 **വിശ്വാസ്യത & സ്‌കെയിലബിലിറ്റി**
- **Deterministic Execution**: സ്ഥിരം, ആവർത്തിക്കാവുന്ന വർക്‌ഫ്ലോ ഫലങ്ങൾ
- **Error Recovery**: വർക്‌ഫ്ലോ ഘട്ടങ്ങളിൽ പിശകുകൾ കേട്ടുപിടിക്കൽ സൗമ്യമായി കൈകാര്യം ചെയ്യൽ
- **Performance Monitoring**: എക്സിക്യൂഷൻ മെട്രിക്‌സ് ട്രാക്ക് ചെയ്യുകയും മെച്ചപ്പെടുത്തലുകൾ കണ്ടെത്തുക
- **Resource Management**: AI മോഡൽ വിഭവങ്ങളുടെ ഫലപ്രദമായ വിനിയോഗവും ഉപയോഗവും

### 🔒 **സുരക്ഷ & പാലനം**
- **Secure Authentication**: `az login` (AzureCliCredential) മുഖേന Microsoft Entra ID ഓതന്റിക്കേഷൻ
- **Audit Trails**:Workflow പ്രവർത്തനവും തീരുമാന പോയന്റുകളും തികച്ചും ലോഗ് ചെയ്യൽ
- **Access Control**:Workflow പ്രവർത്തനത്തിന്റെയും മേൽനോട്ടത്തിന്റെയും നിസ്തുല അനുവാദങ്ങൾ
- **Data Privacy**:Workflow മുഴുവൻ രഹസ്യ വിവരങ്ങൾ സുരക്ഷിതമായി കൈകാര്യം ചെയ്യൽ

### 📊 **ഓബ്സർവബിലിറ്റി & മാനേജ്‌മെന്റ്**
- **Visual Workflow Design**: പ്രോസസ് ഫ്ലോകളും ആശ്രിതകാര്യങ്ങളും വ്യക്തമായി പ്രതിനിധാനം ചെയ്യുക
- **Execution Monitoring**:Workflow പുരോഗതിയും പ്രകടനവും യഥാസമയം നിരീക്ഷിക്കൽ
- **Error Reporting**: വിശദമായ പിശക് വിശകലനവും ഡീബഗിംഗ് കഴിവുകളും
- **Performance Analytics**: മെച്ചപ്പെടുത്തലിനും ശേഷിവിപണനം പ്ലാനിനും മെട്രിക്‌സ്

നിങ്ങളുടെ ആദ്യ എന്റർപ്രൈസ്-സജ്ജ AI വർക്‌ഫ്ലോ ഇത് നിർമ്മിക്കാം! 🚀

## 💻 കോഡ് 실행

പൂർണ്ണമായ നടപ്പാക്കൽ `01.dotnet-agent-framework-workflow-ghmodel-basic.cs` ൽ ലഭ്യമാണ്. ഇതിൽ കാണിക്കുന്നത്:

1. **പരിസ്ഥിതി കോൺഫിഗറേഷൻ** - `.env` ഫയലിൽ നിന്ന് Azure OpenAI കോൺഫിഗറേഷൻ ലോഡ് ചെയ്യുന്നു
2. **Azure OpenAI ക്ലയന്റ് ക്രമീകരണം** - Azure OpenAI Responses API ഉപയോഗിക്കാൻ ക്ലയന്റ് ക്രമീകരിക്കുന്നു
3. **ഏജന്റ് സൃഷ്‌ടി** - പ്രത്യേകഏജന്റുകൾ (Front Desk, Concierge) നിർവചിക്കുന്നു
4. **Workflow Builder** - ബഹുഎജന്റ് വർക്‌ഫ്ലോ ക്രമീകരിച്ച് അനുബന്ധ പ്രവർത്തനം നടപ്പിലാക്കുന്നു
5. **Workflow Execution** - ഫലങ്ങൾ സ്ട്രീമിംഗ് സാദ്ധ്യമാക്കി വർക്‌ഫ്ലോ ഓടിക്കുന്നു
