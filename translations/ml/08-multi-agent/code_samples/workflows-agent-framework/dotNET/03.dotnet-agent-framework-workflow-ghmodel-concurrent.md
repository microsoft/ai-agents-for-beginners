## 💻 കോഡ് ഓടിക്കൽ

`03.dotnet-agent-framework-workflow-ghmodel-concurrent.cs`യിൽ പൂർണ്ണ അംശം ലഭ്യമാണ്. ഈ ഫയൽ യാത്രാ പ്ലാനിംഗിനുള്ള **Fan-Out/Fan-In ഏകകാല വർക്ക്ഫ്ലോ** കാണിക്കുന്നു:

### 🏗️ **വർക്ക്ഫ്ലോ ആർക്കിടെക്ചർ**

```
User Request → ConcurrentStartExecutor → [Researcher Agent || Planner Agent] → ConcurrentAggregationExecutor → Final Output
```

**പ്രധാന ഘടകങ്ങൾ:**

1. **ConcurrentStartExecutor**: ഉപയോഗക്കാരന്റെ അഭ്യർ‍ത്ഥന എല്ലാ ഏജന്റുകൾക്കും ഒരേസമയം പ്രക്ഷേപിക്കുന്നു
2. **Researcher Agent**: ലക്ഷ്യസ്ഥലങ്ങളും ആകർഷണങ്ങളും ഏകകാല വിശകലനം ചെയ്യുന്നു
3. **Planner Agent**: വിശദമായ യാത്രാ പദ്ധതികൾ ഒരേസമയം സൃഷ്ടിക്കുന്നു
4. **ConcurrentAggregationExecutor**: ഇരട്ട ഏജന്റുകളിൽ നിന്നുള്ള ഫലങ്ങൾ ശേഖരിച്ച് ഒത്തു ചേർക്കുന്നു

### 🎯 **Fan-Out/Fan-In പാറ്റേൺ**

ഈ വർക്ക്ഫ്ലോ പരമ്പരാഗത **Fan-Out/Fan-In** പാറ്റേൺ കാണിക്കുന്നു:
- **Fan-Out**: ഒരു ഇൻപുട്ട് സന്ദേശം ഒരേസമയം ഉള്ള നിരവധി ഏജന്റുകൾക്ക് പ്രക്ഷേപിക്കുന്നു
- **ഏകകാല പ്രോസസ്സിംഗ്**: ഒരേ ടാസ്കിൽ നിരവധി ഏജന്റുകൾ സമാന്തരമായി പ്രവർത്തിക്കുന്നു
- **Fan-In**: എല്ലാ ഏജന്റുകളുടെ ഫലങ്ങൾ ശേഖരിച്ച് ഒരേ ഔട്ട്‌പുട്ടിൽ ഒത്തുചേർക്കുന്നു

### 📝 പ്രതീക്ഷിക്കുന്ന ഔട്ട്പുട്ട്

വർക്ക്ഫ്ലോ ചെയ്യുന്നത്:
1. **Broadcast Request**: "ഡിസംബർ മാസത്തിൽ സിയാറ്റിലിലേക്കുള്ള യാത്രയുടെ പദ്ധതി" ഇരട്ടി ഏജന്റുകൾക്കും അയയ്ക്കുന്നു
2. **ഏകകാല പ്രോസസ്സിംഗ്**: ഇരട്ടി ഏജന്റുകളും ഒരേസമയം പ്രവർത്തിക്കുന്നു:
   - ഗവേഷകൻ ആകർഷണങ്ങളും വിശദാംശങ്ങളും തിരിച്ചറിയുന്നു
   - പ്ലാനർ യാത്രാപദ്ധതികളും ലോജിസ്റ്റിക്സും ഉണ്ടാക്കുന്നു
3. **Aggregation**: രണ്ടും ചേർത്ത് സമഗ്ര ഔട്ട്പുട്ട് സൃഷ്ടിക്കുന്നു
4. **ഫലങ്ങൾ പ്രദർശിപ്പിക്കൽ**: കൂട്ടിച്ചേർത്ത യാത്രാ പദ്ധതി മുഴുവൻ വിവരങ്ങളോടെ കാണിക്കുക

### 🔍 ഇഷ്ടാനുസൃത എക്സിക്യുട്ടറുകൾ മനസ്സിലാക്കൽ

**ConcurrentStartExecutor:**
- `IMessageHandler<string>` നടപ്പാക്കുന്നു, പിൻവാങ്ങൽ അനുവദിക്കുന്നു
- ബന്ധിപ്പിച്ച എല്ലാ ഏജന്റുകൾക്കും സന്ദേശങ്ങൾ പ്രക്ഷേപിക്കുന്നു
- ഏകകാല പ്രോസസ്സിങ്ങിനു `TurnToken` അയയ്ക്കുന്നു

**ConcurrentAggregationExecutor:**
- `IMessageHandler<ChatMessage>` നടപ്പാക്കുന്നു, ഏജന്റ് പ്രതികരണങ്ങൾ സ്വീകരിക്കുന്നു
- ത്രെഡ്-സേഫ് രീതിയിൽ സന്ദേശങ്ങൾ ശേഖരിക്കുന്നു
- പ്രതീക്ഷിക്കുന്ന എല്ലാ പ്രതികരണങ്ങളും എത്തിയാൽAggregation നടത്തുന്നു
- `context.YieldOutputAsync()` ഉപയോഗിച്ച് അന്തിമ ഔട്ട്പുട്ട് നൽകിയിരിക്കുന്നു
