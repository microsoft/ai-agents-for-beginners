# ⚡ ആസ്യൂർ ഓപ്പൺഎഐ (പ്രതികരണങ്ങൾ API) ഉപയോഗിച്ച് സമകാലിക ഏജന്റ് വർക്ക്‌ഫ്ലോകൾ (.NET)

## 📋 ഉയർന്ന പ്രകടനമുള്ള സമാന്തര പ്രോസസ്സിംഗ് ട്യൂട്ടോറിയൽ

ഈ നോട്ട്‌ബുക്ക് Microsoft Agent Framework for .NET ഉം Azure OpenAI (Responses API) ഉം ഉപയോഗിച്ച് **സമകാലിക വർക്ക്‌ഫ്ലോ മാതൃകകൾ** കാണിക്കുന്നു. ഒന്നിച്ച് പ്രവർത്തിക്കുന്ന അനേകം AI ഏജന്റുമാർ ഏകസമയത്ത് നടപ്പിലാക്കി ഏകദേശം പരമാവധി ത്യാപനം പ്രാപിക്കുന്ന ഉയർന്ന പ്രകടനമുള്ള സമാന്തര പ്രോസസ്സിംഗ് വർക്ക്‌ഫ്ലോകൾ എങ്ങനെ നിർമ്മിക്കാമെന്ന് നിങ്ങൾക്ക് പഠിക്കാം, കൂടാതെ ഏകോപനം, ഡേറ്റാ സ്ഥിരത എന്നിവ പരിരക്ഷിക്കപ്പെടുന്നു.

- **Async/Await മാതൃക**: ഫലപ്രദമായ സമകാലികതയ്ക്കായി .NET ന്റെ async പ്രോഗ്രാമിംഗ് മോഡൽ ഉപയോഗിക്കുക

```xml
<!-- Azure Identity and Async LINQ for Advanced Operations -->
<PackageReference Include="Azure.Identity" Version="1.15.0" />
<PackageReference Include="System.Linq.Async" Version="6.0.3" />

<!-- Local Agent Framework References -->
<!-- Microsoft.Agents.AI.dll - Core agent abstractions with async support -->
<!-- Microsoft.Agents.AI.OpenAI.dll - Azure OpenAI (Responses API) integration with concurrency -->
```

## 💻 കോഡ് റൺ ചെയ്യൽ

പൂർണ്ണ നടപ്പാക്കൽ `03.dotnet-agent-framework-workflow-ghmodel-concurrent.cs` ഫയലിൽ ലഭ്യമാണ്. യാത്രാ പദ്ധതികളിലേക്കുള്ള **ഫാൻ-ഔട്ട്/ഫാൻ-ഇൻ സമകാലിക വർക്ക്‌ഫ്ലോ** ഇത് കാണിക്കുന്നു:

```
User Request → ConcurrentStartExecutor → [Researcher Agent || Planner Agent] → ConcurrentAggregationExecutor → Final Output
```

**പ്രധാന ഘടകങ്ങൾ:**

1. **ConcurrentStartExecutor**: ഉപയോക്തൃ അഭ്യർത്ഥന എല്ലാവരിലേക്കും ഒരേ സമയം പ്രചരിപ്പിക്കുന്നു
2. **ഗവേഷണ ഏജന്റ്**: കുറഞ്ഞ സമയത്ത് ലക്ഷ്യസ്ഥാനങ്ങളുടെയും ആകർഷണങ്ങളുടെയും വിശകലനം നടത്തുന്നു
3. **പ്ലാനർ ഏജന്റ്**: സമാന്തരമായി സഞ്ചാര പദ്ധതികൾ സൃഷ്ടിക്കുന്നു
4. **ConcurrentAggregationExecutor**: രണ്ട് ഏജന്റുമാരുടെയും ഫലങ്ങൾ ശേഖരിച്ച് സംയോജിപ്പിക്കുന്നു
