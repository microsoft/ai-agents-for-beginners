## 🌱 ആരംഭിക്കുന്നത്

ഈ കോഴ്സിൽ AI ഏജന്റുകൾ നിർമ്മിക്കുന്ന അടിസ്ഥാനപരമായ പാഠങ്ങൾ ഉൾക്കൊള്ളിച്ചിരിക്കുന്നു. ഓരോ പാഠവും തങ്ങളുടെ വിഷയം ഉൾക്കൊള്ളുന്നുവെന്ന് നിങ്ങള് ഇഷ്ടപ്പെട്ടിടത്ത് ആരംഭിക്കാം!

ഈ കോഴ്‌സിനായി ബഹുഭാഷാ പിന്തുണ ലഭ്യമാണ്. ഞങ്ങളുടെ [ലഭ്യമായ ഭാഷകൾ ഇവിടെ കാണുക](#-multi-language-support). 

ഇത് നിങ്ങളുടെ ആദ്യത്തെ സൃഷ്ടಿ Generative AI മോഡലുകളുമായി ജോലി ചെയ്യുന്നതിനായെങ്കിൽ, ഞങ്ങളുടെ [Generative AI For Beginners](https://aka.ms/genai-beginners) കോഴ്സ് പരിശോധിക്കുക, ഇതിൽ GenAI ഉപയോഗിച്ച് നിർമിക്കുന്ന 21 പാഠങ്ങൾ ഉൾക്കൊള്ളിച്ചിരിക്കുന്നു.

ഈ റെപ്പോയെ [നക്ഷത്രം (🌟)](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst) നൽകാനും [ഫോർക്ക്](https://github.com/microsoft/ai-agents-for-beginners/fork) ചെയ്ത് കോഡ് റൺ ചെയ്യാനും മറക്കേണ്ട.

### മറ്റ് പഠനാർത്ഥികളെ പരിചയപ്പെടുക, നിങ്ങളുടെ ചോദ്യങ്ങൾക്ക് മറുപടി നേടുക

നിങ്ങൾ കുടുങ്ങുകയോ AI ഏജന്റുകൾ നിർമ്മിക്കുന്നതിനെക്കുറിച്ച് ചോദ്യങ്ങളുണ്ടെങ്കിൽ, [Microsoft Foundry Discord](https://aka.ms/ai-agents/discord) ലെ നമുടെ സമർപ്പിത Discord ചാനലിൽ ചേരുക.

### നിങ്ങൾക്കുള്ളവ

ഈ കോഴ്‌സിലെ ഓരോ പാഠത്തിലും കോഡ് ഉദാഹരണങ്ങൾ ഉൾക്കൊള്ളിച്ചിരിക്കുന്നു, അവ code_samples ഫോൾഡറിൽ കണ്ടെത്താവുന്നതാണ്. നിങ്ങൾക്ക് [ഫോർക്ക്](https://github.com/microsoft/ai-agents-for-beginners/fork) ചെയ്‌തു നിങ്ങളുടെ സ്വന്തം കോപി സൃഷ്ടിക്കാം.  

ഈ അഭ്യാസങ്ങളിലെ കോഡ് ഉദാഹരണങ്ങൾ Microsoft Agent Framework ഉപയോഗിച്ച് Microsoft Foundry Agent Service V2 ഉപയോഗിക്കുന്നു:

- [Microsoft Foundry](https://aka.ms/ai-agents-beginners/ai-foundry) - Azure അക്കൗണ്ട് ആവശ്യമുണ്ട്

ഈ കോഴ്‌സ് Microsoft നും Aganet Framework നും സേവനങ്ങൾ ഉപയോഗിക്കുന്നു:

- [Microsoft Agent Framework (MAF)](https://aka.ms/ai-agents-beginners/agent-framework)
- [Microsoft Foundry Agent Service V2](https://aka.ms/ai-agents-beginners/ai-agent-service)

ചില കോഡ് സാമ്പിൾسുകൾ [MiniMax](https://platform.minimaxi.com/) പോലുള്ള OpenAI-സാന്ദ്രമായ മറ്റു പ്രൊവൈഡറുകളെ പിന്തുണയ്ക്കുന്നു, ഇത് വലിയ (204K ടോക്കൺ വരെ) കണക്കുകളും മോഡലുകളും നൽകുന്നു. സംയോജന വിവരങ്ങൾക്ക് [Course Setup](./00-course-setup/README.md) കാണുക.

ഈ കോഴ്സ് കോഡ് ഓടിക്കുന്നതിനായി കൂടുതൽ വിവരങ്ങൾക്ക് [Course Setup](./00-course-setup/README.md) കാണുക.
