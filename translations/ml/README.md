> ഈ റിപോസിറ്ററിയിൽ 50-ലധികം ഭാഷാ പരിഭാഷകൾ ഉൾപ്പെടുത്തിയിട്ടുള്ളതിനാൽ ഡൗൺലോഡ് വലുപ്പം വളരെ കൂടുതലാണ്. പരിഭാഷകൾ കൂടാതെ ക്ലോൺ ചെയ്യുവാൻ sparse checkout ഉപയോഗിക്കുക:
>
> **Bash / macOS / Linux:**
> ```bash
> git clone --filter=blob:none --sparse https://github.com/microsoft/ai-agents-for-beginners.git
> cd ai-agents-for-beginners
> git sparse-checkout set --no-cone '/*' '!translations' '!translated_images'
> ```
>
> **CMD (Windows):**
> ```cmd
> git clone --filter=blob:none --sparse https://github.com/microsoft/ai-agents-for-beginners.git
> cd ai-agents-for-beginners
> git sparse-checkout set --no-cone "/*" "!translations" "!translated_images"
> ```
>
> ഇത് വളരെ വേഗത്തിൽ ഡൗൺലോഡ് ചെയ്ത് കോഴ്‌സ് പൂര്‍ത്തിയാക്കുവാന്‍ ആവശ്യമായ എല്ലാം സെറ്റപ്പ് ചെയ്യാം.

## 🌱 തുടക്കം കുറിക്കൽ

ഈ കോഴ്‌സിൽ AI ഏജന്റ്മാർ നിർമ്മിക്കുന്ന അടിസ്ഥാനങ്ങൾ ഉൾക്കൊള്ളുന്നതാണ്. ഓരോ പാഠവും തനും തിരിച്ച പഠിക്കാവുന്നതല്ല, ഇഷ്ടാനുസരിച്ച് തുടങ്ങാം!

ഈ കോഴ്‌സിന് ബഹുഭാഷാ പിന്തുണ ഉണ്ട്. നമ്മുടെ [ലഭ്യമായ ഭാഷകൾ ഇവിടെ കാണുക](#-multi-language-support).

നിങ്ങൾ ആദ്യമായി Generative AI മോഡലുകള്‍ ഉപയോഗിച്ച് നിര്‍മിക്കുകയാണെങ്കിൽ, ഞങ്ങളുടെ [Generative AI For Beginners](https://aka.ms/genai-beginners) കോഴ്‌സ് പരിശോധിക്കുക, ഇത് GenAI ഉപയോഗിച്ച് 21 പാഠങ്ങൾ ഉൾക്കൊള്ളുന്നു.

ഈ റിപോസിറ്ററിയിൽ [സ്റ്റാർ (🌟) നൽകാനും](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst) [ഫോർക്കുചെയ്യാനും](https://github.com/microsoft/ai-agents-for-beginners/fork) മറക്കേണ്ട.

### മറ്റ് പഠനക്കാർക്ക് കൂടിക്കാഴ്ച നടത്താനും നിങ്ങളുടെ ചോദ്യങ്ങൾക്ക് ഉത്തരം ലഭിക്കാനും

നിങ്ങൾ തടസ്സപ്പെടുകയാണെങ്കിൽ അല്ലെങ്കിൽ AI ഏജന്റ്മാർ നിർമ്മിക്കുന്നതു സംബന്ധിച്ച ചോദ്യങ്ങൾ ഉണ്ടെങ്കിൽ, ഞങ്ങളുടെ പ്രത്യേക Discord ചാനലിൽ പങ്കെടുക്കുക [Microsoft Foundry Discord](https://aka.ms/ai-agents/discord).

### നിങ്ങള്‍ക്കു വേണ്ടത്

ഈ കോഴ്‌സിലെ ഓരോ പാഠത്തിലും കോഡ് ഉദാഹരണങ്ങൾ ഉൾക്കൊള്ളുന്നു, അവ code_samples ഫോൾഡറിൽ കണ്ടെത്താം. നിങ്ങളുടെ സ്വന്തം കോപ്പി സൃഷ്ടിക്കുവാൻ [ഈ റിപോസിറ്ററി ഫോർക്കുചെയ്യൂ](https://github.com/microsoft/ai-agents-for-beginners/fork).

ഈ വ്യായാമങ്ങളിലെ കോഡ് ഉദാഹരണങ്ങൾ Microsoft Agent Framework ഉപയോഗിച്ച് Microsoft Foundry Agent Service V2 ഉപയോഗിക്കുന്നു:

- [Microsoft Foundry](https://aka.ms/ai-agents-beginners/ai-foundry) - Azure അക്കൗണ്ട് ആവശ്യമാണ്

ഈ കോഴ്‌സ് Microsoft നൽകരുതുന്ന താഴെപ്പറയുന്ന AI ഏജന്റ് ഫ്രെയിംവർക്കുകളും സേവനങ്ങളും ഉപയോഗിക്കുന്നു:

- [Microsoft Agent Framework (MAF)](https://learn.microsoft.com/agent-framework/overview/)
- [Microsoft Foundry Agent Service V2](https://aka.ms/ai-agents-beginners/ai-agent-service)

ചില കോഡ് സാമ്പിളുകൾ [MiniMax](https://platform.minimaxi.com/) പോലെയുള്ള OpenAI-യുമായി അനുയോജ്യമായ മറ്റും ചേരുന്നവയ്ക്കും പിന്തുണ നൽകുന്നു, որոնք വലിയ കോൺടെക്സ്റ്റ് മോഡലുകൾ (204K ടോക്കൺ വരെ) നൽകുന്നു. കൺഫിഗറേഷൻ വിശദാംശങ്ങൾക്കായി [കോഴ്‌സ് സെറ്റ്അപ്പ്](./00-course-setup/README.md) കാണുക.

ഈ കോഴ്‌സിനായുള്ള കോഡ് നടപ്പാക്കുന്നതിന് കൂടുതൽ വിവരങ്ങൾക്ക് [കോഴ്‌സ് സെറ്റ്അപ്പ്](./00-course-setup/README.md) കാണുക.
