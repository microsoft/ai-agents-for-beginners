## 🌱 തുടങ്ങാം

ഈ കോഴ്‌സ് AI ഏജന്റുകൾ നിർമ്മിക്കുന്ന അടിസ്ഥാനങ്ങൾ ആസ്പദമാക്കി പാഠങ്ങൾ ഉൾക്കൊള്ളുന്നു. ഓരോ പാഠവും തന്റെ വിഷയത്തെ അടിസ്ഥാനമാക്കിയുള്ളതാണ്, നിങ്ങൾക്ക് ഇഷ്ടമുള്ളതിടത്ത് നിന്ന് തുടങ്ങിയാലും 됩니다!

ഈ കോഴ്‌സിന് ബഹുഭാഷാ പിന്തുണ ഉണ്ട്. ഞങ്ങളുടെ [ലഭ്യമായ ഭാഷകൾ ഇവിടെ](#-multi-language-support) കാണുക.

നിങ്ങൾ ആദ്യമായി ജനറേറ്റീവ് AI മോഡലുകളുമായി പ്രവർത്തിക്കുന്നുവെങ്കിൽ, 21 പാഠങ്ങളുള്ള [തുടക്കക്കാർക്കുള്ള ജനറേറ്റീവ് AI](https://aka.ms/genai-beginners) കോഴ്‌സ് നോക്കൂ.

[ഈ റിപ്പോയ്ക്ക് സ്റ്റാർ (🌟) നൽകാനും](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst) [റിപ്പോ ഫോർക്കുചെയ്യാനും](https://github.com/microsoft/ai-agents-for-beginners/fork) മറക്കരുത്, കോഡ് പ്രവർത്തിപ്പിക്കാൻ.

### മറ്റു പഠിതാക്കളുമായി சந்தിക്കുക, നിങ്ങളുടെ ചോദ്യങ്ങൾക്ക് മറുപടി ലഭിക്കുക

AI ഏജന്റുകൾ നിർമ്മിക്കുന്നതിൽ നിങ്ങൾക്ക് ബുദ്ധിമുട്ട് ഉണ്ടെങ്കിൽ അല്ലെങ്കിൽ ചോദ്യങ്ങൾ ഉണ്ടായാൽ, [Microsoft Foundry Discord](https://aka.ms/ai-agents/discord) ൽ ഞങ്ങളുടെ സമർപ്പിത Discord ചാനലിൽ ചേരുക.

### നിങ്ങൾക്ക് ആവശ്യമുള്ളത്

ഈ കോഴ്‌സിലെ ഓരോ പാഠവും കോഡ് ഉദാഹരണങ്ങളും ഉൾക്കൊള്ളുന്നു, അത് code_samples ഫോൾഡറിൽ കാണാം. നിങ്ങളുടെ സ്വന്തം കോപ്പി സൃഷ്ടിക്കാൻ [ഈ റിപ്പോ ഫോര്‍ക്ക് ചെയ്യുക](https://github.com/microsoft/ai-agents-for-beginners/fork).

ഈ വ്യായാമങ്ങളിലെ കോഡ് ഉദാഹരണങ്ങൾMicrosoft Agent Framework മൈക്രോസോഫ്റ്റ് ഫൗണ്ട്രി ഏജന്റ് സർവീസ് V2 ഉപയോഗിക്കുന്നു:

- [Microsoft Foundry](https://aka.ms/ai-agents-beginners/ai-foundry) - Azure അക്കൗണ്ട് ആവശ്യമാണ്

ഈ കോഴ്‌സ്Microsoft നൽ‌കുന്ന താഴെ പറയുന്ന AI ഏജന്റ് ഫ്രെയിമ്വർക്കുകളും സർവീസുകളും ഉപയോഗിക്കുന്നു:

- [Microsoft Agent Framework (MAF)](https://learn.microsoft.com/agent-framework/overview/)
- [Microsoft Foundry Agent Service V2](https://aka.ms/ai-agents-beginners/ai-agent-service)

ചില കോഡ് സാമ്പിളുകൾ ഓപ്പൺഎഐ-സമൃദ്ധ പ്രൊവൈഡറായ [MiniMax](https://platform.minimaxi.com/) പോലുള്ള മറ്റ് പ്രൊവൈഡറുകളേയും പിന്തുണയ്ക്കുന്നു, കൂടാതെ 204K ടോക്കണുകൾ വരെ വലിയ കണ്ടെക്‌സ്‌റ്റ് മോഡലുകൾ നൽകുന്നു. ക്രമീകരണ വിവരംക്കായി [കോഴ്‌സ് സെറ്റപ്പ്](./00-course-setup/README.md) കാണുക.

ഈ കോഴ്‌സിനു വേണ്ടിയുള്ള കോഡ് റണ്ണ് ചെയ്യുന്നതിനെക്കുറിച്ച് കൂടുതൽ വിവരങ്ങൾക്ക് [കോഴ്‌സ് സെറ്റപ്പ്](./00-course-setup/README.md) കാണുക.
