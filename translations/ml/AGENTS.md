## പ്രോജക്ട് അവലോകനം

ഈ റപ്പോസിറ്ററിയിൽ "ആർ സി. ഐ. ഏജന്റുകൾ തുടങ്ങുന്നവർക്ക്" എന്ന ഒരു സമഗ്ര വിദ്യാഭ്യാസ കോഴ്‌സ് സഞ്ചരിക്കുന്നു, AI ഏജന്റുകൾ നിർമ്മിക്കാൻ ആവശ്യമായ എല്ലാ കാര്യങ്ങളും പഠിപ്പിക്കുന്നതാണ്. കോഴ്‌സിൽ AI ഏജന്റുകളുടെ അടിസ്ഥാനങ്ങൾ, രൂപകൽപന മാതൃകകൾ, ഫ്രെയിംവർക്ക്‌കൾ, ഉൽപ്പാദന വിന്യാസം എന്നിവയെക്കുറിച്ചുള്ള 18 പാഠങ്ങൾ ഉൾപ്പെടുന്നു.

**പ്രധാന സാങ്കേതികവിദ്യകൾ:**
- Python 3.12+
- ഇൻട്രാക്റ്റീവ് പഠനത്തിന് Jupyter നോട്ട്‌ബുക്കുകൾ
- AI ഫ്രെയിംവർക്ക്: Microsoft Agent Framework (MAF)
- Azure AI സേവനങ്ങൾ: Microsoft Foundry, Microsoft Foundry Agent Service V2

**ആർക്കിടെക്ചർ:**
- പാഠത്തിനനുസരിച്ചുള്ള ഘടന (00-15+ ഡയറക്ടറികൾ)
- ഓരോ പാഠത്തിലും: README ഡോക്യുമെന്റേഷൻ, കോഡ് സാമ്പിൾസ് (Jupyter നോട്ട്‌ബുക്കുകൾ), ചിത്രങ്ങൾ
- സ്വയംപരിവർത്തന സംവിധാനം വഴി ബഹുഭാഷാ പിന്തുണ
- Microsoft Agent Framework ഉപയോഗിച്ച് ഓരോ പാഠത്തിനും ഒരു Python നോട്ട്‌ബുക്ക്

## സജ്ജീകരണ കമാൻഡുകൾ

### മുൻവൈദ്യാപിക
- Python 3.12 അല്ലെങ്കിൽ ഉയർന്ന പതിപ്പ്
- Azure സബ്സ്ക്രിപ്ഷൻ (Microsoft Foundry-ക്കായി)
- Azure CLI ഇൻസ്റ്റാൾ ചെയ്ത് ലോഗിൻ ചെയ്യുക (`az login`)

### പ്രാഥമിക അവസ്ഥ

1. **റപ്പോസിറ്ററി ക്ലോൺ ചെയ്യുക അല്ലെങ്കിൽ ഫോർക്കു ചെയ്യുക:**
   ```bash
   gh repo fork microsoft/ai-agents-for-beginners --clone
   # അല്ലെങ്കിൽ
   git clone https://github.com/microsoft/ai-agents-for-beginners.git
   cd ai-agents-for-beginners
   ```

2. **Python വെർച്ച്വൽ എൻവയറൻമെന്റ് സൃഷ്ടിച്ച് സജീവമാക്കുക:**
   ```bash
   python3 -m venv venv
   source venv/bin/activate  # വിൻഡോസിൽ: venv\Scripts\activate
   ```

3. **ആവശ്യമായ ഡിപ്പെൻഡൻസികൾ ഇൻസ്റ്റാൾ ചെയ്യുക:**
   ```bash
   pip install -r requirements.txt
   ```

4. **എൻവയറൻമെന്റ് വേരിയബിൾസ് സെറ്റപ്പ് ചെയ്യുക:**
   ```bash
   cp .env.example .env
   # നിങ്ങളുടെ API കീകളും.ENDPOINTS കൂടാതെ .env എഡിറ്റ് ചെയ്യുക
   ```

### ആവശ്യമുള്ള എൻവയറൻമെന്റ് വേരിയബിൾസ്

**Microsoft Foundry** (ആവശ്യമാണ്):
- `AZURE_AI_PROJECT_ENDPOINT` - Microsoft Foundry പ്രോജക്ട് എൻഡ്പോയിന്റ്
- `AZURE_AI_MODEL_DEPLOYMENT_NAME` - മോഡൽ വിന്യാസ നാമം (ഉദാ: gpt-4o)

**Azure AI Search** (പാഠം 05 - RAG):
- `AZURE_SEARCH_SERVICE_ENDPOINT` - Azure AI Search എൻഡ്പോയിന്റ്
- `AZURE_SEARCH_API_KEY` - Azure AI Search API കീ

അംഗീകാരം: നോട്ട്‌ബുക്കുകൾ പ്രവർത്തിക്കുന്നതിന് മുമ്പ് `az login` ഓടിക്കുക (`AzureCliCredential` ഉപയോഗിക്കുന്നു).

## വികസന പ്രവാഹം

### Jupyter നോട്ട്‌ബുക്കുകൾ പ്രവർത്തിപ്പിക്കൽ

ഓരോ പാഠത്തിലും വ്യത്യസ്ത ഫ്രെയിംവർക്കുകൾക്കായി നിരവധി Jupyter നോട്ട്‌ബുക്കുകൾ ഉണ്ടാകും:

1. **Jupyter ആരംഭിക്കുക:**
   ```bash
   jupyter notebook
   ```

2. **ഒരു പാഠ ഡയറക്ടറിയിലേക്ക് നാവിഗേറ്റ് ചെയ്യുക** (ഉദാ: `01-intro-to-ai-agents/code_samples/`)

3. **നോട്ട്‌ബുക്കുകൾ തുറന്ന് ഓടിക്കുക:**
   - `*-python-agent-framework.ipynb` - Microsoft Agent Framework ഉപയോഗിച്ച് (Python)
   - `*-dotnet-agent-framework.ipynb` - Microsoft Agent Framework ഉപയോഗിച്ച് (.NET)

### Microsoft Agent Framework ഉപയോഗിച്ച് പ്രവർത്തിക്കൽ

**Microsoft Agent Framework + Microsoft Foundry:**
- Azure സബ്സ്ക്രിപ്ഷൻ ആവശ്യമുണ്ട്
- Agent Service V2-ക്കായി `FoundryChatClient` ഉപയോഗിക്കുന്നു (Foundry പോർട്ടലിൽ ഏജന്റുകൾ കാണപ്പെടുന്നു)
- നിർമ്മാണത്തിനായി സജ്ജം, ഇൻബിൽറ്റ് ഒബ്സർവബിലിറ്റി
- ഫയൽ പാറ്റേൺ: `*-python-agent-framework.ipynb`

### സാധാരണ പ്രശ്നങ്ങൾ

1. **Python പതിപ്പിന്റെ പൊരുത്തക്കേട്:**
   - Python 3.12+ ഉപയോഗിക്കുന്നത് ഉറപ്പാക്കുക
   - പഴയ പതിപ്പുകളുമായോ ചില പാക്കേജുകൾ പ്രവർത്തിക്കില്ല
   - Python പതിപ്പ് നിശ്ചയിക്കാൻ `python3 -m venv` ഉപയോഗിക്കുക

2. **എൻവയറൻമെന്റ് വേരിയബിൾസ്:**
   - എല്ലായ്പ്പോഴും `.env.example`-ൽ നിന്നു `.env` സൃഷ്ടിക്കുക
   - `.env` ഫയൽ കമ്മിറ്റ് ചെയ്യരുത് (`.gitignore`-ൽ ഉൾക്കൊള്ളുന്നു)
   - കീ-ലെസ് Entra ID അംഗീകാരംക്ക് `az login` ഉപയോഗിച്ച് സൈൻ ഇൻ ചെയ്യുക

3. **പാക്കേജ് കോൺഫ്ലിക്റ്റുകൾ:**
   - പുതിയ വെർച്ച്വൽ എൻവയറൻമെന്റ് ഉപയോഗിക്കുക
   - വ്യത്യസ്ത പാക്കേജുകളുടെ പകരം `requirements.txt` വഴിയാണ് ഇൻസ്റ്റാൾ
   - ചില നോട്ട്‌ബുക്കുകൾ തങ്ങളുടെ മാർക്ക്‌ഡൗൺ സെല്ലുകളിൽ ആവശ്യമായ പാക്കേജുകൾ പരാമർശിച്ചേക്കും

4. **Azure സേവനങ്ങൾ:**
   - Azure AI സേവനങ്ങൾക്ക് സജീവ സബ്സ്ക്രിപ്ഷൻ ആവശ്യം
   - ചില സവിശേഷതകൾ പ്രദേശം-സ്പെസിഫിക് ആണ്
   - നിങ്ങളുടെ Azure OpenAI മോഡൽ വിന്യാസം Responses API പിന്തുണയ്‌ക്കണം
