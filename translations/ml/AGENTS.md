# AGENTS.md

## പ്രോജעקטിന്റെSamgrahaനം

ഈ റെപ്പോസിറ്ററി "AI ഏജൻറുകൾ തുടങ്ങിവർക്കായി" എന്ന ദൈർഘ്യമേറിയ വിദ്യാഭ്യാസ കോഴ്സ് ഉൾക്കൊള്ളുന്നു - AI ഏജൻറുകൾ നിർമ്മിക്കാൻ ആവശ്യമായ എല്ലാം പഠിപ്പിക്കുന്ന ഒരു സമഗ്രമായ കോഴ്സ്. ഈ കോഴ്‌സിൽ 18 പാഠങ്ങൾ (00-18 സംഖ്യകൾ ആയി നമ്പർ ചെയ്തതു) അടങ്ങിയിരിക്കുന്നു, അടിസ്ഥാനങ്ങൾ, ഡിസൈൻ മാതൃകകൾ, ഫ്രെയിംവർക്കുകൾ, പ്രൊഡക്ഷൻ വിന്യാസം, ലൊക്കൽ/ഡിവൈസ് ഏജൻറുകൾ, AI ഏജൻറുകളുടെ സുരക്ഷ എന്നിവ ഉൾപ്പെടുന്നു.

**പ്രധാന സാങ്കേതികവിദ്യകൾ:**
- Python 3.12+
- ഇന്ററാക്ടീവ് പഠനത്തിന് Jupyter നോട്ട്‌ബുക്കുകൾ
- AI ഫ്രെയിംവർക്കുകൾ: Microsoft Agent Framework (MAF)
- Azure AI സേവനങ്ങൾ: Microsoft Foundry, Microsoft Foundry Agent Service V2

**ആർക്കിടെക്ചർ:**
- പാഠം അടിസ്ഥാനത്തിലുള്ള ഘടന (00-18 ഡയറക്ടറികൾ)
- ഓരോ പാഠത്തിലും ഉൾപ്പെടുന്നു: README പ്രമാണം, കോഡ് ഉദാഹരണങ്ങൾ (Jupyter നോട്ട്‌ബുക്കുകൾ), ചിത്രങ്ങൾ
- സ automated അര്‍ദ്ദഭാഷ പരിഭാഷ സംവിധാനം വഴി ബഹുഭാഷ പിന്തുണ
- ഓരോ പാഠത്തിനും Microsoft Agent Framework ഉപയോഗിച്ച് ഒരുപPython നോട്ട്‌ബുക്ക്

## സെറ്റപ്പ് കമാൻഡുകൾ

### ആവശ്യമായ മുൻകൂർ ശിപാർശകൾ
- Python 3.12 അല്ലെങ്കിൽ അതിന് മുകളിലെ പതിപ്പ്
- Azure സബ്സ്ക്രിപ്ഷൻ (Microsoft Foundryയ്ക്കായി)
- Azure CLI ഇൻസ്റ്റാൾ ചെയ്ത് അംഗീകാരമിൽ (`az login`)

### പ്രാഥമിക സെറ്റപ്പ്

1. **റെപ്പോസിറ്ററി ക്ലോൺ ചെയ്യുക അല്ലെങ്കിൽ ഫോർക്ക് ചെയ്യുക:**
   ```bash
   gh repo fork microsoft/ai-agents-for-beginners --clone
   # OR
   git clone https://github.com/microsoft/ai-agents-for-beginners.git
   cd ai-agents-for-beginners
   ```

2. **Python വിർച്വൽ എൻവയോൺമെന്റ് സൃഷ്ടിച്ച് ആക്ടിവേറ്റ് ചെയ്യുക:**
   ```bash
   python3 -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   ```

3. **ഡിപ്പൻഡൻസികൾ ഇൻസ്റ്റാൾ ചെയ്യുക:**
   ```bash
   pip install -r requirements.txt
   ```

4. **പരിസ്ഥിതി വേരിയബിൾസെറ്റപ്പ് ചെയ്യുക:**
   ```bash
   cp .env.example .env
   # Edit .env with your API keys and endpoints
   ```

### ആവശ്യമുള്ള പരിസ്ഥിതി വ്യരിയബിൾസ്

**Microsoft Foundry** (ആവശ്യമാണ്)ക്ക്:
- `AZURE_AI_PROJECT_ENDPOINT` - Microsoft Foundry പ്രോജക്ട് എൻഡ്‌പോയിന്റ്
- `AZURE_AI_MODEL_DEPLOYMENT_NAME` - മോഡൽ വിന്യസത്തിന്റെ പേര് (ഉദാ: gpt-5-mini)

**Azure AI Search** (പാഠം 05 - RAG)ക്ക്:
- `AZURE_SEARCH_SERVICE_ENDPOINT` - Azure AI Search എൻഡ്‌പോയിന്റ്
- `AZURE_SEARCH_API_KEY` - Azure AI Search API കീ

അംഗീകാരം: നോട്ട്‌ബുക്കുകൾ പ്രവർത്തിപ്പിക്കുന്നതിന് മുമ്പ് `az login` നടത്തുക (ഉപയോഗിക്കുന്നു `AzureCliCredential`).

## വികസന പ്രവൃത്തി പ്രവാഹം

### Jupyter നോട്ട്‌ബുക്കുകൾ പ്രവർത്തിപ്പിക്കൽ

ഓരോ പാഠത്തിലും വ്യത്യസ്ത ഫ്രെയിംവർക്കുകൾക്കായി വിവിധ Jupyter നോട്ട്‌ബുക്കുകൾ ഉൾക്കൊള്ളുന്നു:

1. **Jupyter ആരംഭിക്കുക:**
   ```bash
   jupyter notebook
   ```

2. **ഒരു പാഠ ഡയറക്ടറിയിലേക്ക് നവിഗേറ്റ് ചെയ്യുക** (ഉദാ: `01-intro-to-ai-agents/code_samples/`)

3. **നോട്ട്‌ബുക്കുകൾ തുറന്ന് പ്രവർത്തിപ്പിക്കുക:**
   - `*-python-agent-framework.ipynb` - Microsoft Agent Framework (Python) ഉപയോഗിച്ച്
   - `*-dotnet-agent-framework.ipynb` - Microsoft Agent Framework (.NET) ഉപയോഗിച്ച്

### Microsoft Agent Framework ഉപയോഗിച്ച് പ്രവർത്തിക്കൽ

**Microsoft Agent Framework + Microsoft Foundry:**
- Azure സബ്സ്ക്രിപ്ഷൻ ആവശ്യമാണ്
- `FoundryChatClient` ഉപയോഗിക്കുന്നു Agent Service V2-ക്കായി (Foundry പോർട്ടലിൽ ഏജൻറുകൾ കാണാവുന്നതാണ്)
- നിർമ്മാണത്തിന് സജ്ജമായത് അന്തർഗ്ഗത നിരീക്ഷണ ശേഷിയോടുകൂടി
- ഫയൽ മാതൃക: `*-python-agent-framework.ipynb`

## ടെസ്റ്റിംഗ് നിർദ്ദേശങ്ങൾ

ഇത് ഒരു വിദ്യാഭ്യാസ റിപോസിറ്ററി ആണ് ഉദാഹരണ കോഡുകളോടുകൂടി, നിർമാണ കോഡ് അല്ല, ഓട്ടോമേറ്റഡ് ടെസ്റ്റുകൾ ചേര്‍ക്കപ്പെട്ടിട്ടില്ല. നിങ്ങളുടെ സെറ്റപ്പ് ശരിയാണെന്ന് നിർണയിക്കാൻ:

### കൈയടച്ചുള്ള ടെസ്റ്റിംഗ്

1. **Python പരിസ്ഥിതി പരിശോധിക്കുക:**
   ```bash
   python --version  # Should be 3.12+
   pip list | grep -E "(agent-framework|azure-ai|azure-identity)"
   ```

2. **നോട്ട്‌ബുക്ക് എക്സിക്യൂഷൻ ടെസ്റ്റ് ചെയ്യുക:**
   ```bash
   # Convert notebook to script and run (tests imports)
   jupyter nbconvert --to script <lesson-folder>/code_samples/<notebook>.ipynb --stdout | python
   ```

3. **പരിസ്ഥിതി വേരിയബിൾസ് സ്ഥിരീകരിക്കുക:**
   ```bash
   python -c "import os; from dotenv import load_dotenv; load_dotenv(); print('✓ AZURE_AI_PROJECT_ENDPOINT' if os.getenv('AZURE_AI_PROJECT_ENDPOINT') else '✗ AZURE_AI_PROJECT_ENDPOINT missing')"
   ```

### വ്യക്തിഗത നോട്ട്‌ബുക്കുകൾ പ്രവർത്തിപ്പിക്കൽ

Jupyter-ൽ നോട്ട്‌ബുക്കുകൾ തുറന്ന് സെല്ലുകൾ ക్రమം പാലിച്ച് പ്രവർത്തിപ്പിക്കുക. ഓരോ നോട്ട്‌ബുക്കും സ്വയംപര്യാപ്തമാണ്, ഇതിൽ ഉൾപ്പെടുന്നവ:
- ഇറക്കുമതി പ്രസ്താവനകൾ
- ഉപയോഗ ക്രമീകരണങ്ങൾ ലോഡ് ചെയ്‌തൽ
- ഉദാഹരണ ഏജൻറ് നടപ്പാക്കലുകൾ
- markdown സെല്ലുകളിൽ പ്രതീക്ഷിക്കുന്ന ഔട്ട്‌പുട്ടുകൾ

### വിന്യസിച്ച ഏജൻറുകളുടെ സ്മോക്ക്-ടെസ്റ്റിംഗ്

Microsoft Foundry ഹോസ്റ്റുചെയ്ത ഏജൻറുകൾ വിന്യസിച്ച പാഠങ്ങളിൽ (01, 04, 05, 16), ഈ റെപ്പോ സ്മോക്ക്-ടെസ്റ്റ് കാറ്റലോഗുകൾ `tests/` അണിയിച്ചിരിക്കുന്നു, അവ `.github/workflows/smoke-test.yml` പ്രവൃത്തി പ്രവാഹം വഴി [AI Smoke Test](https://github.com/marketplace/actions/ai-smoke-test) ആക്ഷൻ ഉപയോഗിച്ചു പ്രവർത്തിക്കുന്നു. ഇത് ഹല്കാ പോസ്റ്റ്-ഡിപ്ലോയ് ഗേറ്റ് ആണ് (ഏജൻറ് എത്താനാകുമോ, പ്രാഥമിക പ്രാമ്പ്റ്റ് പ്രതീക്ഷകൾ പാലിക്കുന്നുണ്ടോ?), പാഠം 10, 16-ലെ മൂല്യനിർണയ കണിക്‌ഷുകളെ പൂർത്തിയാക്കുന്നതായി. കാറ്റലോഗ്-തേസ്-ലേസൺ-തിന്റേത് [tests/README.md](./tests/README.md) കാണുക. പാഠം 17 ലൊക്കലായാണ് Foundry Local ഉപയോഗിച്ച് പ്രവർത്തിക്കുന്നത്, ഹോസ്റ്റുചെയ്ത എൻഡ്‌പോയിന്റ് ഇല്ല, അതിനാൽ അത് നേരിട്ട് നോട്ട്‌ബുക്ക് പ്രവർത്തനത്തിലൂടെ പരിശോധിക്കപ്പെടുന്നു.
