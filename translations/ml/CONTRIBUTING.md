# സംഭാവനകൾ

ഈ പദ്ധതി സംഭാവനകളും നിർദേശങ്ങളും സ്വാഗതം ചെയ്യുന്നു. നിങ്ങളുടെ സംഭാവന ഉപയോഗിക്കാൻ നിങ്ങൾക്ക് അവകാശം ഉള്ളതും പ്രായോഗികമായി അവകാശങ്ങൾ നൽകുന്നതായി പ്രഖ്യാപിക്കുന്ന ഒരു Contributor License Agreement (CLA) നിങ്ങൾക്ക് സമ്മതിക്കേണ്ടത് ആവശ്യമാണ്. വിശദാംശങ്ങൾക്ക്, <https://cla.opensource.microsoft.com> സന്ദർശിക്കുക.

നിങ്ങൾ ഒരു പുൾ അഭ്യർത്ഥന സമർപ്പുമ്പോൾ, CLA ബോട്ട് സ്വയം നിങ്ങൾക്ക് CLA നൽകേണ്ടതുണ്ടോ എന്ന് കണ്ടെത്തും, പുൾ അഭ്യർത്ഥന ആ അനുസരിച്ച് അലങ്കരിക്കും. ബോട്ട് നൽകിയ നിർദ്ദേശങ്ങൾ പാലിക്കുക. മൈക്രോസോഫ്റ്റ് CLA ഉപയോഗിക്കുന്ന റിപോസിറ്ററികൾക്കിടയിൽ ഇത് നിങ്ങൾ ഒരു തവണ മാത്രം ചെയ്യേണ്ടതാണ്.

## നടത്തിപ്പിന്റെ നിയമങ്ങൾ

ഈ പദ്ധതി [Microsoft Open Source Code of Conduct](https://opensource.microsoft.com/codeofconduct/) സ്വീകരിച്ചിട്ടുണ്ട്. കൂടുതൽ വിവരങ്ങൾക്ക്, [Code of Conduct FAQ](https://opensource.microsoft.com/codeofconduct/faq/) കാണുക അല്ലെങ്കിൽ അധിക ചോദിച്ചലുകൾക്കായി [opencode@microsoft.com](mailto:opencode@microsoft.com) ൽ ബന്ധപ്പെടുക.

## പുൾ അഭ്യർത്ഥന മാർഗ്ഗനിർദേശങ്ങൾ

- ഓരോ പുൾ അഭ്യർത്ഥനയും ഒരു ലൊജിക്കൽ മാറ്റത്തിൽ മാത്രം കേന്ദ്രീകരിക്കുക.
- സമർപ്പിക്കുന്നതിന് മുൻപ് ബാധിക്കപ്പെട്ട നോട്ട്‌ബുക്കുകളും കോഡ് സാമ്പിളുകളും ടെസ്റ്റ് ചെയ്യുക.
- ഉദാഹരണങ്ങൾ ചേർക്കുമ്പോൾ അല്ലെങ്കിൽ മാറ്റുമ്പോൾ ബന്ധപ്പെട്ട പാഠം രേഖകൾ അപ്‌ഡേറ്റ് ചെയ്യുക.
- ഇംഗ്ലീഷ് ഉറവിട ഉള്ളടക്കം മാത്രമേ ഇഡിറ്റ് ചെയ്യരുത്. വിവർത്തനങ്ങൾ ഓട്ടോമേറ്റഡ് ട്രാൻസ്ലേഷൻ വർക്ക്‌ഫ്ലോ വഴി പാലിക്കുന്നു.
- ക്രെഡൻഷ്യൽസ്, `.env` ഫയലുകൾ, താൽക്കാലിക ഫയലുകൾ, അല്ലെങ്കിൽ സൃഷ്ടിച്ച ഡെവലപ്പ്മെന്റ് ആർട്ടിഫാക്ടുകൾ കമ്മിറ്റ് ചെയ്യരുത്.

## ആഷാസം പരിധി, തൃത്‌യ-പാർട്ടി ഉൽപ്പന്നങ്ങൾ

ഈ പാഠ്യപദ്ധതി മൈക്രോസോഫ്റ്റ് സാങ്കേതികവിദ്യകളിലും വെൻഡർ-ന്യുട്ട്രൽ ഓപ്പൺ സ്റ്റാൻഡേർഡുകളിലും കേന്ദ്രീകരിക്കുന്നു. സംഭാവനകൾ വ്യക്തമായ വിദ്യാഭ്യാസ ലക്ഷ്യത്തിനായിരിക്കണം, മാത്രമല്ല ഒരു തൃത്‌യ-പാർട്ടി വാണിജ്യ ഉൽപ്പന്നം, ഹോസ്റ്റ് ചെയ്ത സേവനം, മോഡൽ റൂട്ടർ, SDK, MCP സർവർ മറ്റു വെൻഡർ-നിർദിഷ്ട ഓഫറിംഗുകൾ പരിചയപ്പെടുത്തുക അല്ലെങ്കിൽ പ്രചരിപ്പിക്കുക എന്ന ഹ്രസ്വ ലക്ഷ്യമില്ലാതിരിക്കണം.

ഒരു ഓപ്പൺ സ്റ്റാൻഡേർഡ് അല്ലെങ്കിൽ ഇന്റർഓപ്പറബിലിറ്റി സീനാരിയോ വിശദീകരിക്കാൻ ആവശ്യമുണ്ടെങ്കിൽ മാത്രമേ ഓപ്പൺ-സോഴ്‌സ് സോഫ്റ്റ്‌വെയർ, തൃത്‌യ-പാർട്ടി ഡിപെൻഡൻസികൾ പരാമർശിക്കാവൂ, അവ ന്യൂട്രൽ ആയി അവതരിപ്പിക്കപ്പെടണം, വെൻഡറും ഹോസ്റ്റ് ചെയ്ത എൻഡ് പോയിന്റും കേന്ദ്രീകരിക്കരുത്. നിങ്ങളുടെ നിർദ്ദേശിക്കുന്ന സംഭാവന വേണമെങ്കിൽ വെൻഡർ-നിർദിഷ്ട ഉൽപ്പന്നം അല്ലെങ്കിൽ സേവനം ഉൾപ്പെടുത്തിയിരിക്കാൻ, ഒരു പിശക് തുറന്നു, മെയിന്റെയ്നർ അംഗീകാരം നേടുക, തുടർന്ന് പുൾ അഭ്യർത്ഥന സമർപ്പിക്കുക.

സംഭാവനക്കാർക്ക് അവരുടെ സംഭാവനയിൽ പരാമർശിക്കുന്ന ഉൽപ്പന്നം അല്ലെങ്കിൽ സേവനവുമായി ബന്ധപ്പെട്ട ഏതെങ്കിലും തൊഴിൽ, ഉടമസ്ഥത, പറ്റവം, അല്ലെങ്കിൽ മറ്റ് ബന്ധങ്ങൾ അനാവരണം ചെയ്യണം. പിന്തുണയ്‌ക്കാത്ത വില നിശ്ചയം, പ്രവർത്തനക്ഷമത, സുരക്ഷ, സ്വകാര്യത, അല്ലെങ്കിൽ താരതമ്യ അവകാശവാദങ്ങൾ ഉൾപ്പെടുത്തരുത്. റണ്ണബിൾ ഉദാഹരണങ്ങൾ സാധാരണയായി പഠിതാവ് ഡാറ്റ അയക്കരുത് അല്ലെങ്കിൽ ഒരു പുറത്തെ തൃത്‌യ-പാർട്ടി സേവനം വഴി പൊതു പ്രവർത്തനങ്ങൾ നിർവഹിക്കരുത്.
