# സാമ്പിൾ റിസീറ്റ് ഫിക്സ്ചറുകൾ

നോട്ട്ബുക്ക് പ്രവർത്തിപ്പിക്കാതെ പരിശോധനക്ക് മുക്കാല്ലം മുൻനിർമിത റിസീറ്റ് ഫയലുകൾ.

| ഫയൽ | അതെന്താണ് |
|---|---|
| `01_valid_receipt.json` | ഒരു സാധുവായ ഒപ്പിട്ട റിസീറ്റ് `lookup_flights` ഉപകരണം വിളിയ്ക്കുവാൻ. പരിശോധന തിരിച്ചുനൽകുന്നു True. |
| `02_tampered_receipt.json` | ഒപ്പിട്ട ശേഷമുള്ള ഒരു ഫീൽഡ് മാറ്റി സമാനമായ റിസീറ്റ്. പരിശോധന തിരിച്ചുനൽകുന്നു False. |
| `03_chain_three_receipts.json` | മൂന്നു സാധുവായ റിസീറ്റുകളുടെ ശൃംഖല (തിരയൽ, പിടി, ബുക്ക്) ഓരോന്നും മുമ്പത്തെത്തോടു ബന്ധിപ്പിച്ചിട്ടുള്ള `previous_receipt_hash`. |

ഫിക്സ്ചറുകൾ പൽലച്ചിയുടെ canonical JCS ബൈറ്റുകൾ നേരിട്ട് Ed25519 ഉപയോഗിച്ചാണ് ഒപ്പിടുന്നത്.
SHA-256 ഉള്ളടക്ക ദ്രവ്യഘടകങ്ങളിലും റിസീറ്റ്-ചെയിൻ ലിങ്കുകളിലും തുടരുന്നു ഉപയോഗിക്കുന്നത്, ഒപ്പിടുന്നതിന് മുമ്പുള്ള ഒരു അധിക പ്രീ-ഹാഷ്‌ ആയി അല്ല.


## സാമ്പിളുകൾ സ്ഥിരീകരിക്കൽ

`18-signed-receipts.ipynb`ൽ, ആദ്യം Setupയും സെക്ഷൻ 1 മുതൽ 3 വരെയും പ്രവർത്തിപ്പിക്കുക.
സെക്ഷൻ 3, `verify_chain` നിർവചിക്കുന്നു; സെക്ഷൻസ് 1നും 2നും മാത്രം മതിയാകില്ല.
തുടർന്ന് പുതിയ സെല്ലിൽ താഴെയുള്ള ബ്ലോക്ക് പ്രവർത്തിപ്പിക്കുക, നോട്ട്ബുക്കിന്റെ പ്രവർത്തന ഡയറക്ടറി
`18-securing-ai-agents/code_samples` ആയി സജ്ജമാക്കിയിട്ടുള്ളത്. താഴെ ഫിക്സ്ചർ പാതകൾ ആ ഡയറക്ടറിയെ അടിസ്ഥാനമാക്കിയതാണ്.


```python
import json
from pathlib import Path

fixture_dir = Path("sample_receipts")

# This fixture key is pinned by the verifier, outside the receipt under test.
FIXTURE_ISSUER_PUBLIC_KEY = "11qYAYKxCrfVS_7TyWQHOg7hcvPapiMlrwIaaPcHURo"
fixture_trusted_public_keys = {FIXTURE_ISSUER_PUBLIC_KEY}

valid = json.loads((fixture_dir / "01_valid_receipt.json").read_text())
print(
    f"Valid receipt: {verify_receipt(valid, fixture_trusted_public_keys)}"
)  # True

tampered = json.loads((fixture_dir / "02_tampered_receipt.json").read_text())
print(
    f"Tampered receipt: {verify_receipt(tampered, fixture_trusted_public_keys)}"
)  # False

chain = json.loads((fixture_dir / "03_chain_three_receipts.json").read_text())
for r in verify_chain(chain, fixture_trusted_public_keys):
    print(f"  Receipt {r['index']} ({r['tool']}): {'VALID' if r['overall_valid'] else 'INVALID'}")
```

### Jupyterകൾ ഇല്ലാതെ ഉദാഹരണം പരിശോധിക്കൽ

റിപോസിറ്ററി രൂപം മുതൽ, പാഠഭാഗം അനുസരണകൾ ഇൻസ്റ്റാൾ ചെയ്ത് പ്രവർത്തിപ്പിക്കുക:

```bash
python -m pip install -r 18-securing-ai-agents/code_samples/requirements.txt
python -m unittest discover -s 18-securing-ai-agents/code_samples -p test_signed_receipts.py -v
```

ഈ പരിശോധനകൾ നോട്ട്‌ബുക്കിന്റെ Python ഉദാഹരണങ്ങളും മുകളിൽ നൽകിയിട്ടുള്ള കൃത്യമായ README ബ്ലോക്കും പ്രവർത്തിപ്പിക്കുന്നു
. കൂടാതെ, പരിശോധന നടത്തുന്നതിനുള്ള പരീക്ഷകർ ട്രില്ലാപ്പ് ചെയ്തതും അപ്പിൻ ചെയ്തിട്ടില്ലാത്ത കീകളും നിരാകരിക്കുന്നുവെന്ന് പരിശോധിക്കുന്നു.
പരിശോധനകൾ നോട്ട്‌ബുക്കിന്റെ `%pip` സെറ്റ് അപ്പ് സെൽ ഒഴിച്ച് പ്രവർത്തിക്കുന്നു, കാരണം ആശ്രിതങ്ങൾ സ്വതന്ത്രമായി ഇൻസ്റ്റാൾ ചെയ്യപ്പെടുന്നു.
അവ നോട്ട്‌ബുക്കോ ഫിക്‌സ്ചറുകളോ മാറ്റുന്നില്ല.

## ഇത് എങ്ങനെ സൃഷ്ടിച്ചു

ഫിക്‌സ്ചറുകൾ നോട്ട്‌ബുക്കിന്‍റെ തന്നെ കോഡ് പാത്ത് ഉപയോഗിക്കുന്നു, ഒരൊറ്റ നിശ്ചിത സൈൻ ചെയ്‌തിരിക്കുന്ന കീയും
ബൈറ്റ്പര്യവസായത്തിന് സ്ഥിരമായ സമയവും ഉപയോഗിച്ച്. പുനർനിർമ്മിക്കാൻ:

```bash
python3 generate_fixtures.py
```

(സ്ക്രിപ്റ്റ് ഈ ഡയറക്ടറിയിലെ `generate_fixtures.py` ല് ഉണ്ട്.)

## ശിഷ്യർ ഗന്ധജെ.എസ്.ഒ.എൻ പരിശോധിച്ച് എന്തു പഠിക്കുന്നു

റാ പോലീസ് ഫോർമാറ്റ് വായന നോട്ട്‌ബുക്കിലുള്ള സെൽസിൽ ലഭിക്കാത്ത ഒരു തിരിച്ചറിവ് നിർമ്മിക്കുന്നു.
JSON സിലിക്കളിൽ കാഴ്‌ച്ചചെയ്യുന്ന ശിഷ്യർ വളരെക്കാൽ ശ്രദ്ധിക്കുന്നതാണ്:

1. സിഗ്‌നേച്ചർ ഒരു ഒപേക്ക് base64url സ്ട്രിംഗാണ്, എന്നാൽ മറ്റെല്ലാ ഫീൽഡുകളും ലളിതമായ വായിക്കാൻ കഴിയുന്ന JSON ആണു.
   സിഗ്‌നേച്ചർ ഉള്ളടക്കം എൻക്രിപ്റ്റ് ചെയ്യുന്നില്ല; അത് അതിനെ സ്ഥിരീകരിക്കുന്നു.
2. `public_key` റസീറ്റ്-ഇൽ ഉൾപ്പെടുത്തിയിട്ടുണ്ട്, ഇത് സ്വയം-സദ്യിഷ്ടത പരിശോധിക്കാൻ മതിയെങ്കിലും ജാരൻറിയുടെ വിശ്വാസം ഉറപ്പാക്കാനാകില്ല.
   ഒരു ഓഡിറ്റർ അത് റസീറ്റ് പുറത്ത് പിനിട്ടിട്ടുള്ള ഒരു കീയുമായി അല്ലെങ്കിൽ വിശ്വസനീയമായ രജിസ്ട്രിയിലെ വഴി പരിഹരിച്ച കീയുമായി താരതമ്യം ചെയ്യേണ്ടതാണ്.

3. ഏതെങ്കിലും ഫീൽഡിന്റെ ഒരു അക്ഷരം മാറ്റിയ ശേഷം, ഈ ഫയൽ വീണ്ടും
   `02_tampered_receipt.json`-നൊപ്പം താരതമ്യം ചെയ്യുക, ബൈറ്റ്-തല മെക്കാനിസത്തിന്റെ പ്രത്യക്ഷമാണ്.
