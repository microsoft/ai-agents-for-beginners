# കമ്പ്യൂട്ടർ ഉപയോഗ ഏജന്റുകൾ (CUA) നിർമ്മിക്കല്‍

കമ്പ്യൂട്ടർ ഉപയോഗ ഏജന്റുകൾ ഒരു വ്യക്തി ചെയ്യുന്നത് പോലെ വെബ്സൈറ്റുകളുമായി ഇടപഴകാൻ കഴിയും: ബ്രൗസർ തുറക്കുക, പേജ് പരിശോധിക്കുക, കണ്ടതിൽ നിന്നുതന്നെ അടുത്ത നല്ല നടപടി എടുക്കുക. ഈ പാഠത്തിൽ, നിങ്ങൾ ഒരു ബ്രൗസർ ഓട്ടോമേഷൻ ഏജന്റ് നിർമ്മിക്കും, അത് Airbnb-യിൽ തെരയുകയും, ഘടനാപരമായ ലിസ്റ്റിംഗ് ഡാറ്റ പിഴിയുകയും, സ്റ്റോക്ക്‌ഹോംയിലെ ഏറ്റവും കുറഞ്ഞ ചെലവിൽ ഉള്ള താമസ സ്ഥലം തിരിച്ചറിയുകയും ചെയ്യും.

ഈ പാഠം Browser-Use നെ എഐ-ചാലിത നാവിഗേഷനുമായി സംയോജിപ്പിക്കുന്നു, Playwright ഉം Chrome DevTools Protocol (CDP) ഉം ബ്രൗസർ നിയന്ത്രണത്തിനായി, Azure OpenAI വേർഷൻ സജ്ജമായ ആർഗ്യുമെന്റിനായി, 그리고 Pydantic ഘടനാപരമായ പിഴിയലിനായി.

## പരിചയം

ഈ പാഠം ഉൾക്കൊള്ളുന്നതൊ:

- API-മാത്രം ഓട്ടോമേഷനേക്കാൾ കമ്പ്യൂട്ടർ ഉപയോഗ ഏജന്റുകൾ എപ്പോൾ മികച്ചതാണെന്ന് മനസിലാക്കുക
- Browser-Use നെ Playwright ഉം CDP ഉം സംയോജിപ്പിച്ച് വിശ്വാസയോഗ്യമായ ബ്രൗസർ ലൈഫ്‌സൈക്കിൾ മാനേജ്മെന്റ് നേടുക
- ഡൈനാമിക് വെബ് പേജുകളിൽ നിന്നും ലിസ്റ്റിംഗ് ഡാറ്റ പിഴിയാൻ Azure OpenAI വി​ഷന്‍ ഉം ഘടനാപരമായ Pydantic ഔട്ട്‌പുട്ടും ഉപയോഗിക്കുക
- ഏജന്റ്-ഫസ്റ്റ്, അക്ക്ടർ-ഫസ്റ്റ്, അല്ലെങ്കിൽ ഹൈബ്രിഡ് ബ്രൗസർ ഓട്ടോമേഷൻ വർക്ക്‌ഫ്ലോ എപ്പോൾ ഉപയോഗിക്കണമെന്ന് തീരുമാനിക്കുക

## പഠന ലക്ഷ്യങ്ങൾ

ഈ പാഠം പൂർത്തിയാക്കുമ്പോൾ, നിങ്ങൾക്ക് അറിയാം എങ്ങനെ:

- Azure OpenAI ഉം Playwright ഉം Browser-Use ൽ ഘടിപ്പിക്കുക
- യഥാർത്ഥ വെബ്‌സൈറ്റ് നാവിഗേറ്റ് ചെയ്യുകയും ഡൈനാമിക് UI ഘടകങ്ങൾ കൈകാര്യം ചെയ്യുകയും ചെയ്യുന്ന ബ്രൗസർ ഓട്ടോമേഷൻ വർക്ക്‌ഫ്ലോ നിർമ്മിക്കുക
- ദൃശ്യ പേജ് ഉള്ളടക്കത്തിൽ നിന്ന് ടൈപ്പുചെയ്ത ഫലങ്ങൾ പിഴിച്ച് അവ downstream ബിസിനസ് ലോജിക്കാക്കി മാറ്റുക
- ബ്രൗസർ ടാസ്ക്ക് എത്രത്തോളം പ്രവചിക്കാനാവുന്നതാണെന്ന് ആശ്രയിച്ച് ഏജന്റ് അല്ലെങ്കി അക്റ്റർ മാതൃക തിരഞ്ഞെടുക്കുക

## കോഡ് ഉദാഹരണം

ഈ പാഠത്തിൽ ഒരു നോൺബുക്ക് ട്യൂട്ടോറിയലുണ്ട്:

- [15-browser-user.ipynb](./15-browser-user.ipynb): CDP-മാർഗ്ഗം ക്രോം സെഷൻ ആരംഭിച്ച് Airbnbയിൽ സ്റ്റോക്ക്‌ഹോം ലിസ്റ്റിംഗുകൾ തിരയുകയും Browser-Usevisiൻ ഉപയോഗിച്ചു വിലകൾ പിഴിക്കുകയും ഏറ്റവും കുറഞ്ഞ ഓപ്ഷൻ ഘടനാപരമായി തിരികെ നൽകുകയും ചെയ്യുന്നു.

## മുൻകൂർ ആവശ്യങ്ങൾ

- Python 3.12+
- നിങ്ങളുടെ പരിസ്ഥിതിയില്‍ Azure OpenAI വിന്യസിച്ചു
- ലോക്കലായി ക്രോം അല്ലെങ്കിൽ ക്രോमിയം ഇൻസ്റ്റാൾ ചെയ്തിരിക്കുന്നത്
- Playwright അവലംബങ്ങൾ ഇൻസ്റ്റാൾ ചെയ്യപ്പെട്ടത്
- അസിങ്ക് പൈതൺ അടിസ്ഥാന പരിചയം

## സെറ്റ്‌അപ്പ്

നോൺബുക്കിൽ ഉപയോഗിക്കുന്ന പാക്കേജുകൾ ഇൻസ്റ്റാൾ ചെയ്യുക:

```bash
pip install browser_use playwright python-dotenv
playwright install chromium
```

നോൺബുക്ക് ഉപയോഗിക്കുന്ന Azure OpenAI പരിസ്ഥിതി ചാരങ്ങൾ ക്രമീകരിക്കുക:

```bash
AZURE_OPENAI_ENDPOINT=...
AZURE_OPENAI_API_KEY=...
AZURE_OPENAI_CHAT_DEPLOYMENT_NAME=...
# ഐച്ചികം: ഒഴിവാക്കിയാൽ പുതിയतम API പതിപ്പിലേക്ക് ഡീഫോൾട്ട് ചെയ്യുന്നു
AZURE_OPENAI_API_VERSION=...
```

## ആർക്കിടെക്ചർ അവലോകനം

ഈ നോൺബുക്ക് ഹൈബ്രിഡ് ബ്രൗസർ ഓട്ടോമേഷൻ വർക്ക്‌ഫ്ലോ കാണിക്കുന്നു:

1. Chrome CDP സജ്ജീകരണം കൊണ്ടാണ് ആരംഭിക്കുന്നത്, അതിനാൽ Playwright ഉം Browser-Use ഉം ഒരേ ബ്രൗസർ സെഷൻ പങ്കുവെക്കുകയും ചെയ്യുന്നു.
2. Browser-Use ഏജന്റ് തുറന്ന നാവിഗേഷൻ ടാസ്കുകൾ കൈകാര്യം ചെയ്യുന്നു, ഉദാഹരണത്തിന് Airbnb തുറക്കൽ, പాప్-അപ്പുകൾ ഒഴിവാക്കൽ, സ്റ്റോക്ക്‌ഹോം തിരയൽ എന്നിവ.
3. സജീവ പേജ് ഘടനാപരമായ Pydantic സ്കീമ ഉപയോഗിച്ച് പരിശോധിച്ചും ലിസ്റ്റിംഗ് തലക്കെട്ടുകൾ, രാത്രിദിവസ വിലകൾ, റേറ്റിങ്ങുകൾ, URLs പിഴിച്ചു പിഴിക്കുന്നു.
4. പൈതൺ ലോജിക്ക് പിഴിഞ്ഞ ലിസ്റ്റിങ്ങുകൾ താരതമ്യം ചെയ്ത് ഏറ്റവും കുറഞ്ഞ വില തെളിയിക്കുന്നു.

ഈ സമീപനം Browser-Use ന് നല്കിയുള്ള ദൃശ്യ അടിസ്ഥാന reasoning ഫ്ലെക്സിബലാണ്, എന്നാൽ നിങ്ങൾക്ക് ആവശ്യമുള്ളപ്പോൾ നിർണായകമായ ബ്രൗസർ നിയന്ത്രണവും നൽകുന്നു.

## പ്രധാന സംഗ്രഹങ്ങളും മികച്ച പ്രാക്ടീസുകളും

### ഏജന്റ് vs അക്റ്റർ എപ്പോൾ ഉപയോഗിക്കാം

| സാഹചര്യങ്ങൾ | ഏജന്റ് ഉപയോഗിക്കുക | അക്റ്റർ ഉപയോഗിക്കുക |
|----------|-----------|-----------|
| ഡൈനാമിക് ലേഔട്ടുകൾ | അതെ, എഐ പേജ് മാറലുകൾക്ക് അനുയോജ്യമാണ് | ഇല്ല, തകരാറുള്ള സെലക്ടറുകൾ തകരാം |
| അറിയപ്പെടുന്ന ഘടന | ഇല്ല, ഏജന്റ് നേരിട്ട നിയന്ത്രണത്തിനേക്കാൾ മന്ദഗതിയിലുള്ളത് | അതെ, വേഗവും കൃത്യവുമാണ് |
| ഘടകങ്ങൾ കണ്ടെത്തൽ | അതെ, പ്രാകൃതഭാഷ നല്ല ഫലമുണ്ടാക്കും | ഇല്ല, കൃത്യ സെലക്ടറുകളും ആവശ്യമാണ് |
| സമയ നിയന്ത്രണം | ഇല്ല, കുറവാകം പ്രവചിക്കാനാകുന്നില്ല | അതെ, കാത്തിരിപ്പ്, വീണ്ടും ശ്രമം എന്നിവ സമ്പൂർണ നിയന്ത്രണം |
| സങ്കീർണ്ണ പ്രവൃത്തി പ്രക്രിയകൾ | അതെ, അനपेക്ചിത UI നിലകൾ കൈകാര്യം ചെയ്യുന്നു | ഇല്ല, വ്യക്തമായ ബ്രാഞ്ചിംഗ് ആവശ്യമാണ് |

### Browser-Use മികച്ച പ്രാക്ടീസുകൾ

1. അന്വേഷണംക്കും ഡൈനാമിക് നാവിഗേഷനും വേണ്ടി’agence’ തുടങ്ങുക.
2. ഇടപെടൽ പ്രവചിപ്പിക്കാവുന്നതാകുമ്പോൾ നേരിട്ട പേജ് നിയന്ത്രണത്തിലേക്ക് മാറുക.
3. പിഴിഞ്ഞ ഡാറ്റ സ്ഥിരീകരിക്കപ്പെടുകയും ടൈപ്പ്-സുരക്ഷിതമാക്കുകയും ചെയ്യുന്ന ഘടനാപരമായ മോഡലുകൾ ഉപയോഗിക്കുക.
4. ദൃശ്യ UI മാറ്റങ്ങളേ ഉളവാക്കുന്ന നടപടികളിന് ശേഷം തന്ത്രപരമായ വൈകിപ്പിക്കൽ ചേർക്കുക.
5. പരാജയങ്ങൾ ഡീബഗ് ചെയ്യാൻ എളുപ്പമുള്ളത് എങ്കിൽ വീണ്ടും തയ്യാറാക്കുമ്പോൾ സ്ക്രീൻഷോട്ടുകൾ പിടിക്കുക.
6. വെബ്സൈറ്റുകൾ മാറാൻ സാധ്യതയുള്ളത് കണക്കിലെടുക്കുകയും പാപ്പ്-അപ്പുകളുടെയും ലേഔട്ട് മാറ്റങ്ങളുടെയും ഫാൾബാക്ക് തന്ത്രങ്ങൾ രൂപകൽപ്പന ചെയ്യുക.
7. ഏജന്റ്-അക്റ്റർ മാതൃകകൾ സംയോജിപ്പിച്ച് ഫ്ലെക്സിബിലിറ്റി, കൃത്യത ഇരുവരും നേടുക.

### യാഥാർത്ഥ്യ പ്രയോഗങ്ങൾ

- യാത്രാ ബുക്കിംഗ്, വില നിരീക്ഷണം
- ഇ-കൊമേഴ്സ് വില താരതമ്യവും ലഭ്യത പരിശോധനയും
- ഡൈനാമിക് വെബ്സൈറ്റുകളിൽ നിന്നുള്ള ഘടനാപരമായ പിഴിയൽ
- വ്യൂ-അറിയുന്ന UI പരിശോധനയും സ്ഥിരീകരണവും
- വെബ്സൈറ്റ് നിരീക്ഷണം, അലേർട്ട് പ്രക്രിയകൾ
- ബഹുസ്ഥാപക ഫ്ളോറുകളിൽ ബുദ്ധിമുട്ടില്ലാത്ത ഫോമ്ഫില്ലിംഗ്

## യാഥാർത്ഥ്യ ഉദാഹരണം: Microsoft Project Opal

ഈ പാഠത്തിൽ നിങ്ങൾ നിർമ്മിക്കുന്ന ഏജന്റ് ഒരു ചെറിയ, നാടുവെള്ളമുള്ള **കമ്പ്യൂട്ടർ ഉപയോഗ ഏജന്റ് (CUA)** ആണ് — ഒരു വ്യക്തി ചെയ്യുന്നതുപോലെ ബ്രൗസർ പ്രവർത്തിപ്പിക്കുന്ന പ്രോഗ്രാം. മൈക്രോസോഫ്റ്റ് ഈ യഥാർത്ഥ ആശയം Microsoft 365 CoPilot-ല്‍ **[Project Opal (Frontier)](https://support.microsoft.com/en-us/microsoft-365-copilot/get-started-with-project-opal-frontier)** എന്ന സംവിധാനത്തിലേക്ക് കൊണ്ടുവരുന്നു.

Project Opal-ൽ, നിങ്ങൾ ഒരു ടാസ്ക് വിവരിക്കുന്നില്ല, ഏജന്റ് നിങ്ങളുടെ പേര് കൊണ്ട് **സ്വകാര്യമായ Windows 365 Cloud PC-യിൽ കമ്പ്യൂട്ടർ ഉപയോഗം നടത്തുന്നു**, നിങ്ങളുടെ സ്ഥാപനത്തിന്റെ ബ്രൗസർ അടിസ്ഥാനമുള്ള ആപ്ലിക്കേഷനുകൾ, സൈറ്റുകൾ, ഡാറ്റ എന്നിവയിൽ പ്രവർത്തിക്കുന്നു. ഇത് **പശ്ചാത്തലത്തിൽ അസിങ്ക്രോണസ് ആയി നടത്തപ്പെടുന്നു**, നിങ്ങൾക്ക് പ്രവർത്തനം മാർഗ്ഗനിർദ്ദേശം ചെയ്യുകയോ എപ്പോൾ വേണമെങ്കിലും നിയന്ത്രണം എടുക്കുകയോ കഴിയും. ഉദാഹരണ ജോലിയുകൾ:

- സെക്യൂരിറ്റി ഗ്രൂപ്പ് അംഗത്വ അഭ്യർത്ഥനകളുടെ കൈമാറ്റം
- ഓഡിറ്റ് തെളിവുകൾ ശേഖരിച്ച് നിയമാനുസൃത പരിശോധനകൾക്കായി സ്ഥിരീകരണം
- ഐടി സംഭവങ്ങൾ ട്രയാജിങ് (ടിക്കറ്റ് നില അപ്ഡേറ്റ്, ഉടമകൾ നിയോഗം, ജൂജിക്സ് അടക്കൽ)
- ഫിനാൻഷ്യൽ ക്ലോസ് ഡെക്ക് സൃഷ്ടിക്കാൻ എക്സെൽ ഡാറ്റ സംയോജനം

Opal **ഉൽപ്പാദന-നിലവാരമുള്ള, വിശ്വസനീയമായ** കമ്പ്യൂട്ടർ ഉപയോഗ ഏജന്റ് എങ്ങനെ ആണ് എന്നതിന് ഒരു ഉപകാരപ്രദമായ संदർഭമാണ് — അതും മുൻപത്തെ പാഠങ്ങൾ മുതൽ പരീക്ഷിക്കാൻ സഹായിക്കുന്നു:

| ഈ കോഴ്സിലെ ആശയം | Project Opal ഇത് എങ്ങനെ പ്രയോഗിക്കുന്നു |
|------------------------|-----------------------------|
| **ഹ്യൂമൻ-ഇൻ-ദി-ലൂപ്പ്** (പാഠം 06) | Opal ലോഗിൻ ക്രെഡൻഷ്യലുകൾ, സെൻസിറ്റീവ് ഡാറ്റ, അല്ലെങ്കില്‍ अस्पष्ट നിർദ്ദേശങ്ങൾക്ക് ഇടവേള നൽകുന്നു, പാസ്‌വേർഡുകൾ നൽകുകയോ ഫോം സമർപ്പിക്കുകയോ എത്രയോ ചെയ്യാറില്ല. നിങ്ങൾക്ക് *Take Control* ചെയ്ത് *Return Control* എടുക്കാം ഇടത്തരം ടാസ്കിൽ. |
| **വിശ്വസനീയവും സുരക്ഷിതവും ആയ ഏജന്റുകൾ** (പാഠങ്ങൾ 06 & 18) | Windows 365 Cloud PC ലെ ഐസൊലേറ്റഡായ ഇടത്ത് പ്രവർത്തിക്കുന്നു, സാധാരണയായി ബ്രൗസർ മാത്രം (മറ്റ് കമ്പ്യൂട്ടർ ആക്സസ് തടഞ്ഞു, Intune മുഖേന ഉറപ്പുവരുത്തുന്നു), നിങ്ങളുടെ ഐഡന്റിറ്റി ഉപയോഗിച്ച് മാത്രം അനുമതിയായ ഭാഗങ്ങൾ അഡ്രസ്സ് ചെയ്യുന്നു, എല്ലാ പ്രവർത്തനങ്ങളും ഓഡിറ്റിന് ലോഗ് ചെയ്യുന്നു. |
| **പ്ലാനിംഗ് & മെറ്റക്കോസ്നിഷൻ** (പാഠങ്ങൾ 07 & 09) | Opal ജോലിക്കായി ആദ്യം ഒരു പദ്ധതി നിർമിക്കുന്നു, തുടർന്ന് ഓരോ ഘട്ടത്തിലും സ്വന്തം ആർ‌ഗ്യുമെന്റിനെ മേൽനോട്ടം വഹിച്ച് സംശയാസ്പദ പ്രവർത്തനം കണ്ടെത്തുമ്പോൾ ഇടവേള നൽകുന്നു. |
| **മீண்டும் ഉപയോഗിക്കാവുന്ന കഴിവുകൾ / ഉപകരണങ്ങൾ** (പാഠം 04) | **Skills** നിങ്ങൾക്ക് ആവർത്തിക്കാവുന്ന ജോലികൾക്കുള്ള നിർദ്ദേശങ്ങൾ എഴുതാൻ ഉദ്ദേശിച്ചിരിക്കുന്നു (.md ഫയൽ നിന്നോ Opal ഉപയോഗിച്ചോ എഴുതിയതിനു), പിന്നീട് സംഭാഷണങ്ങളിൽ പുനർഉപയോഗം ചെയ്യാം. |

> **ലഭ്യമായത്:** Project Opal നിലവിൽ [Frontier early access program](https://adoption.microsoft.com/copilot/frontier-program/) ല്‍ Microsoft 365 Copilot സബ്സ്ക്രിപ്ഷൻ ഉള്ള ഉപയോക്താക്കൾക്കായി ലഭ്യമാണ്, നിങ്ങളുടെ അഡ്മിനിസ്ട്രേറ്റർ സെറ്റ് അപ്പ് പൂർത്തിയാക്കണം. Experimental Frontier ഫീച്ചറായതിനാൽ കഴിവുകൾ ആണൊടക്കത്തിലൂടെ മാറാനുണ്ട്.
