# AI এজেন্টদের জন্য শুরু থেকে - স্টাডি গাইড

এই গাইডটি কোর্সের মধ্যে আপনার চলাফেরার সময় একটি ব্যবহারিক সঙ্গী হিসেবে ব্যবহার করুন। এটি
পাঠগুলো প্রতিস্থাপনের উদ্দেশ্যে নয়। এটি আপনাকে সিদ্ধান্ত নিতে সাহায্য করে কোথা থেকে শুরু করবেন, প্রতিটি পাঠে কি খুঁজবেন,
এবং ধারণাগুলোকে একত্রিত করে একটি ছোট কাজ করা এজেন্ট ডেমো তৈরি করবেন কিভাবে।


যদি এটাই আপনার প্রথম বার এখানে আসে, সোজা শুরু করুন:

1. [Course Setup](./00-course-setup/README.md) পড়ুন।
2. ক্রমানুসারে পাঠ ০১-০৬ সম্পন্ন করুন।
3. শেখার সময় একটি ছোট ডেমো আইডিয়া মনে রাখুন।
4. প্রতিটি পাঠের পর, প্রশ্ন করুন: "আমার এজেন্ট এখন কি করতে পারে যা আগে পারতো না?"


## মনে রাখার জন্য একটি সহজ ডেমো

এজেন্টগুলো শেখার একটি ভালো উপায় হলো কোর্সে একটি ডেমো আইডিয়া অনুসরণ করা।

উদাহরণ ডেমো: **একটি কোর্স সহায়ক এজেন্ট**।

ব্যবহারকারীর প্রশ্ন:

> "আমি জানতে চাই কিভাবে এজেন্টরা টুল ব্যবহার করে। সঠিক পাঠগুলো খুঁজে বের করুন, যা আমাকে
> আগে পড়া উচিত তা সংক্ষিপ্তভাবে বলুন এবং একটি ছোট অনুশীলন কাজ দিন।"

একটি সাধারণ চ্যাটবট তার জানা তথ্য থেকে উত্তর দিতে পারে। একটি এজেন্ট আরো করতে পারে:

1. **কোর্স ফাইলগুলো পড়া বা অনুসন্ধান করা** সঠিক পাঠগুলো খুঁজে পেতে।
2. **টুল ব্যবহার করা** পাঠের লিঙ্ক, উদাহরণ, বা সহায়ক ডকুমেন্ট পেতে।
3. **পরিকল্পনা করা** এক দীর্ঘ উত্তর দেওয়ার পরিবর্তে সংক্ষিপ্ত শেখার পথ।
4. **প্রসঙ্গ ব্যবহার করা** চলমান আলাপ থেকে শিখারের লক্ষ্য ধরে রাখতে।
5. **স্মৃতি ব্যবহার করা** যদি অ্যাপ্লিকেশন স্মৃতি সমর্থন করে ব্যবহারকারীর পছন্দ মনে রাখা।
6. **ট্রেস, উত্স, বা লগ দেখানো** যাতে ব্যবহারকারী বুঝতে পারে কী ঘটেছে।
7. **নিরাপত্তা রক্ষার নিয়ম প্রয়োগ করা** ঝুঁকিপূর্ণ কাজের আগে বা সংবেদনশীল ডেটা ব্যবহারের সময়।


প্রতিটি পাঠ অধ্যয়ন করার সময় এই ডেমোটি ফের আসুন এবং জিজ্ঞাসা করুন: এই পাঠটি কোন নতুন ক্ষমতা যোগ করবে?


## আপনি যা তৈরি করতে যাচ্ছেন

কোর্স শেষ হওয়ার সময়, আপনাকে সক্ষম হতে হবে এজেন্ট সিস্টেম ব্যাখ্যা ও তৈরি করতে যা এই অংশগুলো একত্রিত করে:


| অংশ | সাধারণ অর্থ | ডেমোতে |
|------|------------------------|-------------|
| মডেল | ব্যবহারকারীর অনুরোধের ব্যাখ্যা করার যুক্তি ইঞ্জিন | বুঝতে পারে যে শিখার জন্য টুল ব্যবহারের পাঠ চাইছে |
| টুল | ফাংশন, API, ফাইল, ব্রাউজার, বা পরিষেবা যা এজেন্ট ব্যবহার করতে পারে | রিপোজিটরি অনুসন্ধান বা পাঠ সামগ্রী উদ্ধার করে |
| জ্ঞান | উত্তর নির্ভর করার জন্য ডকুমেন্ট বা ডেটা | কোর্স README ফাইল ও পাঠ সামগ্রী |
| প্রসঙ্গ | পরবর্তী মডেল কলের জন্য তথ্য | ব্যবহারকারীর লক্ষ্য এবং টুল ফলাফল |
| স্মৃতি | পরে ব্যবহারের জন্য সংরক্ষিত তথ্য | শিখার ব্যক্তি হাতে-কলমে পাইথন উদাহরণ পছন্দ করে |
| পরিকল্পনা | বড় লক্ষ্য ভাঙ্গে ছোট ধাপে | পাঠ খুঁজে বের করা, সংক্ষিপ্ত করা, অনুশীলন প্রস্তাব |
| সমন্বয় | টুল, ধাপ, বা এজেন্টের মধ্যে কাজ ভাগ করা | একটি পরিকল্পনাকারী প্রথম সার্চ টুল কল করে, তারপর সংক্ষিপ্তকরিয়ে |
| বিশ্বাস | নিরাপত্তা, সুরক্ষা, মূল্যায়ন, দেখা-শোনা | লগ করে টুল কল এবং উচ্চ প্রভাবের কাজের আগে জিজ্ঞাসা করে |

## মডেল ও প্রদানকারী

কোর্সের কোড নমুনাগুলো **Microsoft Agent Framework (MAF)** ব্যবহার করে এবং লক্ষ্য করেছে **Azure OpenAI Responses API** - এটা সুপারিশকৃত API যা চ্যাট পূরক, টুল কলিং, মাল্টিমোডাল ইনপুট, এবং রাষ্ট্রভিত্তিক আলাপগুলো একটি API সার্ফেসে মিলিয়েছে। আপনি সংযোগ করতে পারেন **Microsoft Foundry** প্রকল্পের মাধ্যমে (`FoundryChatClient` সহ) অথবা সরাসরি Azure OpenAI (`OpenAIChatClient` সহ) এ।

পাঠগুলো শেষে আপনি কিছু প্রদানকারী অপশন পাবেন:

- **Microsoft Foundry / Azure OpenAI (Responses API)** — প্রধান পথ যা বিভিন্ন পাঠে ব্যবহৃত হয়। `az login` দিয়ে সাইন ইন করুন বিনা কী এর Entra ID প্রমাণীকরণের জন্য।
- **Foundry Local** — OpenAI-সমতুল্য API মাধ্যমে পুরোপুরি ডিভাইসে মডেল চালান (ক্লাউড নেই, API কী নেই)। অফলাইন বা বিনামূল্যের পরীক্ষা-নিরীক্ষার জন্য আদর্শ। দেখুন [Course Setup](./00-course-setup/README.md)।
- **MiniMax** — OpenAI-সমতুল্য প্রদানকারী বড় প্রসঙ্গ মডেল নিয়ে, সহজেই বিকল্প হিসেবে ব্যবহৃত।

> **বিঃদ্রঃ:** GitHub Models বাতিল হচ্ছে (২০২৬ জুলাই অবধি) এবং Responses API সমর্থন করে না। নমুনাগুলো আপডেট করা হয়েছে Azure OpenAI / Microsoft Foundry ব্যবহার করার জন্য।

## আপনার শেখার পথ বেছে নিন

আপনি সম্পূর্ণ কোর্স ধারাবাহিকভাবে নিতে পারেন, অথবা আপনার তৈরির লক্ষ্যের ভিত্তিতে একটি পথ বেছে নিতে পারেন।


| যদি আপনার লক্ষ্য হয়... | শুরু করুন | তারপর পড়ুন |
|-----------------------|------------|------------|
| এজেন্ট কি তা বুঝতে | ০১, ০২, ০৩ | ০৪, ০৫, ০৬ |
| টুল ব্যবহার করে এজেন্ট তৈরি করতে | ০৪ | ০৫, ০৭, ১৪ |
| RAG-ভিত্তিক এজেন্ট তৈরি করতে | ০৫ | ০৪, ০৬, ১২ |
| বহু-ধাপ কর্মপ্রক্রিয়া ডিজাইন করতে | ০৭ | ০৮, ০৯, ১৪ |
| বহু-এজেন্ট সিস্টেম বুঝতে | ০৮ | ০৭, ০৯, ১১ |
| এজেন্টকে প্রোডাকশনের জন্য প্রস্তুত করতে | ০৬, ১০ | ১২, ১৩, ১৬, ১৮ |
| Foundry তে এজেন্ট স্থাপন ও বৃদ্ধি করতে | ১০, ১৬ | ০৬, ১৩, ১৮ |
| লোকাল / অফলাইন-প্রথম এজেন্ট তৈরি করতে | ১৭ | ০৪, ০৫, ১১ |
| প্রোটোকল ও ব্রাউজার অটোমেশন অন্বেষণ করতে | ১১, ১৫ | ১০, ১৮ |

টিপ: যদি আপনি এজেন্টে নতুন হন, তাহলে পাঠ ০১-০৬ স্কিপ করবেন না। এগুলো আপনাকে বাকি কোর্সের জন্য প্রয়োজনীয় শব্দজ্ঞান দেবে।

## স্থাপিত এজেন্ট যাচাই স্মোক টেস্ট দিয়ে

যখন আপনি একটি এজেন্ট স্থাপন করেন (পাঠ ১৬), একটি **স্মোক টেস্ট** হল সবচেয়ে সস্তা প্রথম
পরীক্ষা যা যাচাই করে যে স্থাপনাটি সত্যিই উত্তর দেয়। এই রেপো প্রস্তুত-চালনার জন্য
ক্যাটালগ শিপ করে [tests/](./tests/README.md) এ পাঠ ০১, ০৪, ০৫, এবং ১৬ এ স্থাপনযোগ্য এজেন্টদের জন্য,
০১, ০৪, ০৫ এবং ১৬, যুক্ত করা হয়েছে

[AI Smoke Test](https://github.com/marketplace/actions/ai-smoke-test) GitHub
অ্যাকশন। পাঠের এজেন্ট মোতায়েন করার পর **Actions** ট্যাব থেকে এগুলো চালান।
স্মোক টেস্ট হল প্রথম গেট — অফলাইন এবং অনলাইন মূল্যায়ন (পাঠ ১০ এবং ১৬)
আপনাকে বলে কতটা *ভাল* এজেন্টটি।

## শুরু করার জন্য মূল ধারণা

### সরঞ্জামসমূহ

একটি টুল হল এমন কিছু যা এজেন্ট বাহ্যিক মডেলের বাইরে কাজ করার জন্য কল করতে পারে। একটি ভাল টুলের
একটি স্পষ্ট নাম, একটি সংকীর্ণ কাজ, টাইপ করা ইনপুট, পূর্বনির্ধারিত আউটপুট, এবং নিরাপদ ব্যর্থ হওয়ার উপায় থাকে।


কোর্স হেল্পার ডেমোর জন্য, একটি টুল হতে পারে:

- `search_lessons(query)`
- `read_lesson(path)`
- `create_practice_task(topic)`

### RAG এবং জ্ঞান

RAG এজেন্টকে অনুমান না করে উৎস উপাদান থেকে উত্তর দিতে সাহায্য করে। এই
কোর্সে, উৎস উপাদান হতে পারে পাঠের README, কোড নমুনা অথবা পাঠ থেকে লিঙ্ককৃত বাহ্যিক
সম্পদ।

যখন উত্তর অবশ্যই নথি, ডেটা বা বর্তমান প্রকল্প ফাইলগুলির উপর ভিত্তি করে হওয়া উচিত তখন RAG ব্যবহার করুন।




পর্যাপ্ত দৃশ্যমান রাখুন যেন একজন ডেভেলপার বা ব্যবহারকারী তা পরীক্ষা করতে পারে।


ডেমোর জন্য, একটি পরিকল্পনা হতে পারে:

১. টুল ব্যবহারের সাথে সম্পর্কিত পাঠগুলি খুঁজুন।
২. সবচেয়ে প্রাসঙ্গিক পাঠগুলির সারাংশ তৈরি করুন।
৩. একটি অনুশীলন কাজ সুপারিশ করুন।

### প্রসঙ্গ

প্রসঙ্গ হচ্ছে মডেল যা এখন দেখছে। খুব কম প্রসঙ্গ এজেন্টকে গুরুত্বপূর্ণ
তথ্য মিস করতে পারে। খুব বেশি প্রসঙ্গ এজেন্টকে ধীর, বেশি ব্যয়বহুল,
অথবা সহজে বিভ্রান্ত করে তুলতে পারে।

ভালো প্রসঙ্গ প্রকৌশল মানে পরবর্তী মডেল কলের জন্য সঠিক তথ্য নির্বাচন করা।


### মেমোরি

মেমোরি হচ্ছে তথ্য যা ভবিষ্যতের জন্য সংরক্ষিত হয়। সবকিছু সংরক্ষণ করবেন না। তথ্য
শুধুমাত্র তখনই সংরক্ষণ করুন যখন এটি উপকারী, নিরাপদ এবং আপডেট বা মুছে ফেলা সহজ হয়।

উদাহরণস্বরূপ, "শিক্ষার্থী পছন্দ করেন পাইথন উদাহরণ" মনে রাখা উপকারী হতে পারে।
সংবেদনশীল ব্যক্তিগত তথ্য মনে রাখা সাধারণত নয়।

### মূল্যায়ন এবং পর্যবেক্ষণযোগ্যতা

মূল্যায়ন জিজ্ঞেস করে: এজেন্ট কি সঠিক কাজটি করেছে?

পর্যবেক্ষণযোগ্যতা জিজ্ঞেস করে: আমরা কি দেখতে পাচ্ছি এটি কিভাবে ঘটল?

প্রোডাকশন এজেন্টের জন্য, মডেল কল, টুল কল, প্রাপ্ত প্রসঙ্গ,
বিলম্ব, খরচ, ব্যর্থতা, এবং ব্যবহারকারীর প্রতিক্রিয়া ট্র্যাক করুন।

### বিশ্বাস এবং নিরাপত্তা

বিশ্বস্ত এজেন্টদের প্রয়োজন শুধু একটি সহায়ক প্রম্পট নয়। ন্যুনতম-অধিকার টুল ব্যবহার করুন,
উচ্চ প্রভাবের কাজের জন্য মানব অনুমোদন, দরকার হলে তথ্য লুকানো, এবং
যা কাজ নিরীক্ষণ করা প্রয়োজন সেগুলোর জন্য লগ বা রসিদ রাখুন।

## ১৫ মিনিটের রিভিউ রুটিন

প্রতিটি পাঠের পরে এই রুটিনটি ব্যবহার করুন:

১. **একটি বাক্যে পাঠের সারাংশ দিন।**
২. **নতুন এজেন্ট ক্ষমতার নাম বলুন।** উদাহরণস্বরূপ: টুল ব্যবহার, পুনরুদ্ধার,
   পরিকল্পনা, মেমোরি, পর্যবেক্ষণযোগ্যতা, বা নিরাপত্তা।
৩. **এটি কোর্স হেল্পার ডেমোতে যোগ করুন।** এখন ডেমোতে কী পরিবর্তন হয়?
৪. **ঝুঁকি নির্ণয় করুন।** এই ক্ষমতা ভুলভাবে ব্যবহৃত হলে কী সমস্যা হতে পারে?
৫. **একটি পরীক্ষা প্রশ্ন লিখুন।** আপনি কীভাবে যাচাই করবেন যে এজেন্ট ভালো আচরণ করছে?

## দ্রুত স্ব-মূল্যায়ন

এগিয়ে যাওয়ার আগে, এই প্রশ্নগুলোর উত্তর চেষ্টা করুন:

১. এমন কি কাজ এজেন্ট পারে যা একটি সাধারন চ্যাটবট নিজে থেকে পারে না?
২. প্রথমে কোন টুলটি আপনার এজেন্টের দরকার হবে, এবং কেন?
৩. কোন জ্ঞান উৎস এজেন্টের উত্তরের ভিত্তি হওয়া উচিত?
৪. পরবর্তী মডেল কলের জন্য কিসের প্রসঙ্গ অন্তর্ভুক্ত করা উচিত?

5. এজেন্টটির কি মনে রাখা উচিত এবং কি স্টোর করা এড়ানো উচিত?
6. কখন এজেন্টকে মানব অনুমোদনের জন্য জিজ্ঞাসা করা উচিত?
7. কোন লগ, ট্রেস বা রসিদগুলি পরে এজেন্ট ডিবাগ বা অডিট করতে সাহায্য করবে?


## প্রস্তাবিত ক্যাপস্টোন অনুশীলন

কোর্সের শেষে, এমন একটি ছোট এজেন্ট তৈরি করুন যা শিক্ষার্থীকে এই
রিপোজিটরি নেভিগেট করতে সাহায্য করে।

ন্যূনতম সংস্করণ:

- ব্যবহারকারীর কাছ থেকে একটি বিষয় গ্রহণ করুন।
- সবচেয়ে প্রাসঙ্গিক পাঠ খুঁজে বের করুন।
- আগে কী পড়তে হবে তা সংক্ষেপে ব্যাখ্যা করুন।
- একটি হাতে-কলমে অনুশীলনের কাজ প্রস্তাব করুন।
- কোন পাঠ ফাইল বা লিঙ্ক ব্যবহৃত হয়েছে তা দেখান।

প্রসারিত সংস্করণ:

- শিক্ষার্থীর পছন্দের প্রোগ্রামিং ভাষা মনে রাখুন।
- উত্তর দেওয়ার আগে একটি সহজ পরিকল্পনা ব্যবহার করুন।
- চূড়ান্ত প্রতিক্রিয়ার আগে একটি স্ব-পরীক্ষার ধাপ যোগ করুন।
- টুল কল এবং প্রাপ্ত উত্সগুলি লগ করুন।
- ব্রাউজার বা ইউআই অটোমেশন টাস্ক ওপেন করার আগে নিশ্চিতকরণ জিজ্ঞাসা করুন।

এটি আপনাকে একটি ছোট কিন্তু বাস্তবসম্মত উপায় দেয় টুলস, RAG, পরিকল্পনা,
প্রসঙ্গ, মেমরি, পর্যবেক্ষণযোগ্যতা এবং বিশ্বাস একটি প্রকল্পে অনুশীলনের জন্য।
