# এজেন্ট স্মোক টেস্টসমূহ

এই ফোল্ডারে আপনি কোর্সে আপনি যে এজেন্টগুলি তৈরি করেন তাদের জন্য **স্মোক-টেস্ট ক্যাটালগ** রাখা হয়েছে।
একটি স্মোক টেস্ট হলো একটি সস্তা, দ্রুত পরীক্ষা যা দেখায় যে একটি **মাইক্রোসফট ফাউন্ড্রি হোস্টেড
এজেন্ট** পৌঁছনীয়, সাড়া দিচ্ছে, এবং তার সবচেয়ে মৌলিক প্রম্পটের
প্রত্যাশাগুলো অনুসরণ করছে। এটি একটি প্রথম গেট — পুরো মূল্যায়ন
পাইপলাইন যা আপনি [Lesson 10](../10-ai-agents-production/README.md) এবং
[Lesson 16](../16-deploying-scalable-agents/README.md) থেকে শিখেন তার পরিবর্তে নয়।

ক্যাটালগগুলো ব্যবহার করে [AI Smoke Test](https://github.com/marketplace/actions/ai-smoke-test)
গিটহাব অ্যাকশন [`.github/workflows/smoke-test.yml`](../../../.github/workflows/smoke-test.yml)
ওয়ার্কফ্লোর মাধ্যমে।

## কিভাবে চালাবেন

১. **পাঠের এজেন্ট** মাইক্রোসফট ফাউন্ড্রিতে হোস্টেড এজেন্ট হিসেবে ডিপ্লয় করুন (ডিপ্লয়মেন্ট ওয়ার্কফ্লো জন্য
   Lesson 16 দেখুন)। **এজেন্ট নাম** এবং আপনার
   **ফাউন্ড্রি প্রজেক্ট এন্ডপয়েন্ট** নোট করুন।
২. এই রেপোজিটরি সিক্রেটগুলো যোগ করুন (Settings → Secrets and variables → Actions):
   `AZURE_CLIENT_ID`, `AZURE_TENANT_ID`, `AZURE_SUBSCRIPTION_ID`। ফেডারেটেড
   পরিচয়কে **Azure AI User** ভূমিকা প্রয়োজন **Foundry project scope** এ।
৩. **Actions** ট্যাব থেকে **Smoke-test hosted agents** রান করুন এবং পাঠের জন্য উপযুক্ত
   `tests_file` নির্বাচন করুন, তারপর মিলানো `agent_name` এবং
   `project_endpoint` প্রদান করুন।

## কোন কোন পাঠে স্মোক টেস্ট আছে?

স্মোক টেস্টগুলো সেই পাঠে প্রযোজ্য যা আপনি **একটি এজেন্ট ডিপ্লয় করেন** এবং যার টেক্সট উত্তরসমূহ
জানা কনটেন্টের সাথে মিলিয়ে_assert_ করা যায়। যেসব পাঠ ধারণাগত, শুধুমাত্র লোকাল চালিত,
বা অ-নির্দিষ্ট সৃজনশীল আউটপুট তৈরি করে সেগুলো উদ্দেশ্যমূলকভাবে বাদ দেওয়া হয়েছে:

- **Lesson 17 (Local AI Agents তৈরি)** সম্পূর্ণ আপনার ওয়ার্কস্টেশনে Foundry Local এর মাধ্যমে চলে এবং
  Foundry Responses এন্ডপয়েন্ট প্রকাশ করে না, তাই এই
  অ্যাকশন প্রযোজ্য নয়। এটি স্থানীয়ভাবে নোটবুক চালিয়ে যাচাই করুন।
- ডিজাইন-প্যাটার্ন ও থিওরি পাঠসমূহ (02, 03, 06, 07, 09, 12) একটিও
  ডিপ্লয়েবল এজেন্ট স্মোক-টেস্টের জন্য সরবরাহ করে না।

## ক্যাটালগ স্কিমা (দ্রুত রেফারেন্স)

প্রতিটি ক্যাটালগ একটি JSON ডকুমেন্ট যা একটি টপ-লেভেল `tests` অ্যারে ধারণ করে। প্রতিটি এন্ট্রি একটি প্রম্পট POST করে এবং রিপ্লাইতে অ্যাসার্ট করে:


| ফিল্ড | অর্থ |
|-------|---------|
| `id` | লগে প্রিন্ট করা ইউনিক স্টেপ আইডেন্টিফায়ার। |
| `description` | মানব-পাঠযোগ্য উদ্দেশ্য। |
| `prompt` | এজেন্টকে পাঠানো বার্তা। |
| `assertions.status` | প্রত্যাশিত HTTP স্থিতি (ডিফল্ট ২০০)। |
| `assertions.contains_any` | উত্তরে যদি এই ডিসাবস্ট্রিংগুলির কোনওটি থাকে তবে পাশ করুন। |
| `assertions.contains_all` | উত্তরে যদি প্রতিটি ডিসাবস্ট্রিং থাকে তবে পাশ করুন। |
| `assertions.contains_none` | উত্তরে যদি এই ডিসাবস্ট্রিংগুলির কোনওটি না থাকে তবে পাশ করুন। |
| `save_response_id_as` | পরবর্তী মাল্টি-টার্ন ধাপের জন্য উত্তর আইডি সংরক্ষণ করুন। |
| `use_previous_response_id` | সংরক্ষিত উত্তর আইডির সাথে এই টার্নটি সংযুক্ত করে পাঠান। |

অ্যাসারশনগুলো কেস-অনির্বাচিত সাবস্ট্রিং পরীক্ষা। দেখুন
[অ্যাকশন ডকুমেন্টেশন](https://github.com/marketplace/actions/ai-smoke-test) সম্পূর্ণ স্কিমার জন্য,
যাতে Foundry-পরিচালিত কথোপকথন সম্পদ অন্তর্ভুক্ত।
