## 🌱 শুরু করা হচ্ছে

এই কোর্সে AI এজেন্ট তৈরি করার মৌলিক বিষয়গুলি শেখানো হয়। প্রতিটি পাঠ তার নিজস্ব বিষয় আচ্ছাদিত করে, তাই যেখানে ইচ্ছা সেখান থেকে শুরু করুন!

এই কোর্সের জন্য বহুভাষিক সমর্থন রয়েছে। আমাদের কাছে পাবেন [এখানে উপলব্ধ ভাষাগুলো](#-multi-language-support)। 

যদি এটি আপনার প্রথমবারের মতো জেনেরেটিভ AI মডেলগুলির সাথে কাজ করা হয়, তাহলে আমাদের [নবাগতদের জন্য জেনেরেটিভ AI](https://aka.ms/genai-beginners) কোর্স দেখুন, যেখানে ২১টি পাঠ রয়েছে GenAI নিয়ে কাজ করার।

ভুলে যাবেন না [এই রিপোজিটরিটি স্টার (🌟) করুন](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst) এবং [রিপোজিটরিটি ফর্ক করুন](https://github.com/microsoft/ai-agents-for-beginners/fork) কোড চালানোর জন্য।

### অন্যান্য শিক্ষার্থীদের সাথে পরিচিত হন, আপনার প্রশ্নের উত্তর পান

যদি আপনি আটকে যান বা AI এজেন্ট তৈরির বিষয়ে কোনও প্রশ্ন থাকে, তাহলে আমাদের নিবেদিত Discord চ্যানেলে যোগ দিন [Microsoft Foundry Discord](https://aka.ms/ai-agents/discord)।

### আপনার প্রয়োজন

এই কোর্সের প্রতিটি পাঠে কোড উদাহরণ রয়েছে, যা code_samples ফোল্ডারে পাওয়া যাবে। আপনি [রিপোজিটরিটি ফর্ক করে](https://github.com/microsoft/ai-agents-for-beginners/fork) আপনার নিজস্ব কপি তৈরি করতে পারেন।  

এই অনুশীলনের কোড উদাহরণগুলো Microsoft Agent Framework এবং Microsoft Foundry Agent Service V2 ব্যবহার করে:

- [Microsoft Foundry](https://aka.ms/ai-agents-beginners/ai-foundry) - Azure একাউন্ট দরকার

এই কোর্সে ব্যবহার করা AI Agent ফ্রেমওয়ার্ক এবং সার্ভিসগুলো Microsoft থেকে:

- [Microsoft Agent Framework (MAF)](https://learn.microsoft.com/agent-framework/overview/)
- [Microsoft Foundry Agent Service V2](https://aka.ms/ai-agents-beginners/ai-agent-service)

কিছু কোড উদাহরণ [MiniMax](https://platform.minimaxi.com/) এর মতো বিকল্প OpenAI-সমর্থিত প্রোভাইডারও সাপোর্ট করে, যা বড়-কন্টেক্সট মডেল অফার করে (২০৪কে টোকেন পর্যন্ত)। কনফিগারেশন বিস্তারিত জানতে দেখুন [কোর্স সেটআপ](./00-course-setup/README.md)।

এই কোর্সের কোড চালানোর আরও তথ্য পেতে যান [কোর্স সেটআপ](./00-course-setup/README.md)।
