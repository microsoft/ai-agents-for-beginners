# ⚡ Azure OpenAI (Responses API) সহ সমান্তরাল এজেন্ট ওয়ার্কফ্লো (.NET)

## 📋 উচ্চ-পারফরম্যান্স সমান্তরাল প্রক্রিয়াকরণ টিউটোরিয়াল

এই নোটবুকটি Microsoft Agent Framework for .NET এবং Azure OpenAI (Responses API) ব্যবহার করে **সমান্তরাল ওয়ার্কফ্লো প্যাটার্ন** প্রদর্শন করে। আপনি শিখবেন কীভাবে উচ্চ-পারফরম্যান্স, সমান্তরাল প্রক্রিয়াকরণ ওয়ার্কফ্লো তৈরি করতে হয় যা একসঙ্গে একাধিক AI এজেন্টকে চালিয়ে থ্রুপুট বাড়ায়, সুতরাং সমন্বয় এবং ডেটার সামঞ্জস্যতা বজায় থাকে।

## 🎯 শেখার উদ্দেশ্য

### 🚀 **সমান্তরাল প্রক্রিয়াকরণের মূলনীতি**
- **সমান্তরাল এজেন্ট এক্সিকিউশন**: সর্বোচ্চ পারফরম্যান্সের জন্য একসঙ্গে একাধিক AI এজেন্ট চালানো
- **Async/Await প্যাটার্ন**: দক্ষ সমান্তরালতার জন্য .NET এর async প্রোগ্রামিং মডেল ব্যবহার
- **Azure OpenAI (Responses API)**: Azure OpenAI Responses API এর একাধিক সমান্তরাল কল সমন্বয় করা
- **রিসোর্স ম্যানেজমেন্ট**: সমান্তরাল অপারেশনগুলিতে AI মডেল রিসোর্স দক্ষতার সাথে পরিচালনা করা

### 🏗️ **উন্নত সমান্তরালতার আর্কিটেকচার**
- **টাস্ক-ভিত্তিক সমান্তরালতা**: অপ্টিমাল সমান্তরাল এক্সিকিউশনের জন্য .NET Task Parallel Library ব্যবহার
- **সিনক্রোনাইজেশন প্যাটার্ন**: রেস কন্ডিশন এড়িয়ে সমান্তরাল এজেন্টদের সমন্বয় করা
- **লোড ব্যালেন্সিং**: উপলব্ধ সমান্তরাল প্রক্রিয়াকরণের ক্ষমতা জুড়ে কাজ দক্ষতার সাথে বিতরণ
- **ফল্ট টলারেন্স**: পুরো ওয়ার্কফ্লো বন্ধ না করে পৃথক এজেন্টের ব্যর্থতা পরিচালনা

### 🏢 **এন্টারপ্রাইজ সমান্তরাল অ্যাপ্লিকেশন**
- **হাই-ভলিউম ডকুমেন্ট প্রক্রিয়াকরণ**: একসঙ্গে বহু ডকুমেন্ট প্রক্রিয়াকরণ
- **রিয়েল-টাইম কন্টেন্ট বিশ্লেষণ**: আসা ডেটা স্ট্রিমের সমান্তরাল বিশ্লেষণ
- **ব্যাচ প্রক্রিয়াকরণ অপ্টিমাইজেশন**: বৃহৎ-স্কেল ডেটা প্রক্রিয়াকরণের জন্য থ্রুপুট সর্বোত্তম করা
- **মাল্টি-মোডাল বিশ্লেষণ**: বিভিন্ন কন্টেন্ট টাইপ এবং ফরম্যাটের সমান্তরাল প্রক্রিয়াকরণ

## 💻 কোড চালানো

সম্পূর্ণ ইমপ্লিমেন্টেশন `03.dotnet-agent-framework-workflow-ghmodel-concurrent.cs` এ উপলব্ধ। এই ফাইলটি একটি **Fan-Out/Fan-In সমান্তরাল ওয়ার্কফ্লো** প্রণয়ন করে যা ট্রাভেল পরিকল্পনার জন্য:

### 🏗️ **ওয়ার্কফ্লো আর্কিটেকচার**

```
User Request → ConcurrentStartExecutor → [Researcher Agent || Planner Agent] → ConcurrentAggregationExecutor → Final Output
```

**মূল উপাদানসমূহ:**

1. **ConcurrentStartExecutor**: ব্যবহারকারীর অনুরোধ একসঙ্গে সব এজেন্টকে সম্প্রচার করে
2. **Researcher Agent**: গন্তব্য এবং আকর্ষণগুলো সমান্তরালভাবে বিশ্লেষণ করে
3. **Planner Agent**: বিস্তারিত ভ্রমণ পরিকল্পনা সমান্তরালভাবে তৈরি করে
4. **ConcurrentAggregationExecutor**: উভয় এজেন্টের ফলাফল সংগ্রহ এবং একত্রিত করে

### 🎯 **Fan-Out/Fan-In প্যাটার্ন**

এই ওয়ার্কফ্লো ক্লাসিক **Fan-Out/Fan-In** প্যাটার্ন প্রদর্শন করে:
- **Fan-Out**: একটি ইনপুট বার্তা একসঙ্গে একাধিক এজেন্টকে সম্প্রচার করা হয়
- **সমান্তরাল প্রক্রিয়াকরণ**: একাধিক এজেন্ট একই কাজ সমান্তরালে করে
- **Fan-In**: সব এজেন্টের ফলাফল সংগ্রহ করে একটি একক আউটপুটে একত্রিত করা হয়

### 🔧 কাস্টমাইজেশন অপশন

**আরো সমান্তরাল এজেন্ট যোগ করুন:**
```csharp
// Create additional specialized agents
AIAgent budgetAgent = azureClient.GetChatClient(deployment).AsAIAgent(
    name: "Budget-Agent", instructions: "Calculate travel costs...");

// Add to fan-out
var workflow = new WorkflowBuilder(startExecutor)
    .AddFanOutEdge(startExecutor, targets: [researcherAgent, plannerAgent, budgetAgent])
    .AddFanInBarrierEdge(sources: [researcherAgent, plannerAgent, budgetAgent], target: aggregationExecutor)
    .WithOutputFrom(aggregationExecutor)
    .Build();

// Update aggregation count
if (this._messages.Count == 3) { ... }
```

- **কন্টেন্ট তৈরি**: একাধিক লেখক একসঙ্গে পৃথক অংশ তৈরি করছে
- **কোড রিভিউ**: একাধিক রিভিউয়ার বিভিন্ন দৃষ্টিকোণ থেকে কোড বিশ্লেষণ করছে
- **মার্কেট রিসার্চ**: বিভিন্ন মার্কেট সেগমেন্টের সমান্তরাল বিশ্লেষণ
- **ডকুমেন্ট প্রক্রিয়াকরণ**: সমান্তরাল এক্সট্রাকশন, বিশ্লেষণ, এবং যাচাই
- **বহু-দৃষ্টিভঙ্গি বিশ্লেষণ**: একই ইনপুটের বিভিন্ন দৃষ্টিভঙ্গি গ্রহণ

### 🔍 কাস্টম এক্সিকিউটর বোঝা

**ConcurrentStartExecutor:**
- `IMessageHandler<string>` ইমপ্লিমেন্ট করে স্ট্রিং ইনপুট গ্রহণ করে
- সংযুক্ত সব এজেন্টকে মেসেজ সম্প্রচার করে
- সমান্তরাল প্রক্রিয়াকরণের জন্য `TurnToken` পাঠায়

**ConcurrentAggregationExecutor:**
- `IMessageHandler<ChatMessage>` ইমপ্লিমেন্ট করে এজেন্টের প্রতিক্রিয়া গ্রহণ
- থ্রেড-সেফ পদ্ধতিতে মেসেজ সংগ্রহ করে
- সব প্রত্যাশিত প্রতিক্রিয়া এলে একত্রিত করে
- `context.YieldOutputAsync()` ব্যবহার করে চূড়ান্ত আউটপুট প্রদান করে

### ⚡ পারফরম্যান্স সুবিধাসমূহ

**সমান্তরাল বনাম সিকোয়েন্সিয়াল:**
- সিকোয়েন্সিয়াল: Agent1 (30 সেকেন্ড) → Agent2 (30 সেকেন্ড) = **মোট 60 সেকেন্ড**
- সমান্তরাল: Agent1 (30 সেকেন্ড) || Agent2 (30 সেকেন্ড) = **মোট 30 সেকেন্ড**

**থ্রুপুট উন্নতি**: N সংখ্যক সমান্তরাল এজেন্টের জন্য N গুণ দ্রুত (ওয়ার্কলোড ও রিসোর্স অনুসারে)

### 🛡️ ত্রুটি পরিচালনা

ওয়ার্কফ্লো পৃথক এজেন্ট ব্যর্থতা সুন্দরভাবে পরিচালনা করে:
- একটি এজেন্ট ব্যর্থ হলেও অন্যরা প্রক্রিয়াকরণ চালিয়ে যায়
- অ্যাগ্রেগেটর টাইমআউট লজিক প্রয়োগ করতে পারে
- প্রয়োজন হলে আংশিক ফলাফল ফেরত দেয়া যেতে পারে
