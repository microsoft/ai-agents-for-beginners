## ইভেন্টের নাম: GitHub মডেল দিয়ে AI এজেন্ট প্রোটোটাইপিং

## বিবরণ

GitHub মডেলের জন্য ধন্যবাদ, আপনার প্রথম AI এজেন্ট তৈরি করার জন্য কেবল একটি GitHub অ্যাকাউন্টই যথেষ্ট! GitHub মডেলে শক্তিশালী মডেলগুলো যেমন OpenAI gpt-4.1, DeepSeek-R1, Llama-3.1, এবং আরও অনেক কিছু রয়েছে, যা আপনি প্লেগ্রাউন্ডে বা আপনার কোডে ব্যবহার করতে পারেন।

> **নোট:** GitHub Models অপরিহার্য (জুলাই ২০২৬-এ বিলুপ্তি)। নতুন প্রকল্পের জন্য GitHub Models ব্যবহার করবেন না — পরিবর্তে **Microsoft Foundry** মডেল ব্যবহার করুন।

## ইভেন্টের নাম: LangGraph এবং Azure Cosmos DB-এর সঙ্গে মাল্টি-এজেন্ট API

## বিবরণ

মাল্টি-এজেন্ট AI অ্যাপ্লিকেশনগুলো কীভাবে বুদ্ধিমান সিস্টেম তৈরি করছে তা বদলে দিচ্ছে - কিন্তু বাস্তব বিশ্বের স্কেলেবিলিটি এবং পারফরম্যান্সের জন্য আপনি কিভাবে আর্কিটেকচার করবেন? এই সেশনে, আমরা একটি প্রোডাকশন-গ্রেড মাল্টি-এজেন্ট অ্যাপ্লিকেশনকে গভীরভাবে বিশ্লেষণ করব যা LangGraph দিয়ে এজেন্ট অর্কেস্ট্রেশন, FastAPI দিয়ে API স্তর, এবং Azure Cosmos DB কে স্টেট ম্যানেজমেন্ট, ভেক্টর স্টোরেজ, এবং ট্রানজেকশনাল ডেটার জন্য প্রধান ভিত্তি হিসেবে ব্যবহার করে তৈরি করা হয়েছে।

বিস্তারিত কোড ওয়াকথ্রু মাধ্যমে, আপনি দেখতে পাবেন কীভাবে একটি এজেন্ট-চালিত ওয়ার্কফ্লো ডিজাইন ও বাস্তবায়ন করবেন যা retrieval-augmented generation (RAG), মেমরি পারসিস্টেন্স, এবং গতিশীল স্টেট ট্রানজিশন সহজভাবে সংহত করে। আমরা আলোচনা করব:

LangGraph দিয়ে কাঠামোবদ্ধ যুক্তির জন্য এজেন্ট সহযোগিতা
এজুর কোসমস DB ব্যবহার করে রিয়েল-টাইম চ্যাট ইতিহাস সংরক্ষণ - একই ডাটাবেস যা ChatGPT এর চ্যাট ইতিহাস চালায়, ইতিহাসে দ্রুত বর্ধিত AI এজেন্ট অ্যাপ্লিকেশন
Cosmos DB-এর প্রকৃত এম্বেডিং সমর্থনের মাধ্যমে জ্ঞান অনুসন্ধানের জন্য ভেক্টর শার্চ
FastAPI-এর অ্যাসিঙ্ক ক্ষমতা যা ইন্টারঅ্যাকশনকে দ্রুত এবং স্কেলযোগ্য রাখে
এই সেশনের শেষে, আপনি একটি পরিষ্কার ব্লুপ্রিন্ট পাবেন নিজস্ব স্কেলযোগ্য, ক্লাউড-নেটিভ মাল্টি-এজেন্ট অ্যাপ্লিকেশন তৈরি ও ডিপ্লয় করার জন্য যা আধুনিক AI এবং ক্লাউড ইনফ্রাসট্রাকচারের শক্তি ব্যবহার করে। আপনি AI ইঞ্জিনিয়ার হোন, ক্লাউড আর্কিটেক্ট বা Python ডেভেলপার, এই টকটি আপনাকে বাস্তব অভিজ্ঞতা এবং পরীক্ষিত প্যাটার্ন সরবরাহ করবে পরবর্তী প্রজন্মের AI-চালিত অ্যাপ্লিকেশন তৈরির জন্য।

## ইভেন্টের নাম: Microsoft Foundry এবং GitHub Copilot ব্যবহার করে Java এর জন্য AI এজেন্ট

## বিবরণ

এই সেশনে আমরা দেখাবো কীভাবে Microsoft Foundry ব্যবহার করে আপনার Java অ্যাপ্লিকেশনগুলিতে উন্নত AI এজেন্ট ক্ষমতা একত্রিত করবেন, যার মধ্যে প্রকল্পের লক্ষ্য নির্ধারণ, মডেল নিয়ে পরীক্ষা-নিরীক্ষা এবং নিরাপদভাবে প্রোডাকশন-রেডি সমাধান স্কেল করে ডিপ্লয় করা রয়েছে। পথ চলতে চলতে আপনি জানবেন GitHub Copilot (IntelliJ, VS Code, এবং Eclipse-এ) কীভাবে কোডিং এবং প্রম্পট তৈরি সহজ করে, যখন মডেল নির্বাচন, ফাইন-টিউনিং এবং এজেন্টিক ওয়ার্কফ্লোতে সেরা অনুশীলনগুলো নিশ্চিত করে দায়িত্বশীল এবং দক্ষ উন্নয়ন। আপনি AI এজেন্টে নতুন হন বা উন্নত এজেন্ট তৈরির কৌশল খুঁজছেন, এই সেশন আপনাকে এমন টুল দিয়ে সজ্জিত করবে যা আপনি ইতিমধ্যে জানেন, পরবর্তী স্তরের অভিজ্ঞতা দিতে।

## ইভেন্টের নাম: LangChain4j এবং Dynamic Sessions ব্যবহার করে Java AI এজেন্ট তৈরি

## বিবরণ

LangChain4j কে Azure Container Apps (ACA) ডাইনামিক সেশনের সাথে সংযুক্ত করে Azure AI সেবার সঙ্গে যুক্ত করে আপনার Java অ্যাপ্লিকেশনে AI এজেন্টের সম্ভাবনা খুলুন। এই সেশনটি একটি অনুশীলনী উদাহরণ দেখায় যা একটি দূরবর্তী পরিবেশের সঙ্গে ইন্টারঅ্যাকটিভ এজেন্ট তৈরি করে, যার মধ্যে ফাইল ম্যানেজমেন্ট অন্তর্ভুক্ত। শিখুন কাস্টম টুল কীভাবে সংজ্ঞায়িত করবেন, এজেন্ট ওয়ার্কফ্লোতে সেগুলোকে অন্তর্ভুক্ত করবেন, এবং Azure-এর স্কেলযোগ্য ইনফ্রাস্ট্রাকচার ব্যবহার করে বুদ্ধিমান, গতিশীল সমাধান ডিপ্লয় করবেন।

## ইভেন্টের নাম: অদায়িত্বশীল AI এজেন্ট

## বিবরণ

আমাদের সাথে যোগ দিন AI এজেন্টের সম্ভাব্য ঝুঁকি উদ্ঘাটন এবং কথোপকথন AI প্ল্যাটফর্মে বিশ্বাসযোগ্য AI অনুশীলন সংযুক্ত করার চ্যালেঞ্জ মোকাবেলায়! এই সেশনটি অদায়িত্বশীল AI এজেন্টের উদাহরণগুলিতে গভীরভাবে প্রবেশ করবে— যাতে রয়েছে অবিশ্বাস্য মডেল ব্যর্থতা, প্রতিযোগিতামূলক জেলব্রেক, এবং অন্যান্য ঝুঁকি যা বিশ্বাস এবং সম্মতি ক্ষুণ্ণ করে।

আমরা Microsoft-এর নতুনতম বিশ্বাসযোগ্য AI টুলগুলো অনুসন্ধান করব, যার মধ্যে রয়েছে কনটেন্ট ফিল্টার, রেড টিমিং কৌশল, এবং মূল্যায়ন—সহ লাইভ ডেমো যে AI এজেন্টগুলো জবাবদিহি এবং অদায়িত্বশীলভাবে আচরণ করে যা আপনি বিশ্বাস করতে পারবেন না।

🔥 আপনি যা পাবেন:
✅ কীভাবে AI ঝুঁকি চিহ্নিত এবং প্রতিরোধ করবেন ব্যবহারের আগে
✅ Azure AI Content Safety কীভাবে ঝুঁকিপূর্ণ আচরণ সনাক্ত এবং সমাধান করে
✅ AI এজেন্টকে বিশ্বাসযোগ্য করার গোপন উপাদান

ইতিহাসের সঠিক পাশে রাখা AI তৈরির জন্য প্রস্তুত হোন— কেবল AI তৈরি করবেন না, AI তৈরি করুন যেটি গুরুত্বপূর্ণ!

## ইভেন্টের নাম: Microsoft Foundry Agent Service দিয়ে আপনার কোড-প্রথম অ্যাপ তৈরি (.NET)

## বিবরণ

Microsoft Foundry Agent Service একটি নির্বিঘ্ন পরিষেবা এবং SDK মিশ্রণ যা শক্তিশালী AI-চালিত সমাধানগুলির উন্নয়ন সহজ করে। এই সেশনে, আপনি শিখবেন কিভাবে Azure এবং C# এর সাহায্যে আপনার নিজস্ব কোড-প্রথম AI এজেন্ট তৈরি করবেন। এটি প্রশ্নের উত্তর দিতে পারে, ডেটা বিশ্লেষণ করতে পারে এবং বাহ্যিক ডেটা উত্সগুলোর সাথে সংযুক্ত হতে পারে। আপনি আরো জটিল আর্কিটেকচার যেমন একাধিক এজেন্ট একসাথে কাজ করা কেমন হয় তাও অনুসন্ধান করবেন।

## ইভেন্টের নাম: Azure Cosmos দ্বারা চালিত মাল্টি-এজেন্ট AI অ্যাপ্লিকেশন নির্মাণে C# ব্যবহার করে Semantic Kernel

## বিবরণ

আমরা আপনাকে Semantic Kernel ফ্রেমওয়ার্কের উপর নির্মিত একটি মাল্টি-এজেন্ট অ্যাপ্লিকেশন C# এ কীভাবে তৈরি হয় তা দেখাবো। আপনি এজেন্টিক অ্যাপ্লিকেশনগুলোর পেছনের ধারণা বুঝবেন, বাস্তবায়নের বিস্তারিত ও সূক্ষ্মতাগুলো বোঝবেন, এবং কীভাবে বিভিন্ন ব্যবহারের জন্য Azure Cosmos DB কে ডাটাবেস হিসেবে একত্রিত করবেন শিখবেন।
