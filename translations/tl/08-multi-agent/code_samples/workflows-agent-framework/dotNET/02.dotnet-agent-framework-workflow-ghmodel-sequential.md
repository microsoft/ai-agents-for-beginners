# ⏩ Sunud-sunod na Workflow ng Ahente gamit ang Azure OpenAI (Responses API) (.NET)

## 📋 Advanced na Tutorial ng Sunud-sunod na Pagproseso

Ipinapakita sa notebook na ito ang **sunud-sunod na mga pattern ng workflow** gamit ang Microsoft Agent Framework para sa .NET at Azure OpenAI (Responses API). Matututuhan mo kung paano gumawa ng sopistikadong, hakbang-hakbang na mga pipeline ng pagproseso kung saan ang mga ahente ay nagpapatupad sa isang tiyak na pagkakasunod-sunod, na bawat yugto ay nakabatay sa mga resulta ng nakaraang yugto.

## 🎯 Mga Layunin sa Pagkatuto

### 🔄 **Arkitektura ng Sunud-sunod na Pagproseso**
- **Disenyong Linear Workflow**: Gumawa ng hakbang-hakbang na mga pipeline ng pagproseso na may malinaw na dependencies
- **Pamamahala ng Estado**: Panatilihin ang konteksto at daloy ng datos sa buong sunud-sunod na mga yugto ng workflow
- **Azure OpenAI (Responses API)**: Gamitin ang mga modelo ng Azure OpenAI sa multi-stage na mga workflow ng .NET
- **Mga Pattern ng Enterprise Pipeline**: Bumuo ng mga production-ready na sunud-sunod na sistema ng pagproseso

### 🏗️ **Advanced na Mga Pattern ng Sunud-sunod**
- **Stage-Gate Processing**: Magpatupad ng mga validation checkpoint sa pagitan ng mga yugto ng workflow
- **Pagpapanatili ng Konteksto**: Panatilihin ang estado at naipong kaalaman sa lahat ng yugto
- **Pagpapalaganap ng Error**: Pamahalaan ang mga pagkabigo nang maayos sa mga sunud-sunod na chain ng pagproseso
- **Optimization ng Performance**: Epektibong sunud-sunod na pagpapatupad na may minimal na overhead

### 🏢 **Mga Enterprise Sequential na Aplikasyon**
- **Document Processing Pipeline**: Multi-stage na pagsusuri, transformasyon, at pag-validate ng dokumento
- **Quality Assurance Workflows**: Sunud-sunod na pagsusuri, pag-validate, at proseso ng pag-apruba
- **Content Production Pipeline**: Pananaliksik → Pagsusulat → Pag-edit → Pagsusuri → Paglalathala
- **Business Process Automation**: Multi-step na mga workflow ng negosyo na may malinaw na dependencies ng yugto

### 🏗️ **Arkitektura ng Sunud-sunod na Workflow**

```mermaid
graph TD
    A[Initial Input] --> B[Stage 1: Ahente ng Pagsusuri]
    B --> C[Tsekpo 1]
    C --> D[Stage 2: Ahente ng Pagpoproseso]
    D --> E[Tsekpo 2]
    E --> F[Stage 3: Ahente ng Pagpapatunay]
    F --> G[Panghuling Output]
```

**Pangunahing Komponent:**
- **Sunud-sunod na Ahente**: Espesyalisadong mga ahente para sa bawat yugto ng pagproseso
- **Konteksto ng Estado**: Nagpapanatili ng naipong datos at mga desisyon sa mga yugto
- **Checkpoints**: Mga validation point sa pagitan ng mga yugto upang matiyak ang kalidad at pagkakapare-pareho
- **Azure OpenAI Client**: Consistent na access sa AI model sa lahat ng yugto ng workflow

## 💻 Pagpapatakbo ng Code

Ang kumpletong implementasyon ay makukuha sa `02.dotnet-agent-framework-workflow-ghmodel-sequential.cs`. Ipinapakita ng file na ito ang **three-stage na workflow ng pagsusuri ng muwebles**:

1. **Yugto 1 - Sales Agent**: Sinusuri ang mga larawan ng muwebles at nagbibigay ng mga suhestiyon sa pagbili
2. **Yugto 2 - Price Agent**: Nagbibigay ng detalyadong paghahati-hati ng presyo at mga pagpipilian sa budget
3. **Yugto 3 - Quote Agent**: Lumilikha ng propesyonal na quote document sa format na Markdown

### 🏗️ **Arkitektura ng Workflow**

```
Image Input → Sales Analysis → Price Estimation → Quote Generation → Final Output
```

Bawat ahente:
- Tumanggap ng output mula sa nakaraang yugto bilang konteksto
- Nagtatayo batay sa dating pagsusuri gamit ang espesyalisadong kaalaman
- Pinananatili ang pagkakaugnay ng workflow sa pamamagitan ng pamamahala ng estado

### 📝 Inaasahang Output

Ang workflow ay:
1. **Sales Agent**: Tukuyin ang mga item ng muwebles mula sa larawan at magbigay ng mga rekomendasyon
2. **Price Agent**: Magdagdag ng detalyadong pagsusuri sa presyo na may mga tier ng budget at mga rekomendasyon sa pamimili
3. **Quote Agent**: Gumawa ng isang format na dokumento ng quote na may lahat ng impormasyong pinagsama

Ang huling output ay magiging komprehensibo, propesyonal na quote para sa muwebles batay sa pagsusuri ng larawan.
