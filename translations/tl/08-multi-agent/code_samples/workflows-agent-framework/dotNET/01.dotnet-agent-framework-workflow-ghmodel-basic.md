# 🔄 Mga Pangunahing Daloy ng Trabaho ng Ahente gamit ang Azure OpenAI (Responses API) (.NET)

## 📋 Tutorial sa Orkestrasyon ng Daloy ng Trabaho

Ipinapakita ng notebook na ito kung paano bumuo ng sopistikadong **daloy ng trabaho ng ahente** gamit ang Microsoft Agent Framework para sa .NET at Azure OpenAI (Responses API). Matututuhan mong lumikha ng multi-step na mga proseso ng negosyo kung saan nakikipagtulungan ang mga AI agent upang magawa ang kumplikadong mga gawain sa pamamagitan ng estrukturadong mga pattern ng orkestrasyon.

## 🎯 Mga Layunin sa Pagkatuto

### 🏗️ **Mga Pangunahing Kaalaman sa Arkitektura ng Daloy ng Trabaho**
- **Workflow Builder**: Magdisenyo at mag-orchestrate ng kumplikadong multi-step na mga proseso ng AI
- **Agent Coordination**: Magkoordina ng maraming espesyalisadong ahente sa loob ng mga workflow
- **Azure OpenAI (Responses API)**: Gamitin ang Azure OpenAI Responses API sa mga daloy ng trabaho
- **Visual Workflow Design**: Lumikha at biswal na ipakita ang estruktura ng daloy ng trabaho para sa mas mahusay na pag-unawa

### 🔄 **Mga Pattern ng Orkestrasyon ng Proseso**
- **Sequential Processing**: Pagsamahin ang maraming gawain ng ahente sa lohikal na pagkakasunod
- **State Management**: Panatilihin ang konteksto at daloy ng data sa mga yugto ng workflow
- **Error Handling**: Magpatupad ng matibay na pag-recover sa error at katatagan ng workflow
- **Performance Optimization**: Magdisenyo ng epektibong mga workflow para sa mga operasyon sa antas ng enterprise

### 🏢 **Mga Aplikasyon ng Enterprise Workflow**
- **Business Process Automation**: I-automate ang kumplikadong mga workflow ng organisasyon
- **Content Production Pipeline**: Mga editorial workflow na may review at approval na mga yugto
- **Customer Service Automation**: Multi-step na pagresolba ng mga customer inquiry
- **Data Processing Workflows**: ETL na mga workflow na may AI-powered na transformasyon

## ⚙️ Mga Kinakailangan at Pagsisimula

### 📦 **Mga Kinakailangang NuGet Packages**

Ginagamit sa demonstrasyong ito ng workflow ang ilang mahahalagang package sa .NET:

```xml
<!-- Core AI Framework -->
<PackageReference Include="Microsoft.Extensions.AI" Version="9.9.0" />

<!-- Azure OpenAI (Responses API) -->
<PackageReference Include="Azure.AI.OpenAI" Version="2.1.0" />
<PackageReference Include="Azure.Identity" Version="1.13.1" />

<!-- Agent Framework (Local Development) -->
<!-- Microsoft.Agents.AI.dll - Core agent abstractions -->
<!-- Microsoft.Agents.AI.OpenAI.dll - Azure OpenAI (Responses API) integration -->

<!-- Configuration and Environment -->
<PackageReference Include="DotNetEnv" Version="3.1.1" />
```

### 🔑 **Azure OpenAI Configuration**

**Pagsasaayos ng Kapaligiran (.env file):**
```env
AZURE_OPENAI_ENDPOINT=https://<your-resource>.openai.azure.com
AZURE_OPENAI_DEPLOYMENT=gpt-4o-mini
```

**Access sa Azure OpenAI:**
1. Gumawa ng Azure OpenAI resource sa Azure portal
2. I-deploy ang isang modelo (halimbawa, `gpt-4o-mini`) at tandaan ang pangalan ng deployment
3. Mag-sign in gamit ang `az login` at i-configure ang environment variables tulad ng ipinakita sa itaas

**Mga Pangunahing Komponent:**
- **WorkflowBuilder**: Pangunahing engine ng orkestrasyon para sa pagdidisenyo ng mga workflow

- **Azure OpenAI Client**: Integrasyon ng Azure OpenAI Responses API
- **Execution Context**: Namamahala ng estado at daloy ng data sa pagitan ng mga yugto ng workflow

## 💻 Pagpapatakbo ng Code

Ang kumpletong implementasyon ay makikita sa `01.dotnet-agent-framework-workflow-ghmodel-basic.cs`. Ipinapakita ng file na ito:

1. **Environment Configuration** - Pag-load ng Azure OpenAI configuration mula sa `.env` file
2. **Azure OpenAI Client Setup** - Pag-configure sa client upang gamitin ang Azure OpenAI Responses API
3. **Agent Creation** - Pagdedepina ng espesyalisadong mga ahente (Front Desk at Concierge)
4. **Workflow Builder** - Paglikha ng multi-agent workflow na may sequential processing
5. **Workflow Execution** - Pagpapatakbo ng workflow gamit ang streaming results

### 🚀 Pagpapatakbo ng Halimbawa

```bash
# Gawing executable ang script (Unix/Linux/macOS)
chmod +x 01.dotnet-agent-framework-workflow-ghmodel-basic.cs

# Patakbuhin ang workflow
./01.dotnet-agent-framework-workflow-ghmodel-basic.cs
```

O sa Windows:
```powershell
dotnet run 01.dotnet-agent-framework-workflow-ghmodel-basic.cs
```

### 📝 Inaasahang Output

Gagawin ng workflow ang mga sumusunod:
1. Tatanggapin ang iyong kahilingan sa destinasyon ng paglalakbay ("Gusto kong pumunta sa Paris")
2. Magbibigay ang Front Desk agent ng paunang rekomendasyon
3. Susuriin at paiigtingin ng Concierge agent ang rekomendasyon
4. Ipapakita ang panghuling output ng buong daloy ng pag-uusap
