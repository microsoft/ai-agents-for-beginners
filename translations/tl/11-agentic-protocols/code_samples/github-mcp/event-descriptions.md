## Pangalan ng Kaganapan: Multi-Agent API gamit ang LangGraph at Azure Cosmos DB

## Paglalarawan

Ang pag-angat ng multi-agent AI applications ay binabago kung paano tayo bumubuo ng matatalinong sistema - ngunit paano mo ba ito ia-arkitektura para sa totoong scalability at performance? Sa sesyong ito, aalisin natin nang malalim ang isang production-grade na multi-agent application na ginawa gamit ang LangGraph para sa agent orchestration, FastAPI bilang API layer, at Azure Cosmos DB bilang backbone para sa state management, vector storage, at transactional data.

Sa pamamagitan ng detalyadong walkthrough ng code, makikita mo kung paano magdesenyo at mag-implementa ng isang agent-driven workflow na seamlessly na-integrate ang retrieval-augmented generation (RAG), memory persistence, at dynamic state transitions. Tatalakayin namin:

Pakikipagtulungan ng agent gamit ang LangGraph para sa structured reasoning
Real-time na storage ng chat history gamit ang Azure Cosmos DB - ang parehong database na nagpapaandar ng chat history sa ChatGPT, ang pinakamabilis na lumalagong AI agent application sa kasaysayan
Vector search para sa retrieval ng kaalaman gamit ang native embeddings support ng Cosmos DB
Mga async capabilities ng FastAPI upang panatilihing responsive at scalable ang pakikipag-ugnayan
Pagkatapos ng sesyon na ito, magkakaroon ka ng malinaw na blueprint para bumuo at mag-deploy ng sarili mong scalable, cloud-native na multi-agent applications na ginagamit ang kapangyarihan ng modernong AI at cloud infrastructure. Kahit ikaw ay AI engineer, cloud architect, o Python developer, bibigyan ka ng talk na ito ng praktikal na pananaw at mga napatunayang pattern para bumuo ng susunod na henerasyon ng AI-powered na mga application.

## Pangalan ng Kaganapan: Prompting ay ang Bagong Scripting: Kilalanin ang GenAIScript

## Paglalarawan

Minsan, pinadali ng jQuery ang web development sa pamamagitan ng pag-abstra sa mga komplikasyon, na nagpapahintulot sa mga developer na magtuon sa pagbuo imbis na makipagbuno sa mga quirks ng browser. Ngayon, ang pagde-develop ng AI ay humaharap sa katulad na hamon. Patuloy na lumilitaw ang mga bagong pattern at ang pagsabay dito ay maaaring maging napakalaki, lalo na habang ang mga AI tool—lalo na ang mga agentic—ay nagiging mas makapangyarihan at komplikado. Sa talk na ito, tatalakayin namin kung paano ginagawang intuitive ng GenAIScript ang AI automation agents katulad ng pagsulat ng JavaScript, na tumutulong sa iyo na gawing mas madali ang paulit-ulit na trabaho nang hindi kailangan ng malawak na AI expertise.
