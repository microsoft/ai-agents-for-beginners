## Pangalan ng Kaganapan: Multi-Agent API gamit ang LangGraph at Azure Cosmos DB

## Paglalarawan

Ang pag-angat ng mga multi-agent AI application ay binabago kung paano tayo bumubuo ng matatalinong sistema - pero paano mo iyon ina-arkitekto para sa totoong scalability at performance? Sa sesyong ito, susuriin natin nang malalim ang production-grade na multi-agent application na binuo gamit ang LangGraph para sa agent orchestration, FastAPI para sa API layer, at Azure Cosmos DB bilang backbone para sa pamamahala ng estado, vector storage, at transactional data.

Sa pamamagitan ng detalyadong walkthrough ng code, makikita mo kung paano magdisenyo at magpatupad ng workflow na pinamumunuan ng agent na walang putol na nagsasama ng retrieval-augmented generation (RAG), memory persistence, at dynamic state transitions. Tatalakayin namin:

Pagtutulungan ng agent gamit ang LangGraph para sa istrukturadong pag-iisip
Real-time na pagsasaayos ng history ng chat gamit ang Azure Cosmos DB - ang parehong database na nagpapatakbo ng chat history sa ChatGPT, ang pinakamabilis lumaking AI agent application sa kasaysayan
Vector search para sa pagkuha ng kaalaman gamit ang katutubong embeddings support ng Cosmos DB
Async na kakayahan ng FastAPI upang panatilihing responsive at scalable ang mga interaksyon
Sa pagtatapos ng sesyon na ito, magkakaroon ka ng malinaw na plano para sa pagtayo at pag-deploy ng sarili mong scalable, cloud-native na multi-agent applications na gumagamit ng kapangyarihan ng makabagong AI at cloud infrastructure. Kahit ikaw ay AI engineer, cloud architect, o Python developer, bibigyan ka ng talakayang ito ng praktikal na mga pananaw at mga pattern na sinubok sa laban upang bumuo ng susunod na henerasyon ng AI-powered na mga aplikasyon

## Pangalan ng Kaganapan: Ang Prompting ay ang Bagong Scripting: Kilalanin ang GenAIScript

## Paglalarawan

Noong una, ginawang mas madali ng jQuery ang web development sa pamamagitan ng pag-aalis ng mga kumplikasyon, na nagpapahintulot sa mga developer na mag-focus sa paggawa sa halip na labanan ang mga pambihirang katangian ng browser. Ngayon, ang AI development ay nahaharap sa katulad na hamon. Patuloy na lumilitaw ang mga bagong pattern at maaaring maging napakalaki ang pagsunod dito, lalo na habang ang mga AI tool—lalo na ang mga agentic—ay nagiging mas makapangyarihan at kumplikado. Paano kung magagamit mo ang mga makabagong kakayahan ng AI upang i-automate ang mga gawain gamit ang mga simpleng at pamilyar na JavaScript abstractions? Narito ang GenAIScript—isang paraan upang maisama ang AI sa iyong workflow nang madali, itinuturing ang mga prompt na parang reusable code snippets. Sa talakayang ito, susuriin natin kung paano ginagawang intuitive ng GenAIScript ang AI automation agents na parang sumusulat ng JavaScript, na tumutulong sa iyo na pagaanin ang paulit-ulit na gawain nang hindi kailangan ng malalim na kaalaman sa AI.
