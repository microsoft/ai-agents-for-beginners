# Pagsasagawa ng kontribusyon

Tinatanggap ng proyektong ito ang mga kontribusyon at mungkahi. Karamihan sa mga kontribusyon ay nangangailangan na pumayag ka sa isang Contributor License Agreement (CLA) na nagsasaad na ikaw ay may karapatan, at talagang nagbibigay sa amin ng mga karapatan na gamitin ang iyong kontribusyon. Para sa mga detalye, bisitahin ang <https://cla.opensource.microsoft.com>.

Kapag nagsumite ka ng pull request, awtomatikong tutukuyin ng isang CLA bot kung kailangan mong magbigay ng CLA at bibigyang palamuti ang pull request nang naaangkop. Sundin ang mga tagubiling ibinigay ng bot. Gagawin mo lamang ito isang beses sa mga repositoryong gumagamit ng Microsoft CLA.

## Kodigo ng Pag-uugali

Inampon ng proyektong ito ang [Microsoft Open Source Code of Conduct](https://opensource.microsoft.com/codeofconduct/). Para sa karagdagang impormasyon, tingnan ang [Code of Conduct FAQ](https://opensource.microsoft.com/codeofconduct/faq/) o makipag-ugnayan sa [opencode@microsoft.com](mailto:opencode@microsoft.com) para sa mga dagdag na tanong o puna.

## Mga patnubay sa pull request

- Panatilihing nakatuon ang bawat pull request sa isang lohikal na pagbabago.
- Subukan ang mga apektadong notebook at halimbawa ng kodigo bago isumite.
- I-update ang kaugnay na dokumentasyon ng aralin kapag nagdagdag o nagbago ng isang halimbawa.
- I-edit lamang ang nilalamang Ingles na pinagmulan. Pinamamahalaan ng automated translation workflow ang mga pagsasalin.
- Huwag mag-commit ng mga kredensyal, `.env` na mga file, pansamantalang mga file, o mga nilikhang artipakto ng pag-unlad.

## Saklaw ng pag-edit at mga produktong pangatlong partido

Nakatuon ang kurikulum na ito sa mga teknolohiyang Microsoft at mga vendor-neutral na bukas na pamantayan. Ang mga kontribusyon ay dapat magsilbi ng malinaw na layunin pang-edukasyon at hindi dapat pangunahing inilaan upang ipakilala o itaguyod ang isang komersyal na produkto ng pangatlong partido, hosted service, model router, SDK, MCP server, o iba pang alok na spesipiko sa vendor.

Maaaring banggitin ang open-source na software at mga third-party na dependencies kapag kinakailangan upang ipaliwanag ang isang bukas na pamantayan o senaryo ng interoperability, ipinapakita nang neutral, at hindi sentralisado sa isang produkto ng vendor o hosted na endpoint. Kung ang iminungkahing kontribusyon mo ay naglalaman ng isang vendor-specific na produkto o serbisyo, magbukas ng isyu at kumuha ng pahintulot mula sa tagapangalaga bago magsumite ng pull request.

Dapat isiwalat ng mga kontribyutor ang anumang kaugnay na employment, pagmamay-ari, sponsorship, o ibang ugnayan sa isang produkto o serbisyong binanggit sa kanilang kontribusyon. Huwag isama ang hindi suportadong mga pahayag tungkol sa presyo, pagganap, seguridad, privacy, o paghahambing. Ang mga natatakbong halimbawa ay hindi dapat magpadala ng data ng mag-aaral o magsagawa ng mga pampublikong aksyon sa pamamagitan ng isang panlabas na third-party na serbisyo bilang default.
