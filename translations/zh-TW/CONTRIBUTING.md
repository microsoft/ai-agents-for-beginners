# 貢獻指南

此專案歡迎貢獻與建議。大多數貢獻需要您同意一份貢獻者授權協議 (CLA)，聲明您有權且實際授權我們使用您的貢獻。詳細資訊請參閱 <https://cla.opensource.microsoft.com>。

當您提交拉取請求 (pull request) 時，CLA 機器人會自動判定您是否需要提供 CLA，並相應標記拉取請求。請依照機器人提供的指示操作。在使用 Microsoft CLA 的倉庫中，您只需執行一次此流程。

## 行為守則

本專案已採用 [Microsoft 開源行為守則](https://opensource.microsoft.com/codeofconduct/)。欲了解更多資訊，請參閱 [行為守則常見問題](https://opensource.microsoft.com/codeofconduct/faq/) 或聯繫 [opencode@microsoft.com](mailto:opencode@microsoft.com) 詢問其他問題或提供意見。

## 拉取請求指南

- 每個拉取請求應集中於一個邏輯更動。
- 在提交前請測試受影響的筆記本和程式碼範例。
- 新增或更改範例時，請更新相關課程文件。
- 僅編輯英文原始內容。翻譯由自動翻譯工作流程維護。
- 請勿提交認證憑證、`.env` 檔案、暫存檔案或產生的開發產物。

## 編輯範圍與第三方產品

本課程專注於 Microsoft 技術和供應商中立的開放標準。貢獻內容應具明確教育目的，不得以介紹或推廣第三方商業產品、託管服務、模型路由器、SDK、MCP 伺服器或其他廠商專有產品為主。

當必須解釋開放標準或互通性場景時，可引用開源軟體與第三方相依項，但必須以中立方式呈現，且不聚焦於任何廠商產品或託管端點。若您的提案包含廠商專有產品或服務，請先開啟議題並取得維護者批准後，再提交拉取請求。

貢獻者必須揭露與其貢獻中提及的產品或服務相關的職務、持股、贊助或其他關係。請勿包含未經證實的定價、效能、安全性、隱私或比較性聲明。可執行範例預設不得傳送學習者資料或透過外部第三方服務執行公開操作。
