## 🌱 入门指南

本课程包含构建 AI 代理的基础课程。每节课涵盖不同主题，随意选择起点吧！

本课程支持多语言。请查看我们的[可用语言列表](#-multi-language-support)。

如果你是首次使用生成式 AI 模型构建，推荐学习我们的[初学者生成式 AI](https://aka.ms/genai-beginners)课程，包含 21 课生成式 AI 构建内容。

不要忘记给本仓库[加星(🌟)](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst)并[Fork 本仓库](https://github.com/microsoft/ai-agents-for-beginners/fork)运行代码。

### 结识其他学习者，获取问题解答

遇到困难或者有 AI 代理构建问题，欢迎加入我们的专属 Discord 频道 [Microsoft Foundry Discord](https://aka.ms/ai-agents/discord)。

### 你需要准备

本课程每课包含代码示例，存放于 code_samples 文件夹。你可以[Fork 本仓库](https://github.com/microsoft/ai-agents-for-beginners/fork)创建自己的副本。  

这些示例代码使用微软代理框架及 Microsoft Foundry Agent Service V2：

- [Microsoft Foundry](https://aka.ms/ai-agents-beginners/ai-foundry) - 需要 Azure 账号

本课程使用微软以下 AI 代理框架和服务：

- [微软代理框架 (MAF)](https://learn.microsoft.com/agent-framework/overview/)
- [Microsoft Foundry Agent Service V2](https://aka.ms/ai-agents-beginners/ai-agent-service)

部分示例代码支持兼容 OpenAI 的其他供应商如 [MiniMax](https://platform.minimaxi.com/)，提供大上下文模型（最高 204K 令牌）。配置详情详见[课程配置](./00-course-setup/README.md)。

有关运行本课程代码的更多信息，请参阅[课程配置](./00-course-setup/README.md)。
