## 🌱 入门指南

这门课程涵盖构建 AI 代理的基础知识。每节课都有独立主题，可以随意开始学习！

课程支持多语言。请查看我们的[支持语言列表](#-multi-language-support)。

如果你是第一次使用生成式 AI 模型构建应用，请查看我们的[生成式 AI 初学者课程](https://aka.ms/genai-beginners)，包含21节构建 GenAI 的课程。

不要忘记给本仓库[标星（🌟）](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst)和[分叉](https://github.com/microsoft/ai-agents-for-beginners/fork)来运行代码。

### 遇见其他学习者，获得问题解答

如果遇到困难或有关于构建 AI 代理的任何疑问，请加入我们的专用 Discord 频道：[Microsoft Foundry Discord](https://aka.ms/ai-agents/discord)。

### 你需要准备的

课程中每节课都包含代码示例，位于 code_samples 文件夹。你可以[分叉本仓库](https://github.com/microsoft/ai-agents-for-beginners/fork)创建自己的副本。

本课程的代码示例使用 Microsoft 代理框架和 Microsoft Foundry 代理服务 V2：

- [Microsoft Foundry](https://aka.ms/ai-agents-beginners/ai-foundry) - 需要 Azure 账号

本课程使用 Microsoft 提供的以下 AI 代理框架和服务：

- [Microsoft 代理框架 (MAF)](https://learn.microsoft.com/agent-framework/overview/)
- [Microsoft Foundry 代理服务 V2](https://aka.ms/ai-agents-beginners/ai-agent-service)

一些代码示例还支持兼容 OpenAI 的其他提供商，例如提供大上下文模型（最高支持204K令牌）的[MiniMax](https://platform.minimaxi.com/)。配置详情见[课程设置](./00-course-setup/README.md)。

更多关于运行本课程代码的信息请查看[课程设置](./00-course-setup/README.md)。
