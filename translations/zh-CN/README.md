## 🌱 入门指南

本课程涵盖构建 AI 代理的基础知识。每节课专注于一个主题，您可以从任何地方开始学习！

本课程支持多语言。请前往我们[可用语言这里](#-multi-language-support)。

如果这是您第一次使用生成式 AI 模型构建，推荐查看我们的[生成式 AI 初学者课程](https://aka.ms/genai-beginners)，其中包含21个构建生成式 AI 的课程。

别忘了[为此仓库点星 (🌟)](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst)并[分叉此仓库](https://github.com/microsoft/ai-agents-for-beginners/fork)以运行代码。

### 认识其他学习者，获得问题解答

如果您在构建 AI 代理时遇到困难或有任何问题，请加入我们的专用 Discord 频道：[Microsoft Foundry Discord](https://aka.ms/ai-agents/discord)。

### 您需要准备的内容

本课程的每节课都包含代码示例，保存在 code_samples 文件夹中。您可以[分叉此仓库](https://github.com/microsoft/ai-agents-for-beginners/fork)以创建您自己的副本。  

这些练习的代码示例使用 Microsoft Agent Framework 和 Microsoft Foundry Agent Service V2：

- [Microsoft Foundry](https://aka.ms/ai-agents-beginners/ai-foundry) - 需要 Azure 账户

本课程使用 Microsoft 提供的以下 AI 代理框架和服务：

- [Microsoft Agent Framework (MAF)](https://learn.microsoft.com/agent-framework/overview/)
- [Microsoft Foundry Agent Service V2](https://aka.ms/ai-agents-beginners/ai-agent-service)

部分代码示例也支持兼容 OpenAI 的替代提供商，如[MiniMax](https://platform.minimaxi.com/)，它提供大上下文模型（最高支持 204K 令牌）。详情请参见[课程设置](./00-course-setup/README.md)。

有关运行本课程代码的更多信息，请访问[课程设置](./00-course-setup/README.md)。
