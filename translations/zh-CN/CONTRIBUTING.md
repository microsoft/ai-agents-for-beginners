# 贡献指南

欢迎对本项目进行贡献和提出建议。大多数贡献需要您同意一份贡献者许可协议 (CLA)，声明您有权利且确实授予我们使用您贡献内容的权利。详情请访问 <https://cla.opensource.microsoft.com>。

当您提交拉取请求时，CLA 机器人会自动判断您是否需要提供 CLA，并适当标记该拉取请求。请按照机器人提供的说明操作。使用 Microsoft CLA 的多个仓库中，您只需执行此操作一次。

## 行为准则

本项目采用了 [Microsoft 开源行为准则](https://opensource.microsoft.com/codeofconduct/)。更多信息，请参阅 [行为准则常见问题](https://opensource.microsoft.com/codeofconduct/faq/) 或通过 [opencode@microsoft.com](mailto:opencode@microsoft.com) 联系我们，提出额外问题或意见。

## 拉取请求指南

- 保持每个拉取请求专注于一个逻辑性变更。
- 在提交前测试受影响的笔记本和代码示例。
- 添加或更改示例时，请更新相关课程文档。
- 仅编辑英文源内容。翻译由自动翻译工作流维护。
- 不要提交凭据、`.env` 文件、临时文件或生成的开发工件。

## 编辑范围和第三方产品

本课程重点关注微软技术和供应商中立的开放标准。贡献应服务于明确的教育目的，且不得主要用于介绍或推广第三方商业产品、托管服务、模型路由器、SDK、MCP 服务器或其他供应商特定的产品。

当开源软件和第三方依赖对解释开放标准或互操作场景是必要时，可被引用，但必须保持中立，且不围绕供应商的产品或托管端点展开。如果您的贡献包含供应商特定的产品或服务，请先提出 issue 并获得维护者批准后再提交拉取请求。

贡献者必须披露其与其贡献中提及的产品或服务相关的任何雇佣关系、所有权、赞助或其他关联。请勿包含未经支持的定价、性能、安全、隐私或比较声明。运行示例默认不得传输学习者数据或通过外部第三方服务执行公共操作。
