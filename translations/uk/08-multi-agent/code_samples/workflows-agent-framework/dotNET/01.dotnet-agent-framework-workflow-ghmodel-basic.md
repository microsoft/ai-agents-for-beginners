# 🔄 Основні робочі процеси агентів з Azure OpenAI (Responses API) (.NET)

## 📋 Навчальний посібник з оркестрації робочих процесів

У цьому ноутбуку демонструється, як створювати складні **робочі процеси агентів** за допомогою Microsoft Agent Framework для .NET і Azure OpenAI (Responses API). Ви навчитеся створювати багатокрокові бізнес-процеси, де агенти зі штучним інтелектом співпрацюють для виконання складних завдань через структуровані патерни оркестрації.

## 🎯 Навчальні цілі

### 🏗️ **Основи архітектури робочих процесів**
- **Workflow Builder**: Проєктування та оркестрація складних багатокрокових AI процесів
- **Координація агентів**: Координація кількох спеціалізованих агентів у робочих процесах
- **Azure OpenAI (Responses API)**: Використання Azure OpenAI Responses API у робочих процесах
- **Візуальне проєктування робочих процесів**: Створення та візуалізація структур робочих процесів для кращого розуміння

### 🔄 **Патерни оркестрації процесів**
- **Послідовна обробка**: Ланцюжок кількох завдань агента в логічному порядку
- **Управління станом**: Підтримка контексту та потоку даних між етапами робочого процесу
- **Обробка помилок**: Впровадження надійного відновлення від помилок і стійкості робочого процесу
- **Оптимізація продуктивності**: Проєктування ефективних робочих процесів для корпоративних операцій

### 🏢 **Корпоративні прикладні робочі процеси**
- **Автоматизація бізнес-процесів**: Автоматизація складних організаційних робочих процесів
- **Конвеєр створення контенту**: Редакційні робочі процеси з етапами перевірки та затвердження
- **Автоматизація обслуговування клієнтів**: Багатокрокове вирішення запитів клієнтів
- **Обробка даних**: ETL робочі процеси з AI-оптимізованим перетворенням

## ⚙️ Вимоги та налаштування

### 📦 **Необхідні пакети NuGet**

У цьому демонстраційному робочому процесі використовуються кілька ключових .NET пакетів:

```xml
<!-- Core AI Framework -->
<PackageReference Include="Microsoft.Extensions.AI" Version="9.9.0" />

<!-- Azure OpenAI (Responses API) -->
<PackageReference Include="Azure.AI.OpenAI" Version="2.1.0" />
<PackageReference Include="Azure.Identity" Version="1.13.1" />

<!-- Agent Framework (Local Development) -->
<!-- Microsoft.Agents.AI.dll - Core agent abstractions -->
<!-- Microsoft.Agents.AI.OpenAI.dll - Azure OpenAI (Responses API) integration -->

<!-- Configuration and Environment -->
<PackageReference Include="DotNetEnv" Version="3.1.1" />
```

### 🔑 **Конфігурація Azure OpenAI**

**Налаштування середовища (.env файл):**
```env
AZURE_OPENAI_ENDPOINT=https://<your-resource>.openai.azure.com
AZURE_OPENAI_DEPLOYMENT=gpt-4o-mini
```

**Доступ до Azure OpenAI:**
1. Створіть ресурс Azure OpenAI у порталі Azure
2. Розгорніть модель (наприклад, `gpt-4o-mini`) і збережіть ім’я розгортання
3. Увійдіть за допомогою `az login` і налаштуйте змінні середовища, як показано вище

### 🏗️ **Огляд архітектури робочих процесів**

```mermaid
graph TD
    A[Побудова робочого процесу] --> B[Реєстр агентів]
    B --> C[Двигун виконання робочих процесів]
    C --> D[Agent 1: Генератор контенту]
    C --> E[Agent 2: Рецензент контенту] 
    D --> F[Результати робочого процесу]
    E --> F
    G[Azure OpenAI (API відповідей)] --> D
    G --> E
```

**Ключові компоненти:**
- **WorkflowBuilder**: Основний двигун оркестрації для проєктування робочих процесів
- **AIAgent**: Окремі спеціалізовані агенти зі специфічними можливостями
- **Клієнт Azure OpenAI**: Інтеграція Azure OpenAI Responses API
- **Execution Context**: Керує станом і потоком даних між етапами робочого процесу

## 💻 Запуск коду

Повна реалізація доступна у файлі `01.dotnet-agent-framework-workflow-ghmodel-basic.cs`. Цей файл демонструє:

1. **Налаштування середовища** - Завантаження конфігурації Azure OpenAI з файлу `.env`
2. **Налаштування клієнта Azure OpenAI** - Конфігурування клієнта для використання Azure OpenAI Responses API
3. **Створення агентів** - Визначення спеціалізованих агентів (Front Desk та Concierge)
4. **Workflow Builder** - Створення багатоагентного робочого процесу з послідовною обробкою
5. **Виконання робочого процесу** - Запуск робочого процесу з потоковою трансляцією результатів

### 🚀 Запуск прикладу

```bash
# Зробіть скрипт виконуваним (Unix/Linux/macOS)
chmod +x 01.dotnet-agent-framework-workflow-ghmodel-basic.cs

# Запустіть робочий процес
./01.dotnet-agent-framework-workflow-ghmodel-basic.cs
```

Або у Windows:
```powershell
dotnet run 01.dotnet-agent-framework-workflow-ghmodel-basic.cs
```

### 📝 Очікуваний результат

Робочий процес буде:
1. Приймати ваш запит про місце подорожі ("Я хотів би поїхати до Парижа")
2. Агент Front Desk надасть початкову рекомендацію
3. Агент Concierge перегляне і доопрацює рекомендацію
4. Остаточний вихід відображатиме повний потік розмови

Ви можете налаштувати робочий процес шляхом:
- Зміни інструкцій агентів для зміни їхньої поведінки
- Додавання більшої кількості агентів для створення складних багатокрокових робочих процесів
- Зміни повідомлення користувача для тестування різних сценаріїв
- Коригування з’єднань робочого процесу для створення різних патернів виконання
