# 🔍 Корпоративний RAG з Microsoft Foundry (.NET)

## 📋 Мети навчання

Цей нотатник демонструє, як створювати системи генерації з доповненням пошуку корпоративного рівня (RAG) за допомогою Microsoft Agent Framework у .NET з Microsoft Foundry. Ви навчитесь створювати готових до виробництва агентів, які можуть шукати серед документів і надавати точні, контекстно-залежні відповіді з корпоративною безпекою та масштабованістю.

**Можливості корпоративного RAG, які ви розробите:**
- 📚 **Інтелект документів**: Розширена обробка документів за допомогою сервісів Azure AI
- 🔍 **Семантичний пошук**: Високопродуктивний векторний пошук з корпоративними функціями
- 🛡️ **Інтеграція безпеки**: Контроль доступу на основі ролей та шаблони захисту даних
- 🏢 **Масштабована архітектура**: Готові до виробництва системи RAG з моніторингом

## 🎯 Архітектура корпоративного RAG

### Основні компоненти підприємства
- **Microsoft Foundry**: Керована корпоративна платформа штучного інтелекту з безпекою та відповідністю
- **Постійні агенти**: Агенти зі станом, що зберігають історію розмов та керують контекстом
- **Управління векторним сховищем**: Індексація та пошук документів корпоративного рівня
- **Інтеграція ідентичності**: Автентифікація Azure AD та контроль доступу на основі ролей

### Переваги .NET для підприємств
- **Типобезпечність**: Перевірка під час компіляції для операцій RAG і структур даних
- **Асинхронна продуктивність**: Не блокуюча обробка документів та пошукові операції
- **Управління пам’яттю**: Ефективне використання ресурсів для великих колекцій документів
- **Шаблони інтеграції**: Рідна інтеграція з сервісами Azure з впровадженням залежностей

## 🏗️ Технічна архітектура

### Трубопровід корпоративного RAG
```
Document Upload → Security Validation → Vector Processing → Index Creation
                      ↓                    ↓                  ↓
User Query → Authentication → Semantic Search → Context Ranking → AI Response
```

### Основні компоненти .NET
- **Azure.AI.Agents.Persistent**: Управління корпоративними агентами з збереженням стану
- **Azure.Identity**: Інтегрована аутентифікація для безпечного доступу до сервісів Azure
- **Microsoft.Agents.AI.AzureAI**: Оптимізована для Azure реалізація агентського фреймворку
- **System.Linq.Async**: Високопродуктивні асинхронні операції LINQ
