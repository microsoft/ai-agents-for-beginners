# AGENTS.md

## Огляд проекту

Цей репозиторій містить "AI Agents for Beginners" - комплексний освітній курс, який навчає всьому необхідному для створення AI агентів. Курс складається з 18 уроків, що охоплюють основи, шаблони проектування, фреймворки та розгортання AI агентів у продакшн.

**Основні технології:**
- Python 3.12+
- Jupyter Notebooks для інтерактивного навчання
- AI фреймворки: Microsoft Agent Framework (MAF)
- Azure AI сервіси: Microsoft Foundry, Microsoft Foundry Agent Service V2

**Архітектура:**
- Структура на основі уроків (папки 00-15+)
- Кожен урок містить: README документацію, приклади коду (Jupyter notebooks) та зображення
- Підтримка багатьох мов через автоматизовану систему перекладу
- Один старовий Python ноутбук на урок із використанням Microsoft Agent Framework

## Команди для налаштування

### Вимоги
- Python 3.12 або вище
- Підписка Azure (для Microsoft Foundry)
- Встановлені та автентифіковані Azure CLI (`az login`)

### Початкове налаштування

1. **Клонуйте або форкніть репозиторій:**
   ```bash
   gh repo fork microsoft/ai-agents-for-beginners --clone
   # АБО
   git clone https://github.com/microsoft/ai-agents-for-beginners.git
   cd ai-agents-for-beginners
   ```

2. **Створіть та активуйте віртуальне середовище Python:**
   ```bash
   python3 -m venv venv
   source venv/bin/activate  # У Windows: venv\Scripts\activate
   ```

3. **Встановіть залежності:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Налаштуйте змінні середовища:**
   ```bash
   cp .env.example .env
   # Редагуйте .env зі своїми API ключами та кінцевими точками
   ```

### Необхідні змінні середовища

Для **Microsoft Foundry** (обов’язково):
- `AZURE_AI_PROJECT_ENDPOINT` - кінцева точка проекту Microsoft Foundry
- `AZURE_AI_MODEL_DEPLOYMENT_NAME` - ім'я розгортання моделі (наприклад, gpt-4o)

Для **Azure AI Search** (Урок 05 - RAG):
- `AZURE_SEARCH_SERVICE_ENDPOINT` - кінцева точка Azure AI Search
- `AZURE_SEARCH_API_KEY` - ключ API Azure AI Search

Аутентифікація: Перед запуском ноутбуків виконайте `az login` (використовується `AzureCliCredential`).

## Робочий процес розробки

### Запуск Jupyter Notebooks

Кожен урок містить кілька Jupyter ноутбуків для різних фреймворків:

1. **Запустіть Jupyter:**
   ```bash
   jupyter notebook
   ```

2. **Перейдіть до папки уроку** (наприклад, `01-intro-to-ai-agents/code_samples/`)

3. **Відкрийте та виконайте ноутбуки:**

**Microsoft Agent Framework + Microsoft Foundry:**
- Потрібна підписка Azure
- Використовує `FoundryChatClient` для Agent Service V2 (агенти відображаються в порталі Foundry)
- Готовий до продакшну з вбудованою спостережливістю
- Шаблон імені файлу: `*-python-agent-framework.ipynb`

## Додаткові зауваження

### Часті проблеми

1. **Несумісність версії Python:**
   - Переконайтесь, що використовується Python 3.12+
   - Деякі пакети можуть не працювати зі старими версіями
   - Використовуйте `python3 -m venv` для явного визначення версії Python

2. **Змінні середовища:**
   - Завжди створюйте `.env` з `.env.example`
   - Не комітьте `.env` файл (він в `.gitignore`)
   - Авторизуйтеся за допомогою `az login` для безключової автентифікації Entra ID

3. **Конфлікти пакетів:**
   - Використовуйте свіжесоздане віртуальне середовище
   - Встановлюйте пакети з `requirements.txt`, а не окремо
   - Деякі ноутбуки можуть вимагати додаткові пакети, згадані в markdown клітинках

4. **Сервіси Azure:**
   - Сервіси Azure AI вимагають активної підписки
   - Деякі функції обмежені регіонально
   - Переконайтесь, що ваше розгортання Azure OpenAI підтримує Responses API

## Специфічний контекст проекту

### Підтримка багатьох мов

У цьому репозиторії використовується автоматизована система перекладу:
- Підтримка понад 50 мов
- Переклади зберігаються у папках `/translations/<lang-code>/`
- Робочий процес GitHub Actions керує оновленнями перекладів
- Джерельні файли англійською мовою у корені репозиторію

### Структура уроку

Кожен урок має сталу структуру:
1. Мініатюра відео з посиланням
2. Текстовий зміст уроку (README.md)
3. Приклади коду в кількох фреймворках
4. Цілі навчання та передумови
5. Додаткові ресурси для вивчення з посиланнями

### Іменування прикладів коду

Формат: `<номер-уроку>-python-agent-framework.ipynb`
- `01-python-agent-framework.ipynb` - Урок 1, MAF Python
- `14-sequential.ipynb` - Урок 14, MAF розширені шаблони

### Спеціальні папки

- `translated_images/` - Локалізовані зображення для перекладів
- `images/` - Оригінальні зображення для англійського вмісту
- `.devcontainer/` - Налаштування контейнера розробки VS Code
- `.github/` - Робочі процеси GitHub Actions та шаблони

### Залежності

Основні пакети з `requirements.txt`:
- `agent-framework` - Microsoft Agent Framework
- `a2a-sdk` - Підтримка протоколу Agent-to-Agent
- `azure-ai-inference`, `azure-ai-projects` - Azure AI сервіси
- `azure-identity` - Azure аутентифікація (AzureCliCredential)
- `azure-search-documents` - Інтеграція з Azure AI Search
- `mcp[cli]` - Підтримка Model Context Protocol
