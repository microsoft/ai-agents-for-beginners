# 🔄 Azure OpenAI（Responses API）を使用した基本的なエージェントワークフロー（.NET）

## 📋 ワークフローオーケストレーションチュートリアル

このノートブックでは、Microsoft Agent Framework for .NETとAzure OpenAI（Responses API）を使用して高度な<strong>エージェントワークフロー</strong>を構築する方法を説明します。AIエージェントが協力して複雑なタスクを完了するためのマルチステップのビジネスプロセスを、構造化されたオーケストレーションパターンで作成する方法を学びます。

## 🎯 学習目標

### 🏗️ <strong>ワークフローアーキテクチャの基本</strong>
- **Workflow Builder**：複雑なマルチステップのAIプロセスを設計・オーケストレーションする
- **Agent Coordination**：ワークフロー内で複数の専門エージェントを連携させる
- **Azure OpenAI（Responses API）**：ワークフローでAzure OpenAI Responses APIを活用する
- <strong>ビジュアルワークフロー設計</strong>：ワークフロー構造を作成・視覚化して理解を深める

### 🔄 <strong>プロセスオーケストレーションパターン</strong>
- <strong>順次処理</strong>：複数のエージェントタスクを論理的な順序で連鎖させる
- <strong>状態管理</strong>：ワークフローステージ間のコンテキストとデータフローを維持する
- <strong>エラー処理</strong>：堅牢なエラー回復とワークフローの回復力を実装する
- <strong>パフォーマンス最適化</strong>：企業規模の運用向けに効率的なワークフローを設計する

### 🏢 <strong>企業向けワークフローアプリケーション</strong>
- <strong>業務プロセス自動化</strong>：複雑な組織ワークフローを自動化する
- <strong>コンテンツ制作パイプライン</strong>：レビューと承認段階を含む編集ワークフロー
- <strong>カスタマーサービス自動化</strong>：多段階の顧客問い合わせ解決
- <strong>データ処理ワークフロー</strong>：AI支援の変換を伴うETLワークフロー

## ⚙️ 前提条件とセットアップ

### 📦 **必要なNuGetパッケージ**

このワークフローのデモでは、いくつかの主要な.NETパッケージを使用しています：

```xml
<!-- Core AI Framework -->
<PackageReference Include="Microsoft.Extensions.AI" Version="10.*" />

<!-- Azure OpenAI (Responses API) -->
<PackageReference Include="Azure.AI.OpenAI" Version="2.1.0" />
<PackageReference Include="Azure.Identity" Version="1.15.0" />

<!-- Agent Framework (Local Development) -->
<!-- Microsoft.Agents.AI.dll - Core agent abstractions -->
<!-- Microsoft.Agents.AI.OpenAI.dll - Azure OpenAI (Responses API) integration -->

<!-- Configuration and Environment -->
<PackageReference Include="DotNetEnv" Version="3.1.1" />
```

### 🔑 **Azure OpenAI設定**

**環境設定（.envファイル）：**
```env
AZURE_OPENAI_ENDPOINT=https://<your-resource>.openai.azure.com
AZURE_OPENAI_DEPLOYMENT=gpt-5-mini
```

**Azure OpenAIアクセス方法：**
1. AzureポータルでAzure OpenAIリソースを作成する
2. モデル（例：`gpt-5-mini`）をデプロイし、デプロイ名を控える
3. `az login`でサインインし、上記のように環境変数を設定する

### 🏗️ <strong>ワークフローアーキテクチャの概要</strong>

```mermaid
graph TD
    A[ワークフロービルダー] --> B[エージェントレジストリ]
    B --> C[ワークフロー実行エンジン]
    C --> D[Agent 1: コンテンツジェネレーター
    C --> E[Agent 2: コンテンツレビュアー 
    D --> F[ワークフロー結果]
    E --> F
    G[Azure OpenAI (Responses API)] --> D
    G --> E
```

**主要コンポーネント：**
- **WorkflowBuilder**：ワークフロー設計のための主要なオーケストレーションエンジン
- **AIAgent**：特定の能力を持つ個別の専門エージェント
- **Azure OpenAI Client**：Azure OpenAI Responses APIの統合
- **Execution Context**：ワークフローステージ間の状態とデータフローの管理

## 💻 コードの実行

完全な実装は `01.dotnet-agent-framework-workflow-ghmodel-basic.cs` にあります。このファイルでは以下を示しています：

1. <strong>環境設定</strong> - `.env`ファイルからAzure OpenAI設定を読み込む
2. **Azure OpenAIクライアント設定** - Azure OpenAI Responses APIを使用するクライアントの設定
3. <strong>エージェント作成</strong> - 専門エージェント（フロントデスクとコンシェルジュ）を定義する
4. <strong>ワークフロービルダー</strong> - 順次処理によるマルチエージェントワークフローの作成
5. <strong>ワークフロー実行</strong> - ストリーミング結果でワークフローを実行する

### 🚀 実例の実行

```bash
# スクリプトを実行可能にする（Unix/Linux/macOS）
chmod +x 01.dotnet-agent-framework-workflow-ghmodel-basic.cs

# ワークフローを実行する
./01.dotnet-agent-framework-workflow-ghmodel-basic.cs
```

Windowsの場合：
```powershell
dotnet run 01.dotnet-agent-framework-workflow-ghmodel-basic.cs
```

### 📝 期待される出力

ワークフローは以下を行います：
1. あなたの旅行先のリクエストを受け付けます（「パリに行きたいです」）
2. フロントデスクエージェントが初期の推奨を提供します
3. コンシェルジュエージェントが推奨を見直し、洗練します
4. 最終出力で会話ストリーム全体を表示します

### 🔧 カスタマイズ

ワークフローは次のようにカスタマイズできます：
- エージェントの指示を変更して動作を変える

- ユーザーメッセージを変更して異なるシナリオをテストする
- ワークフローのエッジを調整して異なる実行パターンを作る
