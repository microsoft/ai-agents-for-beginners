# 貢献する

このプロジェクトは貢献や提案を歓迎します。ほとんどの貢献には、あなたが貢献物を使用する権利を持ち、実際にそれを当方に許諾していることを宣言する貢献者ライセンス契約(CLA)に同意する必要があります。詳細については <https://cla.opensource.microsoft.com> をご覧ください。

プルリクエストを送信すると、CLAボットが自動的にCLAの提出が必要かどうかを判断し、プルリクエストに適切な表示をします。ボットの指示に従ってください。Microsoft CLAを使用しているリポジトリであれば、これを行うのは一度だけで済みます。

## 行動規範

このプロジェクトは [Microsoft Open Source Code of Conduct](https://opensource.microsoft.com/codeofconduct/) を採用しています。詳細については、[行動規範 FAQ](https://opensource.microsoft.com/codeofconduct/faq/) を参照するか、追加の質問やコメントは [opencode@microsoft.com](mailto:opencode@microsoft.com) にお問い合わせください。

## プルリクエストのガイドライン

- 各プルリクエストは1つの論理的な変更に集中させてください。
- 影響を受けるノートブックやコードサンプルは提出前にテストしてください。
- 例を追加または変更する場合は、関連するレッスンのドキュメントも更新してください。
- 編集は英語のソースコンテンツのみにしてください。翻訳は自動翻訳ワークフローで管理されます。
- 資格情報、`.env`ファイル、一時ファイル、生成された開発成果物をコミットしないでください。

## 編集の範囲とサードパーティ製品

このカリキュラムはMicrosoftの技術およびベンダーニュートラルなオープンスタンダードに重点を置いています。寄稿は明確な教育的目的に役立つものでなければならず、主にサードパーティの商用製品、ホスティングサービス、モデルルーター、SDK、MCPサーバー、その他のベンダー固有の提供物を紹介または宣伝することを目的としてはなりません。

オープンスタンダードや相互運用性のシナリオを説明するために必要で、中立的に提示されており、ベンダーの製品やホストされているエンドポイントに焦点を当てていない場合に限り、オープンソースソフトウェアやサードパーティの依存関係を参照することがあります。提案される寄稿にベンダー固有の製品やサービスが含まれる場合は、プルリクエストを提出する前にイシューを開き、メンテナの承認を得てください。

寄稿者は、自身の寄稿で言及されている製品やサービスに関して関連する雇用関係、所有関係、スポンサーシップ、その他の関連性について開示しなければなりません。裏付けのない価格、性能、セキュリティ、プライバシー、または比較に関する主張を含めないでください。実行可能な例はデフォルトで学習者のデータを送信したり、外部のサードパーティサービスを通じて公開アクションを実行したりしてはなりません。
