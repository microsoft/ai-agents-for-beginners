## Nama Acara: API Multi-Ejen dengan LangGraph dan Azure Cosmos DB

## Penerangan

Kebangkitan aplikasi AI multi-ejen sedang mengubah cara kita membina sistem pintar - tetapi bagaimana anda mereka bentuknya untuk skalabiliti dan prestasi dunia sebenar? Dalam sesi ini, kami akan menyelami aplikasi multi-ejen gred produksi yang dibina dengan LangGraph untuk orkestrasikan ejen, FastAPI untuk lapisan API, dan Azure Cosmos DB sebagai tulang belakang pengurusan keadaan, penyimpanan vektor, dan data transaksi.

Melalui walkthrough kod yang terperinci, anda akan lihat cara mereka bentuk dan melaksanakan aliran kerja pemandu ejen yang mengintegrasikan dengan lancar retrieval-augmented generation (RAG), pemeliharaan memori, dan peralihan keadaan dinamik. Kami akan membicarakan:

Kerjasama ejen dengan LangGraph untuk penalaran berstruktur
Penyimpanan sejarah sembang masa nyata menggunakan Azure Cosmos DB - pangkalan data yang sama yang menggerakkan sejarah sembang dalam ChatGPT, aplikasi ejen AI paling pesat berkembang dalam sejarah
Carian vektor untuk pengambilan pengetahuan dengan sokongan embeddings asli Cosmos DB
Keupayaan async FastAPI untuk mengekalkan interaksi yang responsif dan skalabel
Menjelang akhir sesi ini, anda akan mempunyai pelan jelas untuk membina dan menyebarkan aplikasi multi-ejen asli awan yang skalabel yang memanfaatkan kekuatan AI moden dan infrastruktur awan. Sama ada anda jurutera AI, arkitek awan, atau pembangun Python, ceramah ini akan melengkapkan anda dengan wawasan praktikal dan corak teruji untuk membina generasi aplikasi AI yang seterusnya
