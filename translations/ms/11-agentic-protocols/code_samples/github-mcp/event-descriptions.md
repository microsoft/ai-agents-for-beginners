## Nama Acara: API Multi-Agen dengan LangGraph dan Azure Cosmos DB

## Penerangan

Kebangkitan aplikasi multi-agen AI sedang mengubah cara kita membina sistem pintar - tetapi bagaimana anda mereka bentuknya untuk skala dan prestasi dunia sebenar? Dalam sesi ini, kami akan menyelami aplikasi multi-agen gred produksi dibina dengan LangGraph untuk orkestrasi agen, FastAPI untuk lapisan API, dan Azure Cosmos DB sebagai tulang belakang untuk pengurusan keadaan, penyimpanan vektor, dan data transaksi.

Melalui tinjauan kod terperinci, anda akan melihat cara mereka bentuk dan melaksanakan aliran kerja dipacu agen yang mengintegrasikan dengan lancar penjanaan berpemulihan (RAG), ketekalan memori, dan peralihan keadaan dinamik. Kami akan merangkumi:

Kerjasama agen dengan LangGraph untuk pemikiran berstruktur
Penyimpanan sejarah sembang masa nyata menggunakan Azure Cosmos DB - pangkalan data yang sama yang menyokong sejarah sembang dalam ChatGPT, aplikasi agen AI dengan pertumbuhan terpantas dalam sejarah
Carian vektor untuk pengambilan pengetahuan dengan sokongan penanaman asli Cosmos DB
Keupayaan async FastAPI untuk memastikan interaksi responsif dan berskala
Pada akhir sesi ini, anda akan mempunyai cetak biru jelas untuk membina dan menyebarkan aplikasi multi-agen asli awan yang berskala yang memanfaatkan kuasa AI moden dan infrastruktur awan. Sama ada anda jurutera AI, arkitek awan, atau pembangun Python, ceramah ini akan melengkapkan anda dengan wawasan praktikal dan corak yang telah terbukti untuk membina generasi berikut aplikasi berkuasa AI.

## Nama Acara: Prompting adalah Skrip Baru: Kenali GenAIScript

## Penerangan

jQuery pernah memudahkan pembangunan web dengan mengabstrakkan kerumitan, membolehkan pembangun fokus pada pembinaan dan bukan berjuang dengan keanehan pelayar. Hari ini, pembangunan AI menghadapi cabaran serupa. Corak baru sentiasa muncul dan mengekori boleh menjadi luar biasa, terutama kerana alat AI—terutamanya agenik—semakin berkuasa dan kompleks. Bagaimana jika anda boleh memanfaatkan keupayaan AI terkini untuk mengautomasikan tugas menggunakan abstraksi JavaScript mudah dan biasa? Dalam ceramah ini, kami akan meneroka bagaimana GenAIScript menjadikan agen automasi AI semudah menulis JavaScript, membantu anda memudahkan kerja berulang tanpa memerlukan kepakaran AI mendalam.
