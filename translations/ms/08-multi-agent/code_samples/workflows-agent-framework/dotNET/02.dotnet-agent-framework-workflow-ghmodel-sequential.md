# ⏩ Aliran Kerja Agen Berturutan dengan Azure OpenAI (Responses API) (.NET)

## 📋 Tutorial Pemprosesan Berturutan Lanjutan

Notebook ini memperagakan **corak aliran kerja berturutan** menggunakan Microsoft Agent Framework untuk .NET dan Azure OpenAI (Responses API). Anda akan belajar bagaimana membina rangkaian pemprosesan langkah demi langkah yang canggih di mana agen melaksanakan mengikut susunan tertentu, dengan setiap peringkat membina berdasarkan keputusan peringkat sebelumnya.

## 🎯 Objektif Pembelajaran

### 🔄 **Senibina Pemprosesan Berturutan**
- **Reka Bentuk Aliran Kerja Linear**: Cipta rangkaian pemprosesan langkah demi langkah dengan kebergantungan yang jelas
- **Pengurusan Keadaan**: Mengekalkan konteks dan aliran data merentasi peringkat aliran kerja berturutan
- **Azure OpenAI (Responses API)**: Manfaatkan model Azure OpenAI dalam aliran kerja .NET berbilang peringkat
- **Corak Rangkaian Perusahaan**: Bina sistem pemprosesan berturutan sedia produksi

### 🏗️ **Corak Berturutan Lanjutan**
- **Pemprosesan Pintu Peringkat**: Laksanakan titik semakan pengesahan antara peringkat aliran kerja
- **Pemeliharaan Konteks**: Mengekalkan keadaan dan pengetahuan terkumpul merentasi semua peringkat
- **Penghantaran Ralat**: Tangani kegagalan dengan teratur dalam rantaian pemprosesan berturutan
- **Pengoptimuman Prestasi**: Pelaksanaan berturutan cekap dengan overhead minimal

### 🏢 **Aplikasi Berturutan Perusahaan**
- **Rangkaian Pemprosesan Dokumen**: Analisis dokumen berbilang peringkat, transformasi, dan pengesahan
- **Aliran Kerja Jaminan Kualiti**: Semakan berturutan, pengesahan, dan proses kelulusan
- **Rangkaian Penghasilan Kandungan**: Penyelidikan → Penulisan → Penyuntingan → Semakan → Penerbitan
- **Automasi Proses Perniagaan**: Aliran kerja perniagaan berbilang langkah dengan kebergantungan peringkat yang jelas

## 💻 Menjalankan Kod

Pelaksanaan lengkap tersedia dalam `02.dotnet-agent-framework-workflow-ghmodel-sequential.cs`. Fail ini memperagakan **aliran kerja analisis perabot tiga peringkat**:

1. **Peringkat 1 - Agen Jualan**: Menganalisis imej perabot dan memberikan cadangan pembelian
2. **Peringkat 2 - Agen Harga**: Memberikan pecahan harga terperinci dan pilihan bajet
3. **Peringkat 3 - Agen Sebut Harga**: Menjana dokumen sebut harga profesional dalam format Markdown

### 🏗️ **Senibina Aliran Kerja**

```
Image Input → Sales Analysis → Price Estimation → Quote Generation → Final Output
```

Setiap agen:
- Menerima output dari peringkat sebelumnya sebagai konteks
- Membina atas analisis sebelumnya dengan kepakaran khusus
- Mengekalkan kesinambungan aliran kerja melalui pengurusan keadaan

### 🚀 Menjalankan Contoh

**Prasyarat:**
- Letakkan imej perabot di `../imgs/home.png` (atau kemaskini pemboleh ubah `imgPath`)
- Konfigurasi fail `.env` anda dengan titik akhir dan penyebaran Azure OpenAI, kemudian log masuk dengan `az login`

```bash
# Jadikan skrip boleh dijalankan (Unix/Linux/macOS)
chmod +x 02.dotnet-agent-framework-workflow-ghmodel-sequential.cs

# Jalankan aliran kerja secara berurutan
./02.dotnet-agent-framework-workflow-ghmodel-sequential.cs
```

Atau di Windows:
```powershell
dotnet run 02.dotnet-agent-framework-workflow-ghmodel-sequential.cs
```

### 📝 Output Dijangka

Aliran kerja akan:
1. **Agen Jualan**: Kenal pasti item perabot dari imej dan berikan cadangan
2. **Agen Harga**: Tambah analisis harga terperinci dengan kategori bajet dan cadangan pembelian
3. **Agen Sebut Harga**: Jana dokumen sebut harga berformat dengan semua maklumat disintesis

Output akhir akan menjadi sebut harga perabot yang menyeluruh dan profesional berdasarkan analisis imej.

### 🔍 Memahami Aliran Keadaan

Setiap agen dalam urutan menerima:
- **Input Asal**: Mesej pengguna awal (imej + teks)
- **Output Agen Sebelumnya**: Semua respons agen sebelumnya dalam sejarah perbualan
- **Konteks Terkumpul**: Keadaan lengkap yang dikekalkan sepanjang aliran kerja

Ini membolehkan pemprosesan pelbagai peringkat yang canggih di mana setiap agen membina berdasarkan konteks menyeluruh dari semua peringkat sebelumnya.
