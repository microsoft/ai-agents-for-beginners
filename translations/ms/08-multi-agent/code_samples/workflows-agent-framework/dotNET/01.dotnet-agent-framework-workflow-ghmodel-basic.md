# 🔄 Aliran Kerja Ejen Asas dengan Azure OpenAI (API Respons) (.NET)

## 📋 Tutorial Orkestrasi Aliran Kerja

Notebook ini menunjukkan cara membina **aliran kerja ejen** yang canggih menggunakan Microsoft Agent Framework untuk .NET dan Azure OpenAI (API Respons). Anda akan belajar mencipta proses perniagaan berbilang langkah di mana ejen AI bekerjasama untuk menyelesaikan tugasan kompleks melalui corak orkestrasi berstruktur.

## 🎯 Objektif Pembelajaran

### 🏗️ **Asas Seni Bina Aliran Kerja**
- **Pembina Aliran Kerja**: Reka dan orkestrasi proses AI berbilang langkah yang kompleks
- **Penyelarasan Ejen**: Menyelaraskan pelbagai ejen pakar dalam aliran kerja
- **Azure OpenAI (API Respons)**: Memanfaatkan Azure OpenAI Responses API dalam aliran kerja
- **Reka Bentuk Aliran Kerja Visual**: Mencipta dan memvisualisasikan struktur aliran kerja untuk kefahaman yang lebih baik

### 🔄 **Corak Orkestrasi Proses**
- **Pemprosesan Bersiri**: Mengikat beberapa tugasan ejen dalam urutan logik
- **Pengurusan Keadaan**: Mengekalkan konteks dan aliran data merentasi peringkat aliran kerja
- **Pengendalian Ralat**: Melaksanakan pemulihan ralat yang mantap dan ketahanan aliran kerja
- **Pengoptimuman Prestasi**: Mereka bentuk aliran kerja cekap untuk operasi skala perusahaan

### 🏢 **Aplikasi Aliran Kerja Perusahaan**
- **Automasi Proses Perniagaan**: Mengautomasikan aliran kerja organisasi yang kompleks
- **Saluran Penghasilan Kandungan**: Aliran kerja editorial dengan peringkat semakan dan kelulusan
- **Automasi Perkhidmatan Pelanggan**: Penyelesaian pertanyaan pelanggan berbilang langkah
- **Aliran Kerja Pemprosesan Data**: Aliran kerja ETL dengan transformasi dipacu AI

```xml
<!-- Agent Framework (Local Development) -->
<!-- Microsoft.Agents.AI.dll - Core agent abstractions -->
<!-- Microsoft.Agents.AI.OpenAI.dll - Azure OpenAI (Responses API) integration -->

<!-- Configuration and Environment -->
<PackageReference Include="DotNetEnv" Version="3.1.1" />
```

### 🔑 **Konfigurasi Azure OpenAI**

**Persediaan Persekitaran (fail .env):**
```env
AZURE_OPENAI_ENDPOINT=https://<your-resource>.openai.azure.com
AZURE_OPENAI_DEPLOYMENT=gpt-5-mini
```

**Akses Azure OpenAI:**
1. Cipta sumber Azure OpenAI di portal Azure
2. Lancarkan model (contoh, `gpt-5-mini`) dan ambil nama pelancaran
3. Log masuk dengan `az login` dan konfigurasikan pemboleh ubah persekitaran seperti yang ditunjukkan di atas

## 💻 Menjalankan Kod

Pelaksanaan lengkap tersedia dalam `01.dotnet-agent-framework-workflow-ghmodel-basic.cs`. Fail ini menunjukkan:

1. **Konfigurasi Persekitaran** - Memuat konfigurasi Azure OpenAI dari fail `.env`
2. **Persediaan Klien Azure OpenAI** - Mengkonfigurasi klien untuk menggunakan Azure OpenAI Responses API
3. **Penciptaan Ejen** - Mendefinisikan ejen khusus (Kaunter Hadapan dan Concierge)
4. **Pembina Aliran Kerja** - Mencipta aliran kerja berbilang ejen dengan pemprosesan bersiri
5. **Pelaksanaan Aliran Kerja** - Menjalankan aliran kerja dengan keputusan penstriman

### 🚀 Menjalankan Contoh

```bash
# Jadikan skrip boleh dilaksanakan (Unix/Linux/macOS)
chmod +x 01.dotnet-agent-framework-workflow-ghmodel-basic.cs

# Jalankan aliran kerja
./01.dotnet-agent-framework-workflow-ghmodel-basic.cs
```

Atau di Windows:
```powershell
dotnet run 01.dotnet-agent-framework-workflow-ghmodel-basic.cs
```

### 📝 Jangkaan Output

Aliran kerja akan:
1. Menerima permintaan destinasi perjalanan anda ("Saya ingin pergi ke Paris")
2. Ejen Kaunter Hadapan memberikan cadangan awal
3. Ejen Concierge menyemak dan memperbaiki cadangan tersebut
4. Output akhir memaparkan aliran perbualan lengkap
