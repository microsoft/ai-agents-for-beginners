# 🔄 Aliran Kerja Ejen Asas dengan Azure OpenAI (Responses API) (.NET)

## 📋 Tutorial Orkestrasi Aliran Kerja

Buku nota ini menunjukkan cara membina **aliran kerja ejen** yang canggih menggunakan Rangka Kerja Ejen Microsoft untuk .NET dan Azure OpenAI (Responses API). Anda akan belajar mencipta proses perniagaan berbilang langkah di mana ejen AI bekerjasama untuk melaksanakan tugasan kompleks melalui corak orkestrasi berstruktur.

## 🎯 Objektif Pembelajaran

### 🏗️ **Asas Seni Bina Aliran Kerja**
- **Pembina Aliran Kerja**: Reka bentuk dan orkestrasi proses AI berbilang langkah yang kompleks
- **Penyelarasan Ejen**: Selaraskan pelbagai ejen khusus dalam aliran kerja
- **Azure OpenAI (Responses API)**: Manfaatkan Azure OpenAI Responses API dalam aliran kerja
- **Reka Bentuk Aliran Kerja Visual**: Cipta dan visualisasikan struktur aliran kerja untuk pemahaman lebih baik

### 🔄 **Corak Orkestrasi Proses**
- **Pemusatan Berurutan**: Rangkai pelbagai tugasan ejen dalam urutan logik
- **Pengurusan Keadaan**: Kekalkan konteks dan aliran data di seluruh peringkat aliran kerja
- **Pengendalian Ralat**: Laksanakan pemulihan ralat yang kukuh dan ketahanan aliran kerja
- **Pengoptimuman Prestasi**: Reka aliran kerja cekap untuk operasi skala perusahaan

### 🏢 **Aplikasi Aliran Kerja Perusahaan**
- **Automasi Proses Perniagaan**: Automasi aliran kerja organisasi yang kompleks
- **Saluran Pengeluaran Kandungan**: Aliran kerja editorial dengan tahap semakan dan kelulusan
- **Automasi Perkhidmatan Pelanggan**: Penyelesaian pertanyaan pelanggan berbilang langkah
- **Aliran Kerja Pemprosesan Data**: Aliran kerja ETL dengan transformasi berkuasa AI

## ⚙️ Prasyarat & Persediaan

### 📦 **Pakej NuGet Diperlukan**

Demonstrasi aliran kerja ini menggunakan beberapa pakej .NET utama:

```xml
<!-- Core AI Framework -->
<PackageReference Include="Microsoft.Extensions.AI" Version="9.9.0" />

<!-- Azure OpenAI (Responses API) -->
<PackageReference Include="Azure.AI.OpenAI" Version="2.1.0" />
<PackageReference Include="Azure.Identity" Version="1.13.1" />

<!-- Agent Framework (Local Development) -->
<!-- Microsoft.Agents.AI.dll - Core agent abstractions -->
<!-- Microsoft.Agents.AI.OpenAI.dll - Azure OpenAI (Responses API) integration -->

<!-- Configuration and Environment -->
<PackageReference Include="DotNetEnv" Version="3.1.1" />
```

### 🔑 **Konfigurasi Azure OpenAI**

**Persediaan Persekitaran (fail .env):**
```env
AZURE_OPENAI_ENDPOINT=https://<your-resource>.openai.azure.com
AZURE_OPENAI_DEPLOYMENT=gpt-4o-mini
```

**Akses Azure OpenAI:**
1. Cipta sumber Azure OpenAI dalam portal Azure
2. Sebarkan model (contohnya, `gpt-4o-mini`) dan catat nama penyebaran
3. Log masuk dengan `az login` dan konfigurasikan pemboleh ubah persekitaran seperti yang ditunjukkan di atas

### 🏗️ **Gambaran Keseluruhan Seni Bina Aliran Kerja**

```mermaid
graph TD
    A[Pembina Aliran Kerja] --> B[Daftar Ejen]
    B --> C[Enjin Pelaksanaan Aliran Kerja]

    D --> F[Keputusan Aliran Kerja]
    E --> F
    G[Azure OpenAI (API Respons)] --> D
    G --> E
```

**Komponen Utama:**
- **WorkflowBuilder**: Enjin orkestrasi utama untuk mereka bentuk aliran kerja
- **AIAgent**: Ejen khusus individu dengan keupayaan tertentu
- **Azure OpenAI Client**: Integrasi Azure OpenAI Responses API
- **Execution Context**: Mengurus keadaan dan aliran data antara peringkat aliran kerja

## 💻 Menjalankan Kod

Pelaksanaan lengkap tersedia dalam `01.dotnet-agent-framework-workflow-ghmodel-basic.cs`. Fail ini menunjukkan:

1. **Konfigurasi Persekitaran** - Memuatkan konfigurasi Azure OpenAI dari fail `.env`
2. **Persediaan Klien Azure OpenAI** - Mengkonfigurasi klien untuk menggunakan Azure OpenAI Responses API
3. **Kewujudan Ejen** - Mendefinisikan ejen khusus (Kaunter Hadapan dan Concierge)
4. **Pembina Aliran Kerja** - Mencipta aliran kerja pelbagai ejen dengan pemprosesan berurutan
5. **Pelaksanaan Aliran Kerja** - Menjalankan aliran kerja dengan hasil penstriman

### 🚀 Menjalankan Contoh

```bash
# Jadikan skrip boleh dijalankan (Unix/Linux/macOS)
chmod +x 01.dotnet-agent-framework-workflow-ghmodel-basic.cs

# Jalankan aliran kerja
./01.dotnet-agent-framework-workflow-ghmodel-basic.cs
```

Atau di Windows:
```powershell
dotnet run 01.dotnet-agent-framework-workflow-ghmodel-basic.cs
```

### 📝 Output Dijangka

Aliran kerja akan:
1. Menerima permintaan destinasi perjalanan anda ("Saya ingin pergi ke Paris")
2. Ejen Kaunter Hadapan memberikan cadangan awal
3. Ejen Concierge menyemak dan memperhalusi cadangan
4. Output akhir memaparkan aliran perbualan lengkap
