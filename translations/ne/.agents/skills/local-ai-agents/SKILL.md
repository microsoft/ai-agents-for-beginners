# Foundry Local र Qwen सँग स्थानीय AI एजेन्टहरू सिर्जना गर्दै

> [पाठ १७ – स्थानीय AI एजेन्टहरू सिर्जना गर्दै] (../../../17-creating-local-ai-agents/README.md) को लागि सहायक कौशल।
> विद्यार्थीलाई एउटा एजेन्ट निर्माण गर्न मद्दत गर्न प्रयोग गर्नुहोस् जसले तर्क गर्छ, उपकरणहरू कल गर्दछ, र
> पूर्ण रूपमा आफ्नै मेसिनमा कागजात खोज्छ — कुनै क्लाउड इन्फ्रेन्स छैन। हरेक सिफारिश
> पाठ सामग्री र चल्ने योग्य नोटबुकमा आधारित हुनु पर्छ।

## ट्रिगरहरू

जब विद्यार्थी चाहन्छ तब यो कौशल सक्रिय गर्नुहोस्:
- गोपनीयता, लागत, वा अफलाइन कारणहरूका लागि एजेन्ट **पूर्ण रूपमा डिभाइसमा** चलाउन।
- **Foundry Local** सँग मोडेल स्थानीय रूपमा सेवा गर्न र OpenAI-संग अनुकूल अन्तबिन्दुसँग जडान गर्न।
- भरपर्दो स्थानीय उपकरण कलहरू चलाउन **Qwen फङ्सन-कलिंग** मोडेल प्रयोग गर्न।
- **स्थानीय RAG** (Chroma) वा **स्थानीय MCP सर्भर** थप्न।
- **हाइब्रिड** स्थानीय/क्लाउड मार्ग निर्देशन रणनीति डिजाइन गर्न।

## मुख्य मानसिक मोडेल

एउटा SLM गोपनीयता, लागत, र अफलाइन सञ्चालनका लागि व्यापकताको सट्टा कारोबार गर्छ। विजेता
रणनीति: **SLM लाई समन्वय गर्न दिनुहोस् र उपकरणहरूलाई भारी भार उठाउन दिनुहोस्।** मोडेललाई
कोडबेस थाहा हुन आवश्यक छैन — यसले कहिले `read_file` र `search_docs` कल गर्ने थाहा पाउनुपर्छ। त्यो SLM को बलमा खेल्छ (सीमित निर्णयहरू
जस्तै उपकरण चयन) र यसको कमजोरीबाट टाढा राख्छ (व्यापक ज्ञान, लामो बहु-हप तर्क)।



## किन यी विशेष भागहरू

- **Foundry Local** ले **OpenAI-संग अनुकूल HTTP अन्तबिन्दु** खोल्दछ, त्यसैले क्लाउड एजेन्ट कोड केवल `base_url` परिवर्तन गरेर स्थानान्तरण हुन्छ (र स्थानीय प्लेसहोल्डर API कुञ्जी प्रयोग गरेर)। यो मेसिनको लागि सबैभन्दा राम्रो बिल्ड (CPU/GPU/NPU) पनि स्वचालित रूपमा चयन गर्दछ।
- **Qwen** मोडेलहरू फङ्सन कलिंगका लागि तालिम दिइएका छन् र राम्रो फर्मको उपकरण कलहरू लगातार निकाल्दछन् — यसले स्थानीय *च्याट* मोडेललाई स्थानीय *एजेन्ट* मा परिवर्तन गर्दछ।
- **Chroma** इन-प्रोसेस चल्छ र भेक्टरहरू डिस्कमा भण्डारण गर्छ, त्यसैले सम्पूर्ण RAG पाइपलाइन (एम्बेड → भण्डार → पुनः प्राप्त → तर्क) स्थानीय नै रहन्छ।
- **MCP** ट्रान्सपोर्ट हो, क्लाउड सेवा होइन: एक MCP सर्भर स्थानीय रूपमा `stdio` मा चलाउन सकिन्छ।

## सेटअप आवश्यकताहरू

```bash
foundry model run qwen2.5-7b-instruct
foundry service status
```

```python
from foundry_local import FoundryLocalManager
from openai import OpenAI

manager = FoundryLocalManager("qwen2.5-7b-instruct")
client = OpenAI(base_url=manager.endpoint, api_key=manager.api_key)  # local placeholder
```

~8 GB RAM यथार्थपरक न्यूनतम हो; GPU/NPU सहयोगी हुन्छ तर आवश्यक छैन।

## पुन: सिर्जना गर्न प्रमुख ढाँचाहरू

विद्यार्थीलाई नोटबुकमा मार्गनिर्देशन गर्नुहोस्
[`17-local-agent-foundry-local.ipynb`](../../../17-creating-local-ai-agents/code_samples/17-local-agent-foundry-local.ipynb):

- **स्यान्डबक्स गरिएको उपकरणहरू**: प्रत्येक फाइल उपकरणले पथहरू समाधान गर्दछ र एक परियोजना मूल बाहेक केही पनि अस्वीकार गर्दछ — स्थानीय रूपमा समेत, उपकरण प्रयोगकर्ताको अनुमतिहरूमा चल्छ।
- **उपकरण-कलिङ लूप**: उपकरणहरू OpenAI उपकरण स्किमासँग दर्ता गर्नुहोस्, अनुरोध गरिएका उपकरणहरू स्थानीय रूपमा चलाउनुहोस्, नतिजाहरू फिर्ता खुवाउनुहोस्, अन्तिम उत्तर नआएसम्म दोहोर्याउनुहोस्।
- **स्थानीय RAG**: कागजातहरूलाई Chroma सङ्ग्रहमा अपसर्ट गर्नुहोस्; `search_docs` शीर्ष-k टुक्राहरू फिर्ता गर्दछ।
- **स्थानीय MCP**: `stdio` मार्फत स्थानीय सर्भरसँग जडान गर्नुहोस्; यसलाई परियोजना निर्देशिकामा सीमित गर्नुहोस् र यसको आउटपुटहरूको मान्यता गर्नुहोस्।

## हाइब्रिड मार्गनिर्देश (स्थानीय मोडेल मध्ये एकको रूपमा)

| स्थिति | कहाँ चल्छ |
|-----------|---------------|
| संवेदनशील डाटा / अफलाइन | स्थानीय SLM |
| सरल, सीमित कार्य | स्थानीय SLM (सस्तो, छिटो) |
| गैर-संवेदनशील डेटामा कठिन बहु-हप तर्क | क्लाउड मोडेल |
| क्लाउड आउटेज | स्थानीय SLM (शिष्टतापूर्वक ह्रास) |

यो पाठ १६ को मोडेल-राउटिंग विचारलाई प्रतिबिम्बित गर्छ, कार्यस्थानलाई एउटा मार्गको रूपमा मान्दै। 
त्यस्ता डिजाइनहरूलाई प्राथमिकता दिनुहोस् जसले स्थानीयमा फर्कन्छन् ताकि एजेन्ट गुणस्तरमा कम हुन्छ, 
सिधै असफल नहुने।

## सहायक उपकरणहरूको लागि सुरक्षा उपायहरू

- हरेक फाइल/उपकरणको अपरेशनलाई स्याण्डबक्स गरिएको प्रोजेक्ट डाइरेक्टरीमा मात्र सीमित राख्नुहोस्।
- सिक्ने व्यक्तिको स्पष्ट लक्ष्य गोपनीयता/अफलाइन छ भने, कोड वा डाटालाई क्लाउडमा नपठाउनुहोस् — सम्पूर्ण प्रक्रिया स्थानीय राख्नुहोस्।
- SLM गुणस्तरका लागि यथार्थपरक अपेक्षा सेट गर्नुहोस्; मोडेलको सम्झिएको ज्ञानभन्दा औजारहरू र RAG मा भर पर्नुहोस्।
- पाठ १७ मा कुनै पनि फाउन्ड्री रिस्पोन्सेस इन्डपोइन्ट छैन, त्यसैले क्लाउड स्मोक-टेस्ट क्रियाकलाप लागु हुँदैन — नोटबुक स्थानीय रूपमा चलाएर मान्य गर्नुहोस्।
