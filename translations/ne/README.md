## 🌱 सुरु गर्ने तरिका

यस कोर्समा AI एजेन्टहरू निर्माण गर्ने आधारभूत कुरा समेटिएको छ। प्रत्येक पाठले आफ्नो विषय समेट्छ, त्यसैले जुनसुकै ठाउँबाट सुरु गर्न सक्नुहुन्छ!

यो कोर्सका लागि बहुभाषी समर्थन छ। हाम्रो [यहाँ उपलब्ध भाषाहरू](#-multi-language-support)मा जानुहोस्।

यदि तपाईं पहिलो पटक Generative AI मोडेलहरू प्रयोग गर्दै हुनुहुन्छ भने, हाम्रोगो [Generative AI For Beginners](https://aka.ms/genai-beginners) कोर्स हेर्नुहोस्, जसमा GenAI प्रयोग गरेर निर्माण गर्ने २१ पाठहरू छन्।

[यो रिपो लाई स्टार (🌟) गर्नुहोस्](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst) र [यो रिपोबाट फोर्क गर्नुहोस्](https://github.com/microsoft/ai-agents-for-beginners/fork) ताकि तपाईंले कोड चलाउन सक्नुहुनेछ।

### अन्य सिक्नेहरूलाई भेट्नुहोस्, आफ्नो प्रश्नहरूको उत्तर पाउनुहोस्

यदि तपाईंलाई कुनै समस्या परे वा AI एजेन्टहरू निर्माण गर्न सम्बन्धि कुनै प्रश्न छ भने, हाम्रो समर्पित डिस्कोर्ड च्यानल [Microsoft Foundry Discord](https://aka.ms/ai-agents/discord) मा सामेल हुनुस्।

### तपाईंलाई के चाहिन्छ 

यस कोर्सका प्रत्येक पाठमा कोड उदाहरणहरू छन्, जुन code_samples फोल्डरमा पाउन सकिन्छ। तपाईं आफ्नो प्रतिलिपि बनाउन यो रिपो [फोर्क गर्न सक्नुहुन्छ](https://github.com/microsoft/ai-agents-for-beginners/fork)।

यी अभ्यासका कोड उदाहरणहरूले Microsoft Agent Framework सँग Microsoft Foundry Agent Service V2 प्रयोग गर्छन्:

- [Microsoft Foundry](https://aka.ms/ai-agents-beginners/ai-foundry) - Azure खाता आवश्यक

यस कोर्सले निम्न Microsoft का AI एजेन्ट फ्रेमवर्कहरू र सेवाहरू प्रयोग गर्छ:

- [Microsoft Agent Framework (MAF)](https://learn.microsoft.com/agent-framework/overview/)
- [Microsoft Foundry Agent Service V2](https://aka.ms/ai-agents-beginners/ai-agent-service)

केही कोड उदाहरणहरूले वैकल्पिक OpenAI-समर्थित प्रदायकहरू जस्तै [MiniMax](https://platform.minimaxi.com/), जसले ठूलो-कन्टेक्स्ट मोडेलहरू (सम्म 204K टोकनहरू) प्रस्ताव गर्छ, समर्थन गर्छ। कन्फिगरेसन विवरणहरूका लागि [Course Setup](./00-course-setup/README.md) हेर्नुहोस्।

यस कोर्सको कोड चलाउन थप जानकारीका लागि [Course Setup](./00-course-setup/README.md) मा जानुहोस्।
