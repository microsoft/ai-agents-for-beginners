## 🌱 सुरु गर्ने तरिका

यस कोर्समा AI एजेन्टहरू बनाउनका आधारभूत कुरा समेटिएको छ। प्रत्येक पाठले आफ्नो विषय समेट्छ त्यसैले जहाँबाट सुरू गर्न मन लाग्छ त्यहाँबाट सुरू गर्नुहोस्!

यस कोर्सलाई बहुभाषी समर्थन उपलब्ध छ। हाम्रो [यहाँ उपलब्ध भाषाहरू](#-multi-language-support) मा जानुहोस्।

यदि तपाइँलाई जेनेरेटिभ AI मोडलहरूसँग पहिलो पटक काम गर्दै हुनुहुन्छ भने, हाम्रो [जेनेरेटिभ AI प्रारम्भकर्ताका लागि](https://aka.ms/genai-beginners) कोर्स हेर्नुहोस्, जसमा जनरेटिभ AI संग निर्माणका लागि २१ पाठहरु छन्।

[यस रिपोमा स्टार (🌟) दिन नबिर्सनुहोस्](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst) र [यो रिपो फोर्क गर्न](https://github.com/microsoft/ai-agents-for-beginners/fork) कोड चलाउन।

### अन्य सिक्नेहरूलाई भेट्नुहोस्, आफ्नो प्रश्नहरूको उत्तर पाउनुहोस्

यदि तपाईं अल्झनुहुन्छ वा AI एजेन्टहरू निर्माण सम्बन्धी कुनै प्रश्न छ भने, [Microsoft Foundry Discord](https://aka.ms/ai-agents/discord) मा हाम्रो समर्पित डिस्कोर्ड च्यानलमा सहभागी हुनुहोस्।

### तपाईंलाई के चाहिन्छ

यस कोर्सका प्रत्येक पाठमा कोड उदाहरणहरू छन्, जुन code_samples फोल्डरमा फेला पार्न सकिन्छ। तपाईँ [यो रिपो फोर्क](https://github.com/microsoft/ai-agents-for-beginners/fork) गरेर आफ्नो प्रतिलिपि बनाउन सक्नुहुन्छ।

यी अभ्यासका कोड उदाहरणहरू Microsoft Agent Framework र Microsoft Foundry Agent Service V2 प्रयोग गर्छन्:

- [Microsoft Foundry](https://aka.ms/ai-agents-beginners/ai-foundry) - Azure खाता आवश्यक

यस कोर्सले Microsoft का निम्न AI एजेन्ट फ्रेमवर्कहरू र सेवा प्रयोग गर्दछ:

- [Microsoft Agent Framework (MAF)](https://learn.microsoft.com/agent-framework/overview/)
- [Microsoft Foundry Agent Service V2](https://aka.ms/ai-agents-beginners/ai-agent-service)

केही कोड उदाहरणहरू वैकल्पिक OpenAI-अनुकूल प्रदायकहरू जस्तै [MiniMax](https://platform.minimaxi.com/) पनि समर्थन गर्छन्, जसले ठूलो-सन्दर्भ मोडलहरू (२०४K टोकनसम्म) प्रस्ताव गर्छ। कन्फिगरेसन विवरणहरूका लागि [कोर्स सेटअप](./00-course-setup/README.md) हेर्नुहोस्।

यस कोर्सको कोड चलाउनका लागि थप जानकारीका लागि [कोर्स सेटअप](./00-course-setup/README.md) मा जानुहोस्।
