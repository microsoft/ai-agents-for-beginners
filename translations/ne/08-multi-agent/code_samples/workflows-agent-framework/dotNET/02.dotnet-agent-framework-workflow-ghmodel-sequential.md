# ⏩ Azure OpenAI (Responses API) सँग अनुक्रमिक एजेन्ट वर्कफ्लोहरू (.NET)

## 📋 उन्नत अनुक्रमिक प्रशोधन ट्युटोरियल

यो नोटबुकले Microsoft Agent Framework for .NET र Azure OpenAI (Responses API) प्रयोग गरी **अनुक्रमिक वर्कफ्लो ढाँचा** प्रदर्शन गर्दछ। तपाईंले कसरी जटिल, चरण-द्वारा-चरण प्रशोधन पाइपलाइनहरू निर्माण गर्ने सिक्नुहुनेछ जहाँ एजेन्टहरूले विशिष्ट क्रममा कार्यान्वयन गर्छन्, प्रत्येक चरणले अघिल्लो चरणको नतिजामा आधारित हुन्छ।

## 🎯 सिकाइ लक्ष्यहरू

### 🔄 **अनुक्रमिक प्रशोधन वास्तुकला**
- **रेखीय वर्कफ्लो डिजाइन**: स्पष्ट निर्भरताहरू सहित चरण-द्वारा-चरण प्रशोधन पाइपलाइनहरू सिर्जना गर्नुहोस्
- **स्थिति व्यवस्थापन**: अनुक्रमिक वर्कफ्लो चरणहरूमा सन्दर्भ र डेटा प्रवाह कायम राख्नुहोस्
- **Azure OpenAI (Responses API)**: बहु-चरण .NET वर्कफ्लोहरूमा Azure OpenAI मोडेलहरू प्रयोग गर्नुहोस्
- **उद्यम पाइपलाइन ढाँचा**: उत्पादन-सज्जित अनुक्रमिक प्रशोधन प्रणालीहरू निर्माण गर्नुहोस्

### 🏗️ **उन्नत अनुक्रमिक ढाँचा**
- **चरण-गेट प्रशोधन**: वर्कफ्लो चरणहरू बीच मान्यता जाँच बिन्दुहरू कार्यान्वयन गर्नुहोस्
- **सन्दर्भ संरक्षण**: सबै चरणहरूमा अवस्था र जम्मा गरिएको ज्ञान कायम राख्नुहोस्
- **त्रुटि प्रक्षेपण**: अनुक्रमिक प्रशोधन श्रृंखलाहरूमा असफलताहरूलाई सहजरूपमा व्यवस्थापन गर्नुहोस्
- **प्रदर्शन अनुकूलन**: न्यूनतम ओभरहेडसहित कुशल अनुक्रमिक कार्यान्वयन

### 🏢 **उद्यम अनुक्रमिक अनुप्रयोगहरू**
- **दस्तावेज प्रशोधन पाइपलाइन**: बहु-चरण दस्तावेज विश्लेषण, रूपान्तरण, र मान्यता
- **गुणस्तर आश्वासन वर्कफ्लोहरू**: अनुक्रमिक समीक्षा, मान्यता, र स्वीकृति प्रक्रिया
- **सामग्री उत्पादन पाइपलाइन**: अनुसन्धान → लेखन → सम्पादन → समीक्षा → प्रकाशन
- **व्यवसाय प्रक्रिया स्वचालन**: स्पष्ट चरण निर्भरतासहितको बहु-चरण व्यवसाय वर्कफ्लोहरू

## ⚙️ पूर्वापेक्षाहरू र सेटअप

### 📦 **आवश्यक NuGet प्याकेजहरू**

.NET अनुक्रमिक वर्कफ्लोहरूको लागि आवश्यक प्याकेजहरू:

```xml
<!-- Core AI Framework -->
<PackageReference Include="Microsoft.Extensions.AI" Version="10.*" />

<!-- Azure OpenAI (Responses API) -->
<PackageReference Include="Azure.AI.OpenAI" Version="2.*" />

<!-- Azure Identity and Async LINQ Support -->
<PackageReference Include="Azure.Identity" Version="1.15.0" />
<PackageReference Include="System.Linq.Async" Version="6.0.3" />

<!-- Local Agent Framework References -->
<!-- Microsoft.Agents.AI.dll - Core agent abstractions -->
<!-- Microsoft.Agents.AI.OpenAI.dll - Azure OpenAI (Responses API) integration -->
```

### 🔑 **Azure OpenAI कन्फिगरेसन**

**पर्यावरण सेटअप (.env फाइल):**
```env
AZURE_OPENAI_ENDPOINT=https://<your-resource>.openai.azure.com
AZURE_OPENAI_DEPLOYMENT=gpt-5-mini
```

**कन्फिगरेसन व्यवस्थापन:**
```csharp
// Load environment variables securely
Env.Load("../../../.env");
var azureEndpoint = Environment.GetEnvironmentVariable("AZURE_OPENAI_ENDPOINT");
var deployment = Environment.GetEnvironmentVariable("AZURE_OPENAI_DEPLOYMENT");
```


**मुख्य कम्पोनेन्टहरू:**
- **अनुक्रमिक एजेन्टहरू**: प्रत्येक प्रशोधन चरणका लागि विशेष एजेन्टहरू
- **स्थिति सन्दर्भ**: चरणहरूमा जम्मा गरिएको डेटा र निर्णयहरू कायम राख्छ
- **चेकप्वाईन्टहरू**: गुणस्तर र स्थिरता सुनिश्चित गर्न चरणहरू बीच मान्यता बिन्दुहरू
- **Azure OpenAI क्लाइन्ट**: सबै वर्कफ्लो चरणहरूमा निरन्तर एआई मोडेल पहुँच

## 🎨 **अनुक्रमिक वर्कफ्लो डिजाइन ढाँचाहरू**

### 📝 **दस्तावेज प्रशोधन पाइपलाइन**
```
Raw Document → Content Extraction → Analysis → Validation → Structured Output
```

### 🎯 **सामग्री सिर्जना वर्कफ्लो**
```
Brief/Requirements → Research → Content Creation → Review → Final Polish
```

### 🔍 **गुणस्तर आश्वासन पाइपलाइन**
```
Initial Review → Technical Validation → Compliance Check → Final Approval
```

### 💼 **व्यवसाय बुद्धिमत्ता वर्कफ्लो**
```
Data Collection → Processing → Analysis → Report Generation → Distribution
```

## 🏢 **उद्यम अनुक्रमिक लाभहरू**

### 🎯 **विश्वसनीयता र गुणस्तर**
- **नियतात्मक प्रशोधन**: संरचित चरणहरू मार्फत निरन्तर, दोहोरिने नतिजाहरू
- **गुणस्तर गेटहरू**: प्रत्येक चरणमा गुणस्तर सुनिश्चित गर्ने मान्यता बिन्दुहरू
- **त्रुटि अलगाव**: एउटा चरणमा समस्या भएसँगै अर्को चरणहरूमा फैलँदैन
- **अडिट ट्रेलहरू**: प्रत्येक चरणमा निर्णय र रूपान्तरणहरूको पूर्ण ट्र्याकिङ

### 📈 **स्केलेबिलिटी र प्रदर्शन**
- **मोड्युलर डिजाइन**: प्रत्येक चरणलाई स्वतन्त्र रूपमा अनुकूलन गर्न सकिन्छ
- **स्रोत व्यवस्थापन**: चरणहरूमा एआई मोडेल स्रोतको कुशल व्यवस्थापन
- **स्थिति अनुकूलन**: उत्कृष्ट प्रदर्शनका लागि चरणहरू बीच न्यूनतम अवस्था स्थानान्तरण
- **समानान्तर चरण समूहहरू**: धेरै अनुक्रमिक वर्कफ्लोहरू समानान्तर रूपमा चलाउन सक्छन्

### 🔒 **सुरक्षा र अनुपालन**
- **चरण-स्तर सुरक्षा**: विभिन्न प्रशोधन चरणहरूको लागि फरक सुरक्षा नीतिहरू
- **डेटा मान्यता**: प्रत्येक जाँच बिन्दुमा डेटा अखण्डता र अनुपालन सुनिश्चित गर्नुहोस्
- **पहुंने नियन्त्रण**: विभिन्न वर्कफ्लो चरणहरूका लागि सूक्ष्म अनुमतिहरू
- **नियमित अनुपालन**: संरचित प्रशोधन मार्फत नियामकीय आवश्यकताहरू पूरा गर्नुहोस्

### 📊 **अनुगमन र विश्लेषण**
- **चरण-स्तर मेट्रिक्स**: प्रत्येक वर्कफ्लो चरणको प्रदर्शन अनुगमन
- **बोटलनेक पहिचान**: ढिला चरणहरू पहिचान गरी अनुकूलन गर्नुहोस्
- **गुणस्तर मेट्रिक्स**: प्रत्येक चरणमा गुणस्तर र सफलता दर ट्र्याक गर्नुहोस्
- **प्रशोधन अनुकूलन**: चरण-स्तर विश्लेषणमा आधारित निरन्तर सुधार

आउनुहोस् सशक्त अनुक्रमिक एआई प्रशोधन पाइपलाइनहरू निर्माण गरौं! 🚀

### 🎯 वास्तविक-विश्व अनुप्रयोगहरू

यो अनुक्रमिक ढाँचाः
- **ई-कॉमर्स**: उत्पादन विश्लेषण → मूल्य निर्धारण → कोट निर्माण
- **रियल स्टेट**: सम्पत्ति विश्लेषण → मूल्याङ्कन → सूची निर्माण
- **बीमा**: दावा विश्लेषण → मूल्याङ्कन → कोट निर्माण
- **सामग्री सिर्जना**: अनुसन्धान → लेखन → सम्पादन → प्रकाशन

### 🔍 अवस्था प्रवाह बुझ्न

श्रृंखलामा प्रत्येक एजेन्टले प्राप्त गर्दछ:
- **मूल इनपुट**: प्रारम्भिक प्रयोगकर्ता सन्देश (छवि + पाठ)
- **अघिल्लो एजेन्टको आउटपुटहरू**: सम्पूर्ण संवाद इतिहासमा सबै अघिल्लो एजेन्ट प्रतिक्रिया
