# ⚡ Azure OpenAI (Responses API) संग समवर्ती एजेन्ट वर्कफ्लोहरू (.NET)

## 📋 उच्च-प्रदर्शन समानान्तर प्रशोधन ट्यूटोरियल

यस नोटबुकले Microsoft Agent Framework for .NET र Azure OpenAI (Responses API) प्रयोग गरेर **समवर्ती वर्कफ्लो ढाँचाहरू** प्रदर्शन गर्दछ। तपाईंले थाहा पाउनुहुनेछ कि कसरी उच्च-प्रदर्शन, समानान्तर प्रशोधन वर्कफ्लोहरू निर्माण गर्ने जसले एकै पटक धेरै AI एजेन्टहरू सञ्चालन गरेर थ्रूपुट अधिकतम गर्दछ र समन्वय र डाटा स्थिरता कायम राख्दछ।

## 🎯 सिकाइका उद्देश्यहरू

### 🚀 **समवर्ती प्रशोधनको आधारभूत कुरा**
- **समानान्तर एजेन्ट कार्यान्वयन**: अधिकतम प्रदर्शनको लागि एकै पटक धेरै AI एजेन्टहरू चलाउनुहोस्
- **Async/Await ढाँचा**: कुशल समवर्ती कार्यका लागि .NET को async प्रोग्रामिङ मोडल प्रयोग गर्नुहोस्
- **Azure OpenAI (Responses API)**: Azure OpenAI Responses API को धेरै समवर्ती कलहरू समन्वय गर्नुहोस्
- **स्रोत व्यवस्थापन**: समवर्ती अपरेशनहरू बीच AI मोडेल स्रोतहरू कुशलतापूर्वक व्यवस्थापन गर्नुहोस्

### 🏗️ **उन्नत समवर्ती वास्तुकला**
- **टास्क-आधारित समानान्तरता**: अधिकतम समवर्ती कार्यान्वयनका लागि .NET टास्क समानान्तर पुस्तकालय प्रयोग गर्नुहोस्
- **समक्रमण ढाँचाहरू**: दौड सर्तहरू टार्दै समवर्ती एजेन्टहरू समन्वय गर्नुहोस्
- **लोड सन्तुलन**: उपलब्ध समवर्ती प्रशोधन क्षमता भरि कार्य प्रभावकारी रूपमा वितरित गर्नुहोस्
- **त्रुटि सहिष्णुता**: सम्पूर्ण वर्कफ्लो रोके बिना व्यक्तिगत एजेन्ट असफलताहरू सम्हाल्नुहोस्

### 🏢 **उद्यम समवर्ती अनुप्रयोगहरू**
- **उच्च-परिमाण कागजात प्रशोधन**: धेरै कागजातहरू एकै पटक प्रशोधन गर्नुहोस्
- **रियल-टाइम सामग्री विश्लेषण**: आउने डाटा स्ट्रिमहरूको समवर्ती विश्लेषण
- **ब्याच प्रशोधन अनुकूलन**: ठूलो-स्तर डाटा प्रशोधन अपरेशनहरूको थ्रूपुट अधिकतम गर्नुहोस्
- **बहु-मोड विश्लेषण**: विभिन्न सामग्री प्रकार र ढाँचाहरूको समानान्तर प्रशोधन

## 💻 कोड चलाउने

पूर्ण कार्यान्वयन `03.dotnet-agent-framework-workflow-ghmodel-concurrent.cs` मा उपलब्ध छ। यो फाइलले यात्रा योजना बनाउने **फ्यान-आउट/फ्यान-इन समवर्ती वर्कफ्लो** प्रदर्शन गर्दछ:

### 🏗️ **वर्कफ्लो वास्तुकला**

```
User Request → ConcurrentStartExecutor → [Researcher Agent || Planner Agent] → ConcurrentAggregationExecutor → Final Output
```

**मुख्य कम्पोनेन्टहरू:**

1. **ConcurrentStartExecutor**: प्रयोगकर्ता अनुरोध सबै एजेन्टहरूलाई एकै पटक प्रसारित गर्दछ
2. **Researcher Agent**: गन्तव्य र आकर्षणहरू समानान्तर रूपमा विश्लेषण गर्दछ
3. **Planner Agent**: विस्तृत यात्रा योजना समानान्तर रूपमा बनाउँछ
4. **ConcurrentAggregationExecutor**: दुवै एजेन्टका परिणामहरू सङ्कलन र मर्ज गर्दछ

### 🎯 **फ्यान-आउट/फ्यान-इन ढाँचा**

यो वर्कफ्लोले परम्परागत **फ्यान-आउट/फ्यान-इन** ढाँचाको प्रदर्शन गर्दछ:
- **फ्यान-आउट**: एउटा इनपुट सन्देशलाई एकै पटक धेरै एजेन्टहरूलाई प्रसारित गरिन्छ
- **समवर्ती प्रशोधन**: धेरै एजेन्टहरू एकै काममा समानान्तर रूपमा काम गर्छन्
- **फ्यान-इन**: सबै एजेन्टबाट परिणामहरू सङ्कलन गरिन्छ र एउटै आउटपुटमा समाहित गरिन्छ

### 🔧 अनुकूलन विकल्पहरू

**थप समवर्ती एजेन्टहरू थप्नुहोस्:**
```csharp
// Create additional specialized agents
AIAgent budgetAgent = azureClient.GetChatClient(deployment).AsAIAgent(
    name: "Budget-Agent", instructions: "Calculate travel costs...");

// Add to fan-out
var workflow = new WorkflowBuilder(startExecutor)
    .AddFanOutEdge(startExecutor, targets: [researcherAgent, plannerAgent, budgetAgent])
    .AddFanInBarrierEdge(sources: [researcherAgent, plannerAgent, budgetAgent], aggregationExecutor)
    .WithOutputFrom(aggregationExecutor)
    .Build();

// Update aggregation count
if (this._messages.Count == 3) { ... }
```

- **बजार अनुसन्धान**: विभिन्न बजार खण्डहरूको समानान्तर विश्लेषण

### 🔍 कस्टम Executor हरू बुझ्नुहोस्

**ConcurrentStartExecutor:**
- `IMessageHandler<string>` कार्यान्वयन गरेर स्ट्रिङ इनपुट स्वीकार्छ
- सबै जडित एजेन्टहरूलाई सन्देश प्रसारित गर्दछ
- समवर्ती प्रशोधन सुरु गर्न `TurnToken` पठाउँछ

**ConcurrentAggregationExecutor:**
- एजेन्ट प्रतिक्रियाहरू प्राप्त गर्न `IMessageHandler<ChatMessage>` कार्यान्वयन गर्दछ
- सन्देशहरू थ्रेड-सेफ तरिकाले सङ्कलन गर्दछ
- सबै अपेक्षित प्रतिक्रियाहरू आएपछि समेकन गर्दछ
- `context.YieldOutputAsync()` प्रयोग गरी अन्तिम आउटपुट दिन्छ

### ⚡ प्रदर्शन लाभहरू

**समवर्ती र क्रमबद्ध:**
- क्रमबद्ध: Agent1 (३० सेकेन्ड) → Agent2 (३० सेकेन्ड) = **कुल ६० सेकेन्ड**
- समवर्ती: Agent1 (३० सेकेन्ड) || Agent2 (३० सेकेन्ड) = **कुल ३० सेकेन्ड**

**थ्रूपुट सुधार**: N वटा समवर्ती एजेन्टका लागि N गुणा छिटो (कार्यभार र स्रोतहरू अनुसार)
