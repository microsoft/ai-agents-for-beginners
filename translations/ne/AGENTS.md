# AGENTS.md

## परियोजना अवलोकन

यो रिपोजिटरीमा "शुरुआतीहरूका लागि AI एजेन्टहरू" समावेश छ - AI एजेन्टहरू निर्माण गर्न आवश्यक सबै कुरा सिकाउने एक व्यापक शैक्षिक कोर्स। कोर्समा १८ पाठहरू (नम्बर ००-१८) छन् जसले आधारभूत, डिजाइन ढाँचा, फ्रेमवर्कहरू, उत्पादन परिनियोजन, स्थानीय/डिभाइस एजेन्टहरू, र AI एजेन्टहरूको सुरक्षा समेट्छ।

**मुख्य प्रविधिहरू:**
- Python 3.12+
- अन्तरक्रियात्मक सिकाइका लागि Jupyter नोटबुकहरू
- AI फ्रेमवर्कहरू: Microsoft Agent Framework (MAF)
- Azure AI सेवा: Microsoft Foundry, Microsoft Foundry Agent Service V2

**साङ्गठन:**
- पाठ-आधारित संरचना (००-१८ डिरेक्टरीहरू)
- प्रत्येक पाठमा हुन्छ: README दस्तावेज, कोड नमूनाहरू (Jupyter नोटबुकहरू), र छविहरू
- स्वचालित अनुवाद प्रणाली मार्फत बहुभाषी समर्थन
- प्रत्येक पाठका लागि एक Python नोटबुक माइक्रोसफ्ट एजेन्ट फ्रेमवर्कको प्रयोग गरेर

## सेटअप आदेशहरू

### पूर्वापेक्षाहरू
- Python 3.12 वा माथि
- Azure सदस्यता (Microsoft Foundry का लागि)
- Azure CLI स्थापना र प्रमाणीकृत (`az login`)

### प्रारम्भिक सेटअप

१. **रिपोजिटरी क्लोन वा फोर्क गर्नुहोस्:**
   ```bash
   gh repo fork microsoft/ai-agents-for-beginners --clone
   # OR
   git clone https://github.com/microsoft/ai-agents-for-beginners.git
   cd ai-agents-for-beginners
   ```

२. **Python भर्चुअल वातावरण सिर्जना र सक्रिय गर्नुहोस्:**
   ```bash
   python3 -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   ```

३. **निर्भरताहरू स्थापना गर्नुहोस्:**
   ```bash
   pip install -r requirements.txt
   ```

४. **पर्यावरण चरहरू सेट गर्नुहोस्:**
   ```bash
   cp .env.example .env
   # Edit .env with your API keys and endpoints
   ```

### आवश्यक वातावरण चरहरू

**Microsoft Foundry** का लागि (आवश्यक):
- `AZURE_AI_PROJECT_ENDPOINT` - Microsoft Foundry परियोजना अन्त बिन्दु
- `AZURE_AI_MODEL_DEPLOYMENT_NAME` - मोडेल परिनियोजन नाम (जस्तै, gpt-5-mini)

**Azure AI Search** का लागि (पाठ ०५ - RAG):
- `AZURE_SEARCH_SERVICE_ENDPOINT` - Azure AI Search अन्त बिन्दु
- `AZURE_SEARCH_API_KEY` - Azure AI Search API कुञ्जी

प्रमाणीकरण: नोटबुकहरू चलाउनुभन्दा पहिले `az login` चलाउनुहोस् (यसले `AzureCliCredential` लाई प्रयोग गर्छ)।
