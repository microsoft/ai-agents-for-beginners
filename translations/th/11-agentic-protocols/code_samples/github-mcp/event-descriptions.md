## คำอธิบาย

ขอบคุณ GitHub Models ทั้งหมดที่คุณต้องการเพื่อสร้างเอเย่นต์ AI ตัวแรกของคุณคือบัญชี GitHub! GitHub Models มีโมเดลทรงพลังเช่น OpenAI gpt-4.1, DeepSeek-R1, Llama-3.1 และอีกมากมาย พร้อมให้ลองใช้งานใน playground หรือในโค้ดของคุณ

## ชื่องานอีเวนต์: Multi-Agent API ด้วย LangGraph และ Azure Cosmos DB

## คำอธิบาย

การเติบโตของแอปพลิเคชัน AI หลายเอเย่นต์กำลังเปลี่ยนวิธีที่เราสร้างระบบอัจฉริยะ—but คุณจะออกแบบพวกมันให้สามารถปรับขนาดและประสิทธิภาพในโลกจริงได้อย่างไร? ในเซสชันนี้ เราจะเจาะลึกแอปพลิเคชันมัลติเอเย่นต์ระดับโปรดักชันที่สร้างด้วย LangGraph สำหรับการประสานงานเอเย่นต์, FastAPI สำหรับเลเยอร์ API, และ Azure Cosmos DB เป็นโครงสร้างหลักสำหรับการจัดการสถานะ, การเก็บเวกเตอร์ และข้อมูลธุรกรรม

ผ่านโค้ดขั้นตอนอย่างละเอียด คุณจะได้เห็นวิธีออกแบบและดำเนินการเวิร์กโฟลว์ที่ขับเคลื่อนด้วยเอเย่นต์ที่ผสานรวมการสร้างแบบ Retrieval-Augmented Generation (RAG), การเก็บความจำ และการเปลี่ยนสถานะแบบไดนามิก เราจะครอบคลุม:

การทำงานร่วมกันของเอเย่นต์ด้วย LangGraph สำหรับการคิดเชิงโครงสร้าง
การจัดเก็บประวัติการแชทแบบเรียลไทม์โดยใช้ Azure Cosmos DB - ฐานข้อมูลเดียวกับที่ใช้เก็บประวัติแชทใน ChatGPT ซึ่งเป็นแอปเอเย่นต์ AI ที่เติบโตเร็วที่สุดในประวัติศาสตร์
การค้นหาเวกเตอร์เพื่อดึงความรู้ด้วยการรองรับ embeddings ดั้งเดิมของ Cosmos DB
ความสามารถ async ของ FastAPI เพื่อทำให้การโต้ตอบตอบสนองได้ดีและปรับขนาดได้
เมื่อจบเซสชันนี้ คุณจะมีแบบแผนชัดเจนในการสร้างและปรับใช้แอปพลิเคชันมัลติเอเย่นต์ที่ปรับขนาดได้อย่างคลาวด์เนทีฟ ที่ใช้พลังของ AI สมัยใหม่และโครงสร้างพื้นฐานคลาวด์ ไม่ว่าคุณจะเป็นวิศวกร AI, สถาปนิกคลาวด์ หรือผู้พัฒนา Python งานนี้จะช่วยให้คุณมีข้อมูลเชิงลึกและรูปแบบปฏิบัติที่ผ่านการพิสูจน์แล้วเพื่อสร้างแอป AI รุ่นต่อไป

## ชื่องานอีเวนต์: สร้างแอปโค้ด-เฟิร์สของคุณด้วย Microsoft Foundry Agent Service (.NET)

## คำอธิบาย

Microsoft Foundry Agent Service เป็นการผสมผสานระหว่างบริการและ SDK ที่ช่วยให้การพัฒนาโซลูชันขับเคลื่อนด้วย AI ที่ทรงพลังเป็นเรื่องง่าย ในเซสชันนี้ คุณจะได้เรียนรู้วิธีสร้างเอเย่นต์ AI แบบโค้ด-เฟิร์สของคุณเองด้วย Azure และ C# ที่สามารถตอบคำถาม วิเคราะห์ข้อมูล และรวมแหล่งข้อมูลภายนอก คุณยังจะได้สำรวจสถาปัตยกรรมที่ซับซ้อนมากขึ้น รวมถึงเอเย่นต์หลายตัวที่ทำงานร่วมกัน

## URL
<https://developer.microsoft.com/en-us/reactor/events/25370/>

## ชื่องานอีเวนต์: เอเย่นต์ AI + Aspire

## คำอธิบาย

ในเซสชันนี้เราจะแบ่งปันการพัฒนาที่น่าตื่นเต้นที่สุดบนแพลตฟอร์ม .NET เกี่ยวกับเอเย่นต์ ค้นพบสถานะปัจจุบันของ .NET รวมทั้งฟีเจอร์และการปรับปรุงใหม่ๆ สำรวจความสามารถที่ทรงพลังของเอเย่นต์ AI และเราจะเขียนโค้ดสดกับเอเย่นต์และ Aspire

## URL
<https://developer.microsoft.com/en-us/reactor/events/25332/>

## ชื่องานอีเวนต์: Semantic Kernel ด้วย C# เพื่อสร้างแอป AI หลายเอเย่นต์ที่ขับเคลื่อนโดย Azure Cosmos

## คำอธิบาย

เราจะพาคุณสำรวจแอปพลิเคชันมัลติเอเย่นต์ในภาษา C# ที่สร้างบนกรอบงาน Semantic Kernel คุณจะเข้าใจแนวคิดเบื้องหลังแอปแบบเอเย่นต์ เข้าใจรายละเอียดการนำไปใช้และความซับซ้อนต่างๆ และเรียนรู้วิธีรวม Azure Cosmos DB เป็นฐานข้อมูลสำหรับกรณีการใช้งานต่างๆ

## URL
<https://developer.microsoft.com/en-us/reactor/events/25455/>
