การทำงานร่วมกันของเอเย่นต์ด้วย LangGraph สำหรับการวิเคราะห์เชิงโครงสร้าง

การค้นหาเวกเตอร์เพื่อดึงความรู้ด้วยการสนับสนุน embeddings ดั้งเดิมของ Cosmos DB  
ความสามารถ async ของ FastAPI เพื่อรักษาการโต้ตอบให้ตอบสนองและขยายตัวได้  
เมื่อสิ้นสุดเซสชันนี้ คุณจะมีแผนผังชัดเจนสำหรับการสร้างและปรับใช้แอปพลิเคชันหลายเอเย่นต์แบบเนทีฟคลาวด์ที่สามารถปรับขนาดได้โดยใช้พลังของ AI และโครงสร้างพื้นฐานคลาวด์สมัยใหม่ ไม่ว่าคุณจะเป็นวิศวกร AI สถาปนิกคลาวด์ หรือผู้พัฒนา Python การบรรยายนี้จะมอบข้อมูลเชิงปฏิบัติและรูปแบบที่ทดสอบจริงเพื่อสร้างแอปพลิเคชัน AI รุ่นต่อไป

## Event Name: Semantic Kernel กับ C# เพื่อสร้างแอปพลิเคชัน AI หลายเอเย่นต์ที่ใช้กำลังจาก Azure Cosmos

## Description

เราจะนำคุณผ่านแอปพลิเคชันหลายเอเย่นต์ใน C# ที่สร้างขึ้นบนฐานของเฟรมเวิร์ก Semantic Kernel คุณจะเข้าใจแนวคิดเบื้องหลังแอปพลิเคชันแบบเอเย่นต์ เข้าใจรายละเอียดการติดตั้งและข้อสังเกต และเรียนรู้วิธีผสาน Azure Cosmos DB เป็นฐานข้อมูลสำหรับกรณีการใช้งานต่างๆ
