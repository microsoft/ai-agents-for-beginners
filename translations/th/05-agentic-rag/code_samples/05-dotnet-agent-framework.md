# 🔍 Enterprise RAG กับ Microsoft Foundry (.NET)

## 📋 วัตถุประสงค์การเรียนรู้

โน้ตบุ๊กนี้แสดงวิธีสร้างระบบ Retrieval-Augmented Generation (RAG) ระดับองค์กรโดยใช้ Microsoft Agent Framework ใน .NET กับ Microsoft Foundry คุณจะได้เรียนรู้การสร้างเอเจนต์ที่พร้อมใช้งานจริงซึ่งสามารถค้นหาเอกสารและให้คำตอบที่ถูกต้อง มีบริบท พร้อมความปลอดภัยและความสามารถในการปรับขนาดระดับองค์กร

**ความสามารถของ Enterprise RAG ที่คุณจะสร้าง:**
- 📚 **ความชาญฉลาดของเอกสาร**: การประมวลผลเอกสารขั้นสูงด้วยบริการ Azure AI
- 🔍 **การค้นหาทางความหมาย**: การค้นหาเวกเตอร์ประสิทธิภาพสูงพร้อมฟีเจอร์องค์กร
- 🛡️ **การรวมระบบความปลอดภัย**: การเข้าถึงตามบทบาทและรูปแบบการปกป้องข้อมูล
- 🏢 **สถาปัตยกรรมที่ปรับขนาดได้**: ระบบ RAG พร้อมใช้งานจริงพร้อมการตรวจสอบ

## 🎯 สถาปัตยกรรม Enterprise RAG

### องค์ประกอบหลักขององค์กร
- **Microsoft Foundry**: แพลตฟอร์ม AI ระดับองค์กรที่มีการจัดการพร้อมความปลอดภัยและการปฏิบัติตามกฎระเบียบ
- **เอเจนต์ถาวร**: เอเจนต์ที่มีสถานะ บันทึกประวัติการสนทนาและการจัดการบริบท
- **การจัดการคลังเวกเตอร์**: การจัดทำดัชนีและดึงข้อมูลเอกสารระดับองค์กร
- **การรวมระบบตัวตน**: การยืนยันตัวตน Azure AD และการควบคุมการเข้าถึงตามบทบาท

### ประโยชน์ของ .NET ระดับองค์กร
- **ความปลอดภัยของชนิดข้อมูล**: การตรวจสอบในเวลาคอมไพล์สำหรับการดำเนินการ RAG และโครงสร้างข้อมูล
- **ประสิทธิภาพแบบ Async**: การประมวลผลเอกสารและการค้นหาแบบไม่บล็อค
- **การจัดการหน่วยความจำ**: การใช้งานทรัพยากรอย่างมีประสิทธิภาพสำหรับคอลเลกชันเอกสารขนาดใหญ่
- **รูปแบบการรวมระบบ**: การรวมบริการ Azure แบบเนทีฟด้วยการฉีดพึ่งพา

## 🏗️ สถาปัตยกรรมทางเทคนิค

### ท่อข้อมูล Enterprise RAG
```
Document Upload → Security Validation → Vector Processing → Index Creation
                      ↓                    ↓                  ↓
User Query → Authentication → Semantic Search → Context Ranking → AI Response
```

### องค์ประกอบหลักของ .NET
- **Azure.AI.Agents.Persistent**: การจัดการเอเจนต์ระดับองค์กรพร้อมการเก็บสถานะ
- **Azure.Identity**: การยืนยันตัวตนแบบรวมเพื่อการเข้าถึงบริการ Azure อย่างปลอดภัย
- **Microsoft.Agents.AI.AzureAI**: การใช้งานเฟรมเวิร์กเอเจนต์ที่ปรับแต่งสำหรับ Azure
- **System.Linq.Async**: การดำเนินการ LINQ แบบอะซิงโครนัสที่มีประสิทธิภาพสูง

### ความปลอดภัยและการปฏิบัติตามกฎระเบียบ

- **การปกป้องข้อมูล**: การเข้ารหัสข้อมูลขณะพักและขณะส่งสำหรับเอกสารที่มีความละเอียดอ่อน
- **การบันทึกการตรวจสอบ**: การติดตามกิจกรรมอย่างครบถ้วนเพื่อความปฏิบัติตามข้อกำหนด

### ประสิทธิภาพและการปรับขนาด
- **การจัดการพูลการเชื่อมต่อ**: การจัดการการเชื่อมต่อ Azure อย่างมีประสิทธิภาพ
- **การประมวลผลแบบ Async**: การดำเนินการไม่บล็อคสำหรับสถานการณ์ที่มีปริมาณงานสูง
- **กลยุทธ์การแคช**: แคชอัจฉริยะสำหรับเอกสารที่เข้าถึงบ่อย
- **การโหลดบาลานซ์**: การประมวลผลแบบกระจายสำหรับการปรับใช้ขนาดใหญ่

### การจัดการและการตรวจสอบ
- **การตรวจสอบสุขภาพ**: การตรวจสอบแบบบิวท์อินสำหรับองค์ประกอบระบบ RAG
- **เมตริกประสิทธิภาพ**: การวิเคราะห์รายละเอียดเกี่ยวกับคุณภาพการค้นหาและเวลาตอบสนอง
- **การจัดการข้อผิดพลาด**: การจัดการข้อยกเว้นอย่างครบถ้วนพร้อมนโยบายการลองใหม่
- **การจัดการการกำหนดค่า**: การตั้งค่าสภาพแวดล้อมเฉพาะพร้อมการตรวจสอบความถูกต้อง

## 📊 รูปแบบ Enterprise RAG

### รูปแบบการจัดการเอกสาร
- **การอัปโหลดจำนวนมาก**: การประมวลผลชุดเอกสารขนาดใหญ่ได้อย่างมีประสิทธิภาพ
- **การอัปเดตแบบผสมผสาน**: การเพิ่มและแก้ไขเอกสารแบบเรียลไทม์
- **การควบคุมเวอร์ชัน**: การจัดการเวอร์ชันเอกสารและการติดตามการเปลี่ยนแปลง
- **การจัดการเมทาดาทา**: แอตทริบิวต์และการจำแนกประเภทเอกสารที่สมบูรณ์

### รูปแบบการค้นหาและดึงข้อมูล
- **การค้นหาแบบไฮบริด**: การรวมกันของการค้นหาทางความหมายและคำค้นหาเพื่อผลลัพธ์ที่ดีที่สุด
- **การค้นหาแบบหลายมิติ**: การกรองและจัดหมวดหมู่แบบหลายมิติ
- **การปรับคะแนนความเกี่ยวข้อง**: อัลกอริทึมการให้คะแนนที่กำหนดเองสำหรับความต้องการเฉพาะโดเมน
- **การจัดลำดับผลลัพธ์**: การจัดอันดับขั้นสูงพร้อมบูรณาการตรรกะทางธุรกิจ

### รูปแบบความปลอดภัย
- **ความปลอดภัยในระดับเอกสาร**: การควบคุมการเข้าถึงที่ละเอียดสำหรับแต่ละเอกสาร
- **การจำแนกข้อมูล**: การติดป้ายความละเอียดอัตโนมัติและการป้องกัน
- **การติดตามตรวจสอบ**: การบันทึกการดำเนินการ RAG ทั้งหมดอย่างครบถ้วน
- **การปกป้องความเป็นส่วนตัว**: ความสามารถในการตรวจจับและแก้ไขข้อมูลส่วนบุคคล (PII)
