# คำตอบสำหรับการทดสอบความรู้

## คำถามที่ 1

**คำตอบ: A2.** ตัวแทนหลายคนมีประโยชน์เมื่อภารกิจมีบทบาทเฉพาะที่แตกต่างกัน เครื่องมือหรือสิทธิ์แยกต่างหาก และการส่งมอบงานที่ชัดเจนซึ่งต้องการการประสานงาน บอทสนับสนุนง่ายๆ โดยปกติสามารถเป็นตัวแทนเพียงคนเดียวได้ ปริมาณคำขอที่เหมือนกันจำนวนมากเป็นเรื่องเกี่ยวกับการปรับขนาดเป็นหลักและโดยตัวมันเองไม่จำเป็นต้องใช้การออกแบบตัวแทนหลายคน

## คำถามที่ 2

**คำตอบ: A1.** ตัวแทนเพียงคนเดียวโดยทั่วไปง่ายต่อการทดสอบ สังเกต และดำเนินการเมื่อชุดคำสั่งและเครื่องมือชุดเดียวสามารถจัดการภารกิจได้ การเข้าถึงเครื่องมือหลายอย่างไม่ได้หมายความว่าจะต้องใช้ตัวแทนหลายคน บทบาทแยกต่างหากที่มีสิทธิ์และข้อกำหนดการตรวจสอบต่างกันอาจชอบด้วยเหตุผลของการออกแบบตัวแทนหลายคน
