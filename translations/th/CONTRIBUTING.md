# การมีส่วนร่วม

โครงการนี้ยินดีต้อนรับการมีส่วนร่วมและคำแนะนำ ส่วนใหญ่การมีส่วนร่วมจะต้องให้คุณตกลงใน Contributor License Agreement (CLA) ที่ระบุว่าคุณมีสิทธิ์และได้ให้สิทธิกับเราจริง ๆ ในการใช้การมีส่วนร่วมของคุณ สำหรับรายละเอียดเพิ่มเติม โปรดเยี่ยมชม <https://cla.opensource.microsoft.com>.

เมื่อคุณส่ง pull request บอท CLA จะกำหนดโดยอัตโนมัติว่าคุณจำเป็นต้องให้ CLA หรือไม่ และตกแต่ง pull request ตามความเหมาะสม ให้ทำตามคำแนะนำที่บอทให้ไว้ คุณจำเป็นต้องทำเพียงครั้งเดียวในทุกๆ ที่เก็บที่ใช้ Microsoft CLA

## กฎการประพฤติปฏิบัติ

โครงการนี้ได้นำ [Microsoft Open Source Code of Conduct](https://opensource.microsoft.com/codeofconduct/) มาใช้ สำหรับข้อมูลเพิ่มเติม โปรดดูที่ [Code of Conduct FAQ](https://opensource.microsoft.com/codeofconduct/faq/) หรือ ติดต่อ [opencode@microsoft.com](mailto:opencode@microsoft.com) หากมีคำถามหรือความคิดเห็นเพิ่มเติม

## แนวทางการส่ง pull request

- ให้แต่ละ pull request เน้นที่การเปลี่ยนแปลงเชิงตรรกะเพียงอย่างเดียว
- ทดสอบสมุดโน้ตและตัวอย่างโค้ดที่ได้รับผลกระทบก่อนส่ง
- อัปเดตเอกสารบทเรียนที่เกี่ยวข้องเมื่อเพิ่มหรือเปลี่ยนแปลงตัวอย่าง
- แก้ไขเนื้อหาภาษาอังกฤษต้นฉบับเท่านั้น การแปลจะดูแลโดยกระบวนการแปลอัตโนมัติ
- ห้าม commit ข้อมูลรับรอง ไฟล์ `.env` ไฟล์ชั่วคราว หรือสิ่งของที่พัฒนาสร้างขึ้นอัตโนมัติ

## ขอบเขตงานแก้ไขและผลิตภัณฑ์ของบุคคลที่สาม

หลักสูตรนี้เน้นเทคโนโลยีของ Microsoft และมาตรฐานเปิดที่เป็นกลางต่อผู้จำหน่าย การมีส่วนร่วมควรมีวัตถุประสงค์ทางการศึกษาที่ชัดเจนและต้องไม่มุ่งเน้นเพื่อแนะนำหรือส่งเสริมผลิตภัณฑ์เชิงพาณิชย์ของบุคคลที่สาม บริการโฮสต์ เราเตอร์โมเดล SDK เซิร์ฟเวอร์ MCP หรือข้อเสนอเฉพาะของผู้จำหน่ายอื่น ๆ

ซอฟต์แวร์โอเพนซอร์สและการพึ่งพาบุคคลที่สามอาจถูกอ้างอิงเมื่อจำเป็นต้องอธิบายมาตรฐานเปิดหรือสถานการณ์การทำงานร่วมกัน พวกมันต้องถูกนำเสนออย่างเป็นกลางและไม่มุ่งเน้นที่ผลิตภัณฑ์หรือปลายทางที่โฮสต์โดยผู้จำหน่าย หากการมีส่วนร่วมที่คุณเสนอรวมถึงผลิตภัณฑ์หรือบริการเฉพาะของผู้จำหน่าย ให้เปิดประเด็นและขออนุมัติจากผู้ดูแลก่อนส่ง pull request

ผู้มีส่วนร่วมต้องเปิดเผยข้อมูลการจ้างงาน การเป็นเจ้าของ การสนับสนุน หรือความเกี่ยวข้องอื่นๆ กับผลิตภัณฑ์หรือบริการที่อ้างอิงในส่วนของตน ห้ามรวมคำอ้างอิงเกี่ยวกับราคา ประสิทธิภาพ ความปลอดภัย ความเป็นส่วนตัว หรือการเปรียบเทียบที่ไม่มีหลักฐาน ตัวอย่างที่สามารถรันได้ต้องไม่ส่งข้อมูลผู้เรียนหรือดำเนินการสาธารณะผ่านบริการบุคคลที่สามภายนอกโดยค่าเริ่มต้น
