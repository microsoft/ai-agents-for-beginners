# திட்டமிடல் வடிவமைப்பு

## அறிமுகம்

இந்த பாடம் கீழ்காணும் விஷயங்களை கையாளும்

* தெளிவான ஒருங்கிணைந்த இலக்கை வரையறுக்க மற்றும் ஒரு கூடிய பணியை கையாளக்கூடிய பணிகளாக பிரிக்க.
* நம்பகமான மற்றும் இயந்திர-படிக்கும் பதில்களுக்கு அமைந்த அமைப்பான வெளியீட்டை பயன்படுத்த.
* நிகழ்வு பெற்ற அணுகுமுறையை பயன்படுத்தி இயக்கமுள்ள பணிகள் மற்றும் எதிர்பாராத உள்ளீடுகளை கையாள.

## கற்றல் இலக்குகள்

இந்த பாடத்தை முடித்த பின் உங்களுக்கு கிடைக்கும் புரிதல்:

* ஒரு AI முகவருக்கு ஒருங்கிணைந்த இலக்கை அடையாளம் காணவும் மற்றும் அமைக்கவும், அது என்ன சாதிக்க வேண்டும் என்பதில் தெளிவாக இருக்க உத்தரவாதம் செய்யவும்.
* ஒரு கூடிய பணியை கையாளக்கூடிய துணைப் பணிகளாக உடைத்தும் அவற்றை தர்க்கமான தொடர்ச்சியில் ஒழுங்குபடுத்தவும்.
* முகவர்களுக்கு சரியான கருவிகள் (எ.கா., தேடல் கருவிகள் அல்லது தரவுக் குறிப்பாய்வு கருவிகள்) வழங்கி, அவற்றை எப்போது மற்றும் எப்படி பயன்படுத்தப்பட வேண்டும் எனத் தீர்மானித்து, எதிர்பாராத சூழ்நிலைகளைக் கையாளவும்.
* துணைப் பணிகளின் முடிவுகளை மதிப்பீடு செய்து, செயல்திறனை அளவிடி, இறுதி வெளியீட்டை மேம்படுத்த நடவடிக்கைகளை மீளாய்வு செய்யவும்.

## ஒருங்கிணைந்த இலக்கை வரையறுக்கல் மற்றும் பணியை உடைத்தல்

![Ilakkamum Paniyum](../../../translated_images/ta/defining-goals-tasks.d70439e19e37c47a.webp)

பெரும்பாலான நிஜ உலக பணிகள் ஒரே கட்டத்தில் கையாளவே முடியாதவைகள். ஒரு AI முகவருக்கு திட்டமிடல் மற்றும் நடவடிக்கைகளை வழிநடத்த ஒரு தெளிவான நோக்கம் தேவை. உதாரணமாக, இலக்கை எடுத்துக்கொள்ளவும்:

    "3-நாட்கள் பயண திட்டம் உருவாக்குதல்."

இது எளிதாகக் கூறப்பட வேண்டும் எனினும் இன்னும் மேம்படுத்தப்பட வேண்டும். இலக்கு தெளிவாக இருக்கும்போது, முகவரும் (மேலும் மனித கூட்டாளர்களும்) சரியான முடிவை அடைவதில் கவனம் செலுத்த முடியும், உதாரணமாக விமான விருப்பங்கள், ஹோட்டல் பரிந்துரைகள் மற்றும் செயல்பாடுகள் ஆகியவற்றுடன் விரிவான பயண திட்டத்தை உருவாக்குவது.

### பணியினைப் பிரித்தல்

பெரிய அல்லது சிக்கலான பணிகள் சிறிய, இலக்கு வழி துணைப் பணிகளாக பிரிக்கப்பட்டால் எளிதாக கையாளலாம்.
பயண திட்ட உதாரணத்திற்கு, இலக்கை கீழ்காணும் சில துணைப் பணிகளாக பிரிக்கலாம்:

* விமான பதிவு
* ஹோட்டல் பதிவு
* கார் வாடகை
* தனிப்பயனாக்கம்

ஒவ்வொரு துணைப் பணியும் தனித்துவமான முகவர்கள் அல்லது செயலிகளால் கையாளப்படலாம். ஒரு முகவரி சிறந்த விமான சலுகைகளை தேடுவதில் நிபுணத்துவம் பெறலாம், மற்றொன்று ஹோட்டல் பதிவு கவனிக்கலாம், அப்படி தொடரலாம். ஒரு ஒருங்கிணைப்பாளர் அல்லது “அடுத்த கட்ட” முகவர் இதழ்கள் முடிவுகளை ஒருங்கிணைத்து பயனர் முன்னிருக்கும் ஒரே பயணத் திட்டமாக உருவாக்கலாம்.

இந்த தொகுதி முறை மேலும் சிறு மேம்பாடுகளுக்கு அனுமதிக்கிறது. எடுத்துக்காட்டாக, உணவு பரிந்துரைகள் அல்லது உள்ளூர்செயல்பாடு பரிந்துரைகள் போன்ற சிறப்பான முகவர்களை சேர்க்கவும், அதன்பின்னர் பயணத் திட்டம் காலக்கெடுவாக மேம்படுத்தலாம்.

### அமைப்பான வெளியீடு

பெரிய மொழி மாதிரிகள் (LLMs) அமைப்பான வெளியீட்டைக் (எ.கா., JSON) உருவாக்க முடியும், இது அடுத்த கட்ட முகவர்களோ சேவைகளோ பரிசோதித்து செயலாற்ற எளியதாக இருக்கிறது. இது ஒரு பல-முகவர் சூழலில், திட்டமிடல் வெளியீட்டை பெற்ற பிறகு இவற்றை செயல்படுத்த சிறந்த நடவடிக்கையாகும்.

கீழ்காணும் Python குறியீடு ஒரு எளிய திட்டமிடல் முகவரி இலக்கை துணைப் பணிகளாக உடைத்து அமைப்பான திட்டத்தை உருவாக்கியது:

```python
from pydantic import BaseModel
from enum import Enum
from typing import List, Optional, Union
import json
import os
from typing import Optional
from pprint import pprint
from agent_framework.foundry import FoundryChatClient
from azure.identity import AzureCliCredential

class AgentEnum(str, Enum):
    FlightBooking = "flight_booking"
    HotelBooking = "hotel_booking"
    CarRental = "car_rental"
    ActivitiesBooking = "activities_booking"
    DestinationInfo = "destination_info"
    DefaultAgent = "default_agent"
    GroupChatManager = "group_chat_manager"

# பயண துணைபணி மாதிரி
class TravelSubTask(BaseModel):
    task_details: str
    assigned_agent: AgentEnum  # நாம் அந்த பணியை முகவரிடம் ஒதுக்க விரும்புகிறோம்

class TravelPlan(BaseModel):
    main_task: str
    subtasks: List[TravelSubTask]
    is_greeting: bool

provider = FoundryChatClient(
    project_endpoint=os.environ["AZURE_AI_PROJECT_ENDPOINT"],
    model=os.environ["AZURE_AI_MODEL_DEPLOYMENT_NAME"],
    credential=AzureCliCredential(),
)

# பயனர் செய்தியை வரையறு
system_prompt = """You are a planner agent.
    Your job is to decide which agents to run based on the user's request.
    Provide your response in JSON format with the following structure:
{'main_task': 'Plan a family trip from Singapore to Melbourne.',
 'subtasks': [{'assigned_agent': 'flight_booking',
               'task_details': 'Book round-trip flights from Singapore to '
                               'Melbourne.'}
    Below are the available agents specialised in different tasks:
    - FlightBooking: For booking flights and providing flight information
    - HotelBooking: For booking hotels and providing hotel information
    - CarRental: For booking cars and providing car rental information
    - ActivitiesBooking: For booking activities and providing activity information
    - DestinationInfo: For providing information about destinations
    - DefaultAgent: For handling general requests"""

user_message = "Create a travel plan for a family of 2 kids from Singapore to Melbourne"

response = client.create_response(input=user_message, instructions=system_prompt)

response_content = response.output_text
pprint(json.loads(response_content))
```

### பல-முகவர் ஒருங்கிணைப்புடன் திட்டமிடல் முகவர்

இந்த எடுத்துக்காட்டில், ஒரு Semantic Router முகவர் பயனர் கோரிக்கையை பெறுகிறது (எ.கா., "என் பயணத்திற்கு ஹோட்டல் திட்டம் வேண்டும்.").

திட்டமிடுபவர் பின்வருமாறு செய்கிறது:

* ஹோட்டல் திட்டத்தை பெறுதல்: திட்டமிடுபவர் பயனர் செய்தியை எடுத்து, கணினி இயக்கவியல் மூலம் (கிடைக்கும் முகவர் விவரங்கள் உட்பட) அமைப்பான பயணத் திட்டத்தை உருவாக்குகிறான்.
* முகவர்களும் அவர்களின் கருவிகளும் பட்டியலிடுதல்: முகவர் பதிவு விமானம், ஹோட்டல், கார் வாடகை மற்றும் செயல்பாடுகள் போன்ற முகவர்களின் பட்டியலை மற்றும் அவர்கள் வழங்கும் செயல்பாடுகள் அல்லது கருவிகளை உள்ளடக்கியது.
* திட்டத்தை உரிய முகவர்களுக்கு அனுப்புதல்: துணைப் பணிகளின் எண்ணிக்கையைப் பொறுத்து, திட்டமிடுபவர் செய்தியைக் குறிப்பிட்ட முகவருக்கு நேரடியாக அனுப்பலாம் (ஒரே பணிக்கான சூழல்) அல்லது பல-முகவர் ஒத்துழைப்புக்கு குழும உரையாடல் மேலாளரின் மூலம் ஒருங்கிணைக்கலாம்.
* முடிவை சுருக்குதல்: இறுதியில், திட்டமிடுபவர் உருவாக்கப்பட்ட திட்டத்தை தெளிவாக சுருக்கி வழங்குகிறான்.
கீழ்காணும் Python குறியீடு இந்த படிகளை விளக்குகிறது:

```python

from typing import List, Optional, Union

class TravelPlan(BaseModel):
    main_task: str
    subtasks: List[TravelSubTask]
    is_greeting: bool
import json
import os
from typing import Optional

from agent_framework.foundry import FoundryChatClient

# கிளையன்டை உருவாக்கு

provider = FoundryChatClient(
    project_endpoint=os.environ["AZURE_AI_PROJECT_ENDPOINT"],
    model=os.environ["AZURE_AI_MODEL_DEPLOYMENT_NAME"],
    credential=AzureCliCredential(),

from pprint import pprint

# பயனர் செய்தியை வரையறு

    Below are the available agents specialized in different tasks:
    - FlightBooking: For booking flights and providing flight information
    - HotelBooking: For booking hotels and providing hotel information
    - CarRental: For booking cars and providing car rental information
    - ActivitiesBooking: For booking activities and providing activity information
    - DestinationInfo: For providing information about destinations
    - DefaultAgent: For handling general requests"""

user_message = "Create a travel plan for a family of 2 kids from Singapore to Melbourne"

response = client.create_response(input=user_message, instructions=system_prompt)

response_content = response.output_text

# பதிலளிக்கப்பட்ட உள்ளடக்கத்தை JSON ஆக ஏற்றியபின் அச்சிடு

```

### மீளாய்வு திட்டமிடல்

சில பணிக்கான முடிவுகள் அடுத்த பணிக்கு சென்று தாக்கம் செய்கின்ற நிலையில், பின்னோக்கு அல்லது மீள்படிப்படியாகத் திட்டமிடல் தேவைப்படலாம். உதாரணமாக, முகவர் விமான பதிவுக் காலத்தில் எதிர்பாராத தரவு வடிவமைப்பை கண்டுபிடித்தால், ஹோட்டல் பதிவுக்குப் போகும் முன் தனது செயல்முறையை மாற்ற வேண்டியிருக்கலாம்.

மேலும், பயனர் கருத்து (எ.கா., ஒருவர் முன்னிருக்கு விமானத்தை விரும்புகிறாரா) ஒரு பகுதி மீள்நலக்கூறிணைவு ஏற்படுத்தலாம். இந்த இயக்கமுள்ள, மீளாய்வு கூறும் முறையில் இறுதி தீர்வு நிஜ உலக தடைகளுக்கும் மாறும் பயனர் விருப்பத்திற்கும் இணங்கும்.

## சுருக்கம்

இந்த கட்டுரையில், நாங்கள் ஒரு திட்டமிடலை உருவாக்கும் உதாரணத்தைப் பார்த்தோம், அதன் மூலம் கிடைக்கும் முகவர்களை இயக்கியாகத் தேர்வு செய்ய முடியும். திட்டமிடல் வெளியீடு பணிகளை உடைத்து முகவர்களுக்கு ஒப்படைக்கிறது, அதனால் அவை செயலாக்கப்பட முடிகிறது. முகவர்கள் பணியை செய்ய தேவையான செயல்பாடுகள்/கருவிகளுக்கு அணுகல் பெற்றிருக்க வேண்டும் என்பதும் கருதப்படுகிறது. முகவர்களில் கூடுதலாக பிரதிபலிப்பு, சுருக்கி மற்றும் சுழற்சி உரையாடல் போன்ற மற்ற வடிவமைப்புகளையும் சேர்க்கலாம் மேலும் தனிப்பயனாக்க.

## கூடுதல் வளங்கள்
