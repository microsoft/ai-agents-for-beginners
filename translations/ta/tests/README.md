# முகவர் புகையிலை சோதனைகள்

இந்த கோப்புறை நீங்கள் பாடக்குறிப்பில் உருவாக்கும் முகவர்களுக்கான **புகையிலை-சோதனை பட்டியல்கள்** வைத்திருக்கிறது.
ஒரு புகையிலை சோதனை என்பது ஒரு கைக்கூலி, விரைவு சோதனை ஆகும், இது **வெளியிடப்பட்ட Microsoft Foundry ஹோஸ்ட் செய்யப்பட்ட
முகவரி** எட்டுபடக்கூடியதாக, பதிலளிக்கக்கூடியதாகவும், அதன் அடிப்படை உத்தரவுகள்
எதிர்பார்ப்பு படி செயல்படுவதாகும் என்பதை சோதனைசெய்கிறது. இது முதல் கதவு ஆகும் — பாடத்தில் நீங்கள் கற்றுக் கொள்கிற முழு மதிப்பீட்டு
செயல்முறைக்கு மாற்றாக இல்லை, அது [பாடம் 10](../10-ai-agents-production/README.md) மற்றும்
[பாடம் 16](../16-deploying-scalable-agents/README.md) இல் உள்ளது.

இந்த பட்டியல்கள் [AI புகையிலை சோதனை](https://github.com/marketplace/actions/ai-smoke-test)
GitHub செயல் மூலம் [`.github/workflows/smoke-test.yml`](../../../.github/workflows/smoke-test.yml)
வேலைப்பாட்டை உபயோகிக்கின்றன.

## எப்படிச் செயல்படுத்துவது

1. **பாடத்தின் முகவரை** Microsoft Foundry இல் ஹோஸ்ட் செய்யப்பட்ட முகவராக (பயன்படுத்தும்
   வேலைப்பாடுக்கு பாடம் 16-ஐ பார்க்கவும்) வெளியிடவும். **முகவரி பெயரை** மற்றும் உங்கள்
   **Foundry திட்ட விருப்பத்தை** குறிக்கவும்.
2. இந்த சேமிப்பக ரகசியங்களை சேர்க்கவும் (அமைப்புகள் → ரகசியங்கள் மற்றும் மாறிலிகள் → செயல்கள்):
   `AZURE_CLIENT_ID`, `AZURE_TENANT_ID`, `AZURE_SUBSCRIPTION_ID`. இந்த ஒன்றிணைந்த
   அடையாளம் **Azure AI பயனர்** பகுதியில் இருக்க வேண்டியுள்ளது **Foundry திட்ட அளவில்**.
3. **செயல்கள்** தாவலில், **புகையிலை-சோதனை ஹோஸ்ட் செய்யப்பட்ட முகவர்கள்** இயக்கு, பாடத்திற்கு
   பொருந்தக்கூடிய `tests_file` தேர்ந்தெடுத்து, பழுதுபார்க்கும் `agent_name` மற்றும்
   `project_endpoint` வழங்கவும்.

## எந்த பாடங்களில் புகையிலை சோதனைகள் உள்ளன?

புகையிலை சோதனைகள், நீங்கள் **ஒரு முகவரை வெளியிடுகிறீர்கள்** என்றும், அதன் உரை பதில்கள்
புலப்படும் உள்ளடக்கம் மீது சோதிக்கக்கூடியபோது பொருந்தும். கருத்துக் கோட்பாடுகள்,
உள்ளூரையாக மட்டுமே இயங்கும், அல்லது அடையாளமிட இயலாத படைப்பாற்றல் வெளியீடு

- **பாடம் 17 (உள்ளூர AI முகவர்களை உருவாக்குதல்)** உங்கள் கணினியில் எல்லாம் இயங்குகிறது
  Foundry உள்ளூர் மூலம் மற்றும் **Foundry பதில்கள் இடைமுகத்தை** வெளியாக்கவில்லை, எனவே இந்த
  செயல் பொருந்தாது. அதனை நோட்புக் உள்ளூராக இயக்கி சரிபார்க்கவும்.
- வடிவமைப்பு-முறை மற்றும் கோட்பாடு பாடங்கள் (02, 03, 06, 07, 09, 12) ஒரே
  மேம்படுத்தக்கூடிய முகவர்களை புகையிலை-சோதனைக்காக வழங்கவில்லை.

## பட்டியல் அமைப்பு (விரைவான சுட்டுமுறை)

ஒவ்வொரு பட்டியலும் ஒரு JSON ஆவணம் ஆகும், அதில் மேல் நிலை `tests` வரிசை உள்ளது. ஒவ்வொரு நுழைவும்
ஒரு உத்தரவினை அனுப்பி பதிலைச் சோதிக்கின்றது:

| புலம் | பொருள் |
|-------|---------|
| `id` | லாக்கில் அச்சிடப்படும் தனித்துவமான படி அடையாளம். |
| `description` | மனிதன் வாசிக்கக்கூடிய நோக்கம். |
| `prompt` | முகவருக்கு அனுப்பப்படும் செய்தி. |
| `assertions.status` | எதிர்பார்க்கப்படும் HTTP நிலை (இயல்பாக 200). |
| `assertions.contains_any` | பதிலில் ஏதேனும் இவை உள்ளதொன்றுக்கு பாஸ் செய்யும். |
| `assertions.contains_all` | பதிலில் எல்லா துண்டுகளும் இருந்தால் பாஸ் செய்யும். |
| `assertions.contains_none` | பதிலில் எந்த துண்டுகளும் இல்லாதால் பாஸ் செய்யும். |
| `save_response_id_as` | பின்னர் பல-மடங்கு படிக்க பயன்படுத்த பதில் ஐடியை சேமிக்கவும். |
| `use_previous_response_id` | இந்த மடக்கு சேமிக்கப்பட்ட பதில் ஐடியுடன் தொடராக அனுப்பவும். |

Assertions என்பது பெரிய/சிறிய எழுத்துத் தன்மையற்ற துண்டு சரிபார்ப்புகள் ஆகும். முழு அமைப்புக்கு [செயல் ஆவணம்](https://github.com/marketplace/actions/ai-smoke-test) ஐ பார்க்கவும்,
இதில் Foundry மேலாண்மை உரையாடல் வளங்களும் உள்ளன.
முழு தாள் வடிவமைப்பு, அதில் Foundry-ஐ இயக்கும் உரையாடல் வளங்கள் அடங்கும்.
