# AGENTS.md

## திட்டம் பார்வை

இந்த சேமிப்பகம் "ஆரம்பத்திற்கான AI முகவர்கள்" - AI முகவர்கள் உருவாக்க தேவையான அனைத்தையும் கற்பிக்கும் விரிவான கல்வித் துறையை உள்ளடக்கியது. இந்த பாடநெறி 18 பாடங்களால் அமைந்தது, அடிப்படைகள், வடிவமைப்பு மாதிரிகள், கட்டமைப்புக்கள் மற்றும் AI முகவர்கள் தயாரிப்பு பயன்பாட்டை உள்ளடக்குகிறது.

**முக்கிய தொழில்நுட்பங்கள்:**
- பைதான் 3.12+
- இணைப்பு கற்றலுக்கான ஜூபிடர் நோட்டுப் புத்தகங்கள்
- AI கட்டமைப்புகள்: Microsoft Agent Framework (MAF)
- Azure AI சேவைகள்: Microsoft Foundry, Microsoft Foundry Agent Service V2

**வடிவமைப்பு:**
- பாடம் அடிப்படையிலான அமைப்பு (00-15+ அடைவைகள்)
- ஒவ்வொரு பாடத்திலும் உள்ளது: README ஆவணங்கள், குறியீடு உதாரணங்கள் (Jupyter நோட்டுப் புத்தகங்கள்), மற்றும் படங்கள்
- தானாக மொழிபெயர்ப்பு செயல்முறை மூலம் பல மொழிகள் ஆதரவு
- ஒவ்வொரு பாடத்திலும் Microsoft Agent Framework பயன்படுத்திய பைதான் நோட்டுப்புத்தகம் ஒன்று

## அமைப்பு கட்டளைகள்

### தேவை
- பைதான் 3.12 அல்லது மேல்
- Azure சந்தா (Microsoft Foundry க்கு)
- Azure CLI நிறுவப்பட்டு அங்கீகரிக்கப்பட்டது (`az login`)

### ஆரம்ப அமைப்பு

1. **சேமிப்பகத்தை இடுகையிடவும் அல்லது கிளோன் செய்யவும்:**
   ```bash
   gh repo fork microsoft/ai-agents-for-beginners --clone
   # அல்லது
   git clone https://github.com/microsoft/ai-agents-for-beginners.git
   cd ai-agents-for-beginners
   ```

2. **பைதான் கல்பனி சூழலை உருவாக்கி செயல்படுத்து:**
   ```bash
   python3 -m venv venv
   source venv/bin/activate  # விண்டோஸில்: venv\Scripts\activate
   ```

3. **சவர்க்கல்களை நிறுவுக:**
   ```bash
   pip install -r requirements.txt
   ```

4. **சூழல் மாறிகளை அமைக்கவும்:**
   ```bash
   cp .env.example .env
   # உங்கள் API சாவிகள் மற்றும் முடிவுகளுடன் .env ஐ தொகுக்கவும்
   ```

### தேவைப்படும் சூழல் மாறிகள்

**Microsoft Foundry** க்கு (தேவை):
- `AZURE_AI_PROJECT_ENDPOINT` - Microsoft Foundry திட்ட முகவரி
- `AZURE_AI_MODEL_DEPLOYMENT_NAME` - மாதிரி மேற்பார்வையின் பெயர் (எ.கா., gpt-4o)

**Azure AI Search** க்கு (பாடம் 05 - RAG):
- `AZURE_SEARCH_SERVICE_ENDPOINT` - Azure AI தேடல் முகவரி
- `AZURE_SEARCH_API_KEY` - Azure AI தேடல் API விசை

அங்கீகாரம்: நோட்டுப் புத்தகங்கள் இயக்குவதற்கு முன் `az login` ஓட்டவும் (`AzureCliCredential` பயன்படுத்துகிறது).
