# AGENTS.md

## திட்டம் பார்வை

இந்த சேமிப்பகம் "ஆரம்பக்காரர்களுக்கான AI முகவர்கள்" என்பதைக் கொண்டுள்ளது - AI முகவர்கள் உருவாக்க தேவையான அனைத்தையும் கற்பிக்கும் விரிவான கல்வி பாடநெறி. இந்த பாடநெறி 18 பாடங்கள் (எண்கள் 00-18) கொண்டுள்ளது, அடிப்படைகள், வடிவமைப்பு முறை, கட்டமைப்புகள், தயாரிப்பு செயல்படுத்தல், உள்ளூர்/சாதன முகவர்கள் மற்றும் AI முகவர்களின் பாதுகாப்பை உள்ளடக்கியது.

**முக்கிய தொழில்நுட்பங்கள்:**
- Python 3.12+
- இடையறாத கற்றலுக்கு Jupyter நோட்புக் கள்
- AI கட்டமைப்புகள்: Microsoft Agent Framework (MAF)
- Azure AI சேவைகள்: Microsoft Foundry, Microsoft Foundry Agent Service V2

**வடிவமைப்பு:**
- பாட அடிப்படையிலான அமைப்பு (00-18 கோப்புறைகள்)
- ஒவ்வொரு பாடத்திலும் உள்ளன: README ஆவணங்கள், குறியீடு மாதிரிகள் (Jupyter நோட்புக் கள்), மற்றும் படங்கள்
- தானாக மொழிபெயர்ப்புக்கான பல-மொழி உதவி
- Microsoft Agent Framework பயன்படுத்திய ஒரு Python நோட்புக் ஒவ்வொரு பாடத்திற்கும்

## அமைப்பு கட்டளைகள்

### முன்னுரிமைகள்
- Python 3.12 அல்லது அதற்கு மேல்
- Azure சந்தா (Microsoft Foundry க்கு)
- Azure CLI நிறுவப்பட்டு அனுமதிக்கபட்டது (`az login`)

### ஆரம்ப அமைப்பு

1. **சேமிப்பகத்தை கிளோன் அல்லது ஃபோர்க் செய்யவும்:**
   ```bash
   gh repo fork microsoft/ai-agents-for-beginners --clone
   # OR
   git clone https://github.com/microsoft/ai-agents-for-beginners.git
   cd ai-agents-for-beginners
   ```

2. **Python மெய்நிகர் சூழல் உருவாக்கி செயல்படுத்தவும்:**
   ```bash
   python3 -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   ```

3. **அதிரவைகளை நிறுவவும்:**
   ```bash
   pip install -r requirements.txt
   ```

4. **சூழல் மாறிலிகளை அமைக்கவும்:**
   ```bash
   cp .env.example .env
   # Edit .env with your API keys and endpoints
   ```

### தேவைப்படும் சூழல் மாறிலிகள்

**Microsoft Foundry** க்கு (தேவை):
- `AZURE_AI_PROJECT_ENDPOINT` - Microsoft Foundry திட்ட முடிவு முகவரி
- `AZURE_AI_MODEL_DEPLOYMENT_NAME` - வலைப்பின்னல் பெயர் (எ.கா., gpt-5-mini)

**Azure AI Search** க்கு (பாடம் 05 - RAG):
- `AZURE_SEARCH_SERVICE_ENDPOINT` - Azure AI Search முடிவு முகவரி
- `AZURE_SEARCH_API_KEY` - Azure AI Search API விசை

அனுமதி: நோட்புக் இயக்குவதற்கு முன் `az login` இயக்கு (இதில் `AzureCliCredential` பயன்படுத்தப்படுகிறது).

   - எப்பொழுதும் `.env` உருவாக்கவும் `.env.example` இருந்து
   - `.env` கோப்பை கமிட் செய்ய வேண்டாம் (அது `.gitignore` இல் உள்ளது)
   - விசையின்றி Entra ID அங்கீகாரத்துக்கு `az login` உடன் உள்நுழையவும்

3. **பொதி முரண்பாடுகள்:**
   - புதிய மெய்நிகர் சூழலைப் பயன்படுத்தவும்
   - தனித்தோறும் தொகுப்புகளுக்கு பதிலாக `requirements.txt` இருந்து நிறுவவும்
   - சில நோட்புக் களுக்கு கூடுதல் தொகுப்புகள் அவசியம் ஆகலாம்; அவை மார்க்டவுன் செல்களில் குறிப்பிடப்பட்டுள்ளன

4. **Azure சேவைகள்:**
   - Azure AI சேவைகளுக்கு செயலில் உள்ள சந்தா தேவை
   - சில அம்சங்கள் பிராந்திய-சார்ந்தவை
