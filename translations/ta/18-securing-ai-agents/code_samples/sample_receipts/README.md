# மாதிரி ரசீது ஏற்பாடுகள்

நோட்புக் இயக்காமல் ஆய்விற்கான மூன்று முற்பக்கத்தில் உருவாக்கப்பட்ட ரசீது கோப்புகள்.

| கோப்பு | அது என்ன |
|---|---|
| `01_valid_receipt.json` | `lookup_flights` கருவி அழைப்பு ஒன்றுக்கான சரியான ஒப்புவிக்கப்பட்ட ரசீது. சோதனை True ஐ நிச்சயிக்கிறது. |
| `02_tampered_receipt.json` | கையொப்பமிடப்பட்ட பிறகு ஒரு புலம் மாற்றப்பட்ட அதே ரசீது. சோதனை False ஐ நிச்சயிக்கிறது. |
| `03_chain_three_receipts.json` | மூன்று சரியான ரசீதுகளின் சங்கிலி (தேடல், பிடிப்பு, பதிவு) அடுத்ததுடன் `previous_receipt_hash` மூலம் இணைக்கப்பட்டவை. |

ஏற்பாடுகள் பayload இன் canonical JCS பைட்டுகளை நேரடியாக Ed25519 கொண்டு கையொப்பமிடுகின்றன.
SHA-256 உள்ளடக்க வடிகட்டல்கள் மற்றும் ரசீது-ச sling களுக்காக தொடர்ந்தும் பயன்படுத்தப்படுகின்றது, கையொப்பமிடுவதற்கு முன் மேலதிக முன்னிலை-ஹாஷ் ஆக அல்ல.


## மாதிரிகளை சரிபார்த்தல்

நோட்புக் நான்கு பிரிவுகளில் சரிபார்ப்பை விளக்குகிறது. இந்த ஏற்பாடுகளை அந்தக் கதைமூட்டாமல் நேரடியாக சரிபார்க்க:


```python
import json
from pathlib import Path

# Assumes you have completed the imports and helper functions
# from sections 1 and 2 of 18-signed-receipts.ipynb.

valid = json.loads(Path("01_valid_receipt.json").read_text())
print(f"Valid receipt: {verify_receipt(valid)}")        # True

tampered = json.loads(Path("02_tampered_receipt.json").read_text())
print(f"Tampered receipt: {verify_receipt(tampered)}")  # False

chain = json.loads(Path("03_chain_three_receipts.json").read_text())
for r in verify_chain(chain):
    print(f"  Receipt {r['index']} ({r['tool']}): {'VALID' if r['overall_valid'] else 'INVALID'}")
```

## தீரா JSON ஐ ஆய்வு செய்து மாணவர்கள் கற்றுக்கொள்ளும் விஷயங்கள்

துல்லியமான ரசீது வடிவமைப்பை வாசிப்பதால், நோட்புக் செல்களில் எப்போதும் கிடைக்காத உள்ளுணர்வு உருவாகிறது. JSON ஐ விரைவாக பார்ப்பவர்கள் சில விஷயங்களை கவனிக்கின்றனர்:


1. கையொப்பம் என்பது ஒரு மறைக்கப்பட்ட base64url தொடர், ஆனால் மற்ற எல்லா புலங்களும் நேரடியாக வாசிக்கக்கூடிய JSON ஆகும்.
   கையொப்பம் உள்ளடக்கத்தை கடவுச்செய்து விடவில்லை; அது அதற்கான சான்றிதழ் ஆகும்.
2. பரிசுத்தாளில் `public_key` நுழைக்கப்பட்டுள்ளது. ஆய்வாளர் வேறு எதையும் தேவையில்லை
   அதை சரிபார்க்க (தாவம் செய்யப்பட்ட விசை உண்மையில் அறிவிக்கப்பட்டவருக்கு சொந்தமானது என்ற நம்பிக்கையை கொண்டு)
   வெளியீட்டாளர்; அடையாள அட கட்டமைப்பை பற்றிய பாடம் README பார்க்கவும்).
3. எந்த ஒற்றை எழுத்தையும் மாற்றி, பின்னர் இந்த கோப்பை 
   `02_tampered_receipt.json` உடன் மீண்டும் ஒப்பிடுவது பைட் இரு நிலை செயலியை தெளிவாக்குகிறது.
