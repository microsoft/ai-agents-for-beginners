# பாடநெறி அமைத்தல்

## அறிமுகம்

இந்த பாடத்தில் இந்த பாடநெறியின் குறியீட்டு எடுத்துக்காட்டுகளை இயக்குவது எப்படி என்பது பற்றி காணலாம்.

## மற்ற மாணவர்களுடன் சேரவும் உதவி பெறவும்

உங்கள் ரெப்போவை கிளோன் செய்ய தொடங்குவதற்கு முன், எந்தவொரு அமைப்பு தொடர்பான உதவி, பாடநெறி குறித்த கேள்விகள், அல்லது மற்ற மாணவர்களுடன் தொடர்பு கொள்ள [AI Agents For Beginners Discord channel](https://aka.ms/ai-agents/discord)னை சேர்ந்துகொள்ளவும்.

## இந்த ரெப்போவை கிளோன் செய்யவோ அல்லது ஃபோர்க் செய்யவோ செய்க

தொடங்க, தயவுசெய்து GitHub களஞ்சியத்தை கிளோன் அல்லது ஃபோர்க் செய்யவும். இது உங்களுக்கு குறியீட்டை இயக்க, சோதிக்க மற்றும் திருத்த உங்கள் சொந்த பதிப்பை உருவாக்கும்!

இது <a href="https://github.com/microsoft/ai-agents-for-beginners/fork" target="_blank">ரெப்போவை ஃபோர்க் செய்ய</a> இணைப்பை கிளிக் செய்வதன் மூலம் செய்யலாம்

இப்போது உங்களிடம் கீழ்காணும் இணைப்பில் இந்த பாடநெறியின் உங்கள் சொந்த ஃபோர்க் பதிப்பு இருக்க வேண்டும்:

### எளியது கிளோன் (வரவிருக்கும் பட்டறை / Codespaces க்கு பரிந்துரை)

  > முழு களஞ்சியம் முழு வரலாற்றையும் அனைத்து கோப்புகளையும் பதிவிறக்கம் செய்யும் போது பெரியதாக (~3 GB) இருக்கலாம். நீங்கள் எவ்வளவு மட்டுமே பட்டறையில் பங்கேற்கிறீர்கள் அல்லது சில பாடக் கோப்புறைகள் மட்டுமே தேவைப்படுகின்றன என்றால், வரலாற்றை சுருக்கி அல்லது புலோபுகளை தவிர்த்து பெரும்பான்மையான பதிவிறக்கத்தை தவிர்க்க எளிய கிளோன் (அல்லது மெல்லிய கிளோன்) தேர்வு செய்யலாம்.

#### விரைவான எளிய கிளோன் — குறைந்த வரலாறு, அனைத்து கோப்புகளும்

கீழ் உள்ள கட்டளைகளில் `<your-username>` என்பதை உங்கள் ஃபோர்க் URL (அல்லது நீங்கள் விரும்பினால் மேலாளர் URL) மூலம் மாற்றவும்.

சமீபத்திய கமிட்ட வரலாற்றை மட்டும் கிளோன் செய்ய:

```bash|powershell
git clone --depth 1 https://github.com/<your-username>/ai-agents-for-beginners.git
```

குறிப்பிட்ட பிராஞ்சை கிளோன் செய்ய:

```bash|powershell
git clone --depth 1 --branch <branch-name> https://github.com/<your-username>/ai-agents-for-beginners.git
```

#### பகுதி (மெல்லிய) கிளோன் — குறைந்த புலோபுகள் + தேர்ந்தெடுக்கப்பட்ட கோப்புறைகள் மட்டுமே

இது பகுதி கிளோன் மற்றும் sparse-checkout பயன்படுத்துகிறது (Git 2.25+ தேவை மற்றும் பகுதி கிளோன் ஆதரவு உள்ள நவீன Git பரிந்துரை) :

```bash|powershell
git clone --depth 1 --filter=blob:none --sparse https://github.com/<your-username>/ai-agents-for-beginners.git
```

ரெப்போ கோப்புறைக்கு நுழையவும்:

```bash|powershell
cd ai-agents-for-beginners
```

பின்னர் நீங்கள் வேண்டிய கோப்புறைகளை குறிப்பிடுங்கள் (கீழுள்ள உதாரணம் இரண்டு கோப்புறைகளை காட்டுகிறது):

```bash|powershell
git sparse-checkout set 00-course-setup 01-intro-to-ai-agents
```

கிளோன் செய்து கோப்புகளை சரிபார்த்து நடந்த பிறகு, நீங்கள் கோப்புகள் மட்டுமே வேண்டும் மற்றும் இடம் விடுவிக்க விரும்பினால் (கிட் வரலாறு தேவை இல்லை), தயவுசெய்து களஞ்சிய மெட்டாடேட்டாவை அழிக்கவும் (💀மீட முடியாதது — அனைத்து Git செயல்பாடுகளையும் இழக்க விடும்: கமிட்கள், புல்கள், புஷ்கள் அல்லது வரலாறு அணுகல் இல்லை).

```bash
# zsh/bash
rm -rf .git
```

```powershell
# PowerShell
Remove-Item -Recurse -Force .git
```

#### GitHub Codespaces பயன்படுத்துதல் (உள்ளூர் பெரிய பதிவிறக்கங்களை தவிர்க்க பரிந்துரை)

- இந்த ரெப்போவுக்கு புதிய Codespace ஒன்றை [GitHub UI](https://github.com/codespaces) மூலம் உருவாக்கவும்.  

- புதிதாக உருவாக்கப்பட்ட Codespace இன் டெர்மினலில், நீங்கள் தேவையான பாடக் கோப்புறைகள் மட்டும் Codespace பணித்தளத்தில் கொண்டு வர மேலே உள்ள எளிய/மெல்லிய கிளோன் கட்டளைகளில் ஒன்றை இயக்கவும்.
- விருப்பத்தேர்வு: Codespaces இல் கிளோன் செய்த பிறகு, கூடுதல் இடத்தை மீட்டெடுக்க .git ஐ நீக்கவும் (மேலே நீக்கும் கட்டளைகளை காணவும்).
- குறிப்பு: Codespaces இல் ரெப்போவை நேரடியாக திறக்க விரும்பினால் (கூடுதல் கிளோன் இல்லாமல்), Codespaces வளர்ச்சிக் கருவி சூழலை கட்டமைக்கிறது மற்றும் உங்களுக்கு தேவையானதைவிட அதிகமானவற்றை வழங்கலாம். புதிய Codespace இல் எளிய நகலை கிளோன் செய்வது இடைவெளி பயன்பாட்டை மேலோட்டமாக கட்டுப்படுத்த உதவும்.

#### உதவிக்குறிப்புகள்

- நீங்கள் திருத்த/கமிட் செய்ய விரும்பினால் எப்போதும் கிளோன் URL ஐ உங்கள் ஃபோர்குடன் மாற்றவும்.
- பின்னர் நீங்கள் அதிக வரலாறு அல்லது கோப்புகள் தேவைப்படின், அவற்றை பெற அல்லது sparse-checkout ஐ மாற்றி கூடுதல் கோப்புறைகளை சேர்க்கலாம்.

## குறியீட்டை இயக்குதல்

இந்த பாடநெறி உங்கள் கைமுறையாக AI முகவர்களை கட்டமைப்பதற்கான அனுபவத்தை பெற Jupyter குறிப்பேடுகளின் தொடர் ஒன்றை வழங்குகிறது.

குறியீட்டு எடுத்துக்காட்டுகள் **Microsoft Agent Framework (MAF)** ஐ `FoundryChatClient` உடன் பயன்படுத்துகின்றன, இது **Microsoft Foundry** வழியாக **Microsoft Foundry Agent Service V2** (Responses API) உடன் இணைக்கிறது.

அனைத்து Python குறிப்பேடுகளும் `*-python-agent-framework.ipynb` என அடையாளம் செய்யப்படுகின்றன.


- **Azure CLI** — அங்கீகாரத்திற்கு தேவை. [aka.ms/installazurecli](https://aka.ms/installazurecli) இல் இருந்து நிறுவவும்.
- **Azure சந்தா** — Microsoft Foundry மற்றும் Microsoft Foundry Agent Service அடைவுக்கு.
- **Microsoft Foundry திட்டம்** — மேற்கோள் அளிக்கும் மாதிரி கொண்ட திட்டம் (எ.கா., `gpt-4o`). கீழே [படி 1](#படி-1-microsoft-foundry-திட்டம்-உருவாக்குதல்) காணவும்.

இந்த களஞ்சியத்தின் அடியில் `requirements.txt` கோப்பு உள்ளது, இதில் குறியீட்டு எடுத்துக்காட்டுகளை இயக்க தேவையான அனைத்து Python பாம்பாக்கள் உள்ளன.

அவற்றை நிறுவ நீங்கள் கீழ்காணும் கட்டளையை உங்கள் டெர்மினலில் இயக்கலாம்:

## Microsoft Foundry மற்றும் Microsoft Foundry Agent Service அமைத்தல்

### படி 1: Microsoft Foundry திட்டம் உருவாக்குதல்

குறிப்பேடுகளை இயக்க Microsoft Foundry **ஹப்** மற்றும் **திட்டம்** தேவையாகும்.

1. [ai.azure.com](https://ai.azure.com) செல்லவும் மற்றும் உங்கள் Azure கணக்கில் உள்நுழைக.
2. **ஹப்** உருவாக்கவும் (அல்லது ஏற்கனவே உள்ளதை பயன்படுத்தவும்). காணவும்: [Hub resources overview](https://learn.microsoft.com/azure/ai-foundry/concepts/ai-resources).
3. ஹப்பில் உள்ளே **திட்டம்** உருவாக்கவும்.
4. **Models + Endpoints** → **Deploy model** மூலம் ஒரு மாதிரியை (எ.கா., `gpt-4o`) இயக்கவும்.

### படி 2: உங்கள் திட்ட முகவரி மற்றும் மாதிரி பெயரை பெறுதல்

Microsoft Foundry போர்டலில் உங்கள் திட்டத்திலிருந்து:

- **திட்ட முகவரி** — **Overview** பக்கத்திற்கு சென்று முகவரி URL ஐ நகலெடுக்கவும்.

![Project Connection String](../../../translated_images/ta/project-endpoint.8cf04c9975bbfbf1.webp)

- **மாதிரி இயக்கும் பெயர்** — **Models + Endpoints**க்கு சென்று உங்கள் இயக்கப்பட்ட மாதிரியை தேர்ந்தெடுத்து **Deployment name** (எ.கா., `gpt-4o`) நோட்டுப் படுத்தவும்.

### படி 3: `az login` மூலம் Azure க்கு உள்நுழையவும்

அனைத்து குறிப்பேடுகளும் அங்கீகாரத்திற்கு **`AzureCliCredential`** பயன்படுத்துகின்றன — API விசைகள் நிர்வகிக்க தேவையில்லை. இதற்காக Azure CLI மூலம் உள்நுழையவேண்டும்.

1. **Azure CLI ஐ நிறுவவும்** (நீங்கள் ஏற்கனவே நிறுவவில்லையெனில்): [aka.ms/installazurecli](https://aka.ms/installazurecli)

2. **உள்நுழைய** கீழ்காணும் கட்டளையை இயக்கவும்:

    ```bash|powershell
    az login
    ```

    அல்லது உங்களிடம் உலாவி இல்லாத தொலைநிலை/Codespace சூழல் இருந்தால்:

    ```bash|powershell
    az login --use-device-code
    ```

3. **உங்கள் சந்தாவை தேர்ந்தெடுக்கவும்** (அன்புறுத்தப்படின்) — உங்கள் Foundry திட்டத்தை கொண்டாடுமான ஒன்றை தேர்வு செய்யவும்.

4. **உள்நுழைவதை உறுதி செய்ய**:

    ```bash|powershell
    az account show
    ```

> **ஏன் `az login`?** குறிப்பேடுகள் `azure-identity` தொகுப்பின் `AzureCliCredential`ஐ பயன்படுத்தி அங்கீகாரப்படுத்துகின்றன. அதனால் உங்கள் Azure CLI அமர்வு அங்கீகாரங்களை வழங்குகிறது — உங்கள் `.env` கோப்பில் API விசைகள் அல்லது ரகசியங்கள் தேவையில்லை. இது ஒரு [பாதுகாப்பு சிறந்த நடைமுறை](https://learn.microsoft.com/azure/developer/ai/keyless-connections).


## பாடம் 5 க்கு கூடுதல் அமைப்பு (Agentic RAG)

பாடம் 5 **Azure AI Search**ஐ பயன்படுத்துகிறது retrieval-augmented generation க்காக. நீங்கள் அந்த பாடத்தை இயக்கு முனைவின் போது கீழ்காணும் மாறிகளை `.env` கோப்பில் சேர்க்கவும்:

| மாறி | எங்கே கண்டறியலாம் |
|----------|-----------------|
| `AZURE_SEARCH_SERVICE_ENDPOINT` | Azure போர்டல் → உங்கள் **Azure AI Search** வளம் → **Overview** → URL |
| `AZURE_SEARCH_API_KEY` | Azure போர்டல் → உங்கள் **Azure AI Search** வளம் → **Settings** → **Keys** → பிரதான நிர்வாக விசை |

## நேரடியாக Azure OpenAI ஐ அழைக்கும் பாடங்களுக்கு கூடுதல் அமைப்பு (பாடங்கள் 6 மற்றும் 8)

சில குறிப்பேடுகள் பாடங்கள் 6 மற்றும் 8ல் நேரடியாக **Azure OpenAI** (Responses API பயன்படுத்தி) அழைக்கின்றன Microsoft Foundry திட்டத்தின் மூலம் செல்லாமல். இந்த எடுத்துக்காட்டுகள் முந்தைய காலத்தில் GitHub Models பயன்படுத்தியுள்ளன, அது முற்றிலும் நிறுத்தப்படுமே (ஜூலை 2026லிருந்து) மற்றும் Responses API க்குப் பொருந்தாது. நீங்கள் அந்த எடுத்துக்காட்டுகளை இயக்க திட்டமிட்டால், கீழ்காணும் மாறிகளை `.env` கோப்பில் சேர்க்கவும்:

| மாறி | எங்கே கண்டறியலாம் |
|----------|-----------------|
| `AZURE_OPENAI_ENDPOINT` | Azure போர்டல் → உங்கள் **Azure OpenAI** வளம் → **Keys and Endpoint** → முகவரி (எ.கா., `https://<your-resource>.openai.azure.com`) |
| `AZURE_OPENAI_DEPLOYMENT` | உங்கள் இயக்கப்பட்ட மாதிரியின் பெயர் (எ.கா., `gpt-4o-mini`) Responses API க்கு ஆதரவானது |
| `AZURE_OPENAI_API_KEY` | விருப்பதன்மையானது — நீங்கள் விசை அடிப்படையுடைய அங்கீகாரத்தை பயன்படுத்தினால் மட்டுமே, `az login` / Entra ID அல்லாமல் |

> Responses API நிலையான `/openai/v1/` முகவரியை பயன்படுத்துகிறது, ஆகவே `api-version` தேவையில்லை. விசையின்றி Entra ID அங்கீகாரத்திற்கு `az login` மூலம் உள்நுழையவும்.

## மாற்று தொளர்: MiniMax (OpenAI-உடன் பொருந்தக்கூடியது)

[MiniMax](https://platform.minimaxi.com/) OpenAI உடன் பொருந்தக்கூடிய API மூலம் பெரிய பரிமாண மாதிரிகள் (முதலில் 204K டோகன்கள் வரை) வழங்குகிறது. Microsoft Agent Framework இன் `OpenAIChatClient` எந்த OpenAI உடன் பொருந்தக்கூடிய முகவரியுடன் செயல்படுவதால், Azure OpenAI அல்லது OpenAIக்கு மாற்றாக MiniMax ஐ பயன்படுத்தலாம்.

இந்த மாறிகளைக் `.env` கோப்பில் சேர்க்கவும்:

| மாறி | எங்கே கண்டறியலாம் |
|----------|-----------------|
| `MINIMAX_API_KEY` | [MiniMax Platform](https://platform.minimaxi.com/) → API விசைகள் |
| `MINIMAX_BASE_URL` | பயன்படுத்த `https://api.minimax.io/v1` (இசையான மதிப்பு) |
| `MINIMAX_MODEL_ID` | பயன்படுத்தும் மாதிரி பெயர் (எ.கா., `MiniMax-M3`) |

**உதாரண மாதிரிகள்**: `MiniMax-M3` (பரிந்துரைக்கப்பட்டது), `MiniMax-M2.7`, `MiniMax-M2.7-highspeed` (வேகமான பதில்கள்). மாதிரி பெயர்கள் மற்றும் கிடைக்கும் தன்மை காலமுறைகளில் மாறக்கூடும், மற்றும் குறிப்பிட்ட மாதிரிக்கு அணுகல் உங்கள் கணக்கு அல்லது பிராந்தியத்தின் அடிப்படையில் இருக்கலாம் — தற்போதைய பட்டியலுக்கு [MiniMax Platform](https://platform.minimaxi.com/) சேதத்தை பார்க்கவும். `MiniMax-M3` உங்கள் கணக்கிற்கு கிடைக்கவில்லையெனில், நீங்கள் அணுகக்கூடிய மாதிரியை `MINIMAX_MODEL_ID` ஆக அமைக்கவும் (எ.கா., `MiniMax-M2.7`).

`OpenAIChatClient` பயன்படுத்தும் குறியீட்டு எடுத்துக்காட்டுகள் (எ.கா., பாடம் 14 ஹோட்டல் முன்பதிவு வேலைத் தொகுப்பு) `MINIMAX_API_KEY` அமைக்கப்படும்போது தானாக உங்கள் MiniMax கட்டமைப்பைப் பிரிந்து பயன்படுத்தும்.

## மாற்று தொளர்: Foundry Local (மாதிரிகளை உலோகத்தில் இயக்குதல்)

[Foundry Local](https://foundrylocal.ai) என்பது முழுக்க உங்கள் இயந்திரத்தில் மட்டும் OpenAI உடன் பொருந்தக்கூடிய API மூலம் மொழி மாதிரிகளை பதிவிறக்கம், நிர்வகித்து பராமரிக்கும் லைட்ட்வெய்ட் ஓட்டை நேரடி ரன்டைம் ஆகும் — மேகமும், Azure சந்தாவும், அல்லது API விசைகளும் தேவையில்லை. இது ஆன்லைன் அல்லாமல் தொழில்துறையில், மேகச் செலவுகளை தவிர்ப்பதற்கான முயற்சியில், அல்லது தரவை இயந்திரத்தில் வைத்துக்கொள்ள சிறந்த விருப்பமாகும்.

Microsoft Agent Framework இன் `OpenAIChatClient` எந்த OpenAI-உடன் பொருந்தக்கூடிய முகவரியுடன் செயல்படுவதால், Foundry Local ஒரு உள்ளூர் மாற்று ஆகும் Azure OpenAIக்காக.

**1. Foundry Local ஐ நிறுவுக**

```bash
# விண்டோஸ்
winget install Microsoft.FoundryLocal

# மேக் ஓஎஸ்
brew install foundrylocal
```

**2. ஒரு மாதிரியை பதிவிறக்கம் செய்து இயக்குக** (இது உள்ளூர் சேவையை ஆரம்பிக்கும்):

```bash
foundry model list          # பயன்படுத்தக்கூடிய மாடல்களை பார்க்கவும்
foundry model run phi-4-mini
```

**3. உள்ளூர் முகவரியை கண்டறிய பயன்படுத்தப்படும் Python SDK ஐ நிறுவுக:**

```bash
pip install foundry-local-sdk
```

**4. Microsoft Agent Framework ஐ உங்கள் உள்ளூர்மாதிரிக்கு குறிக்கவும்:**

```python
from foundry_local import FoundryLocalManager
from agent_framework.openai import OpenAIChatClient

# தேவையானால் பதிவிறக்கம் செய்து, மாடலை உள்ளூர் சேவையகத்தில் வழங்கி, பின்னர் எண்ட்பாயிண்ட்/போர்ட்டை கண்டுபிடிக்கிறது.
manager = FoundryLocalManager("phi-4-mini")

chat_client = OpenAIChatClient(
    base_url=manager.endpoint,      # உதாரணம் http://localhost:<port>/v1
    api_key=manager.api_key,        # Foundry Localஇற்கான எப்போதும் "தேவை இல்லை"
    model_id=manager.get_model_info("phi-4-mini").id,
)

agent = chat_client.as_agent(
    name="LocalAgent",
    instructions="You are a helpful assistant running fully on-device.",
)
```

> **குறிப்பு:** Foundry Local ஒரு OpenAI உடன் பொருந்தக்கூடிய **Chat Completions** முகவரியை வெளிப்படுத்துகிறது. உள்ளூர் வளர்ச்சி மற்றும் ஆன்லைன் அல்லாத சூழல்களுக்கு இதைப் பயன்படுத்தவும். முழுமையான **Responses API** அம்சங்களுக்காக (நிலையான உரையாடல்கள், ஆழமான கருவி ஒருங்கிணைப்பு மற்றும் முகவர் முறை வளர்ச்சி), பாடங்களில் காட்டியபடி **Azure OpenAI** அல்லது **Microsoft Foundry** திட்டத்தை இலக்கு செய்யவும். தற்போதைய மாதிரி பட்டியல் மற்றும் தள ஆதரிக்கான [Foundry Local ஆவணம்](https://foundrylocal.ai) பார்க்கவும்.

## பாடம் 8 க்கான கூடுதல் அமைப்பு (Bing Grounding Workflow)


பாடம் 8 இல் உள்ள நிபந்தனை அடிப்படையிலான வேலைப்பாட்டுப் புத்தகத்தில் மைக்ரோசாப்ட் ஃபவுண்ட்ரி மூலம் **பிங் கிரவுண்டிங்** பயன்படுத்தப்படுகிறது. நீங்கள் அந்த மாதிரியை இயக்க திட்டமிட்டிருந்தால், உங்கள் `.env` கோப்பில் இந்த மாறியை சேர்க்கவும்:

| மாறி | எங்கு காண்பது |
|----------|-----------------|
| `BING_CONNECTION_ID` | Microsoft Foundry போர்டல் → உங்கள் திட்டம் → **கையாளும் பகுதி** → **இணைக்கப்பட்ட வளங்கள்** → உங்கள் பிங் இணைப்பு → இணைப்பு ஐடியை நகலெடு |

## பிரச்சினை தீர்க்கும் வழிகள்

### macOS-இல் SSL சான்றிதழ் சரிபார்ப்பு பிழைகள்

நீங்கள் macOS-இல் இருந்தால் மற்றும் பின்வருவோர் போன்ற பிழையை சந்தித்தால்:

```plaintext
ssl.SSLCertVerificationError: [SSL: CERTIFICATE_VERIFY_FAILED] certificate verify failed: self-signed certificate in certificate chain
```

இது macOS-இல் பைத்தான் தொடர்பான அறிந்த பிரச்சினையாகும், அங்கு கணினி கணினி SSL சான்றிதழ்கள் தானாக நம்பப்பட்டு வராது. கீழ்க்கண்ட தீர்வுகளை வரிசையாக முயற்சிக்கவும்:

**விருப்பம் 1: பைத்தானின் Install Certificates ஸ்கிரிப்ட்டை இயக்கவும் (பரிந்துரைக்கப்படுகிறது)**

```bash
# உங்கள் நிறுவிய Python பதிப்பை (உதா., 3.12 அல்லது 3.13) 3.XX மூலம் மாற்றுக:
/Applications/Python\ 3.XX/Install\ Certificates.command
```

**விருப்பம் 2: உங்கள் நோட்புக்கில் `connection_verify=False` பயன்படுத்தவும் (GitHub மாடல்களுக்கு மட்டுமே)**

பாடம் 6 நோட்புக்கில் (`06-building-trustworthy-agents/code_samples/06-system-message-framework.ipynb`), கருத்திடப்பட்ட ஒரு வழியுண்டு ஏற்கனவே சேர்க்கப்பட்டுள்ளது. கிளையண்ட் உருவாக்கும்போது `connection_verify=False` பகுதியை கருத்திடாத நிலையில் மாற்றவும்:

```python
client = ChatCompletionsClient(
    endpoint=endpoint,
    credential=AzureKeyCredential(token),
    connection_verify=False,  # உங்களுக்கான சான்றிதழ் பிழைகள் ஏற்பட்டால் SSL சரிபார்ப்பை முடக்கு
)
```

> **⚠️ எச்சரிக்கை:** SSL சரிபார்ப்பை அணைத்தல் (`connection_verify=False`) சான்றிதழ் சரிபார்ப்பை தவிர்த்து பாதுகாப்பை குறைக்கும். இது மேம்பாட்டு சூழலில் தற்காலிகமாக மட்டுமே பயன்படுத்தவும், உற்பத்தியில் எப்போதும் பயன்படுத்த வேண்டாம்.

**விருப்பம் 3: `truststore` ஐ நிறுவி பயன்படுத்தவும்**

```bash
pip install truststore
```

பிறகு எந்த ஒரு நெட்வொர்க்கு அழைப்புகளை செய்வதற்கு முன் உங்கள் நோட்புக் அல்லது ஸ்கிரிப்ட்டின் மேல் பின்வருமாறு சேர்க்கவும்:

```python
import truststore
truststore.inject_into_ssl()
```
