# பங்களிப்பு செய்யல்

இந்த திட்டம் பங்களிப்புகள் மற்றும் பரிந்துரைகளை வரவேற்கிறது. பெரும்பாலான பங்களிப்புகள், நீங்கள் பங்களிப்பை பயன்படுத்த எங்களுக்கு உரிமைகள் வழங்குவதற்கு உரிமையுள்ளீர்கள் மற்றும் உண்மையில் வழங்குகிறீர்கள் என்று கூறும் பங்களிப்பாளர் உரிமம் ஒப்பந்தத்துக்கு (CLA) ஒப்புக்கொள்வது அவசியமாகிறது. விவரங்களுக்கு, <https://cla.opensource.microsoft.com> சென்று பாருங்கள்.

நீங்கள் ஒரு புல் ரெக்குவெஸ்ட் சமர்ப்பிக்கும் போது, ஒரு CLA பாஸ் தானாகவே நீங்கள் CLA அளிக்க வேண்டுமா என்பதை தீர்மானித்து, புல் ரெக்குவெஸ்ட்டை பொருத்தமாக சீரமைக்கும். பாஸ் வழங்கிய வழிமுறைகளை பின்பற்றவும். Microsoft CLA பயன்படுத்தும் ரெப்போசிடரிகளுக்கு ஒருமுறை இந்த காரியம் செய்யவேண்டும்.

## நடத்தை விதிகள்

இந்த திட்டம் [Microsoft Open Source Code of Conduct](https://opensource.microsoft.com/codeofconduct/)ஐ ஏற்றுக்கொண்டுள்ளது. மேலதிக தகவலுக்கு, [Code of Conduct FAQ](https://opensource.microsoft.com/codeofconduct/faq/) பார்க்கவும் அல்லது மேலதிக கேள்விகள் அல்லது கருத்துக்களுக்கு [opencode@microsoft.com](mailto:opencode@microsoft.com) தொடர்பு கொள்ளவும்.

## புல் ரெக்குவெஸ்ட் வழிகாட்டிகள்

- ஒவ்வொரு புல் ரெக்குவெஸ்ட் ஒரு கருத்தோடு கவனமாக இருக்க வேண்டும்.
- சமர்ப்பிப்பதற்கு முன் பாதிக்கப்பட்ட நோட்புக் மற்றும் குறியீட்டு உதாரணங்களை சோதனை செய்யவும்.
- ஒரு உதாரணத்தைச் சேர்க்கும் அல்லது மாற்றும் போது தொடர்புடைய பாடக் குறிப்புகளைப் புதுப்பிக்கவும்.
- ஆங்கில ಮೂಲ உள்ளடக்கத்தையேத் திருத்தவும். மொழிபெயர்ப்புகள் தானியங்கி மொழிபெயர்ப்பு வேலைநிலையால் பராமரிக்கப்படுகின்றன.
- கடவுச்சொற்கள், `.env` கோப்புகள், தற்காலிகக் கோப்புகள் அல்லது உருவாக்கப்பட்ட மேம்பாட்டு பொருட்களை கமிட் செய்யாதீர்கள்.

## தொகுப்புரு வரம்பும் மூன்றாம் தரப்பு பொருட்கள்

இந்த பாடத்திட்டம் Microsoft தொழில்நுட்பங்களும் விற்பனையாளருக்கு சாராத திறந்த தரநிலைகளும் மீது கவனம் செலுத்துகிறது. பங்களிப்புகள் தெளிவான கல்வி நோக்கத்துடன் இருக்க வேண்டும் மற்றும் மூன்றாம் தரப்பு வர்த்தகப் பொருள், முகாம்படுத்தப்படும் சேவை, மாதிரி ரூட்டர், SDK, MCP சர்வர் அல்லது வேறு விற்பனையாளர் சார்ந்த ஆஃபரிங் அறிமுகம் செய்ய அல்லது ஊக்குவிக்க இல்லாமல் இருக்க வேண்டும்.

திறந்த மூல மென்பொருள் மற்றும் மூன்றாம் தரப்பு சார்புகள் திறந்த தரநிலை அல்லது இடைசேர்க்கை சூழலின் விளக்கத்திற்கு அவசியமான போது மட்டும் குறிப்பிடப்படலாம், நியாயமான முறையில் வழங்கப்பட வேண்டும், விற்பனையாளரின் பொருள் அல்லது முகாம்படுத்தப்படும் இறுதி புள்ளிக்கு மையமாக இருக்கக்கூடாது. உங்கள் பங்களிப்பு விற்பனையாளர் சார்ந்த பொருள் அல்லது சேவையை உள்ளடக்கியால், ஒரு விடயத்தை திறக்கவும் மற்றும் புல் ரெக்குவெஸ்ட் சமர்ப்பிப்பதற்கு முன் பராமரிப்பவன் ஒப்புதல் பெறவும்.

பங்களிப்பாளர்கள் தங்களின் பங்களிப்பில் குறிப்பிடப்பட்ட பொருள் அல்லது சேவையுடன் தொடர்புடைய வேலைவாய்ப்பு, உரிமை, ஆதரவு அல்லது பிற தொடர்புகளை வெளிப்படுத்த வேண்டும். ஆதரவு இல்லாத விலை, செயல்திறன், பாதுகாப்பு, தனியுரிமை அல்லது ஒப்பீட்டு கூற்றுகளை உள்ளடக்க கூடாது. இயங்கக்கூடிய உதாரணங்கள் கண்காணிப்பாளர் தரவுகளை பரிமாறாதவோ அல்லது இயல்பாக வெளிப்புற மூன்றாம் தரப்பு சேவையினூடாக பொது நடவடிக்கைகள் செய்யாதவோ ஆக இருக்க வேண்டும்.
