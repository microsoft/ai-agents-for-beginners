## 🌱 துவக்கம்

இந்த பாடநெறி எய்ஐ முகவர்கள் உருவாக்க அடிப்படைகளை உள்ளடக்கிய பாடங்களை கொண்டுள்ளது. ஒவ்வொரு பாடமும் தனித்தென தலைப்பைக் கொண்டிருப்பதால் நீங்கள் விரும்பிய இடத்திலிருந்து தொடங்கலாம்!

இந்த பாடநெறிக்குப் பன்மொழி ஆதரவு உள்ளது. எங்கள் [கிடைக்கும் மொழிகள் இங்கே](#-multi-language-support) பார்க்கவும்.

உங்களது முதன்முறையாக உருவாக்கும் Generative AI மாதிரிகளுடன் பணியாற்றினால், [Generative AI For Beginners](https://aka.ms/genai-beginners) பாடநெறியை பார்க்கவும், இதில் GenAI உடன் உருவாக்க 21 பாடங்கள் உள்ளன.

இந்த சேமிப்பகத்துக்கு [ஸ்டார் (🌟) அளிப்பதையும்](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst) [Fork செய்யவும்](https://github.com/microsoft/ai-agents-for-beginners/fork) குறியீட்டை இயக்க.

### பிற பயனாளர்களை மாலை நக்காணுங்கள், உங்கள் கேள்விகளுக்கு பதில்கள் பெறுங்கள்

எய்ஐ முகவர்களை உருவாக்கி இருக்கையில் சிக்கல் ஏற்படுமானால் அல்லது ஏதேனும் கேள்விகள் உண்டானால், [Microsoft Foundry Discord](https://aka.ms/ai-agents/discord) இல் உள்ள நமது ஒதுக்கப்பட்ட Discord சேனலில் சேருக.

### உங்களுக்கு தேவை

இந்த பாடநெறி ஒவ்வொரு பாடத்திலும் குறியீட்டு உதாரணங்கள் உள்ளன, அவை code_samples கோப்பகத்தில் காணலாம். நீங்கள் இந்த சேமிப்பகத்தை [Fork செய்து](https://github.com/microsoft/ai-agents-for-beginners/fork) உங்கள் சொந்த நகலை உருவாக்கலாம்.  

இந்த பயிற்சிகளுக்கு உள்ள குறியீடு உதாரணங்கள் Microsoft Agent Framework மற்றும் Microsoft Foundry Agent Service V2 பயன்படுத்துகிறது:

- [Microsoft Foundry](https://aka.ms/ai-agents-beginners/ai-foundry) - Azure கணக்கு தேவை

இந்த பாடநெறி Microsoft வழங்கும் பின்வரும் AI முகவர் கட்டமைப்புகள் மற்றும் சேவைகளை பயன்படுத்துகிறது:

- [Microsoft Agent Framework (MAF)](https://aka.ms/ai-agents-beginners/agent-framework)
- [Microsoft Foundry Agent Service V2](https://aka.ms/ai-agents-beginners/ai-agent-service)

சில குறியீடு உதாரணங்கள் OpenAI-ஐ பின்பற்றும் வேறு வழங்குநர்களை, உதாரணமாக மிகப்பெரிய பார்வை கொண்ட மாதிரிகள் (204K டோக்கன்கள் வரை) வழங்கும் [MiniMax](https://platform.minimaxi.com/) போன்றவற்றையும் ஆதரிக்கின்றன. அமைப்புக்கான விவரங்களுக்கு [Course Setup](./00-course-setup/README.md) பார்க்கவும்.

இந்த பாடநெறிக்கான குறியீடு இயக்குவதற்கான மேலதிக தகவலுக்கு [Course Setup](./00-course-setup/README.md) பார்க்கவும்.
