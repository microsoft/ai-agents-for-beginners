>
> **CMD (Windows):**
> ```cmd
> git clone --filter=blob:none --sparse https://github.com/microsoft/ai-agents-for-beginners.git

> git sparse-checkout set --no-cone "/*" "!translations" "!translated_images"
> ```

## 🌱 துவக்கம்

இந்த பாடத்திட்டத்தில் AI முகவரிகள் கட்டுமானத்தின் அடிப்படைகளை உள்ளடக்கிய பாடங்கள் உள்ளன. ஒவ்வொரு பாடமும் தனிப்பட்ட தலைப்பை கையாள்கிறது, ஆகவே உங்கள் விருப்பப்படி எங்கு வேண்டுமானாலும் துவங்குங்கள்!

இந்த பாடத்திட்டத்திற்கு பல்மொழி ஆதரவு உள்ளது. எங்கள் [இங்கு கிடைக்கும் மொழிகள்](#-multi-language-support) காணவும்.

இது உங்கள் முதல் முறையாக உருவாக்கும் Generative AI மாதிரிகள் கட்டுமானமாக இருந்தால், எங்கள் [துவக்கத்துக்கான Generative AI](https://aka.ms/genai-beginners) பாடத்திட்டத்தை பார்க்கவும், இதில் GenAI கொண்டு கட்டுமானம் செய்வது குறித்த 21 பாடங்கள் உள்ளன.

இந்த ரெப்போவை [நட்சத்திரம் (🌟) செய்ய மறக்காமல்](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst) மற்றும் [கிளோன் செய்யவும்](https://github.com/microsoft/ai-agents-for-beginners/fork), குறியீட்டை இயக்க.

### மற்ற கற்றித்தலைவர்களை சந்திக்கவும், உங்கள் கேள்விகளுக்கு பதில் பெறவும்

நீங்கள் திண்டாட்டமாக இருந்தால் அல்லது AI முகவரிகள் பற்றிய கேள்விகள் இருந்தால், எங்கள் [Microsoft Foundry Discord](https://aka.ms/ai-agents/discord) என்பதில் உள்ள நியமிக்கப்பட்ட Discord சேனலில் சேர்ந்திடவும்.

### தேவையானவை

இந்த பாடத்திட்டத்தின் ஒவ்வொரு பாடத்திலும் குறியீட்டு எடுத்துக்காட்டுகள் உள்ளன, அவை code_samples என்ற கோப்புறையில் உள்ளன. நீங்கள் [இந்த ரெப்போவை கிளோன் செய்யலாம்](https://github.com/microsoft/ai-agents-for-beginners/fork) உங்கள் சொந்த көшியை உருவாக்க.

இந்த பயிற்சி குறியீட்டு எடுத்துக்காட்டுகளில் Microsoft Agent Framework மற்றும் Microsoft Foundry Agent Service V2 உபயோகிக்கப்படுகிறது:

- [Microsoft Foundry](https://aka.ms/ai-agents-beginners/ai-foundry) - Azure கணக்கு தேவை

இந்த பாடத்திட்டத்தில் Microsoft வழங்கும் பின்வரும் AI முகவர் கட்டமைப்புகளும் சேவைகளும் பயன்படுத்தப்படுகின்றன:

- [Microsoft Agent Framework (MAF)](https://learn.microsoft.com/agent-framework/overview/)
- [Microsoft Foundry Agent Service V2](https://aka.ms/ai-agents-beginners/ai-agent-service)

சில குறியீட்டு எடுத்துக்காட்டுகள் OpenAI-போன்ற பிரதிநிதிகளான [MiniMax](https://platform.minimaxi.com/) போன்ற மாற்று வழங்குநர்களையும் ஆதரிக்கின்றன, இது பெரிய உள்ளடக்க மாதிரிகள் (204K டோகன்களுக்குப் புறம்பாக) வழங்குகிறது. கட்டமைப்பு விவரங்களுக்கு [பாடத்திட்ட அமைப்பு](./00-course-setup/README.md) பார்க்கவும்.

இந்த பாடத்திட்ட குறியீட்டை இயக்குவதற்கான மேலதிகத் தகவலுக்கு, [பாடத்திட்ட அமைப்பு](./00-course-setup/README.md) பார்க்கவும்.
