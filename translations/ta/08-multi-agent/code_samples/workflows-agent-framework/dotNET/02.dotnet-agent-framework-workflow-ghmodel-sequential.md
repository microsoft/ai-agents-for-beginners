# ⏩ Azure OpenAI (Responses API) உடன் தொடர் முகவர் பணிநிரலாக்கங்கள் (.NET)

## 📋 மேம்பட்ட தொடர் செயலாக்க கையேடு

இந்த நோட்புக் Microsoft Agent Framework மற்றும் Azure OpenAI (Responses API) ஐ பயன்படுத்தி **தொடர் பணிநிரல் முறைமைகள்** பற்றி விளக்குகிறது. முகவர்கள் குறிப்பிட்ட வரிசையில் செயல்பட்டு, முன்னைய கட்டத்தின் முடிவுகளின் அடிப்படையில் அடுத்த கட்டம் செயல்படும், அதாவது படிப்படியாக கையாளும் செயல்முறைகளைக் கட்டமைக்க நீங்கள் கற்றுக்கொள்வீர்கள்.

## 🎯 கற்றல் நோக்கங்கள்

### 🔄 **தொடர் செயலாக்க கட்டமைப்பு**
- **நெளிப்படையான பணிநிரல் வடிவமைப்பு**: தெளிவான சார்புகளை கொண்ட படிப்படியாக செயலாக்க குழாய்கள் உருவாக்குதல்
- **நிலை மேலாண்மை**: தொடர்வழக்க பணிநிரல் கட்டங்களில் நிலை மற்றும் தரவு ஓட்டத்தை பராமரித்தல்
- **Azure OpenAI (Responses API)**: பல கட்ட .NET பணிநிரல்களில் Azure OpenAI மாதிரிகளை பயன்படுத்துதல்
- **உற்பத்தி குழாய் வடிவங்கள்**: தயாரிப்பிற்கு ஏற்ப தொடர் செயலாக்க அமைப்புகளை உருவாக்குதல்

### 🏗️ **மேம்பட்ட தொடர் வடிவங்கள்**
- **கட்ட பதிவு செயலாக்கம்**: பணிநிரல் கட்டங்களுக்கிடையில் சரிபார்ப்பு புள்ளிகளை நிறைவேற்றுதல்
- **சூழல் பராமரிப்பு**: அனைத்து கட்டங்களிலும் நிலை மற்றும் சேகரிக்கப்பட்ட அறிவை பராமரித்தல்
- **பிழை பரவல்**: தொடர் செயலாக்க சங்கிலிகளில் தவறுகளை மெதுவாக கையாளல்
- **செயல்திறன் மேம்பாடு**: குறைந்த உபரி செலவுடன் திறம்பட தொடர் செயல்பாடு

### 🏢 **எண்டர்ப்ரைஸ் தொடர் செயலிகள்**
- **ஆவணம் செயலாக்க குழாய்**: பல கட்ட ஆவண பகுப்பு, மாற்றம் மற்றும் சரிபார்ப்பு
- **தர உறுதிப்பாடு பணிநிரல்கள்**: தொடர் மதிப்பாய்வு, சரிபார்ப்பு மற்றும் அங்கீகார நடவடிக்கைகள்
- **உள்ளடக்கம் உற்பத்தி குழாய்**: ஆராய்ச்சி → எழுத்து → திருத்தம் → மதிப்பாய்வு → வெளியீடு
- **வியாபார செயல்முறை தானியங்கி**: தெளிவான கட்ட சார்புகளுடன் பல படி வியாபார பணிநிரல்கள்

### 🔑 **Azure OpenAI அமைப்பு**

**சூழல் அமைப்பு (.env கோப்பு):**
```env
AZURE_OPENAI_ENDPOINT=https://<your-resource>.openai.azure.com
AZURE_OPENAI_DEPLOYMENT=gpt-4o-mini
```

**அமைப்பு மேலாண்மை:**
```csharp
// Load environment variables securely
Env.Load("../../../.env");
var azureEndpoint = Environment.GetEnvironmentVariable("AZURE_OPENAI_ENDPOINT");

```

### 🎯 யഥார்த்த பயன்பாடுகள்

- **விமா**: க்ளைம் பகுப்பாய்வு → மதிப்பீடு → மேற்கோள் உருவாக்கம்
- **உள்ளடக்கம் உருவாக்கம்**: ஆராய்ச்சி → எழுத்து → திருத்தம் → வெளியீடு

### 🔍 நிலை ஓட்டத்தை அறிதல்

தொடரில் ஒவ்வொரு முகவரும் பெறுவது:
- **மூலம் உள்ளீடு**: ஆரம்ப பயனர் செய்தி (படம் + உரை)
- **முந்தைய முகவர் வெளியீடுகள்**: உரையாடல் வரலாற்றில் முன்னர் பங்கு பெற்ற அனைத்து முகவர் பதில்களும்
