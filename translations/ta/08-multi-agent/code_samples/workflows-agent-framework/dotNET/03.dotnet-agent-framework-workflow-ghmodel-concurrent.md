# ⚡ Azure OpenAI (Responses API) உடன் ஒரே நேரத்தில் செயல்படும் முகவர் பணித் திட்டங்கள் (.NET)

## 📋 உயர் செயல்திறன் இணை செயலாக்க பயிற்சி

இந்த நோட்ட்புக் Microsoft Agent Framework for .NET மற்றும் Azure OpenAI (Responses API) ஐ பயன்படுத்தி **ஒன்றோடு ஒன்றாக நடக்கும் பணித் திட்ட வடிவமைப்புகளை** காண்பிக்கிறது. ஒரே நேரத்தில் பல AI முகவரிகளை இயக்கி ஒருங்கிணைப்பு மற்றும் தரவு நிலைத்தன்மையை பராமரித்துக் கொண்டே அதிகப்படியான உற்பத்தியை அதிகரிக்கும் உயர் செயல்திறன், இணை செயலாக்க பணித் திட்டங்களை எவ்வாறு உருவாக்கலாம் என்பதை நீங்கள் கற்றுக்கொள்ளப்போகிறீர்கள்.

## 🎯 கற்றல் நோக்கங்கள்

### 🚀 **ஒரே நேரத்தில் செயலாக்க அடிப்படைகள்**
- **இணை முகவர் இயக்கம்**: அதிகபட்ச செயல்திறனுக்கு ஒரே நேரத்தில் பல AI முகவரிகளை இயக்கவும்
- **Async/Await மாதிரிகள்**: திறமையான ஒரே நேரத்தில் செயலாக்கத்துக்காக .NET இன் async நிரலாக்க முறைமையை பயன்படுத்தவும்
- **Azure OpenAI (Responses API)**: ஒரே நேரத்தில் Azure OpenAI Responses API க்கு பல கோரிக்கைகளை ஒருங்கிணைக்கவும்
- **வள மேலாண்மை**: ஒரே நேரத்தில் செயல்படும் செயல்களில் AI மாதிரி வளங்களை திறமையாக நிர்வகிக்கவும்

### 🏗️ **மேம்பட்ட ஒரே நேரத்தில் செயலாக்க கட்டமைப்பு**
- **Task-Based Parallelism**: சிறந்த ஒரே நேரத்தில் செயலாக்கத்திற்கான .NET Task Parallel Library ஐ பயன்படுத்தவும்
- **ஒத்திசைவு மாதிரிகள்**: போட்டி நிலைகள் தவிர்த்து ஒரே நேரத்தில் செயல்படும் முகவர்களை ஒருங்கிணைக்கவும்
- **பயன்பாட்டு சரிபார்த்தல்**: கிடைக்கும் ஒரே நேரத்தில் செயலாக்க திறனில் வேலை சிறப்பாக பகிரவும்
- **தோல்வி தாங்கும்**: ஒரு முகவரின் தோல்வி entire workflow ஐ நிறுத்தாமல் கையாளவும்

### 🏢 **தொழிற்துறை ஒரே நேரத்தில் செயல்படும் செயலிகள்**
- **அதிக அளவு ஆவண செயலாக்கம்**: பல ஆவணங்களை ஒரே நேரத்தில் செயலாக்கவும்
- **நேரடி உள்ளடக்க பகுப்பாய்வு**: வருகிற தரவு ஓட்டங்களின் ஒரே நேரத்தில் பகுப்பாய்வு
- **தொகுப்பு செயலாக்க மேம்பாடு**: பெரும் அளவிலான தரவு செயலாக்க செயல்களை அதிகபட்சம் செய்யவும்
- **பல தளம் பகுப்பாய்வு**: வெவ்வேறு உள்ளடக்க வகைகள் மற்றும் வடிவமைப்புக்களின் இணை செயலாக்கம்

## 💻 குறியீட்டை இயக்குதல்

முழுமையான நிரலை `03.dotnet-agent-framework-workflow-ghmodel-concurrent.cs` இல் கிடைக்கிறது. இது பயண திட்டமிடலுக்கு **Fan-Out/Fan-In ஒரே நேரத்தில் செயல்படும் பணித் திட்டத்தை** காட்சி படுத்துகிறது:

### 🏗️ **பணித் திட்ட கட்டமைப்பு**

```
User Request → ConcurrentStartExecutor → [Researcher Agent || Planner Agent] → ConcurrentAggregationExecutor → Final Output
```

**முக்கிய கூறுகள்:**

1. **ConcurrentStartExecutor**: பயனர் கோரிக்கையை அனைத்து முகவர்களுக்கும் ஒரே நேரத்தில் பாதுகிடுகிறது
2. **Researcher Agent**: இலக்கிடங்கள் மற்றும் பார்வைகள் ஒரே நேரத்தில் பகுப்பாய்வு செய்கிறது
3. **Planner Agent**: விரிவான பயணத் திட்டங்களை ஒரே நேரத்தில் உருவாக்குகிறது
4. **ConcurrentAggregationExecutor**: இரு முகவர்களின் முடிவுகளை சேகரித்து தொகுக்கின்றது

### 🎯 **Fan-Out/Fan-In மாதிரி**

இந்த பணித் திட்டம் பரிசீலித்த **Fan-Out/Fan-In** மாதிரியை விளக்குகிறது:
- **Fan-Out**: ஒரு உள்ளீட்டு செய்தி பல முகவர்களுக்கு ஒரே நேரத்தில் பரப்பப்படுகிறது
- **ஒன்றிணைந்த செயலாக்கம்**: பல முகவர்கள் ஒரே பணியை இணையாகச் செய்கிறார்கள்
- **Fan-In**: அனைத்து முகவர்களிடமிருந்து முடிவுகள் சேகரித்து ஒரே வெளியீட்டில் திரட்டப்படுகின்றன

   - திட்டமிடுபவர் பயண ஏற்பாடுகளை மற்றும் நடைமுறைகளை உருவாக்குகிறார்
3. **தொகுப்பு**: இரு பதில்களை ஒருங்கிணைத்து முழுமையான வெளியீட்டை உருவாக்கு
4. **முடிவுகளை காட்சி**: அனைத்து தகவல்களுடன் ஒற்றை ஒருங்கிணைந்த பயணத் திட்டத்தை காட்டுக

### 🔧 தனிப்பயனாக்கும் விருப்பங்கள்

**மேலும் ஒரே நேரத்தில் செயல்படும் முகவர்களைச் சேர்க்கவும்:**
```csharp
// Create additional specialized agents
AIAgent budgetAgent = azureClient.GetChatClient(deployment).AsAIAgent(

    .AddFanOutEdge(startExecutor, targets: [researcherAgent, plannerAgent, budgetAgent])

    .WithOutputFrom(aggregationExecutor)
    .Build();

// Update aggregation count
if (this._messages.Count == 3) { ... }
```

**முகவர் নির্দেশங்களை மாற்றவும்:**

const string ResearcherAgentInstructions = "Your custom instructions for research...";

### 🎯 உண்மையான உலக பயன்பாடுகள்

இந்த ஒரே நேரத்தில் செயல்படும் மாதிரி சிறந்தது:
- **உள்ளடக்க உருவாக்கம்**: பல எழுத்தாளர்கள் வெவ்வேறு பிரிவுகளை ஒரே நேரத்தில் எழுத்து
- **குறியீட்டு மதிப்பாய்வு**: பல மதிப்பாய்வாளர்கள் வெவ்வேறு கோடுகளை பார்வையிடுதல்
- **சந்தை ஆராய்ச்சி**: பல சந்தை பகுதியினை இணையாக பகுப்பாய்வு செயல்
- **ஆவண செயலாக்கம்**: ஒரே நேரத்தில் தரவு எடுக்கும், பகுப்பாய்வு மற்றும் சரிபார்ப்பு
- **பல கோண பகுப்பாய்வு**: ஒரே உள்ளீட்டில் பல பார்வைகளைப் பெறுதல்

### 🔍 தனிப்பயன் செயலாக்கிகள் புரிதல்

**ConcurrentStartExecutor:**
- `IMessageHandler<string>`ஐ அமல்படுத்தி காட்சி செய்தி உள்ளீட்டை ஏற்கிறது
- அனைத்து இணைக்கப்பட்ட முகவர்களுக்கும் செய்திகளை பரப்புகிறது
- ஒரே நேரத்தில் செயலாக்கத்தைத் தூண்ட `TurnToken` அனுப்புகிறது

**ConcurrentAggregationExecutor:**
- `IMessageHandler<ChatMessage>`ஐத் தழுவி முகவர்கள் பதில்களை பெறுகிறது
- தண்டவாள பாதுகாப்புடன் செய்திகளைச் சேகரிக்கிறது
- எதிர்பார்க்கப்படும் அனைத்து பதில்களும் வந்ததும் தொகுக்கிறது
- `context.YieldOutputAsync()` பயன்படுத்தி இறுதி வெளியீட்டை வழங்குகிறது

### ⚡ செயல்திறன் நன்மைகள்

**ஒரே நேரத்தில் vs தொடர்:**
- தொடர்: Agent1 (30 வினாடிகள்) → Agent2 (30 வினாடிகள்) = **மொத்தம் 60 வினாடிகள்**
- ஒரே நேரத்தில்: Agent1 (30 வினாடிகள்) || Agent2 (30 வினாடிகள்) = **மொத்தம் 30 வினாடிகள்**

**உற்பத்தித் திறன் மேம்பாடு**: N ஒரே நேரத்தில் செயல்படும் முகவர்களுக்கு N மடங்கு வேகமானது (பணிப் பாரமும் வளங்களும் பொருந்தும்)

### 🛡️ பிழை கையாளல்

இந்த பணித் திட்டம் தனி முகவர் தோல்விகளை மென்மையாக கையாள்கிறது:
- ஒருவன் தோல்வி அடைந்தால், மற்றவர்கள் பணியை தொடர்கின்றனர்

- தேவையானால் பகுதி முடிவுகள் வழங்கப்படலாம்
