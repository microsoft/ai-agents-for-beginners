# ⚡ Azure OpenAI (Responses API) உடன் ஒரே நேரத்தில் ஏஜென்ட் வேலைப்பழக்கவழக்கங்கள் (.NET)

## 📋 உயர்தர ஒரே நேரடி செயலாக்க படிக்கையகம்

இந்த நோட்புக் Microsoft Agent Framework for .NET மற்றும் Azure OpenAI (Responses API) ஐப் பயன்படுத்தி **ஒரே நேரத்தில் வேலை செய்யும் வேலைபழக்கவழக்கங்களை** காண்பிக்கிறது. ஒரே பனப்பட்டு நிறைய AI ஏஜென்ட்களை ஒரே நேரத்தில் இயக்கி சமநிலை மற்றும் தரவு முறையான நிலைத்தன்மையை பராமரிப்பதன் மூலம் அதிகபட்ச ஓட்டளிப்பை உருவாக்கும் உயர்தர ஒரே நேரடி செயலாக்க வேலைப்பழக்கவழக்கங்களை உருவாக்க எப்படி என்பதைக் கற்றுக்கொள்வீர்கள்.

## 🎯 கற்றல் குறிக்கோள்கள்

### 🚀 **ஒரே நேரடி செயலாக்க அடிப்படைகள்**
- **அரட்டை ஏஜென்ட் இயக்கம்**: அதிகபட்ச செயல்திறனைப் பெற பல AI ஏஜென்ட்களை ஒரே நேரத்தில் இயக்கவும்
- **Async/Await முறைமை**: நன்மையான ஒரே நேரடி செயலாக்கத்திற்கான .NET இன் Async நிரலாக்க மாதிரியை பயன்படுத்துக
- **Azure OpenAI (Responses API)**: Azure OpenAI Responses API உடன் பல concurrent அழைப்புகளை ஒருங்கிணைத்தல்
- **வள மேலாண்மை**: ஒரே நேரடி செயலிகளுக்கிடையில் AI மாதிரி வளங்களை திறம்பட நிர்வகித்தல்

### 🏗️ **மேம்பட்ட ஒரே நேரடி கட்டமைப்பு**
- **Task-Based Parallelism**: சிறந்த ஒரே நேரடி செயல்முறைக்காக .NET Task Parallel Library ஐப் பயன்படுத்துக
- **இணைப்பு முறைகள்**: போட்டியிடும் சமய நிலைகள் தவிர்த்து concurrent ஏஜென்ட்களை ஒருங்கிணைக்கவும்
- **சுமை சமன்பாடு**: கிடைக்கக்கூடிய concurrent செயலாக்க திறனை திறம்படப் பகிரவும்
- **த்ருடித்து சகிப்புத்தன்மை**: ஒரே ஏஜென்ட் தோல்விகள் முழு வேலைப்பழக்கத்தை நிறுத்தாமல் கையாளலாம்

### 🏢 **எண்டர்பிரைஸ் ஒரே நேரடி பயன்பாடுகள்**
- **அதிக.External документ செயலாக்கம்**: பல ஆவணங்களை ஒரே நேரத்தில் செயலாக்கவும்
- **உண்மை நேர உள்ளடக்க பகுப்பாய்வு**: வரும் தரவு ஓட்டங்களை ஒரே நேரத்தில் பகுப்பாய்வு செய்வது
- **குழு செயலாக்க முன்னேற்றம்**: பெரும் அளவு தரவு செயலாக்க செயல்பாட்டிற்கான ஓட்டளிப்பை அதிகரிக்கவும்
- **பன்முகம் பகுப்பாய்வு**: வெவ்வேறு உள்ளடக்க வகைகள் மற்றும் வடிவங்களின் ஒரே நேரடி செயலாக்கம்

## 🏢 **எண்டர்பிரைஸ் செயல்திறன் நன்மைகள்**

### ⚡ **ஓட்டளிப்பு மற்றும் விரிவாக்கம்**
- **சீரான செயல்திறன் விரிவாக்கம்**: ஓட்டளிப்பை அதிகரிக்க மேலும் concurrent ஏஜென்ட்களைச் சேர்க்கவும்
- **வள பயன்பாடு**: கிடைக்கும் AI மாதிரி திறனின் மிக அதிக திறன்
- **செயலாக்க நேரம் குறைப்பு**: ஒரே நேரில் செயலாக்கம் மூலம் முக்கியமான நேரம் குறைப்பு
- **திடமான விரிவாக்கம்**: வேலையின்படி concurrent ஏஜென்ட் எண்ணிக்கையை தானாக மாற்றவும்

### 🛡️ **நம்பகத்தன்மை மற்றும் சகிப்புத்தன்மை**
- **பிழை தனித்துவம்**: தனிப்பட்ட ஏஜென்ட் தோல்விகள் மற்ற concurrent செயல்களை பாதிக்காது
- **மெதுவாக இழப்பீடு**: குறைந்த ஏஜென்ட் வசதியுடன் சிஸ்டம் தொடரும்
- **பிழை மீட்பு**: தோல்வியுற்ற concurrent செயல்களுக்கு தானாகத் திரும்ப முயற்சி செய்விதிகள்
- **சுமை பகிர்வு**: கிடைக்கும் ஏஜென்டுகளுக்கு சமமாக வேலை பகிர்தல்

### 📊 **செயல்திறன் கண்காணிப்பு**
- **ஒரே நேரடி செயல்பாட்டு அளவுகோல்கள்**: அனைத்து பக்கவச வினைகளின் செயல்திறனை கண்காணிக்கவும்
- **வள பயன்பாடு பகுப்பாய்வு**: CPU, நினைவகம் மற்றும் நெட்வொர்க்கு பயன்பாட்டைப் பார்க்கவும்
- **ஓட்டளிப்பு பகுப்பாய்வு**: ஒரே நேரடி செயலாக்கத்தின் மூலம் திறன் பெருக்கத்தை அளவிடுக
- **கதிர் கண்டறிதல்**: செயல்திறனில் தடைகள் இருப்பதை கண்டுபிடித்து சரி செய்யவும்

### 🔧 **உருவாக்கம் மற்றும் செயல்பாடு**
- **Async நிரலாக்க மாதிரி**: .NET இன் முழுமையான async/await முறைகளைப் பயன்படுத்துக
- **வடிவமைப்பு ஒருங்கிணைப்பு**: உட்பிரதிகள் நிர்வாகம் மற்றும் ஒருங்கிணைப்பு திறன்கள்
- **தவறு கையாள்தல்**: ஒரே நேரடி செயலிகளுக்கான முழுமையான பிழை கையாள்தல்
- **பிழைத்துடிப்புத்தன்மை ஆதரவு**: ஒரே நேரடி வேலைப்பழக்கங்களில் Visual Studio பிழைத்தடு கருவிகள்

.NET உடன் உயர்தர concurrent AI வேலைப்பழக்கங்களை உருவாக்குவோம்! 🚀

## 💻 குறியீட்டை இயக்குதல்

முழுமையான செயலாக்கம் `03.dotnet-agent-framework-workflow-ghmodel-concurrent.cs` இல் உள்ளது. இந்த கோப்பு பயணம் திட்டமிடுவதற்கான **Fan-Out/Fan-In concurrent workflow** ஐ காட்சிப்படுத்துகிறது:

### 🏗️ **வேலைப்பழக்க கட்டமைப்பு**

```
User Request → ConcurrentStartExecutor → [Researcher Agent || Planner Agent] → ConcurrentAggregationExecutor → Final Output
```

**முக்கிய கூறுகள்:**

1. **ConcurrentStartExecutor**: பயனர் கோரிக்கையை அனைத்து ஏஜென்ட் க்கும் ஒரே நேரத்தில் பரப்புகிறது
2. **ஆராய்ச்சி ஏஜென்ட்**: இடங்களையும் ஈர்ப்புகளையும் ஒரே நேரத்தில் பகுப்பாய்வு செய்கிறது
3. **திட்டமிடும் ஏஜென்ட்**: விரிவான பயணத் திட்டங்களை concurrent ஆக உருவாக்குகிறது
4. **ConcurrentAggregationExecutor**: இரு ஏஜெண்ட்களிடமிருந்து முடிவுகளை சேகரித்து இணைக்கிறது

### 🎯 **Fan-Out/Fan-In முறை**

இந்த வேலைப்பழக்கம் பாரம்பரியமான **Fan-Out/Fan-In** முறைபாட்டைக் காட்டுகிறது:
- **Fan-Out**: ஒரே உள்ளீட்டு செய்தி பல ஏஜெண்ட்களுக்குத் தானாக பரப்பப்படுகிறது
- **ஒரே நேரடி செயல்திறன்**: பல ஏஜெண்ட்கள் ஒரே பணியில் பக்கவசமாக வேலை செய்கின்றன
- **Fan-In**: அனைத்து ஏஜெண்ட்களிடமிருந்தும் முடிவுகள் சேகரிக்கப்பட்டு ஒரே வெளியீட்டில் இணைக்கப்படுகின்றன

   - திட்டமிடும் ஏஜென்ட் திட்டத்தையும் மொத்த ஏற்பாடுகளையும் உருவாக்குகிறது
3. **இணைப்பு**: இரு பதில்களையும் ஒருங்கிணைத்து விரிவான வெளியீட்டை உருவாக்குகிறது
4. **முடிவுகளை காட்டு**: அனைத்து தகவல்களுடன் கூடிய இணைந்த பயணத் திட்டத்தை காட்டுகிறது

### 🔧 தனிப்பயனாக்க விருப்பங்கள்

**மேலும் concurrent ஏஜென்ட்களைச் சேர்க்கவும்:**
```csharp
// Create additional specialized agents
AIAgent budgetAgent = azureClient.GetChatClient(deployment).AsAIAgent(
    name: "Budget-Agent", instructions: "Calculate travel costs...");

// Add to fan-out
var workflow = new WorkflowBuilder(startExecutor)
    .AddFanOutEdge(startExecutor, targets: [researcherAgent, plannerAgent, budgetAgent])
    .AddFanInBarrierEdge(sources: [researcherAgent, plannerAgent, budgetAgent], target: aggregationExecutor)
    .WithOutputFrom(aggregationExecutor)
    .Build();

// Update aggregation count
if (this._messages.Count == 3) { ... }
```

**ஏஜென்ட் அறிவுறுத்தல்களை மாற்றவும்:**
```csharp
const string ResearcherAgentInstructions = "Your custom instructions for research...";
const string PlanAgentInstructions = "Your custom instructions for planning...";
```

**பணியை மாற்றவும்:**
```csharp

    workflow, 
    "Plan a European vacation for 2 weeks in summer"
);
```

### 🎯 உண்மை உலக பயன்பாடுகள்

இந்த concurrent முறைபாடு சிறந்தது:
- **உள்ளடக்க உருவாக்கம்**: பல எழுத்தாளர்கள் வெவ்வேறு பகுதிகளை ஒரே நேரத்தில் உருவாக்குவது
- **குறியீடு மதிப்பாய்வு**: பல மதிப்பாய்வாளர்கள் வெவ்வேறு கோடுகளை விசாரணை செய்தல்
- **சந்தை ஆராய்ச்சி**: வெவ்வேறு சந்தை பிரிவுகளின் ஒரே நேரடி பகுப்பாய்வு
- **ஆவண் செயலாக்கம்**: ஒரே நேரத்தில் பெறுதல், பகுப்பு மற்றும் சரிபார்ப்பு
- **பல பார்வை பகுப்பு**: ஒரே உள்ளீட்டில் இருந்து வித்தியாசமான பார்வைகள் பெறுவது

### 🔍 தனிப்பயன் Executor களைப் புரிதல்

**ConcurrentStartExecutor:**
- `IMessageHandler<string>` ஐ செயல்படுத்தி சரம் உள்ளீட்டை ஏற்றுக்கொள்கிறது
- இணைக்கப்பட்ட அனைத்து ஏஜெண்டுகளுக்கும் செய்திகளை பரப்புகிறது
- ஒரே நேரடி செயல்களைத் துவங்க `TurnToken` ஐ அனுப்புகிறது

**ConcurrentAggregationExecutor:**
- `IMessageHandler<ChatMessage>` ஐ செயல்படுத்தி ஏஜென்ட் பதில்களைப் பெறுகிறது
- திரட்டு செய்கின்றது மற்றும் திரெடுக்கு பாதுகாப்பான முறையில் சேகரிக்கிறது
- எதிர்பார்க்கப்படும் அனைத்து பதில்களும் வந்தபோது இணைக்கிறது
- `context.YieldOutputAsync()` ஐ பயன்படுத்தி இறுதி வெளியீட்டை வழங்குகிறது

### ⚡ செயல்திறன் நன்மைகள்

**ஒரே நேரடி மற்றும் வரிசைப்படுத்தப்பட்ட செயலாக்கம்:**
- வரிசைப்படுத்தப்பட்டது: Agent1 (30s) → Agent2 (30s) = **மொத்தம் 60 விநாடிகள்**
- ஒரே நேரடி: Agent1 (30s) || Agent2 (30s) = **மொத்தம் 30 விநாடிகள்**

**ஓட்டளிப்பு மேம்பாடு**: N concurrent ஏஜென்ட்களுக்கு N மடங்கு வேகமாக (வேலை மற்றும் வளங்களின் அடிப்படையில்)

### 🛡️ பிழை கையாள்தல்

வேலைப்பழக்கம் தனி ஏஜென்ட் தோல்விகளை மென்மையாக கையாள்கிறது:
- ஒருவன் தோல்வியடைந்தால் மற்றவர்கள் செயல்பட தொடர்வார்கள்
- கூட்டு நிர்வாகி கால அவகாசத்தின் நெறிமுறையை செயல்படுத்தலாம்
- தேவையானால் பகுதி முடிவுகளை திருப்பி வழங்கலாம்

### 📊 மேம்பட்ட அம்சங்கள்
