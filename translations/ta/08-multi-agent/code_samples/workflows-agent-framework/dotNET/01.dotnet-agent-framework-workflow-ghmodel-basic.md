# 🔄 Azure OpenAI (Responses API) உடன் அடிப்படை முகவர் பணிச்சுழற்சிகள் (.NET)

## 📋 பணிச்சுழற்சி ஒழுங்கமைப்புக் கையேடு

இந்த நோட்புக், .NET மற்றும் Azure OpenAI (Responses API) உடன் Microsoft Agent Framework-ஐ பயன்படுத்தி வலுவான **முகவர் பணிச்சுழற்சிகளை** உருவாக்குவது எப்படி என்பதை காட்டுகிறது. நீங்கள் எய்ஐ முகவர்கள் ஒத்துழைத்து தொடர் கட்டமைப்புகளைப் பயன்படுத்தி சிக்கலான பணிகள் நிறைவுசெய்வதற்கான பல படி வணிக செயல்முறைகளை உருவாக்குவதைக் கற்கப்போகிறீர்கள்.

## 🎯 கற்றல் இலக்குகள்

### 🏗️ **பணிச்சுழற்சி கட்டமைப்பு அடிப்படைகள்**
- **பணிச்சுழற்சி கட்டுமானி**: சிக்கலான பல படி AI செயல்முறைகளை வடிவமைத்து ஒழுங்கமைக்க
- **முகவர் ஒருங்கிணைப்பு**: பணிச்சுழற்சிகளில் பலதுறை சிறப்பு முகவர்களை ஒருங்கிணைக்க
- **Azure OpenAI (Responses API)**: பணிச்சுழற்சிகளில் Azure OpenAI Responses API-ஐ பயன்படுத்த
- **காட்சி பணிச்சுழற்சி வடிவமைப்பு**: சிறந்த புரிதலுக்காக பணிச்சுழற்சி கட்டமைப்புகளை உருவாக்கி காட்சிப்படுத்த

### 🔄 **செயல்முறை ஒழுங்கமைப்பு முறைமைகள்**
- **தொடர்புடைய செயலாக்கம்**: பல முகவர் பணிகளை பொருத்தமான வரிசையில் சங்கிலிப்படுத்த
- **நிலை மேலாண்மை**: பணிச்சுழற்சி கட்டங்களில் உள்ள தகவல் மற்றும் தரவுத் தொடர்பை பராமரிக்க
- **பிழை கையாளுதல்**: வலுவான பிழை மீட்பு மற்றும் பணிச்சுழற்சி ஒப்பந்தங்களை செயல்படுத்த
- **செயற்பாட்டு மேம்பாடு**: நிறுவன அளவு செயல்பாடுகளுக்கு திறமையான பணிச்சுழற்சிகளை வடிவமைக்க

### 🏢 **நிறுவன பணிச்சுழற்சி பயன்பாடுகள்**
- **வணிக செயல்முறை தானியங்கி**: சிக்கலான நிறுவன பணிச்சுழற்சிகளை தானியகப்படுத்த
- **உள்ளடக்க உற்பத்தி குழாய்**: ஆய்வு மற்றும் ஒப்புதலுடன் உள்ளடக்க பணிச்சுழற்சிகள்
- **வாடிக்கை சேவை தானியங்கி**: பல படி வாடிக்கை விசாரணை தீர்வு
- **தரவு செயலாக்க பணிச்சுழற்சிகள்**: AI-திறனாய்ச் செலுத்தும் மாற்றத்துடன் ETL செயல்பாடுகள்

இந்த பணிச்சுழற்சி காட்சியமைப்பு பல முக்கிய .NET தொகுதிகளைப் பயன்படுத்துகிறது:

```xml
<PackageReference Include="DotNetEnv" Version="3.1.1" />
```

### 🔑 **Azure OpenAI கட்டமைப்பு**

**சுற்றுச்சூழல் அமைப்பு (.env கோப்பு):**
```env
AZURE_OPENAI_ENDPOINT=https://<your-resource>.openai.azure.com
AZURE_OPENAI_DEPLOYMENT=gpt-5-mini
```

**Azure OpenAI அணுகல்:**
1. Azure போர்டலில் Azure OpenAI வளத்தை உருவாக்கவும்
2. ஒரு மாதிரியை (எ.கா., `gpt-5-mini`) பரிமாறவும் மற்றும் பரிமாற்றப் பெயரை குறிக்கவும்
3. `az login` மூலம் உள்நுழைந்து மேலே காட்டப்பட்டபடி சுற்றுச் சூழல் மாறி மதிப்புகளை அமைக்கவும்

### 🏗️ **பணிச்சுழற்சி கட்டமைப்பு கண்ணோட்டம்**

```mermaid
graph TD
    A[வேலை جریان கட்டுமானி] --> B[முகவர் பதிவேடு]
    B --> C[வேலை جریان செயலாக்க இயந்திரம்]
    C --> D[Agent 1: உள்ளடக்க உற்பத்தியாளர்]
    C --> E[Agent 2: உள்ளடக்க ஆய்வாளர்] 
    D --> F[வேலை جریان முடிவுகள்]
    E --> F
    G[Azure OpenAI (பதில்கள் API)] --> D
    G --> E
```

**முக்கிய கூறுகள்:**
- **WorkflowBuilder**: பணிச்சுழற்சிகளை வடிவமைக்கும் பிரதான ஒழுங்கமைப்பு இயந்திரம்
- **AIAgent**: தனிநபர் சிறப்பு திறன்களுடன் கூடிய முகவர்கள்
- **Azure OpenAI Client**: Azure OpenAI Responses API ஒருங்கிணைத்தல்
- **Execution Context**: பணிச்சுழற்சி கட்டங்களுக்குள் நிலை மற்றும் தரவு சரவெளியை நிர்வகிக்கிறது

- **பிழை மீட்பு**: எந்த பணிச்சுழற்சி கட்டத்திலும் தோல்விகளை சிரமான முறையில் கையாளுதல்
- **செயற்பாட்டு கண்காணிப்பு**: செயல்பாட்டு அளவுகோல்களையும் மேம்பாட்டுக் வாய்ப்புகளையும் பின்தொடர்தல்

- **அணுகல் கட்டுப்பாடு**: பணிச்சுழற்சி இயக்கிப்பார்வைக்கும் கண்டறிதலுக்கும் துல்லியமான அனுமதிகள்
- **தரவு தனியுரிமை**: பணிச்சுழற்சிகளுக்குள் உணர்ச்சியற்ற தகவல்களின் பாதுகாப்பான கையாளுதல்

### 📊 **காணொளித்தன்மையுடனும் மேலாண்மையுடனும்**
- **காட்சி பணிச்சுழற்சி வடிவமைப்பு**: செயல்முறை ஓட்டங்களும் சார்புகளும் தெளிவாகக் காட்டுதல்
- **செயல்பாட்டு கண்காணிப்பு**: பணிச்சுழற்சி முன்னேற்றம் மற்றும் செயல்திறன் நேரடி கண்காணிப்பு
- **பிழை அறிக்கை**: விரிவான பிழை பகுப்பாய்வு மற்றும் குறியீடு திறன்கள்
- **செயற்பாட்டு பகுப்பாய்வு**: மேம்படுத்தல் மற்றும் திறன் திட்டமிடலுக்கான அளவுகோல்கள்
