# 🔄 அடிப்படைக் கூலி முகவர்கள் உள் Azure OpenAI (Responses API) உடன் (.NET)

## 📋 வேலைப்பாடு ஒருங்கிணைப்பு பயிற்சி

இந்த நோட்புக் Microsoft Agent Framework .NET மற்றும் Azure OpenAI (Responses API) பயன்படுத்தி மேம்பட்ட **முகவர் வேலைப்பாடுகளை** எப்படி உருவாக்குவது என்பதைக் காட்டுகிறது. தனித்திருந்த கையாளும் உதவிக் கூலிகள் கூடி அமைந்திருக்கும் ஒருங்கிணைந்த அயல் செயல்முறைகளை உருவாக்கி, புரிந்துகொள்ளச் செய்வீர்கள்.

## 🎯 கற்றல் நோக்கங்கள்

### 🏗️ **வேலைப்பாடு معماري அடிப்படைகள்**
- **வேலைப்பாடு கட்டமைப்பாளர்**: சிக்கலான, பல-படி AI செயல்முறைகளை வடிவமைத்து ஒருங்கிணைக்கவும்
- **முகவர் ஒத்துழைப்பு**: வேலைப்பாடுகளில் பல சிறப்பு முகவர்களை ஒருங்கிணைக்கவும்
- **Azure OpenAI (Responses API)**: வேலைப்பாடுகளில் Azure OpenAI பதில்கள் API ஐ பயன்படுத்தவும்
- **காட்சி வேலைப்பாடு வடிவமைப்பு**: வேலைப்பாடுகளின் அமைப்புகளை உருவாக்கி பார்வையிடவும்

### 🔄 **செயல்முறை ஒருங்கிணைப்பு வடிவங்கள்**
- **வரிசைப்படுத்தப்பட்ட செயலாக்கம்**: பல முகவர் பணிகளை தர்க்கமான வரிசையில் இணைக்கவும்
- **நிலை மீதாண்மை**: வேலைப்பாட்டு படிகளுக்கு இடையில் சூழலை மற்றும் தரவு தொடர்புகளை பராமரிக்கவும்
- **பிழை கையாளல்**: வலுவான பிழை மீட்பு மற்றும் வேலைப்பாடு துன்புறுத்தல் எதிர்ப்பு நடைமுறை
- **செயற்பாட்டு மேம்பாடு**: தேர்ச்சியான, பெரிய அளவிலான செயல்பாடுகளுக்கான திறமையான வேலைப்பாடுகளை வடிவமைக்கவும்

### 🏢 **எந்தர்ப்ரைஸ் வேலைப்பாடு பயன்பாடுகள்**
- **வணிக செயல்முறை தானியங்கி**: சிக்கலான அமைப்புச் செயல்முறைகளை தானியக்கியாக்கவும்
- **உள்ளடக்க உற்பத்தி குழாய்**: விமர்சனமும் அங்கீகார படிகளும் கொண்ட ஆசிரியர் வேலைப்பாடுகள்
- **வாடிக்கையாளர் சேவை தானியக்கம்**: பல படிகளைக் கொண்ட வாடிக்கையாளர் விசாரணை தீர்வு
- **தரவு செயலாக்க வேலைப்பாடுகள்**: AI இயக்கப்படும் மாற்றத்துடன் ETL வேலைப்பாடுகள்

### 🔑 **Azure OpenAI அமைப்பு**

**சுற்றுப்புற அமைப்பு (.env கோப்பு):**
```env
AZURE_OPENAI_ENDPOINT=https://<your-resource>.openai.azure.com
AZURE_OPENAI_DEPLOYMENT=gpt-4o-mini
```

**Azure OpenAI அணுகல்:**
1. Azure போர்டலில் Azure OpenAI வளத்தை உருவாக்கவும்
2. ஒரு மாதிரியை (எ.கா., `gpt-4o-mini`) அமைத்து வைக்கவும்; அமைப்பு பெயரை குறி வைக்கவும்
3. `az login` மூலம் உள்நுழைந்து மேலே காட்டிய சுற்று மாறிலிகளை அமைக்கவும்

### 🏗️ **வேலைப்பாடு معماري மேல் கண்ணோட்டம்**

```mermaid
graph TD
    A[பணிச்சுழற்சி கட்டுமானர்] --> B[முகவர் பதிவுத்தாள்]
    B --> C[பணிச்சுழற்சி செயலாக்க இயந்திரம்]
    C --> D[Agent 1: உள்ளடக்கத்தை உருவாக்குபவர்]
    C --> E[Agent 2: உள்ளடக்கத்தை மதிப்பாய்வாளர்] 
    D --> F[பணிச்சுழற்சி முடிவுகள்]

    G --> E
```

**முக்கிய கூறுகள்:**
- **WorkflowBuilder**: வேலைப்பாடுகளுக்கான பிரதான ஒருங்கிணைப்பு இயந்திரம்
- **AIAgent**: தனித்துவ சிறப்பு திறன்கள் கொண்ட தனி முகவர்கள்
- **Azure OpenAI Client**: Azure OpenAI பதில்கள் API ஒருங்கிணைவு
- **Execution Context**: வேலைப்பாட்டு படிகளுக்கு இடையில் நிலை மற்றும் தரவின் கிடைப்பை நிர்வகிக்கிறது
