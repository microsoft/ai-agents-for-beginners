# கணினி பயன்பாட்டு முகவர்கள் (CUA) உருவாக்குதல்

கணினி பயன்பாட்டு முகவர்கள் ஒரு நபர் போலவே இணையதளங்களுடன் தொடர்பு கொள்ளலாம்: ஒரு உலாவியை திறந்து, பக்கத்தை ஆய்வு செய்து, அவர்கள் காணும் அடுத்த சிறந்த நடவடிக்கையை எடுத்து. இந்த பாடத்தில், நீங்கள் Airbnb-ஐ தேடும், கட்டமைக்கப்பட்ட பட்டியல் தரவுகளை எடுத்து, ஸ்டாக்ஹோலா்மில் மிகக் குறைந்த விலையில் தங்கும் இடத்தை கண்டுபிடிக்கும் உலாவி தானியக்க முகவரின் ஒருவகையை உருவாக்குவீர்கள்.

இந்த பாடம் AI-ஐ இயக்கும் வழிசெலுத்தலுக்கான Browser-Use-ஐ, உலாவி கட்டுப்பாட்டிற்கு Playwright மற்றும் Chrome DevTools Protocol (CDP)-ஐ, Azure OpenAI-ஐ பார்வை செயல்திறனை பயின்று விவரிக்க, மற்றும் Pydantic-ஐ கட்டமைக்கப்பட்ட சுருக்கத்திற்கு இணைக்கிறது.

## அறிமுகம்

இந்த பாடம் கீழுள்ளவற்றை உள்ளடக்கியது:

- API மட்டும் தானியக்கத்துக்கு பதிலாக கணினி பயன்பாட்டு முகவர்கள் எப்போது சிறந்தது என்பதை புரிந்துகொள்வது
- நம்பகமான உலாவி வாழ்நாள் மேலாண்மைக்காக Browser-Use-ஐ Playwright மற்றும் CDP-இன் உதவியுடன் இணைத்தல்
- வேகமாக மாறும் இணையதளத் தளங்களில் பட்டியல் தரவுகளை எடுக்க Azure OpenAI பார்வை மற்றும் கட்டமைக்கப்பட்ட Pydantic வெளியீட்டை பயன்படுத்துதல்
- முகவர் முதன்மை, நடிகர் முதன்மை அல்லது கலவை உலாவி தானியக்க வேலைப்பாட்டை எப்போது பயன்படுத்த வேண்டும் என்பதை தீர்மானித்தல்

## கற்றல் இலக்குகள்

இந்த பாடத்தை முடித்த பிறகு, நீங்கள் அறிந்துகொள்ளுவீர்கள்:

- Azure OpenAI மற்றும் Playwright-ஐ Browser-Use உடன் அமைத்தல்
- ஒரு உண்மையான இணையதளத்தில் மடங்கான UI கூறுகளை கையாளும் உலாவி தானியக்க வேலைப்பாட்டை உருவாக்குதல்
- பக்கத்தின் தெரியும் உள்ளடக்கத்தில் இருந்து வகைப்பாட்டை பெற்று வணிக பின்விளைவுகளை உருவாக்குதல்
- உலாவி பணியின் முன்னறிவிக்கப்பட்ட தன்மை அடிப்படையில் முகவர் மற்றும் நடிகர் மாதிரிகளில் தேர்வு செய்தல்

## குறியீடு மாதிரி

இந்த பாடத்தில் ஒரு நோட்டுபுக் பாடமாகும்:

- [15-browser-user.ipynb](./15-browser-user.ipynb): CDP மூலம் ஒரு Chrome அமர்வை தொடங்கி, Airbnb-இல் ஸ்டாக்ஹோல்மின் பட்டியல்களைத் தேடி, Browser-Use பார்வையுடன் விலை விவரங்களை எடுத்து, மிகவும் குறைந்த செலவான விருப்பத்தை கட்டமைக்கப்பட்ட தரவாக வழங்குகிறது.

## முன்-தேவைகள்

- Python 3.12+
- உங்கள் சுற்றுச்சூழலில் செட் செய்யப்பட்ட Azure OpenAI நேர்முகம்
- உங்கள் கணினியில் Chrome அல்லது Chromium நிறுவப்பட்டுள்ளன
- Playwright சார்ந்த பொருட்கள் நிறுவப்பட்டுள்ளன
- async Python-இன் அடிப்படை அறிவு

## அமைப்பு

நோட்டுபுக் பயன்படுத்தும் தொகுதிகளை நிறுவவும்:

```bash
pip install browser_use playwright python-dotenv
playwright install chromium
```

நோட்டுபுக்கில் பயன்படும் Azure OpenAI சுற்றுச்சூழல் மாறிலிகளை அமைக்கவும்:

```bash
AZURE_OPENAI_ENDPOINT=...
AZURE_OPENAI_API_KEY=...
AZURE_OPENAI_CHAT_DEPLOYMENT_NAME=...
# விருப்பமானது: தவிர்க்கப்படும் போது புதிய API பதிப்புக்கு இயல்புநிலை அமைக்கப்படுகிறது
AZURE_OPENAI_API_VERSION=...
```

## கட்டமைப்பு திருக்கட்டுரை

நோட்டுபுக் ஒரு கலவை உலாவி தானியக்க வேலைப்பாட்டை விளக்குகிறது:

1. CDP செயல்படுத்தப்பட்ட நிலையில் Chrome துவங்குகிறது, ஆகவே Playwright மற்றும் Browser-Use இருவரும் ஒரே உலாவி அமர்வை பகிர முடியும்.
2. ஒரு Browser-Use முகவர் Airbnb-ஐ திறப்பது, பாப்-அப்களை மறுப்பது மற்றும் ஸ்டாக்ஹோல்மின் தேடும் போன்ற திறந்த வழிசெலுத்தல் பணிகளை கையாள்கிறது.
3. செயலில் இருக்கும் பக்கத்தை கட்டமைக்கப்பட்ட Pydantic ஸ்கீமாவுடன் ஆய்வு செய்து, பட்டியல் தலைப்புகள், தினசரி விலை, மதிப்பீடுகள் மற்றும் URL-களை எடுக்கிறது.
4. Python தார்க்கீகம் எடுக்கப்பட்ட பட்டியல்களை ஒப்பிட்டு மிகக் குறைந்த விலையுள்ள முடிவை வெளிப்படுத்துகிறது.

இந்த அணுகுமுறை Browser-Use திறனான பார்வை அடிப்படையிலான காரணக்கணிப்பை வைத்திருக்கிறது மேலும் தேவையான போது நீங்கள் உறுதிசெய்யக்கூடிய உலாவி கட்டுப்பாட்டை வழங்குகிறது.

## முக்கியமான குறிப்பு மற்றும் சிறந்த நடைமுறைகள்

### முகவர் மற்றும் நடிகரை எப்போது பயன்படுத்த வேண்டும்

| சூழல் | முகவரை பயன்படுத்தவும் | நடிகரை பயன்படுத்தவும் |
|----------|-----------|-----------|
| மாறும் விருப்ப அமைப்புகள் | ஆம், AI பக்க மாற்றங்களுக்கு ஒத்துழைகிறது | இல்லை, முறிந்த தேர்வுசெய்கிறது ஆபத்தானது |
| தெரிந்த கட்டமைப்பு | இல்லை, முகவர் நேரடி கட்டுப்பாட்டைவிட மெதுவாக இருக்கிறது | ஆம், விரைவாகவும் துல்லியமாகவும் உள்ளது |
| கூறுகளைக் கண்டுபிடித்தல் | ஆம், இயற்கை மொழி நன்றாக செயல்படுகிறது | இல்லை, சரியான தேர்வுகள் தேவைப்படுகிறது |
| நேர நிர்வாகம் | இல்லை, குறைவான முன்னறிவிப்பு | ஆம், காத்திருப்பு மற்றும் மீண்டும் முயற்சி ஆகியவற்றுக்கு முழு கட்டுப்பாடு உள்ளது |
| கவனிக்க வேண்டிய வடிவமைப்புகள் | ஆம், எதிர்பாராத UI நிலைகளை கையாள்கிறது | இல்லை, தெளிவான கிளைகளைக் கேட்கிறது |

### Browser-Use சிறந்த நடைமுறைகள்

1. ஆராய்ச்சி மற்றும் மாறும் வழிசெலுத்தலுக்காக முதலில் முகவருடன் தொடங்குக.
2. தொடர்பு நிலையான போது நேரடி பக்க கட்டுப்பாட்டுக்கு மாறுக.
3. எடுக்கப்பட்ட தரவுகள் சரிபார்க்கப்பட்டு வகைப்பாடு பாதுகாக்கப்படுவது உறுதி செய்ய கட்டமைக்கப்பட்ட வெளியீட்டு மாதிரிகளைப் பயன்படுத்துக.
4. காட்சிக்கு பாதிப்பூட்டும் நடவடிக்கைகளுக்கு பிறகு தாமதங்களை நுணுக்கமாக சேர்க்கவும்.
5. தோல்விகளை எளிதாக கண்டறிய திரை படம் எடுக்கும் போது அதை எடுத்து வைக்கவும்.
6. இணையதளங்கள் மாற்றப்படுவதை எதிர்பார்த்து, பாப்-அப்புகள் மற்றும் விருப்ப இடமாற்றங்களுக்கு மாற்று செயல்பாடுகளை வடிவமைக்கவும்.
7. முகவர் மற்றும் நடிகர் மாதிரிகளை கலக்கவும், இதன்மூலம் துல்லியத்தையும் நுணுக்கத்தையும் பெறலாம்.

### உலாவி முகவர்களுக்கான பாதுகாப்பு வழிகாட்டுதல்கள்

உலாவி முகவர்கள் நேரடி இணையதளங்களிலேயே இயங்குவதால், அவர்கள் கட்டுப்பாடுகள் நுணுக்கமானவை ஆக வேண்டும், API ஒரே வகையான ஸ்கிரிப்ட்டைவிட முக்கியமாக வேறுபடுகிறது. நோட்டுபுக் டெமோவில் இருந்து உண்மை வேலைப்பாட்டிற்கு மாறுவதற்கு முன், முகவர் என்ன பார்க்க முடியும், கிளிக் செய்ய முடியும் மற்றும் சமர்ப்பிக்க முடியும் என்பதை நிர்ணயிக்கவும்.

1. **உலாவி சூழல் வரையறுக்கவும்.** முகவரை தனிப்பட்ட உலாவி சுயவிவரம் அல்லது பாதுகாப்பான இடத்தில் இயக்கி, பணிக்கு தேவையான டொமைன்களுக்கு மட்டுப்படுத்தவும்.
2. **பார்வையிடலை செயலில் இருந்து பிரிக்கவும்.** முதலில் முகவருக்கு தேடுதல், வாசித்தல் மற்றும் தரவு எடுக்க அனுமதிக்கவும்; படிவங்களை சமர்ப்பிப்பது, செய்திகள் அனுப்புவது, பயணங்களை பதிவு செய்வது, கொள்முதல் செய்வது, பதிவுகளை அழிப்பது அல்லது கணக்கு அமைப்புகளை மாற்றுவது போன்றவை முன் தெளிவான அனுமதி படிகள் வேண்டும்.
3. **குறிப்பு மற்றும் தடவுதளங்களில் ரகசியங்களை வைக்காதே.** கடவுச்சொற்கள், கட்டண விவரங்கள், அமர்வு கூகீகள் அல்லது மூல தனித்துவமான தகவல்களை மாதிரி உள்ளடக்கத்தில் வைக்காதீர். அங்கீகாரம் பெற பயனர் செயலில் கையளிக்கவும் மற்றும் ரகசிய பகுதிகளை பதிவு அலுவல்களில் அகற்றவும்.
4. **பக்க உள்ளடக்கத்தை நம்பிக்கையில்லாத உள்ளீடாகக் கருதுக.** இணையதளம் முகவருக்கான அல்லாத அல்லது பயனருக்கான வாயில்களை கொண்டிருக்கும். முகவர் அதன் இலக்குகளை மாற்றக்கூடும், தகவல் வெளிப்படுத்தக்கூடும், பாதுகாப்பு முறைகளை இடையூறுச் செய்யக்கூடும் அல்லது தொடர்பற்ற தளங்களுக்கு செல்லக்கூடும் பக்க எழுத்துக்களை புறக்கணிக்க வேண்டும்.
5. **அபாயகரமான படிகளுக்கு சுற்றி தீர்மானிக்கப்பட்ட சோதனைகள் செய்யவும்.** தற்போதைய URL, பக்க தலைப்பு, தேர்ந்தெடுக்கப்பட்ட பொருள், விலை, பெறுநர் மற்றும் செயலின் சுருக்கத்தை கோடுகளை கொண்டு பரிசோதித்து பின்பு பயனருக்கு இறுதி அனுமதிக்க கேட்கவும்.
6. **பட்ஜெட்டுக்கள் மற்றும் நிறுத்த நிலைமைகளை அமைக்கவும்.** முகவர் பயன்படுத்தக்கூடிய நடவடிக்கைகள், மீண்டும் முயற்சிகள், தாவல்கள் மற்றும் நிமிடங்களின் எண்ணிக்கையை வரையறுக்கவும். பக்க நிலை அவ்விருப்பமற்றவெனில், தொடர க்ளிக் செய்யாதே.
7. **நன்மையான சான்றுகளை பதிவு செய்து, எல்லாவற்றையும் அல்லாமல்.** நடவடிக்கை சுருக்கங்கள், நேரலுக்குறிப்புகள், URL-கள், தேர்ந்தெடுக்கப்பட்ட கூறுகளின் விளக்கங்கள் மற்றும் திரைபட குறிப்பு அம்சங்களை வைத்திருத்தல் தோல்விகளை மீண்டும் பரிசீலிக்க உதவும். தேவையற்ற பாதுகாப்பான பக்க உள்ளடக்கத்தையும் சேமிக்க வேண்டாம்.

Airbnb உதாரணத்தில், பாதுகாப்பான இயல்பான முறையானது பட்டியல்களைத் தேடி விலைகளை எடுப்பது. உள்நுழைவதும், ஒருவரை தொடர்புகொள்வதும் அல்லது பதிவு செய்வதில் பயனர் அனுமதி பெற வேண்டும்.

### உண்மையான பயன்பாடுகள்

- பயண முன்பதிவு மற்றும் விலை கண்காணிப்பு
- மின் வர்த்தக விலை ஒப்பீடு மற்றும் கிடைக்கும் நிலை பரிசோதனைகள்
- மாறும் இணையதளங்களிலிருந்து கட்டமைக்கப்பட்ட சுருக்கம்
- பார்வை அறிவு கொண்ட UI சோதனை மற்றும் சரிபார்ப்பு
- இணையதள கண்காணிப்பு மற்றும் எச்சரிக்கை
- பல படி முறைகளுக்கு மேல் நுண்ணறிவு படிவ நிரப்பல்

## உண்மையான உதாரணம்: Microsoft Project Opal

இந்த பாடத்தில் நீங்கள் உருவாக்கும் முகவர் ஒரு சிறிய, உள்ளூர் வெர்ஷன் **கணினி பயன்பாட்டு முகவர் (CUA)** — ஒரு நபர் போல உலாவியை இயக்கும் திட்டம். Microsoft இதே சிந்தனையை Microsoft 365 Copilot உடன் நிறுவனங்களுக்கு கொண்டு வருகிறது, அதன் பெயர் **[Project Opal (Frontier)](https://support.microsoft.com/en-us/microsoft-365-copilot/get-started-with-project-opal-frontier)** ஆகும்.

Project Opal மூலம், நீங்கள் ஒரு பணி விவரிக்கும்போது முகவர் உங்கள் சார்பில் **ஒரு பாதுகாப்பான Windows 365 Cloud PC-இல் கணினி பயன்பாட்டைப் பயன்படுத்தி** அமைப்பின் உலாவி வடிவ ஆண்டுகள், தளம் மற்றும் தரவுகளுக்கு அங்கீகாரம் பெற்று செயல்படுகிறது. இது **பின்னணி முறையில் இடையூறு இல்லாமல்** இயங்கி, நீங்கள் தேவைப்பட்டால் பணியை வழிமொழியவோ அல்லது கட்டுப்பாடு எடுக்கவோ முடியும். உதாரண வேலைகள்:

- ஒத்துழைப்பு ஆய்வுகளுக்கான கணக்கு சான்றுகளை சேகரித்தல் மற்றும் சரிபார்த்தல்
- IT வழக்கு சிக்கல்களின் தலைமை வகித்தல் (டிக்கெட் நிலையை புதுப்பித்தல், உரிமையாளர்களுக்கு ஒதுக்குதல், நகல் வழக்குகளை மூடல்)
- Excel தரவுகளை நிதி முடிவில் தொகுத்தல்

## அறிவு சோதனை

அடுத்த பாடத்திற்கு முன்னர் உங்கள் புரிதலை தேர்ந்தெடுக்கவும்.

**1. இணைய உலாவி அடிப்படையிலான கணினி பயன்பாட்டு முகவர் API-மூல வேலைப்பாடுக்களுக்கு பதிலாக எப்போது சாதகமாக இருக்கும்?**

<details>
<summary>பதில்</summary>

<details>
<summary>பதில்</summary>

<details>
<summary>பதில்</summary>

**4. ஒரு வலைப்பக்கம் முகவருக்கு அதன் ஆரம்ப அறிவுறுத்தல்களை புறக்கணிக்க, வேறு தளத்திற்கு செல்ல மற்றும் சேமிக்கப்பட்ட அங்கீகார விவரங்களை வெளிப்படுத்த சொல்கிறது. முகவர் அந்த எழுத்துக்களை எப்படி கையாளவேண்டும்?**

<details>
<summary>பதில்</summary>

அதை நம்பிக்கையில்லாத பக்க உள்ளடக்கமாக கருதுக, வளர்ப்பவர் அல்லது பயனர் அறிவுரையாக அல்ல. முகவர் अनुमதிக்கப்பட்ட டொமைனிலும் பணிச் சுட்டியிலும் மட்டுமே தங்கியிருக்க வேண்டும், ரகசியங்களை வெளிப்படுத்த மறுக்க வேண்டும், இலக்கை மாற்றும், பாதுகாப்பு முறைகளை உறைச்சல் செய்யும் அல்லது தொடர்பற்ற தளங்களுக்கு விடுவிக்கும் பக்க எழுத்துக்களை பின்பற்ற வேண்டாம்.
</details>

**5. உலாவி முகவர் இயங்கும் போது எத்தகைய சான்றுகளை வைத்திருக்க வேண்டும், மற்றும் என்ன தவிர்க்க வேண்டும்?**

<details>
<summary>பதில்</summary>

நடவடிக்கை சுருக்கங்கள், நேர குறிபுகள், URL-கள், தேர்ந்தெடுக்கப்பட்ட கூறுகளின் விளக்கங்கள், சரிபார்ப்பு முடிவுகள் மற்றும் திரைபட குறிப்பு குறிப்புகளை வைத்திருத்தல் வேலைப்பாடு பரிசீலனை செய்ய உதவும். கடவுச் சொற்கள், கட்டண விவரங்கள், அமர்வு கூகீகள், மூல தனிப்பட்ட தகவல்கள் அல்லது முழுமையான பக்க உள்ளடக்கங்களை சேமிப்பதை தவிர்க்கவும், மாறாக வைத்திருப்பதற்கான தனிப்பட்ட காரணம் இருந்தால் தவிர.
</details>
