# கணினி பயன்பாட்டு முகவர்கள் (CUA) உருவாக்குதல்

கணினி பயன்பாட்டு முகவர்கள் ஒரு நபர் செய்கிறபடி இணையதளத்துடன் தொடர்பு கொள்கின்றனர்: ஒரு உலாவி திறந்து, பக்கத்தை ஆய்வு செய்து, அவர்கள் பார்க்கும் அடுத்த சிறந்த செயல்பாட்டை மேற்கொள்கின்றனர். இந்த பாடத்தில், நீங்கள் Airbnb-ஐத் தேடும், கட்டமைக்கப்பட்ட பட்டியல் தரவை எடுக்கின்ற, மற்றும் ஸ்டாக்ஹோல்மில் குறைந்த விலை வாடகையை கண்டறியும் உலாவி தானியங்கி முகவரைக் கட்டும்.

இந்த பாடம் Browser-Use ஐ AI-இயங்கும் வழிசெலுத்தலுக்கு, Playwright மற்றும் Chrome DevTools Protocol (CDP) உலாவி கட்டுப்பாட்டுக்கு, Azure OpenAI பார்வை-இயங்கும் காரணமாக்கலுக்கு, மற்றும் Pydantic கட்டமைக்கப்பட்ட எடுப்பிற்கு இணைக்கும்.

## அறிமுகம்

இந்த பாடத்தில் உங்களுக்கு கற்பதற்காக:

- API மட்டும் தானியக்கத்துக்குப் பதிலாக கணினி பயன்பாட்டு முகவர்கள் எப்போது சிறந்தவை என்பதை புரிந்துகொள்ளல்
- Browser-Use ஐ Playwright மற்றும் CDP உடன் இணைத்து நம்பகமான உலாவி வாழ்க்கைச் சுற்றம் மேலாண்மை செய்வது
- Azure OpenAI பார்வை மற்றும் கட்டமைக்கப்பட்ட Pydantic வெளியீட்டைப் பயன்படுத்தி இயக்கமுள்ள வலைபக்கங்களில் இருந்து பட்டியல் தரவை எடுப்பது
- ஒரு முகவர் முதல், நடிப்பாளர் முதல், அல்லது கலந்த உலாவி தானியக்க பணிமுறை எப்போது பயன்படுத்த வேண்டும் என்பதில் முடிவெடுக்குதல்

## கற்றல் குறிக்கோள்கள்

இந்த பாடத்தை முடித்த பிறகு, நீங்கள் அறிந்துகொள்ளுவீர்கள்:

- Browser-Use ஐ Azure OpenAI மற்றும் Playwright உடன் உருவாக்குவது
- ஒரு உண்மையான இணையதளத்தை வழிசெல்லும் மற்றும் இயக்கமுள்ள UI கூறுகளை கையாளும் உலாவி தானியக்க பணிமுறை உருவாக்குவது
- காணக்கூடிய பக்க உள்ளடக்கத்திலிருந்து டைப் செய்யப்பட்ட முடிவுகளை எடுத்து அவற்றை வணிகத் தர்க்கத்துக்கு மாற்றுவது
- உலாவி பணியை எவ்வாறு கணிக்க முடியும் என்பதைப் பொறுத்து முகவர் மற்றும் நடிப்பாளர் மாற்றங்களை தேர்ந்தெடுத்தல்

## குறியீட்டுத் உதாரணம்

இந்த பாடத்தில் ஒரு நோட்புக் படிமுறை அடங்கும்:

- [15-browser-user.ipynb](./15-browser-user.ipynb): CDP இன் மூலம் Chrome அமர்வை துவக்கி, ஸ்டாக்ஹோல்மிற்கான Airbnb பட்டியல் தேடும், Browser-Use பார்வை மூலம் விலைகளை எடுக்கச் செய்தல், மற்றும் குறைந்த விலை விருப்பத்தை கட்டமைக்கப்பட்ட தரவாக தருதல்.

## முன் தேவைகள்

- Python 3.12+
- உங்கள் சூழலில் கட்டமைக்கப்பட்ட Azure OpenAI அமைப்பு
- உள்ளூர் இயந்திரத்தில் Chrome அல்லது Chromium நிறுவல்
- Playwright சார்ந்தவை நிறுவல்
- async Python அடிப்படை அறிமுகம்

## அமைப்பு

நோட்புக் இல் பயன்படுத்தப்படும் தொகுதிகளை நிறுவுக:

```bash
pip install browser_use playwright python-dotenv
playwright install chromium
```

நோட்புக் பயன்படுத்தும் Azure OpenAI சுற்றுச்சூழல் மாறிகளை அமைக்கவும்:

```bash
AZURE_OPENAI_ENDPOINT=...
AZURE_OPENAI_API_KEY=...
AZURE_OPENAI_CHAT_DEPLOYMENT_NAME=...
# விருப்பமானது: தவிர்த்துவிட்டால் சமீபத்திய API பதிப்புக்கு இயல்பாக அமைக்கப்படும்
AZURE_OPENAI_API_VERSION=...
```

## கட்டமைப்பு கண்ணோட்டம்

நோட்புக் கலந்துள்ள ஹைப்ரிட் உலாவி தானியக்க பணிமுறையை காட்டுகிறது:

1. Playwright மற்றும் Browser-Use இரண்டும் ஒரே உலாவி அமர்வை பகிரக்கூடிய CDP இயங்கும் Chrome துவக்கம்.
2. Browser-Use முகவர் Airbnb ஐ திறக்கும், பாப்-அப்புகளை நீக்கும், மற்றும் ஸ்டாக்ஹோல்மிற்கான தேடலைச் செய்வது போன்ற திறந்த முடிவுறுத்தல் வழிசெல்லல் பணிகளை கவனிக்கும்.
3. பட்டியல் தலைப்புகள், அன்றாட விலைகள், மதிப்பீடுகள், மற்றும் URL களை எடுக்க கட்டமைக்கப்பட்ட Pydantic திட்டமிடல் கொண்டு செயற்பாட்டுப் பக்கம் ஆய்வு செய்யப்படுகிறது.
4. எடுக்கப்பட்ட பட்டியல்களை Python காரணமாக்கல் ஒப்பிட்டு குறைந்த விலை முடிவை வெளிப்படுத்துகிறது.

இந்த முறையில் Browser-Use இன் நெகிழ்வான பார்வை அடிப்படையிலான காரணமாக்கலை வைத்திருப்பதோடு நீங்கள் தேவையான போது தீர்மானமான உலாவி கட்டுப்பாட்டை வழங்குகிறது.

## முக்கியக் கற்றல் மூலாதாரங்கள் மற்றும் சிறந்த நடைமுறைகள்

### எப்போது முகவரைக் க்குப் பயன்படுத்த வேண்டும் மற்றும் எப்போது நடிப்பாளரை

| சூழ்நிலை | முகவரைக் க்குப் பயன்பாடு | நடிப்பாளர்க் க்குப் பயன்பாடு |
|----------|-----------|-----------|
| இயக்கமுள்ள அமைப்பளிகள் | ஆம், AI பக்க மாற்றங்களுக்கு தக்க மாற்றம் செய்ய முடியும் | இல்லை, மெல்லிய தேர்வதிகள் உடையும் |
| தெரிந்த அமைப்பு | இல்லை, முகவர் நேரடி கட்டுப்பாட்டுக்கு ஒப்பிடுகையில் மெதுவாக உள்ளது | ஆம், விரைவு மற்றும் துல்லியமானது |
| கூறுகள் கண்டுபிடித்தல் | ஆம், இயற்கை மொழி நன்றாக செயல்படும் | இல்லை, கணுக்கமது தேர்வதிகள் அவசியம் |
| நேர ஒழுங்கு கட்டுப்பாடு | இல்லை, குறைவான கணிக்கக்கூடியது | ஆம், காத்திருப்பு மற்றும் மீண்டும் முயற்சிக்கும் முழு கட்டுப்பாடு |
| சிக்கலான பணிமுறைகள் | ஆம், எதிர்பாராத UI நிலைகளை கையாள முடியும் | இல்லை, தெளிவான கிளைமடிப்பு தேவை |

### Browser-Use சிறந்த நடைமுறைகள்

1. ஆராய்ச்சி மற்றும் இயக்கமுள்ள வழிசெலுத்தலுக்கு முதலில் முகவரைக் கொண்டு துவக்கவும்.
2. பரிமாற்றம் கணிக்கக்கூடியதாக மாறும் போது நேரடி பக்க கட்டுப்பாட்டுக்கு மாற்றவும்.
3. எடுக்கப்பட்ட தரவு சோதிக்கப்பட்டு மற்றும் வகைப்பாடு பாதுகாப்பானதாக இருக்க கட்டமைக்கப்பட்ட விளைவுப் மாதிரிகளை பயன்படுத்தவும்.
4. தெரியக்கூடிய UI மாற்றங்களை தூண்டும் நடவடிக்கைகளுக்குப் பிறகு தாமதங்களை நுணுக்கமாகச் சேர்க்கவும்.
5. தோல்விகள் கண்டுபிடிக்க எளிதாக்க படமாக திரைக்காட்சி எடுப்பதை தொடர்ந்தே செய்யவும்.
6. இணையதளங்கள் மாறும் என்று எதிர்பார்த்து பாப்-அப்புகளுக்கும் அமைப்புப் மாற்றங்களுக்கும் எதிர்Fallback யுத்தியைகளை வடிவமைக்கவும்.
7. நெகிழ்வும் துல்லியமும் இரண்டையும் பெற முகவரையும் நடிப்பாளரையும் கலக்கவும்.

### மெய்நிகர் உலக பயன்பாடுகள்

- பயணம் மொழுதல் மற்றும் விலை கண்காணிப்பு
- மின் வணிக விலை ஒப்பீடு மற்றும் கிடைக்கும்படியான சோதனைகள்
- இயக்கமுள்ள இணையதளங்களில் கட்டமைக்கப்பட்ட எடுப்பு
- பார்வை-அறிந்த UI சோதனை மற்றும் உறுதி
- இணையதள கண்காணிப்பு மற்றும் அலெர்ட்
- பல-படி ஓட்டங்களில் நுண்ணறிவான படிவ நிரப்பல்

## மெய்நிகர் உலக உதாரணம்: மைக்ரோசாஃப்ட் திட்ட ஒப்பால்

இந்த பாடத்தில் நீங்கள் உருவாக்கும் முகவர் ஒரு சிறிய, உள்ளூரான **கணினி பயன்பாட்டு முகவர் (CUA)** — ஒரு நபர் போன்று உலாவியை இயக்கும் ஒரு திட்டமாகும். மைக்ரோசாஃப்ட் இதே கோரிக்கையை நிறுவனத்துக்காக கொண்டு வருகிறது **[Project Opal (Frontier)](https://support.microsoft.com/en-us/microsoft-365-copilot/get-started-with-project-opal-frontier)** என்ற Microsoft 365 Copilot இல் உள்ள ஒரு செயல்பாடாக.

Project Opal உடன், நீங்கள் ஒரு பணியை விவரிக்கிறீர்கள் மற்றும் அந்த முகவர் உங்கள் சார்பில் **பாதுகாப்பான Windows 365 Cloud PC இல் கணினி பயன்பாட்டை** பயன்படுத்தி, உங்கள் நிறுவனத்தின் உலாவி அடிப்படையிலான பயன்பாடுகள், தளங்கள் மற்றும் தரவுகளை இயக்குகிறது. இது **பின்னணியில் ஒழுங்குமுறைப்படி செயல்படுகிறது**, நீங்கள் பணியை வழிநடத்தலாம் அல்லது எப்போது வேண்டுமானாலும் கட்டுப்பாட்டை எடுக்கலாம். உதாரண பணிகள் உள்ளன:

- பாதுகாப்பு குழு உறுப்பினர் கோரிக்கைகளை நிர்வகித்தல்
- ஒழுங்கு ஆய்வுக்காக கணக்கெடுப்பு சான்றுகளை சேகரித்தல் மற்றும் சரிபார்த்தல்
- IT சம்பவங்களைக் கூட்டல் (டிக்கெட் நிலை புதுப்பிப்பு, உரிமையாளர்கள் ஒதுக்குதல், நகல்கள் மூடல்)
- நிதி முடிவுப் பிரகடனத்திற்கு எக்செல் தரவை தொகுத்தல்

Opal என்பது ஒரு **உற்பத்தி தரமான, நம்பகமான** கணினி பயன்பாட்டு முகவர் எப்படி இருக்கும் என்பதற்கான பயனுள்ள குறிப்பு — மற்றும் இது முன்னோர் பாடல்களில் உள்ள கருத்துக்களை வலுப்படுத்துகிறது:
