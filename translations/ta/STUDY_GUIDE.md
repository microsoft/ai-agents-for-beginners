# தொடக்கநிலை AI முகவரிகள் - படிப்பு வழிகாட்டி

இந்த வழிகாட்டியை பாடநெறியில் நீங்கள் பயணிக்கும்போது நடைமுறை துணையாக பயன்படுத்தவும். இது
பாடங்களை மாற்றும் நோக்கில் இல்லை. இது எங்கே இருந்து தொடங்க வேண்டும், ஒவ்வொரு
பாடத்திலும் என்ன தேடுவது, மற்றும் அந்தக் கருத்துக்களை சிறிய வேலை செய்யக்கூடிய முகவர்
டெமோவாக எப்படி இணைக்க வேண்டும் என்பதைக் கூகிக்க உதவுகிறது.

இது உங்கள் முதல் முறையானால், எளிமையாக துவங்குங்கள்:

1. [Course Setup](./00-course-setup/README.md) ஐ படியுங்கள்.
2. பாடங்கள் 01-06-ஐ வரிசையாக முடிக்கவும்.
3. ஒரு சிறிய டெமோ யோசனையை மனதில் வைத்துக் கற்கவும்.
4. ஒவ்வொரு பாடத்திற்குப் பிறகு கேட்டுக் கொள்ளுங்கள்: "எது என் முகவர் இப்போது
   செய்ய முடியும் ஆனால் முன்னர் முடியாது?"

## மனதில் வைக்க ஒரு எளிய டெமோ

முகவரிகள் கற்க ஒரு நல்ல வழி பாடநெறி முழுவதும் ஒரு டெமோ யோசனையை பின்பற்றுவதாகும்.

எடுத்துக்காட்டு டெமோ: **ஒரு பாடநெறி உதவி முகவர்**.

பயனர் கேட்கிறார்:

> "எனக்கு முகவர்கள் கருவிகளை எப்படி பயன்படுத்துகிறார்கள் என்பதை கற்றுக்கொள்ள விரும்புகிறேன். சரியான பாடங்களை கண்டுபிடி, நான் முதலில் எதை
> படிக்க வேண்டும் என்பதைக் சுருக்கி கூறு, மற்றும் எனக்கு ஒரு சிறிய பயிற்சி பணி கொடு."

சாதாரண chatbot அதன் தொடக்க அறிவிலிருந்து பதில் வழங்கும். ஒரு முகவர் இதை விட அதிகம் செய்ய முடியும்:

1. **பாடநெறி கோப்புகளை படிக்க அல்லது தேட** சரியான பாடங்களை கண்டுபிடிக்க.
2. **கருவிகளை பயன்படுத்தி** பாட இணைப்புகள், எடுத்துக்காட்டுகள் அல்லது ஆதரவு பொருட்களை பெற.
3. **ஒரு குறுகிய கற்றல் பாதையை திட்டமிடு** ஒரே நீண்ட பதிலை விட.
4. **நடப்பு உரையாடல் சூழலை பயன்படுத்தி** கற்றவனின்
   இலக்கை கவனம் செலுத்தி இரு.
5. **பயனுள்ள விருப்பங்களை நினைவில் வையுங்கள்** பயன்பாடு நினைவகத்தைக் கையாளும்போது.
6. **சான்றுகள், மேற்கோள்கள் அல்லது பதிவு விளைவுகளை காட்டுங்கள்** பயனர் நிகழ்வுகளை புரிந்து கொள்ள.
7. **ஆபத்தான நடவடிக்கைகள் அல்லது நுண்ணறிவான தரவுகளை பயன்படுத்தும் முன் பாதுகாப்பு வடிகட்டிகள்** பயன்படுத்துங்கள்.

ஒவ்வொரு பாடத்தையும் கற்கும்போது, இந்த டெமோவுக்கு திரும்பி கேளுங்கள்: இந்த பாடம் எந்த புதிய திறனை சேர்க்கும்?


## நீங்கள் எதை உருவாக்க நினைக்கிறீர்கள்

பாடநெறி முடிவுக்கு, நீங்கள் விளக்கி உருவாக்க முடியும் முகவர் அமைப்புகள் இதில் உள்ள பகுதிகளை இணைக்கும்:


| பகுதி | பொதுவான அர்த்தம் | டெமோவில் |
|------|------------------------|-------------|
| மாதிரி | பயனர் கோரிக்கையை விவரிப்பதற்கான காரண விளக்கம் இயந்திரம் | கற்றவன் கருவி பயன்பாடு தொடர்பான பாடங்களை விரும்புவதை புரிகிறது |

## மாதிரிகள் மற்றும் வழங்குநர்கள்

பாட கோட் எடுத்துக்காட்டுகள் **Microsoft Agent Framework (MAF)** பயன்படுத்துகிறது மற்றும் குறிக்கோள் **Azure OpenAI Responses API** — எதிர்காலமாக பரிந்துரைக்கப்படும் API, இது அரட்டை முடிவுகள், கருவி அழைப்புகள், பல்வகை உள்ளீடுகள் மற்றும் நிலையான உரையாடல்களை ஒரு API மேற்பரப்பில் இணைக்கிறது. நீங்கள் **Microsoft Foundry** திட்டத்தின் மூலம் (`FoundryChatClient`) அல்லது நேரடியாக Azure OpenAI-ஐ (`OpenAIChatClient`) மூலம் இணைக்க முடியும்.


பாடங்களை செய்யும்போது, உங்களுக்கு சில வழங்குநர் விருப்பங்கள் உள்ளன:

- **Microsoft Foundry / Azure OpenAI (Responses API)** — பாடங்களின் முழுவதும் பயன்படுத்தப்படும் பிரதான பாதை. விசையில்லா Entra ID அங்கீகாரத்திற்கு `az login` மூலம் உள்நுழையவும்.
- **Foundry Local** — மொத்தமாக சாதனத்திலேயே OpenAI-க்கு இணக்கமான API மூலம் மாதிரிகள் இயங்கும் (முகமது மேகம் இல்லை, API விசைகள் இல்லை). ஆட்ஃப்லைனில் அல்லது இலவசத் தேர்விற்கு சிறந்தது. [Course Setup](./00-course-setup/README.md) பார்க்கவும்.
- **MiniMax** — பெரிய சூழல் மாதிரிகளுடன் கூடிய OpenAI-க்கு இணக்கமான வழங்குநர், மாற்றுப் பயன்படுத்தலாம்.

> **குறிப்பு:** GitHub Models ஓய்வு பெற்றவையாகும் (ஜூலை 2026-ல் ஓய்வு பெறுகிறது) மற்றும் Responses API-யை ஆதரிக்காது. மாதிரிகள் Azure OpenAI / Microsoft Foundry ஐ பயன்படுத்த புதுப்பிக்கப்பட்டுள்ளன.

## பிரசாரம் செய்யப்பட்ட முகவர்களை ஸ்மோக் சோதனைகளுடன் சரிபார்த்தல்

நீங்கள் ஒரு முகவரை பிரசாரம் செய்துள்ள போது (பாடம் 16), **ஸ்மோக் சோதனை** மிகச் சைக்
செலவுள்ள முதன்மை சரிபார்ப்பு ஆகும் அது பிரசாரம் நேர்மையாக பதிலளிக்கிறதா என்பது. இந்த ரெப்போவை இடுக்குமா
[tests/](./tests/README.md) கீழ் ஏற்கனவே இயக்க தயாராகவும் பிரசாரம் செய்யக்கூடிய முகவர்களுக்கான பட்டியல்கள் கொண்டிருப்பதாக
01, 04, 05 மற்றும் 16 பாடங்களின்,
[AI Smoke Test](https://github.com/marketplace/actions/ai-smoke-test) GitHub
செயலியை இணைத்து. அதனை பாடத்தின் முகவருக்கு பிரதானமான **Actions** தாவலில் இயக்கவும்.
ஸ்மோக் சோதனைகள் ஒரு முதன்மை வாயில் — ஆஃப்லைன் மற்றும் ஆன்லைன் மதிப்பீடு (பாடங்கள 10 மற்றும் 16)
உங்கள் முகவர் எவ்வளவு *சிறந்தது* என்பதைக் கூறும்.

## ஆரம்ப நிலை வாரியாக முக்கியக் கருத்துக்கள்

### கருவிகள்

ஒரு கருவி என்பது முகவர் மாடலின் வெளியில் பணி செய்யக் கூடியதாகும். ஒரு நல்ல கருவி
தெளிவான பெயர், குறுகிய பணி, தரப்பட்டுள்ள உள்ளீடுகள், கணிக்கப்பட்ட வெளிவரும் விளைவுகள் மற்றும்
தோல்விக்கு ஒரு பாதுகாப்பான வழி கொண்டது ஆகும்.

பாட உதவித் டெமோவுக்கான கருவி உதாரணமாக இருக்கலாம்:

- `search_lessons(query)`
- `read_lesson(path)`
- `create_practice_task(topic)`

### RAG மற்றும் அறிவு

RAG மூலம் முகவர் ஊகிக்காமல் மூலப்பொருளிலிருந்து பதிலளிக்க உதவுகிறது. இந்த
பாடத்தில், அந்த மூலப்பொருள் பாடம் READMEகள், குறியீட்டு உதாரணங்கள் அல்லது பாடங்களிலிருந்து இணைக்கப்பட்ட
வெளிப்புற வளங்கள் ஆக இருக்கலாம்.

பதில் ஆவணங்கள், தரவுகள் அல்லது தற்போதைய
திட்ட கோப்புகளின் அடிப்படையில் இருக்கும்போது RAG ஐ பயன்படுத்தவும்.

### திட்டமிடல்

கோரிக்கையில் அதிக படிகள் இருந்தால் திட்டமிடல் பயன்படும். திட்டங்களை குறுகியதும்
டெவலப்பர் அல்லது பயனர் ஆய்வு செய்யக்கூடிய அளவிற்கு தெளிவாகவும் வைக்கவும்.

டெமோக்கான ஒரு திட்டம் இப்படித்தான் இருக்கலாம்:

1. கருவி பயன்பாட்டுக்கு சம்பந்தப்பட்ட பாடங்களை கண்டறிதல்.
2. மிகவும் தொடர்புடைய பாடங்களை சுருக்கி கூறுதல்.
3. ஒரு பயிற்சி பணியை பரிந்துரைத்தல்.

### சூழல்

சூழல் என்பது அந்த நேரத்தில் மாடல் பார்க்கும் விஷயம். குறைந்த சூழல்
முக்கிய விவரங்களை தவறவிடக்கூடும். அதிகமான சூழல் முகவருக்கு மெதுவாகவும்
செலவாகவும் அல்லது குழப்பமாகவும் உருவாக்கக்கூடும்.

நல்ல சூழல் பொறியியல் என்பது அடுத்து மாடல் அழைக்கப் பெறும் சரியான
தகவலை தேர்ந்தெடுப்பதாகும்.

### நினைவகம்

நினைவகம் என்பது பிறகு பயன்படக்கூடிய தகவலை சேமிப்பது. எல்லாவற்றையும் சேமிக்க வேண்டாம். பயன்படக்கூடிய,
பாதுகாப்பான மற்றும் எளிதில் புதுப்பிக்கவோ அழிக்கவோ கூடிய தகவல்களைச் சேமிக்கவும்.

உதாரணமாக, "கற்றுக்கொள்வவர் Python உதாரணங்களை விரும்புகிறார்" என்ற நினைவில் வைத்து உதவும்.
தனிப்பட்ட அதிர்ச்சியூட்டும் தகவலை நினைவில் வைத்திருக்க வேண்டாம்.

### மதிப்பீடு மற்றும் கண்காணித்தல்

மதிப்பீடு கேட்கிறது: முகவர் சரியான செயல்பாடு செய்ததா?

கண்காணித்தல் கேட்கிறது: அது எப்படி நிகழ்ந்தது என்பதை நாம் காண முடியும்?

உற்பத்தி முகவர்களுக்காக, மாடல் அழைப்புகள், கருவி அழைப்புகள், மீட்டெடுக்கப்பட்ட சூழல்,
தாமதம், செலவு, தோல்விகள் மற்றும் பயனர் பின்னூட்டம் ஆகியவற்றை கண்காணிக்கவும்.

### நம்பிக்கை மற்றும் பாதுகாப்பு

நம்பகமான முகவர்களுக்கு உதவிய விளக்கத்துடன் மட்டுமல்லாது கூடுதல் பாதுகாப்பும் தேவை. குறைந்த உரிமை கருவிகள் பயன்படுத்தவும்,
அதிக தாக்கம் கொண்ட செயல்களுக்கு மனித அனுமதி, தேவையான இடங்களில் தரவு மறைத்தல் மற்றும்
சோதனை செய்ய வேண்டிய செயல்களுக்கு பதிவுகள் அல்லது ரசீதுகள் வைக்கவும்.

## 15-நிமிட மதிப்பாய்வு முறையியல்

ஒவ்வொரு பாடத்தின் பிறகு இந்த முறையியைப் பயன்படுத்தவும்:

1. **பாடத்தை ஒரே வாக்கியத்தில் சுருக்கவும்.**
2. **புதிய முகவர் திறனை பெயரிடவும்.** உதாரணமாக: கருவி பயன்பாடு, மீட்பு,
   திட்டமிடல், நினைவகம், கண்காணித்தல் அல்லது பாதுகாப்பு.
3. **அதை பாட உதவித் டெமோவில் சேர்க்கவும்.** இப்போது டெமோவில் என்ன மாற்றங்கள் ஏற்பட்டுள்ளன?
4. **ஆபத்தில் இருப்பதை கண்டுபிடி.** இந்த திறன் தவறாக பயன்படுத்தப்பட்டால் என்ன தவறு ஏற்படலாம்?
5. **ஒரு சோதனை கேள்வி எழுதவும்.** எப்படி முகவர் சரியாக நடந்து கொள்வதை நீங்கள் சரிபார்ப்பீர்கள்?

## விரைவு சுய-சோதனை

பின்வரும் கேள்விகளுக்கு பதில் சொல்ல முயற்சிக்கவும்:

1. ஒரு முகவர் தனக்கே உரிய முறையில் என்ன செய்ய முடியும், பொதுவான சாதாரண chatbot செய்ய முடியாதது என்ன?
2. உங்கள் முகவருக்கு முதலில் எது கருவியாக வேண்டும், மற்றும் ஏன்?
3. முகவரின் பதிலை எதை அடிப்படையாகக் கொண்டு வழங்க வேண்டும்?
4. அடுத்த மாடல் அழைப்பில் எந்த சூழல் இருக்க வேண்டும்?

5. முகவர் என்ன நினைவில் வைக்க வேண்டும், மற்றும் எதை சேமிப்பதைத் தவிர்க்க வேண்டும்?
6. முகவர் எப்போது மனித ஒப்புதலைக் கேட்க வேண்டும்?
7. பின்னர் முகவரை டீபக் அல்லது ஆடிட் செய்ய உதவுவதற்கான எந்த பதிவுகள், தடயங்கள் அல்லது ரசீதுகள் உங்களுக்கு உதவும்?


## பரிந்துரை செய்யப்பட்ட சிறந்த கண்காட்சி பயிற்சி

பாடத்தின் முடிவில், ஒரு கற்கலர் இந்த
கிடமாலை பதிவேடில் பயணிப்பதில் உதவும் ஒரு சிறிய முகவரியை உருவாக்கவும்.

குறைந்தபட்ச பதிப்பு:

- பயனரிடமிருந்து ஒரு தலைப்பை ஏற்று கொள்ளவும்.
- மிகவும் பொருத்தமான பாடங்களை கண்டறியவும்.
- முதலில் என்ன வாசிக்க வேண்டும் என்பதன் சுருக்கத்தை வழங்கவும்.
- ஒரு கைமுறை பயிற்சி பணியை பரிந்துரைக்கவும்.
- பயன்படுத்திய பாடக் கோப்புகள் அல்லது இணைப்புகளை காட்டவும்.

விரிவாக்க பதிப்பு:

- கற்கலரின் விருப்பமான நிரலாக்க மொழியை நினைவில் வைக்கவும்.
- பதில் அளிப்பதற்கு முன் ஒரு எளிய திட்டத்தை பயன்படுத்தவும்.
- இறுதி பதிலுக்கு முன் ஒரு சுய-சோதனை படியை சேர்க்கவும்.
- கருவி அழைப்புகள் மற்றும் பெற்ற மூலங்களை பதிவு செய்யவும்.
- உலாவி அல்லது UI தானியங்கி பணிகளைத் திறப்பதற்கு முன் உறுதிப்படுத்த கேளுங்கள்.

இதனால், ஒரு திட்டத்தில் கருவிகள், RAG, திட்டமிடல்,
சூழல், நினைவகம், கவனிப்புசார் திறன் மற்றும் நம்பிக்கை ஆகியவற்றை பயிற்சி செய்ய ஒரு சிறிய ஆனால் நிஜமான வழி பெறப்படுகிறது.
