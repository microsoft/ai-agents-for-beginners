# முகவர் முறைProtocols (MCP, A2A மற்றும் NLWeb) பயன்படுத்துதல்

[![Agentic Protocols](../../../translated_images/ta/lesson-11-thumbnail.b6c742949cf1ce2a.webp)](https://youtu.be/X-Dh9R3Opn8)

> _(இந்த பாடத்தின் வீடியோவைப் பார்க்க மேலுள்ள படத்தைக் கிளிக் செய்யவும்)_

செயற்கை நுண்ணறிவு முகவர்களின் பயன்பாடு அதிகரிக்கும் போதிலும், தரநிலை உறுதிப்படுத்தல், பாதுகாப்பு மற்றும் திறந்த புதுமையை ஆதரிக்கும் நடைமுறைகளுக்கான தேவையும் அதிகரிக்கிறது. இந்த பாடத்தில், இந்த தேவையை பூர்த்தி செய்யும் 3 நடைமுறைகளைப் பற்றி பார்ப்போம் - மாடல் செരுகல் நடைமுறை (MCP), முகவர்-முகவர் (A2A) மற்றும் இயற்கை மொழி வலை (NLWeb).

## அறிமுகம்

இந்த பாடத்தில் நாம் கற்கப்போகுவது:

• எப்படி **MCP** செயற்கை நுண்ணறிவு முகவர்கள் வெளிப்புற சாதனங்கள் மற்றும் தரவுகளை அணுக அனுமதித்து பயனரின் பணிகளை முடிக்க உதவுகிறது.

• எப்படி **A2A** வெவ்வேறு AI முகவர்களுக்கிடையேயான தொடர்பும் ஒத்துழைப்பும் வழிவகுக்கிறது.

• எப்படி **NLWeb** எந்த இணையதளத்திலும் இயற்கை மொழி இடைமுகங்களை கொண்டு AI முகவர்கள் உள்ளடக்கத்தை கண்டுபிடித்து தொடர்பு கொள்ள உதவுகிறது.

## கற்கும் இலக்குகள்

• AI முகவர்களின் சூழலில் MCP, A2A மற்றும் NLWeb இன் முக்கிய நோக்கம் மற்றும் நன்மைகளை **அறிதல்**.

• ஒவ்வொரு நடைமுறையும் LLMக்கள், சாதனங்கள் மற்றும் பிற முகவர்களுக்கிடையேயான தொடர்பு மற்றும் தொடர்பு தொடர்பை எவ்வாறு வசதியாக்குகிறது என்பதை **விளக்குதல்**.

• கடின முகவர் அமைப்புகளை கட்டிட ஒவ்வொரு நடைமுறை வாசலுக்கு ஒதுக்கப்படும் வேறுபட்ட பங்களிப்புகளை **அறிதல்**.

## மாடல் செருகல் நடைமுறை

**மாடல் செருகல் நடைமுறை (MCP)** என்பது செயலிகளுக்கு LLMக்களுக்கு நிரல்படுத்தும் சூழலும் சாதனங்களையும் வழங்கும் திறந்த தரநிலை ஆகும். இது AI முகவர்கள் தொடர்பு கொள்ளக்கூடிய வெவ்வேறு தரவுநம்பல்கள் மற்றும் சாதனங்களுக்கு "பொது இணைப்பான்" போல செயல்பட உதவுகிறது.

MCP இன் கூறுகளைக் காண்போம், நேரடி API பயன்பாட்டுடன் ஒப்பிடும் நன்மைகள் மற்றும் AI முகவர்கள் MCP சேவையகத்தை எப்படி பயன்படுத்தலாம் என்பது பற்றான ஒரு உதாரணம்.

### MCP முதன்மை கூறுகள்

MCP என்பது **கிளையண்ட்-சேவையகம் கட்டமைப்பில்** இயங்குகிறது, முக்கிய கூறுகள்:

• **ஹோஸ்ட்கள்** என்பது MCP சேவையகத்துடன் இணைப்பை தொடங்கும் LLM செயலிகள் (எ.கா., VSCode போன்ற குறிச்சொற்சார்ந்த ஆசிரியர்).

• **க்ளையண்ட்கள்** என்பது ஹோஸ்ட் செயலிக்குள் இருக்கும் கூறுகள், ஒரே சேவையகத்துடன் தனிப்பட்ட இணைப்புகளை பராமரிக்கின்றன.

• **சேவையகங்கள்** என்பது சிறிய எழுதப்பட்ட நிகழ்ச்சிகள், குறிப்பிட்ட திறன்களை வெளிப்படுத்தும்.

நடைமுறையில் மூன்று அடிப்படை மூலக்கூறுகள் உள்ளன, அவை MCP சேவையகத்தின் திறன்கள்:

• **சாதனங்கள்**: AI முகவர் பணி செய்ய அழைக்கக்கூடிய தனிப்பட்ட செயல்கள் அல்லது செயல்பாடுகள். உதாரணமாக, வானிலை சேவை "வானிலை பெற" சாதனம், அல்லது இன்னொரு e-commerce சேவையகம் "பொருள் வாங்க" சாதனம் கொண்டிருக்கலாம். MCP சேவையகங்கள் ஒவ்வொரு சாதனத்தின் பெயர், விளக்கம் மற்றும் உள்ளீடு/வெளியீடு வடிவமைப்பை அறிவிக்கின்றன.

• **வளங்கள்**: MCP சேவையகம் வழங்கக்கூடிய, வாசிக்கக்கூடிய தரவு பொருட்கள் அல்லது ஆவணங்கள், க்ளையண்ட்கள் கோரிக்கை பிறகு பெறக்கூடியவை. உதாரணங்கள்: கோப்பு உள்ளடக்கம், தரவுத்தள பதிவுகள் அல்லது பதிவு கோப்புகள். வளங்கள் உரை (எ.கா., குறியீடு அல்லது JSON) அல்லது இரட்டை வடிவில் (படங்கள், PDFகள்) இருக்கலாம்.

• **ஆரம்பக்கோப்புகள்**: முன்கூட்டியே வரையறுக்கப்பட்ட வார்ப்புருக்கள், சிக்கலான வேலைநிறைவு முறைகளுக்கான முன்னோட்டக் கோரிக்கைகள்.

### MCP இன் நன்மைகள்

MCP AI முகவர்களுக்கு பரிதாபமான பலன்களை அளிக்கிறது:

• **இயல்பான சாதனம் கண்டுபிடிப்பு**: முகவர்கள் சேவையகத்திலிருந்து கிடைக்கக்கூடிய சாதன பட்டியலை மற்றும் அவை என்ன செய்கிறன என்பது குறித்து விளக்கங்களுடன் பெற முடியும். இதனால் API மாற்றம் அடிக்கடி ஏற்படும் நியமித குறியீட்டு புதுப்பிப்புகளில் இருந்து விடுபட முடியும்; MCP "ஒரு முறை ஒருங்கிணை" அணுகுமுறையை வழங்குகிறது, இது அதிக நுட்பத்துவத்தைக் கொண்டது.

• **பல LLMகளுக்கு இடையேயான ஒருங்கிணைப்பு**: MCP வெவ்வேறு LLMகளோடு பணிபுரியும், இது நிதானமாக கோர் மாடல்களை மாற்றுவதற்கான சுதந்திரத்தை அதிகரிக்கிறது.

• **தரநிலையாக்கப்பட்ட பாதுகாப்பு**: MCP ஒரு தரநிலையாக்கப்பட்ட அங்கீகார முறையை கொண்டுள்ளது, இது MCP சேவையகங்களுக்கு அணுகல்களை விரிவாக்கிக்கொள்ளும் போது எளிதாக்குகிறது. இதுவும் வேறு பொதுவான API க்கான விசைகள் மற்றும் அங்கீகார வகைகளை நிர்வகிப்பதை முன்னிலையில் எளிமைப்படுத்துகிறது.

### MCP உதாரணம்

![MCP Diagram](../../../translated_images/ta/mcp-diagram.e4ca1cbd551444a1.webp)

பயனர் MCP கொண்டு இயக்கப்படும் AI உதவியாளரின் மூலம் ஒரு விமானம் முன்பதிவு செய்ய விரும்புகிறார் என கற்பனை செய்யவும்.

1. **இணைப்பு**: AI உதவியாளர் (MCP கிளையண்ட்) ஒரு விமான சேவையகத்தால் வழங்கப்பட்ட MCP சேவையகத்துடன் இணைக்கிறது.

2. **சாதனக் கண்டுபிடிப்பு**: கிளையண்ட் விமான சேவையகத்தின் MCP சேவையகத்திடம், "உங்களிடம் எந்த சாதனங்கள் உள்ளன?" என்று கேட்கிறது. சேவையகம் "விமானங்கள் தேடு" மற்றும் "விமானங்கள் முன்பதிவு செய்ய" போன்ற சாதனங்களுடன் பதிலளிக்கிறது.

3. **சாதன் அழைப்பை**: பின்னர் நீங்கள் AI உதவியாளரை "போர்ட்லாந்திலிருந்து ஹோனொலுலுவுக்கு ஒரு விமானம் தேடவும்" என்று கேட்கிறீர்கள். AI உதவியாளர் LLM பயன்படுத்தி "விமானங்கள் தேடு" சாதனத்தை அழைக்க வேண்டும் என அறிவதும் தேவையான இடம், இலக்கு போன்ற அளவுருக்களை MCP சேவையகத்துக்கு அனுப்புவதும்.

4. **நடைபெறும் செயல்பாடு மற்றும் பதில்**: MCP சேவையகம் உருவகமாக விமான சேவையகத்தின் உள்ளக முன்பதிவு API-வை அழைக்கிறது. பின்னர் விமானப் படிவமான (எ.கா., JSON தரவு) தகவலை பெற்று AI உதவியாளருக்கு அனுப்புகிறது.

5. **மேலும் தொடர்பு**: AI உதவியாளர் விமான விருப்பங்களை வெளிப்படுத்துகிறது. நீங்கள் ஒரு விமானத்தை தேர்ந்தெடுத்ததும், உதவியாளர் "விமானம் முன்பதிவு செய்" சாதனத்தை அழைத்து முன்பதிவை முடிக்கலாம்.

## முகவர்-முகவர் நடைமுறை (A2A)

MCP LLMக்களை சாதனங்களுடன் இணைக்கும் அதே நேரத்தில், **முகவர்-முகவர் (A2A) நடைமுறை** வெவ்வேறு AI முகவர்களுக்கிடையேயான தொடர்பும் ஒத்துழைப்பும் மேம்படுத்துகிறது. A2A வெவ்வேறு நிறுவனங்கள், சூழல்கள் மற்றும் தொழில்நுட்ப கட்டமைப்புகளை கடந்த AI முகவர்களை இணைத்து ஒரு பொதுவான பணியை முடிக்க உதவுகிறது.

A2A கூறுகள் மற்றும் நன்மைகளை பார்க்கவுடன், பயண பயன்பாடு சூழலில் எவ்வாறு பயன்படுத்தலாம் என்பதையும் நாம் கவனிப்போம்.

### A2A முதன்மை கூறுகள்

A2A, முகவர்களுக்கிடையில் தொடர்பை செயல்படுத்தும் மற்றும் பயனர் துணைப் பணியை நிறைவேற்ற ஒத்துழைக்கச் செய்யும் குறிக்கோளுடன் செயல்படும். ஒவ்வொரு கூறும் இதற்கு பங்களிக்கிறது:

#### முகவர் அட்டை

MCP சேவையகம் சாதன பட்டியலை பகிர்ந்து கொள்வது போல, முகவர் அட்டையில்:
- முகவரின் பெயர்.
- அதை முடிக்கும் பொது பணிகள் பற்றிய **விளக்கம்**.
- மற்ற முகவர்கள் (அல்லது மனிதர்கள்) அந்த முகவரை எப்போது மற்றும் ஏன் அழைக்க விரும்புவர் என்பதை புரிய உதவும் **சிறந்த திறன்கள் பட்டியல்** மற்றும் விளக்கத்துடன்.
- முகவரின் **தற்போதைய முடிவு URL**.
- முகவர் வழங்கும் **பதிப்பு** மற்றும் **சிறந்த திறன்கள்** (உதாரணமாக ப்ரூஸ் ரિસ்பான்ஸ் மற்றும் புஷ் அறிவிப்புகள்).

#### முகவர் நிறைவேற்றுபவர்

முகவர் நிறைவேற்றுபவர் பயனர் உரையாடல் சூழலை தொலை முகவருக்கு **கொடுக்க பொறுப்பானவர்**. தொலை முகவர் இதன் பணியை புரிந்து கொள்ள இது அவசியம். A2A சேவையகத்தில், முகவர் தன் சொந்த LLM-ஐ பயன்படுத்தி வரவிருக்கும் கோரிக்கைகளைப் பகுப்பாய்வு செய்து உள்ளக சாதனங்களை இயக்கி பணியை நிறைவேற்றுகிறது.

#### கலைப்படைப்பு

தொலை முகவர் கோரிய பணியை முடித்ததும், அதன் வேலை பொருள் கலைப்படைப்பாக உருவாக்கப்படுகிறது. கலைப்படைப்பு **முகவரின் பணியின் முடிவுகள்**, **முடிக்கப்பட்டதன் விளக்கம்**, மற்றும் நடைமுறையின் மூலம் அனுப்பப்படும் **உரைச் சூழல்** உள்ளடங்கும். கலைப்படைப்பு அனுப்பப்பட்டபிறகு தொலை முகவருடன் இணைப்பு முடிக்கப்படுகிறது மீண்டும் தேவையானபோது திறக்கப்படும்.

#### நிகழ்வு வரிசை

இவை **அப்டேட்ஸ் மற்றும் செய்திகளை கையாள பயன்படுத்தப்படுவது**. சில AI முகவர் அமைப்புகளில், பணிகள் நீண்ட நேரம் எடுத்துக் கொண்டால் முகவர்களுக்கிடையேயான இணைப்பை பணிக் முடிக்கும் க்குள் மூடுவதை தடுக்க இதன் முக்கியத்துவம் அதிகம்.

### A2A இன் நன்மைகள்

• **மேம்பட்ட ஒத்துழைப்பு**: வெவ்வேறு விற்பனையாளர் மற்றும் தள முகவர்களை இணைத்து தங்களைப் பகிர்ந்து கொண்டும் ஒருங்கிணைந்து செயல்படவும் இது உதவுகிறது, இதனால் வழக்கமாக தனித்தனியாக இருக்கும் அமைப்புகளுக்கு இடையே தற்செயல் மிகவும் எளிதாகிறது.

• **மாடல் தேர்வு சுதந்திரம்**: ஒவ்வொரு A2A முகவரும் தங்களுடைய கோரிக்கைகளுக்குப் பயன்படுத்த LLM-ஐ தேர்வு செய்ய முடியும். இதனால் ஒவ்வொரு முகவருக்கும் சிறந்த அல்லது நுட்பம்படுத்திய மாடலை பயன்படுத்திக் கொள்ளலாம், MCP-ல் இருக்கும் ஒரே LLM இணைப்புடன் வேறுபாடாக.

• **உள்ளுணர்வு அங்கீகாரம்**: அங்கீகாரம் நேரடியாக A2A நடைமுறையில் ஒருங்கிணைக்கப்பட்டுள்ளது, இது முகவர் தொடர்புகளுக்கு பலவீனமற்ற பாதுகாப்பை தருகிறது.

### A2A உதாரணம்

![A2A Diagram](../../../translated_images/ta/A2A-Diagram.8666928d648acc26.webp)

இப்போது பயண முன்பதிவு நிலையில் A2A-யைப் பயன்படுத்தி கூறுகளை விரிவாக்குவோம்.

1. **பயனர் கோரிக்கை பல முகவர்களுக்குள்**: பயனர் "அடுத்த வாரம் ஹோனொலுலு முழு பயணத்தை முன்பதிவு செய்யவும், விமானங்கள், ஹோட்டல் மற்றும் வாடகை கார் உட்பட" என்று கூறி "பயண முகவர்" A2A கிளையண்ட்/முகவருடன் தொடர்பு கொள்கின்றார்.

2. **பயண முகவரின் ஒருங்க incoஒவை**: பயண முகவர் இந்த சிக்கலான கோரிக்கையை பெற்றுக் கொள்ளும். தன் LLM பயன்படுத்தி பணியை ஆராய்ந்து பிற சிறப்பு முகவர்களுடன் தொடர்பு கொள்ள வேண்டியதை தீர்மானிக்கிறது.

3. **முகவர் இடையேயான தொடர்பு**: பயண முகவர் lẹhinนั้น "விமான முகவர்," "ஹோட்டல் முகவர்," மற்றும் "கார் வாடகை முகவர்" போன்ற அனைத்து வணிக நிறுவனங்கள் உருவாக்கிய முகவர்களுடன் A2A நடைமுறையை பயன்படுத்தி இணைகிறது.

4. **துரிதக் கடமை நிறைவேற்றல்**: பயண முகவர் இந்த சிறப்பு முகவர்களுக்கு ("ஹோனொலுலு செல்லும் விமானங்களை தேடு," "ஹோட்டல் முன்பதிவு செய்," "கார் வாடகைக்கு எடு") போன்ற குறிப்பிட்ட பணிகளை அனுப்புகிறது. ஒவ்வொரு முகவரும் தங்கள் சொந்த LLMஐ இயக்கு அல்லது தமது தனிப்பட்ட சாதனங்கள் மூலம் இதில் பங்கேற்கின்றன (அவை தெளிவாக MCP சேவையகங்களாக இருக்கலாம்).

5. **கூட்டிய பதில்**: அனைத்து கீழ் முகவர்களும் பணிகளை முடித்ததும், பயண முகவர் (விமான விவரங்கள், ஹோட்டல் உறுதிப்பத்திரம், கார் வாடகை முன்பதிவு) முடிவுகளை தொகுத்து பயனருக்கு ஒரு சுட்டி உரையாடல் வடிவில் விடை அனுப்புகிறது.

## இயற்கை மொழி வலை (NLWeb)

இணையதளங்கள் நீண்ட காலமாகப் பயனர்கள் தகவலும் தரவுகளும் அணுகுவதற்கான முதன்மை வழியாக உள்ளன.

NLWeb இன் வெவ்வேறு கூறுகளை, NLWeb இன் நன்மைகள் மற்றும் எவ்வாறு எங்கள் பயண பயன்பாட்டில் NLWeb செயல்படுகிறது என்பதை பார்ப்போம்.

### NLWeb கூறுகள்

- **NLWeb செயலி (முதன்மை சேவை நிரல்)**: இயற்கை மொழி கேள்விகளை செயல்முறைப்படுத்தும் அமைப்பு. இது தளத்தின் வெவ்வேறு பகுதிகளை இணைத்து பதில்களை உருவாக்கிறது. இதுவே ஒரு இணையதளத்தின் இயற்கை மொழி அம்சங்களுக்கு ஓர் **இயந்திரமாக** செயல்படுகிறது.

- **NLWeb நடைமுறை**: இணையதளத்துடன் இயற்கை மொழியில் அடிப்படை விதிமுறைகளை கொண்டது. இது JSON வடிவில் (அதிகமாக Schema.org பயன்படுத்தி) பதில்களை அனுப்புகிறது. இதன் நோக்கம் “AI வலை”க்கான ஒரு எளிய அடித்தளம் உருவாக்குவதாகும், HTML ஆனது ஆவணங்களை ஆன்லைனில் பகிர்வதை எளிதாக்கியது போல.

- **MCP சேவையகம் (மாடல் செருகல் நடைமுறை முடிவு)**: ஒவ்வொரு NLWeb அமைப்பும் MCP சேவையகமாகவும் செயல்படுகிறது. இது மற்ற AI அமைப்புகளுடன் சாதனங்களையும் தரவுகளையும் பகிர்ந்து கொள்ள உதவுகிறது. முறையில், இணையதள உள்ளடக்கம் மற்றும் திறன்கள் AI முகவர்களால் பயன்படுத்தப்படக்கூடியதாக மாறி “முகவர் சூழல்” இன் ஒரு பகுதி ஆக்குகிறது.

- **இணைப்பு மாடல்கள்**: இணையதள உள்ளடக்கத்தை எண் வடிவமான பிரதிநிதித்துவங்களாக (என்பிங்களாக) மாற்ற பயன்படுத்தப்படும் மாடல்கள். இவை பொருளை கணினிகள் ஒப்பிடுவதற்கும் தேடுவதற்கும் பயன்படுத்தக்கூடிய முறையில் அர்த்தமளிக்கின்றன. இவை ஒரு தனித்த தரவுத்தளத்தில் வைத்திர்க்கப்படுகின்றன, பயனர்கள் எந்த இணைப்பு மாடலை பயன்படுத்த விரும்புகிறாரோ அதை தேர்வு செய்ய முடியும்.

- **வெக்டர் தரவுத்தளம் (திருப்பித் தரும் அமைப்பு)**: இணையதள உள்ளடக்க இணைப்புகளை சேமிப்பது இந்நிலையகம். யாரோ கேள்வி கேட்டால், NLWeb வெக்டர் தரவுத்தளத்தை பரிசோதித்து மிகவும் பொருந்தக்கூடிய தகவலை வேகமாக கண்டுபிடிக்கிறது. இது ஒருங்கிணைக்கப்பட்ட பதில்களின் பட்டியலை தருகிறது, ஒத்தசார்பில் வரிசைப்படுத்தப்பட்ட. NLWeb க்யூட்ரான்ட், ஸ்நோபிளேக், மில்வஸ், அஜுரே AI தேடல் மற்றும் Elasticssearch போன்ற வெவ்வேறு வெக்டர் சேமிப்பு அமைப்புகளுடன் வேலை செய்கிறது.

### NLWeb உதாரணம்

![NLWeb](../../../translated_images/ta/nlweb-diagram.c1e2390b310e5fe4.webp)

மீண்டும் எங்கள் பயண முன்பதிவு இணையதளத்தை கவனிக்கவும், ஆனால் இப்போது அது NLWeb மூலம் இயக்கப்படுகிறது.

1. **தரவு சேர்ப்பு**: பயண இணையதளத்தின் உள்ள முன்பதிவு பொருள் பட்டியல்கள் (விமான பட்டியல்கள், ஹோட்டல் விளக்கங்கள், சுற்றுலா பாடகிகள்) Schema.org பயன்படுத்தி வடிவமைக்கப்பட்டு அல்லது RSS ஊர்களின் மூலம் ஏற்றப்பட்டவை. NLWeb சாதனங்கள் இந்த கட்டமைக்கப்பட்ட தரவை ஏற்க, இணைப்புகளை உருவாக்கி உள்ளூர் அல்லது தொலை பலகை தரவுத்தளத்தில் சேமிக்கும்.

2. **இயற்கை மொழி கேள்வி (மனிதர்)**: பயனர் இணையதளத்தை அணுகி மெனுக்களைத் திரும்ப பார்க்காமல் ஒரு உரையாடல் இடைமுகத்தில் "அடுத்த வாரம் ஹோனொலுலு ஒரு குடும்ப நண்பரான ஹோட்டலை மண்குளியலுடன் கண்டுபிடி" என்று தட்டச்சு செய்கிறார்.

3. **NLWeb செயலாக்கம்**: NLWeb செயலி கேள்வியை பெறுகிறது. இந்த கேள்வியை புரிந்து கொள்ள ஒரு LLMக்கு அனுப்பி, அதே நேரத்தில் வெக்டர் தரவுத்தளத்திலிருந்து தொடர்புடைய ஹோட்டல் பட்டியலை தேடுகிறது.

4. **தூய்மையான முடிவுகள்**: LLM தரவுத்தளத்திலிருந்து பெறப்பட்ட தேடல் முடிவுகளை விளக்குவதற்கு உதவுகிறது, "குடும்ப நட்பு", "குளியலறை" மற்றும் "ஹோனொலுலு" என்ற அளவுகோல்களின் அடிப்படையில் சிறந்த பொருந்துதல்களை அடையாளம் கண்டுபிடித்து இயற்கை மொழி பதிலை வடிவமைக்கிறது. முக்கியமாக, பதில் இணையதளத்தின் உண்மையான ஹோட்டல்களை குறிப்பிடுகிறது, குறைகள் தவிர்க்கப்படுகின்றன.

5. **AI முகவர் தொடர்பு**: NLWeb என்பது MCP சேவையகமாக செயல்படுவதால், வெளிப்புற AI பயண முகவரும் இந்த இணையதளத்தின் NLWeb நிகழ்வுக்கு இணைக்கலாம். அந்த AI முகவர் `ask` MCP முறையை பயன்படுத்தி நேரடியாக கேள்வி கேட்க முடியும்: `ask("ஹோனொலுலு பகுதியில் ஹோட்டல் பரிந்துரைக்கப்பட்ட வேகன் உணவகங்களே உள்ளனவா?")`. இதற்கு NLWeb இந்த கேள்வியை செயலாக்கி, உணவக தகவலின் தரவுத்தளத்தை பயன்படுத்தி (ஏற்றப்பட்டால்) கட்டற்ற JSON பதிலை வழங்கும்.

### MCP/A2A/NLWeb பற்றி மேலும்அறிய விரும்புகிறீர்களா?

மற்ற கற்றலில் உள்ளவர்களை சந்தித்து, அலுவலக நேரங்களில் கலந்துரையாடி உங்கள் AI முகவர் கேள்விகளுக்கு பதில் பெற [Microsoft Foundry Discord](https://discord.com/invite/ATgtXmAS5D) இல் இணைந்துகொள்ளுங்கள்.
