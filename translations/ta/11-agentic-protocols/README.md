# முகவரியாக செயல்படும் ஒப்பந்தங்கள் பயன்படுத்துதல் (MCP, A2A மற்றும் NLWeb)

[![முகவரியாக செயல்படும் ஒப்பந்தங்கள்](../../../translated_images/ta/lesson-11-thumbnail.b6c742949cf1ce2a.webp)](https://youtu.be/X-Dh9R3Opn8)

> _(இந்த பாடத்தின் வீடியோவை காண மேலே உள்ள படத்தை கிளிக் செய்யவும்)_

கலா முகவரிகள் பயன்படுத்தப்படுவது அதிகரிப்பதால், நிலையானமை, பாதுகாப்பு மற்றும் திறந்த கண்டுபிடிப்பை ஆதரிக்கும் ஒப்பந்தங்களுக்கான தேவை அதிகரிக்கிறது. இந்த பாடத்தில், இந்த தேவையை பூர்த்தி செய்யும் 3 ஒப்பந்தங்களை நாம் கற்போம் - மாதிரி சூழல் ஒப்பந்தம் (MCP), முகவர் முதல் முகவருக்கு (A2A) மற்றும் இயற்கை மொழி வலை (NLWeb).

## அறிமுகம்

இந்த பாடத்தில் நாம் கற்போம்:

• எப்படி **MCP** AI முகவர்களுக்கு பாவனையாளர் பணிகளை நிறைவேற்ற வெளிப்புற கருவிகள் மற்றும் தரவு அணுகலை அனுமதிக்கிறது.

• எப்படி **A2A** வெவ்வேறு AI முகவர்களுக்கிடையேயான தொடர்பு மற்றும் ஒத்துழைப்பை தூண்டுகிறது.

• எப்படி **NLWeb** எந்தவொரு இணையதளத்திலும் இயற்கை மொழி இடைமுகங்களை கொண்டு AI முகவர்களுக்கு உள்ளடக்கத்தை கண்டுபிடித்து தொடர்பு கொள்ள உதவுகிறது.

## கற்றல் இலக்குகள்

• AI முகவர்களின் சூழலில் MCP, A2A மற்றும் NLWeb இன் முக்கிய நோக்கம் மற்றும் நன்மைகளை **அறிதல்**.

• ஒவ்வொரு ஒப்பந்தமும் LLMகள், கருவிகள் மற்றும் பிற முகவர்களுக்கிடையேயான தொடர்பு மற்றும் இடைமாற்றத்தை எவ்வாறு எளிதாக்குகிறது என்பதை **விளக்குதல்**.

• சிக்கலான முகவரி அமைப்புகளை கட்டுவதில் ஒவ்வொரு ஒப்பந்தமும் வகிக்கும் வேறுபட்ட பங்குகளை **பேரறிதல்**.

## மாதிரி சூழல் ஒப்பந்தம்

**மாதிரி சூழல் ஒப்பந்தம் (MCP)** என்பது பயன்பாடுகள் LLMகளுக்கு சூழல் மற்றும் கருவிகளை வழங்குவதற்கான நிலையான வழிமுறையை வழங்கும் திறந்த தரநிலை ஆகும். இது AI முகவர்கள் தொடர்பு கொள்ளக்கூடிய வேறு தரவுத் தொற்கள் மற்றும் கருவிகளுடன் ஒரே விதமான "பொதுவான இணைப்பை" செயற்படுத்துகிறது.

MCP இன் கூறுகளையும் நேரடி API பயன்பாட்டை விட வாதான நன்மைகளையும், AI முகவர்கள் ஒரு MCP சர்வரை எப்படி பயன்படுத்தக்கூடும் என்பதற்கான உதாரணத்தையும் பார்ப்போம்.

### MCP முக்கிய கூறுகள்

MCP ஒரு **கிளையன்ட்-சர்வர் கட்டமைப்பில்** இயங்குகிறது மற்றும் முக்கிய கூறுகள்:

• **ஹோஸ்ட்கள்** LLM பயன்பாடுகள் (உதாரணமாக VSCode போன்ற கோட் திருத்தி) ஆகும், அவை MCP சர்வருக்கு இணைப்புகளை தொடங்குகின்றன.

• **கிளையன்ட்கள்** என்பது ஹோஸ்ட் பயன்பாட்டுக்குள்ள கூறுகள், அவை சர்வர்களுடன் ஒற்றை இணைப்பை பேணுகின்றன.

• **சர்வர்கள்** என்பது குறிப்பிட்ட திறன்களை வெளிப்படுத்தும் லைட்வேய்ட் நிரல்கள் ஆகும்.

ஒப்பந்தத்தில் உள்ள மூன்று முக்கிய ஆரம்பக் கூறுகள் MCP சர்வரின் திறன்கள் ஆகும்:

• **கருவிகள்**: AI முகவர் என்ன செயலாற்ற வேண்டும் என்று அழைக்கக் கூடிய தனித் தனிம செயற்பாடுகள் அல்லது பயன்கள்.例如,எந்த நேர மாலை பருவம் இந்த வானிலை பெறுதல் கருவி, அல்லது வணிக சர்வர் ஒரு பொருள் வாங்குதல் கருவியை வெளிப்படுத்தலாம். MCP சர்வர்கள் ஒவ்வொரு கருவியின் பெயர், விளக்கம் மற்றும் உள்ளீடு/வெளியீடு விவரக்கோவை capability பட்டியலில் விளம்பரப்படுத்துகின்றன.

• **வளங்கள்**: MCP சர்வர் வழங்கக்கூடிய வாசிக்கக்கூடிய தரவு உருப்படிகள் அல்லது ஆவணங்கள், கிளையன்ட்கள் அவற்றை தேவையான போது எடுத்துக் கொள்ள முடியும். உதாரணங்கள் கோப்பின் உள்ளடக்கம், தரவுத்தள பதிவுகள் அல்லது பதிவு கோப்புகள். வளங்கள் உரை (குறியீடு அல்லது JSON போன்ற) அல்லது இரட்டை (படங்கள் அல்லது PDF போன்ற) ஆகியவையாக இருக்கலாம்.

• **ஊக்கவசைகள்**: முன் வகைப்படுத்தப்பட்ட வார்ப்புருக்கள், மேலும் சிக்கலான பணிச்சுற்றளைகளை அனுமதிக்கும்.

### MCP நன்மைகள்

MCP AI முகவர்களுக்கு முக்கிய நன்மைகள் வழங்குகிறது:

• **டையனமிக் கருவி கண்டுபிடிப்பு**: சர்வர் வழங்கும் கருவிகளின் பட்டியலையும் அவை செய்யும் செயல்களின் விளக்கத்தையும் முகவர்கள் நேரடியாக பெற முடியும். இது பாரம்பரிய APIகள் போன்ற ஒருசிலவழிவிலக்காத நிரலாக்க ஆக்கிகளுக்கு மாறுபடுகிறது, ஏனெனில் அவை API மாற்றம் நேர்ந்தால் நிரலை புதுப்பிக்க வேண்டும். MCP "ஒருமுறை இணைப்பு" அணுகுமுறையை வழங்கி அதிக துன்பமில்லா தகுதி தருகிறது.

• **விவித்த LLMகளுக்கு இடையேயான இடைத்தொடர்பு**: MCP வெவ்வேறு LLMகளில் இயங்கும், நல்ல செயல்திறனுக்காக மைய மாதிரிகளை மாற்றுவதற்கு எளிதான துல்லியத்தை வழங்குகிறது.

• **நிலையான பாதுகாப்பு**: MCP பொதுவான அங்கீகார முறையைக் கொண்டுள்ளது, மற்ற MCP சர்வர்களுக்கான அணுகலினை இணைக்கும்போது அளவு உயர்திறம் மேம்படுகிறது. இது பாரம்பரிய APIகளின் பல விசைகள் மற்றும் authentication வகைகளை நிர்வகிப்பதை விட எளிதாகும்.

### MCP உதாரணம்

![MCP Diagram](../../../translated_images/ta/mcp-diagram.e4ca1cbd551444a1.webp)

ஒரு பயனர் MCP வழிமுறையை கொண்ட AI உதவியாளரின் உதவியுடன் விமானப் பதிவை செய்ய விரும்புவதாக நினைத்துக் கொள்ளவும்.

1. **இணைப்பு**: AI உதவியாளர் (MCP கிளையன்ட்) விமான நிறுவனத்தால் வழங்கப்பட்ட MCP சர்வருடன் இணைகிறது.

2. **கருவி கண்டுபிடி**: கிளையன்ட் விமான நிறுவனத்தின் MCP சர்வருக்கு "எந்த கருவிகள் உங்களிடம் உள்ளன?" என்று கேட்கிறது. சர்வர் "விமானங்களை தேடு" மற்றும் "விமானங்களை பதிவு செய்" போன்ற கருவிகளை பதிலளிக்கிறது.

3. **கருவி அழைப்பு**: பின்னர் நீங்கள் AI உதவியாளரிடம் "போர்ட்லாந்திடமிருந்து ஹொனொலூலுவுக்கு ஒரு விமானத்தை தேடவும்" என்று கேட்கும். AI உதவியாளர், தனது LLM மூலம், "விமானங்களை தேடு" கருவியை அழைக்க வேண்டும் என்று அறிவதுடன் பாராமெட்டர்களை (தொடக்கம், இலக்கு) MCP சர்வருக்கு அனுப்புகிறது.

4. **நிர்வாகம் மற்றும் பதில்**: MCP சர்வர், ஒரு சுற்றுச்சூழலாக செயல்பட்டு விமான நிறுவனர் உள்ளமைவு பதிவு API-யை πραγμαமாக அழைக்கிறது. பின்பு விமானத் தகவலை பெறுகிறது (எடுத்துக்காட்டு: JSON தரவு) மற்றும் அதை AI உதவியாளருக்கு அனுப்புகிறது.

5. **மேல் தொடர்பு**: AI உதவியாளர் விமான விருப்புகளை வழங்குகிறது. நீங்கள் விமானத்தைத் தேர்ந்தெடுத்தவுடன், உதவியாளர் அதே MCP சர்வரில் "விமான பதிவேடு" கருவியை அழைத்து பதிவை நிறைவேற்றலாம்.

## முகவர் முதல் முகவருக்கு ஒப்பந்தம் (A2A)

MCP LLMகளை கருவிகளுடன் இணைக்க கவனித்தாலும், **முகவர் முதல் முகவருக்கு (A2A) ஒப்பந்தம்** பல்வேறு AI முகவர்களுக்கிடையேயான தொடர்பு மற்றும் ஒத்துழைப்பை எடுக்கிறது. A2A வெவ்வேறு நிறுவனங்கள், சூழல்கள் மற்றும் தொழில்நுட்ப ஸ்டாக்களுக்கிடையே AI முகவர்களை இணைக்கிறது மற்றும் பகிர்ந்த பணியை நிறைவேற்ற உதவுகிறது.

A2A கூறுகளையும் நன்மைகளையும், மற்றும் எவ்வாறு எங்கள் பயண பயன்பாட்டில் இது பயன்படுத்தப்படலாம் என்பதற்கான உதாரணத்தையும் காண்போம்.

### A2A முக்கிய கூறுகள்

A2A முகவரி இடையேயான தொடர்பை தூண்டுவதாகவும் பயனரின் துணைப்பணியை நிறைவேற்ற ஒத்துழைக்குமாறு அமைக்கப்பட்டுள்ளது. ஒப்பந்தத்தின் ஒவ்வொரு கூறும் இதற்கு பங்களிக்கிறது:

#### முகவர் அட்டை

MCP சர்வர் கருவிகளின் பட்டியலை பகிர்ந்தது போல், ஒரு முகவர் அட்டையில் உள்ளது:
- முகவரின் பெயர்.
- அது நிறைவேற்றும் **பொது பணிகளின் விளக்கம்**.
- மற்ற முகவர்களுக்கு (அல்லது மனித பயனர்களுக்கும்) எப்போது மற்றும் ஏன் அந்த முகவரை அழைக்கவேண்டும் என்பதை புரிய உதவும் **குறிப்பிட்ட திறன்களின் பட்டியல்** மற்றும் விளக்கங்கள்.
- முகவரின் **தற்போதைய இடைமுக URL**.
- ஸ்ட்ரீமிங் பதில்கள் மற்றும் புஷ் அறிவிப்புகள் போன்ற முகவரின் **ஆதிகாரம்** மற்றும் **திறன்கள்**.

#### முகவர் செயல்படுத்துபவர்

முகவர் செயல்படுத்துபவர் பயனர் உரையாடல் சூழலை தொலைபேசி முகவருக்கு **கொடுத்துச் செல்லும் பொறுப்பில் இருக்கிறது**, தொலைபேசி முகவருக்கு செய்ய வேண்டிய பணி புரிந்து கொள்ள இது அவசியம். A2A சர்வரில், ஒரு முகவர் தன் சொந்த மிகப்பெரிய மொழி மாதிரியை (LLM) பயன்படுத்தி வரவிருக்கும் கோரிக்கைகளை பகுப்பாய்வு செய்து தனது உள்ளக கருவிகளைப் பயன்படுத்தி பணிகளை நிறைவேற்றும்.

#### செயல்வளம்

தொலை முகவர் கோரிய பணியை நிறைவேற்றிய பிறகு, அவன் பணிபொருள் ஒரு செயல்வளமாக உருவாக்கப்படுகிறது. செயல்வளம் **முகவரின் பணிக்கான முடிவை**, **நிறைவேற்றப்பட்டதற்கான விளக்கத்தையும்**, மற்றும் ஒப்பந்தத்தின் மூலம் அனுப்பப்படும் **உரை சூழலும்** கொண்டிருக்கிறது. செயல்வளம் அனுப்பப்பட்ட பிறகு, தொலை முகவருடன் இணைப்பு மூடப்படுகிறது, மீண்டும் தேவையானபோது திறக்கப்படும்.

#### நிகழ்வு வரிசை

இது **புதுப்பிப்புகளை மற்றும் செய்திகளை கையாள** பயன்படுத்தப்படுகிறது. இது முகவர்களின் இணைப்பு பணிச்செலுத்தும் முன் மூடப்படாமல் இருக்க முக்கியம், குறிப்பாக பணிகள் நிறைவேற்ற நேரம் அதிகமுள்ள போது.

### A2A நன்மைகள்

• **மேம்படுத்தப்பட்ட ஒத்துழைப்பு**: வெவ்வேறு வணிகர்களும் தளங்களும் சேர்ந்த முகவர்கள் தொடர்பு கொண்டு சூழலை பகிர்ந்து ஒருங்கிணைந்து இயங்கும், பாரம்பரியமாக சோர்வடைந்த அமைப்புகளுக்கு இடையேயான சகஜ இயங்குதளத்தை ஏற்படுத்தும்.

• **மாதிரி தேர்வு சுதந்திரம்**: ஒவ்வொரு A2A முகவரும் தன் கோரிக்கைகளை சேவை செய்ய எந்த LLM பயன்படுத்த வேண்டும் என்று தீர்மானிக்க முடியும், இது சில MCP சூழ்நிலைகளில் உள்ள ஒரே LLM இணைப்பை விட அதிக சிறப்பாக்கம் அல்லது நுட்பச் சீரமைப்பை அனுமதிக்கும்.

• **உள்ளமைக்கப்பட்ட அங்கீகாரம்**: அங்கீகாரம் நேரடியாக A2A ஒப்பந்தத்தில் ஒருங்கிணைக்கப்பட்டுள்ளது, முகவர் தொடர்புகளுக்கான வலுவான பாதுகாப்பு கட்டமைப்பை வழங்குகிறது.

### A2A உதாரணம்

![A2A Diagram](../../../translated_images/ta/A2A-Diagram.8666928d648acc26.webp)

பயண பதிவு காட்சி செய்தியை A2A பயன்படுத்தி விரிவாக்குவோம்.

1. **பல முகவர்களுக்கு பயனர் கோரிக்கை**: பயனர் "ஒன்றாராய்ந்து அடுத்த வாரம் ஹொனொலூலு முழு பயணத்தை, விமானங்கள், ஹோட்டல் மற்றும் வாடகை கார் உட்பட பார்க்கவும்" என்று "பயண முகவர்" A2A கிளையன்ட்/முகவரை தொடர்பு கொள்ளலாம்.

2. **பயண முகவர் ஒருங்கிணைப்பு**: பயண முகவர் இந்த சிக்கலான கோரிக்கையை பெறுகிறது. தன் LLM ஐப் பயன்படுத்தி பணி பற்றி யோசித்து மற்ற சிறப்பான முகவர்களுடன் தொடர்பு கொள்ள வேண்டும் என்று தீர்மானிக்கிறது.

3. **முகவர் முகவர் தொடர்பு**: பயண முகவரி பிற நிறுவனங்கள் உருவாக்கிய "வಿಮಾನ முகவர்," "ஹோட்டல் முகவர்," மற்றும் "கார் வாடகை முகவர்" போன்ற கீழமை முகவர்களுடன் இணைவதற்கு A2A ஒப்பந்தத்தைப் பயன்படுத்துகிறது.

4. **ஒப்படைக்கப்பட்ட பணிகளின் நிறைவு**: பயண முகவர் குறிப்பிட்ட பணிகளை (எ.கா., "ஹொனொலூலுக்கு விமானங்களை கண்டுபிடி," "ஹோட்டல் பதிவு செய்," "கார் வாடகு செய்ய்") இந்த சிறப்பு முகவர்களுக்குக் கொடுக்கிறது. ஒவ்வொரு முகவரும் தன் சொந்த LLMகளையும் கருவிகளையும் (தேவைப்பட்டால் MCP சர்வர்களாக) பயன்படுத்தி தன் பணியை நிறைவேற்றுகிறது.

5. **ஒன்றிணைந்த பதில்**: அனைத்து கீழ்முகவர்களும் பணிகளை முடித்தபின், பயண முகவர் முடிவுகளை (விமான விவரங்கள், ஹோட்டல் உறுதிப்பத்திரம், கார் வாடகை பதிவு) தொகுத்து பயனருக்கு ஒரு உரையாடல் முறையிலான முழுமையான பதிலை அனுப்புகிறது.

## இயற்கை மொழி வலை (NLWeb)

வலைத்தளங்கள் பல வருடங்களாக பயனர்களுக்கு இணையம் முழுவதும் தகவல் மற்றும் தரவு பெறுவதற்கு முதன்மையான வழியாக இருக்கின்றன.

NLWeb இன் பல கூறுகள், நன்மைகள் மற்றும் எங்கள் பயண பயன்பாட்டின் உதாரணத்தால் எவ்வாறு NLWeb வேலை செய்கிறது என்பதைப் பார்ப்போம்.

### NLWeb கூறுகள்

- **NLWeb பயன்பாடு (முக்கிய சேவை குறியீடு)**: இயற்கை மொழி கேள்விகளை செயலாக்கும் அமைப்பு. இது தளத்தின் வெவ்வேறு பகுதிகளை இணைத்து பதில்கள் உருவாக்குகிறது. இதை இணையதளத்தின் இயற்கை மொழி அம்சங்களுக்கு சக்தி அளிக்கும் **எஞ்சின்** என்று நினைக்கலாம்.

- **NLWeb ஒப்பந்தம்**: இணையதளத்துடன் இயற்கை மொழி தொடர்புக்கான அடிப்படை விதிகள். இது பதில்களை JSON வடிவில் (அதிகமாக Schema.org பயன்படுத்தி) அனுப்புகிறது. இது “AI வலை” கான எளிய அடித்தளத்தை உருவாக்கும், அதேபோல் HTML ஆன்லைனில் ஆவணங்களை பகிர உதவியது போன்றது.

- **MCP சர்வர் (மாதிரி சூழல் ஒப்பந்த முடிவுப்புள்ளி)**: ஒவ்வொரு NLWeb அமைப்பும் **MCP சர்வராக** இயங்குகிறது. இதனால் அது மற்ற AI அமைப்புகளுடன் **கருவிகள் (உதாரணமாக 'ask' முறை) மற்றும் தரவை பகிர** முடியும். இதனால் தளத்தின் உள்ளடக்கம் மற்றும் திறன்களை AI முகவர்கள் பயன்படுத்த முடியும், தளம் பரவலான "முகவர் சூழலை" ஒரு பகுதியாக ஆக்கியது.

- **உருபெயர்க்கிணை மாதிரிகள்**: இணையதள உள்ளடக்கங்களை கணக்கியல் பிரதிநிதிகளாக மாற்ற பயன்படுத்தப்படுகின்றன (embedding). இந்த உருபெயர்க்கிணைகள் அர்த்தத்தை கணினிகள் ஒப்பிடும் மற்றும் தேடும் விதத்தில் பிடிக்கின்றன. இவை ஒரு சிறப்பு தரவுத்தளத்தில் சேமிக்கப்படுகின்றன, பயனர்கள் விரும்பும் embedding மாதிரியை தேர்ந்தெடுக்கலாம்.

- **வெக்டர் தரவுத்தளம் (திரும்ப மீட்டெடுக்கும் இயந்திரம்)**: இந்த தரவுத்தளம் **இணையதள உள்ளடக்கங்களின் embeddingகளை சேமிக்கிறது**. யாராவது ஒரு கேள்வி கேட்டால், NLWeb இந்த வெக்டர் தரவுத்தளத்தை விரைவில் சரியான தகவலை கண்டுபிடிக்கச் சரிபார்க்கிறது. அது சிக்கலுக்கு ஏற்ப பதில்களுக்கு விரைவு பட்டியலை தருகிறது. NLWeb Qdrant, Snowflake, Milvus, Azure AI Search, மற்றும் Elasticsearch போன்ற வெவ்வேறு வெக்டர் சேமிப்புக் கணினிகளுடன் வேலை செய்கிறது.

### NLWeb உதாரணம்

![NLWeb](../../../translated_images/ta/nlweb-diagram.c1e2390b310e5fe4.webp)

மீண்டும் எங்கள் பயண பதிவு இணையதளத்தை பார்க்கவும், ஆனால் இங்கே அது NLWeb கொண்டு இயக்கப்படுகிறது.

1. **தரவு ஊட்டுதல்**: பயண இணையதளத்தின் தற்போதைய தயாரிப்பு பட்டியல்கள் (விமான பட்டியல்கள், ஹோட்டல் விளக்கங்கள், சுற்றுலா தொகுப்புக்கள்) Schema.org வடிவில் வடிவமைக்கப்படுகின்றன அல்லது RSS ஊட்டல்களில் ஏற்றப்படுகின்றன. NLWeb கருவிகள் இந்த கட்டமைக்கப்பட்ட தரவைப் பெறுகின்றன, embeddingகளை உருவாக்கி உள்ளூர் அல்லது தொலைஇருப்புப் வெக்டர் தரவுத்தளத்தில் சேமிக்கின்றன.

2. **இயற்கை மொழி கேள்வி (மனிதர்)**: ஒரு பயனர் இணையதளத்தை உலாவி, பட்டை வழிகளைப் பயன்படுத்தாமல் உரையாடல் இடைமுகத்தில் "அடுத்த வாரம் ஹொனொலூலுவில் நீச்சல் குளம் உள்ள குடும்பத் தோழமையான ஹோட்டல் கிடைக்குமா?" என்று தட்டச்சு செய்கின்றனர்.

3. **NLWeb செயலாக்கம்**: NLWeb பயன்பாடு இந்த கேள்வியைப் பெறுகிறது. அதை LLM-க்கு அனுப்பி புரிந்துகொள்கிறது மற்றும் அதே சமயம் தனது வெக்டர் தரவுத்தளத்தில் தொடர்புடைய ஹோட்டல் பட்டியலை தேடும்.

4. **சரியான முடிவுகள்**: LLM தரவுத்தளத்திலிருந்து தேடலைப் பொருள் படுத்தி "குடும்பத் தோழமை," "குளம்," மற்றும் "ஹொனொலூலு" போன்ற அளவுருக்களை அடிப்படையாக கொண்டு சிறந்த போட்டிகளை கண்டுபிடித்து, இயற்கை மொழி பதிலை வடிவமைக்க உதவுகிறது. மிக முக்கியமாக, பதில் இணையதளத்தின் உண்மையான ஹோட்டல்களில் இருந்து வருகிறது, புனைவை தவிர்க்கிறது.

5. **AI முகவர் தொடர்பு**: NLWeb MCP சர்வராக செயல்படுவதால், வெளிப்புற AI பயண முகவரும் இந்த இணையதளத்தின் NLWeb பதிப்புடன் இணைக்கலாம். AI முகவர் அதை நேரடியாக `ask` MCP முறையை பயன்படுத்தி கேட்க முடியும்: `ask("ஹொனோலூலு பகுதியில் ஹோட்டல் பரிந்துரைக்கும் வேகவெஜன் உணவகங்கள் உள்ளனவா?")`. NLWeb இதை செயலாக்கி, அவளுடைய உணவக தகவல் தரவுத்தளம் (ஏற்றப்பட்டிருந்தால்) பயன்படுத்தி கட்டமைக்கப்பட்ட JSON பதிலை வழங்கும்.

### MCP/A2A/NLWeb பற்றி கூடுதல் கேள்விகள் உள்ளதா?

மற்ற கற்றுக்கொள்ளுபவர்களுடன் சந்திக்க, அலுவலக நேரங்களில் கலந்து கொள்ள, மற்றும் உங்கள் AI முகவர் கேள்விகளுக்கு பதில் பெற [Microsoft Foundry Discord](https://discord.com/invite/ATgtXmAS5D) திறந்துவைக்கப்பட்டுள்ளது.
