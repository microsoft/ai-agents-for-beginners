LlamaIndex என்பது Retrieval-Augmented Generation (RAG) உருவாக்க எளிதாக செய்யும் வசதி கொண்டது, ஆனால் எங்கள் கட்டமைப்புகள் முகவர்கள் மற்றும் பல முகவர் அமைப்புகளை உருவாக்கும் விதமாகவும் எளிதாக்குகின்றன! இந்த அமர்வில் நாம் Workflows என்ற எங்கள் அடிப்படைக் கட்டுமானத்தை அறிமுகப்படுத்துவோம், இது முகவரி அமைப்புக்களை நிர்மாணிப்பதற்கான அடிப்படை அங்கமாகும், மேலும் RAG மற்றும் பிற கருவிகளைப் பயன்படுத்தும் ஒரு முகவரியை உருவாக்குவோம்.
