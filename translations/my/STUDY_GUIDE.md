# စတင်လေ့လာသူများအတွက် AI အေးဂျင့်များ - လေ့လာမှုလမ်းညွှန်

သင်္ချာကို အတန်းတွင်သွားရာတွင် လက်တွေ့အသုံးပြုသော မိတ်ဆွေ တစ်ဦးအဖြစ် ဤလမ်းညွှန်ကို သုံးပါ။
သင်ခန်းစာများ အစားထိုးရန် မဖြစ်ပါ။ မည်နေရာမှ စမည်၊
သင်ခန်းစာတစ်ခုချင်းစီတွင် ဘာကိုလေ့လာရန်၊ နိုင်ငံများကို ဘယ်လိုဆက်စပ်၍
အလုပ်ဖြစ်သော agent demo အသေးစားတစ်ခုအဖြစ် ဖွဲ့စည်းရန် အကူအညီပေးသည်။

ဒီမှာ ပထမဆုံးပါက လူကြီးမင်း စတင်ရန် ရိုးရှင်းစွာ စတင်ပါ။

၁။ [သင်တန်းရဲ့ စတင်ပြင်ဆင်ရာ](./00-course-setup/README.md) ကိုဖတ်ပါ။
၂။ သင်ခန်းစာ ၀၁-၀၆ ကို အစဉ်လိုက် ပြီးမြောက်အောင်လုပ်ပါ။
၃။ သင်ယူချိန်မှာ သင့်စိတ်ထားတစ်ခုလောက် အေးအေးဆေးဆေး အသေးစား ဒယ်မိုအိုင်ဒီယာ တစ်ခုကို စိတ်ထဲမှာ ထားပါ။
၄။ သင်ခန်းစာတိုင်းပြီးနောက်မှာ ရှင်းပြပါ။ "ငါ့သံတွဲအေးဂျင့်ဟာ ယခင်က မလုပ်နိုင်ခဲ့တာတွေကို ယခုဘာတွေ လုပ်နိုင်ပြီမလဲ?"
   မေးပါ။

## စိတ်ထဲမှာ သိမ်းထားဖို့ ဒယ်မိုတစ်ခု လွယ်ကူသော

အေးဂျင့်တွေကို လေ့လာရတာအတွက် အကောင်းဆုံး နည်းလမ်းတစ်ခုက ဒယ်မိုအိုင်ဒီယာတစ်ခုကို သင်တန်းတလျှောက် လိုက်နာသွားတာပါ။

ဥပမာ ဒယ်မို - **သင်တန်း အကူအညီ အေးဂျင့်**။

အသုံးပြုသူက မေးတယ်။

> "ငါ အေးဂျင့်တွေက တူလ်တွေကို ဘယ်လို သုံးတယ်ဆိုတာ သင်ယူချင်တယ်။ မှန်ကန်တဲ့ သင်ခန်းစာတွေကိုရှာပါ၊ ငါ ရှိသင့်သလောက်ကို အနှစ်ချုပ်ပြပါ၊ နောက်ပြီး စမ်းသပ်ကိရိယာ တစ်ခု လုပ်စရာ ပေးပါ။"
>

တော်တော်များများသော ဆက်သွယ်ရေး စကားပြောအစက်တွေက သူတို့ သိထားတာတွေကနေ ဖြေဆိုပေးနိုင်တယ်။ အေးဂျင့်ကပိုတတ်တယ်။

၁။ **သင်တန်းဖိုင်တွေကို ဖတ်ပြီး ဒါမှမဟုတ် ရှာဖွေ**မှန်ကန်တဲ့ သင်ခန်းစာတွေကို ရှာဖွေပါ။
၂။ **ကိရိယာတွေကို အသုံးပြုပြီး** သင်ခန်းစာလင့်ခ်တွေ၊ ဥပမာတွေ၊ ဒါမှမဟုတ် ထောက်ပံ့ပစ္စည်းတွေကို ရယူပါ။
၃။ **တိုတောင်းတဲ့ သင်ယူလမ်းကြောင်း** တစ်ခုကို စီမံပုံဖော်ပါ - တစ်ကြောင်းကြီးဖြေမှာ မဟုတ်ပါဘူး။
၄။ **ဉာဏ်ပေါင်းစပ်မှု (context)** ကို စကားဝိုင်းလက်ရှိမှတ်စုကနေ အသုံးပြုပြီး သင်ယူသူရဲ့ ရည်မှန်းချက်မှာ အာရုံစိုက်ထားပါ။

၅။ **သုံးစွဲသူ စိတ်ကြိုက်မူကို မှတ်မိထားပါ** (အကယ်၍ လူမှုဆက်စပ်မှုထောက်ပံ့သည်ဆိုပါက)။
၆။ **ကြောင်းတဲ၊ ကိုးကားချက်များ၊ ဒေတာမှတ်တမ်းများ ပြပါ** - အသုံးပြုသူကျသူ ဘာတွေဖြစ်ပျက်သွားတာနားလည်စေရန်။
၇။ **အန္တရာယ်ရှိတဲ့ လုပ်ဆောင်မှုများ သို့မဟုတ် အရေးကြီးသော ဒေတာများ အသုံးမပြုမီ ကာကွယ်စောင့်ရှောက်မှုများ နောက်လိုက်ပါ။**

သင်ခန်းစာတိုင်းအတူတူသင်ယူစဉ် ရှိတယ်ဆိုရင်၊ ဒီဒယ်မိုကို ပြန်လည်ကြည့်ပါ။ "ဒီသင်ခန်းစာက အသစ်ထည့်လို့ရမယ့် စွမ်းရည်ဘာလဲ?"

## မော်ဒယ်များနှင့် ပံ့ပိုးသူများ

သင်တန်းကုဒ်နမူနာများသည် **Microsoft Agent Framework (MAF)** ကို အသုံးပြု၍ **Azure OpenAI Responses API** ကို ဦးတည်သည် — ရှေ့ဆက်အသုံးပြုရန် အကြံပြုထားသည့် API ဖြစ်ပြီး chat completions, ကိရိယာခေါ်ဆိုခြင်း, မျိုးစုံ input နှင့် အခြေအနေပြောဆိုမှုများကို တစ်ခုတည်းသော API အမျိုးအစားတွင် ပေါင်းစည်းထားသည်။ သင်သည် **Microsoft Foundry** စီမံကိန်းတစ်ခုမှ (`FoundryChatClient` သုံး၍) သို့မဟုတ် တိုက်ရိုက် Azure OpenAI (`OpenAIChatClient` ဖြင့်) တွင် ချိတ်ဆက်နိုင်သည်။

သင်ခန်းစာများကို တက်ရောက်စဉ်တွင် ပံ့ပိုးသူ ရွေးချယ်စရာ အချို့ရှိပါသည်-

- **Microsoft Foundry / Azure OpenAI (Responses API)** — သင်ခန်းစာများအတွင်း အသုံးပြုသော အဓိကလမ်းကြောင်းဖြစ်သည်။ keyless Entra ID အတည်ပြုမှုအတွက် `az login` ဖြင့် စနစ်သို့ ဝင်ရောက်ပါ။
- **Foundry Local** — မော်ဒယ်များကို OpenAI နှင့်ကိုက်ညီသော API မှတဆင့် စက်ပေါ်ပေါင်းစုံဖြင့်ပြေးခြင်း (တိမ်မရှိ၊ API key မလိုပါ) ဖြစ်သည်။ အော့ဖ်လိုင်း သို့မဟုတ် ကုန်ကျစရိတ်မဲ့ စမ်းသပ်မှုများအတွက်အကောင်းဆုံးဖြစ်သည်။ [Course Setup](./00-course-setup/README.md) တွင်ကြည့်ပါ။
- **MiniMax** — ကြီးမားသော context မော်ဒယ်များပါရှိသည့် OpenAI-compatible ပေးသွင်းသူဖြစ်ပြီး drop-in အစားထိုးအဖြစ် အသုံးပြုနိုင်သည်။

> **Note:** GitHub Models ကို အသုံးမပြုတော့ပါ (၂၀၂၆ ဇူလိုင်တွင်ပိတ်မည့်) ခုနှစ်တွင်တိုးတက်မှုမရှိသည့် Responses API ကို မထောက်ပံ့ပါ။ ဆင်ဆာပုံများကို Azure OpenAI / Microsoft Foundry အသုံးပြုအောင် အပ်ဒိတ်ပြုလုပ်ထားပါသည်။

သင်ခန်းစာများ 01, 04, 05 နှင့် 16 တွင်တပ်ဆင်နိုင်သော agent များအတွက်

## အလွယ်တကူ နားလည်နိုင်သော အဓိက အယူအဆများ

### ကိရိယာများ

ကိရိယာဆိုသည်မှာ အေးဂျင့်သည် မော်ဒယ်အပြင်တွင် အလုပ်လုပ်ရန် ခေါ်ယူနိုင်သည့် အရာတစ်ခုဖြစ်သည်။ ကောင်းသောကိရိယာ
သည် အမည်ရှင်းလင်းပြီး၊ အလုပ်နယ်နိမိတ်ကောက်နုတ်ထားပြီး၊ အဝင်များအား တိုက်တိတိစစ်ဆေးထားပြီး၊ ထွက်ရှိမှုကို မျှော်မှန်းနိုင်ပြီး
မအောင်မြင်နိုင်သည့် နည်းလမ်းကိုလည်း လုံခြုံစိတ်ချရစေသည်။

သင်တန်းအကူအညီအတွက် နမူနာမှာ ကိရိယာတစ်ခုဖြစ်နိုင်သည်မှာ -

- `search_lessons(query)`
- `read_lesson(path)`
- `create_practice_task(topic)`

### RAG နှင့် အသိပညာ

RAG သည် အေးဂျင့်အား စမ်းသပ်မှုမဟုတ်ဘဲ အရင်းအမြစ် လက်ခံစွာဖြင့် ဖြေကြားရန် ကူညီပေးသည်။ ဒီသင်တန်းတွင်
အဆိုပါ အရင်းအမြစ်များမှာ သင်ခန်းစာ READMEs, ကုဒ်နမူနာများ၊ သို့သော် သင်ခန်းစာများမှ လင့်ခ်ချီးမွမ်းထားသော ပြင်ပ
အရင်းအမြစ်များ ဖြစ်နိုင်သည်။

ဖြေချက်သည် စာရွက်စာတမ်းများ၊ ဒေတာများ သို့မဟုတ် လက်ရှိပရောဂျက်ဖိုင်များအတွက် အခြေခံရမည့်အခါတွင် RAG ကို အသုံးပြုပါ။


### စီမံကိန်းရေးဆွဲခြင်း

အမှာစာတွင် အဆင့်ပိုများပါဝင်သောအခါ စီမံကိန်းရေးဆွဲခြင်း ကူညီသည်။ စီမံကိန်းများကို တိုတောင်းပြီး
ဖန်တီးသူ သို့မဟုတ် အသုံးပြုသူ အဆင်ပြေအောင် မျက်နှာဖုံးနေရာတွင် ထားပါ။

နမူနာအတွက် စီမံကိန်းတစ်ခုမှာ -

1. ကိရိယာအသုံးပြုမှုနှင့် ဆက်စပ်သည့် သင်ခန်းစာများ ရှာဖွေရန်။
2. အများဆုံး သက်ဆိုင်သော သင်ခန်းစာများကို အကျဉ်းချုပ်ဖော်ပြရန်။
3. လေ့ကျင့်မှု အလုပ်တာဝန်တစ်ခုကို အကြံပြုရန်။

### အကြောင်းအရာ

အကြောင်းအရာ ဆိုသည်မှာ မော်ဒယ် ထင်မြင်မြင်ရသော အချက်များ ဖြစ်သည်။ အကြောင်းအရာနည်းပါက အရေးကြီးသော အသေးစိတ်များ ပျောက်ဆုံးနိုင်ပြီး၊
အကြောင်းအရာများလွန်လွန်ဖြစ်ပါက အေးဂျင့်သည် နှေးကွေး၊ စရိတ်များ တိုးတက်သည် သို့မဟုတ် ရှုပ်ထွေးမှုရောက်ရှိနိုင်သည်။





### မှတ်ဉာဏ်

မှတ်ဉာဏ် ဆိုသည်မှာ နောက်ပိုင်းအတွက် သိမ်းဆည်းထားသည့် အချက်အလက်များ ဖြစ်သည်။ အားလုံးကို မသိမ်းပါနှင့်။ အသုံးဝင်ပြီး၊ လုံခြုံပြီး၊ အသစ်ပြင်ဆင်ခြင်း သို့မဟုတ် ဖျက်ပစ်ခြင်း လွယ်ကူသော အချက်များကိုသာ သိမ်းဆည်းပါ။


ကိုယ်ပိုင် သက်သာခွင့်ပေးသည့် ဒေတာများကို မှတ်မိထားရခြင်း မဟုတ်ပါ။


### အကဲဖြတ်ခြင်းနှင့် မျက်မှောက်ကြည့်ခြင်း

အကဲဖြတ်ခြင်းဆိုသည်မှာ - အေးဂျင့်သည် မှန်ကန်သောအရာကို ပြုလုပ်ခဲ့ပြီလား? ဟု မေးခြင်းဖြစ်သည်။

တွေ့မြင်နိုင်မှုဆိုသည်မှာ - ဘယ်လိုဖြစ်ပျက်ခဲ့သည်ကို ကြည့်ရှုနိုင်ပါသလား?

ထုတ်လုပ်မှုအေဂျင့်များအတွက် မော်ဒယ်ခေါ်ဆိုမှုများ၊ ကိရိယာခေါ်ဆိုမှုများ၊ ဗဟုသုတရရှိမှု၊
စောင့်ဆိုင်းချိန်၊ ကုန်ကျစရိတ်၊ အစွန်းရောက်မှုများနှင့် အသုံးပြုသူတုံ့ပြန်ချက်များကို မှတ်တမ်းတင်ထားပါ။

### ယုံကြည်မှုနှင့် လုံခြုံမှု

ယုံကြည်ရသော အေဂျင့်များတွင် ကူညီပေးသော အချက်အလက်တစ်ခုထက် ပိုမိုလိုအပ်သည်။ အနည်းဆုံးအခွင့်အရေးကိရိယာများ၊
အကျိုးသက်ရောက်မှုအရှိန် မြင့်မားသော လုပ်ဆောင်ချက်များအတွက် လူ့အတည်ပြုချက်၊ လိုအပ်သောနေရာတွင် ဒေတာဖျောက်ထားခြင်းနှင့် လုပ်ဆောင်ချက်များအတွက် မှတ်တမ်းများသို့မဟုတ်
သက်သေများစာရင်းများ ရှိရပါမည်။

## ၁၅ မိနစ်ပြန်လည်သုံးသပ်ခြင်း ပုံစံ

မိနစ် ၁၅ ပြန်လည်သုံးသပ်ခြင်းကို သင်တစ်ခုချင်းပြီးနောက် အသုံးပြုပါ။

1. **သင်ခန်းစာကို စာကြောင်းတစ်ကြောင်းဖြင့် အနှစ်ချုပ်ပါ။**
2. **အေးဂျင့်၏ သစ်သစ်သော စွမ်းဆောင်ရည်ကို နာမည်ပေးပါ။** ဥပမာ - ကိရိယာအသုံးပြုမှု၊ ရရှိမှု၊
   စီမံခန့်ခွဲမှု၊ မေမရီ၊ တွေ့မြင်နိုင်မှု သို့မဟုတ် လုံခြုံမှု။
3. **အဲ့ဒီကို သင်ခန်းစာအကူအညီနှင့် လေ့လာမှုသရုပ်ပြတွင် ထည့်ပါ။** လေ့လာမှုသရုပ်ပြတွင် ဘာပြောင်းလဲသွားပါသလဲ?
4. ** အန္တရာယ်ကို ရှာဖွေပါ။** ဒီစွမ်းဆောင်ရည်ကို မမှန်ကန်စွာ အသုံးချလိုက်ရင် ဘာတွေ ပျက်စီးနိုင်ပါသလဲ?
5. ** စမ်းသပ်မေးခွန်းတစ်ခု ရေးပါ။** အေဂျင့်ကောင်းစွာ အပြုအမူ ပြုမပြုကို ဘယ်လို စစ်ဆေးမလဲ?

## မြန်ဆန်တဲ့ ကိုယ်ပိုင်စစ်ဆေးချက်

ရှေ့ဆက်ရန် မတိုင်ခင် ဒီမေးခွန်းတွေကို ဖြေကြည့်ပါ။

1. အေဂျင့်တစ်ယောက်ဘာတွေကို ပုံမှန် chatbot တစ်ယောက်မလုပ်နိုင်တာကို လုပ်နိုင်သလဲ?
2. မင်းအေးဂျင့်အတွက် ပထမဆုံးလိုအပ်မယ့် ကိရိယာက ဘယ်ဟာလဲ၊ ဤဟာဘာကြောင့်လဲ?
3. အေဂျင့်ရဲ့ ဖြေချက်ကို ဘယ်အကြောင်းအရာ အရင်းအမြစ် များတည်ဆောက်သင့်သလဲ?
4. နောက်တစ်ကြိမ် မော်ဒယ်ခေါ်ဆိုမှုမှာ ဘယ်အကြောင်းအရာကို ထည့်သင့်သလဲ?
5. အေဂျင့်က ဘာတွေကို မှတ်မိထားသင့်သလဲ၊ ဘာတွေကို သိမ်းမထားသင့်ပါသလဲ?
6. ဘယ်အချိန်တွင် အေးဂျင့်က လူ့အတည်ပြုချက် မေးသင့်သလဲ?
7. နောက်ပိုင်း ဒီအေးဂျင့်ကို ပြုပြင်၊ စစ်ဆေးရင် အကူအညီဖြစ်စေမည့် မှတ်တမ်းများ၊ ခြေရာအနာဂတ်များ သို့မဟုတ် သက်သေစာရင်းများက ဘာတွေဖြစ်မလဲ?

## အကြံပြု Capstone လေ့ကျင့်မှု

သင်တန်းဆုံးသတ်မည့်အချိန်တွင်၊ နည်းလမ်းသင်ယူသူတစ်ဦးသည် ဤ
repository တွင် လမ်းညွှန်ကူညီပေးမည့် သေးငယ်သော အေးဂျင့်တစ်ခုကို တည်ဆောက်ပါ။

အနည်းဆုံး ဗားရှင်း-

- အသုံးပြုသူထံမှ ခေါင်းစဉ်တစ်ခုကို လက်ခံပါ။
- အရေးပါတဲ့ သင်ခန်းစာများကို ရှာဖွေပါ။
- ပထမဆုံး ဖတ်ရမည့် အကြောင်းအရာအား အကျဉ်းချုပ်ပြပါ။
- လက်တွေ့လေ့ကျင့်မှု တစ်ခုအတွက် အကြံပေးပါ။
- သင်ခန်းစာဖိုင်များ သို့မဟုတ် လင့်ခ်များကို ပြပါ။

တိုးချဲ့ရန် ဗားရှင်း-

- နည်းလမ်းသင်ယူသူ၏ စိတ်ဝင်စားသော ပရိုဂရမ်မင်းဘာသာစကားကို မှတ်မိပါ။
- ဖြေကြားမှု မပြုမီ ရိုးရှင်းသည့်အစီအစဉ်တစ်ခုကို အသုံးပြုပါ။
- နောက်ဆုံးဖြေကြားမည့်အချိန်တွင် ကိုယ်တိုင်စစ်ဆေးမှု ခြေလှမ်းတစ်ခု ထည့်ပါ။
- ကိရိယာခေါ်မှုများနှင့် ရယူထားသော အရင်းအမြစ်များကို မှတ်တမ်းတင်ပါ။
- ဘရောက်ဇာ သို့မဟုတ် UI automation တာဝန်များကို ဖွင့်ရန် သဘောတူကြောင်း မေးမြန်းပါ။

ယင်းသည် တစ်ခုတည်းသောပရောဂျက်တွင် ကိရိယာများ၊ RAG, စီမံကိန်းရေးဆွဲခြင်း၊
အကြောင်းအရာ၊ မှတ်ဉာဏ်၊ ကြည့်ရှုနိုင်မှုနှင့် ယုံကြည်မှုတို့အား သာမာန်နှင့် သက်တောင့်သက်သာရှိစွာ လေ့ကျင့်ရန် နည်းလမ်းတစ်ခုဖြစ်ပါသည်။
