# စီမံကိန်းဒီဇိုင်း

## နိဒါန်း

ဤသင်ခန်းစာတွင် မျက်စိပွတ်မိမည့်အချက်များမှာ

* စပ်ဆိုင်သော ကျယ်ပြန့်သော ရည်မှန်းချက်ကို သတ်မှတ်ခြင်းနှင့် ခက်ခဲသော တာဝန်ကို စီမံခန့်ခွဲနိုင်သော လုပ်ငန်းများသို့ ခွဲခြားခြင်း။
* ယုံကြည်စိတ်ချရပြီး စက်တွင် ဖတ်ရှုနိုင်သည့် တုံ့ပြန်ချက်များအတွက် ဖွဲ့စည်းတည်ဆောက်ထားသော ထုတ်လွှင့်ချက်ကို အသုံးပြုခြင်း။
* ဖြစ်ရပ်အခြေပြု နည်းလမ်းအား အသုံးပြု၍ ဒိုင်နမစ်အလုပ်များနှင့် မမျှော်လင့်ထားသော အချက်အလက်များကို ကိုင်တွယ်ခြင်း။

## သင်ယူရမည့်ရည်မှန်းချက်များ

ဤသင်ခန်းစာကို ပြီးမြောက်စွာ လေ့လာပြီးနောက်၊ သင်သည် အောက်ပါအချက်များကို နားလည်မှုရှိမည်ဖြစ်သည်။

* AI ကိုယ်စားလှယ်အတွက် ကျယ်ပြန့်သော ရည်မှန်းချက်ကို ဖော်ထုတ် ထား၍ ဘာလုပ်ရန် လိုအပ်သည်ကို ရှင်းပြနိုင်ရန် သတ်မှတ်ပေးနိုင်ခြင်း။
* ခက်ခဲသော တာဝန်ကို စီမံခန့်ခွဲရန် တာဝန်အသေးစားသို့ ခွဲခြားပြီး သေချာတိကျသော အဆင့်လိုက်စဉ်သို့ စုစည်းတင်စားနိုင်ခြင်း။
* ကိုယ်စားလှယ်များကို သင့်တော်သောကိရိယာများ (ဥပမာ- ရှာဖွေရေးကိရိယာများ သို့မဟုတ် ဒေတာသုံးသပ်ခန့်မှန်းကိရိယာများ) ဖြင့်ပြင်ဆင်ပေးနိုင်ခြင်း၊ မည်ခါတွင်၊ မည်သို့ အသုံးပြုရန်ဆုံးဖြတ်ပေးခြင်းနှင့် မမျှော်လင့်ထားသော အခြေအနေများကို ကိုင်တွယ်နိုင်ခြင်း။
* တာဝန်အသေးစားရလဒ်များကို သုံးသပ်ပြီး စွမ်းဆောင်ရည်တိုင်းတာကာ နောက်တစ်ဆင့် အလုပ်လုပ်ဆောင်မှုများတိုးတက်အောင် ပြန်လည်ပြင်ဆင်ခြင်း။

## ကျယ်ပြန့်သော ရည်မှန်းချက်သတ်မှတ်ခြင်းနှင့် တာဝန်ခွဲခြင်း

![Defining Goals and Tasks](../../../translated_images/my/defining-goals-tasks.d70439e19e37c47a.webp)

ပုံမှန်တကယ့်ကမ္ဘာတွင် အလုပ်များသည် တစ်ကြိမ်တည်းဖြင့် မျှသာပြည့်စုံစွာဖြေရှင်း၍ မရနိုင်ကြပါ။ AI ကိုယ်စားလှယ်များသည် ၎င်း၏စီမံချက်များနှင့် လုပ်ဆောင်ချက်များကို ဦးတည်ရန် ရည်မှန်းချက် တိတိကျကျလိုအပ်သည်။ ဥပမာအားဖြင့်၊ ရည်မှန်းချက်မှာ -

    "၃ ရက်ခရီးစဉ်အစီအစဉ် ဖန်တီးရန်။"

ရိုးရိုးရှင်းရှင်း ဖြေဆိုနိုင်သော်လည်း နောက်ထပ် အနည်းဆုံးညှိနှိုင်းမှုလိုအပ်သည်။ ရည်မှန်းချက်သည် အသက်သာကြည်လင်သှားလျှင် AI ကိုယ်စားလှယ် (နှင့် လူ you တွေနှင့် ပူးပေါင်းသူများ) ကို တိကျသော ရလဒ်ရရန် အာရုံစိုက်နိုင်ရန် ကောင်းစေသည်၊ ဥပမာ- လေယာဉ်လက်မှတ်ရွေးချယ်မှုများ၊ ဟိုတယ် အကြံပြုချက်များနှင့် လှုပ်ရှားမှု အကြံပြုချက်များပါရှိသော စုံလင်သော ခရီးစဉ်အစီအစဉ် တစ်ခု ဖန်တီးခြင်း။

### တာဝန်ခွဲခြင်း

ကြီးမား သို့မဟုတ် ခက်ခဲသော အလုပ်များမှာ တာဝန်အသေးစား၊ ရည်မှန်းချက်ပြည့်စုံသော လုပ်ငန်းများသို့ ခွဲခြားခြင်းဖြင့် ပိုမို စီမံနိုင်စေသည်။
ခရီးစဉ်အစီအစဉ် မူရင်းရည်မှန်းချက်ကို အောက်ပါအတိုင်း ခွဲခြားနိုင်ပါသည်။

* လေယာဉ် လက်မှတ် ကြိုတင်စာရင်းသွင်းခြင်း
* ဟိုတယ် ကြိုတင်စာရင်းသွင်းခြင်း
* ကားငှားရမ်းခြင်း
* ကိုယ်ပိုင်သီးသန့်တိုးချဲ့မှု

တာဝန်သူတစ်ဦးစီက ကောင်းမွန်ဆုံးအကြောင်းအရာများကို ရှာဖွေရန်၊ ဟိုတယ်လုပ်ငန်းတွင် အကြောင်းအရာ ပေါင်းစည်းမှုကို ဦးတည်လုပ်ဆောင်နိုင်သည်။ တာဝန်ခံများသုံးသပ်မှုဖြင့် အဆိုပါရလဒ်များကို စုပေါင်း၍ သုံးစွဲသူထံ ပေးပို့သည်။

ဤ မော်ဂျူးရွယ်နည်းပညာသည် တိုးတက်မှုများ ပြုလုပ်သွားရန်လည်း အဆင်ပြေသည်။ ဥပမာ - စားနပ်ရိက္ခာ၊ ဒေသဆိုင်ရာလှုပ်ရှားမှု အကြံပြုချက်များအတွက် ထူးခြားသော ကိုယ်စားလှယ်များ ထည့်သွင်း၍ ခရီးစဉ်ကို စဉ်ဆက်မပြတ် တိုးတက်အောင် ပြုလုပ်နိုင်သည်။

### ဖွဲ့စည်းတည်ဆောက်ထားသော ထုတ်လွှင့်ချက်

ကြီးမားသော ဘာသာစကား မော်ဒယ်များ (LLMs) သည် နောက်ပိုင်း ကိုယ်စားလှယ်များသို့ သို့မဟုတ် ဝန်ဆောင်မှုများကို ပိုမို လွယ်ကူစွာ ဖတ်နိုင်သော ဖွန်ရှင်များအတွက် ဖွဲ့စည်းထားသော ထုတ်လွှင့်ချက် (ဥပမာ- JSON) ကို ဖန်တီးနိုင်သည်။ အထူးသဖြင့် အများအပြား ဆိုက် အဖွဲ့အစည်းများ တည်ဆောက်ထားသော နယ်ပယ်တွင် အလွန်အသုံးဝင်သည်။ စီမံကိန်းထုတ်လွှင့်ချက်လာလျှင် လုပ်ငန်းများကို ဆက်လုပ်ဆောင်နိုင်သည်။

အောက်ပါ Python ကုတ်အပိုင်းမှာ ရည်မှန်းချက်ကို တာဝန်အသေးစားများသို့ ခွဲခြားပြီး ဖွဲ့စည်းတည်ဆောက်ထားသော စီမံကိန်းတစ်ခု ဖန်တီးသည့် ရိုးရှင်းသော စီမံကိန်း ကိုယ်စားလှယ်ကို ပြသသည်။

### ပြင်းစွာ အမျိုးမျိုးသော ကိုယ်စားလှယ် စီမံကိန်း ကိုယ်စားလှယ်

ဤနမူနာတွင် Semantic Router Agent တစ်ဦးက အသုံးပြုသူ၏ တောင်းဆိုချက် (ဥပမာ - "ကျွန်ုပ်၏ ခရီးစဉ်အတွက် ဟိုတယ်အစီအစဉ် လိုအပ်သည်။") ကို လက်ခံသည်။

စီမံခန့်ခွဲသူက စဉ်ဆက်မှတ်ချက်ကို

* ဟိုတယ်အစီအစဉ် လက်ခံသည် - အသုံးပြုသူ၏ စာသားကို လက်ခံပြီး စနစ်က ပြောသော တောင်းဆိုချက်များနှင့် ကိုက်ညီမှုအရ ဖွဲ့စည်းထားသော ခရီးစဉ်အစီအစဉ်ကို ဖန်တီးသည်။
* ကိုယ်စားလှယ်များနှင့် ၎င်းတို့၏ ကိရိယာများအား စာရင်းပြုစုသည် - ကိုယ်စားလှယ် စာရင်းတွင် လေယာဉ်၊ ဟိုတယ်၊ ကားငှားခြင်းနှင့် လှုပ်ရှားမှုများအတွက် ကိုယ်စားလှယ်များ နှင့် ၎င်းတို့က ပေးသည့် လုပ်ဆောင်ချက်များ၊ ကိရိယာများ ပါရှိသည်။
* စီမံကိန်းကို ကိုယ်စားလှယ်များသို့ လမ်းညွှန်ပေးသည် - တာဝန်အသေးစား အရေအတွက်ပေါ်မူတည်၍ စီမံခန့်ခွဲသူသည် တစ်ခုတည်းသော ကိုယ်စားလှယ်သို့ တိုက်ရိုက်ပို့ခြင်း သို့မဟုတ် အများအပြားကိုယ်စားလှယ် ပူးပေါင်းဆောင်ရွက်ရန် အဖွဲ့တစ်ခုထိန်းသိမ်းမှုမှတဆင့် ချိန်ညှိပေးသည်။
* ရလဒ်ကို ချုပ်ဆိုသည် - နောက်ဆုံးတွင် စီမံခန့်ခွဲသူက ဖန်တီးထားသော စီမံကိန်းကို ရှင်းလင်းစွာ ချုပ်ကိုင်ပြီးပေးသည်။
အောက်ပါ Python ကုတ်နမူနာသည် ဤအဆင့်များကို ပြသသည်။

တာဝန်အချို့သည် တစ်ဖန်၊ တစ်ဖန် ပြန်လည်လုပ်ဆောင်မှု သို့မဟုတ် ပြန်လည် စီမံမှုလိုအပ်ပါသည်။ တစ်ခုသော တာဝန်အသေးစားရလဒ်သည် နောက်တစ်ခုတွင် သက်ရောက်မှုရှိသည်။ ဥပမာ - ကိုယ်စားလှယ်သည် လေယာဉ်လက်မှတ် ဝယ်ယူကြည့်နေစဉ် မမျှော်လင့်ထားသော ဒေတာပုံစံတစ်ခု တွေ့ရှိပါက ဟိုတယ် ယူဆောင်မှု မလုပ်မီ ၎င်း၏ မဟာဗျူဟာကို ပြင်ဆင်ရန် လိုအပ်သည်။
