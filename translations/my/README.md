## 🌱 စတင်ခြင်း

ဤသင်တန်းတွင် AI ကိုယ်စားလှယ်များ တည်ဆောက်ခြင်း၏ အခြေခံများကို သင်ကြားပေးသည်။ ဘယ်သင်ခန်းစာကိုမဆို စတင်လေ့လာနိုင်သည်။

ဤသင်တန်းတွင် ဘာသာစကားစုံကို ထောက်ပံ့မှု ရှိသည်။ ကျွန်ုပ်တို့၏ [ရရှိနိုင်သော ဘာသာစကားများကို ဤနေရာတွင်](#-multi-language-support) သွားရောက်ကြည့်ပါ။

မိမိ ပထမဆုံး Generative AI မော်ဒယ်များဖြင့် တည်ဆောက်ခြင်းလုပ်ကိုင်မည့်သူများအတွက် [Generative AI For Beginners](https://aka.ms/genai-beginners) သင်တန်းကို သင်ကြားပေးရာတွင် GenAI ဖြင့် တည်ဆောက်ခြင်းဆိုင်ရာ ၂၁ ခန်းစာပါဝင်သည်။

တုန့်ပြန်မှု (🌟) ပေးရန်နှင့် ကုဒ် တည်ဆောက်ရန်အတွက် ဤ repo ကို [star ပြုလုပ်ပါ](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst) နှင့် [fork ပြုလုပ်ပါ](https://github.com/microsoft/ai-agents-for-beginners/fork) မမေ့ပါနှင့်။

### အခြားသင်ယူသူများနှင့် တွေ့ဆုံခြင်း၊ မေးခွန်းများအား ဖြေကြားမှုရယူခြင်း

AI ကိုယ်စားလှယ်များအကြောင်း မစုံလင်မှုရှိပါက သို့မဟုတ် မေးခွန်းများရှိပါက [Microsoft Foundry Discord](https://aka.ms/ai-agents/discord) တွင် လိုက်လံ ဝင်ရောက်မေးမြန်းနိုင်သည်။

### လိုအပ်သောအရာများ

သင်တန်း နှင့်တွဲဖက်၍ ကုဒ် နမူနာများပါရှိပြီး အဆိုပါကုဒ်များကို code_samples ဖိုလ်ဒါတွင် ရှာဖွေနိုင်သည်။ မိမိကိုယ်ပိုင် မိတ္တူ ဖန်တီးရန် [repo ကို fork လုပ်ပါ](https://github.com/microsoft/ai-agents-for-beginners/fork)။

ထိုကုဒ် နမူနာများတွင် Microsoft Foundry Agent Service V2 ဖြင့် Microsoft Agent Framework ကို အသုံးပြုထားသည်။

- [Microsoft Foundry](https://aka.ms/ai-agents-beginners/ai-foundry) - Azure အကောင့် လိုအပ်သည်

ဤသင်တန်းတွင် Microsoft မှ AI ကိုယ်စားလှယ် frameworks နှင့် ဝန်ဆောင်မှုများ ဖြစ်သည်။

- [Microsoft Agent Framework (MAF)](https://learn.microsoft.com/agent-framework/overview/)
- [Microsoft Foundry Agent Service V2](https://aka.ms/ai-agents-beginners/ai-agent-service)

အချို့ကုဒ် နမူနာများသည် [MiniMax](https://platform.minimaxi.com/) ကဲ့သို့ OpenAI ကိုက်ညီသော အခြားပံ့ပိုးသူများကိုလည်း ထောက်ပံ့သည်။ ၎င်းသည် ကြီးမားသော context မော်ဒယ်များ (အထိ 204K token) ကို ပံ့ပိုးပေးသည်။ ပုံသေပြန့်နဲ့အသုံပြုချက်များအတွက် [Course Setup](./00-course-setup/README.md) ကို ကြည့်ပါ။

ဤသင်တန်း၏ ကုဒ် Run နည်းအချက်အလက်များ အတွက် [Course Setup](./00-course-setup/README.md) သို့ သွားပါ။
