## 🌱 စတင်ရန်

ဤသင်တန်းတွင် AI Agent များ တည်ဆောက်ခြင်း အခြေခံ စွမ်းရည်များ များပါရှိသည်။ သင်တန်းတစ်ခုချင်းစီတွင် မိမိစိတ်ကြိုက် အကြောင်းအရာကို စတင်လေ့လာနိုင်ပါသည်။

ဒီသင်တန်းတွင် ဘာသာစကားများစွာကို ထောက်ခံထားသည်။ ကျွန်ုပ်တို့၏ [ရရှိနိုင်သော ဘာသာစကားများ](#-multi-language-support) သို့ သွားရောက်ကြည့်ရှုနိုင်ပါသည်။

သင်သည် Generative AI မော်ဒယ်များဖြင့် ပထမဆုံးတည်ဆောက်ခြင်းဖြစ်ပါက ကျွန်ုပ်တို့၏ [Generative AI For Beginners](https://aka.ms/genai-beginners) သင်တန်းကို ကြည့်ရှုပါ၊ ၎င်းတွင် GenAI ဖြင့် တည်ဆောက်ခြင်းအကြောင်း သင်ခန်းစာ ၂၁ ခု ပါရှိသည်။

ဤ repo ကို [ကြယ်ပွင့် (🌟) ပေးရန်မမေ့ပါနှင့်](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst) နှင့် ကုဒ်များကို လည်ပတ်ရန် [repo ကို fork လုပ်ပါ](https://github.com/microsoft/ai-agents-for-beginners/fork)။

### အခြား ကျောင်းသားများနှင့် တွေ့ဆုံ၊ မေးခွန်းများကို ဖြေကြားကြပါစို့

သင် AI Agent များတည်ဆောက်ရာတွင် အခက်အခဲတက်ပါက သို့မဟုတ် မေးခွန်းများရှိပါက ကျွန်ုပ်တို့၏ [Microsoft Foundry Discord](https://aka.ms/ai-agents/discord) တွင် ရှိသည့် အထူး Discord Channel တွင် ပါဝင်ဆွေးနွေးနိုင်ပါသည်။

### လိုအပ်သောအရာများ

ဤသင်တန်းရှိ သင်ခန်းစာတိုင်းတွင် ကုဒ်နမူနာများ ပါ၀င်ပြီး၊ ၎င်းတို့ကို code_samples ဖိုင်တွဲ၌ ရှာဖွေနိုင်သည်။ သင်၎င်းကို [repo ကို fork လုပ်၍](https://github.com/microsoft/ai-agents-for-beginners/fork) မိမိ၏ မိတ္တူကို ဖန်တီးနိုင်သည်။

ဤလေ့ကျင့်ခန်းခွဲများရှိ ကုဒ်နမူနာများတွင် Microsoft Agent Framework နဲ့ Microsoft Foundry Agent Service V2 ကို အသုံးပြုထားသည်။

- [Microsoft Foundry](https://aka.ms/ai-agents-beginners/ai-foundry) - Azure အကောင့်လိုအပ်သည်

ဤသင်တန်းတွင် Microsoft မှ AI Agent frameworks နှင့် service များကို အသုံးပြုသည်-

- [Microsoft Agent Framework (MAF)](https://aka.ms/ai-agents-beginners/agent-framework)
- [Microsoft Foundry Agent Service V2](https://aka.ms/ai-agents-beginners/ai-agent-service)

အချို့ ကုဒ်နမူနာများတွင် ထပ်တူ OpenAI-ယှဉ်မှု ဆိုင်ရာ ပံ့ပိုးသူများဖြစ်သည့် [MiniMax](https://platform.minimaxi.com/) ကဲ့သို့ စာလုံးအတောအတွင်းကြီးမြင့်သော မော်ဒယ်များ(၂၀၄K tokens ထိ)ကို ရရှိနိုင်သည်။ ကွန်ဖစ်ဂျူရေးရှင်းအသေးစိတ်အတွက် [Course Setup](./00-course-setup/README.md) ကို ကြည့်ရှုပါ။

ဤသင်တန်းအတွက် ကုဒ်ပြုလုပ်မှုအသေးစိတ် များအတွက် [Course Setup](./00-course-setup/README.md) သို့ ဝင်ကြည့်ပါ။

## အထောက်အပံ့ပေးခြင်း

ဤပရောဂျက်သည် အထောက်အပံ့များနှင့် အကြံပြုချက်များကို ကြိုဆိုပါသည်။  များသောအားဖြင့် အထောက်အပံ့များအတွက် သင်သည်
ကိုင်တွယ်မှု လိုင်စင် သဘောတူစာချုပ် (CLA) သို့ သဘောတူရပါမည်၊ ၎င်းသည် သင်မှာ သင်၏ အထောက်အပံ့ကို အသုံးပြုခွင့်ရှိပြီး မှန်ကန်စွာ မှပေးသည်ဟု ကြေညာခြင်း ဖြစ်သည်။
အသေးစိတ်အတွက် <https://cla.opensource.microsoft.com> ကို လည်ပတ်ကြည့်ရှုပါ။

သင်သည် pull request တင်သည့်အခါ၊ CLA bot သည် CLA တောင်းဆိုခြင်း လိုအပ်မှုရှိ/မရှိကို အလိုအလျောက်ဆုံးဖြတ်ပြီး ထို PR ကို သင့်တော်သည့် နည်းဖြင့် အလှဆင်ပါလိမ့်မည် (ဥပမာ- အခြေအနေ စစ်ဆေးခြင်း၊ မှတ်ချက်)။
Bot မှ ပေးသော ညွှန်ကြားချက်များကို လိုက်နာပါ။ သင်သည် ကျွန်ုပ်တို့၏ CLA ကို အသုံးပြုသည့် Repo များ အားလုံးအတွင်း တစ်ခါတည်းသာ ဒီလုပ်ငန်းစဉ်ကို လုပ်အောင် လုပ်ရပါမည်။


ပိုမိုသိရှိလိုပါက [Code of Conduct FAQ](https://opensource.microsoft.com/codeofconduct/faq/) ကို ကြည့်ရှုပါ သို့မဟုတ်
[opencode@microsoft.com](mailto:opencode@microsoft.com) သို့ မေးခွန်းများ သို့မဟုတ် တုံ့ပြန်ချက်များပို့ပါ။


## ကုန်သွယ်မှုအမှတ်တံဆိပ်များ

ဤပရောဂျက်တွင် ပရောဂျက်များ၊ ထုတ်ကုန်များ သို့မဟုတ် ဝန်ဆောင်မှုများအတွက် ကုန်သွယ်မှုအမှတ်တံဆိပ်များ သို့မဟုတ် အမှတ်တံဆိပ်များ ပါရှိနိုင်သည်။ Microsoft ၏
ကုန်သွယ်မှုအမှတ်တံဆိပ်များ သို့မဟုတ် အမှတ်တံဆိပ်များကို အသုံးပြုခြင်းသည်
[Microsoft ၏ ကုန်သွယ်မှုအမှတ်တံဆိပ်နှင့် အမှတ်တံဆိပ်လမ်းညွှန်များ](https://www.microsoft.com/legal/intellectualproperty/trademarks/usage/general) သို့ ကိုက်ညီနေရမည်။
ဤပရောဂျက်၏ ပြင်ဆင်ထားသည့် ဗားရှင်းများတွင် Microsoft ၏ ကုန်သွယ်မှုအမှတ်တံဆိပ်များ သို့မဟုတ် အမှတ်တံဆိပ်များကို အသုံးပြုခြင်းဖြင့် ရောနှောမှုဖြစ်ပေါ်စေရေး သို့မဟုတ် Microsoft ကြီးကြပ်မှု ရှိသည့်အဖြစ် သို့မဟုတ် ထောက်ခံခြင်း သည်မဟုတ်အောင် ကာကွယ်ရမည်။
ပါတနာ တတိယက အမှတ်တံဆိပ်များ သို့မဟုတ် အမှတ်တံဆိပ်များကိုအသုံးပြုခြင်းသည် ၎င်းပါတီများ၏ မူဝါဒများကို လိုက်နာရမည်။
