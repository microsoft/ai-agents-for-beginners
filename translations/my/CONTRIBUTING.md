# ဆက်လက်အကူအညီပေးခြင်း

ဤပရောဂျက်သည် အကူအညီများနှင့် အကြံပြုချက်များကို ဝမ်းမြောက်စွာ လက်ခံသည်။ အကူအညီအများစုသည် သင်သည် သင်၏ပံ့ပိုးမှုကို အသုံးပြုခွင့် ရရှိပြီးဖြစ်ကြောင်း နှင့် အမှန်တကယ် ပံ့ပိုးခွင့်များကို ဆောင်ရွက်ပေးရန် အခွင့်အရေးရှိကြောင်း မကြာခဏ အတည်ပြုသည့် Contributor License Agreement (CLA) သို့ သဘောတူရန် လိုအပ်သည်။ အသေးစိတ်အချက်အလက်များအတွက် <https://cla.opensource.microsoft.com> ကို ကြည့်ပါ။

မည်သည့်အခါမှ သင်သည် pull request တင်သွင်းလျှင် CLA bot တစ်ခုသည် သင်သည် CLA ကို ပေးရန် လိုအပ်သလားဆိုတာ ကိုယ်တိုင်းအလိုအလျောက် ဆုံးဖြတ်ပြီး pull request ကို သင့်တော်သည့် ပုံစံဖြင့် လှည်းထားပါလိမ့်မည်။ bot မှ ပေးသောညွှန်ကြားချက်များကို လိုက်နာပါ။ Microsoft CLA ကို သုံးသော repository များအနိုင်အတိုင်း သင်သည် တစ်ကြိမ်တည်းသာ ဒီလုပ်ငန်းကို လုပ်ရန် လိုအပ်ပါသည်။

## ကိုးဒ်သဘောတူညီချက်

ဤ ပရောဂျက်သည် [Microsoft Open Source Code of Conduct](https://opensource.microsoft.com/codeofconduct/) ကို အသုံးပြုထားသည်။ အသေးစိတ်အချက်အလက်များအတွက် [Code of Conduct FAQ](https://opensource.microsoft.com/codeofconduct/faq/) ကို ကြည့်ရှုပါ သို့မဟုတ် ထပ်မံမေးမြန်းလိုပါက [opencode@microsoft.com](mailto:opencode@microsoft.com) သို့ ဆက်သွယ်ပါ။

## Pull request လမ်းညွှန်ချက်များ

- တစ်ခုသော လော့ဂျစ်တစ်ခုကို အခြေခံသော ပြောင်းလဲမှုတိုင်းကိုသာ pull request တစ်ခုတည်းအနေနဲ့ ထိန်းသိမ်းပါ။
- မတင်သွင်းမီ လက်ခံထားသော notebook များနှင့် ကုဒ်နမူနာများကို စမ်းသပ်ပါ။
- နမူနာတစ်ခု ထည့်သွင်းခြင်း သို့မဟုတ် ပြင်ဆင်ခြင်း အခါတွင် သက်ဆိုင်ရာ သင်ခန်းစာစာတမ်းများကို မြှင့်တင်ထားပါ။
- အင်္ဂလိပ်ဘာသာ ပြည့်စုံသော အရင်းအမြစ်ကိုသာ တည်းဖြတ်ပါ။ ဘာသာပြန်မှုများသည် အလိုအလျောက် ဘာသာပြန်မှု လုပ်ငန်းစဉ်ဖြင့် ထိန်းသိမ်းထားသည်။
- လျှို့ဝှက်နောက်ခံချက်များ၊ `.env` ဖိုင်များ၊ ယာယီဖိုင်များ သို့မဟုတ် ဖန်တီးထားသော ဖွံ့ဖြိုးမှု အရာဝတ္ထုများကို ချိတ်ဆက်မထားပါနှင့်။

## ဘာသာရေး နယ်ပယ်နှင့် တတိယပါတီ ထုတ်ကုန်များ

ဤ သင်တန်းအညွှန်းသည် Microsoft နည်းပညာများနှင့် vendor-neutral ဖွင့်လင်းသော စံချိန်များအပေါ် အာရုံစိုက်ပြီးဖြစ်သည်။ အကူအညီများသည် ပညာရေး ရည်ရွယ်ချက် တိကျစွာ ပါဝင်ရမည်ဖြစ်ပြီး တတိယပါတီ အသေးစား ကုန်ပစ္စည်း၊ hosted ဝန်ဆောင်မှု၊ မော်ဒယ် ရောတာ၊ SDK, MCP ဆာဗာ သို့မဟုတ် ထွက်ရှိထားသော vendor-specific ပစ္စည်းများကို မကျင့်သုံး၊ မမြှင့်တင်ရန် ရည်ရွယ်ထားခြင်း မဖြစ်သင့်ပါ။

ဖွင့်လင်းရန် ရွာဝင်းသစ်ဆော့ဖ်ဝဲများနှင့် တတိယပါတီ မှီခိုမှုများသည် ဖွင့်လင်းစံချိန် သို့မဟုတ် ဆက်သွယ်နိုင်မှု မှတ်ချက်များကို ရှင်းလင်းရန် လိုအပ်သောအခါတွင် သက်ဆိုင်ရာ သဘောတူ ပြထားခြင်းဖြစ်ပြီး vendor ၏ ထုတ်ကုန် သို့မဟုတ် hosted endpoint ကို အဓိကထားခြင်း မဟုတ်ရပါ။ သင်၏ ပံ့ပိုးမှုတွင် vendor-specific ထုတ်ကုန် သို့ဝန်ဆောင်မှု ပါဝင်ပါက Issue ဖွင့်ကာ ပူးပေါင်းသူ၏ ခွင့်ပြုချက် ရမှ ရောက်ရှိရန် pull request တင်ပါ။

ပံ့ပိုးသူများသည် သူတို့၏ ပံ့ပိုးမှုတွင် ကိုးကားထားသော ထုတ်ကုန် သို့ ဝန်ဆောင်မှုနှင့် ဆက်နွယ်သော အလုပ်အကိုင်၊ ပိုင်ဆိုင်မှု၊ အသင်းဝင်မှု သို့မဟုတ် အခြားဆက်စပ်မှုများကို ဖော်ပြရမည်။ ထောက်ခံမရသော စျေးနှုန်း၊ စွမ်းဆောင်ရည်၊ လုံခြုံမှု၊ မူဝါဒ သို့မဟုတ် နှိုင်းယှဉ်ချက်များကို မထည့်သွင်းပါနှင့်။ ပြသနိုင်သော နမူနာများသည် သင်ယူသူ ဒေတာများကို ပေးပို့ခြင်း သို့မဟုတ် ပုံမှန်အားဖြင့် အပြင်တစ်ဖက်က တတိယပါတီ ဝန်ဆောင်မှုမှတဆင့် ပြည်သူသို့ လုပ်ဆောင်မှုများ မပြုလုပ်ရပါ။
