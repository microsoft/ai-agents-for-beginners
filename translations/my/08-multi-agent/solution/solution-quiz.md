# အသိပညာစစ်ဆေးမှု ဖြေချက်များ

## မေးခွန်း ၁

**ဖြေချက်: A2.** အလုပ်တစ်ခုမှာ အထူးပြုအလုပ်တာဝန်များ၊ ဧရိယာသီးသန့်အသုံးပြုချက်များ သို့မဟုတ် ခွင့်ပြုချက်များနဲ့ ဖောက်ထွင်းပေးပို့ရေးအား လိုအပ်သောအခါ မတူကွဲပြားတဲ့အေးဂျင့်များလိုအပ်တတ်သည်။ ရိုးရှင်းတဲ့ ပံ့ပိုးမည့် bot တစ်ခုသည် ယေဘုယျအားဖြင့် တစ်ဦးတည်းအေးဂျင့်ဖြစ်နိုင်သည်။ တူညီသော တောင်းဆိုမှုများအများအပြားသည် အဓိကအားဖြင့် အရွယ်တင်ဖွံ့ဖြိုးမှုစဉ်းစားချက်ဖြစ်ပြီး မတူကွဲပြားသော အေးဂျင့်ဒီဇိုင်းကို သဘောမတူပါ။

## မေးခွန်း ၂

**ဖြေချက်: A1.** တစ်ဦးတည်းအေးဂျင့်သည် တစ်စုပြုလုပ်ချက်တွင် ညွှန်ကြားချက်နှင့် ကိရိယာများဖြင့် အလုပ်ကို ဆောင်ရွက်နိုင်သောအခါ စမ်းသပ်ရ၊ စောင့်ကြည့်ရ၊ နှင့် အလုပ်လုပ်ရန် ရိုးရှင်းလွယ်ကူသည်။ ကိရိယာအများကြီး ဝင်ရောက်ခွင့်ရှိတာက အလိုအလျောက် အေးဂျင့်အများလိုအပ်တာမဟုတ်ပါ။ ခွင့်ပြုချက်များနှင့် လေ့လာစစ်ဆေးရေးလိုအပ်ချက်များကွဲပြားသည့် အထူးပြုလုပ်ဖွဲ့စည်းမှုသည် မတူကွဲပြားသော အေးဂျင့်ဒီဇိုင်းကို တရားဝင်ပြုလုပ်စေလိမ့်မည်။
