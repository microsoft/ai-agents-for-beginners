# ⏩ Azure OpenAI (Responses API) (.NET) နှင့် အဆက်လိုက် Agent အလုပ်စဉ်များ

## 📋 အဆင့်မြင့် အဆက်လိုက် လုပ်ငန်းစဉ် သင်ခန်းစာ

ဤ notebook  သည် Microsoft Agent Framework for .NET နှင့် Azure OpenAI (Responses API) ကို အသုံးပြု၍ **အဆက်လိုက် workflow ပုံစံများ** ကို ပြသသည်။ သင်သည် အဆင့်တိုင်းတွင် ယခင်အဆင့်ရလဒ်များကို အခြေခံ၍ အချက်အလက်များကို တိကျစွာ တစ်ဆင့်ချင်း ဆောင်ရွက်သည့် လုပ်ငန်းစဉ် ပိုင်းလိုင်းများကို တည်ဆောက်နည်းသင်ယူမည်ဖြစ်သည်။

## 🎯 သင်ယူရမည့် ရည်မှန်းချက်များ

### 🔄 **အဆက်လိုက် လုပ်ငန်းစဉ် စနစ်ပညာ**
- **လိုင်းနာ ဝွက်ဖလိုက် ဒီဇိုင်း**: ဖွဲစည်းတိကျသော လုပ်ငန်းစဉ်များကို အဆင့်ဆင့် တည်ဆောက်ခြင်း
- **အခြေအနေ စီမံခန့်ခွဲမှု**: အဆက်လိုက် လုပ်ငန်းစဉ်အဆင့်များတလျောက် Context နှင့် Data အား ထိန်းသိမ်းခြင်း
- **Azure OpenAI (Responses API)**: .NET workflow များအတွင်း Azure OpenAI မော်ဒယ်များကို အသုံးပြုခြင်း
- **လုပ်ငန်း စီမံခန့်ခွဲမှု မော်ဒယ်များ**: အသစ်တည်ဆောက်ပြီး အသုံးပြုနိုင်သော အဆက်လိုက် လုပ်ငန်းစဉ် စနစ်များ

### 🏗️ **အဆင့်မြင့် အဆက်လိုက် ပုံစံများ**
- **အဆင့်စစ်ဆေးမှု (Stage-Gate) လုပ်ငန်းစဉ်**: အဆင့်များကြား စစ်ဆေးမှုများကို ချမှတ်ခြင်း
- **Context ထိန်းသိမ်းမှု**: အဆင့်တိုင်းတွင် စုစည်းထားသော အခြေအနေကို ထိန်းသိမ်းခြင်း
- **ရိုက်နှက်ချက် ပြန်ပျံ့နှံ့မှု**: အဆက်လိုက် စက်ဆော့မှုကြိုးများတွင် ကွက်လပ်များကို ပညာရှိစွာ ကိုင်တွယ်ခြင်း
- **မောင်းနှင်မှု တိုးတက်မှု**: သက်သာစွာမြန်ဆန်သော အဆက်လိုက် ဆောင်ရွက်မှု

### 🏢 **လုပ်ငန်းလည်ပတ်မှုအဆက်လိုက် လျှောက်လွှာများ**
- **စာရွက်စစ်ဆေးသူ လုပ်ငန်းစဉ်**: အဆင့်များစွာဖြင့် စာရွက်စာတမ်း ခွဲခြမ်းစိတ်ဖြာခြင်း၊ ပြောင်းလဲခြင်းနှင့် စစ်ဆေးခြင်း
- **အရည်အသွေး အာမခံ လုပ်ငန်းစဉ်များ**: အဆင့်တိုင်း ပြန်လည်စစ်ဆေးခြင်း၊ အတည်ပြုခြင်းနှင့် အတည်ပြုချက် ခံယူခြင်း
- **အကြောင်းအရာ ထုတ်လုပ်မှု လုပ်ငန်းစဉ်**: သုတေသန → ရေးသားခြင်း → တည်းဖြတ်ခြင်း → ပြန်လည်စစ်ဆေးခြင်း → ထုတ်ဝေခြင်း
- **စီးပွားရေး လုပ်ငန်းစဉ် အလိုအလျောက် စနစ်**: အဆင့်များစွာဖြင့် စီးပွားရေး လုပ်ငန်းစဉ်များ ဖွဲစည်းခြင်း

```xml
<PackageReference Include="Azure.Identity" Version="1.15.0" />

<!-- Local Agent Framework References -->
<!-- Microsoft.Agents.AI.dll - Core agent abstractions -->
<!-- Microsoft.Agents.AI.OpenAI.dll - Azure OpenAI (Responses API) integration -->
```

### 🔑 **Azure OpenAI ပြင်ဆင်မှု**

**ပတ်ဝန်းကျင် ပြင်ဆင်မှု (.env ဖိုင်):**
```env
AZURE_OPENAI_ENDPOINT=https://<your-resource>.openai.azure.com
AZURE_OPENAI_DEPLOYMENT=gpt-4o-mini
```

**ပြင်ဆင်မှု စီမံခန့်ခွဲမှု:**
```csharp
// Load environment variables securely
Env.Load("../../../.env");
var azureEndpoint = Environment.GetEnvironmentVariable("AZURE_OPENAI_ENDPOINT");

```

### 🏗️ **အဆက်လိုက် Workflow လုပ်ငန်းစဉ် ဒီဇိုင်း**

```mermaid
graph TD
    A[Initial Input] --> B[Stage 1: ချဲ့ထွင်စစ်တမ်းအေးဂျင့်]
    B --> C[စစ်ဆေးမှုဦးစွာကြား]
    C --> D[Stage 2: ပြန်လည်စီမံခန့်ခွဲမှုအေးဂျင့်]
    D --> E[စစ်ဆေးမှုနှစ်ကြိမ်ကြား]
    E --> F[Stage 3: အတည်ပြုပြီးသောအေးဂျင့်]
    F --> G[နောက်ဆုံးတင်ပို့ချက်]
    
    H[အခြေအနေအရာအကြောင်းအရာ] --> B
    H --> D
    H --> F
    
    I[Azure OpenAI (တုံ့ပြန်မှု API)] --> B
    I --> D
    I --> F
```

**အဓိက ပစ္စည်းအစိတ်အပိုင်းများ:**
- **အဆက်လိုက် Agents**: အဆင့်တိုင်းအတွက် အထူးပြု Agents များ
- **အခြေအနေ Context**: အဆင့်တိုင်းကို မျှဝေထားသော အချက်အလက် နှင့် ဆုံးဖြတ်ချက်များ ထိန်းသိမ်းခြင်း
- **အဆင့်စစ်ဆေးရာများ**: အဆင့်များအကြား အရည်အသွေးနှင့် တိကျမှုကို သေချာစေရန် စစ်ဆေးမှုများ
- **Azure OpenAI Client**: စစ်မှန်သော AI မော်ဒယ် လက်လှမ်းမီမှု

### 📝 မျှော်မှန်းထွက်ရှိမှု

Workflow သည်
1. **အရောင်း Agent**: ပုံမှ လက်ဝါးပစ္စည်းများကို ဖော်ထုတ်ပြီး အကြံပြုချက်များ ပေးသည်
2. **ဈေးနှုန်း Agent**: အသေးစိတ် ဈေးနှုန်း သုံးသပ်ချက်၊ ဘတ်ဂျက်အဆင့်များနှင့် ဝယ်ယူ အကြံပြုချက်များ ထည့်သွင်းသည်
3. **အမိန့် Agent**: အချက်အလက်အားလုံး ပေါင်းစပ်ပြီး ပုံစံပြ မိန့်ခွန်းစာတမ်း တစ်စောင် ထုတ်ပေးသည်

နောက်ဆုံး ထွက်ရှိမည့် ရလဒ်မှာ ပုံ ခြုံငုံသုံးသပ်ချက်မှ အခြေခံ၍ အပြည့်အဝ ကြီးပွားသော လက်ဝါးပစ္စည်း ကုန်ကျစရိတ် မှတ်တမ်းတစ်စောင် ဖြစ်လာပါလိမ့်မည်။

### 🎯 အမှန်တကယ် အသုံးချနိုင်သည့် လျှောက်လွှာများ

ဤ အဆက်လိုက် ပုံစံသည် အထူးသင့်လျော်သည့် နေရာများမှာ -
- **အီးကော်မာ့(စ်)**: ကုန်ပစ္စည်း ခွဲခြမ်းစိတ်ဖြာ → ဈေးနှုန်း သတ်မှတ် → အမိန့်ထုတ်လုပ်ခြင်း
- **ရောင်းဝယ်ရေး**: ပိုင်ဆိုင်မှု ခွဲခြမ်းစိတ်ဖြာ → တန်ဖိုး သတ်မှတ် → မှတ်တမ်း ဖန်တီးခြင်း
- **အာမခံ**: ခေါင်းဆောင်မှု ခွဲခြမ်းစိတ်ဖြာ → သတ်မှတ်ချက် ထုတ်ခြင်း → အမိန့်ထုတ်ခြင်း
- **အကြောင်းအရာ ဖန်တီးခြင်း**: သုတေသန → ရေးသားမှု → တည်းဖြတ်မှု → ထုတ်ဝေမှု

### 🔍 အခြေအနေ လည်ပတ်မှု နားလည်ခြင်း

အဆက်လိုက် Agent တစ်ဦးချင်းစီသည် လက်ခံရရှိသော အရာများ -
- **အစပိုင်း input**: မူလ အသုံးပြုသူ မက်ဆေ့(ပုံ + စာသား)
- **ယခင် Agent များမှ ထွက်ရှိမှုများ**: ဆွေးနွေးမှု သမိုင်း၌ ယခင် Agent အဖြေများအားလုံး
- **စုစုပေါင်း Context**: Workflow တစ်လျောက် အခြေအနေ အပြည့်အစုံ ထိန်းသိမ်းမှု

ဤသည်က ပြည့်စုံသော Multi-stage လုပ်ငန်းစဉ်များ ဖန်တီးရန် တစ်ဆင့်ချင်း Context များကို လုံးဝသိရှိစေခြင်းဖြစ်သည်။
