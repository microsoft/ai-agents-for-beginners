# 🔄 Azure OpenAI (Responses API) (.NET) ဖြင့် မူလက သဘာဝအိုင်တ်ဆိုင်မြှုပ် ထည့်ထားသော အေးဂျင့်အလုပ်စဉ်များ

## 📋 အလုပ်စဉ် အစီအစဉ် လမ်းညွှန်ချက်

ဒီ notebook က Microsoft Agent Framework for .NET နဲ့ Azure OpenAI (Responses API) ကို အသုံးပြုပြီး ခက်ခဲသော **အေးဂျင့်အလုပ်စဉ်များ** ဘယ်လိုတည်ဆောက်ရမယ်ဆိုတာ ပြသထားပါတယ်။ AI အေးဂျင့်များဟာ ဖွဲ့စည်းထားသော စီမံခန့်ခွဲမှု နမူနာတွေနဲ့ ခက်ခဲတဲ့တာဝန်တွေ ပူးပေါင်းပြီး ဖြေရှင်းနိုင်တဲ့ နောက်ဆက်တွဲ စီးပွားရေးလုပ်ငန်းလုပ်ငန်းစဉ်များ ဖန်တီးဖို့ သင်တန်းရမှာ ဖြစ်ပါတယ်။

ဒီအလုပ်စဉ်ကို ပြသရာမှာ အသုံးပြုသည့် အဓိက .NET packages အချို့ပါဝင်သည်။

### 🔑 **Azure OpenAI ပြင်ဆင်မှု**

**ပတ်ဝန်းကျင်ပြင်ဆင်ခြင်း (.env ဖိုင်):**
```env
AZURE_OPENAI_ENDPOINT=https://<your-resource>.openai.azure.com
AZURE_OPENAI_DEPLOYMENT=gpt-4o-mini
```

**Azure OpenAI ကို ဝင်ရောက်ရန်:**
1. Azure portal မှာ Azure OpenAI resource တစ်ခု ဖန်တီးပါ
2. ပုံစံတစ်ခု (ဥပမာ၊ `gpt-4o-mini`) ကို ဖြန့်ချိပြီး ဖြန့်ချိအမည်ကို မှတ်စုတင်ပါ
3. `az login` ဖြင့် ဝင်ပါ၊ အထက်ဖော်ပြထားသော ပတ်ဝန်းကျင်တန်ဖိုးများကို ပြင်ဆင်ပါ

### 🏗️ **အလုပ်စဉ် ပုံသဏ္ဍာန် စုစည်းမှု အနှိုင်းအယှက်**

```mermaid
graph TD
    A[လုပ်ငန်းစဉ် တည်ဆောက်သူ] --> B[ကိုယ်စားလှယ် မှတ်ပုံတင်စာရင်း]
    B --> C[လုပ်ငန်းစဉ် အချက်အလက် အင်ဂျင်]
    C --> D[Agent 1: အကြောင်းအရာ မျှတသူ
    C --> E[Agent 2: အကြောင်းအရာ ပြန်လည်သုံးသပ်သူ 
    D --> F[လုပ်ငန်းစဉ် ရလဒ်များ]
    E --> F
    G[Azure OpenAI (တုံ့ပြန်ချက် API)] --> D
    G --> E
```

**အဓိက အစိတ်အပိုင်းများ:**
- **WorkflowBuilder**: အလုပ်စဉ် ဖန်တီးခြင်းကို အဓိက စီမံခန့်ခွဲသော အင်ဂျင်
- **AIAgent**: အထူးပြု စွမ်းဆောင်နိုင်သည့် အေးဂျင့် တစ်ဦးချင်း
- **Azure OpenAI Client**: Azure OpenAI Responses API ပေါင်းစပ်မှု
- **Execution Context**: အလုပ်စဉ် အဆင့်များကြား နေအိမ်နှင့် ဒေတာ လှုပ်ရှားမှု ကို စီမံခန့်ခွဲသည်

## 💻 ကုဒ်ကို ဒီလို လည်ပတ်စေခြင်း

တစ်လုံးလုံး အဖွဲ့ရာရှိမှုကို `01.dotnet-agent-framework-workflow-ghmodel-basic.cs` မှာ တွေ့မြင်နိုင်သည်။ ဒီဖိုင်မှာ ပြသထားတာတွေက:

1. **ပတ်ဝန်းကျင် ပြင်ဆင်မှု** - `.env` ဖိုင်မှ Azure OpenAI ပြင်ဆင်မှုများ load လုပ်ခြင်း
2. **Azure OpenAI Client ပြင်ဆင်မှု** - Azure OpenAI Responses API ကို အသုံးပြုရန် Client ပြင်ဆင်ခြင်း
3. **အေးဂျင့် ဖန်တီးခြင်း** - အထူးပြု အေးဂျင့်များ (Front Desk နဲ့ Concierge)
4. **အလုပ်စဉ်တည်ဆောက်သူ** - နောက်ဆက်တွဲလုပ်ငန်းစဉ်ဖြင့် မျိုးစုံအေးဂျင့်အလုပ်စဉ် ဖန်တီးခြင်း
5. **အလုပ်စဉ် အကောင်အထည်ဖော်ခြင်း** - နောက်ဆက်တွဲရလဒ်ပြသမှုနှင့်အတူ အလုပ်စဉ် ပြေးဆောင်ခြင်း

chmod +x 01.dotnet-agent-framework-workflow-ghmodel-basic.cs

dotnet run 01.dotnet-agent-framework-workflow-ghmodel-basic.cs

4. နောက်ဆုံး ထွက်ရှိမှုမှာ စကားပြောဆိုမှု ပုံစံတိကျစွာ ပြသပါမယ်

### 🔧 ကိုယ်ပိုင်ပြင်ဆင်မှု

အလုပ်စဉ်ကို ကုစားနိုင်ပါတယ် -
- အေးဂျင့် လမ်းညွှန်ချက်များ ပြင်ဆင်ခြင်းဖြင့် သူတို့၏ အပြုအမူ ပြောင်းလဲနိုင်ခြင်း
- အေးဂျင့် အရေအတွက် တိုးပြီး ခက်ခဲသော နောက်ဆက်တွဲအလုပ်စဉ်များ ဖန်တီးနိုင်ခြင်း
- အသုံးပြုသူ စာပိုဒ် ပြောင်းလဲ၍ ဆန်းစစ်မှု များပြုလုပ်နိုင်ခြင်း
- အလုပ်စဉ် ချိတ်ဆက်မှုများ ပြင်ဆင်၍ တူညီသော်လည်း ပြုတ်ပြင်ထားသည့် စနစ်ဖြစ်စေရန်
