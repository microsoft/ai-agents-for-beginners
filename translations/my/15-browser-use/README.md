# ကွန်ပျူတာအသုံးပြုမှု Agent များ ဖန်တီးခြင်း (CUA)

ကွန်ပျူတာအသုံးပြုမှု agent များသည် လူတစ်ဦးလိုပင် ဝက်ဘ်ဆိုက်များနှင့် ဆက်သွယ်နိုင်သည်။ ဘရောင်ဇာကို ဖွင့်ခြင်း၊ စာမျက်နှာကို စစ်ဆေးခြင်းနှင့် မြင်ရသည့်အတိုင်း နောက်တစ်ခုသေးငယ်သော လုပ်ဆောင်သင့်သော အဖြစ်အပျက်ကို လုပ်ဆောင်ခြင်းဖြင့် ဖြစ်သည်။ ဤသင်ခန်းစာတွင် Airbnb ကို ရှာဖွေခြင်း၊ ဖော်ပြထားသောစာရင်းအချက်အလက်ကို ဆွဲထုတ်ယူခြင်းနှင့် စတော့ခ်ဟော်လ်မ်ရှိ အဓိကလျှော့စျေး တည်းခိုခန်းကို ဖော်ထုတ်ပေးမည့် ဘရောင်ဇာအလိုအလျောက်လုပ်ငန်း agent တစ်ခု ဖန်တီးသွားပါမည်။

သင်ခန်းစာသည် Browser-Use ကို AI အခြေပြုလမ်းညွှန်မှုအတွက်၊ Playwright နှင့် Chrome DevTools Protocol (CDP) ကို ဘရောင်ဇာထိန်းချုပ်မှုအတွက်၊ Azure OpenAI ကို မြင်ကွင်းမြင်နိုင်သော အကြံပြုချက်အတွက်၊ Pydantic ကို ဖွဲ့စည်းတိကျသော ဆွဲထုတ်မှုအတွက် ပေါင်းစပ်အသုံးပြုထားသည်။

## မိတ်ဆက်

ဤသင်ခန်းစာတွင် လေ့လာရမည့်အချက်များမှာ -

- ကွန်ပျူတာအသုံးပြုမှု agent များသည် API-only အလိုအလျောက်လုပ်ငန်းထက် ဘယ်အချိန်ပိုမိုသင့်တော်သည်ကိုနားလည်ခြင်း
- Browser-Use နှင့် Playwright၊ CDP တို့ကို ပေါင်းစပ်ပြီး ယုံကြည်စိတ်ချရသော ဘရောင်ဇာ အသက်တာစီမံခန့်ခွဲမှုလုပ်ငန်းစဉ်များ တည်ဆောက်ခြင်း
- Azure OpenAI ၏ မြင်ကွင်းခွင့်နှင့် ဖွဲ့စည်းတိကျသော Pydantic ထုတ်လွှင့်မှုဖြင့် ဒိုင်နမစ် ဝက်ဘ်စာမျက်နှာမှ စာရင်းအချက်အလက်များကို ဆွဲထုတ်ခြင်း
- agent ပထမ၊ actor ပထမ၊ သို့မဟုတ် သံ့အသွားပုံစံ ဘရောင်ဇာအလိုအလျောက်လုပ်ငန်းစဉ်ကို ဘယ်အချိန်အသုံးပြုမည်ကို ဆုံးဖြတ်ခြင်း

## သင်ယူရမည့် ရည်မှန်းချက်များ

သင်ခန်းစာကို ပြီးမြောက်စွာ လေ့လာပြီးနောက်တွင် -

- Azure OpenAI နှင့် Playwright ဖြင့် Browser-Use ကို ပြင်ဆင်နိုင်မည့် နည်းလမ်းများ
- တကယ့်ဝက်ဘ်ဆိုက်ကို လမ်းညွှန်သွားရင်း ဒိုင်နမစ် UI အစိတ်အပိုင်းများကို ကိုင်တွယ်နိုင်မည့် ဘရောင်ဇာအလိုအလျောက်လုပ်ငန်းစဉ် တည်ဆောက်ခြင်း
- မြင်သာသောစာမျက်နှာ အကြောင်းအရာမှ အမျိုးအစားသတ်မှတ်ထားသော ရလဒ်များကို ဆွဲထုတ်ကာ နောက်တွင် စီးပွားရေးဗဟိုချက်အဖြစ် ပြောင်းလဲနိုင်ခြင်း
- ဘရောင်ဇာလုပ်ငန်းတာဝန်၏ ခန့်မှန်းနိုင်မှုအပေါ်မူတည်၍ agent နှင့် actor ပုံစံများအကြား ရွေးချယ်နိုင်ခြင်း

## ကိုဒ် နမူနာ

ဤသင်ခန်းစာတွင် notebook tutorial တစ်ခု ပါဝင်သည်။

- [15-browser-user.ipynb](./15-browser-user.ipynb) : CDP မှတစ်ဆင့် Chrome session တစ်ခု စတင်၍ Airbnb တွင် စတော့ခ်ဟော်လ်မ်စာရင်းများ ရှာဖွေ၊ Browser-Use vision ဖြင့် စျေးနှုန်းများကို ဆွဲထုတ်ကာ အဆငျးဆုံးရွေးချယ်မှုကို ဖွဲ့စည်းထားသောအချက်အလက်အဖြစ် ပြန်လည်ပေးပို့သည်။

## ကြိုတင်ပြင်ဆင်မှုများ

- Python 3.12+
- သင့်ပတ်ဝန်းကျင်တွင် Azure OpenAI deployment ပြင်ဆင်ထားပြီး
- Chrome သို့မဟုတ် Chromium ကို ဒေသန္တရတွင် ထည့်သွင်းထားပြီး
- Playwright မူလစာရင်းများ ထည့်သွင်းထားပြီး
- async Python ကို ကိုယ်တိုင်သိရှိမှုအခြေပြု

## ပြင်ဆင်ခြင်း

Notebook တွင် အသုံးပြုမည့် package များကို ထည့်သွင်းပါ။

```bash
pip install browser_use playwright python-dotenv
```

Notebook တွင် အသုံးပြုမည့် Azure OpenAI ပတ်ဝန်းကျင်အပြောင်းအလဲများကို သတ်မှတ်ပါ။

```bash
AZURE_OPENAI_ENDPOINT=...
AZURE_OPENAI_API_KEY=...

AZURE_OPENAI_API_VERSION=...
```

## အဆောက်အအုံ အနှောင့်အယှက်

Notebook သည် ဘရောင်ဇာအလိုအလျောက်လုပ်ငန်းစဉ် သံ့အသွားပုံစံကို ပြသသည်။

၁။ Chrome သည် CDP ကို သုံး၍ စတင်ပြီး Playwright နှင့် Browser-Use တို့သည် အတူတူ ဘရောင်ဇာ session တစ်ခုကို မျှဝေကြသည်။
၂။ Browser-Use agent သည် Airbnb ကိုဖွင့်ခြင်း၊ pop-up များ ပိတ်ခြင်းနှင့် စတော့ခ်ဟော်လ်မ်အတွက် ရှာဖွေရေးကဲ့သို့ သက်ဆိုင်ရာ လမ်းညွှန်မှု အရာဝတ္ထုများကို ကိုင်တွယ်သည်။
၃။ လက်ရှိစာမျက်နှာကို ဖော်ပြထားသည့် Pydantic schema ဖြင့် စစ်ဆေးကာ စာရင်းခေါင်းစဉ်များ၊ တစ်ညစာစျေးနှုန်းများ၊ အဆင့်သတ်မှတ်ချက်များနှင့် URL များကို ဆွဲထုတ်သည်။
၄။ Python လိုဂျစ်သည် ဆွဲထုတ်ထားသော စာရင်းများကို နှိုင်းယှဉ်ပြီး အဓိကလျော့စျေး အဖြစ်ထင်ရှားစေသည်။

ဤနည်းလမ်းသည် Browser-Use တွင် ကောင်းမွန်သော မြင်ကွင်းအခြေခံအကြံပြုချက်နှင့် သင်လိုအပ်သည့်အခါ သေချာသည့် ဘရောင်ဇာထိန်းချုပ်မှုတို့ကို ပူးပေါင်းထားခြင်းဖြစ်သည်။

## အရေးကြီးဆုံး အကြောင်းအရာများနှင့် အကောင်းဆုံးအလေ့အကျင့်များ

### Agent သုံးသင့်သောအချိန် နှင့် Actor သုံးသင့်သောအချိန်

| အခြေအနေ | Agent သုံးပါ | Actor သုံးပါ |
|----------|-----------|-----------|
| ဒိုင်နမစ်ဖွဲ့စည်းခြင်းများ | ဟုတ်ကဲ့၊ AI သည် စာမျက်နှာပြောင်းလဲမှုများကို သင့်တော်စွာ ချိန်ညှိနိုင်သည် | မဟုတ်၊ ကွဲပြားမှု selectors ကြောင့် ပြိုကွက်နိုင်သည် |
| အသိအမှတ်ပြုဖွဲ့စည်းမှု | မဟုတ်၊ agent သည် တိုက်ရိုက်ထိန်းချုပ်မှုထက် နှေးကွေးသည် | ဟုတ်ကဲ့၊ လျင်မြန်ပြီးတိကျသည် |
| အရာဝတ္ထုများ ရှာဖွေရန် | ဟုတ်ကဲ့၊ သဘာဝဘာသာစကားကောင်းစွာ အလုပ်လုပ်သည် | မဟုတ်၊ တိကျသော selector များလိုအပ်သည် |
| အချိန်ထိန်းချုပ်မှု | မဟုတ်၊ ခန့်မှန်းရန်ပိုမိုခက်ခဲသည် | ဟုတ်ကဲ့၊ စောင့်ဆိုင်းမှုနှင့် အသုံးပြန်မှုတွေကို တိတိကျကျ ထိန်းချုပ်နိုင်သည် |
| ရှုပ်ထွေးသောလုပ်ငန်းစဉ်များ | ဟုတ်ကဲ့၊ မမျှော်လင့်ထားသော UI အခြေအနေများကို ကိုင်တွယ်နိုင်သည် | မဟုတ်၊ တိကျသော แตกခွဲခြားမှု လိုအပ်သည် |

### Browser-Use အကောင်းဆုံး အလေ့အကျင့်များ

၁။ စူးစမ်းရှာဖွေရေးနှင့် ဒိုင်နမစ် လမ်းညွှန်မှုအတွက် agent ဖြင့် စတင်ပါ။
၂။ ပုံမှန်ဖြစ်လာသော အပြစ်အနာဂါတ်တွင် တိုက်ရိုက်စာမျက်နှာထိန်းချုပ်မှုသို့ ပြောင်းပါ။
၃။ ဆွဲထုတ်ထားသော ဒေတာသည် စစ်ဆေးထားပြီး အမျိုးအစားလုံခြုံမှုရှိစေရန် ဖွဲ့စည်းတည်ဆောက်ထားသော output model များကို အသုံးပြုပါ။
၄။ မြင်သာသော UI ပြောင်းလဲမှုများကို ဦးတည်လာသော လုပ်ဆောင်ချက်တစ်ခုတွင် သတ်မှတ်အချိန်ကြာမြင့်စေပါ။
၅။ ပြန်လည်စစ်ဆေးမှုအချိန်တွင် အမှားများကို လွယ်ကူစွာ ရှာဖွေဖော်ထုတ်နိုင်ရန် screenshot များကို ဖမ်းယူပါ။
၆။ ဝက်ဘ်ဆိုက်များ လျင်မြန်စွာပြောင်းလဲနိုင်သဖြင့် pop-up များနှင့် ဖွဲ့စည်းခြင်းပြောင်းလဲမှုများအတွက် အစားထိုး မဟာဗျူဟာများ ကျင့်သုံးပါ။
၇။ သံ့အသွား agent နှင့် actor ပုံစံများကို ပေါင်းစပ်အသုံးပြု၍ သံ့အသွားမှုနှင့် တိကျမှု နှစ်မျိုးလုံး ရရှိစေပါ။

### အကောင်အထည်ဖော်မှုများ

- ခရီးသွား စိတ်ချုံ့စေခြင်းနှင့် စျေးနှုန်းကြည့်ရှုခြင်း
- အီးကွမ်မာ့စ် စျေးနှုန်းနှိုင်းယှဉ်ခြင်းနှင့် ရရှိနိုင်မှု စစ်ဆေးခြင်း
- ဒိုင်နမစ် ဝက်ဘ်ဆိုက်များမှ ဖွဲ့စည်းတိကျစွာ ဆွဲထုတ်ခြင်း
- မြင်ကွင်းသိကောင်းစွာ UI စမ်းသပ်ခြင်းနှင့် အတည်ပြုခြင်း
- ဝက်ဘ်ဆိုက် စောင့်ကြည့်ခြင်းနှင့် သတိပေးမှုများ
- အဆင့်မြင့်အစီအစဉ်များ တစ်ဆင့်ချင်း ပြည့်ဆည်းစွာ ဖောင်များ ဖြည့်သွင်းခြင်း

## အကောင်အထည်ဖော်မှုနမူနာ- Microsoft Project Opal

သင်ဤသင်ခန်းစာတွင် ဖန်တီးမည့် agent သည် **ကွန်ပျူတာအသုံးပြုမှု agent (CUA)** ၏ အသေးစား ဒေသတွင်းဗားရှင်းတစ်ခုဖြစ်ပြီး လူတစ်ဦးလို ဘရောင်ဇာ ဘက်မှ လှမ်းဆောင်မည့် ပရိုဂရမ်တစ်ခုဖြစ်သည်။ Microsoft သည် ဤစိတ်ကူးကို လူကြီးအဖွဲ့အစည်းများအတွက် Microsoft 365 Copilot တွင် ပါဝင်သည့် **[Project Opal (Frontier)](https://support.microsoft.com/en-us/microsoft-365-copilot/get-started-with-project-opal-frontier)** ဖြင့် ပံ့ပိုးပေးနေပါသည်။

Project Opal ဖြင့်၊ သင့်အစား အလုပ်ကို ဖော်ပြသောအတိုင်း agent သည် **ကွန်ပျူတာအသုံးပြုမှုကိုလုံခြုံသော Windows 365 Cloud PC နောက်ခံပတ်ဝန်းကျင်တွင်** အသုံးပြုကာ သင့်အဖွဲ့အစည်း၏ ဘရောင်ဇာ အခြေပြု အပလီကေးရှင်းများ၊ ဆိုင်များနှင့် ဒေတာများကို အသုံးပြုသည်။ ၎င်းသည် **နောက်ခံတွင် အဆက်မပြတ် စီမံချက်ပြုလုပ်ပြီး** သင်ကိုယ်တိုင် အလုပ်ကိုလမ်းညွှန်လိုပါက လည်းကောင်း၊ သို့မဟုတ် ထိန်းချုပ်မှုကို ကြိုက်နှစ်သက်သလို လက်ခံနိုင်ပါသည်။ လုပ်ငန်း ဥပမာများမှာ -

- လုံခြုံရေးအဖွဲ့ဝင်အဖွဲ့ မှတောင်းဆိုချက်များ စီမံခန့်ခွဲခြင်း
- လိုက်လံစစ်ဆေးရေးအတွက် စိစစ်မှု သက်သေများ စုဆောင်းခြင်းနှင့် အတည်ပြုခြင်း
- IT ဖြစ်ပွားမှုများ ဘေးကင်းရေးစစ်ဆေးခြင်း (လက်မှတ်အခြေအနေ အပ်ဒိတ်လုပ်ခြင်း၊ တာဝန်ထမ်းသူခန့်အပ်ခြင်း၊ နုတ်ယူသပ်ရပ်မှုများ)
- Excel ဒေတာများကို ငွေကြေးပိတ်သွားစီမံချက် ချပေးခြင်း

Opal သည် **ထုတ်လုပ်မှုအဆင့်၊ ယုံကြည်စိတ်ချရသော** ကွန်ပျူတာအသုံးပြုမှု agent ၏ အထူးသက်မှတ်ဖြစ်ပြီး ရှေ့က သင်ကြားမှုများမှ အကြောင်းအရာများကို ထပ်မံ အာရုံစိုက်စေသည်။

| ဤသင်တန်းအတွင်း အဓိက အယူအဆ | Project Opal တွင် ၎င်း၏အသုံးပြုမှု |
|------------------------|-----------------------------|
| **လူတစ်ဦးပါဝင်ရေး** (သင်ခန်းစာ ၀၆) | Opal သည် login အချက်အလက်များ၊ အချက်အလက်များ သို့မဟုတ် ရှုပ်ထွေးသောညွှန်ကြားချက်များအတွက် ရပ်ဆိုင်းပြီး ပါစ်ဝတ်၊ စာရွက်နမူနာများကို ထည့်သွင်းသော်လည်း ရိုးရှင်းစေချင်ပါက *Take Control* နှင့် *Return Control* ကို လည်ပတ်မှုတွင် အသုံးပြုနိုင်ပါသည်။ |
| **ယုံကြည်စိတ်ချရသော Agent များ** (သင်ခန်းစာ ၀၆ & ၁၈) | Windows 365 Cloud PC မှ ထိန်းသိမ်းထားသော ကျောက်တုံးဖြင့် အကာအကွယ်ရှိပြီး ဘရောင်ဇာအခြေပြုဖြစ်သည်။ (အခြား ကွန်ပျူတာဝင်ရောက်မှုများ ပိတ်ထားသည်။ Intune ဖြင့် ထိန်းချုပ်ထားသည်။) သင့်အသိအမှတ်ပြုချက်ကိုသာ အသုံးပြုကာ အသုံးပြုခွင့်ရှိသောအရာများကိုသာ ဝင်ရောက်နိုင်ပြီး တစ်ခုချင်း လုပ်ဆောင်ချက်များကို မှတ်တမ်းတင်သည်။ |
| **အစီအစဉ်များ ရေးဆွဲခြင်းနှင့် စဉ်းစားခြင်း** (သင်ခန်းစာ ၀၇ & ၀၉) | Opal သည် ဦးစားပေး အလုပ်ကို စီမံခန့်ခွဲနေတာဖြစ်ပြီး သူ့ကိုယ်သူ သုံးသပ်ခြင်းလုပ်ဆောင်နေစဉ် ရိုက်ချက်တွေ့လျှင် ရပ်ဆိုင်းမည်။ |
| **ထပ်မံအသုံးပြုနိုင်သော ကျွမ်းကျင်မှုများ / ကိရိယာများ** (သင်ခန်းစာ ၀၄) | **ကျွမ်းကျင်မှုများ** သည် အလုပ်များကို ပြန်လည်အသုံးပြုရန် (.md ဖိုင်မှ သွင်းယူသည် သို့မဟုတ် Opal ဖြင့်ရေးသားသည်) အတွက် အညွှန်းစာများ သတင်းဥက္ကာရတေ့ တစ်ခုတည်ဆောက်သည်။ |

> **ရရှိနိုင်မှု**: Project Opal သည် လက်ရှိ [Frontier early access program](https://adoption.microsoft.com/copilot/frontier-program/) ၏ အသုံးပြုသူများအတွက် ရရှိနိုင်ပြီး Microsoft 365 Copilot subscription လိုအပ်သည်။ သင့် စီမံခန့်ခွဲသူမှ သတ်မှတ်ချက်များ ပြည့်စုံစွာ ပြီးမြောက်ထားရမည်ဖြစ်သည်။ Frontier ၏ စမ်းသပ်နှင့် စမ်းသပ်မှု အစိတ်အပိုင်းဖြစ်သဖြင့် လာမည့်အချိန်များတွင် တိုးတက်မှုများ ဖြစ်နိုင်သည်။
