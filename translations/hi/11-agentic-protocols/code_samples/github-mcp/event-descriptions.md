## कार्यक्रम का नाम: LangGraph और Azure Cosmos DB के साथ मल्टी-एजेंट API

## विवरण

मल्टी-एजेंट AI अनुप्रयोगों का उदय यह बदल रहा है कि हम बुद्धिमान सिस्टम कैसे बनाते हैं - लेकिन इन्हें वास्तविक दुनिया की स्केलेबिलिटी और प्रदर्शन के लिए कैसे आर्किटेक्ट करें? इस सत्र में, हम LangGraph का उपयोग करके एजेंट ऑर्केस्ट्रेशन के लिए, FastAPI के API लेयर के लिए, और Azure Cosmos DB को स्थिति प्रबंधन, वेक्टर स्टोरेज, और ट्रांजैक्शनल डेटा के लिए रीढ़ की हड्डी के रूप में उपयोग करते हुए उत्पादन-ग्रेड मल्टी-एजेंट एप्लिकेशन में गहराई से उतरेंगे।

विस्तृत कोड वॉकथ्रू के माध्यम से, आप एक एजेंट-चालित वर्कफ़्लो डिज़ाइन और लागू करना सीखेंगे जो RAG (रिट्रीवल-अगुमेंटेड जनरेशन), मेमोरी पर्सिस्टेंस, और डायनामिक स्थिति संक्रमण को सहजता से एकीकृत करता है। हम निम्न को कवर करेंगे:

LangGraph के साथ एजेंट सहयोग संरचित तर्क के लिए
Azure Cosmos DB का उपयोग कर रियल-टाइम चैट इतिहास संग्रहण - वही डेटाबेस जो ChatGPT में चैट इतिहास को संचालित करता है, इतिहास में सबसे तेजी से बढ़ने वाला AI एजेंट एप्लिकेशन
Cosmos DB के स्थानीय एम्बेडिंग सपोर्ट के साथ ज्ञान पुन: प्राप्ति के लिए वेक्टर खोज
FastAPI की असिंक्रोनस क्षमताएं ताकि इंटरैक्शन उत्तरदायी और स्केलेबल रहें
इस सत्र के अंत तक, आपके पास अपने स्वयं के स्केलेबल, क्लाउड-नेटिव मल्टी-एजेंट एप्लिकेशन बनाने और तैनात करने के लिए स्पष्ट ब्लूप्रिंट होगा जो आधुनिक AI और क्लाउड अवसंरचना की शक्ति का उपयोग करता है। चाहे आप AI इंजीनियर हों, क्लाउड आर्किटेक्ट हों, या Python डेवलपर, यह वार्ता आपको व्यावहारिक अंतर्दृष्टि और प्रमाणित पैटर्न प्रदान करेगी ताकि आप AI-चालित अनुप्रयोगों की अगली पीढ़ी बना सकें।

## कार्यक्रम का नाम: Microsoft Foundry Agent Service के साथ अपना कोड-प्रथम ऐप बनाएँ (.NET)

## विवरण

Microsoft Foundry Agent Service सेवा और SDK का एक सहज मिश्रण है जो मजबूत AI-चालित समाधानों के विकास को सरल बनाता है। इस सत्र में, आप सीखेंगे कि Azure और C# के साथ अपना खुद का कोड-प्रथम AI एजेंट कैसे बनाएं जो प्रश्नों का उत्तर दे सके, डेटा विश्लेषण कर सके, और बाहरी डेटा स्रोतों को एकीकृत कर सके। आप एक साथ काम करने वाले कई एजेंटों सहित अधिक जटिल आर्किटेक्चर का भी अन्वेषण करेंगे।

## URL
<https://developer.microsoft.com/en-us/reactor/events/25370/>

## कार्यक्रम का नाम: AI एजेंट + Aspire

## विवरण

इस सत्र में हम .NET प्लेटफ़ॉर्म पर एजेंट्स के आस-पास कुछ सबसे रोमांचक विकास साझा करेंगे। .NET की वर्तमान स्थिति की खोज करें, जिसमें इसके नए फीचर्स और सुधार शामिल हैं। शक्तिशाली AI एजेंट क्षमताओं का अन्वेषण करें। और हम एजेंट्स और Aspire के साथ लाइव कोडिंग करेंगे।

## URL
<https://developer.microsoft.com/en-us/reactor/events/25332/>

## कार्यक्रम का नाम: Semantic Kernel के साथ C# में मल्टी-एजेंट AI एप्लिकेशन बनाना जो Azure Cosmos से संचालित हैं

## विवरण

हम आपको C# में एक मल्टी-एजेंट एप्लिकेशन के माध्यम से चलाएंगे जो Semantic Kernel फ्रेमवर्क के ऊपर बनाया गया है। आप एजेंटिक अनुप्रयोगों के पीछे के सिद्धांत समझेंगे, कार्यान्वयन विवरण और सूक्ष्मताओं को समझेंगे, और विभिन्न उपयोग मामलों के लिए Azure Cosmos DB को डेटाबेस के रूप में एकीकृत करना सीखेंगे।

## URL
<https://developer.microsoft.com/en-us/reactor/events/25455/>
