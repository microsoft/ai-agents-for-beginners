> **CMD (Windows):**
> ```cmd
> git clone --filter=blob:none --sparse https://github.com/microsoft/ai-agents-for-beginners.git

> ```

## 🌱 शुरुआत

इस कोर्स में AI एजेंट बनाने की मूल बातें कवर की गई हैं। हर पाठ अपने विषय को कवर करता है, इसलिए आप अपनी पसंद से कहीं से भी शुरू कर सकते हैं!

इस कोर्स के लिए बहुभाषी समर्थन उपलब्ध है। हमारे [यहाँ उपलब्ध भाषाओं](#-multi-language-support) पर जाएं। 

यदि यह आपका पहली बार जनरेटिव AI मॉडल के साथ निर्माण है, तो हमारे [Generative AI For Beginners](https://aka.ms/genai-beginners) कोर्स को देखें, जिसमें GenAI के साथ निर्माण पर 21 पाठ शामिल हैं।

इस रिपो को [स्टार (🌟)](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst) करना न भूलें और कोड चलाने के लिए [इस रिपो को फोर्क करें](https://github.com/microsoft/ai-agents-for-beginners/fork)।

### अन्य शिक्षार्थियों से मिलें, अपने प्रश्नों के उत्तर पाएं

अगर आप फंस जाएं या AI एजेंट बनाने के बारे में कोई प्रश्न हो, तो हमारी समर्पित Discord चैनल में शामिल हों [Microsoft Foundry Discord](https://aka.ms/ai-agents/discord) पर।

### आपको क्या चाहिए 

इस कोर्स की हर पाठ में कोड उदाहरण शामिल हैं, जो code_samples फोल्डर में पाए जा सकते हैं। आप [इस रिपो को फोर्क करें](https://github.com/microsoft/ai-agents-for-beginners/fork) अपनी खुद की कॉपी बनाने के लिए।  

इन अभ्यासों में कोड उदाहरण Microsoft Agent Framework के साथ Microsoft Foundry Agent Service V2 का उपयोग करते हैं:

- [Microsoft Foundry](https://aka.ms/ai-agents-beginners/ai-foundry) - Azure खाता आवश्यक

इस कोर्स में Microsoft के निम्नलिखित AI एजेंट फ्रेमवर्क और सेवाएं उपयोग की गई हैं:

- [Microsoft Agent Framework (MAF)](https://learn.microsoft.com/agent-framework/overview/)
- [Microsoft Foundry Agent Service V2](https://aka.ms/ai-agents-beginners/ai-agent-service)

कुछ कोड उदाहरण वैकल्पिक OpenAI-संगत प्रदाताओं का भी समर्थन करते हैं जैसे कि [MiniMax](https://platform.minimaxi.com/), जो बड़े संदर्भ मॉडल (204K टोकन तक) प्रदान करता है। कॉन्फ़िगरेशन विवरण के लिए [Course Setup](./00-course-setup/README.md) देखें।

इस कोर्स के लिए कोड चलाने की अधिक जानकारी के लिए, [Course Setup](./00-course-setup/README.md) देखें।

आपके योगदान का उपयोग करने का अधिकार देते हैं। विवरण के लिए <https://cla.opensource.microsoft.com> देखें।

CLA प्रदान करने की आवश्यकता है और PR को उचित रूप से सजाएगा (जैसे स्थिति जांच, टिप्पणी)। बस बोट द्वारा दी गई
निर्देशों का पालन करें। यह प्रक्रिया आपको हमारे CLA उपयोग करने वाले सभी रेपो के लिए केवल एक बार करनी होगी।

इस परियोजना ने [माइक्रोसॉफ्ट ओपन सोर्स कोड ऑफ कंडक्ट](https://opensource.microsoft.com/codeofconduct/) को अपनाया है।
