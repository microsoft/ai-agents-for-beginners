# ⚡ Azure OpenAI (Responses API) के साथ समवर्ती एजेंट वर्कफ़्लोज़ (.NET)

## 📋 उच्च-प्रदर्शन समानांतर प्रसंस्करण ट्यूटोरियल

यह नोटबुक Microsoft Agent Framework for .NET और Azure OpenAI (Responses API) का उपयोग करके **समवर्ती वर्कफ़्लो पैटर्न** को प्रदर्शित करता है। आप सीखेंगे कि कैसे उच्च-प्रदर्शन, समानांतर प्रसंस्करण वर्कफ़्लो बनाएँ जो एक साथ कई AI एजेंटों को निष्पादित करके थ्रूपुट को अधिकतम करते हैं जबकि समन्वय और डेटा संगति बनाए रखते हैं।

## 🎯 सीखने के उद्देश्य

### 🚀 **समवर्ती प्रसंस्करण मूल बातें**
- **समानांतर एजेंट निष्पादन**: अधिकतम प्रदर्शन के लिए एक साथ कई AI एजेंट चलाएँ
- **Async/Await पैटर्न**: कुशल समवर्तीता के लिए .NET के async प्रोग्रामिंग मॉडल का लाभ उठाएँ
- **Azure OpenAI (Responses API)**: Azure OpenAI Responses API को कई समवर्ती कॉल्स के साथ समन्वयित करें
- **संसाधन प्रबंधन**: समवर्ती संचालन में AI मॉडल संसाधनों का कुशल प्रबंधन करें

### 🏗️ **उन्नत समवर्ती वास्तुकला**
- **टास्क-आधारित समानांतरता**: इष्टतम समवर्ती निष्पादन के लिए .NET Task Parallel Library का उपयोग करें
- **सिंक्रोनाइज़ेशन पैटर्न**: रेस कंडीशंस से बचते हुए समवर्ती एजेंटों का समन्वय करें
- **लोड संतुलन**: उपलब्ध समवर्ती प्रसंस्करण क्षमता में कार्य को कुशलता से वितरित करें
- **दोष सहिष्णुता**: संपूर्ण वर्कफ़्लो को रोके बिना व्यक्तिगत एजेंट विफलताओं को संभालें

### 🏢 **एंटरप्राइज समवर्ती अनुप्रयोग**
- **उच्च-संख्या दस्तावेज़ प्रसंस्करण**: एक साथ कई दस्तावेज़ संसाधित करें
- **रीयल-टाइम सामग्री विश्लेषण**: आने वाले डेटा स्ट्रीम्स का समवर्ती विश्लेषण
- **बैच प्रसंस्करण अनुकूलन**: बड़े पैमाने पर डेटा प्रसंस्करण संचालन के लिए थ्रूपुट को अधिकतम करें
- **मल्टी-मोडल विश्लेषण**: विभिन्न सामग्री प्रकारों और प्रारूपों का समानांतर प्रसंस्करण

## 💻 कोड चलाना

पूरी कार्यान्वयन `03.dotnet-agent-framework-workflow-ghmodel-concurrent.cs` में उपलब्ध है। यह फ़ाइल ट्रैवल प्लानिंग के लिए **फैन-आउट/फैन-इन समवर्ती वर्कफ़्लो** को प्रदर्शित करती है:

### 🏗️ **वर्कफ़्लो वास्तुकला**

```
User Request → ConcurrentStartExecutor → [Researcher Agent || Planner Agent] → ConcurrentAggregationExecutor → Final Output
```

**प्रमुख घटक:**

1. **ConcurrentStartExecutor**: उपयोगकर्ता अनुरोध को सभी एजेंटों को एक साथ प्रसारित करता है
2. **Researcher Agent**: गंतव्यों और आकर्षणों का समवर्ती विश्लेषण करता है
3. **Planner Agent**: समवर्ती रूप से विस्तृत यात्रा योजनाएँ तैयार करता है
4. **ConcurrentAggregationExecutor**: दोनों एजेंटों से परिणाम एकत्रित और विलय करता है

### 🎯 **फैन-आउट/फैन-इन पैटर्न**

यह वर्कफ़्लो क्लासिक **फैन-आउट/फैन-इन** पैटर्न को प्रदर्शित करता है:
- **फैन-आउट**: एक इनपुट संदेश को एक साथ कई एजेंटों को प्रसारित किया जाता है
- **समवर्ती प्रसंस्करण**: कई एजेंट समान कार्य पर समानांतर काम करते हैं
- **फैन-इन**: सभी एजेंटों से परिणाम एकत्रित कर एकल आउटपुट में समेकित किया जाता है

वर्कफ़्लो यह करेगा:

4. **परिणाम दिखाना**: सभी जानकारी के साथ विलयित यात्रा योजना प्रदर्शित करेगा

### 🔧 अनुकूलन विकल्प

**अधिक समवर्ती एजेंट जोड़ें:**
```csharp
// Create additional specialized agents
AIAgent budgetAgent = azureClient.GetChatClient(deployment).AsAIAgent(
    name: "Budget-Agent", instructions: "Calculate travel costs...");

// Add to fan-out
var workflow = new WorkflowBuilder(startExecutor)
    .AddFanOutEdge(startExecutor, targets: [researcherAgent, plannerAgent, budgetAgent])
    .AddFanInBarrierEdge(sources: [researcherAgent, plannerAgent, budgetAgent], target: aggregationExecutor)
    .WithOutputFrom(aggregationExecutor)
    .Build();

// Update aggregation count
if (this._messages.Count == 3) { ... }
```

**एजेंट निर्देश संशोधित करें:**
```csharp
const string ResearcherAgentInstructions = "Your custom instructions for research...";
const string PlanAgentInstructions = "Your custom instructions for planning...";
```

**कार्य बदलें:**
```csharp
StreamingRun run = await InProcessExecution.RunStreamingAsync(
    workflow,

);
```

- **कोड समीक्षा**: विभिन्न दृष्टिकोणों से कोड का समवर्ती विश्लेषण करने वाले कई समीक्षक
- **बाजार अनुसंधान**: विभिन्न बाजार खंडों का समानांतर विश्लेषण
- **दस्तावेज़ प्रसंस्करण**: समवर्ती निष्कर्षण, विश्लेषण, और सत्यापन
- **मल्टी-पर्सपेक्टिव विश्लेषण**: एक ही इनपुट पर विविध दृष्टिकोण प्राप्त करना

### 🔍 कस्टम एक्सेक्यूटर्स को समझना

**ConcurrentStartExecutor:**
- `IMessageHandler<string>` को लागू करता है ताकि स्ट्रिंग इनपुट स्वीकार किया जा सके
- सभी जुड़े एजेंटों को संदेश प्रसारित करता है
- समवर्ती प्रसंस्करण प्रारंभ करने के लिए `TurnToken` भेजता है

**ConcurrentAggregationExecutor:**
- `IMessageHandler<ChatMessage>` को लागू करता है ताकि एजेंट प्रतिक्रियाएं प्राप्त की जा सकें
- थ्रेड-सुरक्षित तरीके से संदेश एकत्र करता है
- सभी अपेक्षित प्रतिक्रियाएं आने पर समाकलन करता है
- `context.YieldOutputAsync()` का उपयोग कर अंतिम आउटपुट देता है

### ⚡ प्रदर्शन लाभ

**समवर्ती बनाम अनुक्रमिक:**
- अनुक्रमिक: Agent1 (30s) → Agent2 (30s) = **कुल 60 सेकंड**
- समवर्ती: Agent1 (30s) || Agent2 (30s) = **कुल 30 सेकंड**

**थ्रूपुट सुधार**: N समवर्ती एजेंटों के लिए N× तक तेज (वर्कलोड और संसाधनों पर निर्भर)
