# ⏩ Sekvenciniai Agentų Darbo Srautai su Azure OpenAI (Responses API) (.NET)

## 📋 Išplėstinis Sekvencinio Apdorojimo Vadovas

Šiame užrašų knygelėje demonstruojami **sekvencinių darbo srautų modeliai** naudojant Microsoft Agent Framework skirtą .NET ir Azure OpenAI (Responses API). Sužinosite, kaip kurti sudėtingas, žingsnis po žingsnio apdorojimo grandines, kur agentai veikia tam tikra tvarka, o kiekvienas etapas remiasi ankstesnio etapo rezultatais.

## 🎯 Mokymosi Tikslai

### 🔄 **Sekvencinio Apdorojimo Architektūra**
- **Tiesinis Darbo Srauto Dizainas**: Kurkite žingsnis po žingsnio apdorojimo grandines su aiškiomis priklausomybėmis
- **Būseno Valdymas**: Išlaikykite kontekstą ir duomenų srautą per sekvencinius darbo srauto etapus
- **Azure OpenAI (Responses API)**: Naudokite Azure OpenAI modelius daugiaetapiuose .NET darbo srautuose
- **Įmonių Pagrindiniai Modeliai**: Kurkite gamybai paruoštas sekvencinio apdorojimo sistemas

### 🏗️ **Išplėstiniai Sekvenciniai Modeliai**
- **Etapo Vartų Apdorojimas**: Įgyvendinkite patikros taškus tarp darbo srauto etapų
- **Konteksto Išlaikymas**: Išlaikykite būseną ir sukauptas žinias per visus etapus
- **Klaidų Skleidimas**: Žaismingas gedimų valdymas sekvencinėse apdorojimo grandinėse
- **Veikimo Optimizavimas**: Efektyvus sekvencinis vykdymas su minimaliu režiniu laiku

### 🏢 **Įmonių Sekvencinės Programos**
- **Dokumentų Apdorojimo Vamzdelis**: Daugiaetapė dokumentų analizė, transformavimas ir patikra
- **Kokybės Užtikrinimo Darbo Srautai**: Sekvencinis peržiūrėjimas, patikra ir patvirtinimas
- **Turinio Gamybos Vamzdelis**: Tyrimai → Rašymas → Redagavimas → Peržiūra → Leidyba
- **Verslo Procesų Automatizavimas**: Daugiaetapiai verslo darbo srautai su aiškiomis etapų priklausomybėmis

```xml
<!-- Local Agent Framework References -->
<!-- Microsoft.Agents.AI.dll - Core agent abstractions -->
<!-- Microsoft.Agents.AI.OpenAI.dll - Azure OpenAI (Responses API) integration -->
```

### 🔑 **Azure OpenAI Konfigūracija**

```env
AZURE_OPENAI_DEPLOYMENT=gpt-4o-mini
```

**Konfigūracijos valdymas:**

```csharp
// Load environment variables securely
```

### 🏗️ **Sekvencinio Darbo Srauto Architektūra**

```mermaid
graph TD
    A[Initial Input] --> B[Stage 1: Analizės agentas]
    B --> C[Patikros taškas 1]
    C --> D[Stage 2: Apdorojimo agentas]
    D --> E[Patikros taškas 2]
    E --> F[Stage 3: Validavimo agentas]
    F --> G[Galutinis rezultatas]
    
    H[Būsenos kontekstas] --> B
    H --> D
    H --> F
    
    I[Azure OpenAI (Atsakymų API)] --> B
    I --> D
    I --> F
```

**Pagrindinės Sudedamosios Dalys:**
- **Sekvenciniai Agentai**: Specializuoti agentai kiekvienam apdorojimo etapui

- **Kontroliniai Taškai**: Patikros taškai tarp etapų kokybės ir nuoseklumo užtikrinimui
- **Azure OpenAI Klientas**: Nuoseklus AI modelio pasiekiamumas visuose darbo srauto etapuose

## 💻 Kodo Vykdymas

Pilnas įgyvendinimas yra faile `02.dotnet-agent-framework-workflow-ghmodel-sequential.cs`. Šis failas demonstruoja **trijų etapų baldų analizės darbo srautą**:

1. **1 etapas - Pardavimų Agentas**: analizuoja baldų nuotraukas ir pateikia pirkimo pasiūlymus
2. **2 etapas - Kainos Agentas**: pateikia detalias kainų išskaidymas ir biudžeto galimybes
3. **3 etapas - Pasiūlymo Agentas**: generuoja profesionalų pasiūlymo dokumentą Markdown formatu

### 🏗️ **Darbo Srauto Architektūra**

```
Image Input → Sales Analysis → Price Estimation → Quote Generation → Final Output
```

Kiekvienas agentas:
- Gauta ankstesnio etapo išvestis kaip kontekstas
- Papildo ankstesnę analizę specializuotomis žiniomis
- Išlaiko darbo srauto tęstinumą per būsenos valdymą

### 🚀 Vykdyti Pavyzdį

**Reikalavimai:**
- Įdėkite baldų nuotrauką į `../imgs/home.png` (arba atnaujinkite `imgPath` kintamąjį)
- Sukonfigūruokite savo `.env` failą su Azure OpenAI pabaigos tašku ir diegimu, tada prisijunkite naudodami `az login`

```bash
# Padarykite scenarijų vykdomą (Unix/Linux/macOS)
chmod +x 02.dotnet-agent-framework-workflow-ghmodel-sequential.cs

# Vykdykite nuoseklų darbo eigą
./02.dotnet-agent-framework-workflow-ghmodel-sequential.cs
```

Ar Windows sistemoje:
```powershell
dotnet run 02.dotnet-agent-framework-workflow-ghmodel-sequential.cs
```

### 📝 Tikėtina Išvestis

Darbo srautas atliks:
1. **Pardavimų Agentas**: identifikuos baldų elementus iš nuotraukos ir pateiks rekomendacijas
2. **Kainos Agentas**: pridės detalią kainų analizę su biudžeto lygiais ir pirkimo rekomendacijomis
3. **Pasiūlymo Agentas**: sukurs suformatuotą pasiūlymo dokumentą su visu suvestu turiniu

Galutinis rezultatas bus išsamus, profesionalus baldų pasiūlymas, pagrįstas vaizdo analize.

### 🎯 Realūs Panaudojimai

Šis sekvencinis modelis idealiai tinka:
- **E-komercija**: Produktų analizė → Kainodara → Pasiūlymo generavimas
- **Nekilnojamasis Turtas**: Turto analizė → Vertinimas → Skelbimų kūrimas
- **Draudimas**: Ieškinių analizė → Įvertinimas → Pasiūlymo generavimas

### 🔍 Supratimas apie Būseno Srautą

Kiekvienas sekvencinis agentas gauna:
- **Pradinę Įvestį**: Pradinį vartotojo pranešimą (vaizdą + tekstą)
- **Ankstesnių Agentų Atsakymus**: Visus ankstesnius agentų atsakymus pokalbių istorijoje
- **Sukauptą Kontextą**: Visą būseną, palaikomą per visą darbo srautą

Tai leidžia sudėtingą daugiaetapį apdorojimą, kai kiekvienas agentas kuria remdamasis išsamiu visų ankstesnių etapų kontekstu.
