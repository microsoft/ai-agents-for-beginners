# 🔄 Pagrindiniai agentų darbo srautai su Azure OpenAI (Responses API) (.NET)

## 📋 Darbo srauto organizavimo vadovas

Šis užrašų knygelės pavyzdys demonstruoja, kaip sukurti sudėtingus **agentų darbo srautus** naudojant Microsoft Agent Framework for .NET ir Azure OpenAI (Responses API). Išmoksite kurti kelių žingsnių verslo procesus, kuriuose AI agentai bendradarbiauja siekdami įvykdyti sudėtingas užduotis per struktūrizuotus organizavimo šablonus.

## 🎯 Mokymosi tikslai

### 🏗️ **Darbo srauto architektūros pagrindai**
- **Workflow Builder**: Dizainas ir sudėtingų kelių žingsnių AI procesų organizavimas
- **Agentų koordinacija**: Koordinuoti kelis specializuotus agentus darbo srautuose
- **Azure OpenAI (Responses API)**: Naudoti Azure OpenAI Responses API darbo srautuose
- **Vizualus darbo srauto dizainas**: Kurti ir vizualizuoti darbo srautų struktūras geresniam supratimui

### 🔄 **Procesų organizavimo šablonai**
- **Sekveninis apdorojimas**: Sujungti kelias agentų užduotis loginėje tvarkoje
- **Būsenos valdymas**: Išlaikyti kontekstą ir duomenų srautą per darbo srauto etapus
- **Klaidų valdymas**: Įgyvendinti patikimą klaidų atkūrimą ir darbo srauto atsparumą
- **Veiklos optimizavimas**: Dizainuoti efektyvius darbo srautus įmonės mastu

### 🏢 **Įmonių lygio darbo srauto taikymai**
- **Verslo procesų automatizavimas**: Automatizuoti sudėtingus organizacinius darbo srautus
- **Turinio gamybos grandinė**: Redakciniai darbo srautai su peržiūros ir tvirtinimo etapais
- **Klientų aptarnavimo automatizavimas**: Kelių žingsnių užklausų sprendimas
- **Duomenų apdorojimo darbo srautai**: ETL darbo srautai su AI pagrįsta transformacija

## ⚙️ Reikalavimai ir parengimas

### 📦 **Būtinos NuGet paketai**

Šiam darbo srauto pavyzdžiui naudojami keli pagrindiniai .NET paketai:

```xml
<!-- Core AI Framework -->
<PackageReference Include="Microsoft.Extensions.AI" Version="9.9.0" />

<!-- Azure OpenAI (Responses API) -->
<PackageReference Include="Azure.AI.OpenAI" Version="2.1.0" />
<PackageReference Include="Azure.Identity" Version="1.13.1" />

<!-- Agent Framework (Local Development) -->
<!-- Microsoft.Agents.AI.dll - Core agent abstractions -->
<!-- Microsoft.Agents.AI.OpenAI.dll - Azure OpenAI (Responses API) integration -->

<!-- Configuration and Environment -->
<PackageReference Include="DotNetEnv" Version="3.1.1" />
```

### 🔑 **Azure OpenAI konfigūracija**

**Aplinkos paruošimas (.env failas):**
```env
AZURE_OPENAI_ENDPOINT=https://<your-resource>.openai.azure.com
AZURE_OPENAI_DEPLOYMENT=gpt-4o-mini
```

**Prieiga prie Azure OpenAI:**
1. Sukurkite Azure OpenAI išteklių Azure portale
2. Įdiekite modelį (pvz., `gpt-4o-mini`) ir įsidėmėkite įdiegimo pavadinimą
3. Prisijunkite naudodami `az login` ir sukonfigūruokite aplinkos kintamuosius, kaip parodyta aukščiau

### 🏗️ **Darbo srauto architektūros apžvalga**

```mermaid
graph TD
    A[Darbų eigos kūrėjas] --> B[Agentų registras]
    B --> C[Darbų eigos vykdymo variklis]
    C --> D[Agent 1: Turinys generatorius]
    C --> E[Agent 2: Turinio peržiūrėtojas] 
    D --> F[Darbų eigos rezultatai]
    E --> F
    G[Azure OpenAI (Atsakymai API)] --> D
    G --> E
```

**Pagrindinės dalys:**
- **WorkflowBuilder**: Pagrindinis organzavimo variklis darbo srautams kurti
- **AIAgent**: Individualūs specializuoti agentai su specifinėmis galimybėmis
- **Azure OpenAI klientas**: Azure OpenAI Responses API integracija
- **Vykdymo kontekstas**: Valdo būseną ir duomenų srautą tarp darbo srauto etapų

## 🎨 **Įmonių lygio darbo srauto dizaino šablonai**

```
User Request → Content Generation → Quality Review → Final Output
```

### 🔍 **Dokumentų apdorojimo grandinė**
```
Document Input → Analysis → Extraction → Validation → Structured Output
```

### 💼 **Verslo intelekto darbo srautas**
```
Data Collection → Processing → Analysis → Report Generation → Distribution
```

```
Customer Inquiry → Classification → Processing → Response Generation → Follow-up
```

## 🏢 **Įmonių privalumai**

### 🎯 **Patikimumas ir mastelio keitimas**
- **Deterministinis vykdymas**: Nuoseklūs, pakartojami darbo srautų rezultatai
- **Klaidų atkūrimas**: Švelnus gedimų valdymas bet kuriame darbo srauto etape
- **Veiklos stebėsena**: Sekite vykdymo rodiklius ir optimizavimo galimybes
- **Išteklų valdymas**: Efektyvus AI modelių išteklių paskirstymas ir panaudojimas

### 🔒 **Saugumas ir atitiktis**

- **Prieigos kontrolė**: Smulkios teisės darbo srautų vykdymui ir stebėjimui
- **Duomenų privatumas**: Saugus konfidencialios informacijos tvarkymas darbo srautuose

### 📊 **Stebėsena ir valdymas**
- **Vizualus darbo srauto dizainas**: Aiškus proceso srautų ir priklausomybių atvaizdavimas
- **Vykdymo stebėjimas**: Realaus laiko darbo srauto pažangos ir našumo sekimas
- **Klaidų ataskaitos**: Išsami klaidų analizė ir derinimo galimybės
- **Veiklos analizė**: Rodikliai optimizavimui ir pajėgumų planavimui

## 💻 Kodo paleidimas

Pilnas įgyvendinimas yra faile `01.dotnet-agent-framework-workflow-ghmodel-basic.cs`. Šiame faile demonstruojama:

1. **Aplinkos konfigūracija** - Azure OpenAI konfigūracijos įkėlimas iš `.env` failo
2. **Azure OpenAI kliento paruošimas** - Kliento konfigūracija naudoti Azure OpenAI Responses API
3. **Agentų kūrimas** - Specializuotų agentų (Priekinio stalo ir Konsjeržo) apibrėžimas
4. **Darbo srauto konstruktorius** - Kelių agentų darbo srauto sukūrimas su sekvenciniu apdorojimu
5. **Darbo srauto vykdymas** - Darbo srauto paleidimas su rezultatų srautu

### 🚀 Pavyzdžio paleidimas

```bash
# Padarykite scenarijų vykdomu (Unix/Linux/macOS)
chmod +x 01.dotnet-agent-framework-workflow-ghmodel-basic.cs

# Paleiskite darbo eigą
./01.dotnet-agent-framework-workflow-ghmodel-basic.cs
```

Ar Windows aplinkoje:
```powershell
dotnet run 01.dotnet-agent-framework-workflow-ghmodel-basic.cs
```

### 📝 Laukiamas rezultatas

Darbo srautas:
1. Priims jūsų kelionės užklausą („Norėčiau vykti į Paryžių“)
2. Priekinio stalo agentas pateiks pirminę rekomendaciją
3. Konsjeržo agentas peržiūrės ir patobulins rekomendaciją
4. Galutinis rezultatas rodys visą pokalbio srautą

### 🔧 Tinkintuvimas

Galite tinkinti darbo srautą:
- Pakeisdami agentų instrukcijas jų elgsenai modifikuoti
- Pridėdami daugiau agentų sudėtingiems kelių žingsnių darbo srautams kurti
- Keisdami vartotojo žinutę skirtingoms situacijoms išbandyti
- Koreguodami darbo srauto ryšius skirtingiems vykdymo šablonams sukurti
