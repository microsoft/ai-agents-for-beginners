> **CMD (Windows):**
> ```cmd
> git clone --filter=blob:none --sparse https://github.com/microsoft/ai-agents-for-beginners.git
> cd ai-agents-for-beginners
> git sparse-checkout set --no-cone "/*" "!translations" "!translated_images"
> ```

## 🌱 Pradžia

Šiame kurse yra pamokos, apimančios AI agentų kūrimo pagrindus. Kiekviena pamoka apima savą temą, tad pradėkite ten, kur jums patogiausia!

Šiam kursui yra kelių kalbų palaikymas. Žr. mūsų [galimas kalbas čia](#-multi-language-support).

Jei tai pirmas kartas, kai dirbate su generatyviniais AI modeliais, pažiūrėkite mūsų [Generatyvinis AI pradedantiesiems](https://aka.ms/genai-beginners) kursą, kuriame yra 21 pamoka apie GenAI kūrimą.

Nepamirškite [įvertinti (🌟) šį repo](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst) ir [padaryti forką](https://github.com/microsoft/ai-agents-for-beginners/fork), kad galėtumėte paleisti kodą.

### Susipažinkite su kitais besimokančiaisiais, gaukite atsakymus į savo klausimus

Jei stringate ar turite klausimų apie AI agentų kūrimą, prisijunkite prie mūsų specialaus Discord kanalo [Microsoft Foundry Discord](https://aka.ms/ai-agents/discord).

### Ko jums reikės

Kiekviena šio kurso pamoka turi kodo pavyzdžių, kurie randami code_samples kataloge. Galite [padaryti forką](https://github.com/microsoft/ai-agents-for-beginners/fork) šiai saugyklai sukurti savo kopiją.

Šiuose pavyzdžiuose naudojamas Microsoft Agent Framework su Microsoft Foundry Agent Service V2:

- [Microsoft Foundry](https://aka.ms/ai-agents-beginners/ai-foundry) - Reikalinga Azure paskyra

Šis kursas naudoja šias Microsoft AI agentų platformas ir paslaugas:

- [Microsoft Agent Framework (MAF)](https://learn.microsoft.com/agent-framework/overview/)
- [Microsoft Foundry Agent Service V2](https://aka.ms/ai-agents-beginners/ai-agent-service)

Kai kurie kodo pavyzdžiai taip pat palaiko alternatyvius OpenAI suderinamus tiekėjus, tokius kaip [MiniMax](https://platform.minimaxi.com/), siūlantį didelio konteksto modelius (iki 204K ženklų). Išsamesnę informaciją žiūrėkite [kurso nustatymuose](./00-course-setup/README.md).

Daugiau informacijos apie kodo vykdymą šiam kursui ieškokite [kurso nustatymuose](./00-course-setup/README.md).
