Vektorinę paiešką žinių gavimui su Cosmos DB vietiniu embedded palaikymu
FastAPI asinchronines galimybes palaikyti sąveikas reagavimo ir mastelio požiūriu
Sesijos pabaigoje turėsite aiškų planą, kaip kurti ir diegti savo mastelio keičiamas, debesų principu sukurtas daugiaagentnes programas, kurios išnaudoja šiuolaikinių AI ir debesų infrastruktūros galimybes.
