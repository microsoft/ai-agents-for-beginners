## Ime dogodka: Večagentni API z LangGraph in Azure Cosmos DB

## Opis

Vzpon večagentnih AI aplikacij spreminja način, kako gradimo inteligentne sisteme – ampak kako jih arhitektirati za resnično razširljivost in zmogljivost? Na tej seji bomo podrobno pregledali produkcijsko večagentno aplikacijo, zgrajeno z LangGraph za orkestracijo agentov, FastAPI za API plast in Azure Cosmos DB kot hrbtenico za upravljanje stanja, shranjevanje vektorjev in transakcijske podatke.

Skozi podroben ogled kode boste videli, kako zasnovati in implementirati potek dela, ki temelji na agentih, in brezhibno integrira generiranje z iskanjem (RAG), trajno shranjevanje pomnilnika in dinamične prehode stanj. Pokrili bomo:

Sodelovanje agentov z LangGraph za strukturirano razmišljanje
Shranjevanje zgodovine klepeta v realnem času z Azure Cosmos DB - isto podatkovno bazo, ki poganja zgodovino klepeta v ChatGPT, najhitreje rastoči AI agent aplikaciji v zgodovini
Iskanje vektorjev za pridobivanje znanja s podporo vgrajenih v Cosmos DB
Async zmogljivosti FastAPI za ohranjanje odzivnih in razširljivih interakcij
Na koncu te seje boste imeli jasno predlogo za gradnjo in uvajanje lastnih skalabilnih, oblačno naravnanih večagentnih aplikacij, ki izkoriščajo moč sodobne AI in oblačne infrastrukture. Ne glede na to, ali ste AI inženir, oblačni arhitekt ali Python razvijalec, vas bo ta govor opremil s praktičnimi vpogledi in preizkušenimi vzorci za gradnjo naslednje generacije AI-pogonanih aplikacij.
