> **CMD (Windows):**

> git clone --filter=blob:none --sparse https://github.com/microsoft/ai-agents-for-beginners.git

## 🌱 Začetek

Ta tečaj vsebuje lekcije, ki pokrivajo osnove gradnje AI agentov. Vsaka lekcija obravnava svojo temo, zato začnite kjerkoli želite!

Za ta tečaj je na voljo podpora za več jezikov. Oglejte si naše [razpoložljive jezike tukaj](#-multi-language-support). 

Če je to vaš prvič, da delate z generativnimi AI modeli, preverite naš tečaj [Generative AI For Beginners](https://aka.ms/genai-beginners), ki vsebuje 21 lekcij o gradnji z GenAI.

Ne pozabite [ozvezditi (🌟) tega repozitorija](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst) in [forkati tega repozitorija](https://github.com/microsoft/ai-agents-for-beginners/fork), da lahko zaženete kodo.

### Spoznajte druge udeležence in dobite odgovore na vaša vprašanja

Če naletite na težave ali imate vprašanja o izdelavi AI agentov, se pridružite našemu namenskem Discord kanalu v [Microsoft Foundry Discord](https://aka.ms/ai-agents/discord).

### Kaj potrebujete 

Vsaka lekcija tega tečaja vključuje primerke kode, ki jih najdete v mapi code_samples. Lahko [forkate ta repozitorij](https://github.com/microsoft/ai-agents-for-beginners/fork) in ustvarite svojo kopijo.

Primerki kode v teh vajah uporabljajo Microsoft Agent Framework z Microsoft Foundry Agent Service V2:

- [Microsoft Foundry](https://aka.ms/ai-agents-beginners/ai-foundry) - zahteva Azure račun

Ta tečaj uporablja naslednje ogrodja in storitve AI agentov od Microsofta:

- [Microsoft Agent Framework (MAF)](https://learn.microsoft.com/agent-framework/overview/)
- [Microsoft Foundry Agent Service V2](https://aka.ms/ai-agents-beginners/ai-agent-service)

Nekateri primerki kode podpirajo tudi alternativne ponudnike, združljive z OpenAI, kot je [MiniMax](https://platform.minimaxi.com/), ki ponuja modele z velikim kontekstom (do 204K tokenov). Za podrobnosti o nastavitvi glejte [Course Setup](./00-course-setup/README.md).

Za več informacij o izvajanju kode za ta tečaj obiščite [Course Setup](./00-course-setup/README.md).
