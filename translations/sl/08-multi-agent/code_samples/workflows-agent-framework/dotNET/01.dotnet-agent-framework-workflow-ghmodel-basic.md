# 🔄 Osnovni poteki dela agentov z Azure OpenAI (Responses API) (.NET)

## 📋 Vodič za orkestracijo poteka dela

Ta zvezek prikazuje, kako zgraditi sofisticirane **poteče dela agentov** z uporabo Microsoft Agent Framework za .NET in Azure OpenAI (Responses API). Naučili se boste ustvarjati večstopenjske poslovne procese, kjer AI agenti sodelujejo za izvedbo kompleksnih nalog preko strukturiranih vzorcev orkestracije.

## 🎯 Cilji učenja

### 🏗️ **Osnove arhitekture poteka dela**
- **Ustvarjalec poteka dela**: Oblikovanje in orkestracija kompleksnih večstopenjskih AI procesov
- **Koordinacija agentov**: Usmerjanje več specializiranih agentov znotraj potekov dela
- **Azure OpenAI (Responses API)**: Izraba Azure OpenAI Responses API v potekih dela
- **Vizualno oblikovanje poteka dela**: Ustvarjanje in vizualizacija struktur potekov za boljše razumevanje

### 🔄 **Vzorec orkestracije procesov**
- **Zaporedna obdelava**: Povezovanje več nalog agentov v logičnem vrstnem redu
- **Upravljanje stanja**: Ohranitev konteksta in toka podatkov skozi faze poteka dela
- **Ravnanje z napakami**: Implementacija robustnega okrevanja in odpornosti poteka dela
- **Optimizacija zmogljivosti**: Oblikovanje učinkovitih potekov za obsežne poslovne operacije

### 🏢 **Poslovne aplikacije poteka dela**
- **Avtomatizacija poslovnih procesov**: Avtomatizacija kompleksnih organizacijskih potekov dela
- **Proizvodni tok vsebin**: Uredniški poteki dela z elementi pregleda in odobritve
- **Avtomatizacija službe za stranke**: Večstopenjska rešitev povpraševanj strank
- **Poteki obdelave podatkov**: ETL poteki dela z AI-podprtimi transformacijami

## ⚙️ Zahteve in nastavitev

### 📦 **Zahtevani NuGet paketi**

Ta demonstracija poteka dela uporablja več ključnih .NET paketov:

```xml
<!-- Core AI Framework -->
<PackageReference Include="Microsoft.Extensions.AI" Version="9.9.0" />

<!-- Azure OpenAI (Responses API) -->
<PackageReference Include="Azure.AI.OpenAI" Version="2.1.0" />
<PackageReference Include="Azure.Identity" Version="1.13.1" />

<!-- Agent Framework (Local Development) -->
<!-- Microsoft.Agents.AI.dll - Core agent abstractions -->
<!-- Microsoft.Agents.AI.OpenAI.dll - Azure OpenAI (Responses API) integration -->

<!-- Configuration and Environment -->
<PackageReference Include="DotNetEnv" Version="3.1.1" />
```

### 🔑 **Nastavitev Azure OpenAI**

**Nastavitev okolja (.env datoteka):**
```env
AZURE_OPENAI_ENDPOINT=https://<your-resource>.openai.azure.com
AZURE_OPENAI_DEPLOYMENT=gpt-4o-mini
```

**Dostop do Azure OpenAI:**
1. Ustvarite Azure OpenAI virov v Azure portalu
2. Namestite model (na primer `gpt-4o-mini`) in si zabeležite ime distribucije
3. Prijavite se z `az login` in konfigurirajte okoljske spremenljivke kot je prikazano zgoraj

### 🏗️ **Pregled arhitekture poteka dela**

```mermaid
graph TD
    A[Graditelj delovnih tokov] --> B[Register agentov]
    B --> C[Pogon za izvajanje delovnih tokov]
    C --> D[Agent 1: Generator vsebine]
    C --> E[Agent 2: Recenzent vsebine] 
    D --> F[Rezultati delovnih tokov]
    E --> F
    G[Azure OpenAI (Responses API)] --> D
    G --> E
```

**Ključne komponente:**
- **WorkflowBuilder**: Glavni orkestracijski mehanizem za načrtovanje potekov dela
- **AIAgent**: Posamezni specializirani agenti s specifičnimi sposobnostmi
- **Azure OpenAI Client**: Integracija Azure OpenAI Responses API
- **Execution Context**: Upravljanje stanja in toka podatkov med fazami poteka dela

## 💻 Zagon kode

Celotna implementacija je na voljo v `01.dotnet-agent-framework-workflow-ghmodel-basic.cs`. Ta datoteka prikazuje:

1. **Konfiguracija okolja** - Nalaganje konfiguracije Azure OpenAI iz `.env` datoteke
2. **Nastavitev Azure OpenAI odjemalca** - Konfiguracija odjemalca za uporabo Azure OpenAI Responses API
3. **Ustvarjanje agentov** - Definiranje specializiranih agentov (Front Desk in Concierge)
4. **Ustvarjalec poteka dela** - Kreiranje večagentnega poteka dela z zaporedno obdelavo
5. **Izvajanje poteka dela** - Zagon poteka dela z rezultati v tokovnem načinu

### 🚀 Zagon primera

```bash
# Naredite skripto izvršljivo (Unix/Linux/macOS)
chmod +x 01.dotnet-agent-framework-workflow-ghmodel-basic.cs

# Zaženite potek dela
./01.dotnet-agent-framework-workflow-ghmodel-basic.cs
```

Ali na Windows:
```powershell
dotnet run 01.dotnet-agent-framework-workflow-ghmodel-basic.cs
```

### 📝 Pričakovani izhod

Potek dela bo:
1. Sprejel vašo zahtevo za potovalni cilj ("Rad bi šel v Pariz")
2. Agent Front Desk poda začetno priporočilo
3. Agent Concierge pregleda in izpopolni priporočilo
4. Končni izhod prikaže celoten potek pogovora

- Spremembo uporabniškega sporočila za testiranje različnih scenarijev
- Prilagajanjem povezav poteka za ustvarjanje različnih vzorcev izvajanja
