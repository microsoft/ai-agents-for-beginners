## 🌱 Começar

Este curso tem lições que cobrem os fundamentos da construção de Agentes de IA. Cada lição cobre o seu próprio tema, por isso comece onde quiser!

Existe suporte multilíngue para este curso. Vá às nossas [línguas disponíveis aqui](#-multi-language-support). 

Se for a sua primeira vez a construir com modelos de IA Generativa, confira o nosso curso [IA Generativa para Iniciantes](https://aka.ms/genai-beginners), que inclui 21 lições sobre como construir com GenAI.

Não se esqueça de [estrelas (🌟) neste repositório](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst) e [bifar este repositório](https://github.com/microsoft/ai-agents-for-beginners/fork) para executar o código.

### Conheça Outros Aprendizes, Tire as Suas Dúvidas

Se ficar bloqueado ou tiver dúvidas sobre a construção de Agentes de IA, junte-se ao nosso Canal Discord dedicado no [Microsoft Foundry Discord](https://aka.ms/ai-agents/discord).

### O Que Precisa

Cada lição deste curso inclui exemplos de código, que podem ser encontrados na pasta code_samples. Pode [bifar este repositório](https://github.com/microsoft/ai-agents-for-beginners/fork) para criar a sua própria cópia.  

Os exemplos de código nestes exercícios utilizam o Microsoft Agent Framework com o Microsoft Foundry Agent Service V2:

- [Microsoft Foundry](https://aka.ms/ai-agents-beginners/ai-foundry) - É necessária Conta Azure

Este curso usa os seguintes frameworks e serviços de Agentes de IA da Microsoft:

- [Microsoft Agent Framework (MAF)](https://learn.microsoft.com/agent-framework/overview/)
- [Microsoft Foundry Agent Service V2](https://aka.ms/ai-agents-beginners/ai-agent-service)

Alguns exemplos de código também suportam provedores alternativos compatíveis com OpenAI, como o [MiniMax](https://platform.minimaxi.com/), que oferece modelos de grande contexto (até 204K tokens). Veja os detalhes da configuração em [Configuração do Curso](./00-course-setup/README.md).

Para mais informações sobre como executar o código deste curso, vá a [Configuração do Curso](./00-course-setup/README.md).
