# ⏩ Fluxos de Trabalho Sequenciais com Agentes usando Azure OpenAI (Responses API) (.NET)

## 📋 Tutorial Avançado de Processamento Sequencial

Este notebook demonstra **padrões de fluxos de trabalho sequenciais** utilizando o Microsoft Agent Framework para .NET e Azure OpenAI (Responses API). Vai aprender como construir pipelines sofisticados de processamento passo a passo onde os agentes executam numa ordem específica, com cada etapa a basear-se nos resultados da etapa anterior.

## 🎯 Objetivos de Aprendizagem

### 🔄 **Arquitetura de Processamento Sequencial**
- **Design Linear de Fluxos de Trabalho**: Criar pipelines de processamento passo a passo com dependências claras
- **Gestão de Estado**: Manter contexto e fluxo de dados através das etapas sequenciais do workflow
- **Azure OpenAI (Responses API)**: Aproveitar modelos Azure OpenAI em workflows .NET multi-etapas
- **Padrões para Pipelines Empresariais**: Construir sistemas de processamento sequencial prontos para produção

### 🏗️ **Padrões Avançados Sequenciais**
- **Processamento em Stage-Gate**: Implementar pontos de validação entre etapas do workflow
- **Preservação de Contexto**: Manter estado e conhecimento acumulado ao longo de todas as etapas
- **Propagação de Erros**: Lidar com falhas de forma graciosa em cadeias de processamento sequencial
- **Otimização de Performance**: Execução sequencial eficiente com sobrecarga mínima

### 🏢 **Aplicações Empresariais Sequenciais**
- **Pipeline de Processamento de Documentos**: Análise, transformação e validação de documentos em múltiplas etapas
- **Workflows de Garantia de Qualidade**: Revisão, validação e aprovação sequenciais
- **Pipeline de Produção de Conteúdo**: Investigação → Escrita → Edição → Revisão → Publicação
- **Automação de Processos de Negócio**: Workflows empresariais multi-etapas com dependências claras entre fases

### 🏗️ **Arquitetura do Workflow Sequencial**

```mermaid
graph TD
    A[Initial Input] --> B[Stage 1: Agente de Análise]
    B --> C[Ponto de Verificação 1]
    C --> D[Stage 2: Agente de Processamento]
    D --> E[Ponto de Verificação 2]
    E --> F[Stage 3: Agente de Validação]
    F --> G[Resultado Final]

    H --> D
    H --> F
    
    I[Azure OpenAI (API de Respostas)] --> B
```

**Componentes Chave:**
- **Agentes Sequenciais**: Agentes especializados para cada etapa de processamento
- **Contexto de Estado**: Mantém dados e decisões acumuladas ao longo das etapas
- **Pontos de Verificação**: Pontos de validação entre etapas para assegurar qualidade e consistência
- **Cliente Azure OpenAI**: Acesso consistente ao modelo de IA em todas as etapas do workflow

## 💻 Executar o Código

A implementação completa está disponível em `02.dotnet-agent-framework-workflow-ghmodel-sequential.cs`. Este ficheiro demonstra um **workflow de análise de móveis em três etapas**:

1. **Etapa 1 - Agente de Vendas**: Analisa imagens de móveis e fornece sugestões de compra
2. **Etapa 2 - Agente de Preço**: Fornece detalhamentos de preços e opções de orçamento
3. **Etapa 3 - Agente de Orçamento**: Gera um documento profissional de orçamento em formato Markdown

### 🏗️ **Arquitetura do Workflow**

```
Image Input → Sales Analysis → Price Estimation → Quote Generation → Final Output
```

Cada agente:
- Recebe a saída da etapa anterior como contexto
- Baseia-se na análise anterior com especialização dedicada
- Mantém a continuidade do workflow através de gestão de estado

O workflow irá:

### 🔍 Compreendendo o Fluxo de Estado

Cada agente na sequência recebe:
- **Entrada Original**: A mensagem inicial do utilizador (imagem + texto)
- **Saídas dos Agentes Anteriores**: Todas as respostas dos agentes anteriores no histórico da conversa
- **Contexto Acumulado**: Estado completo mantido ao longo do workflow

Isto permite um processamento multi-etapas sofisticado onde cada agente baseia-se num contexto abrangente de todas as etapas anteriores.
