# Contribuir

Este projeto aceita contribuições e sugestões. A maioria das contribuições requer que concorde com um Acordo de Licença de Contribuidor (CLA) declarando que tem o direito e realmente nos concede os direitos de usar a sua contribuição. Para mais detalhes, visite <https://cla.opensource.microsoft.com>.

Quando submeter um pull request, um bot CLA determinará automaticamente se precisa fornecer um CLA e irá decorar o pull request conforme apropriado. Siga as instruções fornecidas pelo bot. Só terá de fazer isto uma vez em todos os repositórios que usam o CLA da Microsoft.

## Código de Conduta

Este projeto adotou o [Código de Conduta de Código Aberto da Microsoft](https://opensource.microsoft.com/codeofconduct/). Para mais informações, consulte as [FAQ do Código de Conduta](https://opensource.microsoft.com/codeofconduct/faq/) ou contacte [opencode@microsoft.com](mailto:opencode@microsoft.com) para perguntas ou comentários adicionais.

## Diretrizes para pull requests

- Mantenha cada pull request focado numa única alteração lógica.
- Teste os notebooks e exemplos de código afetados antes de submeter.
- Atualize a documentação relevante da lição ao adicionar ou alterar um exemplo.
- Edite apenas o conteúdo fonte em inglês. As traduções são mantidas pelo fluxo de trabalho automático de tradução.
- Não confirme credenciais, ficheiros `.env`, ficheiros temporários ou artefactos de desenvolvimento gerados.

## Âmbito editorial e produtos de terceiros

Este currículo foca-se em tecnologias Microsoft e standards abertos neutros relativamente aos fornecedores. As contribuições devem servir um propósito educacional claro e não devem ter como principal objetivo introduzir ou promover um produto comercial de terceiros, serviço alojado, router modelo, SDK, servidor MCP ou outra oferta específica de um fornecedor.

Software de código aberto e dependências de terceiros podem ser referenciados quando são necessários para explicar um standard aberto ou um cenário de interoperabilidade, são apresentados de forma neutra e não estão centrados num produto de um fornecedor ou num ponto final alojado. Se a sua contribuição proposta incluir um produto ou serviço específico de um fornecedor, abra uma issue e obtenha aprovação do mantenedor antes de submeter um pull request.

Os contribuintes devem divulgar qualquer relação relevante de emprego, propriedade, patrocínio ou outra afiliação com um produto ou serviço referenciado na sua contribuição. Não inclua reivindicações não suportadas sobre preços, desempenho, segurança, privacidade ou comparativos. Exemplos executáveis não devem transmitir dados dos aprendizes nem realizar ações públicas através de um serviço externo de terceiros por defeito.
