## 🌱 Başlarken

Bu kurs, Yapay Zeka Ajanları oluşturmanın temellerini içeren derslere sahiptir. Her ders kendi konusunu kapsar, istediğiniz yerden başlayabilirsiniz!

Bu kurs için çok dilli destek vardır. Mevcut dilleri incelemek için buraya gidin: [burada](#-multi-language-support).

Eğer GenAI modelleri ile ilk kez çalışıyorsanız, 21 dersten oluşan [Yeni Başlayanlar için Üretken Yapay Zeka](https://aka.ms/genai-beginners) kursumuza göz atın.

Kodu çalıştırmak için bu depoyu [yıldızlamayı (🌟)](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst) ve [çatallamayı](https://github.com/microsoft/ai-agents-for-beginners/fork) unutmayın.

### Diğer Öğrenenlerle Tanışın, Sorularınızı Yanıtlayın

Yapay Zeka Ajanları oluştururken takılırsanız ya da sorularınız olursa, [Microsoft Foundry Discord](https://aka.ms/ai-agents/discord) içindeki özel Discord Kanalımıza katılın.

### Gerekli Olanlar

Bu kurstaki her derste kod örnekleri bulunur; bunlara code_samples klasöründen ulaşabilirsiniz. Kendi kopyanızı oluşturmak için bu depoyu [çatallayabilirsiniz](https://github.com/microsoft/ai-agents-for-beginners/fork).

Bu alıştırmalardaki kod örnekleri Microsoft Foundry Agent Service V2 ile Microsoft Agent Framework kullanmaktadır:

- [Microsoft Foundry](https://aka.ms/ai-agents-beginners/ai-foundry) - Azure Hesabı Gereklidir

Bu kurs, Microsoft'tan aşağıdaki Yapay Zeka Ajanı çerçeveleri ve servislerini kullanır:

- [Microsoft Agent Framework (MAF)](https://learn.microsoft.com/agent-framework/overview/)
- [Microsoft Foundry Agent Service V2](https://aka.ms/ai-agents-beginners/ai-agent-service)

Bazı kod örnekleri ayrıca, büyük bağlam modelleri (204K tokene kadar) sunan [MiniMax](https://platform.minimaxi.com/) gibi alternatif OpenAI uyumlu sağlayıcıları destekler. Yapılandırma ayrıntıları için [Kurs Kurulumu](./00-course-setup/README.md) bakınız.

Bu kurs için kod çalıştırma hakkında daha fazla bilgi için, [Kurs Kurulumu](./00-course-setup/README.md) kısmına gidin.
