# ⚡ Azure OpenAI (Responses API) ile Eşzamanlı Ajan İş Akışları (.NET)

## 📋 Yüksek Performanslı Paralel İşleme Eğitimi

Bu not defteri, Microsoft Agent Framework for .NET ve Azure OpenAI (Responses API) kullanarak **eşzamanlı iş akışı desenlerini** göstermektedir. Birden çok AI ajanını aynı anda çalıştırarak verimliliği maksimize eden, koordine ve veri tutarlılığını koruyan yüksek performanslı, paralel işleme iş akışlarının nasıl oluşturulacağını öğreneceksiniz.

- **Azure OpenAI (Responses API)**: Azure OpenAI Responses API'ye birden fazla eşzamanlı çağrıyı koordine etme

## 💻 Kodu Çalıştırma

Tam uygulama `03.dotnet-agent-framework-workflow-ghmodel-concurrent.cs` dosyasında mevcuttur. Bu dosya, seyahat planlaması için **Fan-Out/Fan-In eşzamanlı iş akışını** gösterir:

### 🏗️ **İş Akışı Mimarisi**

```
User Request → ConcurrentStartExecutor → [Researcher Agent || Planner Agent] → ConcurrentAggregationExecutor → Final Output
```

**Ana Bileşenler:**

1. **ConcurrentStartExecutor**: Kullanıcı isteğini tüm ajanlara aynı anda yayınlar
2. **Researcher Agent**: Gidilecek yerler ve cazibe merkezlerini eşzamanlı olarak analiz eder
3. **Planner Agent**: Detaylı seyahat planlarını eşzamanlı oluşturur
4. **ConcurrentAggregationExecutor**: Her iki ajan sonuçlarını toplar ve birleştirir

### 🎯 **Fan-Out/Fan-In Deseni**

Bu iş akışı klasik **Fan-Out/Fan-In** desenini gösterir:
- **Fan-Out**: Tek bir giriş mesajı, birden çok ajana aynı anda yayınlanır
- **Eşzamanlı İşleme**: Birden çok ajan aynı görev üzerinde paralel çalışır
- **Fan-In**: Tüm ajanlardan gelen sonuçlar toplanır ve tek bir çıktı halinde birleştirilir

### 🔍 Özel Executor'ları Anlamak

**ConcurrentStartExecutor:**
- `IMessageHandler<string>` arayüzünü uygular ve string giriş kabul eder
- Tüm bağlı ajanlara mesaj yayınlar
- Eşzamanlı işlemi tetiklemek için `TurnToken` gönderir

**ConcurrentAggregationExecutor:**
- `IMessageHandler<ChatMessage>` arayüzünü uygular ve ajan cevaplarını alır
- Mesajları iş parçacığı güvenli şekilde toplar
- Tüm beklenen yanıtlar geldiğinde toplar
- Son çıktıyı `context.YieldOutputAsync()` kullanarak verir

### ⚡ Performans Yararları

**Eşzamanlı vs Ardışık:**
- Ardışık: Agent1 (30s) → Agent2 (30s) = **Toplam 60 saniye**
- Eşzamanlı: Agent1 (30s) || Agent2 (30s) = **Toplam 30 saniye**

**Verimlilik artışı**: N adet eşzamanlı ajan için N× daha hızlı (iş yükü ve kaynaklara bağlı)

### 🛡️ Hata Yönetimi

İş akışı bireysel ajan hatalarını zarifçe ele alır:
- Bir ajan başarısız olursa, diğerleri işlemeye devam eder
- Toplayıcı zaman aşımı mantığı uygulayabilir
- Gerekirse kısmi sonuçlar döndürülebilir
