# ⚡ Azure OpenAI ile Eşzamanlı Ajan İş Akışları (Yanıtlar API'si) (.NET)

## 📋 Yüksek Performanslı Paralel İşleme Eğitimi

Bu not defteri, Microsoft Agent Framework for .NET ve Azure OpenAI (Yanıtlar API'si) kullanarak **eşzamanlı iş akışı desenlerini** gösterir. Birden fazla AI ajanını aynı anda çalıştırarak maksimal verimi sağlayan, koordinasyonu ve veri tutarlılığını koruyan yüksek performanslı, paralel işleme iş akışları oluşturmayı öğreneceksiniz.

## 🎯 Öğrenme Hedefleri

### 🚀 **Eşzamanlı İşleme Temelleri**
- **Paralel Ajan Çalıştırma**: Maksimum performans için birden çok AI ajanını aynı anda çalıştırma
- **Async/Await Desenleri**: Verimli eşzamanlılık için .NET'in async programlama modelini kullanma
- **Azure OpenAI (Yanıtlar API'si)**: Azure OpenAI Yanıtlar API'sine birden çok eşzamanlı çağrıyı koordine etme
- **Kaynak Yönetimi**: Eşzamanlı işlemler boyunca AI model kaynaklarını verimli yönetme

### 🏗️ **İleri Düzey Eşzamanlılık Mimarisı**
- **Görev Tabanlı Paralelizm**: Optimum eşzamanlı yürütme için .NET Görev Paralel Kitaplığı'nı kullanma
- **Senkronizasyon Desenleri**: Yarış durumlarından kaçınarak eşzamanlı ajanları koordine etme
- **Yük Dengeleme**: Mevcut eşzamanlı işleme kapasitesi arasında işi verimli şekilde dağıtma
- **Hata Toleransı**: Tüm iş akışını durdurmadan bireysel ajan hatalarını ele alma

### 🏢 **Kurumsal Eşzamanlı Uygulamalar**
- **Yüksek Hacimli Belge İşleme**: Birden çok belgeyi aynı anda işleme

## 💻 Kodu Çalıştırma

Tam uygulama `03.dotnet-agent-framework-workflow-ghmodel-concurrent.cs` dosyasında mevcuttur. Bu dosya seyahat planlaması için **Fan-Out/Fan-In eşzamanlı iş akışını** gösterir:

### 🏗️ **İş Akışı Mimarisi**

```
User Request → ConcurrentStartExecutor → [Researcher Agent || Planner Agent] → ConcurrentAggregationExecutor → Final Output
```

**Ana Bileşenler:**

1. **ConcurrentStartExecutor**: Kullanıcı isteğini tüm ajanlara aynı anda yayınlar
2. **Researcher Ajanı**: Hedef yerleri ve atraksiyonları eşzamanlı analiz eder
3. **Planner Ajanı**: Ayrıntılı seyahat planlarını eşzamanlı oluşturur
4. **ConcurrentAggregationExecutor**: Her iki ajan sonuçlarını toplar ve birleştirir

### 🎯 **Fan-Out/Fan-In Deseni**

Bu iş akışı klasik **Fan-Out/Fan-In** desenini göstermektedir:
- **Fan-Out**: Tek giriş mesajı birden çok ajana aynı anda yayınlanır
- **Eşzamanlı İşleme**: Birden fazla ajan aynı görevi paralel yapar
- **Fan-In**: Tüm ajan sonuçları toplanıp tek bir çıktı halinde birleştirilir

### 🔍 Özel Yürütücülerini Anlama

**ConcurrentStartExecutor:**
- `IMessageHandler<string>` arayüzünü uygular, string girdiyi kabul eder
- Tüm bağlı ajanlara mesajları yayınlar
- Eşzamanlı işlemi tetiklemek için `TurnToken` gönderir

**ConcurrentAggregationExecutor:**
- `IMessageHandler<ChatMessage>` arayüzünü uygular, ajan yanıtlarını alır
- Mesajları iş parçacığı güvenli şekilde toplar
- Tüm beklenen yanıtlar geldiğinde birleştirir
- Son çıktıyı `context.YieldOutputAsync()` kullanarak verir

### ⚡ Performans Avantajları

**Eşzamanlı ile Sıralı Karşılaştırması:**
- Sıralı: Ajan1 (30s) → Ajan2 (30s) = **Toplam 60 saniye**
- Eşzamanlı: Ajan1 (30s) || Ajan2 (30s) = **Toplam 30 saniye**

**Verimlilik artışı**: N eşzamanlı ajan için N katına kadar hızlanma (iş yükü ve kaynaklara bağlı)
