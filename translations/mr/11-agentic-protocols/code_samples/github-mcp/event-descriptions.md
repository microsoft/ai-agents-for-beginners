## कार्यक्रमाचे नाव: LangGraph आणि Azure Cosmos DB सह मल्टी-एजंट API

तपशीलवार कोड वॉकथ्रूच्या माध्यमातून, आपण एजंट-चालित वर्कफ्लो कसे डिझाइन आणि अंमलात आणायचा ते पाहणार आहोत ज्यामध्ये retrieval-augmented generation (RAG), मेमरी सुसंगती, आणि डायनॅमिक स्टेट ट्रान्झिशन्स सहजपणे एकत्र केलेले आहे. आपण यावर चर्चा करू:

LangGraph सह एजंट सहकार्य संरचित विचारसरणीसाठी
Azure Cosmos DB वापरून रिअल-टाइम चॅट इतिहास संग्रहण — हा तोच डेटाबेस आहे जो ChatGPT च्या चॅट इतिहासाला चालना देतो, इतिहासातील सर्वात वेगाने वाढणारा AI एजंट अनुप्रयोग
Cosmos DB च्या मूळ एम्बेडिंग्स सपोर्टसह ज्ञान पुनर्प्राप्तीसाठी वेक्टर शोध
FastAPI ची async क्षमता संवाद प्रतिसादक्षम आणि स्केलेबल ठेवण्यासाठी
या सत्राच्या शेवटी, आपल्याकडे आधुनिक AI आणि क्लाउड पायाभूत सुविधा वापरून स्वतःचे स्केलेबल, क्लाउड-नेटिव्ह मल्टी-एजंट अनुप्रयोग तयार आणि परिनियोजित करण्याचा स्पष्ट आराखडा असेल. आपण AI इंजिनीअर, क्लाउड आर्किटेक्ट किंवा Python विकसक असाल, ही चर्चा आपल्याला प्रॅक्टिकल अंतर्दृष्टी आणि चाचलेल्या पॅटर्नसह पुढील पिढीच्या AI-शक्तीप्राप्त अनुप्रयोग तयार करण्यासाठी सज्ज करेल.

## वर्णन

Microsoft Foundry Agent Service ही सेवा आणि SDK चा एक एकसंध संगम आहे जो मजबूत AI-चालित उपाय विकसित करणे सुलभ करतो. या सत्रात, आपण Azure आणि C# वापरून आपला स्वतःचा कोड-प्रथम AI एजंट कसा तयार करायचा हे शिकाल जो प्रश्नांची उत्तरे देऊ शकतो, डेटा विश्लेषण करू शकतो, आणि बाह्य डेटा स्रोतांना समाकलित करू शकतो. आपण अनेक एजंट एकत्र काम करत असलेले अधिक जटिल आर्किटेक्चर्स देखील पाहणार आहोत.

## URL
<https://developer.microsoft.com/en-us/reactor/events/25370/>

## कार्यक्रमाचे नाव: AI एजंट्स + Aspire

## वर्णन

या सत्रात आम्ही .NET प्लॅटफॉर्मवर एजंट्ससंबंधी काही अत्यंत रोमांचक विकास शेअर करू. .NET ची सद्यस्थिती, नवीन वैशिष्ट्ये आणि सुधारणा यांचा शोध घ्या. प्रचंड शक्तिशाली AI एजंट क्षमता एक्स्प्लोर करा. आणि आम्ही एजंट्स आणि Aspire सह थेट कोडिंग देखील करू.

## URL
<https://developer.microsoft.com/en-us/reactor/events/25332/>

## कार्यक्रमाचे नाव: Azure Cosmos द्वारे चालवलेल्या मल्टी-एजंट AI अनुप्रयोगांसाठी C# सह Semantic Kernel

## वर्णन

आम्ही आपल्याला C# मध्ये तयार केलेल्या मल्टी-एजंट अनुप्रयोगाचा मार्गदर्शन करू जो Semantic Kernel फ्रेमवर्कवर आधारित आहे. आपण एजंटिक अनुप्रयोगांची संकल्पना समजून घेणार, अंमलबजावणीची तपशीलवार माहिती आणि सूक्ष्मताः समजून घेणार, आणि विविध वापरांसाठी Azure Cosmos DB कसे डेटाबेस म्हणून एकत्र करायचे हे शिकणार आहोत.

## URL
<https://developer.microsoft.com/en-us/reactor/events/25455/>
