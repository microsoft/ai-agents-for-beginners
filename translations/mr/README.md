> cd ai-agents-for-beginners
> git sparse-checkout set --no-cone '/*' '!translations' '!translated_images'

>
> **CMD (Windows):**
> ```cmd
> git clone --filter=blob:none --sparse https://github.com/microsoft/ai-agents-for-beginners.git
> cd ai-agents-for-beginners
> git sparse-checkout set --no-cone "/*" "!translations" "!translated_images"
> ```
>
> हे तुम्हाला कोर्स पूर्ण करण्यासाठी आवश्यक सर्व काही देतो ज्यामुळे डाउनलोड खूप जलद होते.

## 🌱 सुरुवात करणे

हा कोर्स AI एजंट्स तयार करण्याच्या मूलतत्त्वांवर आधारित धडे शिकवतो. प्रत्येक धडा त्याच्या स्वतःच्या विषयावर आधारित आहे त्यामुळे तुमच्या आवडीनुसार कुठूनही सुरू करा!

या कोर्ससाठी बहुभाषिक समर्थन आहे. आमच्या [उपलब्ध भाषांमध्ये येथे पहा](#-multi-language-support).

जर तुम्ही GenAI मॉडेल्ससह तयार करत असाल तर आमचा [Generative AI For Beginners](https://aka.ms/genai-beginners) कोर्स पहा, ज्यात GenAI सह तयार करण्याचे २१ धडे आहेत.

या रेपॉजिटरीला [स्टार (🌟) द्या](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst) आणि [फोर्क करा](https://github.com/microsoft/ai-agents-for-beginners/fork) आणि कोड चालवा.

### इतर शिकणाऱ्यांना भेटा, तुमचे प्रश्न विचाराः

जर तुम्हाला अडचण आली किंवा AI एजंट्स तयार करण्याबाबत कोणतेही प्रश्न असतील तर आमच्या समर्पित Discord चॅनेलमध्ये सहभागी व्हा [Microsoft Foundry Discord](https://aka.ms/ai-agents/discord).

### तुम्हाला काय हवे

या कोर्समधील प्रत्येक धड्यात कोड उदाहरणे आहेत, जी code_samples फोल्डरमध्ये सापडतील. तुम्ही [ही रेपॉजिटरी फोर्क करू शकता](https://github.com/microsoft/ai-agents-for-beginners/fork) आणि तुमची स्वतःची कॉपी तयार करू शकता.

या सरावांमध्ये कोड उदाहरणांसाठी Microsoft Agent Framework सोबत Microsoft Foundry Agent Service V2 वापरले आहे:

- [Microsoft Foundry](https://aka.ms/ai-agents-beginners/ai-foundry) - Azure Account आवश्यक

या कोर्समध्ये खालील AI एजंट फ्रेमवर्क आणि सेवा Microsoft कडून वापरल्या आहेत:

- [Microsoft Agent Framework (MAF)](https://learn.microsoft.com/agent-framework/overview/)
- [Microsoft Foundry Agent Service V2](https://aka.ms/ai-agents-beginners/ai-agent-service)

काही कोड उदाहरणे पर्यायी OpenAI-सुसंगत प्रदात्यांसाठी देखील समर्थन करतात जसे की [MiniMax](https://platform.minimaxi.com/), जे मोठ्या-कॉन्टेक्स्ट मॉडेल (२04K टोकनपर्यंत) उपलब्ध करतात. कॉन्फिगरेशन तपशीलासाठी [कोर्स सेटअप](./00-course-setup/README.md) पहा.

या कोर्ससाठी कोड चालविण्यासाठी अधिक माहितीसाठी [कोर्स सेटअप](./00-course-setup/README.md) पहा.
