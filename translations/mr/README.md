## 🌱 सुरुवात कशी कराल

हा कोर्स AI एजंट्स तयार करण्याच्या मूलभूत गोष्टींचा समावेश असलेल्या धड्यांसह आहे. प्रत्येक धडा स्वतःचा विषय कव्हर करतो, त्यामुळे कुठूनही सुरुवात करा!

या कोर्सला बहुभाषिक सहाय्य आहे. आमच्या [उपलब्ध भाषांना येथे भेट द्या](#-multi-language-support). 

जर तुम्ही जनरेटिव AI मॉडेल्ससह पहिल्यांदाच काम करत असाल, तर आमचा [Generative AI For Beginners](https://aka.ms/genai-beginners) कोर्स पाहा, ज्यात GenAI सह तयार करण्यावरील 21 धडे आहेत.

[या रिपॉजिटरीला स्टार (🌟)](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst) आणि [फोर्क करा](https://github.com/microsoft/ai-agents-for-beginners/fork) ज्यामुळे कोड चालवता येईल, हे विसरू नका.

### इतर शिकणाऱ्यांना भेटा, तुमचे प्रश्न विचारा

जर तुम्हाला अडचण आली किंवा AI एजंट्स तयार करण्याबद्दल काही प्रश्न असतील, तर आमच्या समर्पित Discord चॅनेलमध्ये सामील व्हा, [Microsoft Foundry Discord](https://aka.ms/ai-agents/discord).

### तुम्हाला काय लागेल

या कोर्समधील प्रत्येक धड्यात कोड उदाहरणे समाविष्ट आहेत, जी code_samples फोल्डरमध्ये मिळतील. तुम्ही तुमची कॉपी तयार करण्यासाठी [हा रेपो फोर्क करू शकता](https://github.com/microsoft/ai-agents-for-beginners/fork).  

या व्यायामांमधील कोड नमुने Microsoft Agent Framework सोबत Microsoft Foundry Agent Service V2 वापरतात:

- [Microsoft Foundry](https://aka.ms/ai-agents-beginners/ai-foundry) - Azure खाते आवश्यक

हा कोर्स Microsoftकडून खालील AI Agent फ्रेमवर्क आणि सेवा वापरतो:

- [Microsoft Agent Framework (MAF)](https://learn.microsoft.com/agent-framework/overview/)
- [Microsoft Foundry Agent Service V2](https://aka.ms/ai-agents-beginners/ai-agent-service)

काही कोड नमुने पर्यायी OpenAI-सुसंगत प्रदाते जसे की [MiniMax](https://platform.minimaxi.com/) देखील समर्थन करतात, जे मोठ्या संदर्भ मॉडेल देतात (२०४K टोकन्सपर्यंत). कॉन्फिगरेशन तपशीलांसाठी [Course Setup](./00-course-setup/README.md) पहा.

या कोर्ससाठी कोड चालविण्याविषयी अधिक माहितीसाठी, [Course Setup](./00-course-setup/README.md) येथे जा.
