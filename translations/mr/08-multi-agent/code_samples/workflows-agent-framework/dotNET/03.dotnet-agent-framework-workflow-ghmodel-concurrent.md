# ⚡ Azure OpenAI (Responses API) सह समवर्ती एजंट वर्कफ्लोज (.NET)

## 📋 उच्च-प्रदर्शन समांतर प्रक्रिया ट्यूटोरियल

हा नोटबुक Microsoft Agent Framework for .NET आणि Azure OpenAI (Responses API) वापरून **समवर्ती वर्कफ्लो पॅटर्न** दाखवतो. तुम्हाला समवर्ती अनेक AI एजंट्स एकाच वेळी चालवून समन्वय आणि डेटा सुसंगतता राखत उच्च-प्रदर्शन, समांतर प्रक्रिया वर्कफ्लोज कसे तयार करायचे ते शिकायला मिळेल.

## 🎯 शिकण्याच्या उद्दिष्टे

### 🚀 **समवर्ती प्रक्रिया मूलतत्त्वे**
- **समांतर एजंट एक्सिक्यूशन**: अधिकाधिक कार्यक्षमतेसाठी अनेक AI एजंट्स एकाच वेळी चालवा
- **Async/Await पॅटर्न्स**: प्रभावी समवर्तीसाठी .NET चा async प्रोग्रामिंग मॉडेल वापरा
- **Azure OpenAI (Responses API)**: Azure OpenAI Responses API शी अनेक समवर्ती कॉल समन्वयित करा
- **स्रोत व्यवस्थापन**: समवर्ती ऑपरेशन्सदरम्यान AI मॉडेल स्त्रोतांची प्रभावी व्यवस्थापन करा

### 🏗️ **उन्नत समवर्ती आर्किटेक्चर**
- **टास्क-आधारित समांतरता**: उत्तम समवर्ती एक्सिक्यूशन्ससाठी .NET Task Parallel Library वापरा
- **सिंक्रोनायझेशन पॅटर्न्स**: समवर्ती एजंट्स समन्वयित करा आणि रेस कंडिशन टाळा
- **लोड बॅलन्सिंग**: उपलब्ध समवर्ती प्रक्रिया क्षमतेमध्ये कार्य प्रभावीपणे वाटा
- **फॉल्ट टॉलरन्स**: संपूर्ण वर्कफ्लो थांबवित न देता वैयक्तिक एजंट अपयश हाताळा

### 🏢 **एंटरप्राइझ समवर्ती अनुप्रयोग**
- **उच्च-आयन दस्तऐवज प्रक्रिया**: अनेक दस्तऐवज एकाच वेळी प्रक्रिया करा
- **रिअल-टाइम कंटेंट विश्लेषण**: अपेक्षित डेटा प्रवाहांचे समवर्ती विश्लेषण
- **बॅच प्रक्रिया ऑप्टिमायझेशन**: मोठ्या प्रमाणावर डेटा प्रक्रिया कार्यक्षमतेत वाढ
- **मल्टी-मोडल विश्लेषण**: वेगवेगळ्या कंटेंट प्रकार आणि फॉर्मेट्सची समांतर प्रक्रिया

## 💻 कोड चालविणे

संपूर्ण अंमलबजावणी `03.dotnet-agent-framework-workflow-ghmodel-concurrent.cs` मध्ये उपलब्ध आहे. हा फाइल प्रवास नियोजनासाठी **फॅन-आउट/फॅन-इन समवर्ती वर्कफ्लो** दाखवतो:

### 🏗️ **वर्कफ्लो आर्किटेक्चर**

```
User Request → ConcurrentStartExecutor → [Researcher Agent || Planner Agent] → ConcurrentAggregationExecutor → Final Output
```

**मुख्य घटक:**

1. **ConcurrentStartExecutor**: वापरकर्त्याची विनंती सर्व एजंट्सना एकाच वेळी प्रसारित करतो
2. **Researcher Agent**: गंतव्ये आणि आकर्षणे समवर्तीपणे विश्लेषित करतो
3. **Planner Agent**: तपशीलवार प्रवास योजना समवर्ती तयार करतो
4. **ConcurrentAggregationExecutor**: दोन्ही एजंट्सचे निकाल गोळा करून विलीन करतो

### 🎯 **फॅन-आउट/फॅन-इन पॅटर्न**

हा वर्कफ्लो क्लासिक **फॅन-आउट/फॅन-इन** पॅटर्न दाखवतो:
- **फॅन-आउट**: एक इनपुट संदेश अनेक एजंट्सना एकाच वेळी प्रसारित केला जातो
- **समवर्ती प्रक्रिया**: अनेक एजंट्स एकाच कार्यावर समांतर काम करतात
- **फॅन-इन**: सर्व एजंट्सच्या निकालांचे एकत्रीकरण आणि संक्षिप्त आउटपुट तयार केले जाते

### 📝 अपेक्षित आउटपुट

वर्कफ्लो खालीलप्रमाणे कार्य करेल:
1. **विनंती प्रसारित करा**: "डिसेंबरमध्ये सियटलला ट्रिप प्लॅन करा" हे दोन्ही एजंट्सना पाठवा
2. **समवर्ती प्रक्रिया**: दोन्ही एजंट्स एकाच वेळी काम करतात:
   - संशोधक आकर्षणे आणि तपशील ओळखतो
   - नियोजक प्रवासाची आराखडा आणि लॉजिस्टिक्स तयार करतो
3. **एकत्रीकरण**: दोन्ही प्रतिसादांना एकत्र करून सविस्तर आउटपुट तयार करा
4. **निकाल दाखवा**: सर्व माहिती असलेली विलीन प्रवास योजना दाखवा

### 🔧 सानुकूलन पर्याय

**अधिक समवर्ती एजंट जोडा:**
```csharp
// Create additional specialized agents
AIAgent budgetAgent = azureClient.GetChatClient(deployment).AsAIAgent(
    name: "Budget-Agent", instructions: "Calculate travel costs...");

// Add to fan-out
var workflow = new WorkflowBuilder(startExecutor)
    .AddFanOutEdge(startExecutor, targets: [researcherAgent, plannerAgent, budgetAgent])
    .AddFanInBarrierEdge(sources: [researcherAgent, plannerAgent, budgetAgent], target: aggregationExecutor)
    .WithOutputFrom(aggregationExecutor)
    .Build();

// Update aggregation count
if (this._messages.Count == 3) { ... }
```

### 🎯 वास्तविक जगातील अनुप्रयोग

- **कंटेंट निर्मिती**: अनेक लेखक वेगवेगळ्या विभागांवर एकाच वेळी काम करतात
- **कोड पुनरावलोकन**: वेगवेगळ्या दृष्टीकोनातून अनेक पुनरावलोकक कोड विश्लेषित करतात
- **बाजार संशोधन**: वेगवेगळ्या बाजार विभागांचे समांतर विश्लेषण
- **दस्तऐवज प्रक्रिया**: समवर्ती काढणी, विश्लेषण आणि पडताळणी
- **मल्टी-दृष्टीकोन विश्लेषण**: एकाच इनपुटवर विविध दृष्टीकोन मिळवणे

### 🔍 सानुकूल कार्यकारी समजून घेणे

**ConcurrentStartExecutor:**
- `IMessageHandler<string>` अंमलात आणते जेणेकरून स्ट्रिंग इनपुट स्वीकारू शकेल
- सर्व कनेक्टेड एजंट्सना संदेश प्रसारित करतो
- समवर्ती प्रक्रिया सुरू करण्यासाठी `TurnToken` पाठवतो

**ConcurrentAggregationExecutor:**
- एजंट प्रतिसाद स्वीकारण्यासाठी `IMessageHandler<ChatMessage>` अंमलात आणते
- संदेश थ्रेड-सुरक्षित पद्धतीने जमा करतो
- अपेक्षित सर्व प्रतिसाद आल्यावर एकत्रीकरण करतो
- `context.YieldOutputAsync()` वापरून अंतिम आउटपुट देतो

### ⚡ कार्यप्रदर्शन फायदे

**समवर्ती विरुद्ध अनुक्रमे:**
- अनुक्रमे: एजंट1 (30s) → एजंट2 (30s) = **एकूण 60 सेकंद**
- समवर्ती: एजंट1 (30s) || एजंट2 (30s) = **एकूण 30 सेकंद**

**थ्रूपुट सुधारणा**: N समवर्ती एजंट्ससाठी N× पर्यंत जलद (कार्यक्षमता आणि स्रोतांवर अवलंबून)
