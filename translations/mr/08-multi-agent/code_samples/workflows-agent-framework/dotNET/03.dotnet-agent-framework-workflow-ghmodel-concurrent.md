# ⚡ Azure OpenAI सह एकाच वेळी एजंट वर्कफ़्लोज (Responses API) (.NET)

## 📋 उच्च कार्यक्षमता समांतर प्रक्रिया ट्यूटोरियल

हा नोटबुक Microsoft Agent Framework for .NET आणि Azure OpenAI (Responses API) वापरून **एकाच वेळी वर्कफ़्लो नमुने** दाखवतो. आपण हे शिकाल की, कशाप्रकारे अनेक AI एजंट्स एकाच वेळी चालवून, समन्वय आणि डेटा सुसंगतता राखून, अधिकाधिक थ्रूपुटसह उच्च कार्यक्षमतेचे, समांतर प्रक्रिया वर्कफ़्लोज तयार करता येतात.

## 🎯 शिकण्याच्या उद्दिष्टे

### 🚀 **समांतर प्रक्रियेच्या मूलभूत तत्त्वे**
- **समांतर एजंट अंमलबजावणी**: जास्तीत जास्त कार्यक्षमतेसाठी अनेक AI एजंट्स एकाच वेळी चालवा
- **Async/Await नमुने**: कार्यक्षम समसामयिकतेसाठी .NET च्या async प्रोग्रामिंग मॉडेलचा उपयोग करा
- **Azure OpenAI (Responses API)**: Azure OpenAI Responses API ला अनेक समांतर कॉल समन्वयित करा
- **संसाधन व्यवस्थापन**: समांतर ऑपरेशन्स दरम्यान AI मॉडेल संसाधने कार्यक्षमरीत्या सांभाळा

### 🏗️ **उन्नत समसामयिक आर्किटेक्चर**
- **टास्क-आधारित समांतरता**: सर्वोत्तम समांतर अंमलबजावणीसाठी .NET Task Parallel Library वापरा
- **समन्वय नमुने**: स्पर्धा परिस्थिती टाळून समांतर एजंट्स समन्वयित करा
- **लोड बॅलन्सिंग**: उपलब्ध समांतर प्रक्रिया क्षमतेवर काम कार्यक्षमपणे वितरित करा
- **दोष सहिष्णुता**: संपूर्ण वर्कफ़्लो थांबविण्याशिवाय वैयक्तिक एजंट चुका हाताळा

### 🏢 **एंटरप्राइज समांतर अनुप्रयोग**
- **उच्च-आकार दस्तऐवज प्रक्रिया**: एकाच वेळी अनेक दस्तऐवज प्रक्रिया करा
- **रिअल-टाइम सामग्री विश्लेषण**: येणाऱ्या डेटा प्रवाहांचे समांतर विश्लेषण
- **बॅच प्रक्रिया अनुकूलन**: मोठ्या प्रमाणावर डेटा प्रक्रियांमधील थ्रूपुट वाढवा
- **मल्टी-मोडल विश्लेषण**: विविध प्रकार सामग्री आणि स्वरूपांच्या समांतर प्रक्रिया

```

```

```

```

```
Single Input → Multiple Concurrent Processors → Result Aggregation → Single Output
```

## 💻 कोड चालविणे

संपूर्ण अंमलबजावणी `03.dotnet-agent-framework-workflow-ghmodel-concurrent.cs` फाइलमध्ये उपलब्ध आहे. ही फाइल ट्रॅव्हल प्लॅनिंगसाठी **फॅन-आउट/फॅन-इन समांतर वर्कफ़्लो** दाखवते:

### 🏗️ **वर्कफ़्लो आर्किटेक्चर**

```
User Request → ConcurrentStartExecutor → [Researcher Agent || Planner Agent] → ConcurrentAggregationExecutor → Final Output
```

**महत्त्वाचे घटक:**

१. **ConcurrentStartExecutor**: वापरकर्त्याच्या विनंतीला सर्व एजंट्सना एकाच वेळी प्रसारित करतो
२. **Researcher Agent**: एकाच वेळी गंतव्य व आकर्षणे विश्लेषित करतो
३. **Planner Agent**: समांतर प्रवास योजना तयार करतो
४. **ConcurrentAggregationExecutor**: दोन्ही एजंटच्या उत्तरांना जमा आणि एकत्र करतो

### 🎯 **फॅन-आउट/फॅन-इन नमुना**

हा वर्कफ़्लो क्लासिक **फॅन-आउट/फॅन-इन** नमुना दर्शवतो:
- **फॅन-आउट**: एक इनपुट संदेश अनेक एजंट्सना एकाच वेळी प्रसारित केला जातो
- **समांतर प्रक्रिया**: अनेक एजंट्स एकाच कामावर समांतर कार्य करतात
- **फॅन-इन**: सर्व एजंट परिणाम एका एकत्रित आउटपुटमध्ये जमा होतात

### 🔧 सानुकूलन पर्याय

**अधिक समांतर एजंट जोडा:**
```csharp
// Create additional specialized agents
AIAgent budgetAgent = azureClient.GetChatClient(deployment).AsAIAgent(
    name: "Budget-Agent", instructions: "Calculate travel costs...");

// Add to fan-out
var workflow = new WorkflowBuilder(startExecutor)
    .AddFanOutEdge(startExecutor, targets: [researcherAgent, plannerAgent, budgetAgent])
    .AddFanInBarrierEdge(sources: [researcherAgent, plannerAgent, budgetAgent], aggregationExecutor)
    .WithOutputFrom(aggregationExecutor)
    .Build();

// Update aggregation count
if (this._messages.Count == 3) { ... }
```

- **मल्टी-दृष्टीकोन विश्लेषण**: समान इनपुटवर विविध दृष्टीकोन मिळवणे

### 🔍 कस्टम एक्झिक्युटर्स समजून घेणे

**ConcurrentStartExecutor:**
- `IMessageHandler<string>` अंमलात येवून स्ट्रिंग इनपुट स्वीकारतो
- सर्व कनेक्टेड एजंट्सना संदेश प्रसारित करतो
- समांतर प्रक्रिया चालू करण्यासाठी `TurnToken` पाठवतो

**ConcurrentAggregationExecutor:**
- `IMessageHandler<ChatMessage>` अंमलात येवून एजंट प्रतिक्रियांची स्वीकृती करतो
- संदेश थ्रेड-सुरक्षित पद्धतीने एकत्र करतो
- अपेक्षित सर्व प्रतिसाद आले की एकत्रित करतो
- `context.YieldOutputAsync()` वापरून अंतिम आउटपुट देते

### ⚡ कार्यक्षमता फायदे

**समांतर व साखळी:**
- साखळी: Agent1 (30s) → Agent2 (30s) = **एकूण 60 सेकंद**
- समांतर: Agent1 (30s) || Agent2 (30s) = **एकूण 30 सेकंद**

**थ्रूपुट सुधारणा**: N समांतर एजंटसाठी N× कार्यक्षमता वाढ (कामाच्या भार व संसाधनांवर अवलंबून)
