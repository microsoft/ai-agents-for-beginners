## نام رویداد: API چندعاملی با LangGraph و Azure Cosmos DB

## توضیحات

ظهور برنامه‌های هوش مصنوعی چندعاملی در حال تحولی است که چگونه سیستم‌های هوشمند ساخته می‌شوند - اما چگونه آنها را برای مقیاس‌پذیری و عملکرد دنیای واقعی طراحی می‌کنید؟ در این جلسه، به بررسی عمیق برنامه‌های چندعاملی سطح تولید ساخته شده با LangGraph برای هماهنگی عوامل، FastAPI برای لایه API و Azure Cosmos DB به عنوان ستون فقرات مدیریت وضعیت، ذخیره برداری و داده‌های تراکنشی می‌پردازیم.

از طریق مرور دقیق کد، خواهید دید چگونه یک گردش کار هدایت شده توسط عامل طراحی و پیاده‌سازی می‌شود که به‌صورت یکپارچه تولید افزایش‌یافته بازیابی (RAG)، ماندگاری حافظه و انتقالات پویا وضعیت را ادغام می‌کند. مباحث این جلسه شامل:

همکاری عامل‌ها با LangGraph برای استدلال ساختاریافته
ذخیره تاریخچه چت در زمان واقعی با استفاده از Azure Cosmos DB - همان پایگاه داده‌ای که تاریخچه چت در ChatGPT، سریع‌ترین برنامه عامل هوش مصنوعی رشد یافته در تاریخ را پشتیبانی می‌کند
جستجوی برداری برای بازیابی دانش با پشتیبانی بومی جاسازی‌های Cosmos DB
قابلیت‌های ناهم‌زمان FastAPI برای حفظ پاسخگویی و مقیاس‌پذیری تعاملات
در پایان این جلسه، یک نقشه راه واضح برای ساخت و استقرار برنامه‌های چندعاملی مقیاس‌پذیر و بومی ابر که از قدرت هوش مصنوعی مدرن و زیرساخت ابری بهره می‌برد، در اختیار خواهید داشت. چه مهندس هوش مصنوعی باشید، چه معمار ابر یا توسعه‌دهنده پایتون، این صحبت شما را با بینش‌های عملی و الگوهای آزموده‌شده برای ساخت نسل بعدی برنامه‌های مجهز به هوش مصنوعی مجهز می‌کند.
