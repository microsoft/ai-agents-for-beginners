# آزمون‌های دودآزمایی عامل

این پوشه شامل **فهرست‌های دودآزمایی** برای عامل‌هایی است که در دوره می‌سازید.
دودآزمایی، یک چک ارزان و سریع است که بررسی می‌کند آیا یک **عامل مستقر شده در میزبانی Microsoft Foundry**
قابل دسترس، پاسخگو و مطابق با ابتدایی‌ترین انتظارهای درخواستش است یا خیر.
این یک دروازهٔ اول است — نه جایگزینی برای خط لولهٔ کامل ارزیابی که در [درس ۱۰](../10-ai-agents-production/README.md) و
[درس ۱۶](../16-deploying-scalable-agents/README.md) می‌آموزید.


این فهرست‌ها توسط [عملیات دودآزمای AI](https://github.com/marketplace/actions/ai-smoke-test) در GitHub
از طریق جریان کاری [`.github/workflows/smoke-test.yml`](../../../.github/workflows/smoke-test.yml) مصرف می‌شوند.


## نحوه اجرا

۱. **عامل درس را** به عنوان یک عامل میزبانی شده در Microsoft Foundry مستقر کنید (جریان استقرار در درس ۱۶).
   نام **عامل** و نقطه انتهایی پروژه **Foundry** خود را یادداشت کنید.
۲. این اسرار مخزن را اضافه کنید (تنظیمات → اسرار و متغیرها → عملیات): `AZURE_CLIENT_ID`، `AZURE_TENANT_ID`، `AZURE_SUBSCRIPTION_ID`.
   شناسهٔ فدرال به نقش **کاربر Azure AI** در **حوزه پروژه Foundry** نیاز دارد.
۳. از برگهٔ **عملیات**، عملیات **آزمون دود برای عوامل میزبانی شده** را اجرا کنید و `tests_file` مناسب برای درس را انتخاب کنید،
   سپس `agent_name` و `project_endpoint` متناظر را وارد کنید.

را می‌توان با محتوای شناخته‌شده مطابقت داد. درس‌های نظری، فقط اجرا روی محلی،
یا تولید خروجی خلاق غیردترمینیستی عمداً مستثنا شده‌اند:


- **درس ۱۷ (ساخت عامل‌های هوش مصنوعی محلی)** کاملاً روی ایستگاه کاری شما با
  Foundry Local اجرا می‌شود و هیچ نقطهٔ پایانی Foundry Responses ارائه نمی‌دهد؛ بنابراین این
  عملیات برای آن کاربرد ندارد. آن را با اجرای محلی دفترچهٔ یادداشت اعتبارسنجی کنید.
- درس‌های الگوی طراحی و نظری (۰۲، ۰۳، ۰۶، ۰۷، ۰۹، ۱۲) حتی یک عامل مستقرشدنی برای دودآزمایی ارائه نمی‌دهند.


## ساختار فهرست (مرجع سریع)

هر فهرست یک سند JSON با آرایه‌ای در سطح بالا به نام `tests` است. هر ورودی یک درخواست ارسال می‌کند و پاسخ را اعتبارسنجی می‌کند:

| فیلد | معنی |
|-------|---------|

| فیلد | معنی |
|-------|---------|
| `id` | شناسه منحصر به فرد مرحله که در لاگ چاپ می‌شود. |
| `description` | هدف قابل فهم برای انسان. |
| `prompt` | پیامی که به عامل ارسال می‌شود. |
| `assertions.status` | وضعیت HTTP مورد انتظار (پیش‌فرض ۲۰۰). |
| `assertions.contains_any` | موفق اگر پاسخ شامل هر یک از این زیررشته‌ها باشد. |
| `assertions.contains_all` | موفق اگر پاسخ شامل همه زیررشته‌ها باشد. |
| `assertions.contains_none` | موفق اگر پاسخ هیچ‌کدام از این زیررشته‌ها را نداشته باشد. |
| `save_response_id_as` | ذخیره شناسه پاسخ برای مرحله چندگانه بعدی. |
| `use_previous_response_id` | ارسال این نوبت به صورت زنجیره‌ای به شناسه پاسخ ذخیره شده. |

Assertions بررسی‌های زیررشته‌ای بدون حساسیت به حروف هستند. به سند
[مستندات عملکرد](https://github.com/marketplace/actions/ai-smoke-test) برای
طرح کامل، شامل منابع گفتگوی مدیریت‌شده توسط Foundry مراجعه کنید.
