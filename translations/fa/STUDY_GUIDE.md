# عوامل هوش مصنوعی برای مبتدیان - راهنمای مطالعه

از این راهنما به‌عنوان همراه عملی در طول دوره استفاده کنید. این راهنما
جایگزین درس‌ها نیست. این به شما کمک می‌کند تصمیم بگیرید از کجا شروع کنید، چه چیزی را
در هر درس جستجو کنید و چگونه ایده‌ها را در یک دموی عامل کوچک و عملی به هم مرتبط کنید.


اگر اولین بار است که اینجا هستید، ساده شروع کنید:

1. [راه‌اندازی دوره](./00-course-setup/README.md) را بخوانید.
2. درس‌های ۰۱ تا ۰۶ را به ترتیب کامل کنید.
3. هنگام یادگیری یک ایده کوچک دمو را در ذهن نگه دارید.
4. پس از هر درس بپرسید: «عامل من اکنون چه کاری می‌تواند انجام دهد که قبلاً نمی‌توانست؟»


## یک دمو ساده برای به یاد داشتن

یک روش خوب برای یادگیری عوامل دنبال کردن یک ایده دمو در کل دوره است.

نمونه دمو: **یک عامل کمک‌کننده دوره**.

کاربر می‌پرسد:

> «می‌خواهم یاد بگیرم چگونه عوامل از ابزارها استفاده می‌کنند. درس‌های مناسب را پیدا کن، خلاصه‌ای از آنچه
> باید ابتدا بخوانم بده و یک تمرین کوتاه برایم فراهم کن.»

یک چت‌بات معمولی می‌تواند بر اساس آنچه می‌داند پاسخ دهد. یک عامل می‌تواند بیشتر از این انجام دهد:

1. **خواندن یا جستجوی فایل‌های دوره** برای یافتن درس‌های مناسب.
2. **استفاده از ابزارها** برای دریافت لینک‌های درس، مثال‌ها یا مطالب پشتیبان.
3. **برنامه‌ریزی** یک مسیر یادگیری کوتاه به‌جای ارائه یک پاسخ طولانی.
4. **استفاده از زمینه** مکالمه فعلی برای متمرکز ماندن بر هدف یادگیرنده.

5. **به یاد سپردن ترجیحات مفید** در صورت پشتیبانی برنامه از حافظه.
6. **نمایش ردگیری‌ها، استنادات یا گزارش‌ها** تا کاربر بفهمد چه اتفاقی افتاده است.
7. **اعمال محدودیت‌ها** قبل از انجام اقدامات پرخطر یا استفاده از داده‌های حساس.

هنگام مطالعه هر درس، به این دمو بازگردید و بپرسید: این درس چه قابلیت جدیدی اضافه می‌کند؟

## مدل‌ها و ارائه‌دهندگان

نمونه‌های کد دوره از **چارچوب عامل مایکروسافت (MAF)** استفاده می‌کنند و هدف API پاسخ‌های Azure OpenAI است — API پیشنهادی آینده که ترکیب کامپلیشن‌های چت، فراخوانی ابزار، ورودی چند‌مدلی و مکالمات حالت‌دار را در یک سطح API ارائه می‌دهد. شما از طریق یک پروژه **Microsoft Foundry** (با `FoundryChatClient`) یا مستقیم به Azure OpenAI (با `OpenAIChatClient`) متصل می‌شوید.

همان‌طور که درس‌ها را پیش می‌برید، چند گزینه ارائه‌دهنده دارید:

- **Microsoft Foundry / Azure OpenAI (Responses API)** — مسیر اصلی که در سراسر درس‌ها استفاده می‌شود. با `az login` برای احراز هویت بدون کلید Entra ID وارد شوید.
- **Foundry Local** — مدل‌ها را به‌طور کامل روی دستگاه از طریق API سازگار با OpenAI اجرا کنید (بدون ابر، بدون کلید API). ایده‌آل برای آزمایش آفلاین یا رایگان. به [Course Setup](./00-course-setup/README.md) مراجعه کنید.
- **MiniMax** — یک ارائه‌دهنده سازگار با OpenAI با مدل‌های با زمینه بزرگ که می‌توان به‌عنوان جایگزین استفاده کرد.

> **توجه:** GitHub Models منسوخ شده است (تا جولای ۲۰۲۶ بازنشسته می‌شود) و از Responses API پشتیبانی نمی‌کند. نمونه‌ها به استفاده از Azure OpenAI / Microsoft Foundry به‌روزرسانی شده‌اند.

## ایده‌های کلیدی به زبان ساده برای مبتدیان

### ابزارها

ابزار چیزی است که عامل می‌تواند آن را برای انجام کاری خارج از مدل فراخوانی کند. یک ابزار خوب
نام واضح، کاری محدود، ورودی‌های تایپ شده، خروجی قابل پیش‌بینی و راهی امن برای
شکست خوردن دارد.

برای دموی کمک‌یار دوره، یک ابزار ممکن است:

- `search_lessons(query)`
- `read_lesson(path)`
- `create_practice_task(topic)`

### RAG و دانش

RAG به عامل کمک می‌کند که از منبع اصلی به جای حدس زدن پاسخ دهد. در این
دوره، آن منبع اصلی می‌تواند README های درس‌ها، نمونه‌های کد یا منابع خارجی
لینک شده از درس‌ها باشد.

زمانی از RAG استفاده کنید که پاسخ باید بر اساس اسناد، داده‌ها یا فایل‌های پروژه جاری
باشد.

### برنامه‌ریزی

برنامه‌ریزی وقتی مفید است که درخواست بیش از یک مرحله داشته باشد. برنامه‌ها را کوتاه و
به اندازه کافی مشهود نگه دارید تا توسعه‌دهنده یا کاربر بتواند آن‌ها را بررسی کند.

برای دمو، یک برنامه ممکن است:

1. درس‌های مرتبط با استفاده از ابزار را پیدا کند.
2. خلاصه‌ای از مرتبط‌ترین درس‌ها ارائه دهد.
3. یک تمرین پیشنهادی توصیه کند.

### زمینه (Context)

زمینه همان چیزی است که مدل در حال حاضر می‌بیند. زمینه خیلی کم می‌تواند باعث شود عامل
جزئیات مهم را از دست بدهد. زمینه خیلی زیاد ممکن است عامل را کندتر، پرهزینه‌تر
یا آسان‌تر به اشتباه بیندازد.

مهندسی خوب زمینه به معنای انتخاب اطلاعات مناسب برای فراخوانی مدل بعدی است.

6. چه زمانی عامل باید برای تأیید انسانی سوال کند؟
7. چه لاگ‌ها، ردپاها یا رسیدهایی به شما کمک می‌کنند عامل را بعداً اشکال‌زدایی یا حسابرسی کنید؟

- خلاصه کند که ابتدا چه چیزی باید خوانده شود.
- یک تمرین عملی پیشنهاد دهد.
- نشان دهد کدام فایل‌ها یا لینک‌های درس استفاده شده است.
