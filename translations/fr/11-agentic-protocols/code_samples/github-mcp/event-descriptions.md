## Nom de l'événement : API multi-agent avec LangGraph et Azure Cosmos DB

## Description

L’essor des applications IA multi-agent transforme la manière dont nous concevons des systèmes intelligents — mais comment les architecturer pour une évolutivité et performativité réelles ? Dans cette session, nous plongerons dans une application multi-agent de niveau production construite avec LangGraph pour l’orchestration des agents, FastAPI pour la couche API, et Azure Cosmos DB comme base pour la gestion d’état, le stockage vectoriel et les données transactionnelles.

À travers un décryptage détaillé du code, vous verrez comment concevoir et implémenter un flux de travail piloté par agent intégrant harmonieusement la génération augmentée par récupération (RAG), la persistance mémoire, et les transitions dynamiques d’état. Nous aborderons :

Collaboration des agents avec LangGraph pour un raisonnement structuré
Stockage en temps réel de l’historique des discussions avec Azure Cosmos DB — la même base de données qui alimente l’historique de ChatGPT, l’application agent IA à la croissance la plus rapide de l’histoire
Recherche vectorielle pour la récupération de connaissances avec le support natif d'embeddings de Cosmos DB
Capacités asynchrones de FastAPI pour maintenir des interactions réactives et évolutives
À la fin de cette session, vous disposerez d’un plan clair pour construire et déployer vos propres applications multi-agent évolutives, natives cloud, tirant parti de la puissance de l’IA moderne et des infrastructures cloud. Que vous soyez ingénieur IA, architecte cloud ou développeur Python, cette présentation vous fournira des insights pratiques et des modèles éprouvés pour bâtir la prochaine génération d’applications alimentées par l’IA.
