> cd ai-agents-for-beginners
> git sparse-checkout set --no-cone '/*' '!translations' '!translated_images'
> ```
>
> **CMD（Windows）：**
> ```cmd
> git clone --filter=blob:none --sparse https://github.com/microsoft/ai-agents-for-beginners.git
> cd ai-agents-for-beginners
> git sparse-checkout set --no-cone "/*" "!translations" "!translated_images"
> ```
>
> 這能為你提供完成課程所需的一切，且下載速度更快。

## 🌱 開始入門

本課程包含有關構建 AI 代理程式基礎的課程。每節課各自涵蓋不同主題，可以隨意從任何地方開始學習！

本課程支援多語言。請前往我們的[可用語言列表](#-multi-language-support)。

如果這是你第一次使用生成式 AI 模型進行構建，請查看我們的[生成式 AI 初學者課程](https://aka.ms/genai-beginners)，該課程包含 21 節關於使用 GenAI 的課程。

別忘了[點星 (🌟) 支持此存儲庫](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst)，並[分叉此存儲庫](https://github.com/microsoft/ai-agents-for-beginners/fork)以運行代碼。

### 認識其他學習者，獲得問題解答

如果遇到困難或有任何有關構建 AI 代理程式的問題，請加入我們的專門 Discord 頻道：[Microsoft Foundry Discord](https://aka.ms/ai-agents/discord)。

### 你需要準備的東西

本課程的每個課程均包含代碼示例，請在 code_samples 資料夾中查找。你可以[分叉此存儲庫](https://github.com/microsoft/ai-agents-for-beginners/fork)來建立自己的副本。  

這些練習的代碼示例使用 Microsoft Agent Framework 與 Microsoft Foundry Agent Service V2：

- [Microsoft Foundry](https://aka.ms/ai-agents-beginners/ai-foundry) - 需要 Azure 帳戶

本課程使用 Microsoft 的以下 AI 代理框架與服務：

- [Microsoft Agent Framework (MAF)](https://learn.microsoft.com/agent-framework/overview/)
- [Microsoft Foundry Agent Service V2](https://aka.ms/ai-agents-beginners/ai-agent-service)

部分代碼範例也支援可替代的 OpenAI 相容提供者，例如提供大量上下文模型（最高可達 204K 代幣）的 [MiniMax](https://platform.minimaxi.com/)。有關配置詳情，請查看[課程設置](./00-course-setup/README.md)。

有關本課程代碼運行的更多資訊，請參閱[課程設置](./00-course-setup/README.md)。
