# ⏩ Sekventiella agentarbetsflöden med Azure OpenAI (Responses API) (.NET)

## 📋 Avancerad handledning för sekventiell bearbetning

Denna anteckningsbok visar **sekventiella arbetsflödesscheman** med Microsoft Agent Framework för .NET och Azure OpenAI (Responses API). Du kommer att lära dig hur du bygger sofistikerade, steg-för-steg bearbetningspipelines där agenter körs i en specifik ordning, där varje steg bygger vidare på resultaten från föregående steg.

## 💻 Köra koden

Den fullständiga implementeringen finns i `02.dotnet-agent-framework-workflow-ghmodel-sequential.cs`. Denna fil demonstrerar ett **trestegs arbetsflöde för möbelanalys**:

1. **Steg 1 - Säljagent**: Analyserar möbelbilder och ger köpförslag
2. **Steg 2 - Prisagent**: Ger detaljerade prisuppdelningar och budgetalternativ
3. **Steg 3 - Offertagent**: Genererar ett professionellt offertdokument i Markdown-format

### 🏗️ **Arkitektur för arbetsflödet**

```
Image Input → Sales Analysis → Price Estimation → Quote Generation → Final Output
```

Varje agent:
- Tar emot utdata från föregående steg som kontext
- Bygger vidare på tidigare analys med specialiserad kompetens
- Upprätthåller kontinuitet i arbetsflödet via tillståndshantering

### 🚀 Köra exemplet

**Förutsättningar:**
- Placera en möbelbild i `../imgs/home.png` (eller uppdatera variabeln `imgPath`)
- Konfigurera din `.env`-fil med din Azure OpenAI-endpoint och distribution, och logga in med `az login`

```bash
# Gör skriptet körbart (Unix/Linux/macOS)
chmod +x 02.dotnet-agent-framework-workflow-ghmodel-sequential.cs

# Kör det sekventiella arbetsflödet
./02.dotnet-agent-framework-workflow-ghmodel-sequential.cs
```

Eller på Windows:
```powershell
dotnet run 02.dotnet-agent-framework-workflow-ghmodel-sequential.cs
```

### 📝 Förväntad utdata

Arbetsflödet kommer att:
1. **Säljagenten**: Identifiera möbelobjekt från bilden och ge rekommendationer
2. **Prisagenten**: Lägg till detaljerad prisanalys med budgetnivåer och shoppingtips
3. **Offertagenten**: Generera ett formaterat offertdokument med all information sammanställd

Den slutgiltiga utdata blir en heltäckande, professionell möbeloffert baserad på bildanalys.

### 🎯 Verkliga tillämpningar

Detta sekventiella mönster är idealiskt för:
- **E-handel**: Produktanalys → Prisättning → Offertgenerering
- **Fastigheter**: Fastighetsanalys → Värdering → Annons skapande
- **Försäkring**: Skadeanalys → Bedömning → Offertgenerering
- **Innehållsskapande**: Forskning → Skrivande → Redigering → Publicering

### 🔍 Förstå tillståndsflödet

Varje agent i sekvensen får:
- **Ursprunglig indata**: Det ursprungliga användarmeddelandet (bild + text)
- **Tidigare agenters utdata**: Alla tidigare agenters svar i konversationshistoriken
- **Ackumulerad kontext**: Komplett tillstånd som upprätthålls genom arbetsflödet

Detta möjliggör sofistikerad flerstegsbehandling där varje agent bygger vidare på en omfattande kontext från alla tidigare steg.
