# 🔄 Grundläggande Agentarbetsflöden med Azure OpenAI (Responses API) (.NET)

## 📋 Handledning för arbetsflödesorkestrering

Denna anteckningsbok visar hur du bygger sofistikerade **agentarbetsflöden** med Microsoft Agent Framework för .NET och Azure OpenAI (Responses API). Du lär dig att skapa flerstegs affärsprocesser där AI-agenter samarbetar för att utföra komplexa uppgifter genom strukturerade orkestreringsmönster.

## 🎯 Lärandemål

### 🏗️ **Grundläggande arbetsflödesarkitektur**
- **Workflow Builder**: Designa och orkestrera komplexa flerstegs AI-processer
- **Agentkoordinering**: Samordna flera specialiserade agenter inom arbetsflöden
- **Azure OpenAI (Responses API)**: Använd Azure OpenAI Responses API i arbetsflöden
- **Visuell arbetsflödesdesign**: Skapa och visualisera arbetsflödesstrukturer för bättre förståelse

### 🔄 **Processorkestreringsmönster**
- **Sekventiell bearbetning**: Kedja ihop flera agentuppgifter i logisk ordning
- **Tillståndshantering**: Behåll kontext och dataflöde mellan arbetsflödets steg
- **Felhhantering**: Implementera robust återhämtning och arbetsflödesresiliens
- **Prestandaoptimering**: Designa effektiva arbetsflöden för företagsomfattande operationer

### 🏢 **Företagsarbetsflödesapplikationer**
- **Automatisering av affärsprocesser**: Automatisera komplexa organisatoriska arbetsflöden
- **Innehållsproduktionspipeline**: Redaktionella arbetsflöden med gransknings- och godkännandesteg
- **Automatisering av kundservice**: Flerstegs hantering av kundförfrågningar
- **Databehandlingsarbetsflöden**: ETL-arbetsflöden med AI-drivna transformationer

## ⚙️ Förutsättningar & installation

### 📦 **Nödvändiga NuGet-paket**

Denna arbetsflödesdemonstration använder flera nyckelpaket för .NET:

```xml
<!-- Core AI Framework -->
<PackageReference Include="Microsoft.Extensions.AI" Version="9.9.0" />

<!-- Azure OpenAI (Responses API) -->
<PackageReference Include="Azure.AI.OpenAI" Version="2.1.0" />
<PackageReference Include="Azure.Identity" Version="1.13.1" />

<!-- Agent Framework (Local Development) -->
<!-- Microsoft.Agents.AI.dll - Core agent abstractions -->
<!-- Microsoft.Agents.AI.OpenAI.dll - Azure OpenAI (Responses API) integration -->

<!-- Configuration and Environment -->
<PackageReference Include="DotNetEnv" Version="3.1.1" />
```

### 🔑 **Azure OpenAI-konfiguration**

**Miljöinställningar (.env-fil):**
```env
AZURE_OPENAI_ENDPOINT=https://<your-resource>.openai.azure.com
AZURE_OPENAI_DEPLOYMENT=gpt-4o-mini
```

**Azure OpenAI-åtkomst:**
1. Skapa en Azure OpenAI-resurs i Azure-portalen
2. Distribuera en modell (t.ex. `gpt-4o-mini`) och notera distributionsnamnet
3. Logga in med `az login` och konfigurera miljövariabler enligt ovan

## 💻 Köra koden

Den fullständiga implementeringen finns i `01.dotnet-agent-framework-workflow-ghmodel-basic.cs`. Den här filen visar:

1. **Miljökonfiguration** - Ladda Azure OpenAI-konfiguration från `.env`-filen
2. **Azure OpenAI-klientinställning** - Konfigurera klienten för att använda Azure OpenAI Responses API
3. **Agentskapande** - Definiera specialiserade agenter (Front Desk och Concierge)
4. **Workflow Builder** - Skapa ett flerskikts arbetsflöde med sekventiell bearbetning
5. **Arbetsflödeskörning** - Kör arbetsflödet med strömmande resultat

### 🚀 Köra exemplet

```bash
# Gör skriptet körbart (Unix/Linux/macOS)
chmod +x 01.dotnet-agent-framework-workflow-ghmodel-basic.cs

# Kör arbetsflödet
./01.dotnet-agent-framework-workflow-ghmodel-basic.cs
```

Eller på Windows:
```powershell
dotnet run 01.dotnet-agent-framework-workflow-ghmodel-basic.cs
```

### 📝 Förväntat resultat

Arbetsflödet kommer att:
1. Acceptera din resedestination ("Jag skulle vilja åka till Paris")
2. Front Desk-agenten ger en initial rekommendation
3. Concierge-agenten granskar och förbättrar rekommendationen
4. Det slutgiltiga resultatet visar hela samtalsströmmen
