# ⚡ Mipangilio ya Wakala wa Concurrent kwa Azure OpenAI (API za Majibu) (.NET)

## 📋 Mafunzo ya Usindikaji Sambamba wa Ufanisi wa Juu

Daftari hili linaonyesha **mifumo ya mtiririko wa kazi wa wakati mmoja** ukitumia Mfumo wa Wakala wa Microsoft kwa .NET na Azure OpenAI (API za Majibu). Utajifunza jinsi ya kujenga mitiririko ya kazi ya usindikaji sambamba yenye ufanisi wa juu inayoongeza uwezo wa utoaji huduma kwa kuendesha maajenti wengi wa AI kwa wakati mmoja huku ikidumisha uratibu na uthabiti wa data.

- **Azure OpenAI (API za Majibu)**: Ratibu simu nyingi za wakati mmoja kwa Azure OpenAI Responses API

### 🏗️ **Mimari ya Mtiririko wa Kazi**

```
User Request → ConcurrentStartExecutor → [Researcher Agent || Planner Agent] → ConcurrentAggregationExecutor → Final Output
```

**Vipengele Muhimu:**

1. **ConcurrentStartExecutor**: Inatuma ombi la mtumiaji kwa maajenti wote kwa wakati mmoja
2. **Wakala Mtafiti**: Anachambua maeneo na vivutio kwa wakati mmoja
3. **Wakala Mpangaji**: Anakua mipango ya safari kwa undani kwa wakati mmoja
4. **ConcurrentAggregationExecutor**: Anakusanya na kuunganisha matokeo kutoka kwa maajenti wote wawili

### 🎯 **Mfano wa Fan-Out/Fan-In**

Mtiririko huu unaonyesha mfano wa kawaida wa **Fan-Out/Fan-In**:
- **Fan-Out**: Ujumbe mmoja wa kuingiza hutumwa kwa maajenti wengi kwa wakati mmoja
- **Usindikaji Sambamba**: Maajenti wengi hufanya kazi sambamba kwenye kazi ile ile
- **Fan-In**: Matokeo kutoka kwa maajenti wote hukusanywa na kuunganishwa kuwa matokeo moja

### 🔍 Kuelewa Wakurugenzi Maalum

**ConcurrentStartExecutor:**
- Inatekeleza `IMessageHandler<string>` kupokea ingizo la aina ya string
- Hunyanyua ujumbe kwa maajenti wote waliounganishwa
- Hutuma `TurnToken` kuzindua usindikaji sambamba

**ConcurrentAggregationExecutor:**
- Inatekeleza `IMessageHandler<ChatMessage>` kupokea majibu ya maajenti
- Hokusanya ujumbe kwa njia salama ya mfululizo
- Hukusanya matokeo pale majibu yote yanapofika
- Hutumia `context.YieldOutputAsync()` kutoa matokeo ya mwisho

### ⚡ Faida za Ufanisi

**Sambamba vs Mfululizo:**
- Mfululizo: Agent1 (30s) → Agent2 (30s) = **sekunde 60 jumla**
- Sambamba: Agent1 (30s) || Agent2 (30s) = **sekunde 30 jumla**

**Kuboresha Ufanisi**: Hadi mara N× kwa maajenti N wa wakati mmoja (kutegemea mzigo na rasilimali)
