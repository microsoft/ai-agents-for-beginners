# ⏩ Mipangilio ya Wakala wa Mfuatano na Azure OpenAI (Responses API) (.NET)

## 📋 Mafunzo ya Usindikaji wa Mfuatano wa Juu Zaidi

Daftari hili linaonyesha **mifumo ya mfuatano wa utaratibu** kwa kutumia Microsoft Agent Framework kwa .NET na Azure OpenAI (Responses API). Utajifunza jinsi ya kujenga michakato tata, hatua kwa hatua ambapo mawakala hufanya kazi kwa mpangilio maalum, kila hatua ikijengwa juu ya matokeo ya hatua iliyopita.

## 🎯 Malengo ya Kujifunza

### 🔄 **Mimari ya Usindikaji wa Mfuatano**
- **Muundo wa Mfuatano wa Moja kwa Moja**: Tengeneza mifumo ya usindikaji hatua kwa hatua yenye utegemezi wazi
- **Usimamizi wa Hali**: Hifadhi muktadha na mtiririko wa data katika hatua za mfuatano wa utaratibu
- **Azure OpenAI (Responses API)**: Tumia mifano ya Azure OpenAI katika michakato ya .NET yenye hatua nyingi
- **Mifano ya Ntandao wa Biashara**: Jenga mifumo ya usindikaji wa mfuatano inayotumika kisanii

### 🏗️ **Mifumo ya Mfuatano ya Juu Zaidi**
- **Usindikaji wa Milango ya Hatua**: Tekeleza vituo vya uthibitisho kati ya hatua za utaratibu
- **Uhifadhi wa Muktadha**: Hifadhi hali na maarifa yaliyokusanywa katika hatua zote
- **Usambazaji wa Makosa**: Shughulikia makosa kwa njia ya heshima katika mnyororo wa usindikaji mfuatano
- **Uboreshaji wa Utendaji**: Utekelezaji wa mfuatano wenye ufanisi na mzigo mdogo

### 🏢 **Programu za Mfuatano za Biashara**
- **Ntandao ya Usindikaji wa Nyaraka**: Uchambuzi wa nyaraka wenye hatua nyingi, mabadiliko, na uthibitisho
- **Mifumo ya Ukaguzi wa Ubora**: Mapitio ya mfuatano, uthibitisho, na michakato ya idhini
- **Ntandao ya Uzalishaji wa Maudhui**: Utafiti → Uandishi → Uhariri → Mapitio → Uchapishaji
- **Uendeshaji wa Michakato ya Biashara**: Michakato ya biashara yenye hatua nyingi iliyowekwa utegemezi wazi

## ⚙️ Masharti & Usanidi

### 📦 **Vipakuzi Muhimu vya NuGet**

Vipakuzi muhimu kwa michakato ya .NET ya mfuatano:

```xml
<!-- Core AI Framework -->
<PackageReference Include="Microsoft.Extensions.AI" Version="9.9.0" />

<!-- Azure OpenAI (Responses API) -->
<PackageReference Include="Azure.AI.OpenAI" Version="2.1.0" />

<!-- Azure Identity and Async LINQ Support -->
<PackageReference Include="Azure.Identity" Version="1.15.0" />
<PackageReference Include="System.Linq.Async" Version="6.0.3" />

<!-- Local Agent Framework References -->
<!-- Microsoft.Agents.AI.dll - Core agent abstractions -->
<!-- Microsoft.Agents.AI.OpenAI.dll - Azure OpenAI (Responses API) integration -->
```

### 🔑 **Usanidi wa Azure OpenAI**

**Usanidi wa Mazingira (faili .env):**
```env
AZURE_OPENAI_ENDPOINT=https://<your-resource>.openai.azure.com
AZURE_OPENAI_DEPLOYMENT=gpt-4o-mini
```

**Usimamizi wa Usanidi:**
```csharp
// Load environment variables securely
Env.Load("../../../.env");
var azureEndpoint = Environment.GetEnvironmentVariable("AZURE_OPENAI_ENDPOINT");
var deployment = Environment.GetEnvironmentVariable("AZURE_OPENAI_DEPLOYMENT");
```
