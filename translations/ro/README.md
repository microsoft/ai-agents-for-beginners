> Acest depozit include traduceri în peste 50 de limbi, ceea ce crește semnificativ dimensiunea descărcării. Pentru a clona fără traduceri, folosește sparse checkout:
>
> **Bash / macOS / Linux:**
> ```bash
> git clone --filter=blob:none --sparse https://github.com/microsoft/ai-agents-for-beginners.git
> cd ai-agents-for-beginners
> git sparse-checkout set --no-cone '/*' '!translations' '!translated_images'
> ```
>
> **CMD (Windows):**
> ```cmd
> git clone --filter=blob:none --sparse https://github.com/microsoft/ai-agents-for-beginners.git
> cd ai-agents-for-beginners
> git sparse-checkout set --no-cone "/*" "!translations" "!translated_images"
> ```
>
> Acest lucru îți oferă tot ce ai nevoie pentru a finaliza cursul cu o descărcare mult mai rapidă.

## 🌱 Începeți

Acest curs are lecții care acoperă fundamentele construirii Agenților AI. Fiecare lecție tratează un subiect propriu, așa că începe de unde dorești!

Există suport multi-limbaj pentru acest curs. Accesează limbile disponibile aici: [disponibile aici](#-multi-language-support). 

Dacă este prima ta dată când construiești cu modele AI Generative, consultă cursul nostru [Inteligență Artificială Generativă pentru Începători](https://aka.ms/genai-beginners), care include 21 de lecții despre construirea cu GenAI.

Nu uita să [acordezi o stea (🌟) acestui repo](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst) și să [faci fork la acest repo](https://github.com/microsoft/ai-agents-for-beginners/fork) pentru a rula codul.

### Cunoaște alți cursanți, primește răspunsuri la întrebările tale

Dacă întâmpini dificultăți sau ai întrebări despre construirea Agenților AI, alătură-te canalului nostru dedicat de Discord în [Microsoft Foundry Discord](https://aka.ms/ai-agents/discord).

### Ce ai nevoie

Fiecare lecție din acest curs include exemple de cod, care pot fi găsite în folderul code_samples. Poți [fork-ui acest repo](https://github.com/microsoft/ai-agents-for-beginners/fork) pentru a-ți crea propria copie.  

Exemplele de cod din aceste exerciții utilizează Microsoft Agent Framework cu Microsoft Foundry Agent Service V2:

- [Microsoft Foundry](https://aka.ms/ai-agents-beginners/ai-foundry) - Cont Azure necesar

Acest curs utilizează următoarele cadre și servicii AI Agent de la Microsoft:

- [Microsoft Agent Framework (MAF)](https://learn.microsoft.com/agent-framework/overview/)
- [Microsoft Foundry Agent Service V2](https://aka.ms/ai-agents-beginners/ai-agent-service)

Unele exemple de cod acceptă și furnizori alternativi compatibili OpenAI, cum ar fi [MiniMax](https://platform.minimaxi.com/), care oferă modele cu context mare (până la 204K tokeni). Vezi [Configurarea cursului](./00-course-setup/README.md) pentru detalii despre configurare.

Pentru mai multe informații despre rularea codului pentru acest curs, accesează [Configurarea cursului](./00-course-setup/README.md).
