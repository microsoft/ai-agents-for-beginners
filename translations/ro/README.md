## 🌱 Începutul

Acest curs are lecții care acoperă elementele fundamentale ale construirii Agenților AI. Fiecare lecție acoperă propriul său subiect, așa că începe de unde preferi!

Există suport multilingv pentru acest curs. Mergi la [limbile disponibile aici](#-multi-language-support). 

Dacă este prima ta dată când construiești cu modele Generative AI, consultă cursul nostru [Generative AI Pentru Începători](https://aka.ms/genai-beginners), care include 21 de lecții despre construirea cu GenAI.

Nu uita să [acordezi o stea (🌟) acestui repo](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst) și să [fork-ui acest repo](https://github.com/microsoft/ai-agents-for-beginners/fork) pentru a rula codul.

### Întâlnește alți cursanți, primește răspunsuri la întrebările tale

Dacă te blochezi sau ai întrebări despre construirea Agenților AI, alătură-te canalului nostru dedicat Discord din [Microsoft Foundry Discord](https://aka.ms/ai-agents/discord).

### Ce ai nevoie

Fiecare lecție din acest curs include exemple de cod, care pot fi găsite în folderul code_samples. Poți [fork-ui acest repo](https://github.com/microsoft/ai-agents-for-beginners/fork) pentru a-ți crea propria copie.  

Exemplele de cod din aceste exerciții utilizează Microsoft Agent Framework cu Microsoft Foundry Agent Service V2:

- [Microsoft Foundry](https://aka.ms/ai-agents-beginners/ai-foundry) - Cont Azure Necesitat

Acest curs folosește următoarele cadre și servicii AI Agent de la Microsoft:

- [Microsoft Agent Framework (MAF)](https://learn.microsoft.com/agent-framework/overview/)
- [Microsoft Foundry Agent Service V2](https://aka.ms/ai-agents-beginners/ai-agent-service)

Unele exemple de cod suportă, de asemenea, furnizori compatibili cu OpenAI alternativi, precum [MiniMax](https://platform.minimaxi.com/), care oferă modele cu context mare (până la 204K de token-uri). Vezi [Configurarea Cursului](./00-course-setup/README.md) pentru detalii de configurare.

Pentru mai multe informații despre rularea codului pentru acest curs, mergi la [Configurarea Cursului](./00-course-setup/README.md).
