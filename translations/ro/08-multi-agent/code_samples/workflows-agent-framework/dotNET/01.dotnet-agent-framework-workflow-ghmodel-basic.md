# 🔄 Fluxuri de lucru de bază pentru agenți cu Azure OpenAI (API Răspunsuri) (.NET)

## 📋 Tutorial de Orchestrare a Fluxului de Lucru

Acest notebook demonstrează cum să construiți fluxuri de lucru **sofisticate de agenți** folosind Microsoft Agent Framework pentru .NET și Azure OpenAI (API Răspunsuri). Veți învăța să creați procese de afaceri în mai mulți pași în care agenții AI colaborează pentru a îndeplini sarcini complexe prin modele de orchestrare structurate.

## 🎯 Obiective de Învățare

### 🏗️ **Fundamentele Arhitecturii Fluxurilor de Lucru**
- **Builder de Fluxuri de Lucru**: Proiectarea și orchestrarea proceselor AI complexe în mai mulți pași
- **Coordonarea Agenților**: Coordonarea mai multor agenți specializați în cadrul fluxurilor de lucru
- **Azure OpenAI (API Răspunsuri)**: Utilizarea API-ului Azure OpenAI Responses în fluxuri de lucru
- **Design Vizual al Fluxului de Lucru**: Crearea și vizualizarea structurilor de fluxuri de lucru pentru o mai bună înțelegere

### 🔄 **Modele de Orchestrare a Proceselor**
- **Procesare Secvențială**: Lanțuirea mai multor sarcini ale agenților în ordinea logică
- **Gestionarea Stării**: Menținerea contextului și a fluxului de date între etapele fluxului de lucru
- **Gestionarea Erorilor**: Implementarea unei recuperări robuste a erorilor și a rezilienței fluxului de lucru
- **Optimizarea Performanței**: Proiectarea fluxurilor eficiente pentru operațiuni la scară de întreprindere

### 🏢 **Aplicații pentru Fluxuri de Lucru în Întreprinderi**
- **Automatizarea Proceselor de Afaceri**: Automatizarea fluxurilor organizaționale complexe
- **Fluxul de Producție a Conținutului**: Fluxuri editoriale cu etape de revizuire și aprobare
- **Automatizarea Serviciului Clienți**: Rezolvarea cercetărilor clienților în mai mulți pași
- **Fluxuri de Procesare a Datelor**: Fluxuri ETL cu transformări alimentate de AI

## ⚙️ Cerințe și Configurare

### 📦 **Pachete NuGet Necesare**

Această demonstrație de flux de lucru folosește mai multe pachete cheie .NET:

```xml
<!-- Core AI Framework -->
<PackageReference Include="Microsoft.Extensions.AI" Version="9.9.0" />

<!-- Azure OpenAI (Responses API) -->
<PackageReference Include="Azure.AI.OpenAI" Version="2.1.0" />
<PackageReference Include="Azure.Identity" Version="1.13.1" />

<!-- Agent Framework (Local Development) -->
<!-- Microsoft.Agents.AI.dll - Core agent abstractions -->
<!-- Microsoft.Agents.AI.OpenAI.dll - Azure OpenAI (Responses API) integration -->

<!-- Configuration and Environment -->
<PackageReference Include="DotNetEnv" Version="3.1.1" />
```

### 🔑 **Configurarea Azure OpenAI**

**Configurarea Mediului (.env file):**
```env
AZURE_OPENAI_ENDPOINT=https://<your-resource>.openai.azure.com
AZURE_OPENAI_DEPLOYMENT=gpt-4o-mini
```

**Acces Azure OpenAI:**
1. Creați o resursă Azure OpenAI în portalul Azure
2. Implementați un model (de exemplu, `gpt-4o-mini`) și notați numele implementării
3. Autentificați-vă cu `az login` și configurați variabilele de mediu după cum este arătat mai sus

**Componente Cheie:**
- **WorkflowBuilder**: Motor principal de orchestrare pentru proiectarea fluxurilor de lucru
- **AIAgent**: Agenți individuali specializați cu capabilități specifice
- **Client Azure OpenAI**: Integrare cu API-ul Azure OpenAI Responses
- **Context de Execuție**: Gestionează starea și fluxul de date între etapele fluxului

## 💻 Rularea Codului

Implementarea completă este disponibilă în `01.dotnet-agent-framework-workflow-ghmodel-basic.cs`. Acest fișier demonstrează:

1. **Configurarea Mediului** - Încărcarea configurației Azure OpenAI din fișierul `.env`
2. **Configurarea Clientului Azure OpenAI** - Configurarea clientului pentru a folosi API-ul Azure OpenAI Responses
3. **Crearea Agenților** - Definirea agenților specializați (Front Desk și Concierge)
4. **Workflow Builder** - Crearea unui flux de lucru multi-agent cu procesare secvențială
5. **Executarea Fluxului de Lucru** - Rularea fluxului cu rezultate în streaming

### 🚀 Rularea Exemplului

```bash
# Fă scriptul executabil (Unix/Linux/macOS)
chmod +x 01.dotnet-agent-framework-workflow-ghmodel-basic.cs

# Rulează fluxul de lucru
./01.dotnet-agent-framework-workflow-ghmodel-basic.cs
```

Sau pe Windows:
```powershell
dotnet run 01.dotnet-agent-framework-workflow-ghmodel-basic.cs
```

### 📝 Ieșire Așteptată

Fluxul de lucru va:
1. Accepta cererea ta de destinație de călătorie ("Aș dori să merg la Paris")
2. Agentul Front Desk oferă o recomandare inițială
3. Agentul Concierge revizuiește și rafinează recomandarea
4. Ieșirea finală afișează fluxul complet al conversației

### 🔧 Personalizare

Poți personaliza fluxul de lucru prin:
- Modificarea instrucțiunilor agenților pentru a schimba comportamentul lor
- Adăugarea mai multor agenți pentru a crea fluxuri de lucru complexe în mai mulți pași
- Schimbarea mesajului utilizatorului pentru a testa scenarii diferite
- Ajustarea muchiilor fluxului pentru a crea modele diferite de execuție
