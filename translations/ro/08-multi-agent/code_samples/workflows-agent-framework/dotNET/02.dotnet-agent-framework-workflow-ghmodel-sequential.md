# ⏩ Fluxuri de lucru secvențiale cu agenți folosind Azure OpenAI (API Răspunsuri) (.NET)

## 📋 Tutorial avansat pentru procesare secvențială

Acest notebook demonstrează **modele de fluxuri de lucru secvențiale** folosind Microsoft Agent Framework pentru .NET și Azure OpenAI (API Răspunsuri). Vei învăța cum să construiești conducte sofisticate de procesare pas-cu-pas în care agenții execută într-o ordine specifică, fiecare etapă bazându-se pe rezultatele etapei anterioare.

## 🎯 Obiective de învățare

### 🔄 **Arhitectura procesării secvențiale**
- **Design liniar al fluxului de lucru**: Crearea conductelor de procesare pas-cu-pas cu dependențe clare
- **Gestionarea stării**: Menținerea contextului și fluxului de date prin etapele secvențiale ale fluxului de lucru
- **Azure OpenAI (API Răspunsuri)**: Folosirea modelelor Azure OpenAI în fluxuri de lucru .NET multi-etape
- **Modele de conducte pentru companii**: Construirea sistemelor de procesare secvențiale gata pentru producție

### 🏗️ **Modele secvențiale avansate**
- **Procesare cu poartă de etapă**: Implementarea punctelor de validare între etapele fluxului de lucru
- **Păstrarea contextului**: Menținerea stării și a cunoștințelor acumulate prin toate etapele
- **Propagarea erorilor**: Gestionarea elegantă a eșecurilor în lanțurile de procesare secvențială
- **Optimizarea performanței**: Executare secvențială eficientă cu un overhead minim

### 🏢 **Aplicații secvențiale pentru companii**
- **Conductă de procesare documente**: Analiză multi-etapă, transformare și validare de documente
- **Fluxuri de lucru de asigurare a calității**: Revizuire, validare și aprobare secvențială
- **Conductă de producție de conținut**: Cercetare → Scriere → Editare → Revizuire → Publicare
- **Automatizarea proceselor de business**: Fluxuri de lucru de business multi-etape cu dependențe clare între etape

## ⚙️ Cerințe și configurare

### 📦 **Pachete NuGet necesare**

Pachete esențiale pentru fluxuri de lucru secvențiale .NET:

```xml
<!-- Core AI Framework -->
<PackageReference Include="Microsoft.Extensions.AI" Version="9.9.0" />

<!-- Azure OpenAI (Responses API) -->
<PackageReference Include="Azure.AI.OpenAI" Version="2.1.0" />

<!-- Azure Identity and Async LINQ Support -->
<PackageReference Include="Azure.Identity" Version="1.15.0" />
<PackageReference Include="System.Linq.Async" Version="6.0.3" />

<!-- Local Agent Framework References -->
<!-- Microsoft.Agents.AI.dll - Core agent abstractions -->
<!-- Microsoft.Agents.AI.OpenAI.dll - Azure OpenAI (Responses API) integration -->
```

### 🔑 **Configurare Azure OpenAI**

**Configurare mediu (.env file):**
```env
AZURE_OPENAI_ENDPOINT=https://<your-resource>.openai.azure.com
AZURE_OPENAI_DEPLOYMENT=gpt-4o-mini
```

**Managementul configurației:**
```csharp
// Load environment variables securely
Env.Load("../../../.env");
var azureEndpoint = Environment.GetEnvironmentVariable("AZURE_OPENAI_ENDPOINT");
var deployment = Environment.GetEnvironmentVariable("AZURE_OPENAI_DEPLOYMENT");
```

### 🏗️ **Arhitectura fluxului de lucru secvențial**

```mermaid
graph TD
    A[Initial Input] --> B[Stage 1: Agent de analiză]
    B --> C[Punct de control 1]
    C --> D[Stage 2: Agent de procesare]
    D --> E[Punct de control 2]
    E --> F[Stage 3: Agent de validare]
    F --> G[Rezultat final]
    
    H[Context de stare] --> B
    H --> D
    H --> F
    
    I[Azure OpenAI (API Răspunsuri)] --> B
    I --> D
    I --> F
```

**Componente cheie:**
- **Agenți secvențiali**: Agenți specializați pentru fiecare etapă de procesare
- **Context de stare**: Menține date și decizii acumulate prin etape
- **Puncte de control**: Puncte de validare între etape pentru a asigura calitatea și consistența
- **Client Azure OpenAI**: Acces consistent la modelul AI prin toate etapele fluxului de lucru

## 💻 Rularea codului

Implementarea completă este disponibilă în `02.dotnet-agent-framework-workflow-ghmodel-sequential.cs`. Acest fișier demonstrează un **flux de lucru de analiză a mobilierului în trei etape**:

1. **Etapa 1 - Agentul de vânzări**: Analizează imaginile cu mobilier și oferă sugestii de cumpărare
2. **Etapa 2 - Agentul de preț**: Oferă detalii despre structura prețurilor și opțiuni de buget
3. **Etapa 3 - Agentul de ofertare**: Generează un document profesional de ofertă în format Markdown

### 🏗️ **Arhitectura fluxului de lucru**

```
Image Input → Sales Analysis → Price Estimation → Quote Generation → Final Output
```

Fiecare agent:
- Primește ieșirea de la etapa anterioară ca context
- Construiește pe baza analizei anterioare cu expertiză specializată
- Menține continuitatea fluxului prin gestionarea stării

### 🚀 Rularea exemplului

**Cerințe preliminare:**
- Plasează o imagine cu mobilier la `../imgs/home.png` (sau actualizează variabila `imgPath`)
- Configurează fișierul `.env` cu endpoint-ul și implementarea Azure OpenAI, apoi autentifică-te cu `az login`

```bash
# Faceți scriptul executabil (Unix/Linux/macOS)
chmod +x 02.dotnet-agent-framework-workflow-ghmodel-sequential.cs

# Rulați fluxul de lucru secvențial
./02.dotnet-agent-framework-workflow-ghmodel-sequential.cs
```

Sau pe Windows:
```powershell
dotnet run 02.dotnet-agent-framework-workflow-ghmodel-sequential.cs
```

### 📝 Rezultat așteptat

Fluxul de lucru va:
1. **Agentul de vânzări**: Identifică articolele de mobilier din imagine și oferă recomandări
2. **Agentul de preț**: Adaugă analiza detaliată a prețurilor cu niveluri de buget și recomandări de cumpărare
3. **Agentul de ofertare**: Generează un document de ofertă formatat cu toate informațiile sintetizate

Rezultatul final va fi o ofertă profesională completă pentru mobilier bazată pe analiza imaginii.

### 🔍 Înțelegerea fluxului de stare

Fiecare agent din secvență primește:
- **Input original**: Mesajul inițial al utilizatorului (imagine + text)
- **Ieșiri ale agenților anteriori**: Toate răspunsurile agenților anteriori în istoricul conversației
- **Context acumulat**: Starea completă menținută pe parcursul fluxului de lucru

Aceasta permite procesare sofisticată în mai multe etape, în care fiecare agent construiește pe baza unui context cuprinzător din toate etapele anterioare.
