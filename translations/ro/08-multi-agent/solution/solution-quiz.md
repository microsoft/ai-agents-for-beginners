# Răspunsuri pentru Verificarea Cunoștințelor

## Întrebarea 1

**Răspuns: A2.** Mai mulți agenți sunt utili atunci când o sarcină are roluri specializate distincte, instrumente sau permisiuni separate și predări clare care necesită coordonare. Un simplu bot de suport poate rămâne de obicei un singur agent. Un volum mare de cereri identice este în primul rând o problemă de scalare și, de unul singur, nu necesită un design multi-agent.

## Întrebarea 2

**Răspuns: A1.** Un singur agent este de obicei mai ușor de testat, observat și operat atunci când un set de instrucțiuni și instrumente poate gestiona sarcina. Accesul la mai multe instrumente nu necesită automat mai mulți agenți. Rolurile separate cu permisiuni diferite și cerințe de audit pot justifica un design multi-agent.
