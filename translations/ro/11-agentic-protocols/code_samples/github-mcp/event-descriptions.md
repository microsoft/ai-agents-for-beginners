## Numele evenimentului: API Multi-Agent cu LangGraph și Azure Cosmos DB

## Descriere

Creșterea aplicațiilor AI multi-agent transformă modul în care construim sisteme inteligente - dar cum să le arhitecturăm pentru scalabilitate și performanță reală? În această sesiune, vom face o incursiune într-o aplicație multi-agent de producție construită cu LangGraph pentru orchestrare agenți, FastAPI ca strat API și Azure Cosmos DB ca schelet pentru gestionarea stării, stocarea vectorială și datele tranzacționale.

Printr-un tur detaliat al codului, vei vedea cum să proiectezi și să implementezi un flux de lucru condus de agenți care integrează fără cusur generarea augmentată prin recuperare (RAG), persistența memoriei și tranziții dinamice de stare. Vom acoperi:

Colaborarea agenților cu LangGraph pentru raționament structurat
Stocarea în timp real a istoricului conversațiilor folosind Azure Cosmos DB - aceeași bază de date care susține istoricul conversațiilor în ChatGPT, cea mai rapidă aplicație AI agent din istorie

Capacitățile async ale FastAPI pentru a menține interacțiunile responsive și scalabile
La finalul acestei sesiuni, vei avea un plan clar pentru construirea și implementarea propriilor aplicații multi-agent scalabile, cloud-native, care valorifică puterea AI moderne și infrastructurii cloud. Indiferent dacă ești inginer AI, arhitect cloud sau dezvoltator Python, această prezentare îți va oferi perspective practice și modele testate pentru a construi următoarea generație de aplicații AI.

## Numele evenimentului: Prompting-ul este noul scripting: întâlnește GenAIScript

## Descriere

jQuery a făcut dezvoltarea web mai ușoară abstrăgând complexitățile, permițând dezvoltatorilor să se concentreze pe construcție în loc să lupte cu particularitățile browserelor. Astăzi, dezvoltarea AI se confruntă cu o provocare similară. Noi modele apar constant și a ține pasul poate fi copleșitor, mai ales pe măsură ce uneltele AI—în special cele agentice—devin mai puternice și complexe. Ce-ar fi dacă ai putea folosi capacitățile AI de ultimă oră pentru a automatiza sarcini folosind abstracțiuni simple și familiare de JavaScript? Iată GenAIScript—o modalitate de a integra AI în fluxul tău de lucru fără efort, tratând prompturile ca fragmente de cod reutilizabile. În această prezentare, vom explora cum GenAIScript face ca agenții de automatizare AI să fie la fel de intuitivi ca scrierea de JavaScript, ajutându-te să simplifici munca repetitivă fără a avea nevoie de o expertiză profundă în AI.
