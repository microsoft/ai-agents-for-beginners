## Naziv događaja: Multi-Agent API s LangGraph i Azure Cosmos DB

## Opis

Uspon multi-agentnih AI aplikacija mijenja način na koji gradimo inteligentne sustave - ali kako ih arhitektirati za stvarnu skalabilnost i performanse? U ovoj sesiji dubinski ćemo zaroniti u proizvodnu multi-agentnu aplikaciju izgrađenu s LangGraph za orkestraciju agenata, FastAPI za API sloj i Azure Cosmos DB kao osnovu za upravljanje stanjem, pohranu vektora i transakcijske podatke.

Kroz detaljan pregled koda, vidjet ćete kako dizajnirati i implementirati tok rada vođen agentima koji besprijekorno integrira generiranje uz pomoć povrata (RAG), trajnost memorije i dinamičke prijelaze stanja. Pokrit ćemo:

Suradnju agenata preko LangGraph za strukturirano rasuđivanje
Pohranu povijesti chata u stvarnom vremenu koristeći Azure Cosmos DB - istu bazu podataka koja pokreće povijest chata u ChatGPT-u, najbrže rastućoj AI agentnoj aplikaciji u povijesti
Pretraživanje vektora za dohvaćanje znanja s podrškom za izvorne ugradnje Cosmos DB-a
Asinhrone mogućnosti FastAPI-a za održavanje responzivnih i skalabilnih interakcija
Do kraja ove sesije imat ćete jasan plan za izgradnju i implementaciju vlastitih skalabilnih, cloud-native multi-agentnih aplikacija koje koriste moć moderne AI i infrastrukture u oblaku. Bilo da ste AI inženjer, arhitekt oblaka ili Python programer, ovaj govor će vam pružiti praktične uvide i isprobane obrasce za izgradnju sljedeće generacije AI-pokretanih aplikacija.
