> Ovaj spremište uključuje prijevode na više od 50 jezika, što znatno povećava veličinu preuzimanja. Za kloniranje bez prijevoda, koristite sparse checkout:
>
> **Bash / macOS / Linux:**
> ```bash
> git clone --filter=blob:none --sparse https://github.com/microsoft/ai-agents-for-beginners.git
> cd ai-agents-for-beginners
> git sparse-checkout set --no-cone '/*' '!translations' '!translated_images'
> ```
>
> **CMD (Windows):**
> ```cmd
> git clone --filter=blob:none --sparse https://github.com/microsoft/ai-agents-for-beginners.git
> cd ai-agents-for-beginners
> git sparse-checkout set --no-cone "/*" "!translations" "!translated_images"
> ```
>
> Ovo vam daje sve što trebate za završetak tečaja uz znatno brže preuzimanje.

## 🌱 Početak

Ovaj tečaj ima lekcije koje pokrivaju osnove izgradnje AI agenata. Svaka lekcija pokriva svoju temu pa započnite gdje god želite!

Postoji višejezična podrška za ovaj tečaj. Pogledajte naše [dostupne jezike ovdje](#-multi-language-support).

Ako ovo prvi put gradite s generativnim AI modelima, pogledajte naš tečaj [Generative AI For Beginners](https://aka.ms/genai-beginners), koji uključuje 21 lekciju o radu s GenAI.

Ne zaboravite [označiti (🌟) ovo spremište](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst) i [razgranati ovo spremište](https://github.com/microsoft/ai-agents-for-beginners/fork) da biste mogli pokrenuti kod.

### Upoznajte druge učenike, dobijte odgovore na svoja pitanja

Ako zapnete ili imate pitanja o izgradnji AI agenata, pridružite se našem posvećenom Discord kanalu u [Microsoft Foundry Discord](https://aka.ms/ai-agents/discord).

### Što vam treba

Svaka lekcija u ovom tečaju uključuje primjere koda, koji se nalaze u mapi code_samples. Možete [razgranati ovo spremište](https://github.com/microsoft/ai-agents-for-beginners/fork) da biste napravili vlastitu kopiju.

Primjeri koda u ovim vježbama koriste Microsoft Agent Framework s Microsoft Foundry Agent Service V2:

- [Microsoft Foundry](https://aka.ms/ai-agents-beginners/ai-foundry) - Potreban Azure račun

Ovaj tečaj koristi sljedeće AI agent okvire i usluge od Microsofta:

- [Microsoft Agent Framework (MAF)](https://learn.microsoft.com/agent-framework/overview/)
- [Microsoft Foundry Agent Service V2](https://aka.ms/ai-agents-beginners/ai-agent-service)

Neki primjeri koda također podržavaju alternativne OpenAI-kompatibilne pružatelje poput [MiniMax](https://platform.minimaxi.com/), koji nudi modele s velikim kontekstom (do 204K tokena). Pogledajte [Course Setup](./00-course-setup/README.md) za detalje o konfiguraciji.

Za više informacija o pokretanju koda za ovaj tečaj, pogledajte [Course Setup](./00-course-setup/README.md).
