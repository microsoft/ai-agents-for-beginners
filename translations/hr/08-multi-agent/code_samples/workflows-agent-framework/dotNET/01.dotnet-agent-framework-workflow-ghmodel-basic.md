# 🔄 Osnovni radni tijekovi agenata s Azure OpenAI (Responses API) (.NET)

## 📋 Tutorial za orkestraciju radnih tijekova

Ovaj bilježnik prikazuje kako izgraditi sofisticirane **radne tijekove agenata** koristeći Microsoft Agent Framework za .NET i Azure OpenAI (Responses API). Naučit ćete kako stvoriti višestupanjske poslovne procese u kojima AI agenti surađuju kako bi izvršili složene zadatke kroz strukturirane obrasce orkestracije.

## 🎯 Ciljevi učenja

### 🏗️ **Osnove arhitekture radnog tijeka**
- **Workflow Builder**: Dizajnirajte i orkestrirajte složene višestupanjske AI procese
- **Koordinacija agenata**: Koordinirajte više specijaliziranih agenata unutar radnih tijekova
- **Azure OpenAI (Responses API)**: Iskoristite Azure OpenAI Responses API u radnim tijekovima
- **Vizualno dizajniranje radnih tijekova**: Kreirajte i vizualizirajte strukture radnih tijekova za bolje razumijevanje

### 🔄 **Obrasci orkestracije procesa**
- **Sekvencijalna obrada**: Povežite više zadataka agenata u logičkom redu
- **Upravljanje stanjem**: Održavajte kontekst i protok podataka kroz faze radnog tijeka
- **Rukovanje pogreškama**: Implementirajte robusno oporavljanje od pogrešaka i otpornost radnog tijeka
- **Optimizacija performansi**: Dizajnirajte učinkovite radne tijekove za poslovne operacije velikih razmjera

### 🏢 **Poslovne primjene radnih tijekova**
- **Automatizacija poslovnih procesa**: Automatizirajte složene organizacijske radne tijekove
- **Proizvodni lanac sadržaja**: Urednički radni tijekovi s fazama pregleda i odobrenja
- **Automatizacija korisničke službe**: Višestupanjsko rješavanje upita korisnika
- **Radni tijekovi obrade podataka**: ETL radni tijekovi s AI-pokretanom transformacijom

## ⚙️ Preduvjeti i postavljanje

### 📦 **Potrebni NuGet paketi**

Ova demonstracija radnog tijeka koristi nekoliko ključnih .NET paketa:

```xml
<!-- Core AI Framework -->
<PackageReference Include="Microsoft.Extensions.AI" Version="9.9.0" />

<!-- Azure OpenAI (Responses API) -->
<PackageReference Include="Azure.AI.OpenAI" Version="2.1.0" />
<PackageReference Include="Azure.Identity" Version="1.13.1" />

<!-- Agent Framework (Local Development) -->
<!-- Microsoft.Agents.AI.dll - Core agent abstractions -->
<!-- Microsoft.Agents.AI.OpenAI.dll - Azure OpenAI (Responses API) integration -->

<!-- Configuration and Environment -->
<PackageReference Include="DotNetEnv" Version="3.1.1" />
```

### 🔑 **Konfiguracija Azure OpenAI**

**Postavljanje okoline (.env datoteka):**
```env
AZURE_OPENAI_ENDPOINT=https://<your-resource>.openai.azure.com
AZURE_OPENAI_DEPLOYMENT=gpt-4o-mini
```

**Pristup Azure OpenAI:**
1. Stvorite Azure OpenAI resurs u Azure portalu
2. Implementirajte model (na primjer, `gpt-4o-mini`) i zabilježite naziv implementacije
3. Prijavite se preko `az login` i konfigurirajte varijable okoline kako je prikazano gore

### 🏗️ **Pregled arhitekture radnog tijeka**

```mermaid
graph TD
    A[Izgraditelj tijeka rada] --> B[Registar agenata]
    B --> C[Pokretač izvršenja tijeka rada]
    C --> D[Agent 1: Generator sadržaja]
    C --> E[Agent 2: Recenzent sadržaja] 
    D --> F[Rezultati tijeka rada]
    E --> F
    G[Azure OpenAI (Responses API)] --> D
    G --> E
```

**Ključne komponente:**
- **WorkflowBuilder**: Glavni mehanizam orkestracije za dizajn radnih tijekova
- **AIAgent**: Pojedinačni specijalizirani agenti sa specifičnim sposobnostima
- **Azure OpenAI Client**: Integracija Azure OpenAI Responses API-ja
- **Execution Context**: Upravljanje stanjem i protokom podataka između faza radnog tijeka

## 💻 Pokretanje koda

Cjelovita implementacija dostupna je u `01.dotnet-agent-framework-workflow-ghmodel-basic.cs`. Ova datoteka pokazuje:

1. **Konfiguracija okoline** - Učitavanje Azure OpenAI konfiguracije iz `.env` datoteke
2. **Postavljanje Azure OpenAI klijenta** - Konfiguracija klijenta za korištenje Azure OpenAI Responses API-ja
3. **Kreiranje agenata** - Definiranje specijaliziranih agenata (Front Desk i Concierge)
4. **Workflow Builder** - Kreiranje višestrukog radnog tijeka agenata s sekvencijalnim procesiranjem
5. **Izvršenje radnog tijeka** - Pokretanje radnog tijeka sa streamanjem rezultata

### 🚀 Pokretanje primjera

```bash
# Postavite skriptu kao izvršnu (Unix/Linux/macOS)
chmod +x 01.dotnet-agent-framework-workflow-ghmodel-basic.cs

# Pokreni tijek rada
./01.dotnet-agent-framework-workflow-ghmodel-basic.cs
```

Ili na Windowsu:
```powershell
dotnet run 01.dotnet-agent-framework-workflow-ghmodel-basic.cs
```

### 📝 Očekivani ispis

Radni tijek će:
1. Prihvatiti vaš zahtjev za putovanjem ("Želio bih ići u Pariz")
2. Agent za recepciju daje početni prijedlog
3. Agent Concierge pregledava i poboljšava prijedlog
4. Završni izlaz prikazuje cjelokupni tok razgovora

Možete prilagoditi radni tijek tako da:
- Mijenjate upute agenata za promjenu njihovog ponašanja

- Promijenite korisničku poruku za testiranje različitih scenarija
- Prilagodite veze radnog tijeka za kreiranje različitih obrazaca izvršenja
