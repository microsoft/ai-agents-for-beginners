# Odgovori na provjeru znanja

## Pitanje 1

**Odgovor: A2.** Više agenata je korisno kada zadatak ima različite specijalističke uloge, odvojene alate ili dozvole, i jasne prijenose koji zahtijevaju koordinaciju. Jednostavan bot za podršku obično može ostati jedan agent. Veliki broj istih zahtjeva prvenstveno je problem skaliranja i sam po sebi ne zahtijeva dizajn s više agenata.

## Pitanje 2

**Odgovor: A1.** Jedan agent je obično lakši za testiranje, praćenje i upravljanje kada jedan set uputa i alata može riješiti zadatak. Pristup nekoliko alata ne zahtijeva automatski više agenata. Odvojene uloge s različitim dozvolama i zahtjevima za reviziju mogu opravdati dizajn s više agenata.
