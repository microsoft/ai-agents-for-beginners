### 🔑 **Azure OpenAI Configuration**

**Environment Setup (.env file):**
```env
AZURE_OPENAI_ENDPOINT=https://<your-resource>.openai.azure.com
AZURE_OPENAI_DEPLOYMENT=gpt-4o-mini
```

**Azure OpenAI Access:**
1. Create Azure OpenAI resource for the Azure portal
2. Deploy one model (example, `gpt-4o-mini`) and remember the deployment name
3. Login with `az login` and set environment variables like e show above
