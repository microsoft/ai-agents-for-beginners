- **Fan-Out**: One input message broadcast to multiple agents at di same time
- **Concurrent Processing**: Multiple agents dey work in parallel on di same task
- **Fan-In**: Results from all agents collect and aggregate into one output

### 🔍 Understanding Custom Executors

**ConcurrentStartExecutor:**
- Implements `IMessageHandler<string>` to receive string input
- Broadcasts messages to all connected agents
- Sends `TurnToken` to trigger concurrent processing

**ConcurrentAggregationExecutor:**
- Implements `IMessageHandler<ChatMessage>` to receive agent responses
- Collects messages in a thread-safe way
- Aggregates when all expected responses don land
- Yields final output using `context.YieldOutputAsync()`

### ⚡ Performance Benefits

**Concurrent vs Sequential:**
- Sequential: Agent1 (30s) → Agent2 (30s) = **60 seconds total**
- Concurrent: Agent1 (30s) || Agent2 (30s) = **30 seconds total**

**Throughput improvement**: Fit be N× faster for N concurrent agents (depend on workload and resources)
