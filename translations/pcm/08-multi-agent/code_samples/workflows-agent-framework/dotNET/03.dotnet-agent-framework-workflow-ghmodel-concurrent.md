### 🔍 About Custom Executors

**ConcurrentStartExecutor:**
- E dey implement `IMessageHandler<string>` to accept string input
- E dey broadcast messages go all connected agents
- E dey send `TurnToken` to start concurrent processing

**ConcurrentAggregationExecutor:**
- E dey implement `IMessageHandler<ChatMessage>` to receive agent responses
- E dey gather messages thread-safe way
- E dey join messages when all responses don come
- E dey return final output with `context.YieldOutputAsync()`

### ⚡ Performance Benefits

**Concurrent vs Sequential:**
- Sequential: Agent1 (30s) → Agent2 (30s) = **60 seconds total**
- Concurrent: Agent1 (30s) || Agent2 (30s) = **30 seconds total**

**Throughput improvement**: Fit faster by N times if you get N concurrent agents (depend on workload and resources)
