## שם האירוע: API רב-סוכני עם LangGraph ו-Azure Cosmos DB

## תיאור

העלייה של אפליקציות AI רב-סוכניות משנה את האופן בו אנו בונים מערכות חכמות - אבל איך אתה מתכנן אותן לסקלביליות וביצועים בעולם האמיתי? במפגש זה נצלול לעומק באפליקציה רב-סוכנית ברמת ייצור, שנבנתה עם LangGraph לאירגון סוכנים, FastAPI לשכבת API, ו-Azure Cosmos DB כעמוד השדרה לניהול מצב, אחסון וקטורים ונתונים עסקיים.

דרך סיור מפורט בקוד, תראה כיצד לתכנן וליישם זרימת עבודה מונחית סוכן שמשתלבת ללא תפרים עם יצירת תוכן עם עזרתה של שליפה (RAG), שימור זיכרון, ומעברים דינמיים במצב. נסקור:

שיתוף פעולה בין סוכנים עם LangGraph להגיון מובנה
אחסון היסטוריית שיחות בזמן אמת באמצעות Azure Cosmos DB - אותה מסד נתונים שמניע את היסטוריית השיחות ב-ChatGPT, אפליקציית סוכן AI הצומחת במהירות המהירה בהיסטוריה
חיפוש וקטורי לשאיבת ידע עם תמיכה טבעית בהטמעות של Cosmos DB
יכולות Async של FastAPI לשמירת תגובות מהירות וסקלביליות
בסיום המפגש תקבל שרטוט ברור לבניית והפצת אפליקציות רב-סוכניות מתקדמות בענן, המנצלות את כוחה של AI מודרנית ותשתית ענן מתקדמת. לא משנה אם אתה מהנדס AI, אדריכל ענן, או מפתח Python, השיחה תצייד אותך בתובנות מעשיות ודפוסים מוכחים לבניית הדור הבא של אפליקציות מגובות בינה מלאכותית.
