## שם האירוע: ממשק API רב-סוכני עם LangGraph ו-Azure Cosmos DB

## תיאור

העלייה של אפליקציות AI רב-סוכניות משנה את האופן שבו אנו בונים מערכות אינטיליגנטיות - אבל איך אתה מתכנן אותן לקנה מידה וביצועים בעולם האמיתי? במפגש זה נצלול לעומק לאפליקציה רב-סוכנית ברמת הפקה שנבנתה עם LangGraph לאורקסטרציה של סוכנים, FastAPI כשכבת API, ו-Azure Cosmos DB כעמוד השדרה לניהול מצב, אחסון וקטורי, ונתונים טרנזקציוניים.

באמצעות סקירת קוד מפורטת, תראה כיצד לתכנן ולממש תהליך עבודה מונחה סוכן המשלב בצורה חלקה יצירה מושהית-עם-שחזור מידע (RAG), שמירת זיכרון ומעברי מצב דינמיים. נסקור:

שיתוף פעולה בין סוכנים עם LangGraph להסקת מסקנות מובנית
אחסון היסטוריית שיחות בזמן אמת באמצעות Azure Cosmos DB - אותו מסד נתונים שמפעיל את היסטוריית השיחות ב-ChatGPT, אפליקציית סוכן AI שצומחת במהירות הגבוהה ביותר בהיסטוריה
חיפוש וקטורי לשחזור ידע עם תמיכת הטמעות טבעית של Cosmos DB
יכולות אסינכרוניות של FastAPI לשמירה על תגובתיות וקנה מידה באינטראקציות
בסוף מפגש זה, יהיה בידיך תכנון ברור לבניית ופריסת אפליקציות רב-סוכניות בקנה מידה בענן המשתמשות בכוחות AI מודרניים ותשתית ענן. אם אתה מהנדס AI, אדריכל ענן, או מפתח Python, ההרצאה תעניק לך תובנות מעשיות ודפוסים מוכחים לבניית הדור הבא של אפליקציות מונעות AI.
