## 🌱 להתחיל

קורס זה כולל שיעורים המכסים את יסודות בניית סוכני בינה מלאכותית. כל שיעור עוסק בנושא משלו, לכן התחילו איפה שתרצו!

יש תמיכה בריבוי שפות עבור קורס זה. עברו ל[שפות הזמינות כאן](#-multi-language-support). 

אם זו הפעם הראשונה שלכם לבנות עם דגמי בינה מלאכותית יוצרת, בדקו את קורס ה-[בינה מלאכותית יוצרת למתחילים](https://aka.ms/genai-beginners), הכולל 21 שיעורים על בנייה עם GenAI.

אל תשכחו [להעניק כוכב (🌟) למאגר זה](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst) ו-[לעשות fork למאגר זה](https://github.com/microsoft/ai-agents-for-beginners/fork) כדי להריץ את הקוד.

### פגוש לומדים אחרים, קבל מענה על שאלותיך

אם אתה נתקע או יש לך שאלות לגבי בניית סוכני בינה מלאכותית, הצטרף לערוץ ה-Discord הייעודי שלנו ב-[Microsoft Foundry Discord](https://aka.ms/ai-agents/discord).

### מה אתה צריך

כל שיעור בקורס כולל דוגמאות קוד שנמצאות בתיקיית code_samples. ניתן [לעשות fork למאגר זה](https://github.com/microsoft/ai-agents-for-beginners/fork) כדי ליצור עותק משלך.  

דוגמאות הקוד בתרגילים אלו משתמשות במסגרת Microsoft Agent Framework עם שירות סוכן Microsoft Foundry V2:

- [Microsoft Foundry](https://aka.ms/ai-agents-beginners/ai-foundry) - דרוש חשבון Azure

קורס זה משתמש במסגרת ושירותי סוכני בינה מלאכותית הבאים מ-Microsoft:

- [Microsoft Agent Framework (MAF)](https://learn.microsoft.com/agent-framework/overview/)
- [Microsoft Foundry Agent Service V2](https://aka.ms/ai-agents-beginners/ai-agent-service)

חלק מדוגמאות הקוד תומכות גם בספקים חלופיים התואמים ל-OpenAI כמו [MiniMax](https://platform.minimaxi.com/), המציע מודלים בהקשר גדול (עד 204K טוקנים). ראו את [הגדרת הקורס](./00-course-setup/README.md) לפרטים על התצורה.

למידע נוסף על הרצת הקוד לקורס זה, עברו ל-[הגדרת הקורס](./00-course-setup/README.md).
