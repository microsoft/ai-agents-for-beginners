## 🌱 מתחילים

בקורס זה יש שיעורים המכסים את יסודות בניית סוכני בינה מלאכותית. כל שיעור מכסה נושא נפרד, לכן התחילו איפה שתרצו!

ישנה תמיכה רב-שפתית לקורס זה. כנסו אל [השפות הזמינות כאן](#-multi-language-support).

אם זו הפעם הראשונה שלכם בבנייה עם דגמי בינה מלאכותית גנרטיבית, בדקו את הקורס שלנו [בינה מלאכותית גנרטיבית למתחילים](https://aka.ms/genai-beginners), הכולל 21 שיעורים על בנייה עם GenAI.

אל תשכחו [לתת כוכב (🌟) למאגר זה](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst) ו-[לזלוג את המאגר הזה](https://github.com/microsoft/ai-agents-for-beginners/fork) כדי להריץ את הקוד.

### פגשו לומדים אחרים, וקבלו מענה לשאלותיכם

אם תקלעו לקשיים או יש לכם שאלות לגבי בניית סוכני בינה מלאכותית, הצטרפו לערוץ הדיסקורד המיוחד שלנו ב-[Microsoft Foundry Discord](https://aka.ms/ai-agents/discord).

### מה אתם צריכים

בכל שיעור בקורס הזה יש דוגמאות קוד, הנמצאות בתיקיית code_samples. אתם יכולים [לזלוג את המאגר הזה](https://github.com/microsoft/ai-agents-for-beginners/fork) כדי ליצור העתק משלכם.

דוגמאות הקוד בתרגילים הללו משתמשות במסגרת Microsoft Agent Framework עם שירות Microsoft Foundry Agent Service V2:

- [Microsoft Foundry](https://aka.ms/ai-agents-beginners/ai-foundry) - דרוש חשבון Azure

קורס זה משתמש במסגרת וסוכנויות AI הבאות מ-Microsoft:

- [Microsoft Agent Framework (MAF)](https://learn.microsoft.com/agent-framework/overview/)
- [Microsoft Foundry Agent Service V2](https://aka.ms/ai-agents-beginners/ai-agent-service)

חלק מדוגמאות הקוד תומכות גם בספקים תואמי OpenAI אחרים כמו [MiniMax](https://platform.minimaxi.com/), שמציע מודלים עם הקשר גדול (עד 204 אלף טוקנים). ראו את [הגדרת הקורס](./00-course-setup/README.md) לפרטים על התצורה.

למידע נוסף על הפעלת הקוד לקורס זה, כנסו אל [הגדרת הקורס](./00-course-setup/README.md).
