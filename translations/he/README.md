> cd ai-agents-for-beginners
> git sparse-checkout set --no-cone '/*' '!translations' '!translated_images'

>
> **CMD (Windows):**
> ```cmd
> git clone --filter=blob:none --sparse https://github.com/microsoft/ai-agents-for-beginners.git
> cd ai-agents-for-beginners
> git sparse-checkout set --no-cone "/*" "!translations" "!translated_images"
> ```
>
> זה נותן לך את כל מה שצריך כדי להשלים את הקורס במהירות הורדה גבוהה יותר.

## 🌱 התחלת עבודה

בקורס זה יש שיעורים המכסים את היסודות בבניית סוכני בינה מלאכותית. כל שיעור מקיף נושא משלו, אז תתחיל מכל מקום שתרצה!

קיימת תמיכה רב-לשונית לקורס זה. עבור ל[שפות הזמינות כאן](#-multi-language-support).

אם זו הפעם הראשונה שלך בבניית מודלים של בינה מלאכותית יצירתית, בדוק את קורס [בינה מלאכותית יצירתית למתחילים](https://aka.ms/genai-beginners), הכולל 21 שיעורים על בנייה עם GenAI.

אל תשכח [להוסיף כוכב (🌟) למאגר זה](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst) ו[לשכפל אותו (fork)](https://github.com/microsoft/ai-agents-for-beginners/fork) כדי להריץ את הקוד.

### הכירו לומדים אחרים, קבלו מענה לשאלותיכם

אם תיתקע או יהיו לך שאלות לגבי בניית סוכני בינה מלאכותית, הצטרף לערוץ דיסקורד ייעודי שלנו ב-[Microsoft Foundry Discord](https://aka.ms/ai-agents/discord).

### מה אתה צריך

בכל שיעור בקורס זה יש דוגמאות קוד, שניתן למצוא בתיקיית code_samples. תוכל [לשכפל את המאגר הזה (fork)](https://github.com/microsoft/ai-agents-for-beginners/fork) כדי ליצור עותק משלך.

דוגמאות הקוד בתרגילים אלה משתמשות במסגרת הסוכנים של מיקרוסופט יחד עם שירות הסוכנים של Microsoft Foundry V2:

- [Microsoft Foundry](https://aka.ms/ai-agents-beginners/ai-foundry) - דרושה חשבון Azure

קורס זה משתמש במסגרת ושירותי סוכני בינה מלאכותית הבאים של מיקרוסופט:

- [Microsoft Agent Framework (MAF)](https://aka.ms/ai-agents-beginners/agent-framework)
- [Microsoft Foundry Agent Service V2](https://aka.ms/ai-agents-beginners/ai-agent-service)

דוגמאות קוד מסוימות תומכות גם בספקים תואמי OpenAI חלופיים כגון [MiniMax](https://platform.minimaxi.com/), שמציעים מודלים להקשר רחב (עד 204 אלף טוקנים). ראה את [הגדרת הקורס](./00-course-setup/README.md) לפרטי התצורה.

למידע נוסף על הרצת הקוד לקורס זה, עבור ל[הגדרת הקורס](./00-course-setup/README.md).
