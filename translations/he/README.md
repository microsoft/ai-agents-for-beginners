> cd ai-agents-for-beginners
> git sparse-checkout set --no-cone '/*' '!translations' '!translated_images'
> ```
>
> **CMD (Windows):**
> ```cmd
> git clone --filter=blob:none --sparse https://github.com/microsoft/ai-agents-for-beginners.git
> cd ai-agents-for-beginners
> git sparse-checkout set --no-cone "/*" "!translations" "!translated_images"
> ```
>
> זה נותן לך את כל מה שצריך כדי להשלים את הקורס עם הורדה מהירה יותר.

## 🌱 להתחלה

בקורס זה יש שיעורים המכסים את היסודות של בניית סוכני בינה מלאכותית. כל שיעור עוסק בנושא משלו, אז תתחיל איפה שתרצה!

יש תמיכה בריבוי שפות עבור קורס זה. עבור ל[שפות הזמינות כאן](#-multi-language-support). 

אם זו הפעם הראשונה שלך לבנות עם מודלים של בינה מלאכותית גנרטיבית, בדוק את קורס [בינה מלאכותית גנרטיבית למתחילים](https://aka.ms/genai-beginners), הכולל 21 שיעורים על בניה עם GenAI.

אל תשכח [להעניק כוכב (🌟) למאגר זה](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst) ו[לפצל את המאגר](https://github.com/microsoft/ai-agents-for-beginners/fork) כדי להריץ את הקוד.

### פגוש לומדים אחרים, קבל מענה לשאלותיך

אם תיתקע או יהיו לך שאלות על בניית סוכני בינה מלאכותית, הצטרף לערוץ ה-Discord שלנו ב-[Microsoft Foundry Discord](https://aka.ms/ai-agents/discord).

### מה אתה צריך 

כל שיעור בקורס כולל דוגמאות קוד, שניתן למצוא בתיקיית code_samples. תוכל [לפצל את המאגר](https://github.com/microsoft/ai-agents-for-beginners/fork) כדי ליצור עותק משלך.  

דוגמאות הקוד בתרגילים אלה משתמשות ב-Microsoft Agent Framework יחד עם Microsoft Foundry Agent Service V2:

- [Microsoft Foundry](https://aka.ms/ai-agents-beginners/ai-foundry) - דרוש חשבון Azure

קורס זה משתמש במסגרת ושירותים הבאים של סוכני בינה מלאכותית מבית Microsoft:

- [Microsoft Agent Framework (MAF)](https://learn.microsoft.com/agent-framework/overview/)
- [Microsoft Foundry Agent Service V2](https://aka.ms/ai-agents-beginners/ai-agent-service)

بعض דוגמאות הקוד תומכות גם בספקים תואמי OpenAI חלופיים כמו [MiniMax](https://platform.minimaxi.com/), אשר מציעים מודלים בהקשר גדול (עד 204K טוקנים). עיין ב-[הגדרת הקורס](./00-course-setup/README.md) לפרטים על הקונפיגורציה.

למידע נוסף על הרצת הקוד עבור קורס זה, עבור אל [הגדרת הקורס](./00-course-setup/README.md).
