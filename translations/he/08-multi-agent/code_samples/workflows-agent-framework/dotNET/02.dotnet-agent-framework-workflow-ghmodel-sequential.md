# ⏩ זרימות עבודה סדרתיות של סוכנים עם Azure OpenAI (Responses API) (.NET)

## 📋 מדריך מתקדם לעיבוד סדרתי

מחברת זו מדגימה **תבניות זרימות עבודה סדרתיות** בעזרת Microsoft Agent Framework ל-.NET ו-Azure OpenAI (Responses API). תלמד כיצד לבנות צינורות עיבוד מתקדמים שלב אחר שלב, שבהם הסוכנים מבצעים בסדר מסוים, כשכל שלב בונה על תוצאות השלב הקודם.

## 🎯 מטרות הלמידה

### 🔄 **ארכיטקטורת עיבוד סדרתי**
- **עיצוב זרימת עבודה ליניארית**: יצירת צינורות עיבוד שלב אחר שלב עם תלות ברורה
- **ניהול מצב**: שמירה על הקשר וזרימת הנתונים בין שלבי הזרימה הסדרתית
- **Azure OpenAI (Responses API)**: שימוש בדגמי Azure OpenAI בזרימות עבודה רב-שלביות ב-.NET
- **תבניות צינורות ארגוניות**: בניית מערכות עיבוד סדרתיות מוכנות לייצור

### 🏗️ **תבניות סדרתיות מתקדמות**
- **עיבוד עם שלבי בדיקה**: יישום נקודות בדיקה לאימות בין שלבי זרימת העבודה
- **שימור הקשר**: שמירה על מצב וידע מצטבר לאורך כל השלבים
- **הפצת שגיאות**: טיפול בכשלים בצורה אלגנטית ברשתות עיבוד סדרתיות
- **אופטימיזציית ביצועים**: ביצוע סדרתי יעיל עם עומס מינימלי

### 🏢 **יישומים סדרתיים ארגוניים**
- **צינור עיבוד מסמכים**: ניתוח, המרה ואימות מסמכים רב-שלבי
- **זרימות עבודה לאבטחת איכות**: סקירה, אימות ואישור סדרתי
- **צינור יצירת תוכן**: מחקר → כתיבה → עריכה → סקירה → פרסום
- **אוטומציה של תהליכים עסקיים**: זרימות עבודה עסקיות רב-שלביות עם תלות שלבית

## ⚙️ דרישות מוקדמות והגדרה

### 📦 **חבילות NuGet דרושות**

חבילות בסיסיות לזרימות עבודה סדרתיות ב-.NET:

```xml
<!-- Core AI Framework -->
<PackageReference Include="Microsoft.Extensions.AI" Version="9.9.0" />

<!-- Azure OpenAI (Responses API) -->
<PackageReference Include="Azure.AI.OpenAI" Version="2.1.0" />

<!-- Azure Identity and Async LINQ Support -->
<PackageReference Include="Azure.Identity" Version="1.15.0" />
<PackageReference Include="System.Linq.Async" Version="6.0.3" />

<!-- Local Agent Framework References -->
<!-- Microsoft.Agents.AI.dll - Core agent abstractions -->
<!-- Microsoft.Agents.AI.OpenAI.dll - Azure OpenAI (Responses API) integration -->
```

### 🔑 **הגדרות Azure OpenAI**

**הגדרת סביבה (קובץ .env):**
```env
AZURE_OPENAI_ENDPOINT=https://<your-resource>.openai.azure.com
AZURE_OPENAI_DEPLOYMENT=gpt-4o-mini
```

**ניהול הגדרות:**
```csharp
// Load environment variables securely
Env.Load("../../../.env");
var azureEndpoint = Environment.GetEnvironmentVariable("AZURE_OPENAI_ENDPOINT");
var deployment = Environment.GetEnvironmentVariable("AZURE_OPENAI_DEPLOYMENT");
```

### 🏗️ **ארכיטקטורת זרימת עבודה סדרתית**

```mermaid
graph TD
    A[Initial Input] --> B[Stage 1: סוכן ניתוח]
    B --> C[נקודת בדיקה 1]
    C --> D[Stage 2: סוכן עיבוד]
    D --> E[נקודת בדיקה 2]
    E --> F[Stage 3: סוכן אימות]
    F --> G[פלט סופי]
    
    H[הקשר מצב] --> B
    H --> D
    H --> F
    
    I[Azure OpenAI (API תגובות)] --> B
    I --> D
    I --> F
```

**רכיבים מרכזיים:**
- **סוכנים סדרתיים**: סוכנים מתמחים לכל שלב בעיבוד
- **קונטקסט מצב**: שומר נתונים והחלטות מצטברים בין השלבים
- **נקודות בדיקה**: נקודות אימות בין השלבים להבטחת איכות ועקביות
- **לקוח Azure OpenAI**: גישה עקבית לדגם ה-AI בכל שלבי זרימת העבודה

## 💻 הרצת הקוד

המימוש המלא זמין בקובץ `02.dotnet-agent-framework-workflow-ghmodel-sequential.cs`. קובץ זה מדגים **זרימת עבודה לניתוח רהיטים בשלושה שלבים**:

1. **שלב 1 - סוכן מכירות**: מנתח תמונות רהיטים ומספק הצעות לרכישה
2. **שלב 2 - סוכן מחירים**: מספק פירוט מחירים ואפשרויות תקציב
3. **שלב 3 - סוכן הצעות מחיר**: יוצר מסמך הצעת מחיר מקצועי בפורמט Markdown

Image Input → Sales Analysis → Price Estimation → Quote Generation → Final Output

- שומר על רצף זרימת העבודה דרך ניהול מצב

### 📝 פלט צפוי

זרימת העבודה תעשה:
1. **סוכן מכירות**: זיהוי פריטי רהיטים מהתמונה ותתן המלצות
2. **סוכן מחירים**: תוסיף ניתוח מחירים מפורט עם רמות תקציב והמלצות לקנייה
3. **סוכן הצעות מחיר**: תייצר מסמך הצעת מחיר מעוצב עם כל המידע המשולב

הפלט הסופי יהיה הצעת מחיר מקצועית ומקיפה עבור רהיטים המבוססת על ניתוח התמונה.

### 🔧 אפשרויות התאמה אישית

**שינוי התנהגות סוכן:**
```csharp
// Adjust agent instructions to change their focus
const string SalesAgentInstructions = "Your custom instructions...";
```

**שינוי זרימה סדרתית:**
```csharp
// Add or reorder workflow stages
var workflow = new WorkflowBuilder(salesagent)
    .AddEdge(salesagent, priceagent)
    .AddEdge(priceagent, quoteagent)
    .AddEdge(quoteagent, newAgent)  // Add another stage
    .Build();
```
