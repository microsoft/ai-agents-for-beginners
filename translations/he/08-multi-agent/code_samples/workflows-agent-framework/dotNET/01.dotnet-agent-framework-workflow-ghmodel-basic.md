# 🔄 זרימות עבודה בסיסיות של סוכנים עם Azure OpenAI (Responses API) (.NET)

## 📋 הדרכה לאורכסטרציה של זרימות עבודה

המחברת הזו ממחישה כיצד לבנות **זרימות עבודה** מתקדמות של סוכנים באמצעות Microsoft Agent Framework עבור .NET ו-Azure OpenAI (Responses API). תלמדו ליצור תהליכים עסקיים מרובי שלבים בהם סוכני AI משתפים פעולה להשלמת משימות מורכבות באמצעות דפוסי אורכסטרציה מובנים.

## 🎯 מטרות הלמידה

### 🏗️ **יסודות ארכיטקטורת זרימות עבודה**
- **בונה זרימות עבודה**: תכנן ואורכסטר תהליכי AI מרובי שלבים ומורכבים
- **תיאום סוכנים**: תאם בין סוכנים מומחים מרובים בתוך זרימות עבודה
- **Azure OpenAI (Responses API)**: השתמש ב-API של Azure OpenAI Responses בזרימות עבודה
- **עיצוב זרימות עבודה חזותי**: צור והצג מבני זרימות עבודה להבנה טובה יותר

### 🔄 **דפוסי אורכסטרציה לתהליכים**
- **עיבוד רציף**: שרשר משימות סוכנים מרובות בסדר לוגי
- **ניהול מצב**: שמור על הקשר וזרימת נתונים בשלבי זרימת העבודה
- **טיפול בשגיאות**: יישם התאוששות שגיאות חזקה וחוסן זרימת עבודה
- **אופטימיזציית ביצועים**: עצב זרימות עבודה יעילות לפעולות בקנה מידה ארגוני

### 🏢 **יישומי זרימות עבודה ארגוניים**
- **אוטומציה של תהליכים עסקיים**: הפוך אוטומטיים זרימות עבודה ארגוניות מורכבות
- **צנרת הפקת תוכן**: זרימות עבודה מערכתיות עם שלבי בדיקה ואישור
- **אוטומציה של שירות לקוחות**: פתרון פניות לקוח מרובי שלבים
- **זרימות עבודה לעיבוד נתונים**: זרימות ETL עם טרנספורמציות מבוססות AI

## ⚙️ דרישות מוקדמות והגדרות

### 📦 **חבילות NuGet הדרושות**

הדגמת זרימת העבודה הזו משתמשת בכמה חבילות מפתח של .NET:

```xml
<!-- Core AI Framework -->
<PackageReference Include="Microsoft.Extensions.AI" Version="9.9.0" />

<!-- Azure OpenAI (Responses API) -->
<PackageReference Include="Azure.AI.OpenAI" Version="2.1.0" />
<PackageReference Include="Azure.Identity" Version="1.13.1" />

<!-- Agent Framework (Local Development) -->
<!-- Microsoft.Agents.AI.dll - Core agent abstractions -->
<!-- Microsoft.Agents.AI.OpenAI.dll - Azure OpenAI (Responses API) integration -->

<!-- Configuration and Environment -->
<PackageReference Include="DotNetEnv" Version="3.1.1" />
```

### 🔑 **הגדרת Azure OpenAI**

**הגדרת הסביבה (קובץ .env):**
```env
AZURE_OPENAI_ENDPOINT=https://<your-resource>.openai.azure.com
AZURE_OPENAI_DEPLOYMENT=gpt-4o-mini
```

**גישה ל-Azure OpenAI:**
1. צור משאב Azure OpenAI בפורטל Azure
2. פרוס מודל (לדוגמה, `gpt-4o-mini`) ורשום את שם הפריסה
3. התחבר עם `az login` וקבע משתני סביבה כפי שמוצג למעלה

### 🏗️ **סקירת ארכיטקטורת זרימות עבודה**

```mermaid
graph TD
    A[בונה תהליכי עבודה] --> B[רישום סוכנים]
    B --> C[מנוע ביצוע תהליך עבודה]
    C --> D[Agent 1: יוצר תוכן]
    C --> E[Agent 2: בוחן תוכן] 
    D --> F[תוצאות תהליכי עבודה]
    E --> F
    G[Azure OpenAI (ה-API של התגובות)] --> D
    G --> E
```

**רכיבים עיקריים:**
- **WorkflowBuilder**: מנוע האורכסטרציה הראשי לתכנון זרימות עבודה
- **AIAgent**: סוכנים מתמחים בודדים עם יכולות ספציפיות
- **לקוח Azure OpenAI**: אינטגרציה עם Azure OpenAI Responses API
- **Execution Context**: מנהל מצב וזרימת נתונים בין שלבי זרימת העבודה

## 💻 הפעלת הקוד

מימוש מלא זמין בקובץ `01.dotnet-agent-framework-workflow-ghmodel-basic.cs`. קובץ זה מדגים:

1. **הגדרת סביבה** - טעינת הגדרת Azure OpenAI מקובץ `.env`
2. **הגדרת לקוח Azure OpenAI** - קביעת תצורה לשימוש ב-Azure OpenAI Responses API
3. **יצירת סוכן** - הגדרת סוכנים מיוחדים (קבלה וקונסיירז')
4. **בונה זרימות עבודה** - יצירת זרימת עבודה עם סוכנים מרובים בעיבוד רציף
5. **הרצת זרימת עבודה** - הפעלת זרימת העבודה עם תוצאות סטרימינג

### 🚀 הרצת הדוגמה

```bash
# הפוך את הסקריפט להרצה (יוניקס/לינוקס/מק)
chmod +x 01.dotnet-agent-framework-workflow-ghmodel-basic.cs

# הפעל את זרימת העבודה
./01.dotnet-agent-framework-workflow-ghmodel-basic.cs
```

```powershell

```
