# 🔀 זרימות עבודה מותנות לסוכנים עם Microsoft Foundry (.NET)

## 📋 מדריך זרימת עבודה חכמה מבוססת החלטות

פנקס עבודה זה ממחיש **תבניות זרימות עבודה מותנות** באמצעות Microsoft Foundry ומסגרת סוכני Microsoft עבור .NET. תלמד כיצד לבנות זרימות עבודה מתוחכמות, מונעות החלטות, המנתבות בעזרת חוכמה עיבוד על בסיס ניתוח בינה מלאכותית, כללי עסק ותנאים דינמיים לאוטומציה ברמת ארגון.

## 💻 הפעלת הקוד

היישום המלא זמין ב־`04.dotnet-agent-framework-workflow-aifoundry-condition.cs`. זה ממחיש **זרימת עבודה לייצור תוכן עם שערי איכות**:

### 🏗️ **ארכיטקטורת זרימת עבודה**

```
Content Outline → Draft Creation → Quality Review → Conditional Routing:
                                                      ├─ Approved (>200 words) → Publish
                                                      └─ Rejected (<200 words) → Review Notification
```

**סוכנים בזרימת העבודה:**
1. **Evangelist Agent**: יוצר טיוטות הדרכה מתוך מתארים עם עיגון Bing
2. **Content Reviewer Agent**: מעריך איכות טיוטות (כמות מילים, שלמות)
3. **Publisher Agent**: שומר תוכן מאושר כקבצי Markdown עם חותמת זמן

**מבצעים מותאמים אישית:**
1. **DraftExecutor**: מארגן יצירת טיוטות
2. **ContentReviewExecutor**: מבצע הערכת איכות
3. **PublishExecutor**: מטפל בפרסום תוכן מאושר
4. **SendReviewExecutor**: מנהל התראות על תוכן שנדחה

### 🔍 הבנת לוגיקה מותנית

**פונקציית תנאי:**
```csharp
public Func<object?, bool> GetCondition(string expectedResult) =>
    reviewResult => reviewResult is ReviewResult review && review.Result == expectedResult;
```

פונקציה זו יוצרת פרדיקט אשר:
1. בודקת אם התוצאה היא מסוג `ReviewResult`
2. משווה את תכונת `Result` לערך הצפוי
3. מחזירה אמת/שקר לקביעת הניתוב

**קצוות זרימת עבודה עם תנאים:**
```csharp
.AddEdge(contentReviewerExecutor, publishExecutor, condition: GetCondition("Yes"))
.AddEdge(contentReviewerExecutor, sendReviewerExecutor, condition: GetCondition("No"))
```

// Define response structure
public class ReviewResult

// Apply to agent
ResponseFormat = ChatResponseFormat.ForJsonSchema(
