# 🔍 RAG ארגוני עם Microsoft Foundry (.NET)

## 📋 מטרות הלמידה

פנקס זה ממחיש כיצד לבנות מערכות Retrieval-Augmented Generation (RAG) ברמת ארגון באמצעות Microsoft Agent Framework ב-.NET עם Microsoft Foundry. תלמד כיצד ליצור סוכנים מוכנים לייצור שיכולים לחפש במסמכים ולספק תגובות מדויקות, מודעות הקשר, עם אבטחה וקנה מידה ארגוניים.

**יכולות RAG ארגוניות שתבנה:**
- 📚 **אינטליגנציה למסמכים**: עיבוד מתקדם של מסמכים עם שירותי Azure AI
- 🔍 **חיפוש סמנטי**: חיפוש וקטורי בעל ביצועים גבוהים עם תכונות ארגוניות
- 🛡️ **אינטגרציית אבטחה**: גישות מבוססות תפקיד וניהול הגנת נתונים
- 🏢 **ארכיטקטורה מדרגית**: מערכות RAG מוכנות לייצור עם ניטור

## 🎯 ארכיטקטורת RAG ארגונית

### רכיבי ליבה ארגוניים
- **Microsoft Foundry**: פלטפורמת AI מנוהלת עם אבטחה ועמידה ברגולציה
- **סוכנים מתמשכים**: סוכנים שמורים עם היסטוריית שיחות וניהול הקשר

- **אינטגרציית זהות**: אימות Azure AD וניהול גישת מבוסס תפקיד

### יתרונות .NET ארגוניים
- **בטיחות טיפוס**: אימות בזמן קומפילציה לפעולות RAG ומבני נתונים

- **ניהול זיכרון**: שימוש יעיל במשאבים לאוספי מסמכים גדולים
- **דפוסי אינטגרציה**: אינטגרציה ילידית לשירותי Azure עם הזרקת תלות

## 🏗️ ארכיטקטורה טכנית

### צינור RAG ארגוני
```
Document Upload → Security Validation → Vector Processing → Index Creation
                      ↓                    ↓                  ↓
User Query → Authentication → Semantic Search → Context Ranking → AI Response
```

### רכיבי ליבה ב-.NET
- **Azure.AI.Agents.Persistent**: ניהול סוכנים ארגוניים עם שמירת מצב
- **Azure.Identity**: אימות משולב לגישה מאובטחת לשירותי Azure
- **Microsoft.Agents.AI.AzureAI**: יישום מסגרת סוכנים מותאמת ל-Azure
- **System.Linq.Async**: פעולות LINQ אסינכרוניות בעלות ביצועים גבוהים
