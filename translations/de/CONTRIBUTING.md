# Beiträge

Dieses Projekt freut sich über Beiträge und Vorschläge. Die meisten Beiträge erfordern, dass Sie einer Contributor License Agreement (CLA) zustimmen, in der Sie erklären, dass Sie das Recht haben und tatsächlich gewähren, uns die Rechte zur Nutzung Ihres Beitrags einzuräumen. Für Details besuchen Sie <https://cla.opensource.microsoft.com>.

Wenn Sie eine Pull-Anfrage einreichen, wird ein CLA-Bot automatisch feststellen, ob Sie eine CLA bereitstellen müssen, und die Pull-Anfrage entsprechend kennzeichnen. Befolgen Sie die Anweisungen des Bots. Dies müssen Sie nur einmal für Repositories tun, die die Microsoft CLA verwenden.

## Richtlinien für Pull-Anfragen

- Halten Sie jede Pull-Anfrage auf eine logische Änderung fokussiert.
- Testen Sie betroffene Notebooks und Codebeispiele vor dem Einreichen.
- Aktualisieren Sie die relevante Lektionendokumentation beim Hinzufügen oder Ändern eines Beispiels.
- Bearbeiten Sie nur englische Quellinhalte. Übersetzungen werden durch den automatisierten Übersetzungsworkflow gepflegt.
- Committen Sie keine Zugangsdaten, `.env`-Dateien, temporären Dateien oder generierten Entwicklungsartefakte.

## Redaktioneller Umfang und Produkte von Drittanbietern

Dieses Curriculum konzentriert sich auf Microsoft-Technologien und herstellerneutrale offene Standards. Beiträge sollten einem klaren Bildungszweck dienen und dürfen nicht in erster Linie dazu bestimmt sein, ein kommerzielles Drittanbieterprodukt, gehosteten Dienst, Model-Router, SDK, MCP-Server oder anderes herstellerspezifisches Angebot einzuführen oder zu bewerben.

Open-Source-Software und Drittanbieterabhängigkeiten dürfen referenziert werden, wenn sie notwendig sind, um einen offenen Standard oder Interoperabilitätsszenario zu erklären, neutral dargestellt werden und nicht im Mittelpunkt eines Herstellerprodukts oder gehosteten Endpunkts stehen. Wenn Ihr vorgeschlagener Beitrag ein herstellerspezifisches Produkt oder einen Dienst beinhaltet, eröffnen Sie ein Issue und holen Sie die Zustimmung der Maintainer ein, bevor Sie eine Pull-Anfrage einreichen.

Beiträger müssen jede relevante Beschäftigung, Eigentümerschaft, Sponsoring oder andere Verbindung zu einem in ihrem Beitrag referenzierten Produkt oder Dienst offenlegen. Fügen Sie keine unbelegten Preis-, Leistungs-, Sicherheits-, Datenschutz- oder Vergleichsaussagen hinzu. Ausführbare Beispiele dürfen standardmäßig keine Lerndaten übertragen oder öffentliche Aktionen über einen externen Drittanbieterdienst ausführen.
