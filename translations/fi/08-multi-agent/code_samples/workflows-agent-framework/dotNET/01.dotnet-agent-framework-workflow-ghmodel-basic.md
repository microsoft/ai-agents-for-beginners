# 🔄 Perusagenttien työnkulut Azure OpenAI:n kanssa (Responses API) (.NET)

## 📋 Työnkulun orkestroinnin opas

Tämä muistikirja näyttää, miten rakennetaan kehittyneitä **agenttien työnkulkuja** Microsoft Agent Frameworkin .NET-versiolla ja Azure OpenAI:lla (Responses API). Opit luomaan monivaiheisia liiketoimintaprosesseja, joissa tekoälyagentit tekevät yhteistyötä suorittaakseen monimutkaisia tehtäviä rakenteellisten orkestrointimallien avulla.

## 🎯 Oppimistavoitteet

### 🏗️ **Työnkulun arkkitehtuurin perusteet**
- **Workflow Builder**: Suunnittele ja orkestroi monimutkaisia monivaiheisia tekoälyprosesseja
- **Agenttien koordinointi**: Koordinoi useita erikoistuneita agentteja työnkuluissa
- **Azure OpenAI (Responses API)**: Hyödynnä Azure OpenAI Responses API:ta työnkuluissa
- **Visuaalinen työnkulun suunnittelu**: Luo ja visualisoi työnkulkurakenteita paremman ymmärryksen saamiseksi

### 🔄 **Prosessien orkestrointimallit**
- **Järjestyksessä tapahtuva käsittely**: Ketjuta useita agenttien tehtäviä loogisessa järjestyksessä
- **Tilan hallinta**: Säilytä konteksti ja tietovirta työnkulun vaiheiden välillä
- **Virheiden hallinta**: Toteuta vahva virheiden palautus ja työnkulun kestävyys
- **Suorituskyvyn optimointi**: Suunnittele tehokkaita työnkulkia yritystason toimintoihin

### 🏢 **Yritysten työnkulun sovellukset**
- **Liiketoimintaprosessien automatisointi**: Automatisoi monimutkaisia organisaation työnkulkuja
- **Sisällöntuotannon putki**: Toimitukselliset työnkulut tarkastus- ja hyväksymisvaiheineen
- **Asiakaspalvelun automaatio**: Monivaiheinen asiakaskyselyjen ratkaisu
- **Tietojenkäsittelyn työnkulut**: ETL-työnkulut tekoälyllä tehostettuun muunnokseen

## ⚙️ Esivaatimukset ja asennus

### 📦 **Tarvittavat NuGet-paketit**

Tämä työnkulun demonstrointi käyttää useita keskeisiä .NET-paketteja:

```xml
<!-- Core AI Framework -->
<PackageReference Include="Microsoft.Extensions.AI" Version="9.9.0" />

<!-- Azure OpenAI (Responses API) -->
<PackageReference Include="Azure.AI.OpenAI" Version="2.1.0" />
<PackageReference Include="Azure.Identity" Version="1.13.1" />

<!-- Agent Framework (Local Development) -->
<!-- Microsoft.Agents.AI.dll - Core agent abstractions -->
<!-- Microsoft.Agents.AI.OpenAI.dll - Azure OpenAI (Responses API) integration -->

<!-- Configuration and Environment -->
<PackageReference Include="DotNetEnv" Version="3.1.1" />
```

### 🔑 **Azure OpenAI:n asetukset**

**Ympäristöasetukset (.env tiedosto):**
```env
AZURE_OPENAI_ENDPOINT=https://<your-resource>.openai.azure.com
AZURE_OPENAI_DEPLOYMENT=gpt-4o-mini
```

**Azure OpenAI -käyttö:**
1. Luo Azure OpenAI -resurssi Azure-portaalissa
2. Ota käyttöön malli (esim. `gpt-4o-mini`) ja muista käyttöönoton nimi
3. Kirjaudu sisään `az login` -komennolla ja määritä ympäristömuuttujat kuten yllä

### 🏗️ **Työnkulun arkkitehtuurin yleiskatsaus**

```mermaid
graph TD
    A[Työnkulun rakentaja] --> B[Agenttirekisteri]
    B --> C[Työnkulun suoritusmoottori]
    C --> D[Agent 1: Sisällön luoja]
    C --> E[Agent 2: Sisällön tarkastaja] 
    D --> F[Työnkulun tulokset]
    E --> F
    G[Azure OpenAI (Vastaus-API)] --> D
    G --> E
```

**Keskeiset komponentit:**
- **WorkflowBuilder**: Pääorkestrointimoottori työnkulkujen suunnitteluun
- **AIAgent**: Yksittäiset erikoistuneet agentit tiettyine kykyineen
- **Azure OpenAI Client**: Azure OpenAI Responses API -integraatio
- **Suorituskonteksti**: Hallitsee tilaa ja tietovirtaa työnkulun vaiheiden välillä

## 💻 Koodin suorittaminen

Täysi toteutus löytyy tiedostosta `01.dotnet-agent-framework-workflow-ghmodel-basic.cs`. Tämä tiedosto näyttää:

1. **Ympäristöasetukset** – Azure OpenAI -asetusten lataaminen `.env` tiedostosta
2. **Azure OpenAI -asiakkaan asennus** – Asiakkaan määrittely Azure OpenAI Responses API:n käyttöön
3. **Agenttien luonti** – Erikoistuneiden agenttien määrittely (Vastaanotto ja Concierge)
4. **Workflow Builder** – Moniagenttinen työnkulku järjestyksellisellä käsittelyllä
5. **Työnkulun suoritus** – Työnkulun ajaminen tulosten striimauksella

### 🚀 Esimerkin ajaminen

```bash
# Tee skriptistä suoritettava (Unix/Linux/macOS)
chmod +x 01.dotnet-agent-framework-workflow-ghmodel-basic.cs

# Suorita työnkulku
./01.dotnet-agent-framework-workflow-ghmodel-basic.cs
```

Tai Windowsilla:
```powershell
dotnet run 01.dotnet-agent-framework-workflow-ghmodel-basic.cs
```

### 📝 Odotettu tulos

Työnkulku:
1. Ottaa vastaan matkakohdepyyntösi ("Haluaisin mennä Pariisiin")
2. Vastaanottoagentti antaa alkuperäisen suosituksen
3. Concierge-agentti tarkistaa ja hienosäätää suosituksen
4. Lopullinen tulos näyttää koko keskustelun striimin
