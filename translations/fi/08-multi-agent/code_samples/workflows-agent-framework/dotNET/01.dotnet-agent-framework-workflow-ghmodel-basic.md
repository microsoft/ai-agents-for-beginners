# 🔄 Perusagenttien työnkulut Azure OpenAI:n kanssa (Responses API) (.NET)

## 📋 Työnkulun orkestroinnin opas

Tämä muistikirja havainnollistaa, miten rakentaa monimutkaisia **agenttien työnkulkuja** Microsoft Agent Frameworkin .NET-versiolla ja Azure OpenAI:lla (Responses API). Opit luomaan monivaiheisia liiketoimintaprosesseja, joissa tekoälyagentit tekevät yhteistyötä suorittaakseen monimutkaisia tehtäviä rakenteellisten orkestrointimallien avulla.

## 🎯 Oppimistavoitteet

### 🏗️ **Työnkulun arkkitehtuurin perusteet**
- **Työnkulun rakentaja**: Suunnittele ja orkestraa monimutkaisia monivaiheisia tekoälyprosesseja
- **Agenttien koordinointi**: Koordinoi useita erikoistuneita agentteja työnkuluissa
- **Azure OpenAI (Responses API)**: Hyödynnä Azure OpenAI Responses API:a työnkuluissa
- **Visuaalinen työnkulun suunnittelu**: Luo ja visualisoi työnkulkujen rakenteita paremman ymmärryksen saamiseksi

### 🔄 **Prosessin orkestrointimallit**
- **Peräkkäinen käsittely**: Ketjuta useita agenttitehtäviä loogisessa järjestyksessä
- **Tilanhallinta**: Ylläpidä kontekstia ja tietovirtaa työnkulun vaiheiden välillä
- **Virheenkäsittely**: Toteuta vankka virheiden palautus ja työnkulun vakaus
- **Suorituskyvyn optimointi**: Suunnittele tehokkaita työnkulkuja yritystason toimintoihin

### 🏢 **Yritystason työnkulkujen sovellukset**
- **Liiketoimintaprosessien automaatio**: Automatisoi monimutkaisia organisaation työnkulkuja
- **Sisällöntuotantoputki**: Toimitukselliset työnkulut, joissa on tarkistus- ja hyväksymisvaiheet
- **Asiakaspalvelun automaatio**: Monivaiheinen asiakaskyselyiden ratkaisu
- **Tietojenkäsittelyn työnkulut**: ETL-työnkulut tekoälyn voimalla tapahtuvalla transformaatiolla

## ⚙️ Vaatimukset ja käyttöönotto

### 📦 **Vaaditut NuGet-paketit**

Tämä työnkulun esittely käyttää useita keskeisiä .NET-paketteja:

```xml
<!-- Core AI Framework -->
<PackageReference Include="Microsoft.Extensions.AI" Version="10.*" />

<!-- Azure OpenAI (Responses API) -->
<PackageReference Include="Azure.AI.OpenAI" Version="2.1.0" />
<PackageReference Include="Azure.Identity" Version="1.15.0" />

<!-- Agent Framework (Local Development) -->
<!-- Microsoft.Agents.AI.dll - Core agent abstractions -->
<!-- Microsoft.Agents.AI.OpenAI.dll - Azure OpenAI (Responses API) integration -->

<!-- Configuration and Environment -->
<PackageReference Include="DotNetEnv" Version="3.1.1" />
```

### 🔑 **Azure OpenAI:n määritykset**

**Ympäristön asetukset (.env-tiedosto):**
```env
AZURE_OPENAI_ENDPOINT=https://<your-resource>.openai.azure.com
AZURE_OPENAI_DEPLOYMENT=gpt-5-mini
```

**Azure OpenAI -pääsy:**
1. Luo Azure OpenAI -resurssi Azure-portaaliin
2. Ota käyttöön malli (esimerkiksi `gpt-5-mini`) ja kirjaa käyttöönoton nimi ylös
3. Kirjaudu sisään `az login` -komennolla ja määritä ympäristömuuttujat edellä kuvatulla tavalla

### 🏗️ **Työnkulun arkkitehtuurin yleiskatsaus**

```mermaid
graph TD
    A[Työnkulun rakentaja] --> B[Agenttirekisteri]
    B --> C[Työnkulun suoritusmoottori]
    C --> D[Agent 1: Sisällön luoja]
    C --> E[Agent 2: Sisällön tarkastaja] 
    D --> F[Työnkulun tulokset]
    E --> F
    G[Azure OpenAI (Vastaus-API)] --> D
    G --> E
```

**Keskeiset komponentit:**
- **WorkflowBuilder**: Pääorkestrointimoottori työnkulkujen suunnitteluun
- **AIAgent**: Yksittäiset, erikoistuneet agentit tiettyine kykyineen
- **Azure OpenAI Client**: Azure OpenAI Responses API -integraatio
- **Execution Context**: Hallinnoi tilaa ja tietovirtaa työnkulun vaiheiden välillä

## 💻 Koodin suoritus

Täydellinen toteutus löytyy tiedostosta `01.dotnet-agent-framework-workflow-ghmodel-basic.cs`. Tämä tiedosto havainnollistaa:

1. **Ympäristön määritys** - Azure OpenAI -määrityksen lataaminen `.env`-tiedostosta
2. **Azure OpenAI Clientin asetukset** - Asiakkaan määritys Azure OpenAI Responses API:n käyttöön
3. **Agenttien luonti** - Erikoistuneiden agenttien määrittely (Front Desk ja Concierge)
4. **Työnkulun rakentaja** - Moniagenttisen työnkulun luominen peräkkäisellä käsittelyllä
5. **Työnkulun suoritus** - Työnkulun ajo siinä käytettävän virtaustulostuksen kanssa

### 🚀 Esimerkin suoritus

```bash
# Tee skriptistä suoritettava (Unix/Linux/macOS)
chmod +x 01.dotnet-agent-framework-workflow-ghmodel-basic.cs

# Suorita työnkulku
./01.dotnet-agent-framework-workflow-ghmodel-basic.cs
```

Tai Windowsilla:
```powershell
dotnet run 01.dotnet-agent-framework-workflow-ghmodel-basic.cs
```

### 📝 Odotettu tulos

Työnkulku:
1. Ottaa vastaan matkakohteesi pyynnön ("Haluaisin mennä Pariisiin")
2. Front Desk -agentti antaa alkuperäisen suosituksen
3. Concierge-agentti tarkistaa ja hioo suositusta
4. Lopputuloksena näytetään koko keskusteluvälineen virtaus

### 🔧 Mukauttaminen

Voit mukauttaa työnkulkua:
- Muokkaamalla agenttien ohjeita niiden käyttäytymisen muuttamiseksi
- Lisäämällä agentteja luomaan monimutkaisempia monivaiheisia työnkulkuja
- Muuttamalla käyttäjän viestiä erilaisten skenaarioiden testaamiseksi
- Säätämällä työnkulun reunoja luodaksesi erilaisia suorituskäytäntöjä
