# ⏩ Peräkkäiset agenttien työnkulut Azure OpenAI:n (Responses API) kanssa (.NET)

## 📋 Kehittynyt peräkkäisen käsittelyn opas

Tämä muistikirja näyttää esimerkkejä **peräkkäisistä työnkulkujen malleista** käyttämällä Microsoft Agent Frameworkia .NET:lle ja Azure OpenAI:ta (Responses API). Opit rakentamaan kehittyneitä, vaiheittain eteneviä käsittelyputkia, joissa agentit suorittavat tehtäviä tietyssä järjestyksessä ja jokainen vaihe rakentuu edellisen vaiheen tulosten päälle.

## 🎯 Oppimistavoitteet

### 🔄 **Peräkkäisen käsittelyn arkkitehtuuri**
- **Lineaarinen työnkulun suunnittelu**: Luo vaiheittaiset käsittelyputket, joissa on selkeät riippuvuudet
- **Tilanhallinta**: Säilytä konteksti ja tietovirta koko peräkkäisen työnkulun ajan
- **Azure OpenAI (Responses API)**: Hyödynnä Azure OpenAI -malleja monivaiheisissa .NET-työnkuluissa
- **Yritystason putkimallit**: Rakenna tuotantovalmiita peräkkäisiä käsittelyjärjestelmiä

### 🏗️ **Kehittyneet peräkkäiset mallit**
- **Vaiheporttien käsittely**: Toteuta validointitarkastuspisteitä työnkulun vaiheiden välillä
- **Kontekstin säilytys**: Säilytä tila ja kertynyt tieto kaikkien vaiheiden yli
- **Virheiden etenemisen hallinta**: Käsittele virheitä ripeästi peräkkäisissä käsittelyketjuissa
- **Suorituskyvyn optimointi**: Tehokas peräkkäinen suoritus minimihäviöin

### 🏢 **Yritystason peräkkäiset sovellukset**
- **Asiakirjakäsittelyputki**: Monivaiheinen asiakirjojen analyysi, muokkaus ja validointi
- **Laatutarkastusprosessit**: Peräkkäinen tarkastus, validointi ja hyväksyntä
- **Sisällöntuotantoputki**: Tutkimus → Kirjoitus → Muokkaus → Tarkastus → Julkaisu
- **Liiketoimintaprosessien automaatio**: Monivaiheiset liiketoiminnan työnkulut selkeillä vaiheriippuvuuksilla

## ⚙️ Esivaatimukset ja asetukset

### 📦 **Vaatimustenmukaiset NuGet-paketit**

Olennaiset paketit .NET-peräkkäisille työnkuluille:

```xml
<!-- Core AI Framework -->
<PackageReference Include="Microsoft.Extensions.AI" Version="9.9.0" />

<!-- Azure OpenAI (Responses API) -->

<!-- Azure Identity and Async LINQ Support -->
<PackageReference Include="Azure.Identity" Version="1.15.0" />
<PackageReference Include="System.Linq.Async" Version="6.0.3" />

<!-- Local Agent Framework References -->
<!-- Microsoft.Agents.AI.dll - Core agent abstractions -->
<!-- Microsoft.Agents.AI.OpenAI.dll - Azure OpenAI (Responses API) integration -->
```

### 🔑 **Azure OpenAI määritykset**

**Ympäristön asetukset (.env-tiedosto):**
```env
AZURE_OPENAI_ENDPOINT=https://<your-resource>.openai.azure.com
AZURE_OPENAI_DEPLOYMENT=gpt-4o-mini
```

**Konfiguraation hallinta:**
```csharp
// Load environment variables securely
Env.Load("../../../.env");
var azureEndpoint = Environment.GetEnvironmentVariable("AZURE_OPENAI_ENDPOINT");
var deployment = Environment.GetEnvironmentVariable("AZURE_OPENAI_DEPLOYMENT");
```

### 🏗️ **Peräkkäisen työnkulun arkkitehtuuri**

```mermaid
graph TD
    A[Initial Input] --> B[Stage 1: Analyysiavustaja]
    B --> C[Tarkistuspiste 1]
    C --> D[Stage 2: Käsittelyavustaja]
    D --> E[Tarkistuspiste 2]
    E --> F[Stage 3: Vahvistusavustaja]
    F --> G[Loppulähtö]
```

**Keskeiset komponentit:**
- **Peräkkäiset agentit**: Erikoistuneet agentit jokaiselle käsittelyvaiheelle

- **Tarkastuspisteet**: Validointipisteet vaiheiden välillä laadun ja johdonmukaisuuden varmistamiseksi
- **Azure OpenAI -asiakas**: Johdonmukainen pääsy tekoälymalleihin kaikissa työnkulun vaiheissa

## 💻 Koodin suorittaminen

Täydellinen toteutus löytyy tiedostosta `02.dotnet-agent-framework-workflow-ghmodel-sequential.cs`. Tämä tiedosto näyttää **kolmivaiheisen huonekaluanalyysin työnkulun**:

1. **Vaihe 1 - Myyntiagentti**: Analysoi huonekalukuvia ja antaa ostoehdotuksia
2. **Vaihe 2 - Hinta-agentti**: Antaa tarkan hintajakautuman ja budjettivaihtoehdot
3. **Vaihe 3 - Tarjousagentti**: Laatii ammatillisen tarjousasiakirjan Markdown-muodossa

### 🏗️ **Työnkulun arkkitehtuuri**

```
Image Input → Sales Analysis → Price Estimation → Quote Generation → Final Output
```

Jokainen agentti:
- Vastaanottaa edellisen vaiheen tuloksen kontekstina
- Rakentaa aikaisempaan analyysiin erikoisosaamisellaan
- Säilyttää työnkulun jatkuvuuden tilanhallinnan avulla

### 🚀 Esimerkin suorittaminen

**Esivaatimukset:**
- Sijoita huonekalukuva polkuun `../imgs/home.png` (tai päivitä `imgPath`-muuttuja)
- Määritä `.env`-tiedostosi Azure OpenAI -päätepisteellä ja käyttöönotolla, ja kirjaudu sisään `az login` -komennolla

```bash
# Tee skriptistä suoritettava (Unix/Linux/macOS)
chmod +x 02.dotnet-agent-framework-workflow-ghmodel-sequential.cs

# Suorita peräkkäinen työnkulku
./02.dotnet-agent-framework-workflow-ghmodel-sequential.cs
```

Tai Windowsilla:
```powershell
dotnet run 02.dotnet-agent-framework-workflow-ghmodel-sequential.cs
```

### 📝 Odotettu tulos

Työnkulku tekee seuraavaa:
1. **Myyntiagentti**: Tunnistaa kuvan huonekalut ja antaa suosituksia
2. **Hinta-agentti**: Lisää tarkan hintakäsittelyn budjettitasoilla ja ostosuosituksilla
3. **Tarjousagentti**: Laatii muotoillun tarjousasiakirjan kaikilla tiedoilla yhteen koottuna

Lopputuloksena on kattava, ammatillinen huonekalutarjous kuvan analyysin perusteella.

```csharp
var workflow = new WorkflowBuilder(salesagent)
```

### 🔍 Tilavirran ymmärtäminen

Jokainen agentti sarjassa saa:
- **Alkuperäisen syötteen**: Käyttäjän alkuperäisen viestin (kuva + teksti)
- **Edellisten agenttien vastaukset**: Kaikki aiemmat agenttien vastaukset keskusteluhistoriassa
- **Kertynyt konteksti**: Koko työnkulun ajan ylläpidetty tila

Tämä mahdollistaa kehittyneen monivaiheisen käsittelyn, jossa jokainen agentti rakentaa laajan kontekstin päälle kaikista aikaisemmista vaiheista.
