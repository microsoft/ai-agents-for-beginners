## Tapahtuman nimi: Monen agentin API LangGraphilla ja Azure Cosmos DB:llä

## Kuvaus

Monen agentin tekoälysovellusten nousu muuttaa tapaa, jolla rakennamme älykkäitä järjestelmiä — mutta miten suunnittelet ne todellisen maailman skaalautuvuutta ja suorituskykyä varten? Tässä sessiossa sukellamme tuotantotason monen agentin sovellukseen, joka on rakennettu LangGraphilla agenttien orkestrointiin, FastAPI:lla API-kerrokseksi ja Azure Cosmos DB:llä tilanhallinnan, vektorisäilytyksen ja transaktiodatan selkärangaksi.

Yksityiskohtaisen koodikävelyn kautta näet, miten suunnitella ja toteuttaa agenttivetoista työnkulkua, joka saumattomasti yhdistää retrieval-augmented generationin (RAG), muistipersistenssin ja dynaamiset tilasiirtymät. Käymme läpi:

Agenttien yhteistyö LangGraphin avulla jäsennettyyn päättelyyn
Reaaliaikainen chat-historian tallennus Azure Cosmos DB:llä — sama tietokanta, joka mahdollistaa ChatGPT:n chat-historian, historian nopeimmin kasvavan tekoälyagenttisovelluksen
Vektorihaut tiedonhakuun Cosmos DB:n natiivilla upotustuesta
FastAPI:n asynkroniset ominaisuudet pitämään vuorovaikutukset responsiivisina ja skaalautuvina
Session lopussa sinulla on selkeä suunnitelma oman skaalautuvan, pilvessä toimivan monen agentin sovelluksesi rakentamiseen ja käyttöönottoon, hyödyntäen modernin tekoälyn ja pilvi-infrastruktuurin voimaa. Olitpa tekoälyinsinööri, pilviarkkitehti tai Python-kehittäjä, tämä puhe antaa sinulle käytännöllisiä oivalluksia ja kokeneita malleja seuraavan sukupolven tekoälyllä varustettujen sovellusten rakentamiseen.

## Tapahtuman nimi: Prompttaus on uusi skriptien kirjoitus: Tutustu GenAIScriptiin

## Kuvaus

jQuery teki aikoinaan web-kehityksen helpommaksi abstraktoimalla monimutkaisuudet pois, sallien kehittäjien keskittyä rakentamiseen selainten outouksien sijaan. Nykyään tekoälyn kehitys kohtaa saman haasteen. Uusia malleja syntyy jatkuvasti ja pysyminen mukana voi olla ylivoimaista, etenkin kun tekoäly työkalut — erityisesti agenttityyppiset — muuttuvat tehokkaammiksi ja monimutkaisemmiksi. Entä jos voisit hyödyntää huipputeknologiaa tehtävien automatisointiin käyttämällä yksinkertaisia, tuttuja JavaScript-abstraktioita? Esittelemme GenAIScriptin — tavan integroida tekoäly työnkulkuusi vaivattomasti, kohtelemalla promtteja uudelleenkäytettävinä koodinpätkinä. Tässä puheessa tutkimme, miten GenAIScript tekee tekoälyautomaatiosta yhtä intuitiivista kuin JavaScriptin kirjoittamisesta, auttaen sinua virtaviivaistamaan toistuvaa työtä ilman syvällistä tekoälyosaamista.
