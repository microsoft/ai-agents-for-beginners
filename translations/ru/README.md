> В этом репозитории есть переводы на 50+ языков, что значительно увеличивает размер загрузки. Чтобы клонировать репозиторий без переводов, используйте разреженную загрузку:
>
> **Bash / macOS / Linux:**
> ```bash
> git clone --filter=blob:none --sparse https://github.com/microsoft/ai-agents-for-beginners.git
> cd ai-agents-for-beginners
> git sparse-checkout set --no-cone '/*' '!translations' '!translated_images'
> ```
>
> **CMD (Windows):**
> ```cmd
> git clone --filter=blob:none --sparse https://github.com/microsoft/ai-agents-for-beginners.git
> cd ai-agents-for-beginners
> git sparse-checkout set --no-cone "/*" "!translations" "!translated_images"
> ```
>
> Это даст вам все необходимое для прохождения курса с гораздо более быстрой загрузкой.

## 🌱 Начало работы

Этот курс содержит уроки, охватывающие основы создания агентов ИИ. Каждый урок посвящён своей теме, так что начинайте с любого!

Для этого курса предусмотрена поддержка нескольких языков. Перейдите к списку доступных языков [здесь](#-multi-language-support). 

Если вы впервые работаете с генеративными моделями ИИ, ознакомьтесь с нашим курсом [Generative AI For Beginners](https://aka.ms/genai-beginners), который включает 21 урок по созданию с помощью GenAI.

Не забудьте [поставить звезду (🌟) этому репозиторию](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst) и [форкнуть этот репозиторий](https://github.com/microsoft/ai-agents-for-beginners/fork) для запуска кода.

### Познакомьтесь с другими учащимися, получите ответы на вопросы

Если у вас возникнут трудности или вопросы по созданию агентов ИИ, присоединяйтесь к нашему специализированному Discord-каналу в [Microsoft Foundry Discord](https://aka.ms/ai-agents/discord).

### Что вам понадобится 

Каждый урок этого курса включает примеры кода, которые можно найти в папке code_samples. Вы можете [форкнуть этот репозиторий](https://github.com/microsoft/ai-agents-for-beginners/fork), чтобы создать собственную копию.  

Примеры кода в этих упражнениях используют Microsoft Agent Framework с Microsoft Foundry Agent Service V2:

- [Microsoft Foundry](https://aka.ms/ai-agents-beginners/ai-foundry) - необходим аккаунт Azure

В этом курсе используются следующие фреймворки и сервисы агентов ИИ от Microsoft:

- [Microsoft Agent Framework (MAF)](https://learn.microsoft.com/agent-framework/overview/)
- [Microsoft Foundry Agent Service V2](https://aka.ms/ai-agents-beginners/ai-agent-service)

Некоторые примеры кода также поддерживают альтернативных провайдеров, совместимых с OpenAI, таких как [MiniMax](https://platform.minimaxi.com/), который предлагает модели с большим контекстом (до 204 тыс. токенов). Подробнее о настройке см. в разделе [Course Setup](./00-course-setup/README.md).

Для получения дополнительной информации о запуске кода курса перейдите в раздел [Course Setup](./00-course-setup/README.md).
