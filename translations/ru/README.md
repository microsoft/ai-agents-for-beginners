>
> **Bash / macOS / Linux:**
> ```bash
> git clone --filter=blob:none --sparse https://github.com/microsoft/ai-agents-for-beginners.git
> cd ai-agents-for-beginners
> git sparse-checkout set --no-cone '/*' '!translations' '!translated_images'
> ```
>
> **CMD (Windows):**
> ```cmd
> git clone --filter=blob:none --sparse https://github.com/microsoft/ai-agents-for-beginners.git
> cd ai-agents-for-beginners
> git sparse-checkout set --no-cone "/*" "!translations" "!translated_images"
> ```
>
> Это даст вам всё необходимое для прохождения курса с гораздо более быстрой загрузкой.

## 🌱 Начало работы

В этом курсе есть уроки, охватывающие основы создания AI Агентов. Каждый урок посвящён своей теме, так что начинайте с любого!

Для этого курса доступна многоязычная поддержка. Посетите [здесь доступные языки](#-multi-language-support). 

Если вы создаёте модели генеративного ИИ впервые, ознакомьтесь с нашим курсом [Генеративный ИИ для начинающих](https://aka.ms/genai-beginners), который включает 21 урок по работе с GenAI.

Не забудьте [поставить звезду (🌟) этому репозиторию](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst) и [форкнуть его](https://github.com/microsoft/ai-agents-for-beginners/fork), чтобы запустить код.

### Встречайте других учеников, получайте ответы на свои вопросы

Если у вас возникнут трудности или вопросы по созданию AI Агентов, присоединяйтесь к нашему специализированному каналу Discord в [Microsoft Foundry Discord](https://aka.ms/ai-agents/discord).

### Что вам нужно

Каждый урок этого курса включает примеры кода, которые можно найти в папке code_samples. Вы можете [форкнуть этот репозиторий](https://github.com/microsoft/ai-agents-for-beginners/fork), чтобы создать свою копию.  

Примеры кода в этих упражнениях используют Microsoft Agent Framework с Microsoft Foundry Agent Service V2:

- [Microsoft Foundry](https://aka.ms/ai-agents-beginners/ai-foundry) - Требуется аккаунт Azure

В этом курсе используются следующие фреймворки и сервисы AI Агентов от Microsoft:

- [Microsoft Agent Framework (MAF)](https://learn.microsoft.com/agent-framework/overview/)
- [Microsoft Foundry Agent Service V2](https://aka.ms/ai-agents-beginners/ai-agent-service)

Некоторые примеры кода также поддерживают альтернативных провайдеров, совместимых с OpenAI, таких как [MiniMax](https://platform.minimaxi.com/), который предлагает модели с большим контекстом (до 204K токенов). Подробнее о настройке в разделе [Course Setup](./00-course-setup/README.md).

Для получения дополнительной информации о запуске кода этого курса перейдите в раздел [Course Setup](./00-course-setup/README.md).
