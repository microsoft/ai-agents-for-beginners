> В этом репозитории более 50 языков переводов, что значительно увеличивает размер скачивания. Чтобы клонировать без переводов, используйте sparse checkout:
>
> **Bash / macOS / Linux:**
> ```bash
> git clone --filter=blob:none --sparse https://github.com/microsoft/ai-agents-for-beginners.git
> cd ai-agents-for-beginners
> git sparse-checkout set --no-cone '/*' '!translations' '!translated_images'
> ```
>
> **CMD (Windows):**
> ```cmd
> git clone --filter=blob:none --sparse https://github.com/microsoft/ai-agents-for-beginners.git
> cd ai-agents-for-beginners
> git sparse-checkout set --no-cone "/*" "!translations" "!translated_images"
> ```
>
> Это даст вам все необходимое для прохождения курса с гораздо более быстрой загрузкой.

## 🌱 Начало работы

Этот курс включает уроки, охватывающие основы создания AI Агентов. Каждый урок посвящён своей теме, так что начинайте с любого!

Для этого курса существует многоязычная поддержка. Посмотрите [доступные языки здесь](#-multi-language-support). 

Если вы впервые работаете с генеративными AI-моделями, посмотрите наш курс [Generative AI For Beginners](https://aka.ms/genai-beginners), который включает 21 урок по созданию с помощью GenAI.

Не забудьте [поставить звёздочку (🌟) этому репозиторию](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst) и [сделать форк репозитория](https://github.com/microsoft/ai-agents-for-beginners/fork) для запуска кода.

### Познакомьтесь с другими учащимися, получите ответы на ваши вопросы

Если вы застряли или у вас есть вопросы по созданию AI Агентов, присоединяйтесь к нашему специализированному Discord-каналу в [Microsoft Foundry Discord](https://aka.ms/ai-agents/discord).

### Что вам понадобится 

Каждый урок в этом курсе включает примеры кода, которые можно найти в папке code_samples. Вы можете [сделать форк репозитория](https://github.com/microsoft/ai-agents-for-beginners/fork), чтобы создать свою копию.  

Примеры кода в этих упражнениях используют Microsoft Agent Framework с Microsoft Foundry Agent Service V2:

- [Microsoft Foundry](https://aka.ms/ai-agents-beginners/ai-foundry) - Требуется аккаунт Azure

Этот курс использует следующие фреймворки и сервисы AI Агентов от Microsoft:

- [Microsoft Agent Framework (MAF)](https://learn.microsoft.com/agent-framework/overview/)
- [Microsoft Foundry Agent Service V2](https://aka.ms/ai-agents-beginners/ai-agent-service)

Некоторые примеры кода также поддерживают альтернативных провайдеров совместимых с OpenAI, таких как [MiniMax](https://platform.minimaxi.com/), который предлагает модели с большим контекстом (до 204K токенов). См. [Course Setup](./00-course-setup/README.md) для деталей конфигурации.

Для дополнительной информации по запуску кода этого курса перейдите в раздел [Course Setup](./00-course-setup/README.md).
