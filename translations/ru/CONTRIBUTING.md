# Вклад в проект

Этот проект приветствует вклады и предложения. Для большинства вкладов требуется согласие с Лицензионным соглашением участника (Contributor License Agreement, CLA), в котором вы подтверждаете, что имеете право и действительно предоставляете нам права на использование вашего вклада. Подробнее смотрите на <https://cla.opensource.microsoft.com>.

Когда вы отправляете pull request, бот CLA автоматически определит, нужно ли вам предоставить CLA, и оформит pull request соответствующим образом. Следуйте инструкциям, которые предоставит бот. Вам нужно будет сделать это только один раз для всех репозиториев, использующих Microsoft CLA.

## Кодекс поведения

Этот проект принял [Кодекс поведения Microsoft Open Source](https://opensource.microsoft.com/codeofconduct/). Для дополнительной информации смотрите [Часто задаваемые вопросы по Кодексу поведения](https://opensource.microsoft.com/codeofconduct/faq/) или свяжитесь с [opencode@microsoft.com](mailto:opencode@microsoft.com) для вопросов или комментариев.

## Руководство по pull request

- Сосредотачивайте каждый pull request на одном логическом изменении.
- Тестируйте затронутые ноутбуки и примеры кода перед отправкой.
- Обновляйте соответствующую документацию урока при добавлении или изменении примера.
- Редактируйте только исходный контент на английском языке. Переводы поддерживаются автоматическим процессом перевода.
- Не добавляйте учетные данные, `.env` файлы, временные файлы или сгенерированные артефакты разработки.

## Тематический охват и сторонние продукты

Этот учебный курс сосредоточен на технологиях Microsoft и нейтральных открытых стандартах. Вклады должны иметь четкую образовательную цель и не должны быть преимущественно предназначены для внедрения или продвижения стороннего коммерческого продукта, облачного сервиса, маршрутизатора модели, SDK, сервера MCP или другого специфичного для вендора предложения.

Открытое программное обеспечение и сторонние зависимости могут упоминаться, когда они необходимы для объяснения открытого стандарта или сценария взаимодействия, представляются нейтрально и не являются центром внимания продукта или облачного сервиса вендора. Если ваш предложенный вклад включает продукт или сервис конкретного вендора, создайте issue и получите одобрение мейнтейнера перед отправкой pull request.

Участники должны раскрывать любую релевантную занятость, владение, спонсорство или другую аффилиацию с продуктом или сервисом, упомянутым в их вкладе. Не включайте неподтвержденные утверждения о ценах, производительности, безопасности, конфиденциальности или сравнении. Исполняемые примеры по умолчанию не должны передавать данные обучающихся или выполнять публичные действия через сторонние внешние сервисы.
