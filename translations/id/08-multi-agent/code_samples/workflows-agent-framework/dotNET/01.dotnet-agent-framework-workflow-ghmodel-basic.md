# 🔄 Alur Kerja Agen Dasar dengan Azure OpenAI (Responses API) (.NET)

## 📋 Tutorial Orkestrasi Alur Kerja

Notebook ini menunjukkan cara membangun **alur kerja agen** yang canggih menggunakan Microsoft Agent Framework untuk .NET dan Azure OpenAI (Responses API). Anda akan belajar membuat proses bisnis multi-langkah di mana agen AI berkolaborasi untuk menyelesaikan tugas kompleks melalui pola orkestrasi yang terstruktur.

## 🎯 Tujuan Pembelajaran

### 🏗️ **Dasar-dasar Arsitektur Alur Kerja**
- **Pembuat Alur Kerja**: Merancang dan mengorkestrasi proses AI multi-langkah yang kompleks
- **Koordinasi Agen**: Mengkoordinasikan beberapa agen khusus dalam alur kerja
- **Azure OpenAI (Responses API)**: Memanfaatkan Azure OpenAI Responses API dalam alur kerja
- **Desain Alur Kerja Visual**: Membuat dan memvisualisasikan struktur alur kerja untuk pemahaman yang lebih baik

### 🔄 **Pola Orkestrasi Proses**
- **Pemrosesan Berurutan**: Menghubungkan beberapa tugas agen secara berurutan
- **Manajemen Status**: Mempertahankan konteks dan aliran data di seluruh tahapan alur kerja
- **Penanganan Kesalahan**: Mengimplementasikan pemulihan kesalahan yang kokoh dan ketahanan alur kerja
- **Optimisasi Kinerja**: Merancang alur kerja yang efisien untuk operasi skala perusahaan

### 🏢 **Aplikasi Alur Kerja Perusahaan**
- **Otomasi Proses Bisnis**: Mengotomatiskan alur kerja organisasi yang kompleks
- **Pipeline Produksi Konten**: Alur kerja editorial dengan tahap tinjau dan persetujuan
- **Otomasi Layanan Pelanggan**: Penyelesaian pertanyaan pelanggan multi-langkah
- **Alur Kerja Pemrosesan Data**: Alur kerja ETL dengan transformasi berbasis AI

```xml
<!-- Configuration and Environment -->
<PackageReference Include="DotNetEnv" Version="3.1.1" />
```

### 🔑 **Konfigurasi Azure OpenAI**

**Pengaturan Lingkungan (file .env):**
```env
AZURE_OPENAI_ENDPOINT=https://<your-resource>.openai.azure.com
AZURE_OPENAI_DEPLOYMENT=gpt-4o-mini
```

**Akses Azure OpenAI:**
1. Buat resource Azure OpenAI di portal Azure
2. Terapkan sebuah model (misalnya, `gpt-4o-mini`) dan catat nama deployment
3. Masuk dengan `az login` dan konfigurasikan variabel lingkungan seperti yang ditunjukkan di atas

**Komponen Kunci:**
- **WorkflowBuilder**: Mesin orkestrasi utama untuk merancang alur kerja
- **AIAgent**: Agen spesialisasi individu dengan kemampuan khusus
- **Klien Azure OpenAI**: Integrasi Azure OpenAI Responses API
- **Execution Context**: Mengelola status dan aliran data antar tahapan alur kerja

## 💻 Menjalankan Kode

Implementasi lengkap tersedia dalam `01.dotnet-agent-framework-workflow-ghmodel-basic.cs`. File ini menunjukkan:

1. **Konfigurasi Lingkungan** - Memuat konfigurasi Azure OpenAI dari file `.env`
2. **Pengaturan Klien Azure OpenAI** - Mengonfigurasi klien untuk menggunakan Azure OpenAI Responses API
3. **Pembuatan Agen** - Mendefinisikan agen khusus (Front Desk dan Concierge)
4. **Pembuat Alur Kerja** - Membuat alur kerja multi-agen dengan pemrosesan berurutan
5. **Eksekusi Alur Kerja** - Menjalankan alur kerja dengan hasil streaming

### 🚀 Menjalankan Contoh

```bash
# Buat skrip dapat dieksekusi (Unix/Linux/macOS)
chmod +x 01.dotnet-agent-framework-workflow-ghmodel-basic.cs

# Jalankan alur kerja
./01.dotnet-agent-framework-workflow-ghmodel-basic.cs
```

Atau di Windows:
```powershell
dotnet run 01.dotnet-agent-framework-workflow-ghmodel-basic.cs
```

### 📝 Output yang Diharapkan

Alur kerja akan:
1. Menerima permintaan tujuan perjalanan Anda ("Saya ingin pergi ke Paris")
2. Agen Front Desk memberikan rekomendasi awal
3. Agen Concierge meninjau dan menyempurnakan rekomendasi
4. Output akhir menampilkan aliran percakapan lengkap
