# 기여하기

이 프로젝트는 기여와 제안을 환영합니다. 대부분의 기여는 기여자가 자신의 기여를 사용할 권한을 실제로 가지고 있음을 선언하는 기여자 라이선스 계약(CLA)에 동의해야 합니다. 자세한 내용은 <https://cla.opensource.microsoft.com>를 방문하세요.

풀 리퀘스트를 제출할 때, CLA 봇이 자동으로 CLA 제출 필요 여부를 판단하고 적절히 표시해 줍니다. 봇이 제공하는 지침을 따르세요. Microsoft CLA를 사용하는 저장소에서는 이 과정을 한 번만 수행하면 됩니다.

## 행동 강령

이 프로젝트는 [Microsoft 오픈 소스 행동 강령](https://opensource.microsoft.com/codeofconduct/)을 채택했습니다. 자세한 내용은 [행동 강령 FAQ](https://opensource.microsoft.com/codeofconduct/faq/)를 참조하거나 추가 질문이나 의견이 있으면 [opencode@microsoft.com](mailto:opencode@microsoft.com)으로 연락하세요.

## 풀 리퀘스트 가이드라인

- 각 풀 리퀘스트는 하나의 논리적 변경에 집중해 주세요.
- 제출 전에 관련 노트북과 코드 샘플을 테스트하세요.
- 예제를 추가하거나 변경할 때 관련 수업 문서를 업데이트하세요.
- 영어 원본 콘텐츠만 편집하세요. 번역은 자동 번역 워크플로우가 관리합니다.
- 자격 증명, `.env` 파일, 임시 파일, 생성된 개발 아티팩트를 커밋하지 마세요.

## 편집 범위 및 제삼자 제품

이 커리큘럼은 Microsoft 기술과 공급업체 중립 오픈 표준에 중점을 둡니다. 기여는 명확한 교육 목적을 가져야 하며, 제삼자 상업 제품, 호스팅 서비스, 모델 라우터, SDK, MCP 서버 또는 기타 공급업체 특정 제공물을 도입하거나 홍보하는 것이 주목적이어서는 안 됩니다.

오픈 소스 소프트웨어와 제삼자 종속성은 오픈 표준이나 상호 운용성 시나리오를 설명하는 데 필요하고, 중립적으로 제시되며, 특정 공급업체의 제품이나 호스팅 엔드포인트에 초점이 맞춰지지 않을 때 참조할 수 있습니다. 기여에 공급업체 특정 제품이나 서비스가 포함된다면, 풀 리퀘스트 제출 전에 이슈를 열고 유지 관리자 승인을 받으세요.

기여자는 자신의 기여에서 참조된 제품이나 서비스와 관련된 고용, 소유권, 후원 또는 기타 관계를 공개해야 합니다. 근거가 없는 가격, 성능, 보안, 개인정보 보호 또는 비교 주장 포함을 금지합니다. 실행 가능한 예제는 기본적으로 학습자 데이터를 전송하거나 외부 제삼자 서비스를 통한 공용 작업을 수행해서는 안 됩니다.
