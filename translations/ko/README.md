## 🌱 시작하기

이 강의 코스에는 AI 에이전트 구축의 기본을 다루는 수업들이 있습니다. 각 수업은 고유한 주제를 다루므로 원하는 곳부터 시작하세요!

이 코스는 다국어 지원이 제공됩니다. [여기에서 지원되는 언어](#-multi-language-support)를 확인하세요.

생성 AI 모델을 처음 사용한다면, 21개의 수업으로 구성된 [초보자를 위한 생성 AI](https://aka.ms/genai-beginners) 강의를 확인해 보세요.

이 저장소를 [별 표시(🌟) 하기](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst)와 [포크하기](https://github.com/microsoft/ai-agents-for-beginners/fork)를 잊지 마시고 코드를 실행하세요.

### 다른 학습자 만나기, 질문 답변 받기

AI 에이전트 구축에 대해 막히거나 궁금한 점이 있으면 [Microsoft Foundry Discord](https://aka.ms/ai-agents/discord)의 전용 Discord 채널에 참여하세요.

### 준비물

이 코스의 각 수업에는 코드 예제가 포함되어 있으며, 코드_samples 폴더에서 확인할 수 있습니다. 저장소를 [포크](https://github.com/microsoft/ai-agents-for-beginners/fork)하여 자신의 복사본을 만들 수 있습니다.

이 연습 문제의 코드 예제는 Microsoft Agent Framework와 Microsoft Foundry Agent Service V2를 사용합니다:

- [Microsoft Foundry](https://aka.ms/ai-agents-beginners/ai-foundry) - Azure 계정 필요

이 강의 코스에서는 Microsoft의 다음 AI 에이전트 프레임워크와 서비스를 사용합니다:

- [Microsoft Agent Framework (MAF)](https://learn.microsoft.com/agent-framework/overview/)
- [Microsoft Foundry Agent Service V2](https://aka.ms/ai-agents-beginners/ai-agent-service)

일부 코드 샘플은 204K 토큰까지 지원하는 대규모 컨텍스트 모델을 제공하는 [MiniMax](https://platform.minimaxi.com/)와 같은 OpenAI 호환 대체 제공자도 지원합니다. 설정 방법은 [Course Setup](./00-course-setup/README.md)을 참조하세요.

이 코스의 코드를 실행하는 방법에 대한 자세한 내용은 [Course Setup](./00-course-setup/README.md)을 참조하세요.
