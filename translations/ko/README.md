## 🌱 시작하기

이 강의는 AI 에이전트 구축의 기초를 다루는 수업들로 구성되어 있습니다. 각 수업은 자체 주제를 다루므로 원하는 곳에서 시작하세요!

이 강의는 다국어 지원을 제공합니다. [여기에서 지원 언어 목록](#-multi-language-support)을 확인하세요.

생성 AI 모델로 처음 구축하는 경우, 21개의 GenAI 구축 수업을 포함한 [초보자를 위한 생성 AI](https://aka.ms/genai-beginners) 강의를 확인하세요.

코드를 실행하려면 이 저장소에 [별 표시(🌟)](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst)를 하고 [포크](https://github.com/microsoft/ai-agents-for-beginners/fork)하는 것을 잊지 마세요.

### 다른 학습자와 만나고 질문에 답을 얻기

AI 에이전트 구축 중에 막히거나 궁금한 점이 있으면 [Microsoft Foundry Discord](https://aka.ms/ai-agents/discord) 내 전용 디스코드 채널에 참여하세요.

### 필요한 것

이 강의의 각 수업에는 코드 예제가 포함되어 있으며, code_samples 폴더에서 확인할 수 있습니다. 저장소를 [포크](https://github.com/microsoft/ai-agents-for-beginners/fork)하여 자신의 복사본을 만드세요.

연습에 사용된 코드 예제들은 Microsoft Agent Framework와 Microsoft Foundry Agent Service V2를 활용합니다:

- [Microsoft Foundry](https://aka.ms/ai-agents-beginners/ai-foundry) - Azure 계정 필요

이 강의에서는 Microsoft의 다음 AI 에이전트 프레임워크 및 서비스를 사용합니다:

- [Microsoft Agent Framework (MAF)](https://learn.microsoft.com/agent-framework/overview/)
- [Microsoft Foundry Agent Service V2](https://aka.ms/ai-agents-beginners/ai-agent-service)

일부 코드 예제는 대규모 컨텍스트 모델(최대 204K 토큰)을 제공하는 [MiniMax](https://platform.minimaxi.com/)와 같은 OpenAI 호환 대체 공급자도 지원합니다. 설정 세부사항은 [강의 설정](./00-course-setup/README.md)을 참조하세요.

이 강의 코드를 실행하는 자세한 내용은 [강의 설정](./00-course-setup/README.md)을 참고하세요.
