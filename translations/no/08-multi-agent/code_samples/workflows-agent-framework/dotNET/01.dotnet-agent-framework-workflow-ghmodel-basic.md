# 🔄 Grunnleggende agentarbeidsflyter med Azure OpenAI (Responses API) (.NET)

## 📋 Veiledning for arbeidsflytorkestrering

Denne notatblokken demonstrerer hvordan man bygger sofistikerte **agentarbeidsflyter** ved å bruke Microsoft Agent Framework for .NET og Azure OpenAI (Responses API). Du vil lære å opprette flertrinns forretningsprosesser hvor AI-agenter samarbeider for å utføre komplekse oppgaver gjennom strukturerte orkestreringsmønstre.

## 🎯 Læringsmål

### 🏗️ **Grunnleggende arbeidsflytarkitektur**
- **Workflow Builder**: Design og orkestrering av komplekse flertrinns AI-prosesser
- **Agentkoordinasjon**: Koordinere flere spesialiserte agenter innen arbeidsflyter
- **Azure OpenAI (Responses API)**: Benytte Azure OpenAI Responses API i arbeidsflyter
- **Visuell arbeidsflytdesign**: Lage og visualisere arbeidsflytstrukturer for bedre forståelse

### 🔄 **Orkestreringsmønstre for prosesser**
- **Sekvensiell behandling**: Kjede flere agentoppgaver i logisk rekkefølge
- **Tilstandsadministrasjon**: Opprettholde kontekst og datstrøm gjennom arbeidsflytens stadier
- **Feilhåndtering**: Implementere robust feilgjenoppretting og arbeidsflytresiliens
- **Ytelsesoptimalisering**: Designe effektive arbeidsflyter for virksomhetsnivåoperasjoner

### 🏢 **Virksomhetsapplikasjoner for arbeidsflyt**
- **Automatisering av forretningsprosesser**: Automatisere komplekse organisatoriske arbeidsflyter
- **Innholdsproduksjonspipeline**: Redaksjonelle arbeidsflyter med gjennomgangs- og godkjenningsstadier
- **Automatisering av kundeservice**: Flertrinns kundehåndtering
- **Databehandlingsarbeidsflyter**: ETL-arbeidsflyter med AI-drevet transformasjon

## ⚙️ Forutsetninger og oppsett

### 📦 **Nødvendige NuGet-pakker**

Denne arbeidsflytdemonstrasjonen bruker flere sentrale .NET-pakker:

```xml
<!-- Core AI Framework -->
<PackageReference Include="Microsoft.Extensions.AI" Version="9.9.0" />

<!-- Azure OpenAI (Responses API) -->
<PackageReference Include="Azure.AI.OpenAI" Version="2.1.0" />
<PackageReference Include="Azure.Identity" Version="1.13.1" />

<!-- Agent Framework (Local Development) -->
<!-- Microsoft.Agents.AI.dll - Core agent abstractions -->
<!-- Microsoft.Agents.AI.OpenAI.dll - Azure OpenAI (Responses API) integration -->

<!-- Configuration and Environment -->
<PackageReference Include="DotNetEnv" Version="3.1.1" />
```

### 🔑 **Azure OpenAI-konfigurasjon**

**Miljøoppsett (.env-fil):**
```env
AZURE_OPENAI_ENDPOINT=https://<your-resource>.openai.azure.com
AZURE_OPENAI_DEPLOYMENT=gpt-4o-mini
```

**Azure OpenAI-tilgang:**
1. Opprett en Azure OpenAI-ressurs i Azure-portalen
2. Distribuer en modell (for eksempel `gpt-4o-mini`) og noter distribusjonsnavnet
3. Logg inn med `az login` og konfigurer miljøvariabler som vist ovenfor

**Nøkkelkomponenter:**

- **Execution Context**: Administrerer tilstand og datstrøm mellom arbeidsflytens stadier

## 💻 Kjøre koden

Hele implementeringen er tilgjengelig i `01.dotnet-agent-framework-workflow-ghmodel-basic.cs`. Denne filen demonstrerer:

1. **Miljøkonfigurasjon** - Laste Azure OpenAI-konfigurasjon fra `.env`-fil
2. **Oppsett av Azure OpenAI-klient** - Konfigurere klienten til å bruke Azure OpenAI Responses API
3. **Opprettelse av agenter** - Definere spesialiserte agenter (Front Desk og Concierge)
4. **Workflow Builder** - Lage en fleragent arbeidsflyt med sekvensiell prosessering
5. **Arbeidsflytutførelse** - Kjøre arbeidsflyten med strømmende resultater

### 🚀 Kjøre eksemplet

```bash
# Gjør skriptet kjørbart (Unix/Linux/macOS)
chmod +x 01.dotnet-agent-framework-workflow-ghmodel-basic.cs

# Kjør arbeidsflyten
./01.dotnet-agent-framework-workflow-ghmodel-basic.cs
```

Eller på Windows:
```powershell
dotnet run 01.dotnet-agent-framework-workflow-ghmodel-basic.cs
```

### 📝 Forventet utdata

Arbeidsflyten vil:
1. Akseptere din reisemålsforespørsel ("Jeg vil gjerne reise til Paris")
2. Front Desk-agenten gir en første anbefaling
3. Concierge-agenten gjennomgår og forbedrer anbefalingen
4. Endelig utdata viser hele samtalestrømmen
