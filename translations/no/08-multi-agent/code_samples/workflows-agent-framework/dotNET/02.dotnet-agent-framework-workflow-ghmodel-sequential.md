# ⏩ Sekvensielle agentarbeidsflyter med Azure OpenAI (Responses API) (.NET)

## 📋 Avansert veiledning for sekvensiell behandling

Denne notatboken demonstrerer **sekvensielle arbeidsflytmønstre** ved bruk av Microsoft Agent Framework for .NET og Azure OpenAI (Responses API). Du vil lære hvordan du bygger sofistikerte, trinnvise behandlingspipelines der agenter utfører i en bestemt rekkefølge, der hvert trinn bygger videre på resultatene fra det forrige trinnet.

- **Feilspredning**: Håndter feil på en ryddig måte i sekvensielle behandlingskjeder

## 💻 Kjøre koden

Hele implementasjonen er tilgjengelig i `02.dotnet-agent-framework-workflow-ghmodel-sequential.cs`. Denne filen demonstrerer en **trettrinns møbelanalyse-arbeidsflyt**:

1. **Trinn 1 - Salgsagent**: Analyserer møbelbilder og gir kjøpsforslag
2. **Trinn 2 - Prisagent**: Gir detaljert prisoversikt og budsjettalternativer
3. **Trinn 3 - Tilbudsagent**: Genererer et profesjonelt tilbudsdokument i Markdown-format

### 🏗️ **Arbeidsflytarkitektur**

```
Image Input → Sales Analysis → Price Estimation → Quote Generation → Final Output
```

Hver agent:
- Mottar utdata fra forrige trinn som kontekst
- Bygger videre på forrige analyse med spesialisert ekspertise
- Opprettholder arbeidsflytkontinuitet gjennom tilstandsadministrasjon

### 🚀 Kjøre eksemplet

**Forutsetninger:**
- Plasser et møbelbilde på `../imgs/home.png` (eller oppdater variabelen `imgPath`)
- Konfigurer `.env`-filen din med Azure OpenAI-endepunktet og distribusjonen, og logg inn med `az login`

```bash
# Gjør skriptet kjørbart (Unix/Linux/macOS)
chmod +x 02.dotnet-agent-framework-workflow-ghmodel-sequential.cs

# Kjør den sekvensielle arbeidsflyten
./02.dotnet-agent-framework-workflow-ghmodel-sequential.cs
```

Eller på Windows:
```powershell
dotnet run 02.dotnet-agent-framework-workflow-ghmodel-sequential.cs
```

### 📝 Forventet output

Arbeidsflyten vil:
1. **Salgsagent**: Identifisere møbelartikler fra bildet og gi anbefalinger
2. **Prisagent**: Legge til detaljert prisanalyse med budsjettnivåer og kjøpsanbefalinger
3. **Tilbudsagent**: Generere et formatert tilbudsdokument med all informasjon syntetisert

Den endelige outputen vil være et omfattende, profesjonelt møbeltilbud basert på bildeanalysen.
