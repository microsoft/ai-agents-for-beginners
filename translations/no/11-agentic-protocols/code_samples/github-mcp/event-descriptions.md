## Arrangementnavn: Multi-Agent API med LangGraph og Azure Cosmos DB

## Beskrivelse

Fremveksten av multi-agent AI-applikasjoner forvandler måten vi bygger intelligente systemer på – men hvordan arkitekterer man dem for reell skalerbarhet og ytelse? I denne økten tar vi et dypdykk i en produksjonsklar multi-agent applikasjon bygget med LangGraph for agentorkestrering, FastAPI for et API-lag, og Azure Cosmos DB som ryggraden for tilstandsadministrasjon, vektorlager og transaksjonsdata.

Gjennom en detaljert kodegjennomgang vil du se hvordan man designer og implementerer en agentdrevet arbeidsflyt som sømløst integrerer hentetilleggsgenerering (RAG), minnepersistens og dynamiske tilstandsoversettelser. Vi vil dekke:

Agent-samarbeid med LangGraph for strukturert resonnering
Lagring av chatthistorikk i sanntid ved bruk av Azure Cosmos DB – den samme databasen som driver chatthistorikken i ChatGPT, den raskest voksende AI-agent-applikasjonen i historien
Vektorsøk for kunnskapsgjenfinning med Cosmos DBs innebygde støtte for embeddinger
FastAPIs asynkrone kapasiteter for å holde interaksjoner responsive og skalerbare
Innen slutten av denne økten vil du ha en klar plan for å bygge og distribuere dine egne skalerbare, sky-native multi-agent applikasjoner som utnytter kraften i moderne AI og skyinfrastruktur. Enten du er AI-ingeniør, skysarkitekt eller Python-utvikler, vil dette foredraget gi deg praktiske innsikter og prøvde mønstre for å bygge neste generasjons AI-drevne applikasjoner.
