# Wkład

Ten projekt z radością przyjmuje wkład i sugestie. Większość wkładów wymaga zgody na Umowę Licencyjną Współtwórcy (CLA), która potwierdza, że masz prawo, i faktycznie udzielasz nam praw do korzystania z twojego wkładu. Szczegóły znajdziesz na <https://cla.opensource.microsoft.com>.

Gdy wyślesz pull request, bot CLA automatycznie sprawdzi, czy musisz dostarczyć CLA i odpowiednio oznaczy pull request. Postępuj zgodnie z instrukcjami bota. Będziesz musiał to zrobić tylko raz dla repozytoriów korzystających z Microsoft CLA.

## Kodeks Postępowania

Ten projekt przyjął [Microsoft Open Source Code of Conduct](https://opensource.microsoft.com/codeofconduct/). Po więcej informacji zobacz [Code of Conduct FAQ](https://opensource.microsoft.com/codeofconduct/faq/) lub skontaktuj się pod adresem [opencode@microsoft.com](mailto:opencode@microsoft.com) w razie dodatkowych pytań lub uwag.

## Wytyczne dotyczące pull requestów

- Każdy pull request powinien skupiać się na jednej logicznej zmianie.
- Przetestuj zmienione notatniki i przykłady kodu przed wysłaniem.
- Zaktualizuj odpowiednią dokumentację lekcji przy dodawaniu lub zmienianiu przykładu.
- Edytuj tylko angielską zawartość źródłową. Tłumaczenia są utrzymywane przez zautomatyzowany proces tłumaczeń.
- Nie dodawaj poświadczeń, plików `.env`, plików tymczasowych ani generowanych artefaktów rozwojowych.

## Zakres redakcyjny i produkty firm trzecich

Ten program nauczania koncentruje się na technologiach Microsoft i neutralnych standardach otwartych. Wkłady powinny służyć jasnemu celowi edukacyjnemu i nie mogą mieć na celu przede wszystkim wprowadzenia lub promocji komercyjnego produktu firm trzecich, usługi hostingowej, modelu routera, SDK, serwera MCP ani innej oferty specyficznej dla dostawcy.

Oprogramowanie open-source i zależności firm trzecich mogą być przywoływane, gdy są niezbędne do wyjaśnienia otwartego standardu lub scenariusza interoperacyjności, są prezentowane neutralnie i nie koncentrują się na produkcie dostawcy lub jego hostowanym punkcie końcowym. Jeśli Twój proponowany wkład zawiera produkt lub usługę specyficzną dla dostawcy, otwórz issue i uzyskaj zgodę opiekuna przed wysłaniem pull requesta.

Współtwórcy muszą ujawnić wszelkie istotne zatrudnienie, własność, sponsorowanie lub inne powiązania z produktem lub usługą wymienioną w ich wkładzie. Nie zamieszczaj niepopartych roszczeń dotyczących cen, wydajności, bezpieczeństwa, prywatności ani porównań. Przykłady wykonywalne nie powinny domyślnie przesyłać danych uczestnika ani wykonywać publicznych akcji przez zewnętrzną usługę firm trzecich.
