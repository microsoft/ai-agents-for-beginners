## Evenementnaam: Multi-Agent API met LangGraph en Azure Cosmos DB

## Beschrijving

De opkomst van multi-agent AI-toepassingen transformeert hoe we intelligente systemen bouwen - maar hoe ontwerp je ze voor schaalbaarheid en prestaties in de echte wereld? In deze sessie duiken we diep in een productieklare multi-agent applicatie gebouwd met LangGraph voor agent orchestratie, FastAPI als API-laag, en Azure Cosmos DB als ruggengraat voor statusbeheer, vectoropslag en transactionele data.

Via een gedetailleerde code walkthrough zie je hoe je een agent-gedreven workflow ontwerpt en implementeert die retrieval-augmented generation (RAG), geheugenpersistentie en dynamische statusovergangen naadloos integreert. We behandelen:

Agent samenwerking met LangGraph voor gestructureerde redenering
Real-time opslag van chatgeschiedenis met Azure Cosmos DB - dezelfde database die de chatgeschiedenis in ChatGPT aandrijft, de snelst groeiende AI-agent applicatie ooit
Vectorzoekopdrachten voor kennisopvraging met Cosmos DB's native ondersteuning voor embeddings
FastAPI’s async mogelijkheden om interacties responsief en schaalbaar te houden
Aan het einde van deze sessie heb je een duidelijk plan om je eigen schaalbare, cloud-native multi-agent applicaties te bouwen en te implementeren die gebruikmaken van moderne AI en cloudinfrastructuur. Of je nu AI-engineer, cloudarchitect of Python-ontwikkelaar bent, deze talk biedt praktische inzichten en beproefde patronen om de volgende generatie AI-gedreven applicaties te bouwen.
