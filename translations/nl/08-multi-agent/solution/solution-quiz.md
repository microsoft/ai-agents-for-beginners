# Antwoorden Kenniscontrole

## Vraag 1

**Antwoord: A2.** Meerdere agenten zijn nuttig wanneer een taak duidelijke specialistische rollen heeft, aparte tools of machtigingen, en duidelijke overdrachten die coördinatie vereisen. Een eenvoudige ondersteuningsbot kan meestal een enkele agent blijven. Een groot aantal identieke verzoeken is vooral een schaalbaarheidskwestie en vereist op zichzelf geen multi-agent ontwerp.

## Vraag 2

**Antwoord: A1.** Een enkele agent is meestal gemakkelijker te testen, observeren en te bedienen wanneer één set instructies en tools de taak kan afhandelen. Toegang tot meerdere tools vereist niet automatisch meerdere agenten. Gescheiden rollen met verschillende machtigingen en auditvereisten kunnen een multi-agent ontwerp rechtvaardigen.
