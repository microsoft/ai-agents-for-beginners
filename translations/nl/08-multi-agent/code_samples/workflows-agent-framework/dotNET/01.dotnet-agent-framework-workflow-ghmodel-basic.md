# 🔄 Basis Agent-workflows met Azure OpenAI (Responses API) (.NET)

## 📋 Workflow Orkestratie Tutorial

Dit notitieboek laat zien hoe je geavanceerde **agent-workflows** bouwt met het Microsoft Agent Framework voor .NET en Azure OpenAI (Responses API). Je leert multi-staps bedrijfsprocessen te creëren waar AI-agenten samenwerken om complexe taken te voltooien via gestructureerde orkestratiepatronen.

## 🎯 Leerdoelen

### 🏗️ **Fundamenten Workflow Architectuur**
- **Workflow Builder**: Ontwerp en orkestreer complexe multi-staps AI-processen
- **Agentcoördinatie**: Coördineer meerdere gespecialiseerde agenten binnen workflows
- **Azure OpenAI (Responses API)**: Maak gebruik van de Azure OpenAI Responses API in workflows
- **Visueel Workflowontwerp**: Creëer en visualiseer workflowstructuren voor beter begrip

### 🔄 **Proces Orkestratiepatronen**
- **Sequentiële verwerking**: Koppel meerdere agenttaken in logische volgorde aan elkaar
- **Statusbeheer**: Behoud context en datastroom over workflowfases heen
- **Foutafhandeling**: Implementeer robuuste foutherstel en workflowresistentie
- **Prestatieoptimalisatie**: Ontwerp efficiënte workflows voor bedrijfsbrede operaties

### 🏢 **Enterprise Workflow Toepassingen**
- **Bedrijfsprocesautomatisering**: Automatiseer complexe organisatorische workflows
- **Content Productiepijplijn**: Redactionele workflows met review- en goedkeuringsfasen
- **Klantenserviceautomatisering**: Multi-staps klantenverzoekafhandeling
- **Dataverwerkingsworkflows**: ETL-workflows met AI-gestuurde transformatie

### 🔑 **Azure OpenAI Configuratie**

**Omgevingssetup (.env-bestand):**
```env
AZURE_OPENAI_ENDPOINT=https://<your-resource>.openai.azure.com
AZURE_OPENAI_DEPLOYMENT=gpt-4o-mini
```

**Toegang Azure OpenAI:**
1. Maak een Azure OpenAI resource aan in het Azure-portaal
2. Deploy een model (bijvoorbeeld `gpt-4o-mini`) en noteer de deploymentnaam
3. Log in met `az login` en configureer omgevingsvariabelen zoals hierboven getoond

## 💻 De Code Uitvoeren

De volledige implementatie is beschikbaar in `01.dotnet-agent-framework-workflow-ghmodel-basic.cs`. Dit bestand laat zien:

1. **Omgevingsconfiguratie** - Laden van Azure OpenAI-configuratie vanuit `.env` bestand
2. **Azure OpenAI Client Setup** - Configureren van de client voor gebruik van Azure OpenAI Responses API
3. **Agent Creatie** - Definiëren van gespecialiseerde agenten (Front Desk en Concierge)
4. **Workflow Builder** - Creëren van een multi-agent workflow met sequentiële verwerking
5. **Workflow Executie** - Uitvoeren van de workflow met streaming resultaten

### 🚀 Het Voorbeeld Uitvoeren

```bash
# Maak het script uitvoerbaar (Unix/Linux/macOS)
chmod +x 01.dotnet-agent-framework-workflow-ghmodel-basic.cs

# Voer de workflow uit
./01.dotnet-agent-framework-workflow-ghmodel-basic.cs
```

Of op Windows:
```powershell
dotnet run 01.dotnet-agent-framework-workflow-ghmodel-basic.cs
```

### 📝 Verwachte Output

De workflow zal:
1. Je reisbestemming verzoek accepteren ("Ik zou graag naar Parijs willen gaan")
2. De Front Desk-agent geeft een eerste aanbeveling
3. De Concierge-agent bekijkt en verfijnt de aanbeveling
4. De eindoutput toont de volledige conversatiestroom
