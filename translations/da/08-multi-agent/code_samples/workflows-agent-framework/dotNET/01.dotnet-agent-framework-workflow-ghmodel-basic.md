# 🔄 Grundlæggende Agentarbejdsgange med Azure OpenAI (Responses API) (.NET)

## 📋 Workflow Orkestrering Tutorial

Denne notesbog demonstrerer, hvordan man bygger sofistikerede **agentarbejdsgange** ved hjælp af Microsoft Agent Framework for .NET og Azure OpenAI (Responses API). Du vil lære at skabe flertrins forretningsprocesser, hvor AI-agenter samarbejder om at løse komplekse opgaver gennem strukturerede orkestreringsmønstre.

## 🎯 Læringsmål

### 🏗️ **Grundlæggende workflowarkitektur**
- **Workflow Builder**: Design og orkestrer komplekse flertrins AI-processer
- **Agentkoordinering**: Koordiner flere specialiserede agenter inden for arbejdsgange
- **Azure OpenAI (Responses API)**: Udnyt Azure OpenAI Responses API i arbejdsgange
- **Visuelt workflowdesign**: Opret og visualiser workflowstrukturer for bedre forståelse

### 🔄 **Process Orkestreringsmønstre**
- **Sekventiel behandling**: Kæd flere agentopgaver i logisk rækkefølge
- **Tilstandsadministration**: Oprethold kontekst og dataflow på tværs af workflowfaser
- **Fejlhåndtering**: Implementer robust fejlgendannelse og workflowresiliens
- **Ydelsesoptimering**: Design effektive arbejdsgange til virksomhedsskala

### 🏢 **Virksomhedsarbejdsgange**
- **Forretningsprocesautomatisering**: Automatiser komplekse organisatoriske arbejdsgange
- **Indholdsproduktionspipeline**: Redaktionelle arbejdsgange med gennemgangs- og godkendelsesfaser
- **Kundeserviceautomatisering**: Flertrins kundespørgselsløsning
- **Databehandlingsarbejdsgange**: ETL-arbejdsgange med AI-drevet transformation

```xml
<!-- Configuration and Environment -->
<PackageReference Include="DotNetEnv" Version="3.1.1" />
```

### 🔑 **Azure OpenAI-konfiguration**

**Miljøopsætning (.env-fil):**
```env
AZURE_OPENAI_ENDPOINT=https://<your-resource>.openai.azure.com
AZURE_OPENAI_DEPLOYMENT=gpt-4o-mini
```

**Azure OpenAI-adgang:**
1. Opret en Azure OpenAI-ressource i Azure-portalen
2. Udrul en model (for eksempel `gpt-4o-mini`) og bemærk udrulningsnavnet
3. Log ind med `az login` og konfigurer miljøvariabler som vist ovenfor

## 💻 Kørsel af koden

Den komplette implementering findes i `01.dotnet-agent-framework-workflow-ghmodel-basic.cs`. Denne fil demonstrerer:

1. **Miljøkonfiguration** – Indlæsning af Azure OpenAI-konfiguration fra `.env`-fil
2. **Azure OpenAI-klientopsætning** – Konfiguration af klienten til at bruge Azure OpenAI Responses API
3. **Agentoprettelse** – Definition af specialiserede agenter (Front Desk og Concierge)
4. **Workflow Builder** – Oprettelse af et multi-agent workflow med sekventiel behandling
5. **Workflowudførelse** – Kørsel af workflowet med streamingresultater

### 🚀 Kør eksemplet

```bash
# Gør scriptet eksekverbart (Unix/Linux/macOS)
chmod +x 01.dotnet-agent-framework-workflow-ghmodel-basic.cs

# Kør arbejdsprocessen
./01.dotnet-agent-framework-workflow-ghmodel-basic.cs
```

Eller på Windows:
```powershell
dotnet run 01.dotnet-agent-framework-workflow-ghmodel-basic.cs
```

### 📝 Forventet output

Workflowet vil:
1. Modtage din rejseanmodning ("Jeg vil gerne til Paris")
2. Front Desk-agenten giver en indledende anbefaling
3. Concierge-agenten gennemgår og raffinerer anbefalingen
4. Det endelige output viser hele samtalestrømmen
