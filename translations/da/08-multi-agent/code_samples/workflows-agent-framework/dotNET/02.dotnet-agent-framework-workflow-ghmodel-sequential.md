# ⏩ Sekventielle Agentarbejdsgange med Azure OpenAI (Responses API) (.NET)

## 📋 Avanceret Sekventiel Behandlingsvejledning

Denne notesbog demonstrerer **sekventielle arbejdsgangsmønstre** ved brug af Microsoft Agent Framework for .NET og Azure OpenAI (Responses API). Du lærer, hvordan du bygger sofistikerede, trin-for-trin behandlingspipelines, hvor agenter udfører i en specifik rækkefølge, hvor hvert trin bygger videre på resultaterne fra det foregående trin.

## 💻 Kørsel af Koden

Den komplette implementering findes i `02.dotnet-agent-framework-workflow-ghmodel-sequential.cs`. Denne fil demonstrerer en **tretrins møbelanalyse-arbejdsgang**:

1. **Trin 1 - Salgsagent**: Analyserer møbelbilleder og giver købsforslag
2. **Trin 2 - Prisagent**: Giver detaljerede prisopdelinger og budgetmuligheder
3. **Trin 3 - Tilbudsagent**: Genererer et professionelt tilbudsdokument i Markdown-format

### 🏗️ **Arbejdsgangsarkitektur**

```
Image Input → Sales Analysis → Price Estimation → Quote Generation → Final Output
```

Hver agent:
- Modtager output fra det foregående trin som kontekst
- Bygger videre på tidligere analyse med specialiseret ekspertise
- Vedligeholder arbejdsgangs-kontinuitet gennem tilstandsstyring

### 🚀 Kørsel af Eksemplet

**Forudsætninger:**
- Placer et møbelbillede ved `../imgs/home.png` (eller opdater `imgPath`-variablen)
- Konfigurer din `.env`-fil med din Azure OpenAI-endpoint og deployment, og log derefter ind med `az login`

```bash
# Gør scriptet eksekverbart (Unix/Linux/macOS)
chmod +x 02.dotnet-agent-framework-workflow-ghmodel-sequential.cs

# Kør den sekventielle arbejdsgang
./02.dotnet-agent-framework-workflow-ghmodel-sequential.cs
```

Eller på Windows:
```powershell
dotnet run 02.dotnet-agent-framework-workflow-ghmodel-sequential.cs
```

### 📝 Forventet Output

Arbejdsgangen vil:
1. **Salgsagent**: Identificere møbelgenstande fra billedet og give anbefalinger
2. **Prisagent**: Tilføje detaljeret prisanalyse med budgetniveauer og indkøbsanbefalinger
3. **Tilbudsagent**: Generere et formateret tilbudsdokument med al information samlet

Det endelige output vil være et omfattende, professionelt møbeltilbud baseret på billedanalyse.

### 🔍 Forståelse af Tilstandsflow

Hver agent i sekvensen modtager:
- **Originalt Input**: Den oprindelige brugermeddelelse (billede + tekst)
- **Tidligere Agentoutput**: Alle tidligere agentresponser i samtalehistorikken
- **Opsamlet Kontekst**: Fuldstændig tilstand vedligeholdt gennem hele arbejdsgangen

Dette muliggør sofistikeret flerstadiebehandling, hvor hver agent bygger videre på omfattende kontekst fra alle tidligere trin.
