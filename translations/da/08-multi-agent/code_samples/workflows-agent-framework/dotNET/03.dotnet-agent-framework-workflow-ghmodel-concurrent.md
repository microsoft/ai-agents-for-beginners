## 💻 Kørsel af Koden

Den komplette implementering findes i `03.dotnet-agent-framework-workflow-ghmodel-concurrent.cs`. Denne fil demonstrerer en **Fan-Out/Fan-In samtidig workflow** til rejseplanlægning:

### 🏗️ **Workflow Arkitektur**

```
User Request → ConcurrentStartExecutor → [Researcher Agent || Planner Agent] → ConcurrentAggregationExecutor → Final Output
```

**Nøglekomponenter:**

1. **ConcurrentStartExecutor**: Sender brugerens anmodning til alle agenter samtidigt
2. **Forsker Agent**: Analyserer destinationer og attraktioner samtidigt
3. **Planlægger Agent**: Opretter detaljerede rejseplaner samtidigt
4. **ConcurrentAggregationExecutor**: Samler og fusionerer resultater fra begge agenter

### 🎯 **Fan-Out/Fan-In Mønster**

Denne workflow demonstrerer det klassiske **Fan-Out/Fan-In** mønster:
- **Fan-Out**: Én inputbesked udsendes til flere agenter samtidigt
- **Samtidig Behandling**: Flere agenter arbejder parallelt på samme opgave
- **Fan-In**: Resultater fra alle agenter samles og aggregeres til ét output

### 🔍 Forståelse af Tilpassede Executers

**ConcurrentStartExecutor:**
- Implementerer `IMessageHandler<string>` til at modtage strenginput
- Udsender beskeder til alle tilsluttede agenter
- Sender `TurnToken` for at udløse samtidig behandling

**ConcurrentAggregationExecutor:**
- Implementerer `IMessageHandler<ChatMessage>` for at modtage agenters svar
- Samler beskeder på trådsikker måde
- Sammenlægger når alle forventede svar ankommer
- Returnerer endeligt output vha. `context.YieldOutputAsync()`

### ⚡ Ydelsesfordele

**Samtidig vs Sekventiel:**
- Sekventiel: Agent1 (30s) → Agent2 (30s) = **60 sekunder samlet**
- Samtidig: Agent1 (30s) || Agent2 (30s) = **30 sekunder samlet**

**Forbedring af gennemløb**: Op til N× hurtigere for N samtidige agenter (afhængigt af belastning og ressourcer)

### 🛡️ Fejlhåndtering

Workflowet håndterer fejl hos individuelle agenter yndefuldt:
- Hvis én agent fejler, fortsætter de andre behandlingen
- Aggregatoren kan implementere timeout-logik
- Delvise resultater kan returneres efter behov
