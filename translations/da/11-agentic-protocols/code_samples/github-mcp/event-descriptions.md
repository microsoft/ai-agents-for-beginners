## Eventnavn: Multi-Agent API med LangGraph og Azure Cosmos DB

## Beskrivelse

Ved slutningen af denne session vil du have en klar plan for at bygge og implementere dine egne skalerbare, cloud-native multi-agent applikationer, der udnytter kraften i moderne AI og cloud-infrastruktur.
