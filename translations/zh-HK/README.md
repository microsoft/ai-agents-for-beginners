## 🌱 開始吧

課程包含建構 AI 代理的基礎課題。每課涵蓋不同主題，隨意從任何地方開始！

此課程支援多語言。請參考我們的[可用語言列表](#-multi-language-support)。 

如果是你第一次使用生成式 AI 模型建構，歡迎參考我們的[生成式 AI 入門](https://aka.ms/genai-beginners)課程，內含 21 個建構 GenAI 的課程。

別忘了[為本倉庫加星（🌟）](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst)和[分叉本倉庫](https://github.com/microsoft/ai-agents-for-beginners/fork)來運行程式碼。

### 認識其他學習者，獲取問題解答

如果你遇到困難或有任何關於建置 AI 代理的問題，歡迎加入我們專屬的 Discord 頻道，連結在 [Microsoft Foundry Discord](https://aka.ms/ai-agents/discord)。

### 你需要準備

每課包含程式碼範例，可在 code_samples 資料夾中找到。你可以[分叉本倉庫](https://github.com/microsoft/ai-agents-for-beginners/fork)來建立你自己的副本。  

課程中範例程式碼使用 Microsoft Agent Framework 及 Microsoft Foundry Agent Service V2：

- [Microsoft Foundry](https://aka.ms/ai-agents-beginners/ai-foundry) - 需 Azure 帳號

本課程使用 Microsoft 的以下 AI 代理框架與服務：

- [Microsoft Agent Framework (MAF)](https://learn.microsoft.com/agent-framework/overview/)
- [Microsoft Foundry Agent Service V2](https://aka.ms/ai-agents-beginners/ai-agent-service)

部分程式碼範例也支援 OpenAI 相容的其他供應商，如 [MiniMax](https://platform.minimaxi.com/)，提供最大上下文（最高 204K 代幣）。設定詳情請參閱 [課程設置](./00-course-setup/README.md)。

有關執行程式碼更多資訊，請見 [課程設置](./00-course-setup/README.md)。
