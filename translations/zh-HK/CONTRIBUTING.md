# 貢獻

本項目歡迎貢獻和建議。大多數貢獻需要您同意一份貢獻者授權協議 (CLA)，聲明您有權利並確實授權我們使用您的貢獻。詳情請訪問 <https://cla.opensource.microsoft.com>。

當您提交拉取請求時，CLA 機器人會自動判斷您是否需要提供 CLA，並適當地標註該請求。請遵循機器人提供的指示。在使用 Microsoft CLA 的多個存儲庫中，您僅需執行此操作一次。

## 行為準則

本項目已採納 [Microsoft 開放源碼行為準則](https://opensource.microsoft.com/codeofconduct/)。欲知更多資訊，請參閱 [行為準則常見問題](https://opensource.microsoft.com/codeofconduct/faq/)，或透過 [opencode@microsoft.com](mailto:opencode@microsoft.com) 聯絡我們，提出額外問題或意見。

## 拉取請求指南

- 保持每個拉取請求專注於一個邏輯變更。
- 提交前測試影響的筆記本和程式碼範例。
- 新增或更改範例時，更新相關課程文檔。
- 僅修改英文原始內容。翻譯由自動翻譯工作流程維護。
- 請勿提交憑證、`.env` 檔案、臨時檔案或生成的開發產物。

## 編輯範圍及第三方產品

本課程以 Microsoft 技術和供應商中立的開放標準為重點。貢獻應具有明確的教育目的，不得主要用來介紹或推廣第三方商業產品、託管服務、模型路由器、SDK、MCP 伺服器或其他供應商特定的方案。

可能會參考開放源碼軟件和第三方依賴，前提是它們對說明開放標準或互操作性情況是必要的，且以中立方式呈現，並非以供應商的產品或託管終端為中心。如果您提議的貢獻包含供應商特定產品或服務，請先開啟議題並獲得維護者同意，然後再提交拉取請求。

貢獻者必須披露與其貢獻中提及的產品或服務的任何相關雇用關係、所有權、贊助或其他關聯。請勿包含無支持的價格、效能、安全性、隱私或比較性主張。可執行的範例預設不得傳送學習者資料，或透過外部第三方服務執行公開操作。
