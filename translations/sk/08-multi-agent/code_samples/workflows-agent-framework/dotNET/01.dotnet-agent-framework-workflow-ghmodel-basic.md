# 🔄 Základné pracovné postupy agentov s Azure OpenAI (Responses API) (.NET)

## 📋 Návod na orchestráciu pracovných postupov

Tento zápisník demonštruje, ako vytvárať sofistikované **pracovné postupy agentov** pomocou Microsoft Agent Framework pre .NET a Azure OpenAI (Responses API). Naučíte sa vytvárať viacstupňové podnikové procesy, kde AI agenti spolupracujú na dosiahnutí komplexných úloh prostredníctvom štruktúrovaných orchestrácií.

## 🎯 Ciele učenia

### 🏗️ **Základy architektúry pracovných postupov**
- **Staviteľ pracovných postupov**: Navrhujte a orchestrujte komplexné viacstupňové AI procesy
- **Koordinácia agentov**: Koordinujte viacerých špecializovaných agentov v rámci pracovných postupov
- **Azure OpenAI (Responses API)**: Využitie Azure OpenAI Responses API v pracovných postupoch
- **Vizualizácia návrhu pracovných postupov**: Vytvárajte a vizualizujte štruktúry pracovných postupov pre lepšie pochopenie

### 🔄 **Vzorce orchestrácie procesov**
- **Sekvenčné spracovanie**: Spojte viacero úloh agenta v logickom poradí
- **Správa stavu**: Udržiavajte kontext a tok dát medzi fázami pracovných postupov
- **Riešenie chýb**: Implementujte robustné zotavenie z chýb a odolnosť pracovných postupov
- **Optimalizácia výkonu**: Navrhujte efektívne pracovné postupy pre podnikové operácie vo veľkom rozsahu

### 🏢 **Podnikové aplikácie pracovných postupov**
- **Automatizácia podnikových procesov**: Automatizujte komplexné organizačné pracovné postupy
- **Pipeline produkcie obsahu**: Redakčné pracovné postupy s kontrolou a schválením
- **Automatizácia zákazníckeho servisu**: Viacstupňové riešenie zákazníckych dopytov
- **Pracovné postupy spracovania dát**: ETL pracovné postupy s AI-poháňanou transformáciou

### 🔑 **Konfigurácia Azure OpenAI**

**Nastavenie prostredia (súbor .env):**
```env
AZURE_OPENAI_ENDPOINT=https://<your-resource>.openai.azure.com
AZURE_OPENAI_DEPLOYMENT=gpt-4o-mini
```

**Prístup k Azure OpenAI:**
1. Vytvorte Azure OpenAI zdroj v Azure portáli
2. Nasadíte model (napríklad `gpt-4o-mini`) a zaznamenajte názov nasadenia
3. Prihláste sa pomocou `az login` a nakonfigurujte premenné prostredia podľa vyššie uvedeného

```mermaid

    E --> F
```

**Kľúčové komponenty:**
- **WorkflowBuilder**: Hlavný orchestrátor pre návrh pracovných postupov
- **AIAgent**: Jednotliví špecializovaní agenti so špecifickými schopnosťami
- **Azure OpenAI Client**: Integrácia s Azure OpenAI Responses API
- **Execution Context**: Spravuje stav a tok dát medzi fázami pracovných postupov

## 💻 Spustenie kódu

Kompletná implementácia je dostupná v súbore `01.dotnet-agent-framework-workflow-ghmodel-basic.cs`. Tento súbor demonštruje:

1. **Konfigurácia prostredia** - Načítanie konfigurácie Azure OpenAI zo súboru `.env`
2. **Nastavenie Azure OpenAI klienta** - Konfigurácia klienta na použitie Azure OpenAI Responses API
3. **Vytvorenie agentov** - Definovanie špecializovaných agentov (Front Desk a Concierge)
4. **Staviteľ pracovných postupov** - Vytvorenie viacagentného pracovného postupu so sekvenčným spracovaním
5. **Vykonanie pracovného postupu** - Spustenie pracovného postupu so streamovanými výsledkami

### 🚀 Spustenie príkladu

```bash
# Spravte skript spustiteľným (Unix/Linux/macOS)
chmod +x 01.dotnet-agent-framework-workflow-ghmodel-basic.cs

# Spustite pracovný tok
./01.dotnet-agent-framework-workflow-ghmodel-basic.cs
```

Alebo na Windows:
```powershell
dotnet run 01.dotnet-agent-framework-workflow-ghmodel-basic.cs
```

### 📝 Očakávaný výstup

Pracovný postup:
1. Prijme vašu požiadavku na cestovnú destináciu („Chcel by som ísť do Paríža“)
2. Agent Front Desk poskytne počiatočné odporúčanie
3. Agent Concierge odporúčanie skontroluje a vylepší
4. Výsledný výstup zobrazí kompletný prúd konverzácie

### 🔧 Prispôsobenie

Pracovný postup môžete prispôsobiť:
- Úpravou inštrukcií agentov zmeníte ich správanie
- Pridaním ďalších agentov vytvoríte komplexné viacstupňové pracovné postupy
- Zmenou správy používateľa otestujete rôzne scenáre
- Úpravou prepojení pracovného postupu vytvoríte rôzne vzorce vykonávania
