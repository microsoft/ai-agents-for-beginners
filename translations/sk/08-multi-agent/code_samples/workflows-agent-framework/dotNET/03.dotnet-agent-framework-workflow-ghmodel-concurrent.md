## 💻 Spustenie kódu

Kompletná implementácia je dostupná v `03.dotnet-agent-framework-workflow-ghmodel-concurrent.cs`. Tento súbor demonštruje **Fan-Out/Fan-In súbežný pracovný tok** pre plánovanie cestovania:

### 🏗️ **Architektúra pracovného toku**

```
User Request → ConcurrentStartExecutor → [Researcher Agent || Planner Agent] → ConcurrentAggregationExecutor → Final Output
```

**Kľúčové komponenty:**

1. **ConcurrentStartExecutor**: Rozosiela požiadavku používateľa všetkým agentom súčasne
2. **Researcher Agent**: Paralelne analyzuje destinácie a atrakcie
3. **Planner Agent**: Paralelne vytvára detailné cestovné plány
4. **ConcurrentAggregationExecutor**: Zhromažďuje a spája výsledky od oboch agentov

### 🎯 **Vzor Fan-Out/Fan-In**

Tento pracovný tok demonštruje klasický **Fan-Out/Fan-In** vzor:
- **Fan-Out**: Jeden vstupný odkaz je rozoslaný viacerým agentom súčasne
- **Súbežné spracovanie**: Viacerí agenti pracujú paralelne na tej istej úlohe
- **Fan-In**: Výsledky od všetkých agentov sú zhromaždené a zhlukované do jedného výstupu

### 🔍 Pochopenie vlastných executorov

**ConcurrentStartExecutor:**
- Implementuje `IMessageHandler<string>` pre prijímanie reťazcového vstupu
- Rozosiela správy všetkým pripojeným agentom
- Posiela `TurnToken` na spustenie súbežného spracovania

**ConcurrentAggregationExecutor:**
- Implementuje `IMessageHandler<ChatMessage>` pre prijímanie odpovedí agentov
- Zhromažďuje správy vláknovo bezpečným spôsobom
- Agreguje, keď prídu všetky očakávané odpovede
- Vydáva finálny výstup pomocou `context.YieldOutputAsync()`

### ⚡ Výhody výkonu

**Súbežné vs sekvenčné:**
- Sekvenčné: Agent1 (30s) → Agent2 (30s) = **60 sekúnd celkom**
- Súbežné: Agent1 (30s) || Agent2 (30s) = **30 sekúnd celkom**

**Zlepšenie priepustnosti**: Až N× rýchlejšie pri N súbežných agentoch (v závislosti od záťaže a zdrojov)

### 🛡️ Spracovanie chýb

Pracovný tok elegantne rieši zlyhania jednotlivých agentov:
- Ak jeden agent zlyhá, ostatní pokračujú v spracovaní
- Aggregátor môže implementovať časový limit
- V prípade potreby sa dajú vrátiť čiastkové výsledky
