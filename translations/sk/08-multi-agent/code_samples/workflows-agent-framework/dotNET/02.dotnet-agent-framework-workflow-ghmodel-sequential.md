## 💻 Spustenie kódu

Kompletná implementácia je dostupná v súbore `02.dotnet-agent-framework-workflow-ghmodel-sequential.cs`. Tento súbor demonštruje **trojfázový workflow analýzy nábytku**:

1. **Fáza 1 - Predajný agent**: Analyzuje obrázky nábytku a poskytuje nákupné odporúčania
2. **Fáza 2 - Cenový agent**: Poskytuje podrobný rozpis cien a možnosti rozpočtu
3. **Fáza 3 - Agent pre ponuku**: Generuje profesionálny dokument ponuky v Markdown formáte

### 🏗️ **Architektúra workflow**

```
Image Input → Sales Analysis → Price Estimation → Quote Generation → Final Output
```

Každý agent:
- Prijíma výstup z predchádzajúcej fázy ako kontext
- Stavia na predchádzajúcej analýze so špecializovanou expertízou
- Udržuje kontinuitu workflow cez správu stavu

### 🚀 Spustenie príkladu

**Požiadavky:**
- Umiestnite obrázok nábytku na `../imgs/home.png` (alebo aktualizujte premennú `imgPath`)
- Nakonfigurujte svoj `.env` súbor s endpointom a deploymentom Azure OpenAI, potom sa prihláste pomocou `az login`

### 📝 Očakávaný výstup

Workflow:
1. **Predajný agent**: Identifikuje položky nábytku na obrázku a poskytne odporúčania
2. **Cenový agent**: Pridá podrobnú cenovú analýzu s rozpočtovými úrovňami a nákupnými odporúčaniami
3. **Agent pre ponuku**: Generuje formátovaný dokument ponuky so všetkými zhrnutými informáciami

Konečný výstup bude komplexná, profesionálna ponuka nábytku založená na analýze obrázku.
