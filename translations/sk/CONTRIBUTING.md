# Príspevky

Tento projekt vítá príspevky a návrhy. Väčšina príspevkov vyžaduje, aby ste súhlasili s Licenčnou dohodou prispievateľa (CLA), v ktorej vyhlásite, že máte právo a skutočne nám poskytujete práva na použitie vášho príspevku. Pre podrobnosti navštívte <https://cla.opensource.microsoft.com>.

Keď odošlete pull request, bot pre CLA automaticky zistí, či je potrebné poskytnúť CLA, a príslušne označí pull request. Postupujte podľa pokynov bota. Toto budete musieť urobiť iba raz vo všetkých repozitároch, ktoré používajú Microsoft CLA.

## Kódex správania

Tento projekt prijal [Microsoft Open Source Code of Conduct](https://opensource.microsoft.com/codeofconduct/). Pre viac informácií pozrite [Často kladené otázky k Kódexu správania](https://opensource.microsoft.com/codeofconduct/faq/) alebo kontaktujte [opencode@microsoft.com](mailto:opencode@microsoft.com) s ďalšími otázkami alebo pripomienkami.

## Pokyny pre pull requesty

- Každý pull request sa zameriava na jednu logickú zmenu.
- Pred odoslaním otestujte ovplyvnené poznámkové bloky a ukážky kódu.
- Pri pridávaní alebo zmene príkladu aktualizujte príslušnú dokumentáciu lekcie.
- Upravujte iba anglický zdrojový obsah. Preklady spravuje automatizovaný prekladový proces.
- Neodosielajte prihlasovacie údaje, súbory `.env`, dočasné súbory ani generované vývojové artefakty.

## Redakčný záber a produkty tretích strán

Tento študijný plán sa zameriava na technológie Microsoft a neutrálnych otvorených štandardov. Príspevky by mali mať jasný vzdelávací účel a nesmú byť primárne určené na zavedenie alebo propagáciu komerčného produktu tretej strany, hosťovanej služby, modelového routera, SDK, MCP servera alebo inej ponuky špecifickej pre dodávateľa.

Open source softvér a závislosti tretích strán môžu byť spomenuté, ak sú potrebné na vysvetlenie otvoreného štandardu alebo scenára interoperability, sú prezentované neutrálne a nie sú zamerané na produkt alebo hosťovaný koncový bod dodávateľa. Ak váš návrh príspevku zahŕňa produkt alebo službu špecifickú pre dodávateľa, otvorte problém a získajte súhlas správcu pred odoslaním pull requestu.

Prispievatelia musia uviesť akýkoľvek relevantný pracovný pomer, vlastníctvo, sponzorstvo alebo iné spojenie s produktom alebo službou spomenutou vo svojom príspevku. Nezahrňujte nepodložené tvrdenia o cenách, výkone, bezpečnosti, súkromí alebo porovnaniach. Príklady, ktoré je možné spustiť, nesmú predvolene prenášať údaje študentov ani vykonávať verejné akcie prostredníctvom externej služby tretej strany.
