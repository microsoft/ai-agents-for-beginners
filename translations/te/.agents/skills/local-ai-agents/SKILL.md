# Foundry Local మరియు Qwen తో స్థానిక AI ఏజెంట్లను సృష్టించడం

> [పాఠం 17 – స్థానిక AI ఏజెంట్లను సృష్టించడం](../../../17-creating-local-ai-agents/README.md) కోసం సహాయక నైపుణ్యం.
> ఇది ఒక విద్యార్థికి ఒక ఏజెంటును నిర్మించడంలో సహాయం చేయడానికి ఉపయోగించండి, ఆ ఏజెంటు ఆలోచించి, టూల్స్‌ను పిలవగలదు మరియు
> డాక్యుమెంటేషన్‌ను పూర్తిగా వారి సొంత యంత్రంలోనే వెతుకుతారు — క్లౌడ్ ఇన్ఫరెన్సు లేదు. ప్రతి సూచనను పాఠ్య కంటెంట్ మరియు అమలు చేయగల నోట్‌బుక్‌లో ఆధారపడి ఉంచండి.




- ఓ ఏజెంట్‌ని **పూర్తిగా పరికరంలోనే** ప్రైవసీ, ఖర్చు లేదా ఆఫ్‌లైన్ కారణాల కోసం నడపాలి.
- **Foundry Local** తో ఒక మోడల్‌ను స్థానికంగా సర్వ్ చేసి OpenAI-అనుకూల ఎండ్‌పాయింట్ ద్వారా కనెక్ట్ చేయాలి.
- భరోసাযোগ్యమైన స్థానిక టూల్ పిలవడాల కోసం **Qwen ఫంక్షన్-కాల్ మోడల్** ఉపయోగించాలి.
- **స్థానిక RAG** (Chroma) లేదా **స్థానిక MCP సర్వర్** జోడించాలి.
- **హైబ్రిడ్** స్థానిక/క్లౌడ్ రూటింగ్ వ్యూహాన్ని డిజైన్ చేయాలి.




మోడల్‌కు కోడ్‌బేస్ గురించి *తెలియాల్సిన అవసరం లేదు* — ఇది ఎప్పుడు `read_file` మరియు `search_docs` పిలవాలో తెలుసుకోవాలి. ఇది ఒక SLM బలమైన దిశ (పలుకుబడి నిర్ణయాలు, ఉదా: టూల్ ఎంపిక) వైపు మరియు దాని బలహీనత (విస్తృత జ్ఞానం, దీర్ఘ.Multi-hop ఆలోచన) నుండి దూరంగా ఉంటుంది.

## ఈ నిర్దిష్ట భాగాలు ఎందుకు

- **Foundry Local** ఒక **OpenAI-అనుకూల HTTP ఎండ్‌పాయింట్**ను అందిస్తుంది, కాబట్టి క్లౌడ్ ఏజెంట్ కోడ్ ను కేవలం `base_url` మార్చడం ద్వారా బదిలీ చేయవచ్చు (మరియు ఒక స్థానిక ప్లేస్‌హోల్డర్ API కీ ఉపయోగించి). ఇది కూడా మెషీన్ కోసం ఉత్తమ బిల్డ్ (CPU/GPU/NPU) ని ఆటో-ఎంపిక చేస్తుంది.
- **Qwen** మోడల్స్ ఫంక్షన్ కాల్లింగ్ కోసం శిక్షణ పొందినవి మరియు సరిగ్గా పరికరం పిలువను ఉత్పత్తి చేస్తాయి — ఇది స్థానిక *చాట్* మోడల్ ను స్థానిక *ఏజెంట్* గా మార్చుతుంది.

- **MCP** క్లౌడ్ సేవ కాదు: ఒక MCP సర్వర్ స్థానికంగా `stdio` పై నడవచ్చు.

## సెటప్ అవసరాలు

```bash
foundry model run qwen2.5-7b-instruct
foundry service status
```

```python
from foundry_local import FoundryLocalManager
from openai import OpenAI

manager = FoundryLocalManager("qwen2.5-7b-instruct")
client = OpenAI(base_url=manager.endpoint, api_key=manager.api_key)  # local placeholder
```





విద్యార్థికి ఈ నోట్‌బుక్ చూడమని సూచించండి
[`17-local-agent-foundry-local.ipynb`](../../../17-creating-local-ai-agents/code_samples/17-local-agent-foundry-local.ipynb):

- **Sandboxed tools**: ప్రతి ఫైల్ టూల్ ప్రత్యక్ష మార్గాలను పరిష్కరించి ఒకే ప్రాజెక్ట్ రూట్ బయట ఉన్న దాన్ని ఖండిస్తుంది — స్థానికంగా కూడా టూల్ యూజర్ అనుమతులతో నడుస్తుంది.

- **స్థానిక RAG**: డాక్యుమెంట్లు Chroma కలెక్షన్‌లో అప్డేట్ చేయండి; `search_docs` టాప్-k భాగాలని ఇస్తుంది.
- **స్థానిక MCP**: స్థానిక సర్వర్ కు `stdio` ద్వారా కనెక్ట్ అవ్వండి; దాన్ని ప్రాజెక్ట్ డైరెక్టరీకి పరిమితం చేసి, దాని అవుట్పుట్‌లను సరిచూడండి.

## హైబ్రిడ్ రూటింగ్ (స్థానిక ఒక మోడల్ గా ఉండటం)

| పరిస్థితి | ఇది ఎక్కడ నడుస్తుంది |
|-----------|---------------------|

| సింపుల్, పరిమిత పని | స్థానిక SLM (చౌకగా, వేగంగా) |

| క్లౌడ్ అవుటేజ్ | స్థానిక SLM (సౌమ్య నష్టపరిహారం) |

ఇది పాఠం 16 నుండి మోడల్-రూటింగ్ భావనను అనుకరిస్తుంది, వర్క్‌స్టేషన్ ఒక మార్గంగా. ఏజెంట్ తగినంతగా దెబ్బతింటే గుండెలోగా కూలిపోకుండా స్థానిక దిశగా వెళ్ళే డిజైన్లను ప్రాధాన్యం ఇవ్వండి.

## సహాయకుడు కోసం గార్డ్‌రైల్స్


- విద్యార్థి లక్ష్యం ప్రైవసీ/ఆఫ్‌లైన్ అయితే కోడ్ లేదా డేటాను క్లౌడ్‌కు పంపకండి — మొత్తం పైప్లైన్ స్థానికంగానే ఉంచండి.
- SLM నాణ్యతకు వాస్తవమైన అంచనాలను పెట్టండి; మోడల్ గుర్తు పెట్టుకున్న జ్ఞానం కంటే టూల్స్ మరియు RAG పై ఆధారపడండి.
- పాఠం 17కి **ఏ Foundry Responses ఎండ్‌పాయింట్ లేదు**, కాబట్టి క్లౌడ్ స్మోక్-టెస్ట్ చర్య వర్తించదు — నోట్‌బుక్‌ను స్థానికంగా నడపడం ద్వారా ధృవీకరించండి.

## అసిస్టెంట్ కోసం రక్షణా మార్గదర్శకాలు

- ప్రతి ఫైల్/టూల్ ఆపరేషన్‌ను సాండ్‌బాక్స్డ్ ప్రాజెక్ట్ డైరెక్టరీలోనే పరిమితం చేయండి.
- విద్యార్థి పేర్కొన్న లక్ష్యం గోప్యత/ఆఫ్లైన్ అయితే కోడ్ లేదా డేటాను క్లౌడ్‌కు పంపవద్దు — మొత్తం చర్యను స్థానికంగా ఉంచండి.
- SLM నాణ్యతకు యథార్థపు అంచనాలు పెట్టండి; మోడల్ యొక్క జ్ఞాపక శక్తికి బదులు టూల్స్ మరియు RAG మీద ఆధారపడండి.
- పాఠం 17 కు **ఏ** Foundry Responses ఎండ్పాయింట్ లేదు, కాబట్టి క్లౌడ్ స్మోక్-టెస్ట్ చర్య వర్తించదు — నోట్‌బుక్‌ను స్థానికంగా నడిపించి ధృవీకరించండి.
