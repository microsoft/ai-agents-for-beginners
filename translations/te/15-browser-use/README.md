# కంప్యూటర్ వినియోగ ఏజెంట్లు (CUA) తయారీ

కంప్యూటర్ వినియోగ ఏజెంట్లు మనుషులు చేసే విధంగా వెబ్‌సైట్‌లతో ఇంటరాక్ట్ అవుతాయి: బ్రౌజర్ ఓపెన్ చేయడం, పేజీని పరిశీలించడం, మరియు వారు చూస్తున్న దాని నుండి తదుపరి ఉత్తమ చర్య తీసుకోవడం. ఈ పాఠంలో, మీరు బ్రౌజర్ ఆటోమేషన్ ఏజెంట్‌ను నిర్మించబోతున్నారు, ఇది Airbnbని శోధించి, క్రమబద్ధీకృత లిస్టింగ్ డేటాను తీయగలదు మరియు స్టాక్‌హోమ్‌లో అతిపేరు ఉన్న ఉంటువాసానికి గుర్తింపును ఇస్తుంది.

ఈ పాఠం Browser-Useని AI-చేత నావిగేషన్ కొరకు, Playwright మరియు Chrome DevTools Protocol (CDP)ని బ్రౌజర్ నియంత్రణ కోసం, Azure OpenAIని దృష్టి-సౌకర్యం కలిగిన తర్కానికి, మరియు Pydanticని క్రమబద్ధీకృత ఎక్స్‌ట్రాక్షన్ కోసం కలిపి ఉపయోగిస్తుంది.

## పరిచయం

ఈ పాఠం కిందివి కవర్ చేస్తుంది:

- కంప్యూటర్ వినియోగ ఏజెంట్లు API-మాత్రం ఆటోమేషన్ కంటే ఎప్పుడు ఉత్తమమై ఉంటాయో అర్థం చేసుకోవడం
- నమ్మకమైన బ్రౌజర్ జీవచక్రం నిర్వహణ కోసం Browser-Useను Playwright మరియు CDPతో కలపడం
- డైనమిక్ వెబ్ పేజీల నుండి లిస్టింగ్ డేటాను తీసుకోవటానికి Azure OpenAI దృష్టి మరియు Pydantic క్రమబద్ధీకృత అవుట్‌పుట్ వాడటం
- ఏజెంట్-ఫస్ట్, నటుడు-ఫస్ట్ లేదా హైబ్రిడ్ బ్రౌజర్ ఆటోమేషన్ వర్క్‌ఫ్లో ఎప్పుడు వాడాలో నిర్ణయం తీసుకోవడం

## అభ్యాస లక్ష్యాలు

ఈ పాఠం పూర్తి చేసిన తర్వాత, మీరు తెలుసుకుంటారు కిందివి ఎలా చేయాలో:

- Azure OpenAI మరియు Playwrightతో Browser-Useను కాన్ఫిగర్ చేయడం
- నిజమైన వెబ్‌సైట్‌ను నావిగేట్ చేసే మరియు డైనమిక్ UI అంశాలను నిర్వహించే బ్రౌజర్ ఆటోమేషన్ వర్క్‌ఫ్లో రూపొందించడం
- కనిపించే పేజీ కంటెంట్ నుండి టైప్ చేయబడిన ఫలితాలను తీసుకుని వాటిని దిగువ వ్యాపార తర్కాల్లోకి మార్చడం
- బ్రౌజర్ టాస్క్ ఎంత వరకు ముందస్తుగా అంచనా వేసుకోవచ్చో మీద ఆధారపడి ఏజెంట్ మరియు నటుడు నమూనాల మధ్య ఎంపిక చేసుకోవడం

## కోడ్ నమూనా

ఈ పాఠంలో ఒక నోట్‌బుక్ ట్యుటోరియల్ ఉంటుంది:

- [15-browser-user.ipynb](./15-browser-user.ipynb): CDP లో Chrome సెషన్ ప్రారంభించి, Airbnbలో స్టాక్‌హోమ్ లిస్టింగ్‌లను శోధించి, Browser-Use దృష్టితో ధరలను తీసుకుని, అత్యంత సరసమైన ఎంపికను క్రమబద్ధీకృత సమాచారంగా తిరిగి ఇస్తుంది.

## అవసరమైన అంశాలు

- Python 3.12+
- మీ పరిసరంలో Azure OpenAI డిప్లాయ్‌మెంట్ కాన్ఫిగర్ చేయబడింది
- Chrome లేదా Chromium స్థానంలో ఇన్స్టాల్ చేయబడింది
- Playwright ఆధారాలు ఇన్స్టాల్ చేయబడినవి
- async Python పై ప్రాథమిక పరిజ్ఞానం

## సెటప్

నోట్‌బుక్‌లో ఉపయోగించిన ప్యాకేజీలు ఇన్స్టాల్ చేయండి:

```bash
pip install browser_use playwright python-dotenv
playwright install chromium
```

నోట్‌బుక్ ఉపయోగించే Azure OpenAI పరిసర వేరియబుల్స్ సెట్ చేయండి:

```bash
AZURE_OPENAI_ENDPOINT=...
AZURE_OPENAI_API_KEY=...
AZURE_OPENAI_CHAT_DEPLOYMENT_NAME=...
# ఐచ్ఛికం: వదిలివేయబడినప్పుడు తాజా API వెర్షన్‌కు డిఫాల్ట్ అవుతుంది
AZURE_OPENAI_API_VERSION=...
```

## నిర్మాణ అవలోకనం

నోట్‌బుక్ ఒక హైబ్రిడ్ బ్రౌజర్ ఆటోమేషన్ వర్క్‌ఫ్లోని ప్రదర్శిస్తుంది:

1. Playwright మరియు Browser-Use ఇద్దరికీ ఒకే బ్రౌజర్ సెషన్ షేర్ చేయడానికి CDP సక్రియంగా ఉన్న Chrome ప్రారంభమవుతుంది.
2. Browser-Use ఏజెంట్ Airbnbని తెరుచుకోవటం, పాప్-అప్‌లను నిర్మూలించటం, మరియు స్టాక్‌హోమ్ కోసం శోధించడం వంటి తెరిచి ఉన్న నావిగేషన్ పనులను నిర్వహిస్తుంది.
3. త్వరలో పేజీని క్రమబద్ధీకృత Pydantic స్కీమాతో పరిశీలించడం ద్వారా లిస్టింగ్ టైటిల్స్, రాత్రి ప్రైసులు, రేటింగ్స్, మరియు URLs తీసుకోవడం.
4. తీసుకున్న లిస్టింగ్‌లను Python తర్కంతో పోల్చి అత్యంత తక్కువ ధర ఉన్న ఫలితాన్ని హైలైట్ చేస్తుంది.

ఈ విధానం Browser-Use బలంగా ఉన్న దృష్టి-ఆధారిత తర్కాన్ని కొనసాగించేలా చేస్తుంది మరియు మీరు అవసరమైనప్పుడు నిర్దిష్ట బ్రౌజర్ నియంత్రణను ఇస్తుంది.

## ముఖ్యమైన విషయాలు మరియు ఉత్తమన పద్ధతులు

### ఏజెంట్ vs నటుడు ఎప్పుడు ఉపయోగించాలి

| పరిస్థితి | ఏజెంట్ వాడాలి | నటుడు వాడాలి |
|----------|----------------|--------------|
| డైనమిక్ లేఅవుట్లు | అవును, AI పేజీ మార్పులకు అనుగుణంగా ఉంటుంది | కాదు, మురికి ఎంపికకర్తలు అమర్చబడతాయి |
| తెలిసిన నిర్మాణం | కాదు, ఏజెంట్ నేరుగా నియంత్రణ కంటే మందగించింది | అవును, వేగంగా మరియు ఖచ్చితంగా |
| అంశాలు కనుగొనడం | అవును, సహజ భాష బాగా పని చేస్తుంది | కాదు, ఖచ్చితమైన సెలెక్టర్ల అవసరం |
| సమయ నియంత్రణ | కాదు, తక్కువ అంచనా | అవును, వేచి ఉండటం మరియు మళ్లీ ప్రయత్నాలను పూర్తి నియంత్రణ |
| సంక్లిష్ట వర్క్‌ఫ్లోలు | అవును, ఆశ్చర్యకర UI స్థితులను నిర్వహిస్తుంది | కాదు, స్పష్టమైన శాఖలను అవసరం |

### Browser-Use ఉత్తమ పద్ధతులు

1. అన్వేషణ మరియు డైనమిక్ నావిగేషన్ కోసం ఏజెంట్తో ప్రారంభించండి.
2. ఇంటరాక్షన్ ముందస్తుగా అంచనా వేయగల సాధారణ‌గా మారినప్పుడు నేరుగా పేజీ నియంత్రణకు మారండి.
3. ఎక్స్‌ట్రాక్ట్ అయిన డేటా ధ్రువీకరించబడిన మరియు టైప్-సేఫ్ అయ్యేలా క్రమబద్ధీకృత అవుట్‌పుట్ నమూనాలను వాడండి.
4. కనపడే UI మార్పులకు కారణమయ్యే చర్యల తర్వాత వ్యూహాత్మక విళంబాలు జోడించండి.
5. తిరుగుతూ స్క్రీన్‌షాట్లు తీయండి, ఫెయిల్యూర్‌లు తేలికగా డీబగ్ చేయడానికి.
6. వెబ్‌సైట్లు మారుతుంటాయని ఆశించండి మరియు పాప్-అప్‌ల మరియు లేఅవుట్ మార్పుల కొరకు ప్రత్యామ్నాయ విధానాలను డిజైన్ చేయండి.
7. ఏజెంట్ మరియు నటుడు నమూనాలను కలిపి ఎంతగానో సహనం మరియు ఖచ్చితత్వం పొందండి.

### నిజ జీవిత అనువర్తనాలు

- ప్రయాణ బుకింగ్ మరియు ధర మినిటరింగ్
- ఈ-కామర్స్ ధర పోలిక మరియు లభ్యత తనిఖీలు
- డైనమిక్ వెబ్‌సైట్ల నుండి క్రమబద్ధీకృత ఎక్స్‌ట్రాక్షన్
- దృష్టి అవగాహక UI పరీక్ష మరియు ధ్రువీకరణ
- వెబ్‌సైట్ మానిటరింగ్ మరియు అలర్టింగ్
- బహుళ దశల ఫ్లోలలో తెలివైన ఫారం నింపడం

## నిజ జీవిత ఉదాహరణ: Microsoft ప్రాజెక్ట్ Opal

ఈ పాఠంలో మీరు తయారుచేసే ఏజెంట్ ఒక చిన్న, స్థానిక వెర్షన్ **కంప్యూటర్ వినియోగ ఏజెంట్ (CUA)** – ఒక ప్రోగ్రామ్ అది బ్రౌజర్‌ను ఒక మనిషి చేసే విధంగా నడిపిస్తుంది. Microsoft ఈ అదే భావనను Microsoft 365 Copilotలో **[ప్రాజెక్ట్ Opal (Frontier)](https://support.microsoft.com/en-us/microsoft-365-copilot/get-started-with-project-opal-frontier)** అనే సామర్థ్యంతో సంస్థల్లోకి తీసుకువస్తోంది.

ప్రాజెక్ట్ Opal తో మీరు పని వివరించగలరు మరియు ఏజెంట్ మీ తరఫున **సురక్షిత Windows 365 క్లౌడ్ PCపై కంప్యూటర్ వినియోగం ఉపయోగించి**, మీ సంస్థ బ్రౌజర్ ఆధారిత అనువర్తనాలు, సైట్లు, మరియు డేటాపై కార్యకలాపాలు నిర్వహిస్తుంది. ఇది **అసంక్రామకంగా బ్యాక్‌గ్రౌండ్‌లో పని చేస్తుంది**, మరియు మీరు పని మార్గదర్శనం ఇవ్వవచ్చు లేదా ఎప్పుడైనా నియంత్రణ తీసుకోవచ్చు. ఉదాహరణ పనులు:

- సెక్యూరిటీ గ్రూప్ సభ్యత్వ అభ్యర్థనలను నిర్వహించడం
- కంప్లయన్స్ సమీక్షల కోసం ఆడిట్ సాక్ష్యాలు సేకరించడం మరియు ధృవీకరించడం
- IT ఇన్సిడంట్‌లను ఒప్పందం చేయడం (టికెట్ స్థితి నవీకరణ, యజమానులను కేటాయించడం, నకిలీ అనుకున్న దస్త్రాలను మూసివేయడం)
- Excel డేటాను ఆర్థిక ముగింపు డెక్కుగా సమగ్రపరచడం

Opal **ఉత్పత్తి స్థాయి, నమ్మకమైన** కంప్యూటర్ వినియోగ ఏజెంట్ ఎలా ఉండాలో అన్వయించడానికి ఉపయోగకరమైన సూచనగా ఉంటుంది — మరియు ఇది ఇంతకు ముందు పాఠాల నుండి భావనలను మరింత దృఢం చేస్తుంది:
