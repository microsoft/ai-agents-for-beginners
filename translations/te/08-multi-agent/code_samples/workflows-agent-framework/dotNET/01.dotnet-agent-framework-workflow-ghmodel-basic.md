# 🔄 Azure OpenAI (Responses API) తో ప్రాథమిక ఏజెంట్ వర్క్‌ఫ్లోలు (.NET)

## 📋 వర్క్‌ఫ్లో ఆరీస్‌త్రేషన్ ట్యూటోరియల్

ఈ నోటుబుక్ Microsoft Agent Framework for .NET మరియు Azure OpenAI (Responses API) ఉపయోగించి ఘనమైన **ఏజెంట్ వర్క్‌ఫ్లోలను** ఎలా నిర్మించాలో చూపిస్తుంది. మీరు AI ఏజెంట్లు సమ్మిళితం ఐతే సంక్లిష్టమైన పనులను సాంకేతిక ఆరీస్‌త్రేషన్ ప్యాటర్న్ల ద్వారా పూర్తి చేసుకునేందుకు బహుళ-దశ వ్యాపార ప్రక్రియలను సృష్టించడం నేర్చుకుంటారు.

## 🎯 నేర్చుకునే లక్ష్యాలు

### 🏗️ **వర్క్‌ఫ్లో నిర్మాణపు ప్రాథమికాలు**
- **వర్క్‌ఫ్లో బిల్డర్**: సంక్లిష్ట బహుళ దశ AI ప్రక్రియలను డిజైన్ చేసి ఆరీస్‌త్రేట్ చేయడం
- **ఏజెంట్ సమన్వయం**: వర్క్‌ఫ్లోలలో అనేక ప్రత్యేక ఏజెంట్లను సమన్వయపరచడం
- **Azure OpenAI (Responses API)**: వర్క్‌ఫ్లోలలో Azure OpenAI Responses API ను వినియోగించడం
- **దృష్టాంత వర్క్‌ఫ్లో డిజైన్**: మంచి అర్థం కోసం వర్క్‌ఫ్లో నిర్మాణాలను సృష్టించి చూపించడం

### 🔄 **ప్రక్రియా ఆరీస్‌త్రేషన్ ప్యాటర్న్లు**
- **పటిన దశల ప్రాసెసింగ్**: లాజికల్ క్రమంలో అనేక ఏజెంట్ పనులను జత చేయడం
- **స్థితి నిర్వహణ**: వర్క్‌ఫ్లో దశల మొత్తం సారాంశం మరియు డేటా ప్రవాహాన్ని నిర్వహించడం
- **లోప నిర్వహణ**: గొప్ప లోప పునరుద్ధరణ మరియు వర్క్‌ఫ్లో సహనశీలత అమలు
- **నిర్వహణ సమర్థత**: సంస్థపరిమాణ ఆపరేషన్ల కోసం సమర్థవంతమైన వర్క్‌ఫ్లోలను రూపకల్పన

### 🏢 **సంస్థా వర్క్‌ఫ్లో అనువర్తనాలు**
- **వ్యాపార ప్రక్రియా స్వయంచాలకత**: సంక్లిష్ట సంస్థా వర్క్‌ఫ్లోలను ఆటోమేట్ చేయడం
- **కంటెంట్ ఉత్పత్తి పైప్‌లైన్**: సమీక్ష మరియు ఆమోద దశలతో సంపాదకీయ వర్క్‌ఫ్లోలు
- **గ్రాహక సేవ స్వయంచాలకత**: బహుళ-దశ కస్టమర్ విచారణ పరిష్కారం
- **డేటా ప్రాసెసింగ్ వర్క్‌ఫ్లోలు**: AI-శక్తి పరివర్తనతో ETL వర్క్‌ఫ్లోలు

### 📦 **అవసరమైన NuGet ప్యాకేజీలు**

ఈ వర్క్‌ఫ్లో ప్రదర్శన కొంత ముఖ్యమైన .NET ప్యాకేజీలను ఉపయోగిస్తుంది:

```xml
<!-- Core AI Framework -->
<PackageReference Include="Microsoft.Extensions.AI" Version="9.9.0" />

<!-- Azure OpenAI (Responses API) -->
<PackageReference Include="Azure.AI.OpenAI" Version="2.1.0" />
<PackageReference Include="Azure.Identity" Version="1.13.1" />

<!-- Agent Framework (Local Development) -->
<!-- Microsoft.Agents.AI.dll - Core agent abstractions -->
<!-- Microsoft.Agents.AI.OpenAI.dll - Azure OpenAI (Responses API) integration -->

<!-- Configuration and Environment -->
<PackageReference Include="DotNetEnv" Version="3.1.1" />
```

### 🔑 **Azure OpenAI కాన్ఫిగరేషన్**

**పరిసరాల సెటప్ (.env ఫైల్):**
```env
AZURE_OPENAI_ENDPOINT=https://<your-resource>.openai.azure.com
AZURE_OPENAI_DEPLOYMENT=gpt-4o-mini
```

**Azure OpenAI యాక్సెస్:**
1. Azure పోర్టల్లో Azure OpenAI వనరును సృష్టించండి
2. ఒక నమూనా (ఉదా, `gpt-4o-mini`) పంపిణీ చేసి పంపిణీ పేరును గమనించండి
3. `az login` తో సైన్ ఇన్ అయ్యి పైగా చూపించినట్లుగా పరిసర చరాలు సేకరించండి

### 🏗️ **వర్క్‌ఫ్లో నిర్మాణం అవలోకనం**

```mermaid
graph TD
    A[వర్క్‌ఫ్లో బిల్డర్] --> B[ఏజెంట్ రిజిస్ట్రీ]
    B --> C[వర్క్‌ఫ్లో ఎగ్జిక్యూషన్ ఇంజిన్]
    C --> D[Agent 1: కంటెంట్ జనరేటర్]
    C --> E[Agent 2: కంటెంట్ సమీక్షకుడు] 
    D --> F[వర్క్‌ఫ్లో ఫలితాలు]
    E --> F
    G[అజ్యూర్ ఓపెన్AI (ప్రతిస్పందన API)] --> D
    G --> E
```

**ప్రధాన భాగాల జాబితా:**
- **WorkflowBuilder**: వర్క్‌ఫ్లోల రూపకల్పన కోసం ప్రధాన ఆరీస్‌త్రేషన్ ఇంజిన్
- **AIAgent**: ప్రత్యేక సామర్థ్యాలతో కూడిన వ్యక్తిగత ఏజెంట్లు
- **Azure OpenAI క్లయింట్**: Azure OpenAI Responses API సమ్మేళనం
- **ఎగ్జిక్యూషన్ కాంటెక్స్ట్**: వర్క్‌ఫ్లో దశల మధ్య స్థితి మరియు డేటా ప్రవాహం నిర్వహణ

## 🎨 **సంస్థా వర్క్‌ఫ్లో రూపకల్పన ప్యాటర్న్లు**

### 📝 **కంటెంట్ ఉత్పత్తి వర్క్‌ఫ్లో**
```
User Request → Content Generation → Quality Review → Final Output
```

### 🔍 **డాక్యుమెంట్ ప్రాసెసింగ్ పైప్‌లైన్**
```
Document Input → Analysis → Extraction → Validation → Structured Output
```

### 💼 **వ్యాపార ఇంటెలిజెన్స్ వర్క్‌ఫ్లో**
```
Data Collection → Processing → Analysis → Report Generation → Distribution
```

### 🤝 **కస్టమర్ సర్వీస్ ఆటోమేషన్**
```
Customer Inquiry → Classification → Processing → Response Generation → Follow-up
```

## 🏢 **సంస్థా లాభాలు**

### 🎯 **నమ్మదగినత మరియు విస్తరణ**
- **నిర్ణాయక ఎగ్జిక్యూషన్**: అనుకూల, పునరావృత వర్క్‌ఫ్లో ఫలితాలు
- **లోప పునరుద్ధరణ**: ఏ వర్క్‌ఫ్లో దశలోనైనా విఫలతలను శాంతంగా నిర్వహించడం
- **ప్రదర్శన మానిటరింగ్**: ఎగ్జిక్యూషన్ గణాంకాలు మరియు సమర్థత అవకాశాలను ట్రాక్ చేయడం
- **వనరు నిర్వహణ**: AI మోడల్ వనరుల సమర్థమైన కేటాయింపు మరియు వినియోగం

### 🔒 **భద్రత & అనుకూలత**
- **భరోసా లభించే ధృవీకరణ**: `az login` ద్వారా Microsoft Entra ID ధృవీకరణ (AzureCliCredential)
- **ఆడిట్ ట్రైల్స్**: వర్క్‌ఫ్లో ఎగ్జిక్యూషన్ మరియు నిర్ణయ స్థానం పూర్తి లాగింగ్
- **ప్రవేశ నియంత్రణ**: వర్క్‌ఫ్లో ఎగ్జిక్యూషన్ మరియు మానిటరింగ్ కోసం విచిత్ర అనుమతులు
- **డేటా గోప్యత**: వర్క్‌ఫ్లోలలో సున్నిత సమాచారం భద్రతతో నిర్వహణ

### 📊 **పరిశీలన & నిర్వహణ**
- **విజువల్ వర్క్‌ఫ్లో డిజైన్**: ప్రక్రియా ప్రవాహాలు మరియు ఆధారాలను స్పష్టంగా ప్రదర్శించడం
- **ఎగ్జిక్యూషన్ మానిటరింగ్**: వర్క్‌ఫ్లో పురోగతి మరియు పనితీరు సకాలంలో ట్రాకింగ్
- **లోప నివేదిక**: విశద లోప విశ్లేషణ మరియు డీబగ్గింగ్ సామర్థ్యాలు
- **ప్రదర్శన విశ్లేషణ**: సమర్థత మరియు సామర్థ్య ప్లానింగ్ కోసం గణాంకాలు

మీ మొదటి సంస్థా-సిద్ధమైన AI వర్క్‌ఫ్లోను నిర్మిద్దాం! 🚀

## 💻 కోడ్ నడపడం

పూర్తి అమలు `01.dotnet-agent-framework-workflow-ghmodel-basic.cs` లో లభ్యమే. ఈ ఫైల్:

1. **పరిసరాల కాన్ఫిగరేషన్** - `.env` ఫైలు నుండి Azure OpenAI కాన్ఫిగరేషన్ లోడ్ చేస్తుంది
2. **Azure OpenAI క్లయింట్ సెటప్** - Azure OpenAI Responses API ఉపయోగించేందుకు క్లయింట్ కాంఫిగర్ చేయడం
3. **ఏజెంట్ సృష్టి** - ప్రత్యేక ఏజెంట్లను నిర్వచించడం (ఫ్రంట్ డెస్క్ మరియు కాన్సియర్‌జ్)
4. **వర్క్‌ఫ్లో బిల్డర్** - క్రమంగా ప్రాసెసింగ్ తో బహుళ ఏజెంట్ వర్క్‌ఫ్లో సృష్టించడం
5. **వర్క్‌ఫ్లో ఎగ్జిక్యూషన్** - స్ట్రీమింగ్ ఫలితాలతో వర్క్‌ఫ్లో నడిపించడం

### 🚀 ఉదాహరణ నడపడం

```bash
# స్క్రిప్టును అమలుకోదగిన (Unix/Linux/macOS)గా మార్చండి
chmod +x 01.dotnet-agent-framework-workflow-ghmodel-basic.cs

# వర్క్‌ఫ్లోను నడిపించండి
./01.dotnet-agent-framework-workflow-ghmodel-basic.cs
```

లేదా Windows లో:
```powershell
dotnet run 01.dotnet-agent-framework-workflow-ghmodel-basic.cs
```

### 📝 అంచనా ఔట్‌పుట్

వర్క్‌ఫ్లో:
1. మీ ప్రయాణ గమ్యం అభ్యర్థనను అంగీకరిస్తుంది ("నాకు పారిస్ వెళ్ళాలని ఉంది")
2. ఫ్రంట్ డెస్క్ ఏజెంట్ ప్రాథమిక సిఫార్సును అందిస్తుంది
3. కాన్సియర్‌జ్ ఏజెంట్ సిఫార్సును సమీక్షించి మెరుగుపరుస్తుంది
4. పూర్తి సంభాషణ స్ట్రీమ్ తుది ఔట్‌పుట్‌లో ప్రదర్శిస్తుంది
