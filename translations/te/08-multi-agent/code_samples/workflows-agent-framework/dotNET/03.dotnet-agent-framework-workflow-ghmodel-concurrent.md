# ⚡ Azure OpenAI (Responses API) తో సమాంతర ఏజెంట్ వర్క్‌ఫ్లోలు (.NET)

## 📋 అధిక-ప్రదర్శన సమాంతర ప్రాసెసింగ్ ట్యుటోరియల్

ఈ నోట్బుక్ Microsoft Agent Frameworkfor .NET మరియు Azure OpenAI (Responses API) ఉపయోగించి **సమకాలీన వర్క్‌ఫ్లో నమూనాలు**ను చూపిస్తుంది. మీరు ఎక్కువ పరిమాణాన్ని గరిష్ట పరిమాణంతో పలువురు AI ఏజెంట్లను సమాంతరంగా నడిపిస్తూ సాంకేతిక సహకారం మరియు డేటా స్థిరత్వాన్ని నిలిపి ఉంచే అధిక-ప్రదర్శన, సమాంతర ప్రాసెసింగ్ వర్క్‌ఫ్లోలను ఎలా నిర్మించాలో నేర్చుకుంటారు.

## 🎯 అభ్యాస లక్ష్యాలు

### 🚀 **సమాంతర ప్రాసెసింగ్ మౌలికాలు**
- **సమాంతర ఏజెంట్ అమలు**: గరిష్ట ప్రదర్శన కోసం పలువురు AI ఏజెంట్లను సమకాలీనంగా నడపాలి
- **Async/Await నమూనాలు**: సమర్థవంతమైన సమకాలీన కోసం .NET యొక్క async ప్రోగ్రామింగ్ మోడయుల్ ఉపయోగించాలి
- **Azure OpenAI (Responses API)**: Azure OpenAI Responses API కి పలువురు సమకాలీన కాల్స్ ను సమన్వయ పరచాలి
- **వనరు నిర్వహణ**: సమాంతర కార్యకలాపాలపై AI మోడల్ వనరులు సమర్థవంతంగా నిర్వహించాలి

### 🏗️ **అధునాతన సమకాలీనం నిర్మాణం**
- **టాస్క్-ఆధారిత సమాంతరత**: గరిష్ట సమాంతర అమలుకోసం .NET Task Parallel Library ఉపయోగించాలి
- **సింక్రనైజేషన్ నమూనాలు**: పోటీ పరిస్థితులను నివారించి సమాంతర ఏజెంట్లను సమన్వయపరచాలి
- **లోడ్ బ్యాలెన్సింగ్**: అందుబాటులో ఉన్న సమాంతర ప్రాసెసింగ్ సామర్థ్యాన్ని సమర్థవంతంగా పంచాలి
- **దోష సహనం**: మొత్తం వర్క్‌ఫ్లోను ఆపు పెట్టకుండా వ్యక్తిగత ఏజెంట్ వైఫల్యాలను నిర్వహించాలి

### 🏢 **ఎంటర్‌ప్రైజ్ సమాంతర అనువర్తనాలు**
- **అధిక పరిమాణ గల డాక్యుమెంట్ ప్రాసెసింగ్**: బహు డాక్యుమెంట్లను సమాంతరంగా ప్రాసెస్ చేయాలి
- **రియల్-టైమ్ కంటెంట్ విశ్లేషణ**: వస్తున్న డేటా స్ట్రీమ్లను సమాంతరంగా విశ్లేషించాలి
- **బ్యాచ్ ప్రాసెసింగ్ ఆప్టిమైజేషన్**: పెద్ద స్థాయిలో డేటా ప్రాసెసింగ్ ఆపరేషన్లకు గరిష్ట పరిమాణం అందించాలి
- **మల్టీ-మోడల్ విశ్లేషణ**: విభిన్న కంటెంట్ రకాలు మరియు ఫార్మాట్లను సమాంతర ప్రాసెస్ చేయాలి

## 💻 కోడ్ నడపడం

పూర్తయిన అమలు `03.dotnet-agent-framework-workflow-ghmodel-concurrent.cs` లో అందుబాటులో ఉంది. ఈ ఫైల్ ప్రయాణ ప్రణాళిక కోసం **ఫ్యాన్-అవుట్/ఫ్యాన్-ఇన్ సమాంతర వర్క్‌ఫ్లో**ని చూపిస్తుంది:

### 🏗️ **వర్క్‌ఫ్లో నిర్మాణం**

```
User Request → ConcurrentStartExecutor → [Researcher Agent || Planner Agent] → ConcurrentAggregationExecutor → Final Output
```

**ముఖ్య భాగాలు:**

1. **ConcurrentStartExecutor**: వినియోగదారు అభ్యర్థనను అన్ని ఏజెంట్లకు ఒకేసారి ప్రసారం చేస్తుంది
2. **Researcher Agent**: గమ్యస్థానాలు మరియు ఆకర్షణలను సమాంతర విశ్లేషించేది
3. **Planner Agent**: సమాంతరంగా విస్తృతమైన ప్రయాణ ప్రణాళికలు తయారు చేయడం
4. **ConcurrentAggregationExecutor**: రెండు ఏజెంట్ల ఫలితాలను తీసుకుని విలీనం చేస్తుంది

### 🎯 **ఫ్యాన్-అవుట్/ఫ్యాన్-ఇన్ నమూనా**

ఈ వర్క్‌ఫ్లో సాధారణ **ఫ్యాన్-అవుట్/ఫ్యాన్-ఇన్** నమూనాను చూపిస్తుంది:
- **ఫ్యాన్-అవుట్**: ఒక ఇన్‌పుట్ సందేశాన్ని చాలా ఏజెంట్లకు ఒకేసారి ప్రసారం చేస్తుంది
- **సమాంతర ప్రాసెసింగ్**: బహుళ ఏజెంట్లు ఒకే టాస్క్ పై సమాంతరంగా పని చేస్తారు
- **ఫ్యాన్-ఇన్**: అన్ని ఏజెంట్ల నుండి ఫలితాలను సేకరించి ఏకీకృత అవుట్పుట్ చేస్తుంది

   - రీసెర్చర్ ఆకర్షణలు మరియు వివరాలను గుర్తిస్తుంది
   - ప్లానర్ పర్యటన సూచనలు మరియు లాజిస్టిక్స్ తయారు చేస్తుంది
3. **సమ్మేళనం**: రెండు ప్రతిపాదనలు చేర్చుకుని మనోగ్రాహక అవుట్పుట్ రూపొందిస్తుంది
4. **కోటేషన్ చూపించు**: విలీనం చేసిన ప్రయాణ ప్రణాళికను ప్రదర్శిస్తుంది

### 🔧 అనుకూలీకరణ ఎంపికలు

**ఇంకా అధిక సమాంతర ఏజెంట్లను జోడించండి:**
```csharp
// Create additional specialized agents
AIAgent budgetAgent = azureClient.GetChatClient(deployment).AsAIAgent(
    name: "Budget-Agent", instructions: "Calculate travel costs...");

// Add to fan-out
var workflow = new WorkflowBuilder(startExecutor)
    .AddFanOutEdge(startExecutor, targets: [researcherAgent, plannerAgent, budgetAgent])
    .AddFanInBarrierEdge(sources: [researcherAgent, plannerAgent, budgetAgent], target: aggregationExecutor)
    .WithOutputFrom(aggregationExecutor)
    .Build();

// Update aggregation count
if (this._messages.Count == 3) { ... }
```

**ఏజెంట్ సూచనలను మార్చండి:**
```csharp
const string ResearcherAgentInstructions = "Your custom instructions for research...";
const string PlanAgentInstructions = "Your custom instructions for planning...";
```

**టాస్క్ మార్చండి:**
```csharp

    workflow, 
    "Plan a European vacation for 2 weeks in summer"

```

### 🎯 వాస్తవ ప్రపంచ అనువర్తనాలు

ఈ సమాంతర నమూనా సరైనది:
- **కంటెంట్ సృష్టి**: బహుళ రచయితలు వివిధ విభాగాలను సమాంతరంగా సృష్టిస్తున్నారు
- **కోడ్ సమీక్ష**: పలు సమీక్షకులు కోడ్ ను విభిన్న కోణాల్లో సమీక్షిస్తున్నారు
- **మార్కెట్ రీసెర్చ్**: విభిన్న మార్కెట్ సెగ్మెంట్లను సమాంతర విశ్లేషణ
- **డాక్యుమెంట్ ప్రాసెసింగ్**: సమకాలీనంగా డేటా ఆపేక్ష, విశ్లేషణ, ధృవీకరణ
- **బహుళ-దృష్టికోణ విశ్లేషణ**: ఒకే ఇన్‌పుట్ పై వైవిధ్యమైన అభిప్రాయాలు సేకరణ

### 🔍 అనుకూల ఎగ్జిక్యూటర్లను అవగాహన

**ConcurrentStartExecutor:**
- స్ట్రింగ్ ఇన్‌పుట్‌ను స్వీకరించడానికి `IMessageHandler<string>` ను అమలు చేస్తుంది
- కనెక్ట్ చేసిన అన్ని ఏజెంట్లకు సందేశాలు ప్రసారం చేస్తుంది
- సమాంతర ప్రాసెసింగ్ ప్రారంభించడానికి `TurnToken` పంపుతుంది

**ConcurrentAggregationExecutor:**
- ఏజెంట్ ప్రతిస్పందనలను స్వీకరించడానికి `IMessageHandler<ChatMessage>` ను అమలు చేస్తుంది
- థ్రెడ్-సేఫ్ విధంగా సందేశాలను సేకరిస్తుంది
- అన్ని எதிர్పోజనాలు వచ్చినప్పుడు విలీనం చేస్తుంది
- `context.YieldOutputAsync()` ఉపయోగించి తుది అవుట్పుట్ ఇస్తుంది

### ⚡ ప్రదర్శన లాభాలు

**సమాంతర vs అనుక్రమిక:**
- అనుక్రమిక: Agent1 (30సెకన్లు) → Agent2 (30సెకన్లు) = **మొత్తం 60 సెకన్లు**
- సమాంతర: Agent1 (30సెకన్లు) || Agent2 (30సెకన్లు) = **మొత్తం 30 సెకన్లు**

**థ్రూపుట్ మెరుగుదల**: N సమాంతర ఏజెంట్లకు N× సేపు వేగవంతం (పని భారాలు మరియు వనరులపై ఆధారపడి)

### 🛡️ లోప నిర్వహణ

వర్క్‌ఫ్లో వ్యక్తిగత ఏజెంట్ వైఫల్యాలను సజావుగా నిర్వహిస్తుంది:
- ఒక ఏజెంట్ వైఫల్యమైతే, ఇతరులు ప్రాసెస్ చేస్తూ కొనసాగుతారు
- సమ్మేళన యంత్రం టైమ్ అవుట్ లాజిక్ అమలు చేయొచ్చు
- అవసరమైతే భాగస్వామ్య ఫలితాలు ఇవ్వవచ్చు
