# ⚡ Azure OpenAI (Responses API) తో సమకాలీన ఏజెంట్ వర్క్‌ఫ్లోలు (.NET)

## 📋 అధిక పనితీరు సమాంతర ప్రాసెసింగ్ ట్యుటోరియల్

ఈ నోట్‌బుక్‌ Microsoft Agent Framework for .NET మరియు Azure OpenAI (Responses API) ను ఉపయోగించి **సమకాలీన వర్క్‌ఫ్లో నమూనాలు** ను చూపిస్తుంది. మీరు సమన్వయం మరియు డేటా అనుకూలతను కాపాడుతూ అనేక AI ఏజెంట్లను ఒకేసారి అమలు చేయడం ద్వారా గరిష్ట స్థాయిలో అధిక పనితీరు, సమాంతర ప్రాసెసింగ్ వర్క్‌ఫ్లోలను ఎలా నిర్మించాలో నేర్చుకుంటారు.

## 🎯 నేర్చుకునే లక్ష్యాలు

### 🚀 **సమకాలీన ప్రాసెసింగ్ మౌలికాలు**
- **సమాంతర ఏజంట్ అమలు**: గరిష్ట పనితీరు కోసం అనేక AI ఏజెంట్లను ఒకేసారి నడపండి
- **అసింక్/అవైట్ రూపకల్పన**: సమర్థవంతమైన సమకాలీనత కోసం .NET యొక్క అసింక్ ప్రోగ్రామింగ్ మోడల్‌ను ఉపయోగించండి
- **Azure OpenAI (Responses API)**: Azure OpenAI Responses API కి అనేక సమకాలీన కాల్‌లను సమన్వయం చేయండి
- **వనరుల నిర్వహణ**: సమకాలీన కార్యకలాపాల అంతటా AI మోడల్ వనరులను సమర్థవంతంగా నిర్వహించండి

### 🏗️ **అధునాతన సమకాలీన ఆర్కిటెక్చర్**
- **టాస్క్-ఆధారిత సమాంతరత**: అత్యుత్తమ సమకాలీన అమలుకు .NET Task Parallel Library ఉపయోగించండి
- **సింక్రోనైజేషన్ నమూనాలు**: రేస్ కండిషన్లను నివారించి సమకాలీన ఏజెంట్లను సమన్వయ పరచండి
- **లోడ్ బ్యాలన్సింగ్**: అందుబాటులో ఉన్న సమకాలీన ప్రాసెసింగ్ సామర్థ్యం అంతటా పనిని సమర్థవంతంగా పంపిణీ చేయండి
- **ఫాల్ట్ టోలరెన్స్**: మొత్తం వర్క్‌ఫ్లోని ఆపకుండా వ్యక్తిగత ఏజెంట్ విఫలాలను నిర్వహించండి

- **ఉన్నత వాల్యూమ్ డాక్యుమెంట్ ప్రాసెసింగ్**: అనేక డాక్యుమెంట్లను సమాంతరంగా ప్రాసెస్ చేయండి

- **మల్టీ-మోడ్ విశ్లేషణ**: వివిధ కంటెంట్ రకాల మరియు ఫార్మాట్ల సమాంతర ప్రాసెసింగ్

- **ప్రాసెసింగ్ సమయం తగ్గింపు**: సమాంతర అమలుతో గణనీయమైన సమయం తగ్గుదల

## 💻 కోడ్ నడిపించడం

పూర్తి అమలు `03.dotnet-agent-framework-workflow-ghmodel-concurrent.cs` లో అందుబాటులో ఉంది. ఈ ఫైల్ ప్రయాణ ప్రణాళిక కోసం **ఫ్యాన్-అవుట్/ఫ్యాన్-ఇన్ సమకాలీన వర్క్‌ఫ్లో** ను చూపిస్తుంది:

### 🏗️ **వర్క్‌ఫ్లో ఆర్కిటెక్చర్**

```
User Request → ConcurrentStartExecutor → [Researcher Agent || Planner Agent] → ConcurrentAggregationExecutor → Final Output
```

**ప్రధాన భాగాలు:**

1. **ConcurrentStartExecutor**: వినియోగదారు అభ్యర్థనను అన్ని ఏజెంట్లకు ఒకేసారి ప్రసారం చేస్తుంది
2. **Researcher Agent**: గమ్యస్థానాలను మరియు ఆకర్షణలను సమాంతరంగా విశ్లేషిస్తుంది
3. **Planner Agent**: సమాంతరంగా వివరణాత్మక ప్రయాణ ప్రణాళికలను తయారు చేస్తుంది
4. **ConcurrentAggregationExecutor**: రెండు ఏజెంట్ల నుండి ఫలితాలను సేకరించి విలీనం చేస్తుంది

### 🎯 **ఫ్యాన్-అవుట్/ఫ్యాన్-ఇన్ నమూనా**

ఈ వర్క్‌ఫ్లో క్లాసిక్ **ఫ్యాన్-అవుట్/ఫ్యాన్-ఇన్** నమూనాను చూపిస్తుంది:
- **ఫ్యాన్-అవుట్**: ఒక ఇన్‌పుట్ సందేశం అనేక ఏజెంట్లకు ఒకేసారి ప్రసారం చేయబడుతుంది
- **సమకాలీన ప్రాసెసింగ్**: అనేక ఏజెంట్లు ఒకే పనిపై సమాంతరంగా పని చేస్తారు
- **ఫ్యాన్-ఇన్**: అన్ని ఏజెంట్ల నుంచి ఫలితాలు సేకరించి ఒకే అవుట్పుట్‌గా విలీనం చేయబడతాయి

   - పరిశోధకుడు ఆకర్షణలు మరియు వివరాలను గుర్తిస్తాడు
   - ప్లానర్ యాత్రా ప్రణాళిక మరియు లాజిస్టిక్స్ తయారుచేస్తాడు
3. **సమీకరణ**: రెండు ప్రతిస్పందనలని సమగ్ర అవుట్పుట్‌గా విలీనం చెయ్యడం
4. **ఫలితాలను ప్రదర్శించు**: అన్ని సమాచారంతో సమ్మిళిత ప్రయాణ ప్రణాళికను చూపించండి

### 🔧 అనుకూలీకరణ ఎంపికలు

**మరింత సమకాలీన ఏజెంట్లను చేర్చండి:**
```csharp
// Create additional specialized agents
AIAgent budgetAgent = azureClient.GetOpenAIResponseClient(deployment).CreateAIAgent(

    .AddFanInEdge(aggregationExecutor, sources: [researcherAgent, plannerAgent, budgetAgent])
    .WithOutputFrom(aggregationExecutor)
    .Build();

// Update aggregation count
if (this._messages.Count == 3) { ... }
```

**ఏజెంట్ సూచనలను మార్చండి:**
```csharp
const string ResearcherAgentInstructions = "Your custom instructions for research...";
```

**పనిని మార్చండి:**

### 🎯 వాస్తవ ప్రపంచ అనువర్తనాలు

ఈ సమకాలీన నమూనా ఈ క్రింద వాటికి అనుకూలం:
- **కంటెంట్ సృష్టి**: అనేక రచయితలు విభిన్న విభాగాలను సమాంతరంగా సృష్టించడం
- **కోడ్ సమీక్ష**: వివిధ కోణాల నుండి అనేక సమీక్షకులు కోడ్‌ను విశ్లేషించడం
- **మార్కెట్ రీసర్చ్**: వివిధ మార్కెట్ సెగ్మెంట్ల సమాంతర విశ్లేషణ
- **డాక్యుమెంట్ ప్రాసెసింగ్**: సమాంతర వస్త్రీకరణ, విశ్లేషణ, మరియు ధృవీకరణ
- **బహు-దృష్టికోణ విశ్లేషణ**: ఒకే ఇన్‌పుట్ పైన విభిన్న దృష్టికోణాల పొందడం

### 🔍 అనుకూల ఎగ్జిక్యూటర్ల అర్థం చేసుకోవడం

**ConcurrentStartExecutor:**
- `IMessageHandler<string>` ని అమలుచేసి స్ట్రింగ్ ఇన్‌పుట్‌ను స్వీకరిస్తుంది
- కనెక్ట్ అయిన అన్ని ఏజెంట్లకు సందేశాలను ప్రసారం చేస్తుంది
- సమకాలీన ప్రాసెసింగ్ ప్రారంభించడానికి `TurnToken` ను పంపిస్తుంది

**ConcurrentAggregationExecutor:**
- `IMessageHandler<ChatMessage>` ని అమలుచేసి ఏజెంట్ ప్రతిస్పందనలను స్వీకరిస్తుంది
- సందేశాలను థ్రెడ్-సురక్షితంగా సేకరిస్తుంది
- అన్ని అంచనా ప్రతిస్పందనలు వచ్చినప్పుడు సమీకరణ చేస్తుంది
- `context.YieldOutputAsync()` ఉపయోగించి తుది అవుట్పుట్‌ను ఇస్తుంది

### ⚡ పనితీరు లాభాలు

**సమకాలీన vs ధార్మిక:**
- ధార్మిక: Agent1 (30s) → Agent2 (30s) = **మొత్తం 60 సెకన్లు**
- సమకాలీన: Agent1 (30s) || Agent2 (30s) = **మొత్తం 30 సెకన్లు**

**throughput మెరుగుదల**: N సమకాలీన ఏజెంట్లకు వరుసగా N రెట్లు వేగంగా (పని మరియు వనరుల ఆధారంగా)

### 🛡️ లోప నిర్వహణ

వర్క్‌ఫ్లో వ్యక్తిగత ఏజెంట్ విఫలాలను శ్రద్ధగా నిర్వహిస్తుంది:
- ఒక ఏజెంట్ విఫలమైతే, ఇతరులు పనిచేయడం కొనసాగిస్తారు
- సమీకరణయంత్రం టైమౌట్ లాజిక్‌ను అమలు చేయవచ్చు
- అవసరమైతే భాగశీల ఫలితాలు అందించవచ్చు
