## సెటప్ కమాండ్లు

### పూర్వాపేక్షలు
- పైథాన్ 3.12 లేదా అంతకంటే పైగా
- అజ్యూర్ సబ్స్క్రిప్షన్ (మైక్రోసాఫ్ట్ ఫౌండ్రి కోసం)
- అజ్యూర్ CLI ఇన్స్టాల్ చేసి, ధ్రువీకరించాలి (`az login`)

### ప్రాథమిక సెటప్

1. **రీపాజిటరీని క్లోన్ చేయండి లేదా ఫోর্ক్ చేయండి:**
   ```bash
   gh repo fork microsoft/ai-agents-for-beginners --clone
   # లేదా
   git clone https://github.com/microsoft/ai-agents-for-beginners.git
   cd ai-agents-for-beginners
   ```

2. **Python వర్చువల్ ఎన్విరాన్‌మెంట్‌ని సృష్టించి యాక్టివేట్ చేయండి:**
   ```bash
   python3 -m venv venv
   source venv/bin/activate  # విండోస్‌లో: venv\Scripts\activate
   ```

3. **ఆవశ్యక డిపెండెన్సీలను ఇన్స్టాల్ చేయండి:**
   ```bash
   pip install -r requirements.txt
   ```

4. **పరిసర వేరియబుల్స్ సెట్ చేయండి:**
   ```bash
   cp .env.example .env
   # మీ API కీలు మరియు ఎండ్పాయింట్లతో .env ను మార్చండి
   ```

### అవసరమైన పరిసర వేరియబుల్స్

**Microsoft Foundry** కోసం (అవసరం):
- `AZURE_AI_PROJECT_ENDPOINT` - Microsoft Foundry ప్రాజెక్ట్ ఎండ్పాయింట్
- `AZURE_AI_MODEL_DEPLOYMENT_NAME` - మోడల్ డిప్లాయ్‌మెంట్ పేరు (ఉదా: gpt-4o)

**Azure AI Search** కోసం (పాఠం 05 - RAG):
- `AZURE_SEARCH_SERVICE_ENDPOINT` - Azure AI Search ఎండ్పాయింట్
- `AZURE_SEARCH_API_KEY` - Azure AI Search API కీ

ధ్రువీకరణ: నోట్బుక్స్ నడపడానికి ముందు `az login` నడిపించండి (`AzureCliCredential` ఉపయోగిస్తుంది).

### Microsoft Agent Frameworkతో పని చేయడం

**Microsoft Agent Framework + Microsoft Foundry:**
- అజ్యూర్ సబ్స్క్రిప్షన్ అవసరం
- Agent Service V2 కోసం `FoundryChatClient` ఉపయోగిస్తుంది (Foundry పోర్టల్‌లో ఏజెంట్లు కనిపిస్తాయి)

3. **ప్యాకేజీ ఘర్షణలు:**
   - తాజా వర్చువల్ ఎన్విరాన్‌మెంట్ ఉపయోగించండి
   - `requirements.txt` ద్వారా ఇన్స్టాల్ చెయ్యండి, ఒక్కో ప్యాకేజ్ కాకుండా
   - కొన్ని నోట్బుక్స్.markdown cells లో పేర్కొన్న అదనపు ప్యాకేజీలను అవసరం కావచ్చు

4. **అజ్యూర్ సర్వీసులు:**
   - అజ్యూర్ ఆర్ ఐ సర్వీసులకు క్రియాశీల సభ్యత్వం అవసరం
   - కొన్నిసేవలు ప్రాంత-విశిష్టంగా ఉంటాయి
   - మీ అజ్యూర్ OpenAI మోడల్ డిప్లాయ్‌మెంట్ Responses API ని మద్దతిస్తుంది అని నిర్ధారించుకోండి
