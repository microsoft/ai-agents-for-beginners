## సెటప్ ఆదేశాలు

### ముందుగా అవసరమైనవి
- పైథాన్ 3.12 లేదా అంతకంటె పైగా
- అజుర్ సభ్యత (మైక్రోసాఫ్ట్ ఫౌండ్రీ కొరకు)
- అజుర్ CLI ఇన్స్టాల్ చేసి ప్రవేశించాలి (`az login`)

### ప్రాథమిక సెటప్

1. **రిపాజిటరీని క్లోన్ లేదా ఫోర్క్ చేయండి:**
   ```bash
   gh repo fork microsoft/ai-agents-for-beginners --clone
   # OR
   git clone https://github.com/microsoft/ai-agents-for-beginners.git
   cd ai-agents-for-beginners
   ```

2. **పైథాన్ వర్చువల్ ఎన్విరాన్‌మెంట్ సృష్టించి యాక్టివేట్ చేయండి:**
   ```bash
   python3 -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   ```

3. **డిపెండెన్సీలను ఇన్స్టాల్ చేయండి:**
   ```bash
   pip install -r requirements.txt
   ```

4. **పరిసర వేరియబుల్స్ సెట్ చేయండి:**
   ```bash
   cp .env.example .env
   # Edit .env with your API keys and endpoints
   ```

### అవసరమైన పరిసర వేరియబుల్స్

**మైక్రోసాఫ్ట్ ఫౌండ్రీ** కోసం (అవసరం):
- `AZURE_AI_PROJECT_ENDPOINT` - మైక్రోసాఫ్ట్ ఫౌండ్రీ ప్రాజెక్ట్ ఎండ్‌పాయింట్
- `AZURE_AI_MODEL_DEPLOYMENT_NAME` - మోడల్ డిప్లాయ్‌మెంట్ పేరు (ఉదా: gpt-5-mini)

**అజుర్ ఆర్.ఐ. సెర్చ్** కోసం (పాఠం 05 - RAG):
- `AZURE_SEARCH_SERVICE_ENDPOINT` - అజుర్ ఆర్.ఐ. సెర్చ్ ఎండ్‌పాయింట్
- `AZURE_SEARCH_API_KEY` - అజుర్ ఆర్.ఐ. సెర్చ్ API కీ

ప్రామాణీకరణ: నోట్బుక్స్ నడపడం ముందు `az login` నడిపించండి (`AzureCliCredential` ని ఉపయోగిస్తుంది).

## అభివృద్ధి పని ప్రవాహం

### జూపిటర్ నోట్బుక్స్ నడపడం

ప్రతి పాఠానికి వివిధ ఫ్రేమ్వర్క్ల కొరకు బహుబంద జూపిటర్ నోట్బుక్స్ ఉంటాయి:

1. **జూపిటర్ ప్రారంభించండి:**
   ```bash
   jupyter notebook
   ```

2. **ఒక పాఠం డైరెక్టరీకి నావిగేట్ చేయండి** (ఉదా: `01-intro-to-ai-agents/code_samples/`)

3. **నోట్బుక్స్ తెరవండి మరియు నడిపించండి:**
   - `*-python-agent-framework.ipynb` - మైక్రోసాఫ్ట్ ఏజెంట్ ఫ్రేమ్వర్క్ (పైథాన్)
   - `*-dotnet-agent-framework.ipynb` - మైక్రోసాఫ్ట్ ఏజెంట్ ఫ్రేమ్వర్క్ (.NET)

### మైక్రోసాఫ్ట్ ఏజెంట్ ఫ్రేమ్వర్క్ తో పని

**మైక్రోసాఫ్ట్ ఏజెంట్ ఫ్రేమ్వర్క్ + మైక్రోసాఫ్ట్ ఫౌండ్రీ:**
- అజుర్ సభ్యత అవసరం
- ఏజెంట్ సర్వీస్ V2 కొరకు `FoundryChatClient` ఉపయోగిస్తుంది (ఏజెంట్లు ఫౌండ్రీ పోర్టల్‌లో కనిపిస్తాయి)
- ఉత్పత్తి-సిద్ధమైన బిల్ట్-ఇన్ ఆబ్జర్వబిలిటీతో
- ఫైల్ నమూనా: `*-python-agent-framework.ipynb`

## టెస్టింగ్ సూచనలు

ఇది ఉదాహరణ కోడ్ తో ఉన్న విద్యా రిపాజిటరీ మాత్రమే; ఉత్పత్తి కోడ్ కాదు మరియు ఆటోమేటెడ్ టెస్ట్స్ లేవు. మీ సెటప్ మరియు మార్పులను ధృవీకరించడానికి:

### మాన్యువల్ టెస్టింగ్

1. **పైథాన్ పరిసరాన్ని పరీక్షించండి:**
   ```bash
   python --version  # Should be 3.12+
   pip list | grep -E "(agent-framework|azure-ai|azure-identity)"
   ```

2. **నోట్బుక్ అమలు పరీక్షించండి:**
   ```bash
   # Convert notebook to script and run (tests imports)
   jupyter nbconvert --to script <lesson-folder>/code_samples/<notebook>.ipynb --stdout | python
   ```

3. **పరిసర వేరియబుల్స్‌ని ధృవీకరించండి:**
   ```bash
   python -c "import os; from dotenv import load_dotenv; load_dotenv(); print('✓ AZURE_AI_PROJECT_ENDPOINT' if os.getenv('AZURE_AI_PROJECT_ENDPOINT') else '✗ AZURE_AI_PROJECT_ENDPOINT missing')"
   ```

### వ్యక్తిగత నోట్బుక్స్ నడపడం

జూపిటర్‌లో నోట్బుక్స్ తెరవండి మరియు క్రమం తప్పకుండా సెల్లులను అమలు చేయండి. ప్రతి నోట్బుక్ స్వయంపూర్తిగా ఉంటుంది మరియు ఇలాంటి అంశాలు కలిగి ఉంటుంది:
- ఇంపోర్ట్ స్టేట్మెంట్స్
- కాన్ఫిగరేషన్ లోడింగ్
- ఉదాహరణ ఏజెంట్ అమలులు
- మార్క్డౌన్ సెల్లులలో అంచనా ఫలితాలు

### అమర్చిన ఏజెంట్ల స్మోక్-టెస్టింగ్

మైక్రోసాఫ్ట్ ఫౌండ్రీ హోస్టెడ్ ఏజెంట్‌గా ఏజెంట్ అమర్చిన పాఠాలలో (01, 04, 05, 16), రిపో లో స్మోక్-టెస్ట్ క్యాటలాగ్లు `tests/` క్రింద ఉంటాయి, వీటిని `.github/workflows/smoke-test.yml` వర్క్‌ఫ్లో ద్వారా [AI Smoke Test](https://github.com/marketplace/actions/ai-smoke-test) చర్య చేస్తుంది. ఇవి లైట్‌వైట్ పోస్ట్-డిప్లాయ్ గేట్‌లా ఉంటాయి (ఏజెంట్ చేరుమదలైనదా మరియు ప్రాథమిక ప్రాంప్ట్ అంచనాలను అనుసరిస్తున్నదా?), పాఠాలు 10 మరియు 16 లోని మూల్యాంకన పైప్లైన్‌ను పూర్తి చేస్తాయి. కॅటలాగ్-టు-పాఠం-టు-ఏజెంట్ మ్యాపింగ్ కోసం [tests/README.md](./tests/README.md) చూడండి. పాఠం 17 స్థానికంగా ఫౌండ్రీ లోకల్‌తో నడుస్తుంది మరియు హోస్టెడ్ ఎండ్‌పాయింట్ లేదు, కావున ఇది నేరుగా నోట్బుక్ నడిపించడం ద్వారా ధృవీకరించబడుతుంది.

   - కాన్సెప్ట్ చూపించే నోట్బుక్ ఔట్పుట్లను ఉంచండి
   - తాత్కాలిక ఫైలు మరియు బ్యాకప్ నోట్బుక్స్ (`*-backup.ipynb`) తొలగించండి
