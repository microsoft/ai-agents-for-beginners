> ```
>
> **CMD (విండోస్):**
> ```cmd
> git clone --filter=blob:none --sparse https://github.com/microsoft/ai-agents-for-beginners.git

> ```
>
> ఇది మీకు కోర్సును పూర్తి చేయడానికిష్టమైన ప్రతీదింనీ వేగంగా డౌన్లోడ్ చేసుకోవడానికి సహాయపడుతుంది.

## 🌱 ప్రారంభించడము

ఈ కోర్సులో AI ఏజెంట్లు తయారు చేయడం వంటి మౌలిక అంశాలపై పాఠాలున్నాయి. ప్రతి పాఠం దాని యొక్క ప్రత్యుత్తర విషయాన్ని కవర్ చేస్తుంది కాబట్టి మీరు అనుకున్న ఏ հատվածమైనా ప్రారంభించండి!

ఈ కోర్సుకు బహుభాషా మద్దతు ఉంది. మన [అందుబాటులోని భాషలు ఇక్కడ](#-multi-language-support) చూడండి.

ఇది మీ మొదటి సారి Generative AI మోడల్స్ తో పనిచేస్తున్నట్లయితే, మా [Generative AI For Beginners](https://aka.ms/genai-beginners) కోర్సును చూడండి, ఇందులో GenAI తో పని చేయడం పై 21 పాఠాలు ఉన్నాయి.

ఈ రిపోకు [స్టార్ (🌟) ఇవ్వడం](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst) మరియు కోడ్ నడిపించేందుకు [ఫార్క్ చేయడం](https://github.com/microsoft/ai-agents-for-beginners/fork) మర్చిపోకండి.

### ఇతర నేర్చుకునేవారిని కలుసుకోండి, మీ ప్రశ్నలకు సమాధానాలు పొందండి

మీరు ఇబ్బంది పడితే లేదా AI ఏజెంట్లు తయారుచేసే విషయంపై ఏదైనా ప్రశ్న ఉంటే, మా [Microsoft Foundry Discord](https://aka.ms/ai-agents/discord)లో ఉన్న ప్రత్యేక Discord చానల్‌లో చేరండి.

### మీకు కావలసినది

ఈ కోర్సు ప్రతి పాఠంలో కోడ్ ఉదాహరణలు ఉంటాయి, ఇవి code_samples ఫోల్డర్‌లో ఉన్నాయి. మీరు [ఈ రిపోను ఫార్క్](https://github.com/microsoft/ai-agents-for-beginners/fork) చేసుకొని మీ స్వంత కాపీ రూపొందించవచ్చు.

ఈ వ్యాయామాలలో కుడి కోడ్ ఉదాహరణలు Microsoft Agent Framework తో Microsoft Foundry Agent Service V2 ను ఉపయోగిస్తాయి:

- [Microsoft Foundry](https://aka.ms/ai-agents-beginners/ai-foundry) - Azure ఖాతా అవసరం

ఈ కోర్సు అనుసరించి క్రింది Microsoft AI ఏజెంట్ ఫ్రేమ్‌వర్క్లు మరియు సేవలను ఉపయోగిస్తుంది:

- [Microsoft Agent Framework (MAF)](https://learn.microsoft.com/agent-framework/overview/)
- [Microsoft Foundry Agent Service V2](https://aka.ms/ai-agents-beginners/ai-agent-service)

కొన్ని కోడ్ నమూనాలు ప్రత్యామ్నాయ OpenAI-అనుకూల ప్రొవైడర్లను కూడా మద్దతు ఇస్తాయి, ఉదాహరణకి [MiniMax](https://platform.minimaxi.com/), ఇది పెద్ద కంటెక్స్ట్ మోడల్స్ (204K టోకెన్ల వరకు) అందిస్తుంది. కాన్ఫిగరేషన్ వివరాల కోసం [Course Setup](./00-course-setup/README.md) చూడండి.

ఈ కోర్సుకు సంబంధించిన కోడ్ నడిపించడానికివరకు మరిన్ని సమాచారం కోసం, [Course Setup](./00-course-setup/README.md) కి వెళ్ళండి.
