## 🌱 ప్రారంభించండి

ఈ కోర్సులో AI ఏజెంట్లను నిర్మించడానికి మూలాంశాలపై పాఠాలు ఉన్నాయి. ప్రతి పాఠం తన స్వంత విషయాన్ని కవర్ చేస్తుంది కాబట్టి మీరు మీ ఇష్టమైన చోట ఎక్కడైనా మొదలు పెట్టండి!

ఈ కోర్సుకు బహుభాషా మద్దతు ఉంది. మా [అందుబాటులో ఉన్న భాషల ](#-multi-language-support)వైపు వెళ్లండి.

ఇది మీ మొదటి సారి జనరేటివ్ AI మోడల్స్‌తో నిర్మించడం అయితే, మా [Generative AI For Beginners](https://aka.ms/genai-beginners) కోర్సును చూడండి, ఇందులో GenAIతో నిర్మించడానికి 21 పాఠాలు ఉన్నాయి.

ఈ రిపోను [నక్షత్రం (🌟) పెట్టడం](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst) మరియు కోడ్ నడపడానికి [ఫోర్క్ చేయడం](https://github.com/microsoft/ai-agents-for-beginners/fork) మరువవద్దు.

### ఇతర అభ్యసకులను కలవండి, మీ ప్రశ్నలకు సమాధానాలు పొందండి

మీరు చిక్కుకున్నట్లయితే లేదా AI ఏజెంట్ల నిర్మాణంపై ఏవైనా ప్రశ్నలు ఉంటే, మా ప్రత్యేక Discord ఛానల్ లో చేరండి [Microsoft Foundry Discord](https://aka.ms/ai-agents/discord).

### మీకు అవసరం ఏమి ఉంది

ఈ కోర్సులోని ప్రతి పాఠంలో కోడ్ ఉదాహరణలు ఉంటాయి, అవి code_samples ఫోల్డర్‌లో లభ్యమవుతాయి. మీరు [ఈ రిపోను ఫోర్క్](https://github.com/microsoft/ai-agents-for-beginners/fork) చేయవచ్చు మీ స్వంత కాపీ సృష్టించడానికి.

ఈ వ్యాయామాలలోని కోడ్ ఉదాహరణలు Microsoft Agent Framework ని Microsoft Foundry Agent Service V2 తో ఉపయోగిస్తున్నాయి:

- [Microsoft Foundry](https://aka.ms/ai-agents-beginners/ai-foundry) - Azure ఖాతా అవసరం

ఈ కోర్సులో క్రింది Microsoft AI ఏజెంట్ ఫ్రేమ్‌వర్క్‌లు మరియు సేవలను ఉపయోగిస్తారు:

- [Microsoft Agent Framework (MAF)](https://aka.ms/ai-agents-beginners/agent-framework)
- [Microsoft Foundry Agent Service V2](https://aka.ms/ai-agents-beginners/ai-agent-service)

కొన్ని కోడ్ నమూనాలు [MiniMax](https://platform.minimaxi.com/) వంటి OpenAI-పాటుగా ఉన్న ప్రత్యామ్నాయ ప్రొవైడర్లను కూడా మద్దతు ఇస్తాయి, ఇది పెద్ద కంటెంట్ మోడల్స్ (204K టోకెన్ల వరకు) అందిస్తుంది. కాన్ఫిగరేషన్ వివరాలకు [Course Setup](./00-course-setup/README.md) చూడండి.

ఈ కోర్సు కోసం కోడ్ నడపడానికి మరిన్ని సమాచారం కోసం [Course Setup](./00-course-setup/README.md) చూడండి.
