## ఈవెంట్ పేరు: LangGraph మరియు Azure Cosmos DB తో బహుళ-ఏజెంట్ API

## వివరణ

బహుళ-ఏజెంట్ AI అప్లికేషన్ల ముందు రావడం మనం తెలివైన వ్యవస్థలు ఎలా నిర్మించాలో మార్చేస్తోంది — కానీ వాటిని నిజ ప్రపంచ స్కేలబిల్ మరియు పనితీరు కోసం ఎలా ఆర్చిటెక్ట్ చేయాలి? ఈ సెషన్ లో, మేము LangGraph తో ఏజెంట్ ఆర్కెస్ట్రేషన్, API లేయర్ కోసం FastAPI, మరియు స్థితి నిర్వహణ, వెక్టార్ నిల్వ, లావాదేవీ డేటా కోసం Azure Cosmos DB వాడి నిర్మించిన ప్రొడక్షన్-గ్రేడ్ బహుళ-ఏజెంట్ అప్లికేషన్ లో లోతుగా చూడబోతున్నాము.

విస్తృతమైన కోడ్ వాక్‌త్రూ ద్వారా, మీరు retrieval-augmented generation (RAG), మెమరీ పెర్సిస్టెన్స్, మరియు డైనమిక్ స్టేట్ ట్రాన్సిషన్స్ ను సజావుగా అంతర్నిర్మించుకునే ఏజెంట్-నిర్మాణ వర్క్‌ఫ్లో డిజైన్ మరియు అమలును ఎలా చేయాలో చూసేరు. మేము కవర్ చేస్తాము:

LangGraph తో ఏజెంట్ సహకారం - నిర్మిత తర్కానికి
Azure Cosmos DB ఉపయోగించి రియల్-టైమ్ చాట్ హిస్టరీ నిల్వ - చాట్GPTరచయిత చాట్ హిస్టరీకి సహాయం చేసిన అదే డేటాబేస్
Cosmos DB స్థానిక ఎంబెడ్డింగ్స్ మద్దతుతో సంకేత శోధన కోసం జ్ఞానం రీప్రీవల్
FastAPI యొక్క అసింక్రోనస్ సామర్థ్యాలతో పరస్పర చర్యలను స్పందనాత్మకంగా మరియు స్కేలబుల్ గా ఉంచండి
సెషన్ చివరకి, మీరు ఆధునిక AI మరియు క్లౌడ్ మౌలిక సదుపాయాలను ఉపయోగించి మీ స్వంత స్కేలబుల్, క్లౌడ్-స్వదేశీ బహుళ-ఏజెంట్ అప్లికేషన్లను నిర్మించి పంపిణీ చేసే స్పష్టమైన బ్లూ-print‌ని పొందుతారు. మీరు AI ఇంజనీర్, క్లౌడ్ ఆర్కిటెక్ట్ లేదా Python డెవలపర్ అయినా, ఈ టాక్ మీకు ప్రాక్టికల్ పరిజ్ఞానాలను మరియు యుద్ధ పరీక్షల ప్యాటర్న్లను అందిస్తుంది తద్వారా మీరు తదుపరి తరం AI-శక్తివంతమైన అప్లికేషన్లను నిర్మించగలరు.

## ఈవెంట్ పేరు: ప్రాంప్టింగ్ కొత్త స్క్రిప్టింగ్: GenAIScript తో పరిచయం

## వివరణ

jQuery ఒకసారిగా వెబ్ అభివృద్ధిని సులభతరం చేసింది, బ్రౌజర్ లో సమస్యలతో పోరాడకుండా డెవలపర్లను నిర్మాణంపై దృష్టి పెట్టేలా abstractions అందించడం ద్వారా. ఈ రోజు, AI అభివృద్ధి కూడా ఇనిసేర్పాటు ఒక సవాలు ఎదుర్కొంటోంది. కొత్త ప్యాటర్న్లు తరచుగా వస్తుంటాయి మరియు వాటి తోపాటు ఉండటం ఒత్తిడి కలిగిస్తుంది, ముఖ్యంగా AI టూల్స్—ప్రత్యేకంగా ఏజెంటిక్ టూల్స్— మరింత శక్తివంతంగా మరియు క్లిష్టంగా మారుతున్నప్పుడు. మీరు సులభంగా, మీకు పరిచయమైన JavaScript abstractions ఉపయోగించి టాస్కులను ఆటోమేట్ చేయగలిగితే ఎలా ఉంటుంది? GenAIScript ప్రవేశించండి—ఇది AI ని మీ వర్క్‌ఫ్లోలో సజావుగా చేర్చడానికి ఒక విధానం, ప్రాంప్ట్స్ ని పునర్వినియోగించదగిన కోడ్ స్నిపెట్లలా భావిస్తుంది. ఈ టాక్ లో, GenAIScript AI ఆటోమేషన్ ఏజెంట్స్ ను JavaScript వ్రాయటం వలే సులభంగా ఎలా చేస్తుందో పరిశీలిస్తాము, దీని ద్వారా మీరు AI లో లోతైన పరిజ్ఞానం లేకుండా మళ్లింపుగా పని సరళీకృతం చేసుకోవచ్చు.

LlamaIndex Retrieval-Augmented Generation (RAG) ను సులభతరం చేయుటకు ప్రసిద్ధి చెందింది, కానీ మన ఫ్రేమ్‌వర్క్స్ ఏజెంట్స్ మరియు బహుళ-ఏజెంట్ సిస్టమ్స్ ను కూడా సులభంగా నిర్మించేందుకు వీలు కల్పిస్తాయి! ఈ సెషన్ లో మనం Workflows ను పరిచయం చేస్తాము, ఇది ఏజెంటిక్ సిస్టమ్స్ నిర్మాణం కోసం మన ప్రాథమిక గుచ్ఛం, మరియు RAG మరియు ఇతర టూల్స్ ఉపయోగించే ఏజెంట్ ను నిర్మిస్తాము.

## ఈవెంట్ పేరు: Microsoft Foundry మరియు GitHub Copilot ఉపయోగించి Java కోసం AI ఏజెంట్లు

## వివరణ

ఈ సెషన్ లో మేము మీ Java అప్లికేషన్లలో Microsoft Foundry ఉపయోగించి అధునాతన AI Agent సామర్థ్యాలను ఎలా సంస్థాపించాలో చూపిస్తాము, ప్రాజెక్ట్ లక్ష్యాలను సెట్ చేసి, మోడల్స్ తో ప్రయోగాలు చేసి, సురక్షితంగా ప్రొడక్షన్ సిద్దమైన పరిష్కారాలను స్కేల్ గా ఎలా పంపిణీ చేయాలో నేర్చుకుంటారు. GitHub Copilot (IntelliJ, VS Code, మరియు Eclipse లో) కోడింగ్ మరియు ప్రాంప్ట్ సృష్టిని ఎలా సులభతరం చేస్తుందో మరియు మోడల్ ఎంపిక, ఫైన్-ట్యూనింగ్, మరియు ఏజెంటిక్ వర్క్‌ఫ్లోల ఉత్తమ ఆచారాలు బాధ్యతతోపాటు సమర్థవంతమైన అభివృద్ధిని ఎలా నిర్ధారిస్తాయో తెలుసుకుంటారు. మీరు AI Agent లకు కొత్తవారు అయినా లేదా అధికతర ఏజెంట్ బిల్డింగ్ సాంకేతికతలను కోరుకున్నా, ఈ సెషన్ మీకు మీరు ఇప్పటికే తెలుసుకున్న టూలింగ్ తో తదుపరి స్థాయి అనుభూతులను అందించడానికి సిద్ధం చేస్తుంది.

## ఈవెంట్ పేరు: LangChain4j మరియు డైనమిక్ సెషన్లతో Java AI ఏజెంట్లు నిర్మించడం

## వివరణ

LangChain4j ను Azure Container Apps (ACA) డైనమిక్ సెషన్లతో కలిపి Azure AI సర్వీసులతో కనెక్ట్ చేసి మీ Java అప్లికేషన్లలో AI ఏజెంట్ల శక్తిని తెరవండి. ఈ సెషన్ లో దూరపు వాతావరణం తో ఇన్‌టరాక్ట్ చేయగల ఏజెంట్ నిర్మాణానికి ప్రాక్టికల్ ఉదాహరణ కనిపిస్తుంది, ఇందులో ఫైల్ మేనేజ్‌మెంట్ కూడ ఉంటుంది. ప్రత్యేక టూల్స్ ని నిర్వచించి, వాటిని ఏజెంట్ వర్క్‌ఫ్లోల్లో ఏకీకరించి, Azure స్కేలబుల్ మౌలిక సదుపాయాలను ఉపయోగించి తెలివైన, డైనమిక్ పరిష్కారాలను ఎలా పంపిణీ చేయాలో నేర్చుకోండి.
