# నమూనా చెల్లింపు పత్రాల నమూనాలు

నోట్‌బుక్ నడపకుండా తనిఖీ కోసం మూడునిమిషాల ముందుగా సృష్టించిన చెల్లింపు పత్రాలు.

| ఫైలు | ఏమిటి |
|---|---|
| `01_valid_receipt.json` | `lookup_flights` టూల్ కాల్ కోసం సాధువైన సంతకం చేసిన చెల్లింపు పత్రం. ధృవీకరణ True ఇస్తుంది. |
| `02_tampered_receipt.json` | సంతకానంతరం ఒక ఫీల్డ్ మార్చిన అదే చెల్లింపుపత్రం. ధృవీకరణ False ఇస్తుంది. |
| `03_chain_three_receipts.json` | మూడు చెల్లింపు పత్రాల ష్రేణి (search, hold, book) ప్రతి ఒకదాన్ని మునుపటి ఒకదానికి `previous_receipt_hash` తో లింక్ చేసింది. |

ఈ నమూనాలు పెలాడ్ యొక్క కేనానికల్ JCS బైట్స్ ను నేరుగా Ed25519 తో సంతకం చేస్తాయి.
SHA-256 కంటెంట్ డైజెస్ట్‌లకు మరియు చెల్లింపు-చైన్ లింకులకు ఉపయోగంలో ఉంటుంది, సంతకానికి ముందు అదనపు ప్రీ-హాష్ గా కాదు.


## నమూనాలు ధృవీకరణ

నోట్‌బుక్ నాలుగు విభాగాల్లో ధృవీకరణని వివరించింది. ఈ నమూనాలను నోట్‌బుక్ కథనాలు లేకుండా నేరుగా ధృవీకరించడానికి:


```python
import json
from pathlib import Path

# Assumes you have completed the imports and helper functions
# from sections 1 and 2 of 18-signed-receipts.ipynb.

valid = json.loads(Path("01_valid_receipt.json").read_text())
print(f"Valid receipt: {verify_receipt(valid)}")        # True

tampered = json.loads(Path("02_tampered_receipt.json").read_text())
print(f"Tampered receipt: {verify_receipt(tampered)}")  # False

chain = json.loads(Path("03_chain_three_receipts.json").read_text())
for r in verify_chain(chain):
    print(f"  Receipt {r['index']} ({r['tool']}): {'VALID' if r['overall_valid'] else 'INVALID'}")
```

## మూడవ JSON ని పరిశీలించడం ద్వారా విద్యార్థులు ఏమి నేర్చుకుంటారు

రా చెల్లింపు పత్ర ఫార్మాట్ చదవడం నోటుబుక్ లోని సెల్‌లు సాధారణంగా అందించని అంతర్గత అవగాహనను నిర్మిస్తుంది. JSON ను స్కిమ్ చేసే విద్యార్థులు తరచుగా గమనిస్తారు:


   చదవదగిన JSON. సంతకం విషయం దాచదు; దానికి నిర్ణయాత్మక సాక్ష్యం.
   చదవని JSON. సంతకం కంటెంట్ని ఎన్‌క్రిప్ట్ చేయదు; అది దానికి సాక్ష్యంగా ఉంటుంది.
2. రెసిప్ట్‌లో `public_key` బెట్టబడి ఉంటుంది. ఒక ఆడిటర్‌కు ఇంకేమీ అవసరం లేదు
   సత్యం నిర్థారించడానికి (కీ వాస్తవంగా ఆ యజమాని యొక్కది కాదా అనేది నమ్మకం మీద ఆధారపడి ఉంటుంది;
   గుర్తింపు మౌలిక సదుపాయాలపై పాఠం README చూడండి).
3. ఏ ఫీల్డ్ యొక్క ఒక్క అక్షరాన్ని మార్చి, ఆ ఫైల్‌ను మళ్లీ `02_tampered_receipt.json`తో
   సమానంగా పోల్చడం బైట్-స్థాయి మెకానిజము స్పష్టంగా చేస్తుంది.
