# AGENTS.md

## نظرة عامة على المشروع

يحتوي هذا المستودع على "وكلاء الذكاء الاصطناعي للمبتدئين" - دورة تعليمية شاملة تعلم كل ما يلزم لبناء وكلاء الذكاء الاصطناعي. تتكون الدورة من 18 درسًا (مرقمة من 00 إلى 18) تغطي الأساسيات، أنماط التصميم، الأُطُر، النشر في الإنتاج، وكلاء محليين/على الجهاز، وأمن وكلاء الذكاء الاصطناعي.

**التقنيات الرئيسية:**
- Python 3.12+
- دفاتر جوبيتر للتعلم التفاعلي
- أُطُر الذكاء الاصطناعي: إطار عمل الوكيل من مايكروسوفت (MAF)
- خدمات الذكاء الاصطناعي في Azure: Microsoft Foundry، خدمة وكيل Microsoft Foundry V2

**البنية:**
- هيكل قائم على الدروس (مجلدات 00-18)
- يحتوي كل درس على: وثائق README، عينات كود (دفاتر جوبيتر)، وصور
- دعم متعدد اللغات عبر نظام الترجمة الآلي
- دفتر جوبيتر واحد بلغة Python لكل درس باستخدام إطار عمل الوكيل من مايكروسوفت

## أوامر الإعداد

### المتطلبات الأساسية
- Python 3.12 أو أعلى
- اشتراك Azure (لـ Microsoft Foundry)
- تثبيت ومصادقة Azure CLI (`az login`)

### الإعداد الأولي

1. **استنساخ أو تفريع المستودع:**
   ```bash
   gh repo fork microsoft/ai-agents-for-beginners --clone
   # OR
   git clone https://github.com/microsoft/ai-agents-for-beginners.git
   cd ai-agents-for-beginners
   ```

2. **إنشاء وتفعيل بيئة افتراضية لبيثون:**
   ```bash
   python3 -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   ```

3. **تثبيت الاعتمادات:**
   ```bash
   pip install -r requirements.txt
   ```

4. **إعداد متغيرات البيئة:**
   ```bash
   cp .env.example .env
   # Edit .env with your API keys and endpoints
   ```

### متغيرات البيئة المطلوبة

لـ **Microsoft Foundry** (مطلوب):
- `AZURE_AI_PROJECT_ENDPOINT` - نقطة نهاية مشروع Microsoft Foundry
- `AZURE_AI_MODEL_DEPLOYMENT_NAME` - اسم نشر النموذج (مثل gpt-5-mini)

لـ **Azure AI Search** (الدرس 05 - RAG):
- `AZURE_SEARCH_SERVICE_ENDPOINT` - نقطة نهاية Azure AI Search
- `AZURE_SEARCH_API_KEY` - مفتاح API الخاص بـ Azure AI Search

المصادقة: قم بتشغيل `az login` قبل تشغيل دفاتر جوبيتر (يستخدم `AzureCliCredential`).

## سير عمل التطوير

### تشغيل دفاتر جوبيتر

يحتوي كل درس على دفاتر جوبيتر متعددة لأُطُر مختلفة:

1. **تشغيل جوبيتر:**
   ```bash
   jupyter notebook
   ```

2. **انتقل إلى مجلد الدرس** (مثل `01-intro-to-ai-agents/code_samples/`)

3. **افتح وشغل دفاتر جوبيتر:**
   - `*-python-agent-framework.ipynb` - باستخدام إطار عمل الوكيل من مايكروسوفت (Python)
   - `*-dotnet-agent-framework.ipynb` - باستخدام إطار عمل الوكيل من مايكروسوفت (.NET)

### العمل مع إطار عمل الوكيل من مايكروسوفت

**إطار عمل الوكيل من مايكروسوفت + Microsoft Foundry:**
- يتطلب اشتراك Azure
- يستخدم `FoundryChatClient` لخدمة الوكيل V2 (الوكلاء مرئيون في بوابة Foundry)
- جاهز للإنتاج مع مراقبة مدمجة
- نمط الملفات: `*-python-agent-framework.ipynb`

   ```bash
   python -c "import os; from dotenv import load_dotenv; load_dotenv(); print('✓ AZURE_AI_PROJECT_ENDPOINT' if os.getenv('AZURE_AI_PROJECT_ENDPOINT') else '✗ AZURE_AI_PROJECT_ENDPOINT missing')"
   ```
