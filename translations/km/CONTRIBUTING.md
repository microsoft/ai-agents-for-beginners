# ការរួមចំណែក

គម្រោងនេះបានទទួលស្វាគមន៍ការរួមចំណែក និងយោបល់។ ភាគច្រើននៃការរួមចំណែកត្រូវការឲ្យអ្នកយល់ព្រមលើកិច្ចព្រមព្រៀង អាជ្ញាបណ្ណរបស់អ្នករួមចំណែក (CLA) ដែលប្រកាសថាអ្នកមានសិទ្ធិ និងពិតជាអនុញ្ញាតឲ្យយើងប្រើប្រាស់ការរួមចំណែករបស់អ្នក។ សម្រាប់ព័ត៌មានលម្អិត សូមចូលទៅកាន់ <https://cla.opensource.microsoft.com>។

នៅពេលអ្នកដាក់សំណើ pull request មួយ បុត CLA នឹងកំណត់ដោយស្វ័យប្រវត្តិតើតើអ្នកត្រូវផ្ដល់ CLA ឬទេ ហើយតុបតែង pull request ដោយសមរម្យ។ អ្នកគួរតែអនុវត្តតាមការណែនាំដែលបានផ្ដល់ដោយបុតនោះ។ អ្នកត្រូវតែធ្វើបែបនេះម្តងតែម្តងក្នុងរ៉េហ្វូដែលប្រើ Microsoft CLA។

## ច្បាប់អ conducta

គម្រោងនេះបានទទួលយក [Microsoft Open Source Code of Conduct](https://opensource.microsoft.com/codeofconduct/)។ សម្រាប់ព័ត៌មានបន្ថែម សូមមើល [Code of Conduct FAQ](https://opensource.microsoft.com/codeofconduct/faq/) ឬទាក់ទង [opencode@microsoft.com](mailto:opencode@microsoft.com) សម្រាប់សំណួរឬយោបល់បន្ថែម។

## គោលការណ៍សម្រាប់ការដាក់សំណើ pull request

- រក្សាឲ្យការដាក់សំណើ pull request មួយមានកំណត់លើការផ្លាស់ប្តូរតែមួយ។
- សូមសាកល្បងសៀវភៅកំណត់សម្គាល់ និងគំរូកូដដែលមានផលប៉ះពាល់ មុនពេលដាក់សំណើ។
- ផ្លាស់ប្តូរការបរិយាយមេរៀនដែលពាក់ព័ន្ធ នៅពេលបន្ថែមឬផ្លាស់ប្តូរឧទាហរណ៍មួយ។
- កែសម្រួលមាតិកាភាសាអង់គ្លេសទេ។ ការបកប្រែត្រូវបានគ្រប់គ្រងដោយកម្មវិធីបកប្រែស្វ័យប្រវត្តិ។
- កុំបញ្ជូនឯកសារ សម្ងាត់សម្ងាត់, `.env`, ឯកសារបណ្តោះអាសន្ន ឬគ្រឿងបន្លាស់អភិវឌ្ឍន៍ដែលបានបង្កើត។

## វិសាលភាពកែសម្រួល និងផលិតផលភាគីទីបី

មេរៀននេះផ្តោតលើបច្ចេកវិទ្យា Microsoft និងស្តង់ដារបើកដែលមិនកំពុងលក់ដោយអ្នកផ្គត់ផ្គង់ណាមួយ។ ការរួមចំណែកត្រូវមានគោលបំណងសិក្សាដល់បញ្ញាតិច្បាស់លាស់ ហើយមិនគួរតែប្រើសំរាប់ណែនាំ ឬផ្សព្វផ្សាយផលិតផលពាណិជ្ជកម្មភាគីទីបីឬសេវារបស់ពួកគេ។

កម្មវិធីបើកហូរ និងការពឹងផ្អែកនៅភាគីទីបីអាចត្រូវបានយោង ប្រសិនបើវាសំខាន់សម្រាប់អធិប្បាយព័ន្ធនឹងស្តង់ដារបើកឬករណីធ្វើការមានរួមបញ្ចូលគ្នា ដែលបានបង្ហាញដោយស្មើភាព និងមិនដាក់គោលដៅទៅផលិតផល ឬចំណុចផ្សាយវេបសាយរបស់អ្នកផ្គត់ផ្គង់ណាមួយ។ ប្រសិនបើសំណើររបស់អ្នកមានផលិតផលឬសេវាជាពិសេសពីអ្នកផ្គត់ផ្គង់ណាមួយ សូមបើកបញ្ហាហើយទទួលការអនុម័តពីអ្នកថែរក្សាមុនធ្វើការដាក់សំណើ pull request។

អ្នករួមចំណែកត្រូវបង្ហាញពីការចូលរួមការងារ ការកាន់កាប់ ការស្តារការជាម៉ាធ័រឬការភ្ជាប់ផ្សេងទៀតជាមួយផលិតផលឬសេវាកម្មដែលបានយោងក្នុងការរួមចំណែករបស់ពួកគេ។ កុំរួមបញ្ចូលការអះអាងថ្លៃ ធ្វើអនុវត្តភាព សុវត្ថិភាព ឯកជនភាព ឬការប្រៀបធៀបមិនមានមូលដ្ឋាន។ ឧទាហរណ៍ដែលអាចដំណើរការបានមិនគួរផ្ទេរទិន្នន័យអ្នករៀន ឬអនុវត្តសកម្មភាពសាធារណៈតាមសេវាកម្មភាគីទីបីដោយค่า​ដើម។
