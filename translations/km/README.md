## ការរួមចំណែក

គម្រោងនេះស្វាគមន៍ការរួមចំណែក និងអនុសាសន៍។ ការរួមចំណែកភាគច្រើនត្រូវការឱ្យអ្នកយល់ព្រមនឹង
កិច្ចព្រមព្រៀងអាជ្ញាបណ្ណអ្នករួមចំណែក (CLA) ដែលប្រកាសថា អ្នកមានសិទ្ធិ និងពិតជាមានសិទ្ធិ
ផ្តល់សិទ្ធិដល់យើងក្នុងការប្រើប្រាស់ការរួមចំណែករបស់អ្នក។ សម្រាប់ព័ត៌មានលម្អិត សូមទៅកាន់ <https://cla.opensource.microsoft.com>។

ពេលអ្នកដាក់សំណើទាញយក (pull request) ម្ចាស់ CLA bot នឹងកំណត់ដោយស្វ័យប្រវត្តិថាតើអ្នកត្រូវការផ្តល់
CLA ឬទេ ហើយតាងសញ្ញារបស់ PR ឲ្យសមរម្យ (ឧ. ពិនិត្យស្ថានភាព ការបញ្ចេញមតិ)។ គ្រាន់តែអនុវត្តតាមការណែនាំដែល
បញ្ជាក់ដោយ bot។ អ្នកត្រូវធ្វើរួចតែម្តងតែម្ដងសម្រាប់រាល់ repo ទាំងអស់ដែលប្រើ CLA របស់យើង។

គម្រោងនេះមានការអនុម័ត [កូដអធិប្បាយចេញពី Microsoft](https://opensource.microsoft.com/codeofconduct/)។
សម្រាប់ព័ត៌មានបន្ថែម សូមមើល [សំណួរញឹកញាប់អំពីកូដអធិប្បាយ](https://opensource.microsoft.com/codeofconduct/faq/) ឬ
ទំនាក់ទំនង [opencode@microsoft.com](mailto:opencode@microsoft.com) ប្រសិនបើមានសំណួរឬមតិយោបល់បន្ថែម។
