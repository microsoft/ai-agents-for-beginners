កុំភ្លេច [ផ្ដល់ពន្លឺ (🌟) លើរ៉េពូនេះ](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst) ហើយ [ចម្លងរ៉េពូនេះ](https://github.com/microsoft/ai-agents-for-beginners/fork) ដើម្បីរត់កូដ។

### អ្វីដែលអ្នកត្រូវការ

មេរៀនមួយៗក្នុងមេរៀននេះ មានឧទាហរណ៍កូដ ដែលអាចរកឃើញនៅថត code_samples។ អ្នកអាច [ចម្លងរ៉េពូនេះ](https://github.com/microsoft/ai-agents-for-beginners/fork) ដើម្បីបង្កើតច្បាប់ផ្ទាល់ខ្លួន។

ឧទាហរណ៍កូដក្នុងការប្រលងទាំងនេះ ប្រើប្រាស់ Microsoft Agent Framework ជាមួយ Microsoft Foundry Agent Service V2:

- [Microsoft Foundry](https://aka.ms/ai-agents-beginners/ai-foundry) - តម្រូវអាជ្ញាបណ្ណ Azure

មេរៀននេះប្រើប្រាស់ម៉ាស៊ីនតួអង្គ AI និងសេវាកម្មពី Microsoft ខាងក្រោម៖

- [Microsoft Agent Framework (MAF)](https://learn.microsoft.com/agent-framework/overview/)
- [Microsoft Foundry Agent Service V2](https://aka.ms/ai-agents-beginners/ai-agent-service)

មួយចំនួននៃឧទាហរណ៍កូដក៏គាំទ្រវីស័យអ្នកផ្គត់ផ្គង់ដែលគាំទ្រ OpenAI ផងដែរ ដូចជា [MiniMax](https://platform.minimaxi.com/) ដែលផ្តល់ម៉ូដែល context ទំហំធំ (រហូតដល់ 204K tokens)។ មើលលំអិតនៅ [Course Setup](./00-course-setup/README.md) សម្រាប់ការកំណត់រចនាសម្ព័ន្ធ។

សម្រាប់ព័ត៌មានបន្ថែមអំពីរបៀបរត់កូដសម្រាប់មេរៀននេះ សូមទៅកាន់ [Course Setup](./00-course-setup/README.md)។

## ការរួមចំណែក

គម្រោងនេះស្វាគមន៍ការរួមចំណែក និងយោបល់។ ការរួមចំណែកភាគច្រើនត្រូវការឲ្យអ្នកយល់ព្រមនឹង
កិច្ចសន្យាអនុញ្ញាតរបស់អ្នករួមចំណែក (CLA) ដែលចែងថាអ្នកមានសិទិ្ធត្រឹមត្រូវ និងពិតប្រាកដថាអ្នកផ្តល់
សិទិ្ធក្នុងការប្រើប្រាស់ការរួមចំណែករបស់អ្នក។ ដើម្បីពិស្ដារព័ត៌មាន សូមចូលទៅកាន់ <https://cla.opensource.microsoft.com>។

ពេលដែលអ្នកដាក់សំណើ pull request មួយ bot CLA នឹងកំណត់ដោយស្វ័យប្រវត្តិថាតើអ្នកត្រូវផ្តល់
CLA ឬក៏ទេ ហើយតុបតែង PR ដោយសមរម្យ (ឧ. ការត្រួតពិនិត្យสถานะ ការសរសេរកំណត់ហេតុ)។ តាមអនុដែល
bot ផ្តល់ជូន។ អ្នកត្រូវធ្វើនេះតែមួយដងក្នុងគ្រប់ repo ដែលប្រើ CLA របស់យើង។

គម្រោងនេះទទួលយក [សីតិគោលនយោបាយកូដប្រភេទបើកតែម្នាក់](https://opensource.microsoft.com/codeofconduct/) របស់ Microsoft។
សម្រាប់ព័ត៌មានបន្ថែម សូមមើល [សំណួរ ដែលឆ្លើយជំនួសសីតិគោលនយោបាយ](https://opensource.microsoft.com/codeofconduct/faq/) ឬ
ទាក់ទង [opencode@microsoft.com](mailto:opencode@microsoft.com) សម្រាប់សំណួរ ឬមតិយោបល់បន្ថែម។
