## 🌱 ចាប់ផ្តើមពីដើម

មេរៀននេះមានមេរៀនបង្រៀនមូលដ្ឋាននៃការសាងសង់អ្នកតំណាង AI។ មេរៀននីមួយៗគ្របដណ្តប់ប្រធានបទផ្ទាល់ខ្លួន ហើយអ្នកអាចចាប់ផ្តើមនៅគ្រប់ទីកន្លែងដែលចូលចិត្ត!

មានការគាំទ្រជាភាសាចម្រុះសម្រាប់មេរៀននេះ។ ចូលទៅកាន់ [ភាសាដែលមាននៅទីនេះ](#-multi-language-support)។

ប្រសិនបើនេះជាលើកដំបូងរបស់អ្នកក្នុងការសាងសង់ជាមួយម៉ូដែល Generative AI សូមពិនិត្យមើលមេរៀន [Generative AI For Beginners](https://aka.ms/genai-beginners) របស់យើង ដែលមានមេរៀនចំនួន 21 ស្ដីពីការសាងសង់ជាមួយ GenAI។

កុំភ្លេច [ផ្ដល់ផ្កាយ (🌟) អោយឃ្លាំងនេះ](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst) និង [fork ឃ្លាំងនេះ](https://github.com/microsoft/ai-agents-for-beginners/fork) ដើម្បីរត់កូដ។

### អ្វីដែលអ្នកត្រូវការ 

មេរៀននីមួយៗក្នុងមេរៀននេះរួមបញ្ចូលឧទាហរណ៍កូដ ដែលអាចរកបាននៅក្នុងថត code_samples។ អ្នកអាច [fork ឃ្លាំងនេះ](https://github.com/microsoft/ai-agents-for-beginners/fork) ដើម្បីបង្កើតចម្លងផ្ទាល់ខ្លួនរបស់អ្នក។

ឧទាហរណ៍កូដក្នុងការប្រឡងទាំងនេះប្រើក្របខ័ណ្ឌ Microsoft Agent Framework ជាមួយសេវាកម្ម Microsoft Foundry Agent Service V2៖

- [Microsoft Foundry](https://aka.ms/ai-agents-beginners/ai-foundry) - ត្រូវការគណនី Azure

មេរៀននេះប្រើក្របខ័ណ្ឌ និងសេវាកម្មអ្នកតំណាង AI ខាងក្រោមពី Microsoft៖

- [Microsoft Agent Framework (MAF)](https://learn.microsoft.com/agent-framework/overview/)
- [Microsoft Foundry Agent Service V2](https://aka.ms/ai-agents-beginners/ai-agent-service)

ឧទាហរណ៍កូដខ្លះទៀតគាំទ្រ អ្នកផ្គត់ផ្គង់ជំនួសដែលស្រដៀងនឹង OpenAI ដូចជា [MiniMax](https://platform.minimaxi.com/) ដែលផ្ដល់ម៉ូដែល context លំដាប់ធំ (រហូតដល់ 204K tokens)។ មើល [ការតំឡើងមេរៀន](./00-course-setup/README.md) សម្រាប់ព័ត៌មានកំណត់រចនាសម្ព័ន្ធ។

សម្រាប់ព័ត៌មានលម្អិតអំពីការរត់កូដសម្រាប់មេរៀននេះ សូមចូលទៅកាន់ [ការតំឡើងមេរៀន](./00-course-setup/README.md)។

## ការចូលរួម

គម្រោងនេះយល់ព្រមទទួលការចូលរួម និងយោបល់។ ភាគច្រើននៃការចូលរួមខ្លះតម្រូវឱ្យអ្នកយល់ព្រមលើ
កិច្ចសន្យាអ្នករួមចំណែក (CLA) ដែលឲ្យដឹងថាអ្នកមានសិទ្ធិ និងពិតជាអនុញ្ញាតឲ្យយើងប្រើប្រាស់
ការចូលរួមរបស់អ្នក។ សម្រាប់ព័ត៌មានលំអិត សូមទៅកាន់ <https://cla.opensource.microsoft.com>.

នៅពេលអ្នកដាក់សំណើត៣ែញ (pull request) ប្រព័ន្ធ CLA bot នឹងកំណត់ដោយស្វ័យប្រវត្តិថាតើអ្នកត្រូវតែផ្តល់
CLA ហើយតែងតាំងសំណើ PR ឲ្យសមរម្យ (ឧ. ការត្រួតពិនិត្យស្ថានភាព, ការសរសេរមតិ)។ តាមដានការណែនាំ
ដែលបានផ្តល់ដោយប៊ុត។ អ្នកត្រូវធ្វើរឿងនេះម្តងតែម្ដងទូទាំងរ៉េបៗដែលប្រើ CLA របស់យើង។

គម្រោងនេះទទួលបានដំណើរការតាម [Microsoft Open Source Code of Conduct](https://opensource.microsoft.com/codeofconduct/)។
សម្រាប់ព័ត៌មានបន្ថែម សូមមើល [Code of Conduct FAQ](https://opensource.microsoft.com/codeofconduct/faq/) ឬ
ទាក់ទង [opencode@microsoft.com](mailto:opencode@microsoft.com) សម្រាប់សំណួរឬមតិយោបល់បន្ថែមផ្សេងទៀត។
