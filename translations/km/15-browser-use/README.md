# គ្រប់គ្រងភ្នាក់ងារប្រើប្រាស់កុំព្យូទ័រ (CUA)

ភ្នាក់ងារប្រើប្រាស់កុំព្យូទ័រអាចអន្តរកម្មជាមួយវេបសាយដូចជាមនុស្សបាន៖ ដោយបើកកម្មវិធីរកមើលវេប, ពិនិត្យមើលទំព័រ, ហើយអនុវត្តន៍សកម្មភាពល្អបន្ទាប់ពីការមើលឃើញ។ នៅក្នុងមេរៀននេះ អ្នកនឹងសង់ភ្នាក់ងារអូតូម៉ាទិកកម្មវិធីរកមើលដែលស្វែងរក Airbnb, ដកយកទិន្នន័យបញ្ជីដែលមានរចនាសម្ព័ន្ធ, ហើយកំណត់ទីតាំងស្នាក់នៅដែលមានតម្លៃថោកបំផុតនៅ Stockholm។

មេរៀននេះផ្សំនឹងការប្រើ Browser-Use សម្រាប់ការរុករកដែលដឹកនាំដោយ AI, Playwright និង Chrome DevTools Protocol (CDP) សម្រាប់ការគ្រប់គ្រងកម្មវិធីរកមើល, Azure OpenAI សម្រាប់ហេតុផលដែលមានទស្សនវិស័យ, ហើយ Pydantic សម្រាប់ការដកយកទិន្នន័យរៀបចំ។

## មុខងារ

មេរៀននេះនឹងលើកដំឡើង៖

- ការយល់ដឹងពេលដែលភ្នាក់ងារប្រើកុំព្យូទ័រមានសមត្ថភាពល្អជាងអូតូម៉ាទិក API តែម្ដង
- ការរួមបញ្ចូល Browser-Use ជាមួយ Playwright និង CDP សម្រាប់ការគ្រប់គ្រងរបៀបដំណើរការល្អប្រសើរគ្រប់កម្មវិធីរកមើល
- ការប្រើ Azure OpenAI ទស្សនវិស័យ និងការបញ្ចេញលទ្ធផលរៀបចំ Pydantic ដកយកទិន្នន័យបញ្ជីពីទំព័របែបអេឡិចត្រូនិកមានចលនា
- ការសម្រេចចិត្តមុនការប្រើប្រាស់នូវកម្មវិធីអូតូម៉ាទិកដែលផ្អែកលើភ្នាក់ងារប្រតិបត្តិការ ឬរបៀបប្រើប្រាស់រួមម៉ាស៊ីនរកមើល

## គោលបំណងសិក្សា

បន្ទាប់ពីបញ្ចប់មេរៀននេះ អ្នកនឹងស្គាល់របៀប៖

- កំណត់ Browser-Use ជាមួយ Azure OpenAI និង Playwright
- សង់របៀបអូតូម៉ាទិកកម្មវិធីរកមើលដែលរុករកវេបសាយពិត និងគ្រប់គ្រងធាតុ UI មានចលនា
- ដកយកលទ្ធផលដែលមានប្រភេទពីប្លង់ទំព័រដែលមើលឃើញ និងបម្លែងវាទៅជាឡូជិចអាជីវកម្មបន្ត
- ជ្រើសរើសរវាងលំនាំភ្នាក់ងារ និងប្រតិបត្តិការ ដោយផ្អែកលើភាពអាចទាយទល់បាននៃភារកិច្ចកម្មវិធីរកមើល

## ឧទាហរណ៍កូដ

មេរៀននេះរួមបញ្ចូលមួយកំណត់ហេតុកំណត់សម្គាល់នៃសៀវភៅបញ្ជា៖

- [15-browser-user.ipynb](./15-browser-user.ipynb): បើកវគ្គ Chrome តាម CDP, ស្វែងរកបញ្ជី Airbnb សម្រាប់ Stockholm, ដកតម្លៃជាមួយ Browser-Use ទស្សនវិស័យ, ហើយត្រឡប់ជម្រើសតម្លៃថោកជាងគេជាទិន្នន័យរៀបចំ។

## លក្ខខណ្ឌមុនការដំណើរការ

- Python 3.12+
- ការតម្លើង Azure OpenAI ត្រូវបានកំណត់នៅក្នុងបរិស្ថានរបស់អ្នក
- Chrome ឬ Chromium បានដំឡើងក្នុងកន្លែងរបស់អ្នក
- តំឡើងអាស្រ័យភាព Playwright
- មានការស្គាល់មូលដ្ឋានពី Python async

## ការតំឡើង

តំឡើងកញ្ចប់ដែលប្រើនៅក្នុងកំណត់ហេតុនេះ៖

```bash
pip install browser_use playwright python-dotenv
playwright install chromium
```

កំណត់អថេរបរិស្ថាន Azure OpenAI ដែលប្រើដោយកំណត់ហេតុនេះ៖

```bash
AZURE_OPENAI_ENDPOINT=...
AZURE_OPENAI_API_KEY=...
AZURE_OPENAI_CHAT_DEPLOYMENT_NAME=...
# ជាមិនចាំបាច់ៈ បង្ហាញជាគំរូទៅកាន់ជំនាន់ API ថ្មីបំផុតពេលដាក់បោះបង់
AZURE_OPENAI_API_VERSION=...
```

## ទិដ្ឋភាពទូទៅនៃស្ថាបត្យកម្ម

កំណត់ហេតុនេះបង្ហាញពីរបៀបបញ្ចូលកម្មវិធីរកមើលរួម:

1. Chrome ចាប់ផ្តើមជាមួយ CDP បានបើក ដូច្នេះទាំង Playwright និង Browser-Use អាចចែករំលែកវគ្គកម្មវិធីរកមើលដូចគ្នា។
2. ភ្នាក់ងារ Browser-Use គ្រប់គ្រងភារកិច្ចរុករកបើកចំហ ដូចជា បើក Airbnb បិទបង្អួចបង្ហាញ, និងស្វែងរក Stockholm។
3. ទំព័រដែលកំពុងប្រើ ត្រូវបានពិនិត្យជាមួយស្តង់ដាព្យដង់ទីក (Pydantic) ដើម្បីដកចេញចំណងជើងបញ្ជី តម្លៃរាត្រី ទំនាក់ទំនង និង URL។
4. លូជិច Python ប្រៀបធៀបទិន្នន័យដែលបានដកចេញ ហើយបង្ហាញលទ្ធផលដែលមានតម្លៃថោកបំផុត។

វិធីនេះរក្សាបាននូវហេតុផលខាងទស្សនវិស័យដែល Browser-Use ធ្វើបានល្អ ខណៈដែលនៅតែផ្តល់ការគ្រប់គ្រងកម្មវិធីរកមើលមានលក្ខណៈប្រាកដ នៅពេលដែលអ្នកត្រូវការ។

## ចំណុចសំខាន់ៗ និងអនុវត្តខ្លះ

### ពេលណាដែលគួរប្រើ ភ្នាក់ងារ ទល់នឹង ប្រតិបត្តិការ

| ស្ថានការណ៍ | ប្រើភ្នាក់ងារ | ប្រើប្រតិបត្តិការ |
|----------|-----------|-----------|
| រចនាសម្ព័ន្ធមានចលនា | បាទ, AI អាចប្រញាប់នឹងបម្រែបម្រួលទំព័រ | ទេ, ជ្រើសរើសរងគ្រោះបានងាយ |
| រចនាសម្ព័ន្ធដែលបានដឹង | ទេ, ភ្នាក់ងារជាមុនប្រតិបត្តិដោយផ្ទាល់យឺត | បាទ, លឿន និងមិនខុសត្រូវ |
| ស្វែងរកធាតុ | បាទ, ភាសាធម្មជាតិកាន់តែប្រសើរ | ទេ, ត្រូវការជ្រើសរើសត្រឹមត្រូវ |
| គ្រប់គ្រងពេលវេលា | ទេ, មិនអាចទាយបានល្អ | បាទ, គ្រប់គ្រងរង់ចាំ និងសាកល្បងឡើងវិញបានពេញលេញ |
| ធ្វើបែបបទស្មុគស្មាញ | បាទ, ជួយគ្រប់គ្រងស្ថានភាព UI មិនបានរំពឹងទុក | ទេ, ត្រូវការ​ចែកវាំងនន​បានច្បាស់លាស់ |

### អនុវត្ត Browser-Use បែបល្អបំផុត

1. ចាប់ផ្តើមជាមួយភ្នាក់ងារសម្រាប់ការរុករក និងរុករកមានចលនា។
2. ប្តូរទៅគ្រប់គ្រងទំព័រជាប្រចាំពេលដែលអន្តរកម្មក្លាយជាច្បាស់លាស់។
3. ប្រើម៉ូដែលលទ្ធផលដែលមានរចនាសម្ព័ន្ធ ដើម្បីធានាថាទិន្នន័យដែលបានដកចេញត្រូវបានផ្ទៀងផ្ទាត់និងជាប្រភេទដែលមានសុវត្ថិភាព។
4. បន្ថែមពេលរងចាំយ៉ាងយកចិត្តទុកដាក់បន្ទាប់ពីសកម្មភាពដែលបណ្តាលអោយ UI មើលឃើញបានបំផុត។
5. ចាប់រូបថតអេក្រង់អំឡុងពេលធ្វើការជាមួយនេះ ដើម្បីឲ្យការបរាជ័យងាយស្រួលស្រាយរំលាយ។
6. រំពឹងថាវេបសាយនឹងផ្លាស់ប្តូរ ហើយរៀបចំយុទ្ធសាស្ត្របំប្លែងសម្រាប់បង្អួចបង្ហាញ និងបម្លែងរចនាសម្ព័ន្ធ។
7. រួមបញ្ចូលលំនាំភ្នាក់ងារ និងប្រតិបត្តិការ ដើម្បីទទួលបានទាំងភាពបត់បែន និងភាពច្បាស់លាស់។

### ករណី​អនុវត្តជាក់ស្តែងក្នុងពិភពផែនដី

- ការកក់ការធ្វើដំណើរ និងត្រួតពិនិត្យតម្លៃ
- ការប្រៀបធៀបតម្លៃរបស់អេឡិចត្រូនិច និងការត្រួតពិនិត្យភាពទំនេរ
- ការដកយកដែលមានរចនាសម្ព័ន្ធពីវេបសាយមានចលនា
- ការធ្វើតេស្ត UI ដែលយល់ព្រមអំពីទស្សនិកជន និងការផ្ទៀងផ្ទាត់
- ការត្រួតពិនិត្យវេបសាយ និងការបកស្រាយផ្សាយ
- ការបញ្ចូលទម្រង់ឆ្លាតវៃជាការរួមបញ្ចូលច្រើនជំហាន

## គំរូជាក់ស្តែង៖ Microsoft Project Opal

ភ្នាក់ងារដែលអ្នកសង់នៅក្នុងមេរៀននេះគឺជាម៉ូឌែលតូចតាមតំបន់សម្រាប់ **ភ្នាក់ងារប្រើប្រាស់កុំព្យូទ័រ (CUA)** — ព្រограмមួយដែលដំណើរកម្មកម្មវិធីរកមើលដូចមនុស្ស។ Microsoft កំពុងនាំយកគំនិតដូចគ្នានេះទៅក្រុមហ៊ុនជាមួយ **[Project Opal (Frontier)](https://support.microsoft.com/en-us/microsoft-365-copilot/get-started-with-project-opal-frontier)** ជាសមត្ថភាពមួយនៅ Microsoft 365 Copilot។

ជាមួយ Project Opal អ្នកពណ៌នាភារកិច្ច ហើយភ្នាក់ងារធ្វើការលើកបន្ទុកក្នុងនាមអ្នកប្រើប្រាស់ដោយប្រើ **ការប្រើប្រាស់កុំព្យូទ័រនៅលើ Windows 365 Cloud PC ដែលមានសុវត្ថិភាព** ដំណើរការលើកម្មវិធីកម្មវិធីរបស់អង្គភាពរបស់អ្នកនៅលើកម្មវិធីមូលដ្ឋានកម្មវិធីរកមើល វេបសាយ និងទិន្នន័យ។ វាដំណើរការជាអស៊ីនខ័រនៅខាងក្រោយ ហើយអ្នកអាចដឹកនាំការងារឬគ្រប់គ្រងនៅពេលណាមួយក៏បាន។ ការងារឧទាហរណ៍រួមមាន៖

- គ្រប់គ្រងសំណើរសមាជិកក្រុមសន្តិសុខ
- ប្រមូល និងផ្ទៀងផ្ទាត់ភស្តុតាងត្រួតពិនិត្យសម្រាប់ការត្រួតពិនិត្យគោលការណ៍
- ដោះស្រាយបញ្ហា IT (បន្ទាន់សម័យស្ថានភាពសំបុត្រ, ចាត់ចែងម្ចាស់, បិទចម្រុះ)
- សម្រង់ទិន្នន័យ Excel ទៅជាផេកសេចក្តីថ្លែងការណ៍ហិរញ្ញវត្ថុ

Opal គឺជាការពិចារណាដ៏មានប្រយោជន៍សម្រាប់ភ្នាក់ងារប្រើប្រាស់កុំព្យូទ័រដែលមានគុណភាពផលិតកម្ម និងមានការទុកចិត្ត — ហើយវាក៏បង្ហាញឱ្យឃើញគំនិតពីមេរៀនមុនៗ៖

| គំនិតក្នុងវគ្គនេះ | របៀបដែល Project Opal ប្រើប្រាស់វា |
|------------------------|-----------------------------|
| **មនុស្សនៅក្នុងរង្វង់ប្រតិបត្តិការ** (មេរៀន 06) | Opal ឈប់រង់ចាំព័ត៌មានចូលប្រើ, ទិន្នន័យសំងាត់, ឬសេចក្តីណែនាំមិនច្បាស់លាស់ និងមិនចូលបញ្ជូលពាក្យសម្ងាត់ឬបញ្ជូនទម្រង់ដោយគ្មានការបញ្ជាក់ច្បាស់។ អ្នកអាច *គ្រប់គ្រង* និង *ត្រឡប់វិញការគ្រប់គ្រង* ក្នងកំឡុងការងារ។ |
| **ភ្នាក់ងារដែលអាចទុកចិត្ត និងមានសុវត្ថិភាព** (មេរៀន 06 និង 18) | ដំណើរការនៅក្នុង Windows 365 Cloud PC ដែលបានបំបែក, មួយតែកម្មវិធីរកមើលជាមូលដ្ឋាន (ការចូលប្រើកុំព្យូទ័រផ្សេងទៀតបានផ្ទុក, ត្រូវបានបំភ្លឺតាម Intune), ប្រើអត្តសញ្ញាណរបស់អ្នកដូច្នេះវាចូលដំណើរការតែអ្វីដែលអ្នកមានសិទ្ធិបាន និងកត់ត្រាកម្មសិទិ្ធគ្រប់យ៉ាងសម្រាប់ត្រួតពិនិត្យ។ |
| **ការធ្វើផែនការនិងកំណត់គំនិតមុន** (មេរៀន 07 និង 09) | Opal បង្កើតផែនការសម្រាប់ការងារជាមុនសិន ហើយត្រួតពិនិត្យហេតុផលរបស់វាក្នុងគ្រប់ជំហាន និងឈប់បើវាពិចារណាឃើញសកម្មភាពខុសច្បាស់។ |
| **សមត្ថភាព / ឧបករណ៍ដែលអាចប្រើឡើងវិញ** (មេរៀន 04) | **ជំនាញ** អនុញ្ញាតឲ្យអ្នកសរសេរបញ្ជារណ៍សម្រាប់ការងារដែលអាចធ្វើឡើងម្តងទៀត (នាំចូលពីកថាខណ្ឌ `.md` ឬបានបង្កើតជាមួយ Opal) និងប្រើវានៅក្នុងការសន្ទនាបន្តផ្សេងទៀត។ |

> **ភាពអាចប្រើបាន៖** Project Opal មានស្រាប់សម្រាប់អ្នកប្រើប្រាស់នៅក្នុងកម្មវិធីចូលប្រើដំបូង [Frontier early access program](https://adoption.microsoft.com/copilot/frontier-program/) ជាមួយសេវាកម្ម Microsoft 365 Copilot ហើយអ្នកគ្រប់គ្រងត្រូវបំពេញការតម្លើង។ ដោយសារវាជាចំណុចសាកល្បងនៅ Frontier សមត្ថភាពអាចផ្លាស់ប្តូរបានតាមពេលវេលា។
