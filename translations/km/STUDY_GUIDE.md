## សាកល្បងសាមញ្ញមួយដើម្បីរក្សាត្រូវចិត្ត

ជាវិធីល្អក្នុងការរៀនអំពីភ្នាក់ងារគឺតាមដានគំនិតសាកល្បងមួយតាមរយៈវគ្គសិក្សា។

ឧទាហរណ៍សាកល្បង៖ **ភ្នាក់ងារជួយវគ្គសិក្សា**។

អ្នកប្រើប្រាស់សួរ៖

> "ខ្ញុំចង់រៀនពីរបៀបដែលភ្នាក់ងារប្រើឧបករណ៍។ ស្វែងរកមេរៀនដែលត្រឹមត្រូវ សង្ខេបអ្វីដែលខ្ញុំគួរអានជាដំបូង ហើយផ្តល់ឲ្យខ្ញុំបញ្ហាហាត់ប្រាណខ្លីមួយ។"




2. **ប្រើឧបករណ៍** ដើម្បីយកតំណភ្ជាប់មេរៀន ឧទាហរណ៍ ឬសម្ភារៈគាំទ្រ។
3. **ផែនការ** ផ្លូវសិក្សាខ្លីមួយប្ដូរជំនួសឲ្យការឆ្លើយតបវែងមួយ។
4. **ប្រើបរិបទ** ពីការពិភាក្សាបច្ចុប្បន្ន ដើម្បីបញ្ជាក់នូវគោលដៅរបស់អ្នករៀន។
5. **ចងចាំចំណង់ចំណូលចិត្តមានប្រយោជន៍** ប្រសិនបើកម្មវិធីគាំទ្រចងចាំ។
6. **បង្ហាញស្នាម ផ្ទៀងផ្ទាត់ ឬកំណត់ហេតុ** ដូច្នេះអ្នកប្រើអាចយល់អំពីអ្វីដែលបានកើតឡើង។
7. **អនុវត្តការពារ** មុនពេលអនុវត្តសកម្មភាពហានិភ័យ ឬប្រើទិន្នន័យដែលមានអារម្មណ៍ងាយរងគ្រោះ។

## ម៉ូដែល និងអ្នកផ្គត់ផ្គង់

កូដឧទាហរណ៍វគ្គសិក្សាប្រើប្រាស់ **Microsoft Agent Framework (MAF)** ហើយមានគោលដៅទៅកាន់ **Azure OpenAI Responses API** — API ដែលផ្តល់អនុសាសន៍សម្រាប់អនាគត ដែលបញ្ចូលការបំពេញជជែក ការហៅឧបករណ៍ បញ្ចូលពហុរូបមន្ត និងការពិភាក្សាទីតាំងផ្សេងៗក្នុងផ្ទៃ API តែមួយ។ អ្នកអាចភ្ជាប់តាមរយៈគម្រោង **Microsoft Foundry** (ជាមួយ `FoundryChatClient`) ឬទៅកាន់ Azure OpenAI ដោយផ្ទាល់ (ជាមួយ `OpenAIChatClient`)។

នៅពេលដែលអ្នកធ្វើការវិលតាមមេរៀន អ្នកមានជម្រើសអ្នកផ្តល់សេវាកម្មខ្លះៗ៖

- **Microsoft Foundry / Azure OpenAI (Responses API)** — ផ្លូវសំខាន់ប្រើប្រាស់ក្នុងមេរៀនទាំងអស់។ ចូលប្រើជាមួយ `az login` ដើម្បីអះអាងអត្តសញ្ញាណធ្វើជារបារ Entra ID មិនត្រូវការកូនសោ។
- **Foundry Local** — ពន្លឿនម៉ូដែលដោយសំរុងពេញលេញលើឧបករណ៍ដោយផ្ទាល់តាម API ដែលផ្គូផ្គងជាមួយ OpenAI (គ្មានគ្រប់ទិន្នន័យ និងគ្មានកូនសោ API)។ ល្អសម្រាប់ការសាកល្បងក្រៅអ៊ិនធឺណិត ឬមិនចំណាយថវិកា។ មើល [ការតំឡើងវគ្គសិក្សា](./00-course-setup/README.md)។
- **MiniMax** — អ្នកផ្តល់សេវាកម្មដែលផ្គូផ្គងជាមួយ OpenAI ជាមួយម៉ូដែលខ្ទង់បរិបទធំ អាចប្រើជា ជំនួសបញ្ចូលតែមួយបាន។

> **កំណត់សម្គាល់៖** GitHub Models ត្រូវបានផ្អាក (នឹងបញ្ចប់នៅខែកក្កដាឆ្នាំ ២០២៦) ហើយមិនគាំទ្រ Responses API ទេ។ ឧទាហរណ៍ទាំងនេះបានធ្វើបច្ចុប្បន្នភាពដល់ការប្រើប្រាស់ Azure OpenAI / Microsoft Foundry ជំនួសវិញ។
