## សេចក្ដីពិពណ៌នា

ចូលរួមជាមួយយើងដើម្បីស្វែងយល់ពីហានិភ័យដែលអាចកើតមានពីភ្នាក់ងារអាយធី ហើយដោះស្រាយបញ្ហាការចងក្រងវិន័យ AI ដែលទុកចិត្តបានក្នុងវេទិកាអាយធី ចន្ទរកាល! សម័យនេះជ្រេីសទូលាយពីឧទាហរណ៍ភ្នាក់ងារ AI មិនទទួលខុសត្រូវ បង្ហាញឧទាហរណ៍ភាពបរាជ័យម៉ូដែលអស្ចារ្យ ការបង្ហាញជំនួញចោលការបញ្ជា (adversarial jailbreaks) និងហានិភ័យផ្សេងទៀតដែលបណ្តាលឲ្យខូចទំនុកចិត្ត និងការអនុវត្តតាមច្បាប់។
