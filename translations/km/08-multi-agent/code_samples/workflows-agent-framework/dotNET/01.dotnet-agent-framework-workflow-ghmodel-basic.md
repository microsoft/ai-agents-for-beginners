សៀវភៅកំណត់នេះបង្ហាញពីរបៀបបង្កើត **នីតិវិធីការងារសហប្រតិបត្តិភាគម៉ាស៊ីនភាគី** ដែលមានភាពស្មុគស្មាញដោយប្រើ Microsoft Agent Framework សម្រាប់ .NET និង Azure OpenAI (Responses API)។ អ្នកនឹងរៀនពីរបៀបបង្កើតដំណើរការពាណិជ្ជកម្មច្រើនជំហានដែលម៉ាស៊ីនភាគី AI ប្រព្រឹត្តទៅរួមគ្នាដើម្បីបំពេញភារកិច្ចស្មុគស្មាញតាមរយៈគំរូរៀបចំនីតិវិធីដែលបានរៀបរយ។

- **ការសម្របសម្រួលម៉ាស៊ីនភាគី**: សម្របសម្រួលម៉ាស៊ីនភាគីជាច្រើនដែលមានជំនាញជាក់លាក់នៅក្នុងនីតិវិធី

- **ការរចនានីតិវិធីភ្លើងមើលឃើញ**: បង្កើតនិងមើលឃើញរចនាសម្ព័ន្ធនីតិវិធីសម្រាប់ការយល់ដឹងល្អរបស់អ្នក

### 🔑 **ការកំណត់តម្លៃ Azure OpenAI**

**ការតំឡើងបរិយាកាស (.env គំរូបណ្តារ):**
```env
AZURE_OPENAI_ENDPOINT=https://<your-resource>.openai.azure.com
AZURE_OPENAI_DEPLOYMENT=gpt-4o-mini
```

**ការចូលប្រើ Azure OpenAI៖**
1. បង្កើតធនធាន Azure OpenAI នៅក្នុងផត្វល Azure
2. ប្រើម៉ូឌែលណាមួយ (ឧទាហរណ៍ `gpt-4o-mini`) ហើយកត់សម្គាល់ឈ្មោះការបញ្ចូន
3. ចូលប្រើដោយ `az login` ហើយកំណត់អថេរបរិយាកាសដូចបានបង្ហាញខាងលើ

### 🏗️ **ទិដ្ឋភាពទូទៅរចនាសម្ព័ន្ធនីតិវិធីការងារ**

```mermaid
graph TD
    A[អ្នកបង្កើតដំណើរការងារ] --> B[ទីបញ្ជីភ្នាក់ងារ]
    B --> C[វិទ្យុបញ្ជារតភ្ជាប់ដំណើរការងារ]
    C --> D[Agent 1: កម្មវិធីបង្កើតមាតិកា]
    C --> E[Agent 2: អ្នកពិនិត្យមាតិកា] 
    D --> F[លទ្ធផលដំណើរការងារ]
    E --> F
    G[Azure OpenAI (API ពីការឆ្លើយតប)] --> D
    G --> E
```

**ធាតុសំខាន់ៗ៖**
- **WorkflowBuilder**: ម៉ាស៊ីនរៀបចំនីតិវិធីសំខាន់សម្រាប់រចនានីតិវិធី
- **AIAgent**: ម៉ាស៊ីនភាគីជំនាញពិសេសនិមួយៗដែលមានសមត្ថភាពជាក់លាក់
- **Azure OpenAI Client**: រួមបញ្ចូល Azure OpenAI Responses API
- **Execution Context**: គ្រប់គ្រងស្ថានភាពនិងចរន្តទិន្នន័យរវាងជំហាននីតិវិធី

## 🎨 **គំរូរចនានីតិវិធីសហគ្រាស**

### 📝 **នីតិវិធីផលិតកម្មមាតិកា**
```
User Request → Content Generation → Quality Review → Final Output
```

### 🔍 **បំពង់ដំណើរការឯកសារ**
```
Document Input → Analysis → Extraction → Validation → Structured Output
```

### 💼 **នីតិវិធីវិភាគពាណិជ្ជកម្ម**
```
Data Collection → Processing → Analysis → Report Generation → Distribution
```

### 🤝 **ស្វ័យប្រវត្តិនៃសេវាអតិថិជន**
```
Customer Inquiry → Classification → Processing → Response Generation → Follow-up
```
