# ចម្លើយផ្ទៀងផ្ទាត់ចំណេះដឹង

## សំណួរ ១

**ចម្លើយ៖ A2.** ក្រុមប្រតិបត្តិការជាច្រើនមានប្រយោជន៍នៅពេលមានតួនាទីជំនាញ ដាច់ដោយឡែកឧបករណ៍ ឬការអនុញ្ញាតខុសៗគ្នា និងការផ្ទេរបានច្បាស់ ដែលត្រូវការសម្របសម្រួល។ បុតសម្រាប់គាំទ្រងាយៗវាធម្មតានឹងនៅដដែលជាបុតតែមួយ។ បញ្ហាច្រើននៃសំណើដូចគ្នា គឺជាបញ្ហាការពង្រីកសកម្មភាព ជាគ្រាប់ចម្បង និងមិនត្រូវការរចនាមុខងារជាបុតមួយច្រើនទេ។

## សំណួរ ២

**ចម្លើយ៖ A1.** បុតតែមួយធម្មតាកាន់តែងាយស្រួលសាកល្បង, សង្កេត និងបើកបរ នៅពេលដែលមានសំណុំបន្ទប់ និងឧបករណ៍តែមួយអាចដោះស្រាយភារកិច្ច។ ការចូលដំណើរការដល់ឧបករណ៍ជាច្រើនមិនបានបញ្ជាក់ថាត្រូវការបុតសំរាប់ជាច្រើនឡើយ។ តួនាទីដាច់ដោយឡែកដែលមានការអនុញ្ញាត និងការត្រួតពិនិត្យផ្សេងគ្នា សូវ្ឋីភាពពីរដែលត្រូវបានទាមទារអាចធ្វើឲ្យមានការរចនាបុតច្រើនបាន។
