# 🔍 ការបង្កើត Enterprise RAG ជាមួយ Microsoft Foundry (.NET)

## 📋 គោលបំណងការរៀន

សៀវភៅកំណត់ត្រានេះបង្ហាញពីរបៀបបង្កើតប្រព័ន្ធសំណុំបែបបទ Retrieval-Augmented Generation (RAG) កម្រិតសហគ្រាសដោយប្រើ Microsoft Agent Framework នៅក្នុង .NET ជាមួយ Microsoft Foundry។ អ្នកនឹងរៀនបង្កើតភ្នាក់ងារកំពុង​ផលិត ដែលអាចស្វែងរកឯកសារបាន ហើយផ្តល់ចម្លើយត្រឹមត្រូវ មាន​បរិបទ និងមានសុវត្ថិភាព និងអាចពង្រីកកម្រិតបានសម្រាប់សហគ្រាស។

**សមត្ថភាព Enterprise RAG ដែលអ្នកនឹងបង្កើត​​៖**
- 📚 **ភាពឆ្លាតវិចារណ ឯកសារ**: ការប្រមូលផ្តុំឯកសារដោយប្រើសេវាកម្ម AI របស់ Azure ដោយជំនាញខ្ពស់
- 🔍 **ការស្វែងរកអត្ថន័យ**: ការស្វែងរកវេទិកាប្រសិទ្ធភាពខ្ពស់ជាមួយលក្ខណៈសហគ្រាស
- 🛡️ **ការរួមបញ្ចូលសុវត្ថិភាព**: ការតំណើរការការចូលប្រើដោយផ្អែកលើតួនាទី និងគំរូការពារទិន្នន័យ
- 🏢 **ស្ថាបត្យកម្មអាចពង្រីកបាន**: ប្រព័ន្ធ RAG ដែលមានភាពពេញលេញក្នុងការផលិតជាមួយការត្រួតពិនិត្យ

## 🎯 ស្ថាបត្យកម្ម Enterprise RAG

### ធាតុស្នូលសម្រាប់សហគ្រាស
- **Microsoft Foundry**: វេទិកា AI សហគ្រាសដែលគ្រប់គ្រងដោយមានសុវត្ថិភាព និងការអនុវត្តគោលការណ៍
- **ភ្នាក់ងារដែលមានភាពអចិន្ត្រៃយ៍**: ភ្នាក់ងារដែលមានស្ថានភាព ជាមួយប្រវត្តិការសន្ទនា និងការគ្រប់គ្រងបរិបទ
- **ការគ្រប់គ្រងឃ្លាំងវ៉ិចទ័រ**: ការបង្ហាញសារជាឯកសារកម្រិតសហគ្រាស និងការស្វែងរក
- **ការរួមបញ្ចូលអត្តសញ្ញាណ**: ការផ្ទៀងផ្ទាត់ Azure AD និងការគ្រប់គ្រងការចូលប្រើតាមតួនាទី

### អត្ថប្រយោជន៍ .NET សម្រាប់សហគ្រាស
- **កំណត់ប្រភេទគោល**: ការត្រួតពិនិត្យនៅពេលកំណត់ប្រភេទសម្រាប់ប្រតិបត្តិការនិងរចនាសម្ព័ន្ធទិន្នន័យ RAG
- **ប្រតិបត្តិការជាន់លើ Async**: ការប្រមូលផ្តុំឯកសារនិងស្វែងរកដោយមិនរាំងខ្ទប់
- **ការគ្រប់គ្រងអង្គចងចាំ**: ការប្រើធនធានប្រសិទ្ធិភាពសម្រាប់ឯកសារច្រើនទំហំធំព្រុះ
- **គំរូរួមបញ្ចូល**: ការរួមបញ្ចូលសេវា Azure ដើមជាមួយការចាក់បញ្ចូលអាស្រ័យភាព

## 🔧 លក្ខណៈពិសេស និងអត្ថប្រយោជន៍សហគ្រាស

### សុវត្ថិភាព និងការអនុវត្តតាមបទបញ្ញត្តិ
- **ការរួមបញ្ចូល Azure AD**: ការគ្រប់គ្រងអត្តសញ្ញាណ និងការផ្ទៀងផ្ទាត់សហគ្រាស
- **ការចូលប្រើផ្អែកលើតួនាទី**: សិទ្ធិចូលប្រើលម្អិតសម្រាប់ឯកសារនិងប្រតិបត្តិការជាក់លាក់

- **ការបង្វិល​ទម្រង់ការធ្វើការ**: ការប្រតិបត្តិការបែងចែកសម្រាប់ការចេញផ្សាយដោយវិសាលភាពធំ

## 📊 លំនាំរចនា Enterprise RAG

### លំនាំគ្រប់គ្រងឯកសារ
- **ការផ្ទុកបង្កប់ជាច្រើន**: ការប្រមូលផ្តុំឯកសារច្រើនទំហំធំប្រកបដោយប្រសិទ្ធភាព
- **ការធ្វើបច្ចុប្បន្នភាពបន្ត**: ការបន្ថែម និងបម្លែងឯកសារពេញវេលា
- **ការគ្រប់គ្រងកំណែ**: ការកំណត់កំណែឯកសារ និងតាមដានការផ្លាស់ប្តូរ
- **ការគ្រប់គ្រង Metadata**: លក្ខណៈឯកសាររឹងមាំ និងចំណាត់ថ្នាក់

### លំនាំស្វែងរក និងយកវិញ
- **ស្វែងរកតំបន់ផ្សំ**: ផ្គុំការស្វែងរកអត្ថន័យ និងពាក្យគន្លឹះសម្រាប់លទ្ធផលល្អបំផុត
- **ស្វែងរកពហុណាស់**: ការត្រង និងចាត់ថ្នាក់ច្រើនវិមាត្រ
- **ការកំណត់តម្លៃសមរម្យ**: គណនាគោលការណ៍ប្ដូរពិន្ទុបុគ្គល បណ្តាបន្ថែមតាមតម្រូវការជាក់លាក់
- **ជម្រេីសលំដាប់លទ្ធផល**: ការលំដាប់លម្អិតជាមួយការរួមបញ្ចូលតុល្យភាពអាជីវកម្ម

### លំនាំសុវត្ថិភាព
- **សុវត្ថិភាពបណ្ដាលឯកសារ**: ការគ្រប់គ្រងសិទ្ធិចូលប្រើលម្អិតមួយឯកសារ
- **ចាត់ថ្នាក់ទិន្នន័យ**: ការតំឡើងស្លាកភាពរឹងមាំ និងការពារ
- **Audit Trails**: ការចុះបញ្ជីដំណើរការទាំងអស់របស់ប្រព័ន្ធ RAG
- **ការពារជាបុគ្គលិកភាព**: ការរកឃើញ និងការលុបចោល PII
