# Přispívání

Tento projekt vítá příspěvky a návrhy. Většina příspěvků vyžaduje, abyste souhlasili s licenční dohodou přispěvatele (CLA), ve které prohlašujete, že máte právo a skutečně nám udělujete práva k použití vašeho příspěvku. Pro podrobnosti navštivte <https://cla.opensource.microsoft.com>.

Když odešlete pull request, bot CLA automaticky zjistí, zda je třeba poskytnout CLA, a příslušným způsobem označí pull request. Postupujte podle pokynů bota. Toto budete muset udělat pouze jednou pro repozitáře, které používají Microsoft CLA.

## Kodex chování

Tento projekt přijal [Kodex chování otevřeného zdroje Microsoft](https://opensource.microsoft.com/codeofconduct/). Pro více informací si přečtěte [FAQ k Kodexu chování](https://opensource.microsoft.com/codeofconduct/faq/) nebo kontaktujte [opencode@microsoft.com](mailto:opencode@microsoft.com) s dalšími otázkami nebo komentáři.

## Pokyny k pull requestům

- Udržujte každý pull request zaměřený na jednu logickou změnu.
- Otestujte ovlivněné notebooky a ukázky kódu před odesláním.
- Při přidávání nebo změně příkladu aktualizujte příslušnou dokumentaci lekce.
- Upravujte pouze anglický zdrojový obsah. Překlady spravuje automatizovaný překladový workflow.
- Nezapisujte přihlašovací údaje, soubory `.env`, dočasné soubory ani generované artefakty pro vývoj.

## Redakční záběr a produkty třetích stran

Tento kurz se zaměřuje na technologie Microsoft a neutrální otevřené standardy. Příspěvky by měly sloužit jasnému vzdělávacímu účelu a nesmí být primárně určeny k zavedení nebo propagaci komerčního produktu třetí strany, hostované služby, modelového routeru, SDK, MCP serveru nebo jiné nabídky specifické pro dodavatele.

Open-source software a závislosti třetích stran mohou být zmíněny, pokud jsou nezbytné k vysvětlení otevřeného standardu nebo scénáře interoperability, jsou prezentovány neutrálně a nezaměřují se na produkt dodavatele nebo hostovaný koncový bod. Pokud váš navrhovaný příspěvek obsahuje produkt nebo službu specifickou pro dodavatele, založte issue a získejte schválení správce před odesláním pull requestu.

Přispěvatelé musí zveřejnit jakékoliv relevantní zaměstnání, vlastnictví, sponzorství nebo jinou spolupráci s produktem nebo službou uvedenou ve svém příspěvku. Nezahrnujte nepodložená tvrzení o cenách, výkonu, bezpečnosti, ochraně soukromí nebo srovnání. Spustitelné příklady nesmí ve výchozím nastavení přenášet data studenta nebo provádět veřejné akce prostřednictvím externí služby třetí strany.
