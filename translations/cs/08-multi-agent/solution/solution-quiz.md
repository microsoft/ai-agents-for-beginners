# Odpovědi na ověření znalostí

## Otázka 1

**Odpověď: A2.** Více agentů je užitečných, když úkol má odlišné specializované role, samostatné nástroje nebo oprávnění a jasné předání úkolů, které vyžadují koordinaci. Jednoduchý podpůrný bot může obvykle zůstat jako jeden agent. Vysoký počet stejných požadavků je především záležitostí škálování a sám o sobě nevyžaduje návrh s více agenty.

## Otázka 2

**Odpověď: A1.** Jeden agent je obvykle snazší na testování, pozorování a provoz, pokud lze úkol zvládnout jednou sadou instrukcí a nástrojů.
