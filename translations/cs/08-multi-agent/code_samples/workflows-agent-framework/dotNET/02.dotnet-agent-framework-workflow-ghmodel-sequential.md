# ⏩ Sekvenční pracovní postupy agentů s Azure OpenAI (Responses API) (.NET)

## 📋 Pokročilý tutoriál sekvenčního zpracování

Tento poznámkový blok demonstruje **vzory sekvenčních pracovních postupů** pomocí Microsoft Agent Framework pro .NET a Azure OpenAI (Responses API). Naučíte se, jak vytvářet sofistikované, krok za krokem zpracovatelské linky, kde agenti vykonávají úkoly v určitém pořadí, přičemž každé stadium staví na výsledcích předchozího.

## 🎯 Výukové cíle

### 🔄 **Architektura sekvenčního zpracování**
- **Lineární návrh pracovního postupu**: Vytvoření krok za krokem zpracovatelských linek s jasnými závislostmi
- **Správa stavu**: Udržování kontextu a toku dat napříč jednotlivými sekvenčními stadii
- **Azure OpenAI (Responses API)**: Využití modelů Azure OpenAI v vícestupňových .NET pracovních postupech
- **Vzory podnikových linek**: Vytváření produkčně připravených sekvenčních zpracovatelských systémů

### 🏗️ **Pokročilé sekvenční vzory**
- **Zpracování s kontrolními body**: Implementace validačních kontrol mezi stadii pracovního postupu
- **Zachování kontextu**: Udržování stavu a nahromaděných znalostí napříč všemi stadii
- **Šíření chyb**: Elegantní řešení selhání v sekvenčních zpracovatelských řetězcích
- **Optimalizace výkonu**: Efektivní sekvenční vykonávání s minimálním režijním nákladem

### 🏢 **Podnikové sekvenční aplikace**
- **Pipeline pro zpracování dokumentů**: Vícefázová analýza, transformace a validace dokumentů
- **Pracovní postupy kontroly kvality**: Sekvenční revize, validace a schvalovací procesy
- **Pipeline produkce obsahu**: Výzkum → Psání → Editace → Recenze → Publikace
- **Automatizace obchodních procesů**: Vícekrokové obchodní pracovní postupy s jasnými závislostmi stadií

### 🏗️ **Architektura sekvenčního pracovního postupu**

```mermaid
graph TD
    A[Initial Input] --> B[Stage 1: Analytický agent]
    B --> C[Kontrolní bod 1]
    C --> D[Stage 2: Zpracovatelský agent]
    D --> E[Kontrolní bod 2]
    E --> F[Stage 3: Validující agent]
    F --> G[Konečný výstup]
    
    H[Kontext stavu] --> B
    H --> D
    H --> F
    
    I[Azure OpenAI (Responses API)] --> B
    I --> D
    I --> F
```

**Klíčové komponenty:**
- **Sekvenční agenti**: Specializovaní agenti pro každé zpracovatelské stadium
- **Stavový kontext**: Udržuje nahromaděná data a rozhodnutí napříč stadii
- **Kontrolní body**: Validační body mezi stadii pro zajištění kvality a konzistence
- **Azure OpenAI Client**: Konzistentní přístup k AI modelům ve všech stadiích pracovního postupu

## 💻 Spuštění kódu

Kompletní implementace je k dispozici v `02.dotnet-agent-framework-workflow-ghmodel-sequential.cs`. Tento soubor demonstruje **třífázový pracovní postup analýzy nábytku**:

1. **Stadium 1 - Prodejní agent**: Analyzuje obrázky nábytku a poskytuje návrhy na nákup
2. **Stadium 2 - Cenový agent**: Poskytuje podrobné rozklady cen a možnosti rozpočtu
3. **Stadium 3 - Agent pro nabídky**: Generuje profesionální nabídkový dokument ve formátu Markdown

### 🏗️ **Architektura pracovního postupu**

```
Image Input → Sales Analysis → Price Estimation → Quote Generation → Final Output
```

Každý agent:
- Přijímá výstup z předchozího stádia jako kontext
- Staví na předchozí analýze s specializovanou expertízou
- Udržuje kontinuitu pracovního postupu prostřednictvím správy stavu

### 🚀 Spuštění příkladu

**Předpoklady:**
- Umístěte obrázek nábytku na `../imgs/home.png` (nebo aktualizujte proměnnou `imgPath`)
- Nakonfigurujte svůj `.env` soubor s Azure OpenAI endpointem a nasazením, pak se přihlaste pomocí `az login`

```bash
# Nastavte skript jako spustitelný (Unix/Linux/macOS)
chmod +x 02.dotnet-agent-framework-workflow-ghmodel-sequential.cs

# Spusťte sekvenční pracovní postup
./02.dotnet-agent-framework-workflow-ghmodel-sequential.cs
```

Nebo na Windows:
```powershell
dotnet run 02.dotnet-agent-framework-workflow-ghmodel-sequential.cs
```

### 📝 Očekávaný výstup

Pracovní postup:
1. **Prodejní agent**: Identifikuje položky nábytku na obrázku a poskytne doporučení
2. **Cenový agent**: Přidá podrobnou cenovou analýzu s rozdělením rozpočtu a doporučeními pro nákup
3. **Agent pro nabídky**: Vygeneruje formátovaný nabídkový dokument se všemi syntetizovanými informacemi

Konečný výstup bude komplexní, profesionální nabídka nábytku založená na analýze obrázku.
