# 🔄 Základní pracovní postupy agentů s Azure OpenAI (Responses API) (.NET)

## 📋 Tutoriál orchestrací pracovních postupů

Tento notebook ukazuje, jak vytvořit sofistikované **pracovní postupy agentů** pomocí Microsoft Agent Framework pro .NET a Azure OpenAI (Responses API). Naučíte se vytvářet vícefázové obchodní procesy, kde AI agenti spolupracují na dokončení složitých úkolů prostřednictvím strukturovaných vzorů orchestrace.

```xml
<PackageReference Include="DotNetEnv" Version="3.1.1" />
```

### 🔑 **Konfigurace Azure OpenAI**

**Nastavení prostředí (soubor .env):**
```env
AZURE_OPENAI_ENDPOINT=https://<your-resource>.openai.azure.com
AZURE_OPENAI_DEPLOYMENT=gpt-4o-mini
```

**Přístup k Azure OpenAI:**
1. Vytvořte zdroj Azure OpenAI v portálu Azure
2. Nasadíte model (například `gpt-4o-mini`) a zaznamenejte název nasazení
3. Přihlaste se pomocí `az login` a nastavte proměnné prostředí podle výše uvedeného

**Klíčové komponenty:**
- **WorkflowBuilder**: Hlavní orchestrátor pro návrh pracovních postupů

- **Azure OpenAI Client**: Integrace Azure OpenAI Responses API
- **Execution Context**: Správa stavu a toku dat mezi fázemi pracovního postupu

## 💻 Spuštění kódu

Kompletní implementace je k dispozici v `01.dotnet-agent-framework-workflow-ghmodel-basic.cs`. Tento soubor ukazuje:

1. **Konfigurace prostředí** - Načítání konfigurace Azure OpenAI ze souboru `.env`
2. **Nastavení klienta Azure OpenAI** - Konfigurace klienta pro použití Azure OpenAI Responses API
3. **Vytvoření agentů** - Definování specializovaných agentů (Recepce a Concierge)
4. **Sestavovač pracovního postupu** - Vytvoření víceagentního pracovního postupu se sekvenčním zpracováním
5. **Vykonání pracovního postupu** - Spuštění pracovního postupu se streamováním výsledků

