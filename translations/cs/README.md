## 🌱 Začínáme

Tento kurz obsahuje lekce, které pokrývají základy vytváření AI Agentů. Každá lekce se věnuje vlastnímu tématu, takže začněte kdekoliv chcete!

Kurz má podporu vícejazyčnosti. Zkontrolujte naše [dostupné jazyky zde](#-multi-language-support).

Pokud je to poprvé, co vytváříte s generativními AI modely, podívejte se na náš kurz [Generative AI For Beginners](https://aka.ms/genai-beginners), který obsahuje 21 lekcí o práci s GenAI.

Nezapomeňte [ohvězdičkovat (🌟) tento repozitář](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst) a [forkovat tento repozitář](https://github.com/microsoft/ai-agents-for-beginners/fork), abyste mohli spouštět kód.

### Potkejte další studenty, získejte odpovědi na své otázky

Pokud se zaseknete nebo budete mít otázky ohledně vytváření AI Agentů, připojte se k našemu specializovanému Discord kanálu na [Microsoft Foundry Discord](https://aka.ms/ai-agents/discord).

### Co potřebujete

Každá lekce v tomto kurzu obsahuje příklady kódu, které najdete ve složce code_samples. Můžete [forknout tento repozitář](https://github.com/microsoft/ai-agents-for-beginners/fork) pro vytvoření vlastní kopie.

Příklady kódu v těchto cvičeních využívají Microsoft Agent Framework s Microsoft Foundry Agent Service V2:

- [Microsoft Foundry](https://aka.ms/ai-agents-beginners/ai-foundry) - vyžaduje Azure účet

Tento kurz používá následující AI Agent frameworky a služby od Microsoftu:

- [Microsoft Agent Framework (MAF)](https://learn.microsoft.com/agent-framework/overview/)
- [Microsoft Foundry Agent Service V2](https://aka.ms/ai-agents-beginners/ai-agent-service)

Některé příklady kódu také podporují alternativní poskytovatele kompatibilní s OpenAI, jako je [MiniMax](https://platform.minimaxi.com/), který nabízí modely s velkým kontextem (až 204 tisíc tokenů). Podrobnosti najdete v [nastavení kurzu](./00-course-setup/README.md).

Pro více informací o spuštění kódu tohoto kurzu přejděte na [nastavení kurzu](./00-course-setup/README.md).
