## 🌱 Začínáme

Tento kurz obsahuje lekce pokrývající základy tvorby AI agentů. Každá lekce má své vlastní téma, takže začněte, kde chcete!

Kurz podporuje více jazyků. Navštivte naše [dostupné jazyky zde](#-multi-language-support).

Pokud stavíte s generativními AI modely poprvé, podívejte se na náš kurz [Generative AI For Beginners](https://aka.ms/genai-beginners), který obsahuje 21 lekcí o tvorbě s GenAI.

Nezapomeňte [oceňte (🌟) tento repozitář](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst) a [forkujte tento repozitář](https://github.com/microsoft/ai-agents-for-beginners/fork), abyste mohli spustit kód.

### Poznejte další studenty, získejte odpovědi na své otázky

Pokud se zaseknete nebo máte jakékoliv dotazy ohledně vytváření AI agentů, připojte se na náš Discord kanál v [Microsoft Foundry Discord](https://aka.ms/ai-agents/discord).

### Co potřebujete

Každá lekce v tomto kurzu obsahuje příklady kódu, které najdete ve složce code_samples. Můžete [forkovat tento repozitář](https://github.com/microsoft/ai-agents-for-beginners/fork) a vytvořit si tak vlastní kopii.  

Příklady kódu v těchto cvičeních využívají Microsoft Agent Framework s Microsoft Foundry Agent Service V2:

- [Microsoft Foundry](https://aka.ms/ai-agents-beginners/ai-foundry) - vyžaduje účet Azure

Tento kurz používá následující AI agentní frameworky a služby od Microsoftu:

- [Microsoft Agent Framework (MAF)](https://learn.microsoft.com/agent-framework/overview/)
- [Microsoft Foundry Agent Service V2](https://aka.ms/ai-agents-beginners/ai-agent-service)

Některé příklady kódu podporují také alternativní poskytovatele kompatibilní s OpenAI, jako je [MiniMax](https://platform.minimaxi.com/), který nabízí modely s velkým kontextem (až 204 tisíc tokenů). Podrobnosti o konfiguraci naleznete v [Course Setup](./00-course-setup/README.md).

Pro více informací o spuštění kódu pro tento kurz přejděte na [Course Setup](./00-course-setup/README.md).
