# 🔍 Корпоративен RAG с Microsoft Foundry (.NET)

## 📋 Учебни цели

Този тетрадка показва как да построите корпоративни системи за Retrieval-Augmented Generation (RAG) с помощта на Microsoft Agent Framework в .NET и Microsoft Foundry. Ще научите как да създавате готови за производство агенти, които могат да търсят в документи и да предоставят точни, контекстуално осъзнати отговори с корпоративна сигурност и мащабируемост.

**Корпоративни RAG възможности, които ще изградите:**
- 📚 **Интелигентност на документи**: Разширена обработка на документи с използване на Azure AI услуги
- 🔍 **Семантично търсене**: Високоефективно векторно търсене с корпоративни функции
- 🛡️ **Интеграция на сигурността**: Контрол на достъпа базиран на роли и модели за защита на данните
- 🏢 **Мащабируема архитектура**: Готови за продукция RAG системи с мониторинг

## 🎯 Корпоративна RAG архитектура

### Основни корпоративни компоненти
- **Microsoft Foundry**: Управлявана платформа за корпоративен AI със сигурност и съответствие
- **Постоянни агенти**: Състояни агенти с история на разговорите и управление на контекст
- **Управление на векторни хранилища**: Индексиране и извличане на документи на корпоративно ниво
- **Интеграция на идентичността**: Azure AD удостоверяване и контрол на достъпа базиран на роли

### Предимства на .NET за предприятия
- **Типова сигурност**: Проверка по време на компилация за RAG операции и структурите на данни
- **Асинхронна производителност**: Неблокиращи операции за обработка и търсене на документи
- **Управление на паметта**: Ефективно използване на ресурсите за големи колекции документи
- **Интеграционни модели**: Родна интеграция на Azure услуги с dependency injection

## 🏗️ Техническа архитектура

### Enterprise RAG pipeline
```
Document Upload → Security Validation → Vector Processing → Index Creation
                      ↓                    ↓                  ↓
User Query → Authentication → Semantic Search → Context Ranking → AI Response
```

### Основни .NET компоненти
- **Azure.AI.Agents.Persistent**: Управление на корпоративни агенти с персистентност на състоянието
- **Azure.Identity**: Интегрирано удостоверяване за сигурен достъп до Azure услуги
- **Microsoft.Agents.AI.AzureAI**: Имплементация на агентска рамка оптимизирана за Azure
- **System.Linq.Async**: Високоефективни асинхронни LINQ операции
