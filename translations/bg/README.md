> **CMD (Windows):**
> ```cmd
> git clone --filter=blob:none --sparse https://github.com/microsoft/ai-agents-for-beginners.git
> cd ai-agents-for-beginners
> git sparse-checkout set --no-cone "/*" "!translations" "!translated_images"
> ```
>
> Това ви дава всичко необходимо за завършване на курса с много по-бързо изтегляне.

## 🌱 Започване

Този курс включва уроци, които обхващат основите на изграждане на AI агенти. Всеки урок разглежда своята тема, така че започнете откъдето пожелаете!

Курсът поддържа много езици. Вижте нашите [налични езици тук](#-multi-language-support).

Ако това е първият ви път да работите с генеративни AI модели, разгледайте нашия курс [Generative AI For Beginners](https://aka.ms/genai-beginners), който включва 21 урока за изграждане с GenAI.

Не забравяйте да [даде звезда (🌟) на това хранилище](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst) и да [разклоните това хранилище](https://github.com/microsoft/ai-agents-for-beginners/fork), за да изпълните кода.

### Срещнете други учащи се, получете отговори на вашите въпроси

Ако се затрудните или имате въпроси за изграждане на AI агенти, присъединете се към нашия специализиран Discord канал в [Microsoft Foundry Discord](https://aka.ms/ai-agents/discord).

### Какво ви трябва

Всеки урок в този курс включва примери с код, които могат да се намерят в папката code_samples. Можете да [разклоните това хранилище](https://github.com/microsoft/ai-agents-for-beginners/fork), за да създадете собствено копие.

Примерите с код в тези упражнения използват Microsoft Agent Framework с Microsoft Foundry Agent Service V2:

- [Microsoft Foundry](https://aka.ms/ai-agents-beginners/ai-foundry) - изисква Azure акаунт

Този курс използва следните AI агентни рамки и услуги от Microsoft:

- [Microsoft Agent Framework (MAF)](https://learn.microsoft.com/agent-framework/overview/)
- [Microsoft Foundry Agent Service V2](https://aka.ms/ai-agents-beginners/ai-agent-service)

Някои примерни кодове поддържат алтернативни доставчици, съвместими с OpenAI като [MiniMax](https://platform.minimaxi.com/), който предлага модели с голям контекст (до 204K токена). Вижте [Course Setup](./00-course-setup/README.md) за подробности относно конфигурацията.

За повече информация относно стартирането на кода на курса, посетете [Course Setup](./00-course-setup/README.md).
