>
> Това хранилище включва 50+ езикови преводи, което значително увеличава размера на изтегляне. За да клонирате без преводи, използвайте sparse checkout:
>
> **Bash / macOS / Linux:**
> ```bash
> git clone --filter=blob:none --sparse https://github.com/microsoft/ai-agents-for-beginners.git
> cd ai-agents-for-beginners
> git sparse-checkout set --no-cone '/*' '!translations' '!translated_images'
> ```
>
> **CMD (Windows):**
> ```cmd
> git clone --filter=blob:none --sparse https://github.com/microsoft/ai-agents-for-beginners.git
> cd ai-agents-for-beginners
> git sparse-checkout set --no-cone "/*" "!translations" "!translated_images"
> ```
>
> Това ви дава всичко необходимо за завършване на курса с много по-бързо изтегляне.

## 🌱 Започване

Този курс съдържа уроци, покриващи основите на създаването на AI агенти. Всеки урок обхваща своя тема, така че започнете откъдето искате!

Има поддръжка на множество езици за този курс. Вижте нашите [налични езици тук](#-multi-language-support).

Ако това е първият ви път да създавате с генеративни AI модели, разгледайте нашия курс [Generative AI For Beginners](https://aka.ms/genai-beginners), който включва 21 урока за създаване с GenAI.

Не забравяйте да [звездите (🌟) това хранилище](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst) и да [форкнете това хранилище](https://github.com/microsoft/ai-agents-for-beginners/fork), за да стартирате кода.

### Срещнете други учащи, получете отговори на вашите въпроси

Ако се затрудните или имате въпроси относно създаването на AI агенти, присъединете се към нашия специализиран Discord канал в [Microsoft Foundry Discord](https://aka.ms/ai-agents/discord).

### Какво ви е необходимо

Всеки урок в този курс включва кодови примери, които могат да бъдат намерени в папката code_samples. Можете да [форкнете това хранилище](https://github.com/microsoft/ai-agents-for-beginners/fork), за да създадете свое собствено копие.

Кодови примерите в тези упражнения използват Microsoft Agent Framework с Microsoft Foundry Agent Service V2:

- [Microsoft Foundry](https://aka.ms/ai-agents-beginners/ai-foundry) - Необходим е Azure акаунт

Този курс използва следните AI Agent рамки и услуги от Microsoft:

- [Microsoft Agent Framework (MAF)](https://learn.microsoft.com/agent-framework/overview/)
- [Microsoft Foundry Agent Service V2](https://aka.ms/ai-agents-beginners/ai-agent-service)

Някои кодови примери също поддържат алтернативни OpenAI-съвместими доставчици като [MiniMax](https://platform.minimaxi.com/), който предлага модели с голям контекст (до 204K токена). Вижте [Настройка на курса](./00-course-setup/README.md) за конфигурационни подробности.

За повече информация относно изпълнението на кода за този курс, посетете [Настройка на курса](./00-course-setup/README.md).
