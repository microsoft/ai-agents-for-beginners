> cd ai-agents-for-beginners
> git sparse-checkout set --no-cone '/*' '!translations' '!translated_images'
> ```
>
> **CMD (Windows):**
> ```cmd
> git clone --filter=blob:none --sparse https://github.com/microsoft/ai-agents-for-beginners.git
> cd ai-agents-for-beginners
> git sparse-checkout set --no-cone "/*" "!translations" "!translated_images"
> ```
>
> Това ви осигурява всичко необходимо, за да завършите курса с много по-бързо изтегляне.

## 🌱 Започване

Този курс има уроци, покриващи основите на създаването на AI агенти. Всеки урок покрива отделна тема, така че започнете, откъдето пожелаете!

Има поддръжка на много езици за този курс. Отидете на [наличните езици тук](#-multi-language-support).

Ако това е вашето първо време да работите с генеративни AI модели, разгледайте нашия курс [Генеративен AI за начинаещи](https://aka.ms/genai-beginners), който включва 21 урока за работа с GenAI.

Не забравяйте да [звездичкайте (🌟) това хранилище](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst) и да [форкнете това хранилище](https://github.com/microsoft/ai-agents-for-beginners/fork), за да стартирате кода.

### Запознайте се с други учащи, получете отговори на вашите въпроси

Ако се затрудните или имате въпроси за създаването на AI агенти, присъединете се към нашия специализиран Discord канал в [Microsoft Foundry Discord](https://aka.ms/ai-agents/discord).

### Какво ви е необходимо

Всеки урок в този курс включва примери с код, които можете да намерите в папката code_samples. Можете да [форкнете това хранилище](https://github.com/microsoft/ai-agents-for-beginners/fork), за да създадете собствено копие.

Примерите с код в тези упражнения използват Microsoft Agent Framework с Microsoft Foundry Agent Service V2:

- [Microsoft Foundry](https://aka.ms/ai-agents-beginners/ai-foundry) - изисква Azure акаунт

Този курс използва следните AI Agent рамки и услуги на Microsoft:

- [Microsoft Agent Framework (MAF)](https://learn.microsoft.com/agent-framework/overview/)
- [Microsoft Foundry Agent Service V2](https://aka.ms/ai-agents-beginners/ai-agent-service)

Някои примери с код поддържат и алтернативни провайдъри, съвместими с OpenAI, като [MiniMax](https://platform.minimaxi.com/), който предлага модели с голям контекст (до 204K токени). Вижте [Course Setup](./00-course-setup/README.md) за подробности около конфигурацията.

За повече информация относно стартирането на кода за този курс, посетете [Course Setup](./00-course-setup/README.md).
