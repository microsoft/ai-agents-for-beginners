# AGENTS.md

## Преглед на проекта

Този хранилище съдържа "AI Агенти за начинаещи" - обширен образователен курс, който преподава всичко необходимо за изграждането на AI агенти. Курсът се състои от 18 урока, покриващи основи, шаблони за проектиране, рамки и производство на внедряване на AI агенти.

**Основни технологии:**
- Python 3.12+
- Jupyter бележници за интерактивно обучение
- AI рамки: Microsoft Agent Framework (MAF)
- Azure AI услуги: Microsoft Foundry, Azure AI Foundry Agent Service V2

**Архитектура:**
- Структура, базирана на уроци (директории 00-15+)
- Всеки урок съдържа: README документация, кодови примери (Jupyter бележници) и изображения
- Поддръжка на няколко езика чрез автоматизирана система за превод
- Един Python бележник на урок, използващ Microsoft Agent Framework

## Команди за настройка

### Изисквания
- Python 3.12 или по-нова версия
- Абонамент за Azure (за Azure AI Foundry)
- Инсталиран и удостоверен Azure CLI (`az login`)

### Първоначална настройка

1. **Клониране или форк на хранилището:**
   ```bash
   gh repo fork microsoft/ai-agents-for-beginners --clone
   # ИЛИ
   git clone https://github.com/microsoft/ai-agents-for-beginners.git
   cd ai-agents-for-beginners
   ```

2. **Създаване и активиране на виртуална Python среда:**
   ```bash
   python3 -m venv venv
   source venv/bin/activate  # В Windows: venv\Scripts\activate
   ```

3. **Инсталиране на зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Настройка на променливи на околната среда:**
   ```bash
   cp .env.example .env
   # Редактирайте .env с вашите API ключове и крайни точки
   ```

### Изисквани променливи на околната среда

За **Azure AI Foundry** (задължително):
- `AZURE_AI_PROJECT_ENDPOINT` - крайна точка на проекта в Azure AI Foundry
- `AZURE_AI_MODEL_DEPLOYMENT_NAME` - име на внедряване на модела (напр. gpt-4o)

За **Azure AI Search** (Урок 05 - RAG):
- `AZURE_SEARCH_SERVICE_ENDPOINT` - крайна точка на Azure AI Search
- `AZURE_SEARCH_API_KEY` - API ключ за Azure AI Search

Удостоверяване: Изпълнявайте `az login` преди стартиране на бележниците (използва `AzureCliCredential`).

## Работен процес за разработка

### Стартиране на Jupyter бележници

Всеки урок съдържа няколко Jupyter бележника за различни рамки:

1. **Стартирайте Jupyter:**
   ```bash
   jupyter notebook
   ```

2. **Навигирайте до директорията с урока** (например `01-intro-to-ai-agents/code_samples/`)

3. **Отворете и изпълнете бележниците:**
   - `*-python-agent-framework.ipynb` - използва Microsoft Agent Framework (Python)
   - `*-dotnet-agent-framework.ipynb` - използва Microsoft Agent Framework (.NET)

### Работа с Microsoft Agent Framework

**Microsoft Agent Framework + Azure AI Foundry:**
- Изисква абонамент за Azure
- Използва `AzureAIProjectAgentProvider` за Agent Service V2 (агентите са видими в портала на Foundry)
- Готов за производство с вградена наблюдаемост
- Шаблон на файл: `*-python-agent-framework.ipynb`

## Специфичен контекст на проекта

### Поддръжка на няколко езика

Това хранилище използва автоматизирана система за превод:
- Поддържа се на 50+ езика
- Преводите са в директории `/translations/<lang-code>/`
- Работният поток на GitHub Actions обработва обновления на превода
- Изходните файлове са на английски в корена на хранилището

### Структура на уроците

Всеки урок следва последователен модел:
1. Видео миниатюра с линк
2. Писан урок (README.md)
3. Кодови примери в няколко рамки
4. Учебни цели и предпоставки
5. Допълнителни учебни ресурси като връзки

### Наименоване на кодови примери

Формат: `<номер-урок>-python-agent-framework.ipynb`
- `01-python-agent-framework.ipynb` - Урок 1, MAF Python
- `14-sequential.ipynb` - Урок 14, МAF напреднали шаблони

### Специални директории

- `translated_images/` - Локализирани изображения за преводи
- `images/` - Оригинални изображения за английското съдържание
- `.devcontainer/` - Конфигурация за контейнер за разработка на VS Code
- `.github/` - GitHub Actions работни потоци и шаблони

### Зависимости

Основни пакети от `requirements.txt`:
- `agent-framework` - Microsoft Agent Framework
- `a2a-sdk` - Поддръжка на Agent-to-Agent протокол
- `azure-ai-inference`, `azure-ai-projects` - Azure AI услуги
- `azure-identity` - Azure удостоверяване (AzureCliCredential)
- `azure-search-documents` - Интеграция с Azure AI Search
- `mcp[cli]` - Поддръжка на Model Context Protocol
