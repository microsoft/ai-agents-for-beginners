# AGENTS.md

## Преглед на проекта

Това хранилище съдържа "AI агенти за начинаещи" - изчерпателен образователен курс, който преподава всичко необходимо за създаване на AI агенти. Курсът се състои от 18 урока (номерирани от 00 до 18), обхващащи основи, дизайнерски шаблони, рамки, внедряване в продукция, локални/устройствени агенти и сигурност на AI агенти.

**Основни технологии:**
- Python 3.12+
- Jupyter ноутбуци за интерактивно обучение
- AI рамки: Microsoft Agent Framework (MAF)
- Azure AI услуги: Microsoft Foundry, Microsoft Foundry Agent Service V2

**Архитектура:**
- Структура базирана на уроци (папки 00-18)
- Всеки урок съдържа: README документация, примерни кодове (Jupyter ноутбуци) и изображения
- Поддръжка на много езици чрез автоматизирана система за превод
- Един Python ноутбук на урок, използващ Microsoft Agent Framework

## Команди за настройка

### Предварителни изисквания
- Python 3.12 или по-нова версия
- Абонамент в Azure (за Microsoft Foundry)
- Инсталиран и удостоверен Azure CLI (`az login`)

### Първоначална настройка

1. **Клонирайте или форкнете хранилището:**
   ```bash
   gh repo fork microsoft/ai-agents-for-beginners --clone
   # OR
   git clone https://github.com/microsoft/ai-agents-for-beginners.git
   cd ai-agents-for-beginners
   ```

2. **Създайте и активирайте Python виртуална среда:**
   ```bash
   python3 -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   ```

3. **Инсталирайте зависимостите:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Настройте променливите на средата:**
   ```bash
   cp .env.example .env
   # Edit .env with your API keys and endpoints
   ```

### Задължителни променливи на средата

За **Microsoft Foundry** (задължително):
- `AZURE_AI_PROJECT_ENDPOINT` - Крайна точка на Microsoft Foundry проекта
- `AZURE_AI_MODEL_DEPLOYMENT_NAME` - Име на внедряването на модела (например gpt-5-mini)

За **Azure AI Search** (Урок 05 - RAG):
- `AZURE_SEARCH_SERVICE_ENDPOINT` - Крайна точка на Azure AI Search
- `AZURE_SEARCH_API_KEY` - API ключ за Azure AI Search

Аутентикация: Стартирайте `az login` преди да стартирате ноутбуците (използва `AzureCliCredential`).

## Работен процес при разработка

### Стартиране на Jupyter ноутбуци

Всеки урок съдържа множество Jupyter ноутбуци за различни рамки:

1. **Стартирайте Jupyter:**
   ```bash
   jupyter notebook
   ```

2. **Навигирайте до папката на урока** (например `01-intro-to-ai-agents/code_samples/`)

3. **Отворете и стартирайте ноутбуците:**
   - `*-python-agent-framework.ipynb` - Използване на Microsoft Agent Framework (Python)
   - `*-dotnet-agent-framework.ipynb` - Използване на Microsoft Agent Framework (.NET)

### Работа с Microsoft Agent Framework

**Microsoft Agent Framework + Microsoft Foundry:**
- Изисква Azure абонамент
- Използва `FoundryChatClient` за Agent Service V2 (агентите са видими в портала Foundry)
- Готово за продукция с вградена наблюдаемост
- Шаблон за файлове: `*-python-agent-framework.ipynb`

Това е образователно хранилище с примерен код, а не продукционен код с автоматизирани тестове. За да проверите настройката и промените си:

2. **Тествайте изпълнението на ноутбук:**


3. **Проверете променливите на средата:**
   ```bash
   python -c "import os; from dotenv import load_dotenv; load_dotenv(); print('✓ AZURE_AI_PROJECT_ENDPOINT' if os.getenv('AZURE_AI_PROJECT_ENDPOINT') else '✗ AZURE_AI_PROJECT_ENDPOINT missing')"
   ```

### Стартиране на отделни ноутбуци

Отворете ноутбуците в Jupyter и изпълнявайте клетките последователно. Всеки ноутбук е самостоятелен и включва:
- Импорт на библиотеки
- Зареждане на конфигурация
- Примери за реализации на агенти
- Очаквани изходни данни в markdown клетки

### Смоук тест на внедрените агенти

За уроци, където агентът е внедрен като хостван агент в Microsoft Foundry (01, 04, 05, 16), хранилището предоставя каталози за смоук тестове под `tests/`, които се изпълняват чрез `.github/workflows/smoke-test.yml` workflow с действието [AI Smoke Test](https://github.com/marketplace/actions/ai-smoke-test). Това е лек пост-внедреният филтър (може ли агентът да бъде достигнат и изпълнява ли основни очаквания към промпта?), допълващ оценъчната верига в урок 10 и 16. Вижте [tests/README.md](./tests/README.md) за съответствието между каталог-урок-агент. Урок 17 се изпълнява локално с Foundry Local и няма хоствана крайна точка, затова се валидира чрез директно стартиране на неговия ноутбук.

## Контекст, специфичен за проекта

### Поддръжка на много езици

Това хранилище използва автоматизирана система за превод:

- Преводите са в папки `/translations/<lang-code>/`

- Изходните файлове са на английски в корена на хранилището

### Структура на уроците

Всеки урок следва последователен модел:
1. Видео миниатюра с линк
2. Писмено съдържание на урока (README.md)
3. Примерни кодове в няколко рамки
4. Цели за учене и предварителни изисквания
5. Допълнителни учебни ресурси с линкове

### Именуване на примерните кодове

Формат: `<lesson-number>-python-agent-framework.ipynb`
- `01-python-agent-framework.ipynb` - Урок 1, MAF Python
- `14-sequential.ipynb` - Урок 14, разширени шаблони на MAF
- `16-python-agent-framework.ipynb` - Урок 16, продукционен агент за поддръжка на клиенти

- `.devcontainer/` - Конфигурация на контейнера за разработка на VS Code
- `.github/` - GitHub Actions workflow и шаблони

- `azure-identity` - Azure удостоверяване (AzureCliCredential)
- `azure-search-documents` - Интеграция на Azure AI Search
