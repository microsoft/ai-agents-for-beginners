```mermaid

    A[Input: Content Outline] --> B[Изпълнител на чернова
```

## 💻 Стартиране на кода

Пълната имплементация е налична в `04.dotnet-agent-framework-workflow-aifoundry-condition.cs`. Тя демонстрира **работен поток за производство на съдържание с контролни точки за качество**:

### 🏗️ **Архитектура на работния поток**

```
Content Outline → Draft Creation → Quality Review → Conditional Routing:
                                                      ├─ Approved (>200 words) → Publish
                                                      └─ Rejected (<200 words) → Review Notification
```

**Агенти в работния поток:**
1. **Агент евангелист:** Създава чернови на урока от контурите с основаване на Bing
2. **Агент за преглед на съдържанието:** Оценява качеството на черновата (брой думи, пълнота)
3. **Агент публикувач:** Записва одобреното съдържание като маркирани файлове с времеви марки

**Персонализирани изпълнители:**
1. **DraftExecutor:** Координира създаването на чернови
2. **ContentReviewExecutor:** Извършва оценка на качеството
3. **PublishExecutor:** Отговаря за публикуването на одобреното съдържание
4. **SendReviewExecutor:** Управлява известията за отхвърлено съдържание

### 📝 Очакван резултат

Работният поток ще:
1. **Създаде агенти:** Инициализира три специализирани агенти Microsoft Foundry
2. **Генерира чернова:** Агент евангелист създава чернова на урока от контур
3. **Преглед на съдържанието:** Агентът за преглед оценява качеството на черновата
4. **Условна маршрутизация:**
   - **Ако е одобрено (>200 думи):** Изпълнителят за публикуване го записва като Markdown файл
   - **Ако е отхвърлено (<200 думи):** Изпраща известие за прегледа
5. **Показване на резултати:** Показва крайния резултат от работния поток

### 🔍 Разбиране на условната логика

**Функция Condition:**
```csharp
public Func<object?, bool> GetCondition(string expectedResult) =>
    reviewResult => reviewResult is ReviewResult review && review.Result == expectedResult;
```

Тази функция създава предикат, който:
1. Проверява дали резултатът е от тип `ReviewResult`
2. Сравнява свойството `Result` с очакваната стойност
3. Връща true/false, за да определи маршрутизирането

**Ръбове на работния поток с условия:**
```csharp
.AddEdge(contentReviewerExecutor, publishExecutor, condition: GetCondition("Yes"))
.AddEdge(contentReviewerExecutor, sendReviewerExecutor, condition: GetCondition("No"))
```
