> **Ưu tiên Clone Cục bộ?**
>
> Kho lưu trữ này bao gồm hơn 50 bản dịch ngôn ngữ làm tăng kích thước tải xuống đáng kể. Để clone mà không có bản dịch, sử dụng sparse checkout:
>
> **Bash / macOS / Linux:**
> ```bash
> git clone --filter=blob:none --sparse https://github.com/microsoft/ai-agents-for-beginners.git
> cd ai-agents-for-beginners
> git sparse-checkout set --no-cone '/*' '!translations' '!translated_images'
> ```
>
> **CMD (Windows):**
> ```cmd
> git clone --filter=blob:none --sparse https://github.com/microsoft/ai-agents-for-beginners.git
> cd ai-agents-for-beginners
> git sparse-checkout set --no-cone "/*" "!translations" "!translated_images"
> ```
>
> Điều này cung cấp cho bạn tất cả những gì cần thiết để hoàn thành khóa học với tốc độ tải nhanh hơn nhiều.

## 🌱 Bắt đầu

Khóa học này có các bài học bao gồm những nguyên tắc cơ bản để xây dựng Đại lý AI. Mỗi bài học đề cập đến chủ đề riêng của nó, vậy hãy bắt đầu từ đâu bạn thích!

Khóa học này hỗ trợ đa ngôn ngữ. Truy cập [các ngôn ngữ có sẵn tại đây](#-multi-language-support).

Nếu đây là lần đầu tiên bạn xây dựng với các mô hình AI Tạo Sinh, hãy xem khóa học [Generative AI For Beginners](https://aka.ms/genai-beginners), mà bao gồm 21 bài học về xây dựng với GenAI.

Đừng quên [thả sao (🌟) cho repo này](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst) và [fork repo này](https://github.com/microsoft/ai-agents-for-beginners/fork) để chạy mã.

### Gặp gỡ Những Người Học Khác, Nhận Câu Hỏi Được Trả Lời

Nếu bạn gặp khó khăn hoặc có bất kỳ câu hỏi nào về xây dựng Đại lý AI, hãy tham gia Kênh Discord riêng của chúng tôi trong [Microsoft Foundry Discord](https://aka.ms/ai-agents/discord).

### Những gì bạn cần

Mỗi bài học trong khóa này bao gồm các ví dụ mã, có thể tìm thấy trong thư mục code_samples. Bạn có thể [fork repo này](https://github.com/microsoft/ai-agents-for-beginners/fork) để tạo bản sao của riêng bạn.

Các ví dụ mã trong các bài tập này sử dụng Microsoft Agent Framework với Microsoft Foundry Agent Service V2:

- [Microsoft Foundry](https://aka.ms/ai-agents-beginners/ai-foundry) - Yêu cầu Tài khoản Azure

Khóa học này sử dụng các framework và dịch vụ Đại lý AI sau từ Microsoft:

- [Microsoft Agent Framework (MAF)](https://learn.microsoft.com/agent-framework/overview/)
- [Microsoft Foundry Agent Service V2](https://aka.ms/ai-agents-beginners/ai-agent-service)

Một số ví dụ mã cũng hỗ trợ các nhà cung cấp tương thích với OpenAI khác như [MiniMax](https://platform.minimaxi.com/), cung cấp các mô hình ngữ cảnh lớn (lên đến 204K token). Xem phần [Thiết lập Khóa học](./00-course-setup/README.md) để biết chi tiết cấu hình.

Để biết thêm thông tin về cách chạy mã cho khóa học này, hãy truy cập [Thiết lập Khóa học](./00-course-setup/README.md).

Thỏa thuận Cấp phép Đóng góp (CLA) tuyên bố rằng bạn có quyền và thực sự cấp cho chúng tôi
quyền sử dụng đóng góp của bạn. Chi tiết xem tại <https://cla.opensource.microsoft.com>.

Khi bạn gửi yêu cầu kéo, bot CLA sẽ tự động xác định liệu bạn có cần cung cấp
một CLA và trang trí PR cho phù hợp (ví dụ: kiểm tra trạng thái, bình luận). Chỉ cần làm theo hướng dẫn
do bot cung cấp. Bạn chỉ cần làm việc này một lần trong tất cả các kho chứa sử dụng CLA của chúng tôi.

Dự án này đã áp dụng [Bộ Quy tắc Ứng xử Mã nguồn mở Microsoft](https://opensource.microsoft.com/codeofconduct/).
Để biết thêm thông tin hãy xem [Câu hỏi Thường gặp về Quy tắc Ứng xử](https://opensource.microsoft.com/codeofconduct/faq/) hoặc
liên hệ [opencode@microsoft.com](mailto:opencode@microsoft.com) với bất kỳ câu hỏi hoặc nhận xét bổ sung nào.
