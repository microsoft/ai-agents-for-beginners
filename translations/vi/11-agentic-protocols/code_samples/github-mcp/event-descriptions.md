## Tên sự kiện: API đa agent với LangGraph và Azure Cosmos DB

## Mô tả

Trong buổi hội thảo này, chúng tôi sẽ đi sâu vào ứng dụng đa agent cấp sản xuất được xây dựng với LangGraph cho việc điều phối agent, FastAPI cho lớp API, và Azure Cosmos DB là nền tảng quản lý trạng thái, lưu trữ vector, và dữ liệu giao dịch.

Qua việc giải thích mã chi tiết, bạn sẽ thấy cách thiết kế và triển khai một quy trình làm việc điều phối bởi agent tích hợp hàm tạo tăng cường truy xuất (RAG), nhớ lâu dài, và chuyển đổi trạng thái động. Chúng tôi sẽ trình bày:

Hợp tác agent với LangGraph cho lý luận có cấu trúc
Lưu trữ lịch sử chat theo thời gian thực sử dụng Azure Cosmos DB - cơ sở dữ liệu tương tự dùng cho lịch sử chat trong ChatGPT, ứng dụng agent AI phát triển nhanh nhất trong lịch sử
Tìm kiếm vector để truy xuất kiến thức với hỗ trợ embeddings nguyên bản của Cosmos DB
Khả năng async của FastAPI để giữ tương tác nhanh nhạy và có thể mở rộng
Cuối buổi hội thảo, bạn sẽ có một bản thiết kế rõ ràng để xây dựng và triển khai các ứng dụng đa agent có thể mở rộng, bản địa trên đám mây tận dụng sức mạnh của AI hiện đại và hạ tầng điện toán đám mây. Dù bạn là kỹ sư AI, kiến trúc sư đám mây hay nhà phát triển Python, bài nói chuyện này sẽ cung cấp cho bạn những kiến thức thực tế và các mẫu đã kiểm nghiệm để xây dựng thế hệ ứng dụng AI tiên tiến.
