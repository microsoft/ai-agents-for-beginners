# 🔄 Các luồng công việc cơ bản của Agent với Azure OpenAI (Responses API) (.NET)

## 📋 Hướng dẫn Điều phối Quy trình làm việc

Notebook này minh họa cách xây dựng các **luồng công việc agent** tinh vi sử dụng Microsoft Agent Framework cho .NET và Azure OpenAI (Responses API). Bạn sẽ học cách tạo các quy trình nghiệp vụ đa bước, nơi các agent AI hợp tác để hoàn thành các nhiệm vụ phức tạp thông qua các mẫu điều phối có cấu trúc.

## 🎯 Mục tiêu học tập

### 🏗️ **Các nguyên lý Kiến trúc Luồng Công việc**
- **Workflow Builder**: Thiết kế và điều phối các quy trình AI đa bước phức tạp
- **Agent Coordination**: Phối hợp nhiều agent chuyên biệt trong các luồng công việc
- **Azure OpenAI (Responses API)**: Tận dụng Azure OpenAI Responses API trong các luồng công việc
- **Visual Workflow Design**: Tạo và trực quan hóa cấu trúc luồng công việc để hiểu rõ hơn

### 🔄 **Các mẫu Điều phối Quy trình**
- **Sequential Processing**: Xâu chuỗi nhiều nhiệm vụ agent theo thứ tự logic
- **State Management**: Duy trì ngữ cảnh và luồng dữ liệu qua các giai đoạn luồng công việc
- **Error Handling**: Triển khai phục hồi lỗi mạnh mẽ và độ bền luồng công việc
- **Performance Optimization**: Thiết kế luồng công việc hiệu quả cho quy mô doanh nghiệp

### 🏢 **Ứng dụng Luồng Công việc Doanh nghiệp**
- **Business Process Automation**: Tự động hóa các luồng công việc tổ chức phức tạp
- **Content Production Pipeline**: Các luồng biên tập với các giai đoạn duyệt và phê duyệt
- **Customer Service Automation**: Giải quyết các yêu cầu khách hàng đa bước
- **Data Processing Workflows**: Các luồng ETL với chuyển đổi hỗ trợ AI

## ⚙️ Yêu cầu & Cài đặt

### 📦 **Các Gói NuGet Cần Thiết**

Minh họa luồng công việc này sử dụng một số gói .NET quan trọng:

```xml
<!-- Core AI Framework -->
<PackageReference Include="Microsoft.Extensions.AI" Version="9.9.0" />

<!-- Azure OpenAI (Responses API) -->
<PackageReference Include="Azure.AI.OpenAI" Version="2.1.0" />
<PackageReference Include="Azure.Identity" Version="1.13.1" />

<!-- Agent Framework (Local Development) -->
<!-- Microsoft.Agents.AI.dll - Core agent abstractions -->
<!-- Microsoft.Agents.AI.OpenAI.dll - Azure OpenAI (Responses API) integration -->

<!-- Configuration and Environment -->
<PackageReference Include="DotNetEnv" Version="3.1.1" />
```

### 🔑 **Cấu hình Azure OpenAI**

**Thiết lập Môi trường (tệp .env):**
```env
AZURE_OPENAI_ENDPOINT=https://<your-resource>.openai.azure.com
AZURE_OPENAI_DEPLOYMENT=gpt-4o-mini
```

**Truy cập Azure OpenAI:**
1. Tạo một tài nguyên Azure OpenAI trong cổng Azure
2. Triển khai một mô hình (ví dụ `gpt-4o-mini`) và ghi lại tên triển khai
3. Đăng nhập với `az login` và cấu hình biến môi trường như trên

**Các Thành phần Chính:**
- **WorkflowBuilder**: Bộ máy điều phối chính dùng để thiết kế luồng công việc
- **AIAgent**: Các agent chuyên biệt với năng lực cụ thể
- **Azure OpenAI Client**: Tích hợp Azure OpenAI Responses API
- **Execution Context**: Quản lý trạng thái và luồng dữ liệu giữa các giai đoạn luồng công việc
