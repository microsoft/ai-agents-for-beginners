# ⏩ Các Quy Trình Công Việc Theo Trình Tự của Đại Lý với Azure OpenAI (Responses API) (.NET)

## 📋 Hướng Dẫn Xử Lý Theo Trình Tự Nâng Cao

Nhật ký này trình bày **các mẫu quy trình công việc theo trình tự** sử dụng Microsoft Agent Framework cho .NET và Azure OpenAI (Responses API). Bạn sẽ học cách xây dựng các pipeline xử lý phức tạp, từng bước một, nơi các đại lý thực thi theo một thứ tự cụ thể, mỗi giai đoạn dựa trên kết quả của giai đoạn trước.

## 🎯 Mục Tiêu Học Tập

### 🔄 **Kiến Trúc Xử Lý Theo Trình Tự**
- **Thiết Kế Quy Trình Tuyến Tính**: Tạo các pipeline xử lý từng bước với sự phụ thuộc rõ ràng
- **Quản Lý Trạng Thái**: Duy trì ngữ cảnh và luồng dữ liệu qua các giai đoạn công việc theo trình tự
- **Azure OpenAI (Responses API)**: Tận dụng mô hình Azure OpenAI trong các workflow .NET đa giai đoạn
- **Mẫu Pipeline Doanh Nghiệp**: Xây dựng các hệ thống xử lý theo trình tự sẵn sàng cho sản xuất

### 🏗️ **Các Mẫu Theo Trình Tự Nâng Cao**
- **Xử Lý Kiểm Soát Giai Đoạn**: Triển khai các điểm kiểm tra xác thực giữa các giai đoạn workflow
- **Bảo Tồn Ngữ Cảnh**: Duy trì trạng thái và kiến thức tích lũy qua tất cả các giai đoạn
- **Phân Tán Lỗi**: Xử lý thất bại một cách linh hoạt trong chuỗi xử lý theo trình tự
- **Tối Ưu Hiệu Suất**: Thực thi tuần tự hiệu quả với chi phí tối thiểu

### 🏢 **Ứng Dụng Theo Trình Tự Cho Doanh Nghiệp**
- **Pipeline Xử Lý Tài Liệu**: Phân tích, chuyển đổi và xác thực tài liệu đa giai đoạn
- **Quy Trình Đảm Bảo Chất Lượng**: Xem xét, xác thực và phê duyệt tuần tự
- **Pipeline Sản Xuất Nội Dung**: Nghiên cứu → Viết → Biên tập → Đánh giá → Xuất bản
- **Tự Động Hóa Quy Trình Kinh Doanh**: Các workflow kinh doanh đa bước với phụ thuộc giai đoạn rõ ràng

## ⚙️ Yêu Cầu & Thiết Lập

### 📦 **Gói NuGet Cần Thiết**

Các gói quan trọng cho workflow tuần tự .NET:

```xml
<!-- Core AI Framework -->
<PackageReference Include="Microsoft.Extensions.AI" Version="9.9.0" />

<!-- Azure OpenAI (Responses API) -->
<PackageReference Include="Azure.AI.OpenAI" Version="2.1.0" />

<!-- Azure Identity and Async LINQ Support -->
<PackageReference Include="Azure.Identity" Version="1.15.0" />
<PackageReference Include="System.Linq.Async" Version="6.0.3" />

<!-- Local Agent Framework References -->
<!-- Microsoft.Agents.AI.dll - Core agent abstractions -->
<!-- Microsoft.Agents.AI.OpenAI.dll - Azure OpenAI (Responses API) integration -->
```

### 🔑 **Cấu Hình Azure OpenAI**

**Thiết lập môi trường (.env file):**
```env
AZURE_OPENAI_ENDPOINT=https://<your-resource>.openai.azure.com
AZURE_OPENAI_DEPLOYMENT=gpt-4o-mini
```

**Quản lý cấu hình:**
```csharp
// Load environment variables securely
Env.Load("../../../.env");
var azureEndpoint = Environment.GetEnvironmentVariable("AZURE_OPENAI_ENDPOINT");
var deployment = Environment.GetEnvironmentVariable("AZURE_OPENAI_DEPLOYMENT");
```

### 🏗️ **Kiến Trúc Quy Trình Theo Trình Tự**

```mermaid
graph TD
    A[Initial Input] --> B[Stage 1: Tác nhân Phân tích]
    B --> C[Điểm kiểm tra 1]
    C --> D[Stage 2: Tác nhân Xử lý]
    D --> E[Điểm kiểm tra 2]
    E --> F[Stage 3: Tác nhân Xác thực]
    F --> G[Kết quả Cuối cùng]
    
    H[Ngữ cảnh Trạng thái] --> B
    H --> D
    H --> F
    
    I[Azure OpenAI (API Phản hồi)] --> B
    I --> D
    I --> F
```

**Các thành phần chính:**
- **Các Đại Lý Theo Trình Tự**: Đại lý chuyên biệt cho mỗi giai đoạn xử lý
- **Ngữ Cảnh Trạng Thái**: Duy trì dữ liệu tích lũy và các quyết định qua các giai đoạn
- **Điểm Kiểm Tra**: Các điểm xác thực giữa các giai đoạn đảm bảo chất lượng và tính nhất quán
- **Client Azure OpenAI**: Truy cập mô hình AI đồng nhất qua tất cả các giai đoạn workflow

### 📝 Đầu Ra Mong Đợi

Quy trình sẽ:
1. **Đại Lý Bán Hàng**: Xác định các món đồ nội thất trong hình ảnh và đưa ra khuyến nghị
2. **Đại Lý Giá**: Thêm phân tích giá chi tiết với các mức ngân sách và đề xuất mua sắm
3. **Đại Lý Báo Giá**: Tạo tài liệu báo giá có định dạng với tất cả thông tin tổng hợp

Đầu ra cuối cùng sẽ là một báo giá đồ nội thất chuyên nghiệp, toàn diện dựa trên phân tích hình ảnh.

### 🎯 Ứng Dụng Thực Tiễn

Mẫu theo trình tự này phù hợp cho:
- **Thương mại điện tử**: Phân tích sản phẩm → Định giá → Tạo báo giá
- **Bất động sản**: Phân tích tài sản → Định giá → Tạo danh sách
- **Bảo hiểm**: Phân tích yêu cầu → Đánh giá → Tạo báo giá
- **Tạo nội dung**: Nghiên cứu → Viết → Biên tập → Xuất bản
