## Ορισμός Πρακτόρων ΤΝ και Τύποι Πρακτόρων ΤΝ

### Τι είναι οι Πράκτορες ΤΝ;

Ακολουθεί ένας απλός τρόπος να το σκεφτείτε:

> **Οι Πράκτορες ΤΝ είναι συστήματα που επιτρέπουν στα Μεγάλα Γλωσσικά Μοντέλα (LLMs) να *κάνουν πράγματα* — δίνοντάς τους εργαλεία και γνώση για να δρουν στον κόσμο, όχι απλώς να απαντούν σε εντολές.**

Ας το αναλύσουμε λίγο:

- **Σύστημα** — Ένας Πράκτορας ΤΝ δεν είναι μόνο ένα πράγμα. Είναι ένα σύνολο μερών που λειτουργούν μαζί. Στον πυρήνα του, κάθε πράκτορας έχει τρία στοιχεία:
  - **Περιβάλλον** — Ο χώρος στον οποίο εργάζεται ο πράκτορας. Για έναν πράκτορα κρατήσεων ταξιδιών, αυτό θα ήταν η ίδια η πλατφόρμα κρατήσεων.
  - **Αισθητήρες** — Πώς ο πράκτορας διαβάζει την τρέχουσα κατάσταση του περιβάλλοντός του. Ο ταξιδιωτικός πράκτορας μπορεί να ελέγχει τη διαθεσιμότητα ξενοδοχείων ή τις τιμές πτήσεων.
  - **Εκτελεστές** — Πώς ο πράκτορας ενεργεί. Ο ταξιδιωτικός πράκτορας μπορεί να κλείσει ένα δωμάτιο, να στείλει μια επιβεβαίωση ή να ακυρώσει μια κράτηση.

![Τι Είναι οι Πράκτορες ΤΝ;](../../../translated_images/el/what-are-ai-agents.1ec8c4d548af601a.webp)

- **Μεγάλα Γλωσσικά Μοντέλα** — Οι πράκτορες υπήρχαν πριν από τα LLMs, αλλά τα LLMs είναι που κάνουν τους σύγχρονους πράκτορες τόσο ισχυρούς. Μπορούν να κατανοήσουν τη φυσική γλώσσα, να αιτιολογήσουν το πλαίσιο και να μετατρέψουν ένα ασαφές αίτημα χρήστη σε ένα συγκεκριμένο σχέδιο δράσης.

- **Εκτέλεση Δράσεων** — Χωρίς ένα σύστημα πράκτορα, ένα LLM απλώς δημιουργεί κείμενο. Μέσα σε ένα σύστημα πράκτορα, το LLM μπορεί πραγματικά να *εκτελέσει* βήματα — να αναζητήσει σε βάση δεδομένων, να καλέσει API, να στείλει μήνυμα.

- **Πρόσβαση σε Εργαλεία** — Ποια εργαλεία μπορεί να χρησιμοποιήσει ο πράκτορας εξαρτάται από (1) το περιβάλλον στο οποίο τρέχει και (2) τι επέλεξε ο προγραμματιστής να του δώσει. Ένας ταξιδιωτικός πράκτορας μπορεί να μπορεί να αναζητήσει πτήσεις αλλά όχι να επεξεργαστεί αρχεία πελατών — όλα εξαρτώνται από το τι έχεις συνδέσει.

- **Μνήμη + Γνώση** — Οι πράκτορες μπορούν να έχουν βραχυπρόθεσμη μνήμη (την τρέχουσα συνομιλία) και μακροπρόθεσμη μνήμη (μια βάση πελατών, παλαιότερες αλληλεπιδράσεις). Ο ταξιδιωτικός πράκτορας μπορεί να "θυμάται" ότι προτιμάτε καθίσματα δίπλα στο παράθυρο.

### Οι Διαφορετικοί Τύποι Πρακτόρων ΤΝ

Δεν κατασκευάζονται όλοι οι πράκτορες το ίδιο. Ακολουθεί μια ανάλυση των βασικών τύπων, χρησιμοποιώντας τον ταξιδιωτικό πράκτορα ως παράδειγμα:

| **Τύπος Πράκτορα** | **Τι Κάνει** | **Παράδειγμα Ταξιδιωτικού Πράκτορα** |
|---|---|---|
| **Απλοί Αντανακλαστικοί Πράκτορες** | Ακολουθούν κανόνες με κώδικα — χωρίς μνήμη, χωρίς σχεδιασμό. | Βλέπει ένα email παράπονο → το προωθεί στην εξυπηρέτηση πελατών. Τόσο απλά. |
| **Αντανακλαστικοί Πράκτορες με Εσωτερικό Μοντέλο** | Κρατούν ένα εσωτερικό μοντέλο του κόσμου και το ενημερώνουν καθώς τα πράγματα αλλάζουν. | Παρακολουθεί τις ιστορικές τιμές πτήσεων και σημειώνει δρομολόγια που ξαφνικά έγιναν ακριβά. |
| **Πράκτορες Με Βάση Στόχους** | Έχει έναν στόχο και βρίσκει πώς να τον πετύχει βήμα βήμα. | Κλείνει ένα ολόκληρο ταξίδι (πτήσεις, αυτοκίνητο, ξενοδοχείο) ξεκινώντας από την τρέχουσα τοποθεσία σας για να φτάσετε στον προορισμό σας. |
| **Πράκτορες Με Βάση Ωφελιμότητα** | Δεν βρίσκει μόνο *μια* λύση – βρίσκει την *καλύτερη* λύση ζυγίζοντας τις επιλογές. | Ισορροπεί κόστος και άνεση για να βρει το ταξίδι που ταιριάζει καλύτερα στις προτιμήσεις σας. |
| **Μαθησιακοί Πράκτορες** | Βελτιώνονται με τον χρόνο μαθαίνοντας από τα σχόλια. | Προσαρμόζει μελλοντικές προτάσεις κρατήσεων βάσει των αποτελεσμάτων έρευνας μετά το ταξίδι. |
| **Ιεραρχικοί Πράκτορες** | Ένας πράκτορας υψηλού επιπέδου χωρίζει την εργασία σε υποεργασίες και τις αναθέτει σε πράκτορες χαμηλότερου επιπέδου. | Η αίτηση "ακύρωση ταξιδιού" διασπάται σε: ακύρωση πτήσης, ακύρωση ξενοδοχείου, ακύρωση ενοικίασης αυτοκινήτου — κάθε μία διαχειρίζεται από υποπράκτορα. |
| **Συστήματα Πολλαπλών Πρακτόρων (MAS)** | Πολλοί ανεξάρτητοι πράκτορες που συνεργάζονται (ή ανταγωνίζονται). | Συνεργαστικό: ξεχωριστοί πράκτορες χειρίζονται ξενοδοχεία, πτήσεις και ψυχαγωγία. Ανταγωνιστικό: πολλοί πράκτορες ανταγωνίζονται να γεμίσουν δωμάτια ξενοδοχείων στην καλύτερη τιμή. |

## Πότε Να Χρησιμοποιείτε Πράκτορες ΤΝ

Το ότι *μπορείτε* να χρησιμοποιήσετε Πράκτορα ΤΝ δεν σημαίνει ότι *πάντα πρέπει*. Δείτε τις περιπτώσεις όπου οι πράκτορες λάμπουν πραγματικά:

![Πότε να χρησιμοποιείτε Πράκτορες ΤΝ;](../../../translated_images/el/when-to-use-ai-agents.54becb3bed74a479.webp)

- **Προβλήματα Χωρίς Ορισμένη Λύση** — Όταν τα βήματα για την επίλυση ενός προβλήματος δεν μπορούν να προγραμματιστούν εκ των προτέρων. Χρειάζεστε το LLM να βρει δυναμικά το μονοπάτι.
- **Διαδικασίες Με Πολλά Βήματα** — Εργασίες που απαιτούν τη χρήση εργαλείων σε πολλά βήματα, όχι μόνο μια απλή αναζήτηση ή παραγωγή.
- **Βελτίωση Με Τον Χρόνο** — Όταν θέλετε το σύστημα να γίνει πιο έξυπνο βασισμένο σε ανατροφοδότηση χρήστη ή περιβαλλοντικά σήματα.

Θα εμβαθύνουμε περισσότερο στο πότε (και πότε *όχι*) να χρησιμοποιείτε Πράκτορες ΤΝ στο μάθημα **Κατασκευή Αξιόπιστων Πρακτόρων ΤΝ** αργότερα στο μάθημα.

## Βασικά Στοιχεία Λύσεων με Πράκτορες

### Ανάπτυξη Πρακτόρων

Το πρώτο που κάνετε όταν φτιάχνετε έναν πράκτορα είναι να ορίσετε *τι μπορεί να κάνει* — τα εργαλεία, τις ενέργειες και τις συμπεριφορές του.

Σε αυτό το μάθημα, χρησιμοποιούμε την **Microsoft Foundry Agent Service** ως τη βασική πλατφόρμα μας. Υποστηρίζει:

- Μοντέλα από παρόχους όπως OpenAI, Mistral και Meta (Llama)
- Αδειοδοτημένα δεδομένα από παρόχους όπως Tripadvisor
- Τυποποιημένους ορισμούς εργαλείων OpenAPI 3.0

### Στυλ Λύσεων με Πράκτορες

Επικοινωνείτε με LLMs μέσω προτροπών. Με τους πράκτορες, δεν μπορείτε πάντα να δημιουργείτε χειροκίνητα κάθε προτροπή — ο πράκτορας πρέπει να δράσει σε πολλά βήματα. Εκεί μπαίνουν τα **Agentic Patterns**. Είναι επαναχρησιμοποιήσιμες στρατηγικές για προτροπές και έλεγχο LLMs με πιο επεκτάσιμο, αξιόπιστο τρόπο.

Αυτό το μάθημα δομείται γύρω από τα πιο κοινά και χρήσιμα agentic patterns.

### Πλαίσια Πρακτόρων

Τα Πλαίσια Πρακτόρων δίνουν στους προγραμματιστές έτοιμα πρότυπα, εργαλεία και υποδομές για τη δημιουργία πρακτόρων. Κάνουν πιο εύκολο:

- Να συνδέουν εργαλεία και δυνατότητες
- Να παρακολουθούν τι κάνει ο πράκτορας (και να διορθώνουν σφάλματα)
- Να συνεργάζονται μεταξύ πολλών πρακτόρων

Σε αυτό το μάθημα, εστιάζουμε στο **Microsoft Agent Framework (MAF)** για την κατασκευή πρακτόρων έτοιμων για παραγωγή.
