# Συμμετοχή

Αυτό το έργο καλωσορίζει τις συνεισφορές και τις προτάσεις. Οι περισσότερες συνεισφορές απαιτούν να συμφωνήσετε με μια Συμφωνία Αδειοδότησης Συνεισφέροντα (CLA) που δηλώνει ότι έχετε το δικαίωμα, και πραγματικά παραχωρείτε, τα δικαιώματα χρήσης της συνεισφοράς σας. Για λεπτομέρειες, επισκεφθείτε το <https://cla.opensource.microsoft.com>.

Όταν υποβάλετε ένα pull request, ένα bot CLA θα καθορίσει αυτόματα αν χρειάζεται να παρέχετε μια CLA και θα διακοσμήσει το pull request κατάλληλα. Ακολουθήστε τις οδηγίες που παρέχονται από το bot. Θα χρειαστεί να το κάνετε αυτό μόνο μία φορά σε αποθετήρια που χρησιμοποιούν την Microsoft CLA.

## Κώδικας Δεοντολογίας

Αυτό το έργο έχει υιοθετήσει τον [Κώδικα Δεοντολογίας Ανοιχτού Κώδικα της Microsoft](https://opensource.microsoft.com/codeofconduct/). Για περισσότερες πληροφορίες, δείτε τα [Συχνές Ερωτήσεις για τον Κώδικα Δεοντολογίας](https://opensource.microsoft.com/codeofconduct/faq/) ή επικοινωνήστε με το [opencode@microsoft.com](mailto:opencode@microsoft.com) για επιπλέον ερωτήσεις ή σχόλια.

## Οδηγίες για τα pull request

- Κρατήστε κάθε pull request εστιασμένο σε μια λογική αλλαγή.
- Δοκιμάστε τα επηρεαζόμενα τετράδια και τα δείγματα κώδικα πριν την υποβολή.
- Ενημερώστε την αντίστοιχη τεκμηρίωση του μαθήματος όταν προσθέτετε ή αλλάζετε ένα παράδειγμα.
- Επεξεργαστείτε μόνο το αρχικό αγγλικό περιεχόμενο. Οι μεταφράσεις διατηρούνται από τη ροή εργασίας αυτόματης μετάφρασης.
- Μην δεσμεύετε στοιχεία πρόσβασης, αρχεία `.env`, προσωρινά αρχεία ή παραγόμενα αναπτυξιακά αρχεία.

## Επεξεργαστικό πεδίο και προϊόντα τρίτων

Αυτή η ύλη επικεντρώνεται σε τεχνολογίες της Microsoft και ουδέτερα πρότυπα ανοικτού κώδικα. Οι συνεισφορές πρέπει να εξυπηρετούν έναν σαφή εκπαιδευτικό σκοπό και δεν πρέπει να προορίζονται κυρίως για την εισαγωγή ή προώθηση ενός εμπορικού προϊόντος τρίτου μέρους, φιλοξενούμενης υπηρεσίας, μοντέλου δρομολογητή, SDK, MCP server ή άλλης προσφοράς συγκεκριμένης εταιρείας.

Το λογισμικό ανοικτού κώδικα και οι εξαρτήσεις τρίτων μπορεί να αναφέρονται όταν είναι απαραίτητα για την εξήγηση ενός ανοικτού προτύπου ή σεναρίου διαλειτουργικότητας, παρουσιάζονται ουδέτερα και δεν είναι εστιασμένα σε προϊόν ή φιλοξενούμενο σημείο ενός προμηθευτή. Εάν η προτεινόμενη συνεισφορά σας περιλαμβάνει προϊόν ή υπηρεσία συγκεκριμένου προμηθευτή, ανοίξτε ένα θέμα και λάβετε έγκριση από τους διαχειριστές προτού υποβάλετε ένα pull request.

Οι συνεισφέροντες οφείλουν να αποκαλύπτουν οποιαδήποτε σχετική απασχόληση, ιδιοκτησία, χορηγία ή άλλη συνεργασία με προϊόν ή υπηρεσία που αναφέρεται στη συνεισφορά τους. Μην συμπεριλαμβάνετε μη υποστηριζόμενες ισχυρισμούς για τιμολόγηση, απόδοση, ασφάλεια, ιδιωτικότητα ή συγκριτικές αξιολογήσεις. Τα εκτελέσιμα παραδείγματα δεν πρέπει να μεταδίδουν δεδομένα μαθητών ή να εκτελούν δημόσιες ενέργειες μέσω εξωτερικής υπηρεσίας τρίτου μέρους από προεπιλογή.
