# Υποδείγματα Αποδείξεων

Τρία προ-δημιουργημένα αρχεία αποδείξεων για επιθεώρηση χωρίς να εκτελεστεί το σημειωματάριο.

| Αρχείο | Τι είναι |
|---|---|
| `01_valid_receipt.json` | Μια έγκυρη υπογεγραμμένη απόδειξη για κλήση εργαλείου `lookup_flights`. Η επαλήθευση επιστρέφει True. |
| `02_tampered_receipt.json` | Η ίδια απόδειξη με ένα πεδίο τροποποιημένο μετά την υπογραφή. Η επαλήθευση επιστρέφει False. |
| `03_chain_three_receipts.json` | Μια αλυσίδα τριών έγκυρων αποδείξεων (αναζήτηση, κράτηση, έκδοση) με `previous_receipt_hash` που συνδέει κάθε μία με την προηγούμενη. |

Τα υποδείγματα υπογράφουν απευθείας τα κανονικοποιημένα bytes του φορτίου (JCS) με Ed25519.
Το SHA-256 παραμένει σε χρήση για τα περάσματα ελέγχου περιεχομένου και τους συνδέσμους της αλυσίδας αποδείξεων, όχι ως
επιπλέον προ-κατακερματισμός πριν την υπογραφή.

## Επαλήθευση των υποδειγμάτων

Το σημειωματάριο περνάει την επαλήθευση σε τέσσερις ενότητες. Για να επαληθεύσετε απευθείας αυτά τα υποδείγματα
χωρίς να τρέξετε την αφήγηση του σημειωματαρίου:

```python
import json
from pathlib import Path

# Υποθέτει ότι έχετε ολοκληρώσει τις εισαγωγές και τις βοηθητικές συναρτήσεις
# από τα τμήματα 1 και 2 του 18-signed-receipts.ipynb.

valid = json.loads(Path("01_valid_receipt.json").read_text())
print(f"Valid receipt: {verify_receipt(valid)}")        # Σωστό

tampered = json.loads(Path("02_tampered_receipt.json").read_text())
print(f"Tampered receipt: {verify_receipt(tampered)}")  # Λάθος

chain = json.loads(Path("03_chain_three_receipts.json").read_text())
for r in verify_chain(chain):
    print(f"  Receipt {r['index']} ({r['tool']}): {'VALID' if r['overall_valid'] else 'INVALID'}")
```

## Πώς δημιουργήθηκαν αυτά

Τα υποδείγματα χρησιμοποιούν την ίδια διαδρομή κώδικα με το σημειωματάριο, με ένα σταθερό κλειδί υπογραφής
και σταθερές χρονικές σημάνσεις για επαναπαραγωγιμότητα σε επίπεδο bytes. Για να τα ξαναδημιουργήσετε:

```bash
python3 generate_fixtures.py
```

(Το σενάριο βρίσκεται στο `generate_fixtures.py` σε αυτόν τον κατάλογο.)

## Τι μαθαίνουν οι φοιτητές από την επιθεώρηση του καθαρού JSON

Η ανάγνωση της ακατέργαστης μορφής της απόδειξης χτίζει μια διαίσθηση που οι κελιά του σημειωματαρίου
δεν παρέχουν πάντα. Οι φοιτητές που περιηγούνται στο JSON συνήθως παρατηρούν:

1. Η υπογραφή είναι μια αδιαφανής συμβολοσειρά base64url, αλλά κάθε άλλο πεδίο είναι απλό
   αναγνώσιμο JSON. Η υπογραφή δεν κρυπτογραφεί το περιεχόμενο· μόνο το πιστοποιεί.
2. Το `public_key` είναι ενσωματωμένο στην απόδειξη. Ένας ελεγκτής δεν χρειάζεται τίποτα άλλο
   για να επαληθεύσει (υπό την προϋπόθεση εμπιστοσύνης ότι το κλειδί ανήκει όντως στον δηλωθέντα
   εκδότη· δείτε το README της ενότητας για την υποδομή ταυτότητας).
3. Η τροποποίηση ενός μόνο χαρακτήρα οποιουδήποτε πεδίου και η σύγκριση αυτού του αρχείου με
   το `02_tampered_receipt.json`, καθιστά συγκεκριμένο τον μηχανισμό σε επίπεδο bytes.
