# ⏩ Ακολουθιακές Ροές Εργασίας Πρακτόρων με Azure OpenAI (Responses API) (.NET)

## 📋 Εκπαιδευτικό Εργαστήριο Προηγμένης Ακολουθιακής Επεξεργασίας

Αυτό το σημειωματάριο παρουσιάζει **πρότυπα ακολουθιακών ροών εργασίας** χρησιμοποιώντας το Microsoft Agent Framework για .NET και το Azure OpenAI (Responses API). Θα μάθετε πώς να δημιουργείτε εξελιγμένους, βήμα προς βήμα αγωγούς επεξεργασίας όπου οι πράκτορες εκτελούνται με συγκεκριμένη σειρά, με κάθε στάδιο να βασίζεται στα αποτελέσματα του προηγούμενου σταδίου.

## 🎯 Στόχοι Μάθησης

### 🔄 **Αρχιτεκτονική Ακολουθιακής Επεξεργασίας**
- **Γραμμικός Σχεδιασμός Ροής Εργασίας**: Δημιουργία βηματοδοτούμενων αγωγών επεξεργασίας με σαφείς εξαρτήσεις
- **Διαχείριση Καταστάσεων**: Διατήρηση συμφραζομένων και ροής δεδομένων σε ακολουθιακά στάδια ροής εργασίας
- **Azure OpenAI (Responses API)**: Χρήση μοντέλων Azure OpenAI σε πολυ-σταδιακές ροές εργασίας .NET
- **Πρότυπα Επιχειρησιακών Αγωγών**: Δημιουργία έτοιμων για παραγωγή ακολουθιακών συστημάτων επεξεργασίας

### 🏗️ **Προηγμένα Ακολουθιακά Πρότυπα**
- **Επεξεργασία Με Στάδια Ελέγχου**: Υλοποίηση σημείων επικύρωσης μεταξύ σταδίων ροής εργασίας
- **Διατήρηση Συμφραζομένων**: Διατήρηση κατάστασης και συσσωρευμένης γνώσης σε όλα τα στάδια
- **Διάδοση Σφαλμάτων**: Αντιμετώπιση αποτυχιών με ομαλό τρόπο σε ακολουθιακές αλυσίδες επεξεργασίας
- **Βελτιστοποίηση Απόδοσης**: Αποδοτική ακολουθιακή εκτέλεση με ελάχιστο φόρτο

### 🏢 **Επιχειρησιακές Ακολουθιακές Εφαρμογές**
- **Αγωγός Επεξεργασίας Εγγράφων**: Πολυ-σταδιακή ανάλυση, μετασχηματισμός και επικύρωση εγγράφων
- **Ροές Εργασίας Διασφάλισης Ποιότητας**: Ακολουθιακός έλεγχος, επικύρωση και διαδικασίες έγκρισης
- **Αγωγός Παραγωγής Περιεχομένου**: Έρευνα → Συγγραφή → Επιμέλεια → Ανασκόπηση → Δημοσίευση
- **Αυτοματοποίηση Επιχειρησιακών Διαδικασιών**: Πολυ-βηματικές επιχειρησιακές ροές με σαφείς εξαρτήσεις σταδίων

## ⚙️ Προαπαιτούμενα & Ρύθμιση

### 📦 **Απαιτούμενα Πακέτα NuGet**

Απαραίτητα πακέτα για ακολουθιακές ροές εργασίας .NET:

```xml
<!-- Core AI Framework -->
<PackageReference Include="Microsoft.Extensions.AI" Version="9.9.0" />

<!-- Azure OpenAI (Responses API) -->
<PackageReference Include="Azure.AI.OpenAI" Version="2.1.0" />

<!-- Azure Identity and Async LINQ Support -->
<PackageReference Include="Azure.Identity" Version="1.15.0" />
<PackageReference Include="System.Linq.Async" Version="6.0.3" />

<!-- Local Agent Framework References -->
<!-- Microsoft.Agents.AI.dll - Core agent abstractions -->
<!-- Microsoft.Agents.AI.OpenAI.dll - Azure OpenAI (Responses API) integration -->
```

### 🔑 **Διαμόρφωση Azure OpenAI**

**Ρύθμιση Περιβάλλοντος (.env αρχείο):**
```env
AZURE_OPENAI_ENDPOINT=https://<your-resource>.openai.azure.com
AZURE_OPENAI_DEPLOYMENT=gpt-4o-mini
```

**Διαχείριση Διαμόρφωσης:**
```csharp
// Load environment variables securely
Env.Load("../../../.env");
var azureEndpoint = Environment.GetEnvironmentVariable("AZURE_OPENAI_ENDPOINT");
var deployment = Environment.GetEnvironmentVariable("AZURE_OPENAI_DEPLOYMENT");
```

- **Πελάτης Azure OpenAI**: Σταθερή πρόσβαση σε μοντέλα τεχνητής νοημοσύνης σε όλα τα στάδια της ροής εργασίας

## 💻 Εκτέλεση Κώδικα

Η ολοκληρωμένη υλοποίηση είναι διαθέσιμη στο `02.dotnet-agent-framework-workflow-ghmodel-sequential.cs`. Αυτό το αρχείο παρουσιάζει μια **τριών σταδίων ροή ανάλυσης επίπλων**:

1. **Στάδιο 1 - Πράκτορας Πωλήσεων**: Αναλύει εικόνες επίπλων και παρέχει προτάσεις αγοράς
2. **Στάδιο 2 - Πράκτορας Τιμών**: Παρέχει αναλυτικά διαγράμματα τιμολόγησης και επιλογές προϋπολογισμού
3. **Στάδιο 3 - Πράκτορας Προσφοράς**: Δημιουργεί επαγγελματικό έγγραφο προσφοράς σε μορφή Markdown

### 🏗️ **Αρχιτεκτονική Ροής Εργασίας**

```
Image Input → Sales Analysis → Price Estimation → Quote Generation → Final Output
```

Κάθε πράκτορας:
- Λαμβάνει την έξοδο του προηγούμενου σταδίου ως συμφραζόμενο
- Βασίζεται στην προηγούμενη ανάλυση με εξειδικευμένη τεχνογνωσία
- Διατηρεί τη συνέχεια της ροής εργασίας μέσω διαχείρισης κατάστασης


Ή στα Windows:
```powershell
dotnet run 02.dotnet-agent-framework-workflow-ghmodel-sequential.cs
```

### 📝 Αναμενόμενη Έξοδος

Η ροή εργασίας θα:
1. **Πράκτορας Πωλήσεων**: Αναγνωρίσει είδη επίπλων από την εικόνα και παρέχει συστάσεις
2. **Πράκτορας Τιμών**: Προσθέσει αναλυτική ανάλυση τιμολόγησης με επίπεδα προϋπολογισμού και συστάσεις αγοράς
3. **Πράκτορας Προσφοράς**: Δημιουργήσει μορφοποιημένο έγγραφο προσφοράς με συνθετικές πληροφορίες

Το τελικό αποτέλεσμα θα είναι μια ολοκληρωμένη, επαγγελματική προσφορά επίπλων βάσει ανάλυσης εικόνας.

### 🔍 Κατανόηση Ροής Κατάστασης

Κάθε πράκτορας στη σειρά λαμβάνει:
- **Αρχική Είσοδο**: Το αρχικό μήνυμα χρήστη (εικόνα + κείμενο)
- **Έξοδοι Προηγούμενων Πρακτόρων**: Όλες οι προηγούμενες απαντήσεις πρακτόρων στο ιστορικό συνομιλίας
