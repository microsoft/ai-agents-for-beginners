# 🔄 Βασικές Ροές Εργασίας Πρακτόρων με Azure OpenAI (Responses API) (.NET)

## 📋 Εκμάθηση Ορχήστρωσης Ροής Εργασίας

Αυτό το σημειωματάριο παρουσιάζει πώς να δημιουργήσετε εξελιγμένες **ροές εργασίας πρακτόρων** χρησιμοποιώντας το Microsoft Agent Framework για .NET και Azure OpenAI (Responses API). Θα μάθετε να φτιάχνετε επιχειρηματικές διαδικασίες πολλών βημάτων όπου οι πράκτορες AI συνεργάζονται για να ολοκληρώσουν πολύπλοκα καθήκοντα μέσω δομημένων προτύπων ορχήστρωσης.

## 🎯 Στόχοι Μάθησης

### 🏗️ **Βασικά της Αρχιτεκτονικής Ροής Εργασίας**
- **Κατασκευαστής Ροής Εργασίας**: Σχεδίαση και ορχήστρωση πολύπλοκων διαδικασιών AI πολλαπλών βημάτων
- **Συντονισμός Πρακτόρων**: Συντονισμός πολλών εξειδικευμένων πρακτόρων μέσα σε ροές εργασίας
- **Azure OpenAI (Responses API)**: Αξιοποίηση του Azure OpenAI Responses API στις ροές εργασίας
- **Οπτικός Σχεδιασμός Ροής Εργασίας**: Δημιουργία και απεικόνιση δομών ροής εργασίας για καλύτερη κατανόηση

### 🔄 **Πρότυπα Ορχήστρωσης Διαδικασιών**
- **Ακολουθιακή Επεξεργασία**: Αλυσιδωτή εκτέλεση πολλαπλών εργασιών πράκτορα με λογική σειρά
- **Διαχείριση Κατάστασης**: Διατήρηση συμφραζομένων και ροής δεδομένων μεταξύ των σταδίων της ροής εργασίας
- **Διαχείριση Σφαλμάτων**: Εφαρμογή ανθεκτικής αποκατάστασης σφαλμάτων και ανθεκτικότητας ροής εργασίας
- **Βελτιστοποίηση Απόδοσης**: Σχεδιασμός αποδοτικών ροών εργασίας για λειτουργίες σε επίπεδο επιχείρησης

### 🏢 **Εφαρμογές Ροής Εργασίας σε Επιχειρήσεις**
- **Αυτοματοποίηση Επιχειρηματικών Διαδικασιών**: Αυτοματοποίηση πολύπλοκων οργανωτικών ροών εργασίας
- **Γραμμή Παραγωγής Περιεχομένου**: Συντακτικές ροές εργασίας με στάδια αναθεώρησης και έγκρισης
- **Αυτοματοποίηση Εξυπηρέτησης Πελατών**: Επίλυση ερωτήσεων πελατών πολλαπλών βημάτων
- **Ροές Επεξεργασίας Δεδομένων**: ETL ροές εργασίας με μετασχηματισμούς με τεχνητή νοημοσύνη

## ⚙️ Προαπαιτούμενα & Ρύθμιση

### 📦 **Απαραίτητα Πακέτα NuGet**

Η επίδειξη αυτής της ροής εργασίας χρησιμοποιεί αρκετά βασικά πακέτα .NET:

```xml
<!-- Core AI Framework -->
<PackageReference Include="Microsoft.Extensions.AI" Version="10.*" />

<!-- Azure OpenAI (Responses API) -->
<PackageReference Include="Azure.AI.OpenAI" Version="2.1.0" />
<PackageReference Include="Azure.Identity" Version="1.15.0" />

<!-- Agent Framework (Local Development) -->
<!-- Microsoft.Agents.AI.dll - Core agent abstractions -->
<!-- Microsoft.Agents.AI.OpenAI.dll - Azure OpenAI (Responses API) integration -->

<!-- Configuration and Environment -->
<PackageReference Include="DotNetEnv" Version="3.1.1" />
```

### 🔑 **Διαμόρφωση Azure OpenAI**

**Ρύθμιση Περιβάλλοντος (.env αρχείο):**
```env
AZURE_OPENAI_ENDPOINT=https://<your-resource>.openai.azure.com
AZURE_OPENAI_DEPLOYMENT=gpt-5-mini
```

**Πρόσβαση Azure OpenAI:**
1. Δημιουργήστε έναν πόρο Azure OpenAI στο Azure portal
2. Αναπτύξτε ένα μοντέλο (π.χ., `gpt-5-mini`) και σημειώστε το όνομα ανάπτυξης
3. Συνδεθείτε με `az login` και διαμορφώστε τις μεταβλητές περιβάλλοντος όπως φαίνεται παραπάνω

### 🏗️ **Επισκόπηση Αρχιτεκτονικής Ροής Εργασίας**

```mermaid
graph TD
    A[Δημιουργός Ροής Εργασίας] --> B[Μητρώο Πρακτόρων]
    B --> C[Μηχανή Εκτέλεσης Ροής Εργασίας]
    C --> D[Agent 1: Δημιουργός Περιεχομένου]
    C --> E[Agent 2: Ελεγκτής Περιεχομένου] 
    D --> F[Αποτελέσματα Ροής Εργασίας]
    E --> F
    G[Azure OpenAI (API Απαντήσεων)] --> D
    G --> E
```

**Κύρια Συστατικά:**
- **WorkflowBuilder**: Κύριος μηχανισμός ορχήστρωσης για το σχεδιασμό ροών εργασίας
- **AIAgent**: Ατομικοί εξειδικευμένοι πράκτορες με συγκεκριμένες ικανότητες
- **Πελάτης Azure OpenAI**: Ενσωμάτωση Azure OpenAI Responses API
- **Execution Context**: Διαχειρίζεται κατάσταση και ροή δεδομένων μεταξύ σταδίων ροής εργασίας

## 💻 Εκτέλεση Κώδικα

Η πλήρης υλοποίηση είναι διαθέσιμη στο `01.dotnet-agent-framework-workflow-ghmodel-basic.cs`. Αυτό το αρχείο παρουσιάζει:

1. **Διαμόρφωση Περιβάλλοντος** - Φόρτωση διαμόρφωσης Azure OpenAI από αρχείο `.env`
2. **Ρύθμιση Πελάτη Azure OpenAI** - Διαμόρφωση πελάτη για χρήση του Azure OpenAI Responses API
3. **Δημιουργία Πρακτόρα** - Ορισμός εξειδικευμένων πρακτόρων (Reception και Concierge)
4. **Κατασκευαστής Ροής Εργασίας** - Δημιουργία ροής εργασίας πολλαπλών πρακτόρων με ακολουθιακή επεξεργασία
5. **Εκτέλεση Ροής Εργασίας** - Εκτέλεση ροής εργασίας με ροή αποτελεσμάτων

### 🚀 Εκτέλεση Παραδείγματος

```bash
# Κάντε το σενάριο εκτελέσιμο (Unix/Linux/macOS)
chmod +x 01.dotnet-agent-framework-workflow-ghmodel-basic.cs

# Εκτελέστε τη ροή εργασίας
./01.dotnet-agent-framework-workflow-ghmodel-basic.cs
```

Ή σε Windows:
```powershell
dotnet run 01.dotnet-agent-framework-workflow-ghmodel-basic.cs
```

### 📝 Αναμενόμενο Αποτέλεσμα

Η ροή εργασίας θα:
1. Αποδεχτεί το αίτημα προορισμού ταξιδιού σας ("Θα ήθελα να πάω στο Παρίσι")
2. Ο πράκτορας Front Desk παρέχει μια αρχική σύσταση
3. Ο πράκτορας Concierge εξετάζει και βελτιώνει τη σύσταση
4. Το τελικό αποτέλεσμα εμφανίζει τη συνολική ροή συζήτησης

### 🔧 Προσαρμογή

Μπορείτε να προσαρμόσετε τη ροή εργασίας με:
- Τροποποίηση οδηγιών πρακτόρων για αλλαγή της συμπεριφοράς τους
- Προσθήκη περισσότερων πρακτόρων για δημιουργία σύνθετων πολυβηματικών ροών εργασίας
- Αλλαγή του μηνύματος χρήστη για δοκιμή διαφορετικών σεναρίων
- Ρύθμιση των ακμών της ροής εργασίας για δημιουργία διαφορετικών προτύπων εκτέλεσης
