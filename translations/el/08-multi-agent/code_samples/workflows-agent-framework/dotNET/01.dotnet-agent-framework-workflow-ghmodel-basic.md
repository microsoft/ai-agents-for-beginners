# 🔄 Βασικές Ροές Εργασίας Πρακτόρων με Azure OpenAI (Responses API) (.NET)

## 📋 Εισαγωγή στον Συντονισμό Ροών Εργασίας

Αυτό το σημειωματάριο δείχνει πώς να δημιουργήσετε προηγμένες **ροές εργασίας πρακτόρων** χρησιμοποιώντας το Microsoft Agent Framework για .NET και το Azure OpenAI (Responses API). Θα μάθετε να δημιουργείτε πολύ-βηματικές επιχειρησιακές διαδικασίες όπου προγραμματισμένοι πράκτορες συνεργάζονται για να ολοκληρώσουν πολύπλοκα καθήκοντα μέσω δομημένων προτύπων ορχήστρωσης.

## 🎯 Στόχοι Μάθησης

### 🏗️ **Βασικά της Αρχιτεκτονικής Ροής Εργασίας**
- **Workflow Builder**: Σχεδιασμός και ορχήστρωση πολύπλοκων πολύ-βηματικών διαδικασιών AI
- **Συντονισμός Πρακτόρων**: Συντονισμός πολλών εξειδικευμένων πρακτόρων εντός ροών εργασίας
- **Azure OpenAI (Responses API)**: Εκμετάλλευση του Azure OpenAI Responses API στις ροές εργασίας
- **Οπτικός Σχεδιασμός Ροής Εργασίας**: Δημιουργία και απεικόνιση δομών ροής εργασίας για καλύτερη κατανόηση

### 🔄 **Πρότυπα Ορχήστρωσης Διαδικασιών**
- **Ακολουθιακή Επεξεργασία**: Αλληλουχία πολλών εργασιών πρακτόρων με λογική σειρά
- **Διαχείριση Κατάστασης**: Διατήρηση συμφραζομένων και ροής δεδομένων σε όλα τα στάδια της ροής εργασίας
- **Διαχείριση Σφαλμάτων**: Υλοποίηση ανθεκτικής αποκατάστασης σφαλμάτων και ανθεκτικότητας ροής εργασίας
- **Βελτιστοποίηση Απόδοσης**: Σχεδίαση αποδοτικών ροών εργασίας για επιχειρησιακή κλίμακα

### 🏢 **Εφαρμογές Ροών Εργασίας Επιχειρήσεων**
- **Αυτοματοποίηση Επιχειρησιακών Διαδικασιών**: Αυτοματοποίηση πολύπλοκων οργανωτικών ροών εργασίας
- **Διαδικασία Παραγωγής Περιεχομένου**: Επεξεργαστικές ροές εργασίας με στάδια αναθεώρησης και έγκρισης
- **Αυτοματοποίηση Εξυπηρέτησης Πελατών**: Πολύ-βηματη επίλυση ερωτημάτων πελατών
- **Ροές Επεξεργασίας Δεδομένων**: ETL ροές εργασίας με μετασχηματισμό με υποστήριξη AI

## ⚙️ Προαπαιτούμενα & Ρύθμιση

### 📦 **Απαιτούμενα Πακέτα NuGet**

Αυτή η επίδειξη ροής εργασίας χρησιμοποιεί αρκετά βασικά πακέτα .NET:

```xml
<!-- Core AI Framework -->
<PackageReference Include="Microsoft.Extensions.AI" Version="9.9.0" />

<!-- Azure OpenAI (Responses API) -->
<PackageReference Include="Azure.AI.OpenAI" Version="2.1.0" />
<PackageReference Include="Azure.Identity" Version="1.13.1" />

<!-- Agent Framework (Local Development) -->
<!-- Microsoft.Agents.AI.dll - Core agent abstractions -->
<!-- Microsoft.Agents.AI.OpenAI.dll - Azure OpenAI (Responses API) integration -->

<!-- Configuration and Environment -->
<PackageReference Include="DotNetEnv" Version="3.1.1" />
```

### 🔑 **Διαμόρφωση Azure OpenAI**

**Ρύθμιση περιβάλλοντος (.env αρχείο):**  
```env
AZURE_OPENAI_ENDPOINT=https://<your-resource>.openai.azure.com
AZURE_OPENAI_DEPLOYMENT=gpt-4o-mini
```
  
**Πρόσβαση στο Azure OpenAI:**  
1. Δημιουργήστε έναν πόρο Azure OpenAI στο Azure portal  
2. Αναπτύξτε ένα μοντέλο (για παράδειγμα, `gpt-4o-mini`) και σημειώστε το όνομα ανάπτυξης  
3. Συνδεθείτε με `az login` και ρυθμίστε τις μεταβλητές περιβάλλοντος όπως φαίνεται παραπάνω


**Κύρια Συστατικά:**  
- **WorkflowBuilder**: Κύρια μηχανή ορχήστρωσης για σχεδιασμό ροών εργασίας  
- **AIAgent**: Μεμονωμένοι εξειδικευμένοι πράκτορες με συγκεκριμένες δυνατότητες  
- **Azure OpenAI Client**: Ενσωμάτωση Azure OpenAI Responses API  
- **Execution Context**: Διαχείριση κατάστασης και ροής δεδομένων μεταξύ σταδίων ροής εργασίας

## 💻 Εκτέλεση Κώδικα

Η πλήρης υλοποίηση είναι διαθέσιμη στο αρχείο `01.dotnet-agent-framework-workflow-ghmodel-basic.cs`. Αυτό το αρχείο δείχνει:

1. **Διαμόρφωση Περιβάλλοντος** - Φόρτωση ρυθμίσεων Azure OpenAI από `.env` αρχείο  
2. **Διαμόρφωση Azure OpenAI Client** - Παραμετροποίηση του client για χρήση του Azure OpenAI Responses API  
3. **Δημιουργία Πρακτόρων** - Ορισμός εξειδικευμένων πρακτόρων (Front Desk και Concierge)  
4. **Workflow Builder** - Δημιουργία ροής εργασίας με πολλούς πράκτορες και αλληλουχική επεξεργασία  
5. **Εκτέλεση Ροής Εργασίας** - Εκτέλεση ροής εργασίας με ροή αποτελεσμάτων σε streaming

### 🚀 Εκτέλεση Παραδείγματος

```bash
# Κάντε το σενάριο εκτελέσιμο (Unix/Linux/macOS)
chmod +x 01.dotnet-agent-framework-workflow-ghmodel-basic.cs

# Εκτελέστε τη ροή εργασίας
./01.dotnet-agent-framework-workflow-ghmodel-basic.cs
```
  
Ή στα Windows:  
```powershell
dotnet run 01.dotnet-agent-framework-workflow-ghmodel-basic.cs
```
  
### 📝 Αναμενόμενη Έξοδος

Η ροή εργασίας θα:  
1. Αποδεχτεί το αίτημα προορισμού ταξιδιού σας ("Θα ήθελα να πάω στο Παρίσι")
