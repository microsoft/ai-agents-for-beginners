# ⚡ Συγχρονισμένα Ροές Εργασίας Πρακτόρων με Azure OpenAI (Responses API) (.NET)

## 📋 Εκπαιδευτικό Σεμινάριο Υψηλής Απόδοσης Παράλληλης Επεξεργασίας

Αυτό το σημειωματάριο παρουσιάζει **μοτίβα συγχρονισμένων ροών εργασίας** χρησιμοποιώντας το Microsoft Agent Framework για .NET και το Azure OpenAI (Responses API). Θα μάθετε πώς να δημιουργείτε ροές εργασίας υψηλής απόδοσης και παράλληλης επεξεργασίας που μεγιστοποιούν την απόδοση εκτελώντας πολλούς πράκτορες AI ταυτόχρονα, ενώ παράλληλα διατηρούνται ο συντονισμός και η συνοχή των δεδομένων.

### 🚀 **Βασικές Αρχές Παράλληλης Επεξεργασίας**

## 💻 Εκτέλεση του Κώδικα

Η πλήρης υλοποίηση είναι διαθέσιμη στο αρχείο `03.dotnet-agent-framework-workflow-ghmodel-concurrent.cs`. Αυτό το αρχείο παρουσιάζει μια **ροή εργασίας Fan-Out/Fan-In** για προγραμματισμό ταξιδιού:

### 🏗️ **Αρχιτεκτονική Ροής Εργασίας**

```
User Request → ConcurrentStartExecutor → [Researcher Agent || Planner Agent] → ConcurrentAggregationExecutor → Final Output
```

**Κύρια Συστατικά:**

1. **ConcurrentStartExecutor**: Μεταδίδει το αίτημα χρήστη σε όλους τους πράκτορες ταυτόχρονα
2. **Researcher Agent**: Αναλύει προορισμούς και αξιοθέατα παράλληλα
3. **Planner Agent**: Δημιουργεί λεπτομερή ταξιδιωτικά σχέδια παράλληλα
4. **ConcurrentAggregationExecutor**: Συλλέγει και συγχωνεύει τα αποτελέσματα από τους δύο πράκτορες

### 🎯 **Μοτίβο Fan-Out/Fan-In**

Αυτή η ροή εργασίας παρουσιάζει το κλασικό μοτίβο **Fan-Out/Fan-In**:
- **Fan-Out**: Ένα εισερχόμενο μήνυμα μεταδίδεται ταυτόχρονα σε πολλούς πράκτορες
- **Παράλληλη Επεξεργασία**: Πολλοί πράκτορες εργάζονται παράλληλα στην ίδια εργασία
- **Fan-In**: Τα αποτελέσματα από όλους τους πράκτορες συλλέγονται και συγχωνεύονται σε μία ενιαία έξοδο

### 🔍 Κατανόηση Προσαρμοσμένων Εκτελεστών

**ConcurrentStartExecutor:**
- Εφαρμόζει το `IMessageHandler<string>` για αποδοχή συμβολοσειράς εισόδου
- Μεταδίδει μηνύματα σε όλους τους συνδεδεμένους πράκτορες
- Στέλνει `TurnToken` για να ενεργοποιήσει την παράλληλη επεξεργασία

**ConcurrentAggregationExecutor:**
- Εφαρμόζει το `IMessageHandler<ChatMessage>` για λήψη απαντήσεων πρακτόρων
- Συλλέγει μηνύματα με τη μέθοδο thread-safe
- Συγκεντρώνει αποτελέσματα όταν φτάσουν όλοι οι αναμενόμενοι απαντητές
- Παράγει την τελική έξοδο χρησιμοποιώντας `context.YieldOutputAsync()`

### ⚡ Οφέλη Απόδοσης

**Παράλληλη έναντι Διαδοχικής Εκτέλεσης:**
- Διαδοχική: Agent1 (30s) → Agent2 (30s) = **60 δευτερόλεπτα συνολικά**
- Παράλληλη: Agent1 (30s) || Agent2 (30s) = **30 δευτερόλεπτα συνολικά**

**Βελτίωση Ρυθμού Εκτέλεσης**: Μέχρι N φορές ταχύτερα για N παράλληλους πράκτορες (ανάλογα με το φορτίο και τους πόρους)
