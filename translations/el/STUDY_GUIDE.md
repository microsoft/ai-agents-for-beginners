# Πράκτορες Τεχνητής Νοημοσύνης για Αρχάριους - Οδηγός Μελέτης

Χρησιμοποιήστε αυτόν τον οδηγό ως πρακτικό συνοδοιπόρο ενώ προχωράτε στο μάθημα. Δεν
προορίζεται να αντικαταστήσει τα μαθήματα. Σας βοηθά να αποφασίσετε από πού να
ξεκινήσετε, τι να προσέξετε σε κάθε μάθημα και πώς να συνδέσετε τις ιδέες σε μια μικρή
δυναμική επίδειξη πράκτορα.

Αν είστε εδώ για πρώτη φορά, ξεκινήστε απλά:

1. Διαβάστε το [Course Setup](./00-course-setup/README.md).
2. Ολοκληρώστε τα Μαθήματα 01-06 με τη σειρά.
3. Κρατήστε μια μικρή ιδέα επίδειξης στο μυαλό σας καθώς μαθαίνετε.
4. Μετά από κάθε μάθημα, ρωτήστε: "Τι μπορεί τώρα ο πράκτοράς μου που πριν δεν μπορούσε;"

## Μια Απλή Επίδειξη για να Έχετε Υπόψη

Ένας καλός τρόπος να μάθετε για τους πράκτορες είναι να ακολουθήσετε μια ιδέα επίδειξης
σε όλο το μάθημα.

Παράδειγμα επίδειξης: **ένας βοηθός πράκτορας για το μάθημα**.

Ο χρήστης ρωτά:

> "Θέλω να μάθω πώς οι πράκτορες χρησιμοποιούν εργαλεία. Βρες τα κατάλληλα μαθήματα,
> σύνοψη του τι πρέπει να διαβάσω πρώτα, και δώσε μου ένα σύντομο πρακτικό έργο."

Ένας κανονικός chatbot μπορεί να απαντήσει από ό,τι ήδη ξέρει. Ένας πράκτορας μπορεί να κάνει περισσότερο:

1. **Διαβάζει ή ψάχνει αρχεία μαθήματος** για να βρει τα κατάλληλα μαθήματα.
2. **Χρησιμοποιεί εργαλεία** για να ανακτήσει συνδέσμους μαθημάτων, παραδείγματα ή υποστηρικτικό υλικό.
3. **Σχεδιάζει** μια σύντομη διαδρομή μάθησης αντί να δώσει μια μακροσκελή απάντηση.
4. **Χρησιμοποιεί το πλαίσιο** από την τρέχουσα συνομιλία για να παραμείνει εστιασμένος στον στόχο του μαθητή.
5. **Θυμάται χρήσιμες προτιμήσεις** αν η εφαρμογή υποστηρίζει μνήμη.
6. **Εμφανίζει ίχνη, παραπομπές ή αρχεία καταγραφής** ώστε ο χρήστης να καταλάβει τι συνέβη.
7. **Εφαρμόζει προφυλάξεις** πριν αναλάβει ρίσκα ή χρησιμοποιήσει ευαίσθητα δεδομένα.

Καθώς μελετάτε κάθε μάθημα, επιστρέψτε σε αυτήν την επίδειξη και ρωτήστε: ποια νέα δυνατότητα
θα πρόσθετε το μάθημα αυτό;

## Σε Τι Οδηγείτε

Στο τέλος του μαθήματος, θα πρέπει να μπορείτε να εξηγείτε και να κατασκευάζετε συστήματα
πρακτόρων που συνδυάζουν αυτά τα μέρη:

| Μέρος | Σημασία σε απλή γλώσσα | Στην επίδειξη |
|-------|------------------------|---------------|
| Μοντέλο | Η μηχανή λογικής που ερμηνεύει το αίτημα του χρήστη | Καταλαβαίνει ότι ο μαθητής θέλει μαθήματα για τη χρήση εργαλείων |
| Εργαλεία | Συναρτήσεις, APIs, αρχεία, browsers ή υπηρεσίες που μπορεί να χρησιμοποιήσει ο πράκτορας | Ψάχνει το αποθετήριο ή ανακτά περιεχόμενο μαθημάτων |
| Γνώση | Έγγραφα ή δεδομένα που στηρίζουν την απάντηση | Αρχεία README και υλικό μαθημάτων |
| Πλαίσιο | Πληροφορίες που περιέχονται στην επόμενη κλήση μοντέλου | Ο στόχος του χρήστη και τα αποτελέσματα των εργαλείων |
| Μνήμη | Πληροφορίες αποθηκευμένες για μετέπειτα χρήση | Ο μαθητής προτιμά πρακτικά παραδείγματα Python |
| Σχεδιασμός | Διάσπαση ενός μεγαλύτερου στόχου σε μικρότερα βήματα | Βρίσκει μαθήματα, συνοψίζει, προτείνει πρακτική |
| Ορχήστρωση | Καθοδήγηση εργασιών σε εργαλεία, βήματα ή πράκτορες | Ένας προγραμματιστής καλεί εργαλείο αναζήτησης, μετά συνοψιστή |
| Εμπιστοσύνη | Ασφάλεια, αξιολόγηση και παρατηρησιμότητα | Καταγράφει κλήσεις εργαλείων και ζητά επιβεβαίωση πριν ενέργειες υψηλού κινδύνου |

## Μοντέλα και Πάροχοι

Τα παραδείγματα κώδικα του μαθήματος χρησιμοποιούν το **Microsoft Agent Framework (MAF)**
και απευθύνονται στο **Azure OpenAI Responses API** — το συνιστώμενο API που συνδυάζει
συμπληρώσεις συνομιλίας, κλήσεις εργαλείων, πολυτροπική είσοδο και συνομιλίες με κατάσταση σε
μια ενιαία επιφάνεια API. Συνδέεστε είτε μέσω ενός έργου **Microsoft Foundry** (με `FoundryChatClient`)
είτε απευθείας στο Azure OpenAI (με `OpenAIChatClient`).

Καθώς προχωράτε στα μαθήματα, έχετε μερικές επιλογές παρόχων:

- **Microsoft Foundry / Azure OpenAI (Responses API)** — η κύρια διαδρομή που χρησιμοποιείται στα μαθήματα. Συνδεθείτε με `az login` για αυθεντικοποίηση Entra ID χωρίς κλειδιά.
- **Foundry Local** — τρέξτε μοντέλα πλήρως τοπικά μέσω API συμβατού με OpenAI (χωρίς cloud, χωρίς API keys). Ιδανικό για πειραματισμό χωρίς κόστος ή σύνδεση. Δείτε [Course Setup](./00-course-setup/README.md).
- **MiniMax** — πάροχος συμβατός με OpenAI με μοντέλα μεγάλης μνήμης, χρήσιμος ως υποκατάστατο.

> **Σημείωση:** Το GitHub Models είναι παρωχημένο (λήξη Ιουλίου 2026) και δεν υποστηρίζει το Responses API. Τα παραδείγματα έχουν ενημερωθεί για να χρησιμοποιούν Azure OpenAI / Microsoft Foundry.

## Κύριες Ιδέες με Όρους Φιλικούς σε Αρχάριους

### Εργαλεία

Ένα εργαλείο είναι κάτι που ο πράκτορας μπορεί να καλέσει για να κάνει εργασία εκτός μοντέλου. Ένα καλό εργαλείο έχει σαφές όνομα, συγκεκριμένη δουλειά, τυποποιημένες εισόδους, προβλέψιμη έξοδο και ασφαλή τρόπους αποτυχίας.

Για την επίδειξη βοηθού μαθήματος, ένα εργαλείο μπορεί να είναι:

- `search_lessons(query)`
- `read_lesson(path)`
- `create_practice_task(topic)`

### RAG και Γνώση

Το RAG βοηθά τον πράκτορα να απαντά από πρωτογενές υλικό αντί να μαντεύει. Σε αυτό το μάθημα, το υλικό μπορεί να είναι README μαθημάτων, παραδείγματα κώδικα ή εξωτερικοί πόροι συνδεδεμένοι από τα μαθήματα.

Χρησιμοποιήστε RAG όταν η απάντηση πρέπει να στηρίζεται σε έγγραφα, δεδομένα ή τρέχοντα αρχεία έργου.

### Σχεδιασμός

Ο σχεδιασμός είναι χρήσιμος όταν το αίτημα έχει πάνω από ένα βήμα. Κρατήστε τα σχέδια σύντομα και ορατά για να τα ελέγξει ένας προγραμματιστής ή χρήστης.

Για την επίδειξη, ένα σχέδιο μπορεί να είναι:

1. Βρείτε μαθήματα σχετικά με τη χρήση εργαλείων.
2. Συνοψίστε τα πιο σχετικά μαθήματα.
3. Προτείνετε ένα πρακτικό έργο.

### Πλαίσιο

Το πλαίσιο είναι ό,τι βλέπει το μοντέλο τώρα. Πολύ λίγη πληροφορία μπορεί να κάνει τον πράκτορα να χάσει σημαντικές λεπτομέρειες. Πολύ πλαίσιο μπορεί να τον καθυστερήσει, να κοστίσει περισσότερο ή να τον μπερδέψει.

Η καλή μηχανική πλαισίου σημαίνει να επιλέγετε τη σωστή πληροφορία για την επόμενη κλήση μοντέλου.

### Μνήμη

Η μνήμη είναι πληροφορία αποθηκευμένη για μετέπειτα χρήση. Μη σώζετε τα πάντα. Αποθηκεύστε πληροφορίες μόνο όταν είναι χρήσιμες, ασφαλείς και εύκολα ενημερώσιμες ή διαγραφόμενες.

Για παράδειγμα, το να θυμάστε "ο μαθητής προτιμά παραδείγματα Python" μπορεί να είναι χρήσιμο. Το να θυμάστε ευαίσθητα προσωπικά δεδομένα συνήθως όχι.

### Αξιολόγηση και Παρατηρησιμότητα

Η αξιολόγηση ρωτά: ο πράκτορας έκανε το σωστό;

Η παρατηρησιμότητα ρωτά: μπορούμε να δούμε πώς έγινε αυτό;

Για παραγωγικούς πράκτορες, κρατήστε ίχνη κλήσεων μοντέλου, κλήσεων εργαλείων, ανακτημένου πλαισίου, καθυστέρησης, κόστους, αποτυχιών και ανατροφοδότησης χρήστη.

### Εμπιστοσύνη και Ασφάλεια

Οι αξιόπιστοι πράκτορες χρειάζονται περισσότερα από μια απλή σύντομη οδηγία. Χρησιμοποιήστε εργαλεία με ελάχιστα δικαιώματα, ανθρώπινη έγκριση για ενέργειες υψηλού αντίκτυπου, απόκρυψη δεδομένων όπου χρειάζεται και καταγραφές ή αποδείξεις για ενέργειες που πρέπει να ελεγχθούν.

## Ρουτίνα Ανασκόπησης 15 Λεπτών

Χρησιμοποιήστε αυτή τη ρουτίνα μετά από κάθε μάθημα:

1. **Συνοψίστε το μάθημα σε μία πρόταση.**
2. **Ονομάστε τη νέα ικανότητα πράκτορα.** Π.χ.: χρήση εργαλείων, ανάκτηση, σχεδιασμός, μνήμη, παρατηρησιμότητα ή ασφάλεια.
3. **Προσθέστε τη στην επίδειξη βοηθού μαθήματος.** Τι αλλάζει τώρα στην επίδειξη;
4. **Βρείτε τον κίνδυνο.** Τι μπορεί να πάει στραβά αν η ικανότητα αυτή χρησιμοποιηθεί λάθος;
5. **Γράψτε μια ερώτηση ελέγχου.** Πώς θα ελέγχατε την ορθή συμπεριφορά του πράκτορα;

## Γρήγορος Αυτοέλεγχος

Πριν προχωρήσετε, δοκιμάστε να απαντήσετε αυτές τις ερωτήσεις:

1. Τι μπορεί να κάνει ένας πράκτορας που ένας κανονικός chatbot δεν μπορεί μόνος του;
2. Ποιο εργαλείο θα χρειαστεί πρώτα ο πράκτοράς σας, και γιατί;
3. Ποια πηγή γνώσης πρέπει να στηρίξει την απάντηση του πράκτορα;
4. Τι πλαίσιο πρέπει να συμπεριληφθεί στην επόμενη κλήση μοντέλου;
5. Τι πρέπει να θυμάται ο πράκτορας, και τι να αποφεύγει να αποθηκεύει;
6. Πότε πρέπει ο πράκτορας να ζητά ανθρωπίνή έγκριση;
7. Ποια αρχεία καταγραφής, ίχνη ή αποδείξεις θα σας βοηθούσαν να εντοπίσετε ή να ελέγξετε τον πράκτορα αργότερα;

## Προτεινόμενη Άσκηση Κατάληξης

Στο τέλος του μαθήματος, κατασκευάστε έναν μικρό πράκτορα που βοηθά έναν μαθητή να πλοηγηθεί στο αποθετήριο αυτό.

Ελάχιστη έκδοση:

- Δέχεται θέμα από τον χρήστη.
- Βρίσκει τα πιο σχετικά μαθήματα.
- Συνοψίζει τι να διαβαστεί πρώτα.
- Προτείνει ένα πρακτικό, συμμετοχικό έργο.
- Δείχνει ποια αρχεία ή σύνδεσμοι μαθήματος χρησιμοποιήθηκαν.

Εκτεταμένη έκδοση:

- Θυμάται την προτιμώμενη γλώσσα προγραμματισμού του μαθητή.
- Χρησιμοποιεί απλό σχέδιο πριν απαντήσει.
- Προσθέτει βήμα αυτοελέγχου πριν την τελική απάντηση.
- Καταγράφει κλήσεις εργαλείων και ανακτημένες πηγές.
- Ζητά επιβεβαίωση πριν ανοίξει εργασίες browser ή UI automation.

Αυτό σας δίνει έναν μικρό αλλά ρεαλιστικό τρόπο να εξασκηθείτε σε εργαλεία, RAG, σχεδιασμό,
πλαίσιο, μνήμη, παρατηρησιμότητα και εμπιστοσύνη σε ένα μόνο έργο.
