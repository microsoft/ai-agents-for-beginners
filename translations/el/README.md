## 🌱 Ξεκινώντας

Αυτό το μάθημα περιέχει μαθήματα που καλύπτουν τα βασικά της δημιουργίας Πρακτόρων Τεχνητής Νοημοσύνης. Κάθε μάθημα καλύπτει το δικό του θέμα, οπότε ξεκινήστε από όπου θέλετε!

Υπάρχει υποστήριξη πολλαπλών γλωσσών για αυτό το μάθημα. Μεταβείτε στις [διαθέσιμες γλώσσες εδώ](#-multi-language-support).

Εάν είναι η πρώτη φορά που δημιουργείτε με μοντέλα Γεννητικής Τεχνητής Νοημοσύνης, ρίξτε μια ματιά στο μάθημα [Generative AI For Beginners](https://aka.ms/genai-beginners), που περιλαμβάνει 21 μαθήματα σχετικά με τη δημιουργία με GenAI.

Μην ξεχάσετε να [βαθμολογήσετε (🌟) αυτήν την αποθήκη](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst) και να [κάνετε fork αυτήν την αποθήκη](https://github.com/microsoft/ai-agents-for-beginners/fork) για να τρέξετε τον κώδικα.

### Γνωρίστε Άλλους Μαθητές, Πάρτε Απαντήσεις στις Ερωτήσεις σας

Εάν κολλήσετε ή έχετε οποιεσδήποτε ερωτήσεις σχετικά με τη δημιουργία Πρακτόρων Τεχνητής Νοημοσύνης, μπείτε στο αποκλειστικό κανάλι Discord στο [Microsoft Foundry Discord](https://aka.ms/ai-agents/discord).

### Τι Χρειάζεστε

Κάθε μάθημα σε αυτό το μάθημα συνοδεύεται από παραδείγματα κώδικα, τα οποία μπορείτε να βρείτε στον φάκελο code_samples. Μπορείτε να [κάνετε fork αυτήν την αποθήκη](https://github.com/microsoft/ai-agents-for-beginners/fork) για να δημιουργήσετε το δικό σας αντίγραφο.

Τα παραδείγματα κώδικα σε αυτές τις ασκήσεις χρησιμοποιούν το Microsoft Agent Framework με το Microsoft Foundry Agent Service V2:

- [Microsoft Foundry](https://aka.ms/ai-agents-beginners/ai-foundry) - Απαιτεί Δωρεάν Λογαριασμό Azure

Αυτό το μάθημα χρησιμοποιεί τα ακόλουθα πλαίσια και υπηρεσίες Πρακτόρων Τεχνητής Νοημοσύνης από τη Microsoft:

- [Microsoft Agent Framework (MAF)](https://learn.microsoft.com/agent-framework/overview/)
- [Microsoft Foundry Agent Service V2](https://aka.ms/ai-agents-beginners/ai-agent-service)

Ορισμένα παραδείγματα κώδικα υποστηρίζουν επίσης εναλλακτικούς παρόχους συμβατούς με OpenAI όπως το [MiniMax](https://platform.minimaxi.com/), που προσφέρει μοντέλα με μεγάλο πλαίσιο (έως 204Κ tokens). Δείτε το [Course Setup](./00-course-setup/README.md) για λεπτομέρειες ρύθμισης.

Για περισσότερες πληροφορίες σχετικά με την εκτέλεση του κώδικα για αυτό το μάθημα, μεταβείτε στο [Course Setup](./00-course-setup/README.md).

## Συμβολή

Αυτό το έργο καλωσορίζει συμβολές και προτάσεις. Οι περισσότερες απαιτούν να συμφωνήσετε με μια
Συμφωνία Άδειας Συνεργάτη (CLA) που δηλώνει ότι έχετε το δικαίωμα και πράγματι παραχωρείτε
τα δικαιώματα χρήσης της συμβολής σας. Για λεπτομέρειες, επισκεφτείτε <https://cla.opensource.microsoft.com>.

Όταν υποβάλλετε αίτημα έλξης (pull request), ένα bot CLA θα καθορίσει αυτόματα αν χρειάζεται να παρέχετε
μια CLA και θα στολίσει το PR ανάλογα (π.χ., έλεγχος κατάστασης, σχόλιο). Απλά ακολουθήστε τις οδηγίες
που παρέχει το bot. Θα χρειαστεί να το κάνετε μόνο μία φορά σε όλα τα repos που χρησιμοποιούν την CLA μας.

Αυτό το έργο έχει υιοθετήσει τον [Κώδικα Συμπεριφοράς Ανοιχτού Κώδικα της Microsoft](https://opensource.microsoft.com/codeofconduct/).
Για περισσότερες πληροφορίες, δείτε τις [Συχνές Ερωτήσεις Κώδικα Συμπεριφοράς](https://opensource.microsoft.com/codeofconduct/faq/) ή
επικοινωνήστε με [opencode@microsoft.com](mailto:opencode@microsoft.com) για τυχόν επιπλέον ερωτήσεις ή σχόλια.
