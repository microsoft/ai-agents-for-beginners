## 🌱 Ξεκινώντας

Αυτό το μάθημα περιλαμβάνει μαθήματα που καλύπτουν τα βασικά της κατασκευής Πρακτόρων Τεχνητής Νοημοσύνης. Κάθε μάθημα καλύπτει το δικό του θέμα, οπότε ξεκινήστε όπου θέλετε!

Υπάρχει υποστήριξη πολλών γλωσσών για αυτό το μάθημα. Μεταβείτε στις [διαθέσιμες γλώσσες εδώ](#-multi-language-support). 

Αν αυτή είναι η πρώτη σας φορά που κατασκευάζετε με μοντέλα Γεννητικής Τεχνητής Νοημοσύνης, δοκιμάστε το μάθημά μας [Generative AI For Beginners](https://aka.ms/genai-beginners), που περιλαμβάνει 21 μαθήματα για την κατασκευή με GenAI.

Μην ξεχάσετε να [αφεθείτε σε αυτή την αποθήκη (🌟)](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst) και να [κλωνοποιήσετε αυτή την αποθήκη](https://github.com/microsoft/ai-agents-for-beginners/fork) για να τρέξετε τον κώδικα.

### Γνωρίστε Άλλους Μαθητευόμενους, Λάβετε Απαντήσεις σε Ερωτήσεις

Αν κολλήσετε ή έχετε απορίες σχετικά με την κατασκευή Πρακτόρων Τεχνητής Νοημοσύνης, ενταχθείτε στο αφιερωμένο μας κανάλι Discord στο [Microsoft Foundry Discord](https://aka.ms/ai-agents/discord).

### Τι Χρειάζεστε 

Κάθε μάθημα σε αυτό το μάθημα περιλαμβάνει παραδείγματα κώδικα, τα οποία βρίσκονται στον φάκελο code_samples. Μπορείτε να [κλωνοποιήσετε αυτή την αποθήκη](https://github.com/microsoft/ai-agents-for-beginners/fork) για να δημιουργήσετε το δικό σας αντίγραφο.  

Τα παραδείγματα κώδικα σε αυτές τις ασκήσεις χρησιμοποιούν το Microsoft Agent Framework με το Microsoft Foundry Agent Service V2:

- [Microsoft Foundry](https://aka.ms/ai-agents-beginners/ai-foundry) - Απαιτείται λογαριασμός Azure

Αυτό το μάθημα χρησιμοποιεί τα ακόλουθα πλαίσια εργασίας και υπηρεσίες Πρακτόρων Τεχνητής Νοημοσύνης από τη Microsoft:

- [Microsoft Agent Framework (MAF)](https://learn.microsoft.com/agent-framework/overview/)
- [Microsoft Foundry Agent Service V2](https://aka.ms/ai-agents-beginners/ai-agent-service)

Ορισμένα παραδείγματα κώδικα υποστηρίζουν επίσης εναλλακτικούς παρόχους συμβατούς με OpenAI όπως το [MiniMax](https://platform.minimaxi.com/), που προσφέρει μοντέλα μεγάλης κλίμακας (έως 204K tokens). Δείτε τις λεπτομέρειες παραμετροποίησης στο [Course Setup](./00-course-setup/README.md).

Για περισσότερες πληροφορίες σχετικά με το πώς να τρέξετε τον κώδικα για αυτό το μάθημα, επισκεφθείτε το [Course Setup](./00-course-setup/README.md).

## Συνεισφορά

Αυτό το έργο καλωσορίζει συνεισφορές και προτάσεις. Οι περισσότερες συνεισφορές απαιτούν να συμφωνήσετε με μια
Συμφωνία Άδειας Συνεργάτη (CLA) που δηλώνει ότι έχετε το δικαίωμα, και πράγματι παραχωρείτε,
τα δικαιώματα να χρησιμοποιήσουμε τη συνεισφορά σας. Για λεπτομέρειες, επισκεφθείτε <https://cla.opensource.microsoft.com>.

Όταν υποβάλετε ένα pull request, ένα bot CLA θα καθορίσει αυτόματα εάν πρέπει να παρέχετε
μια CLA και θα διακοσμήσει το PR ανάλογα (π.χ., έλεγχος κατάστασης, σχόλιο). Απλώς ακολουθήστε τις οδηγίες
που παρέχει το bot. Αυτό χρειάζεται να γίνει μόνο μία φορά σε όλα τα αποθετήρια που χρησιμοποιούν την CLA μας.

Αυτό το έργο έχει υιοθετήσει τον [Κώδικα Δεοντολογίας Ανοιχτού Κώδικα Microsoft](https://opensource.microsoft.com/codeofconduct/).
Για περισσότερες πληροφορίες δείτε τις [Συχνές Ερωτήσεις Κώδικα Δεοντολογίας](https://opensource.microsoft.com/codeofconduct/faq/) ή
επικοινωνήστε στο [opencode@microsoft.com](mailto:opencode@microsoft.com) για οποιεσδήποτε επιπλέον ερωτήσεις ή σχόλια.
