## 🌱 Ξεκινώντας

Αυτό το μάθημα περιλαμβάνει μαθήματα που καλύπτουν τα βασικά για τη δημιουργία Πρακτόρων Τεχνητής Νοημοσύνης. Κάθε μάθημα καλύπτει ένα συγκεκριμένο θέμα, οπότε ξεκινήστε από όπου θέλετε!

Υπάρχει υποστήριξη πολλών γλωσσών για αυτό το μάθημα. Πηγαίνετε στις [διαθέσιμες γλώσσες εδώ](#-multi-language-support). 

Αν είναι η πρώτη σας φορά που δημιουργείτε με μοντέλα Γενετικής Τεχνητής Νοημοσύνης, δείτε το μάθημα μας [Γενετική ΤΝ για Αρχάριους](https://aka.ms/genai-beginners), που περιλαμβάνει 21 μαθήματα για δημιουργία με GenAI.

Μην ξεχάσετε να [βαθμολογήσετε με αστέρι (🌟) αυτό το repo](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst) και να [κάνετε fork αυτό το repo](https://github.com/microsoft/ai-agents-for-beginners/fork) για να τρέξετε τον κώδικα.

### Γνωρίστε Άλλους Μαθητές, Λάβετε Απαντήσεις στις Ερωτήσεις σας

Αν κολλήσετε ή έχετε ερωτήσεις για τη δημιουργία Πρακτόρων ΤΝ, συμμετάσχετε στο ειδικό κανάλι Discord μας στο [Microsoft Foundry Discord](https://aka.ms/ai-agents/discord).

### Τι Χρειάζεστε 

Κάθε μάθημα σε αυτό το μάθημα περιλαμβάνει παραδείγματα κώδικα, που βρίσκονται στον φάκελο code_samples. Μπορείτε να [κάνετε fork αυτό το repo](https://github.com/microsoft/ai-agents-for-beginners/fork) για να δημιουργήσετε το δικό σας αντίγραφο.  

Τα παραδείγματα κώδικα σε αυτές τις ασκήσεις χρησιμοποιούν το Microsoft Agent Framework με το Microsoft Foundry Agent Service V2:

- [Microsoft Foundry](https://aka.ms/ai-agents-beginners/ai-foundry) - Απαιτείται Λογαριασμός Azure

Αυτό το μάθημα χρησιμοποιεί τα ακόλουθα πλαίσια και υπηρεσίες Πρακτόρων ΤΝ από τη Microsoft:

- [Microsoft Agent Framework (MAF)](https://learn.microsoft.com/agent-framework/overview/)
- [Microsoft Foundry Agent Service V2](https://aka.ms/ai-agents-beginners/ai-agent-service)

Ορισμένα παραδείγματα κώδικα υποστηρίζουν επίσης εναλλακτικούς παρόχους συμβατούς με OpenAI όπως ο [MiniMax](https://platform.minimaxi.com/), που προσφέρει μεγάλα μοντέλα πλαισίου (έως 204K tokens). Δείτε το [Course Setup](./00-course-setup/README.md) για λεπτομέρειες διαμόρφωσης.

Για περισσότερες πληροφορίες σχετικά με την εκτέλεση του κώδικα αυτού του μαθήματος, δείτε το [Course Setup](./00-course-setup/README.md).
