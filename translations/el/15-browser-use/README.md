# Δημιουργία Πρακτόρων Χρήσης Υπολογιστή (CUA)

Οι πράκτορες χρήσης υπολογιστή μπορούν να αλληλεπιδράσουν με ιστοσελίδες όπως θα έκανε ένας άνθρωπος: ανοίγοντας έναν περιηγητή, επιθεωρώντας τη σελίδα και παίρνοντας την καλύτερη επόμενη ενέργεια με βάση αυτά που βλέπουν. Σε αυτό το μάθημα, θα δημιουργήσετε έναν πράκτορα αυτοματοποίησης περιηγητή που αναζητά στο Airbnb, εξάγει δομημένα δεδομένα καταχωρίσεων και εντοπίζει τη φθηνότερη διαμονή στη Στοκχόλμη.

Το μάθημα συνδυάζει το Browser-Use για πλοήγηση με AI, το Playwright και το Chrome DevTools Protocol (CDP) για τον έλεγχο του περιηγητή, το Azure OpenAI για λογική με οραματική υποστήριξη και το Pydantic για δομημένη εξαγωγή.

## Εισαγωγή

Αυτό το μάθημα θα καλύψει:

- Κατανόηση πότε οι πράκτορες χρήσης υπολογιστή είναι καλύτερη επιλογή από αυτοματοποίηση μόνο με API
- Συνδυασμός Browser-Use με Playwright και CDP για αξιόπιστη διαχείριση του κύκλου ζωής του περιηγητή
- Χρήση Azure OpenAI vision και δομημένης εξόδου Pydantic για εξαγωγή δεδομένων καταχωρίσεων από δυναμικές ιστοσελίδες
- Απόφαση πότε να χρησιμοποιήσετε ροή εργασίας αυτοματοποίησης περιηγητή με προτεραιότητα στον πράκτορα, τον εκτελεστή ή υβριδική

## Μαθησιακοί Στόχοι

Μετά την ολοκλήρωση αυτού του μαθήματος, θα γνωρίζετε πώς να:

- Διαμορφώσετε το Browser-Use με Azure OpenAI και Playwright
- Δημιουργήσετε μια ροή εργασίας αυτοματοποίησης περιηγητή που πλοηγείται σε πραγματική ιστοσελίδα και χειρίζεται δυναμικά στοιχεία διεπαφής χρήστη
- Εξάγετε τυποποιημένα αποτελέσματα από το ορατό περιεχόμενο της σελίδας και τα μετατρέψετε σε επιχειρηματική λογική
- Επιλέξετε μεταξύ προτύπων πράκτορα και εκτελεστή ανάλογα με το πόσο προβλέψιμο είναι το καθήκον του περιηγητή

## Δείγμα Κώδικα

Το μάθημα περιλαμβάνει ένα notebook εκπαιδευτικό:

- [15-browser-user.ipynb](./15-browser-user.ipynb): Εκκινεί μια συνεδρία Chrome μέσω CDP, αναζητά καταχωρίσεις στη Στοκχόλμη στο Airbnb, εξάγει τιμές με όραμα Browser-Use και επιστρέφει την οικονομικότερη επιλογή ως δομημένα δεδομένα.

## Προαπαιτούμενα

- Python 3.12+
- Διαμόρφωση ανάπτυξης Azure OpenAI στο περιβάλλον σας
- Τοπική εγκατάσταση Chrome ή Chromium
- Εγκατεστημένες εξαρτήσεις Playwright
- Βασική εξοικείωση με ασύγχρονη Python

Εγκαταστήστε τα πακέτα που χρησιμοποιούνται στο notebook:


## Επισκόπηση Αρχιτεκτονικής

Το notebook παρουσιάζει μια υβριδική ροή εργασίας αυτοματοποίησης περιηγητή:

1. Το Chrome ξεκινά με ενεργοποιημένο το CDP ώστε να μοιράζονται την ίδια συνεδρία περιηγητή το Playwright και το Browser-Use.
2. Ένας πράκτορας Browser-Use χειρίζεται ανοιχτού τύπου εργασίες πλοήγησης όπως το άνοιγμα του Airbnb, το κλείσιμο αναδυόμενων παραθύρων και την αναζήτηση για Στοκχόλμη.
3. Η ενεργή σελίδα επιθεωρείται με δομημένο σχήμα Pydantic για εξαγωγή τίτλων καταχωρίσεων, τιμών ανά διανυκτέρευση, αξιολογήσεων και URLs.
4. Η Python λογική συγκρίνει τις εξαγόμενες καταχωρίσεις και επισημαίνει το φθηνότερο αποτέλεσμα.

Αυτή η προσέγγιση διατηρεί την ευέλικτη, οραματική λογική που το Browser-Use χειρίζεται καλά, ενώ παράλληλα παρέχει ντετερμινιστικό έλεγχο του περιηγητή όταν το χρειάζεστε.

## Βασικά Συμπεράσματα και Καλές Πρακτικές

### Πότε να Χρησιμοποιήσετε Πράκτορα έναντι Εκτελεστή

| Σενάριο | Χρησιμοποιήστε Πράκτορα | Χρησιμοποιήστε Εκτελεστή |
|----------|-------------------------|-------------------------|
| Δυναμικές διατάξεις | Ναι, το AI προσαρμόζεται σε αλλαγές σελίδας | Όχι, οι εύθραυστοι επιλεκτές μπορεί να σπάσουν |
| Γνωστή δομή | Όχι, ο πράκτορας είναι πιο αργός από το άμεσο χειρισμό | Ναι, γρήγορος και ακριβής |
| Εύρεση στοιχείων | Ναι, φυσική γλώσσα λειτουργεί καλά | Όχι, απαιτούνται ακριβείς επιλεκτές |
| Έλεγχος χρονομέτρων | Όχι, λιγότερο προβλέψιμο | Ναι, πλήρης έλεγχος σε αναμονές και επαναλήψεις |
| Πολύπλοκες ροές εργασίας | Ναι, διαχειρίζεται απροσδόκητες καταστάσεις UI | Όχι, απαιτεί ρητή διακλάδωση |

### Καλές Πρακτικές Browser-Use

1. Ξεκινήστε με πράκτορα για εξερεύνηση και δυναμική πλοήγηση.
2. Μεταβείτε σε άμεσο έλεγχο σελίδας όταν η αλληλεπίδραση γίνεται προβλέψιμη.
3. Χρησιμοποιήστε δομημένα μοντέλα εξόδου ώστε τα δεδομένα να επικυρώνονται και να είναι ασφαλή ως προς τους τύπους.
4. Προσθέστε καθυστερήσεις στρατηγικά μετά από ενέργειες που προκαλούν ορατές αλλαγές UI.
5. Καταγράψτε στιγμιότυπα οθόνης κατά τη διάρκεια των επαναλήψεων για ευκολότερο εντοπισμό σφαλμάτων.
6. Περιμένετε αλλαγές στις ιστοσελίδες και σχεδιάστε στρατηγικές αποκατάστασης για αναδυόμενα παράθυρα και μετατοπίσεις διάταξης.
7. Συνδυάστε πρότυπα πράκτορα και εκτελεστή για να αποκτήσετε και ευελιξία και ακρίβεια.

### Πραγματικές Εφαρμογές

- Κράτηση ταξιδιών και παρακολούθηση τιμών
- Σύγκριση τιμών και διαθεσιμότητα σε ηλεκτρονικό εμπόριο
- Δομημένη εξαγωγή από δυναμικές ιστοσελίδες
- Δοκιμές UI με επίγνωση οράματος και επαλήθευση
- Παρακολούθηση ιστοσελίδων και ειδοποιήσεις
- Έξυπνη συμπλήρωση φορμών σε πολυβηματικές ροές

## Πραγματικό Παράδειγμα: Microsoft Project Opal

Ο πράκτορας που δημιουργείτε σε αυτό το μάθημα είναι μια μικρή, τοπική έκδοση ενός **πράκτορα χρήσης υπολογιστή (CUA)** — ενός προγράμματος που οδηγεί έναν περιηγητή όπως θα έκανε ένας άνθρωπος. Η Microsoft φέρνει αυτή τη ιδέα στην επιχείρηση με το **[Project Opal (Frontier)](https://support.microsoft.com/en-us/microsoft-365-copilot/get-started-with-project-opal-frontier)**, μια δυνατότητα στο Microsoft 365 Copilot.

Με το Project Opal, περιγράφετε ένα έργο και ο πράκτορας λειτουργεί εκ μέρους σας χρησιμοποιώντας **χρήση υπολογιστή σε ένα ασφαλές Windows 365 Cloud PC**, λειτουργώντας σε εφαρμογές, ιστοτόπους και δεδομένα της οργανώσεώς σας που βασίζονται σε περιηγητή. Λειτουργεί **ασύγχρονα στο παρασκήνιο**, και μπορείτε να καθοδηγήσετε τη δουλειά ή να αναλάβετε τον έλεγχο ανά πάσα στιγμή. Παραδείγματα εργασιών περιλαμβάνουν:

- Διαχείριση αιτημάτων μέλους ασφαλούς ομάδας
- Συλλογή και επικύρωση αποδεικτικών στοιχείων ελέγχου για αξιολογήσεις συμμόρφωσης
- Ταξινόμηση περιστατικών IT (ενημέρωση κατάστασης εισιτηρίου, ανάθεση ιδιοκτητών, κλείσιμο διπλότυπων)
- Συγκέντρωση δεδομένων Excel σε παρουσίαση οικονομικού κλεισίματος

Το Opal αποτελεί μια χρήσιμη αναφορά για το πώς μοιάζει ένας **παραγωγικός, αξιόπιστος** πράκτορας χρήσης υπολογιστή — και ενισχύει έννοιες από προηγούμενα μαθήματα:

| Έννοια στο μάθημα | Πώς το Project Opal την εφαρμόζει |
|-------------------|------------------------------------|
| **Άνθρωπος στη διαδικασία** (Μάθημα 06) | Το Opal σταματά για διαπιστευτήρια σύνδεσης, ευαίσθητα δεδομένα ή ασαφείς οδηγίες και δεν εισάγει ποτέ κωδικούς ή υποβάλλει φόρμες χωρίς ρητή επιβεβαίωση. Μπορείτε να *αναλάβετε* και να *παραδώσετε* τον έλεγχο κατά τη διάρκεια της εργασίας. |
| **Αξιόπιστοι και ασφαλείς πράκτορες** (Μαθήματα 06 & 18) | Εκτελείται σε απομονωμένο Windows 365 Cloud PC, είναι μόνο για περιηγητή κατά προεπιλογή (η πρόσβαση σε άλλους υπολογιστικούς πόρους μπλοκάρεται, επιβαλλόμενο μέσω Intune), χρησιμοποιεί *τη δική σας* ταυτότητα ώστε να έχει πρόσβαση μόνο στα εξουσιοδοτημένα, και καταγράφει κάθε ενέργεια για δυνατότητα ελέγχου. |
| **Σχεδιασμός & μεταγνωστική λειτουργία** (Μαθήματα 07 & 09) | Το Opal δημιουργεί πρώτα ένα σχέδιο για τη δουλειά, έπειτα επιβλέπει τη δική του λογική σε κάθε βήμα και σταματά αν ανιχνεύσει ύποπτη δραστηριότητα. |
| **Επαναχρησιμοποιήσιμες δυνατότητες / εργαλεία** (Μάθημα 04) | Τα **Skills** σας επιτρέπουν να γράφετε οδηγίες για επαναλαμβανόμενες εργασίες (εισαγόμενες από αρχείο `.md` ή συντεταγμένες με το Opal) και να τις επαναχρησιμοποιείτε σε συνομιλίες. |

> **Διαθεσιμότητα:** Το Project Opal είναι αυτή τη στιγμή διαθέσιμο στους χρήστες του [προγράμματος πρώιμης πρόσβασης Frontier](https://adoption.microsoft.com/copilot/frontier-program/) με συνδρομή Microsoft 365 Copilot, και ο διαχειριστής σας πρέπει να ολοκληρώσει τη ρύθμιση. Επειδή είναι πειραματική δυνατότητα Frontier, οι λειτουργίες ενδέχεται να αλλάξουν με τον χρόνο.
