# 🔄 Alapvető ügynök munkafolyamatok az Azure OpenAI-val (Responses API) (.NET)

## 📋 Munkafolyamat-ütemezési útmutató

Ez a jegyzetfüzet bemutatja, hogyan építsünk kifinomult **ügynök munkafolyamatokat** a Microsoft Agent Framework .NET-hez és az Azure OpenAI-val (Responses API). Megtanulod, hogyan hozz létre többlépcsős üzleti folyamatokat, ahol az AI ügynökök együttműködve komplex feladatokat hajtanak végre strukturált ütemezési mintákon keresztül.

## 🎯 Tanulási célok

### 🏗️ **Munkafolyamat-architektúra alapjai**
- **Munkafolyamat-építő**: Tervezd és szervezd meg a komplex, többlépcsős AI folyamatokat
- **Ügynök koordináció**: Több speciális ügynök koordinálása a munkafolyamatokban
- **Azure OpenAI (Responses API)**: Használd az Azure OpenAI Responses API-t a munkafolyamatokban
- **Vizualizált munkafolyamat-tervezés**: Készíts és jeleníts meg munkafolyamat-struktúrákat a jobb megértés érdekében

### 🔄 **Folyamat-ütemezési minták**
- **Szekvenciális feldolgozás**: Több ügynöki feladat logikus sorrendben láncolása
- **Állapotkezelés**: Kontextus és adatáramlás fenntartása a munkafolyamat szakaszai között
- **Hibakezelés**: Robusztus hibakezelés és a munkafolyamat ellenálló képességének biztosítása
- **Teljesítmény-optimalizálás**: Hatékony munkafolyamatok tervezése vállalati szintű működéshez

### 🏢 **Vállalati munkafolyamat alkalmazások**
- **Üzleti folyamat automatizálás**: Komplex szervezeti munkafolyamatok automatizálása
- **Tartalomgyártási folyamat**: Szerkesztői munkafolyamatok áttekintési és jóváhagyási lépésekkel
- **Ügyfélszolgálat automatizálás**: Többlépéses ügyfélkérdés megoldás
- **Adatfeldolgozó munkafolyamatok**: ETL munkafolyamatok AI-alapú átalakítással

## ⚙️ Előfeltételek és beállítás

### 📦 **Szükséges NuGet csomagok**

Ez a munkafolyamat bemutató több kulcsfontosságú .NET csomagot használ:

```xml
<!-- Core AI Framework -->
<PackageReference Include="Microsoft.Extensions.AI" Version="9.9.0" />

<!-- Azure OpenAI (Responses API) -->
<PackageReference Include="Azure.AI.OpenAI" Version="2.1.0" />
<PackageReference Include="Azure.Identity" Version="1.13.1" />

<!-- Agent Framework (Local Development) -->
<!-- Microsoft.Agents.AI.dll - Core agent abstractions -->
<!-- Microsoft.Agents.AI.OpenAI.dll - Azure OpenAI (Responses API) integration -->

<!-- Configuration and Environment -->
<PackageReference Include="DotNetEnv" Version="3.1.1" />
```

### 🔑 **Azure OpenAI konfiguráció**

**Környezeti beállítás (.env fájl):**
```env
AZURE_OPENAI_ENDPOINT=https://<your-resource>.openai.azure.com
AZURE_OPENAI_DEPLOYMENT=gpt-4o-mini
```

**Azure OpenAI hozzáférés:**
1. Hozz létre egy Azure OpenAI erőforrást az Azure portálon
2. Telepíts egy modellt (például `gpt-4o-mini`), és jegyezd fel a telepítés nevét
3. Jelentkezz be `az login`-nal, és állítsd be a fent látható környezeti változókat

**Főbb összetevők:**
- **WorkflowBuilder**: Fő ütemező motor a munkafolyamatok tervezéséhez
- **AIAgent**: Egyedi, speciális képességű ügynökök
- **Azure OpenAI kliens**: Azure OpenAI Responses API integráció
- **Végrehajtási kontextus**: Kezeli az állapotot és az adatáramlást a munkafolyamat szakaszai között

## 💻 A kód futtatása

A teljes megvalósítás elérhető a `01.dotnet-agent-framework-workflow-ghmodel-basic.cs` fájlban. Ez a fájl bemutatja:

1. **Környezet konfiguráció** – Azure OpenAI konfiguráció betöltése `.env` fájlból
2. **Azure OpenAI kliens beállítása** – A kliens konfigurálása az Azure OpenAI Responses API használatához
3. **Ügynök létrehozása** – Speciális ügynökök definiálása (Portás és Concierge)
4. **Munkafolyamat építő** – Több ügynökből álló munkafolyamat létrehozása szekvenciális feldolgozással
5. **Munkafolyamat végrehajtása** – Munkafolyamat futtatása streaming eredményekkel

### 🚀 Példa futtatása

```bash
# Tegye futtathatóvá a szkriptet (Unix/Linux/macOS)
chmod +x 01.dotnet-agent-framework-workflow-ghmodel-basic.cs

# Futtassa a munkafolyamatot
./01.dotnet-agent-framework-workflow-ghmodel-basic.cs
```

Vagy Windows alatt:
```powershell
dotnet run 01.dotnet-agent-framework-workflow-ghmodel-basic.cs
```

### 📝 Várt kimenet

A munkafolyamat:
1. Elfogadja az utazási cél kérésed ("Szeretnék Párizsba menni")
2. A Portás ügynök első ajánlást ad
3. A Concierge ügynök átnézi és finomítja az ajánlást
4. A végső kimenet megjeleníti a teljes beszélgetési folyamatot
