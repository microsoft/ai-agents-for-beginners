# ⚡ Egyidejű ügynök munkafolyamatok az Azure OpenAI-val (Responses API) (.NET)

## 📋 Nagyteljesítményű párhuzamos feldolgozás bemutató

Ez a jegyzetfüzet az **egyidejű munkafolyamat-mintákat** mutatja be a Microsoft Agent Framework .NET-hez és az Azure OpenAI (Responses API) segítségével. Megtanulhatod, hogyan építs ki nagyteljesítményű, párhuzamos feldolgozású munkafolyamatokat, amelyek maximalizálják az áteresztőképességet azáltal, hogy több AI ügynököt futtatnak egyszerre, miközben fenntartják az együttműködést és az adatkonzisztenciát.

## 💻 A kód futtatása

A teljes megvalósítás elérhető a `03.dotnet-agent-framework-workflow-ghmodel-concurrent.cs` fájlban. Ez a fájl bemutat egy **Fan-Out/Fan-In egyidejű munkafolyamatot** utazástervezéshez:

### 🏗️ **Munkafolyamat architektúra**

```
User Request → ConcurrentStartExecutor → [Researcher Agent || Planner Agent] → ConcurrentAggregationExecutor → Final Output
```

**Kulcsfontosságú elemek:**

1. **ConcurrentStartExecutor**: Az összes ügynöknek egyszerre továbbítja a felhasználói kérést
2. **Kutató Ügynök**: Egyidejűleg elemzi az úti célokat és látnivalókat
3. **Tervező Ügynök**: Egyidejűleg készít részletes utazási terveket
4. **ConcurrentAggregationExecutor**: Összegyűjti és egyesíti mindkét ügynök eredményeit

### 🎯 **Fan-Out/Fan-In minta**

Ez a munkafolyamat bemutatja a klasszikus **Fan-Out/Fan-In** mintát:
- **Fan-Out**: Egy bemeneti üzenetet egyszerre több ügynöknek továbbít
- **Egyidejű feldolgozás**: Több ügynök párhuzamosan dolgozik ugyanazon a feladaton
- **Fan-In**: Az összes ügynök eredményét összegyűjti és egyetlen kimenetté aggregálja

### 🔍 Egyedi végrehajtók megértése

**ConcurrentStartExecutor:**
- Megvalósítja az `IMessageHandler<string>`t string bevitel elfogadásához
- Üzeneteket sugároz az összes kapcsolódó ügynöknek
- Küld egy `TurnToken`-t az egyidejű feldolgozás elindításához

**ConcurrentAggregationExecutor:**
- Megvalósítja az `IMessageHandler<ChatMessage>`-t az ügynökválaszok fogadására
- Szálbiztos módon gyűjti össze az üzeneteket
- Aggregál, amikor minden várt válasz megérkezik
- Adja az végső kimenetet a `context.YieldOutputAsync()`-vel

### ⚡ Teljesítményelőnyök

**Egyidejű vs Szekvenciális:**
- Szekvenciális: Agent1 (30s) → Agent2 (30s) = **összesen 60 másodperc**
- Egyidejű: Agent1 (30s) || Agent2 (30s) = **összesen 30 másodperc**

**Áteresztőképesség javulás**: Akár N-szer gyorsabb N egyidejű ügynöknél (a munkaterheléstől és erőforrásoktól függően)
