# ಕಂಪ್ಯೂಟರ್ ಬಳಕೆ ಏಜೆಂಟುಗಳು (CUA) ರಚನೆ

ಕಂಪ್ಯೂಟರ್ ಬಳಕೆ ಏಜೆಂಟುಗಳು ವ್ಯಕ್ತಿಯಂತೆ ವೆಬ್‌ಸೈಟ್‌ಗಳೊಂದಿಗೆ ಸಂವಹನ ಮಾಡಬಹುದು: ಬ್ರೌಜರ್ ತೆರೆಯುವುದು, ಪುಟವನ್ನು ಪರಿಶೀಲಿಸುವುದು, ಮತ್ತು ಅವರು ನೋಡಿದುದರಲ್ಲಿ ಮುಂದಿನ ಉತ್ತಮ ಕ್ರಿಯೆಯನ್ನು ತೆಗೆದುಕೊಳ್ಳುವುದು. ಈ ಪಾಠದಲ್ಲಿ, ನೀವು ಏರ್‌ಬಿಎನ್‌ಬಿಯನ್ನು ಹುಡುಕಿ, ಸಂರಚಿತ ಲಿಸ್ಟಿಂಗ್ ಡೇಟಾವನ್ನು ಹಾಕಿ ಮತ್ತು ಸ್ಟಾಕ್‌ಹೋಲ್ಮ್‌ನಲ್ಲಿ ಅತ್ಯಂತ ತಗ್ಗು ವೈಶಿಷ್ಟ್ ಗುರುತಿಸುವ ಬ್ರೌಜರ್ ಸ್ವಯಂಚಾಲನಾ ಏಜೆಂಟನ್ನು ಕಟ್ಟುತ್ತೀರಿ.

ಈ ಪಾಠವು ಬ್ರೌಸರ್-ಬಳಕೆ ಅನ್ನು AI-ಚಾಲಿತ ನ್ಯಾವಿಗೇಶನ್‌ಗೆ, ಪ್ಲೇ ರೈಟ್ ಮತ್ತು ಕ್ರೋಮ್ ಡೆವ್‌ಟೂಲ್ ಪ್ರೋಟೋಕಾಲ್ (CDP) ಅನ್ನು ಬ್ರೌಸರ್ ನಿಯಂತ್ರಣಕ್ಕೆ, ಅಜೂರ್ ಓಪನ್‌ಎಐ ಅನ್ನು ದೃಷ್ಟಿ-ಸಾಧ್ಯತೆಯ ನಿರ್ಣಯಕ್ಕೆ ಮತ್ತು ಪೈಡ್ಯಾಂಟಿಕ್ ಅನ್ನು ಸಂರಚಿತ ಹೊರತೆಗೆದುಕೊಳ್ಳಲು ಸಂಯೋಜಿಸುತ್ತದೆ.

## ಪರಿಚಯ

ಈ ಪಾಠದಲ್ಲಿ ರಂದು:

- API-ಮಾತ್ರ ಸ್ವಯಂಚಾಲನೆಯಿಂದ kampuni ಬಳಕೆ ಏಜೆಂಟುಗಳು ಹೇಗೆ ಉತ್ತಮವಾಗುತ್ತವೆಯೆಂದು ಅರ್ಥಮಾಡಿಕೊಳ್ಳುವುದು
- ನಂಬಿಗಸ್ತ ಬ್ರೌಸರ್ ಜೀವನಚಕ್ರ ನಿರ್ವಹಣೆಗೆ ಬ್ರೌಸರ್-ಬಳಕೆಯನ್ನು ಪ್ಲೇ ರೈಟ್ ಮತ್ತು CDP ಜೊತೆಗೆ ಸಂಯೋಜಿಸುವುದು
- ಡೈನಾಮಿಕ್ ವೆಬ್ ಪುಟಗಳಿಂದ ಲಿಸ್ಟಿಂಗ್ ಡೇಟಾವನ್ನು ಹೊರತೆಗೆಯಲು ಅಜೂರ್ ಓಪನ್‌ಎಐ ದೃಷ್ಟಿಯ ಬಳಕೆ ಮತ್ತು ಸಂರಚಿತ ಪೈಡ್ಯಾಂಟಿಕ್ ಫಲಿತಾಂಶವನ್ನು ಬಳಸುದು
- ಏಜೆಂಟ್-ಪ್ರಥಮ, ನಟ-ಪ್ರಥಮ, ಅಥವಾ ಸಂಯುಕ್ತ ಬ್ರೌಸರ್ ಸ್ವಯಂಚಾಲನಾ ಕಾರ್ಯಾಚರಣೆಯಲ್ಲಿ ಯಾವಾಗ ಬಳಸಬೇಕೆಂದು ನಿರ್ಧರಿಸುವುದು

## ಕಲಿಕೆಯ ಗೇಳುಗಳು

ಈ ಪಾಠವನ್ನು ಪೂರ್ಣಗೊಳಿಸಿದ ನಂತರ, ನೀವು ಹೇಗೆ ತಿಳಿದುಕೊಳ್ಳುತ್ತೀರಿ:

- ಅಜೂರ್ ಓಪನ್‌ಎಐ ಮತ್ತು ಪ್ಲೇ ರೈಟ್ ಜೊತೆಗೆ ಬ್ರೌಸರ್-ಬಳಕೆಯನ್ನು ಸಂರಚಿಸುವುದು
- ನಿಜವಾದ ವೆಬ್‌ಸೈಟ್ ನ್ಯಾವಿಗೇಟ್ ಮಾಡುವ ಬ್ರೌಸರ್ ಸ್ವಯಂಚಾಲನಾ ಕಾರ್ಯಚರಣೆಯನ್ನು ನಿರ್ಮಿಸುವುದು ಮತ್ತು ಡೈನಾಮಿಕ್ UI ನಿಬಂಧನೆಗಳನ್ನು ನಿರ್ವಹಿಸುವುದು
- ದೃಶ್ಯ ಪುಟ ವಿಷಯದಿಂದ ಟೈಪ್ ಮಾಡಿದ ಫಲಿತಾಂಶಗಳನ್ನು ಹೊರತೆಗೆಯುವುದು ಮತ್ತು ಅವನ್ನು ಮುಂದಿನ ವ್ಯವಸಾಯ ಲಾಜಿಕ್ ಆಗಿ ಪರಿವರ್ತಿಸುವುದು
- ಬ್ರೌಸರ್ ಕಾರ್ಯವು ನಿಗದಿತವಾಗಿರುವುದರ ಆಧಾರದ ಮೇಲೆ ಏಜೆಂಟ್ ಮತ್ತು ನಟ ಮಾದರಿ ನಡುವೆ ಆಯ್ಕೆ ಮಾಡುವುದು

## ತಂತ್ರಾಂಶ ಮಾದರಿ

ಈ ಪಾಠದಲ್ಲಿ ಒಂದು ನೋಟ್ಬುಕ್ ಟ್ಯುಟೋರಿಯಲ್ ಇದೆ:

- [15-browser-user.ipynb](./15-browser-user.ipynb): CDP ಮೂಲಕ ಕ್ರೋಮ್ సెಷನ್ ಆರಂಭಿಸುತ್ತದೆ, Airbnb ನಲ್ಲಿ ಸ್ಟಾಕ್‌ಹೋಲ್ಮ್ ಲಿಸ್ಟಿಂಗ್‌ಗಳನ್ನು ಹುಡುಕುತ್ತದೆ, ಬ್ರೌಸರ್-ಬಳಕೆ ದೃಷ್ಟಿಯ ಬಳಕೆಯಿಂದ ಬೆಲೆಗಳನ್ನು ಹೊರತೆಗೆಯುತ್ತದೆ ಮತ್ತು ಅತ್ಯಂತ ಅಗ್ಗದ ಆಯ್ಕೆಯನ್ನು ಸಂರಚಿತ ಡೇಟాగా ಹಿಂದಿರುಗಿಸುತ್ತದೆ.

- ಸ್ಥಳೀಯವಾಗಿ ಕ್ರೋಮ್ ಅಥವಾ ಕ್ರೋಮಿಯಂ ಸ್ಥಾಪಿಸಲಾಗಿದೆ
- ಪ್ಲೇ ರೈಟ್ ಅವಲಂಬನೆಗಳು ಸ್ಥಾಪಿಸಲಾಗಿದೆ
- ಅಸಿಂಕ್ Python ಕುರಿತು ಮೂಲ ತಿಳುವಳಿಕೆ

## ವಾಸ್ತುಶಿಲ್ಪ ಅವಲೋಕನ

ನೋಟ್ಬುಕ್ ಒಂದು ಸಂಯುಕ್ತ ಬ್ರೌಸರ್ ಸ್ವಯಂಚಾಲನಾ ಕಾರ್ಯಾಚರಣೆಯನ್ನು ತೋರಿಸುತ್ತದೆ:

1. ಕ್ರೋಮ್ CDP ಸಕ್ರಿಯಗೊಂಡು ಪ್ರಾರಂಭಿಸುತ್ತದೆ, ಆದ್ದರಿಂದ ಪ್ಲೇ ರೈಟ್ ಮತ್ತು ಬ್ರೌಸರ್-ಬಳಕೆ ಒڳ್ರತ ಬ್ರೌಸರ್ ಸೆಷನ್ ಹಂಚಿಕೊಳ್ಳಬಹುದು.
2. ಬ್ರೌಸರ್-ಬಳಕೆ ಏಜೆಂಟ್ ಏರ್‌ಬಿಎನ್‌ಬಿ ತೆರೆಯುವುದು, ಪಾಪ್-ಅಪ್‌ಗಳನ್ನು ತಿರಸ್ಕರಿಸುವುದು, ಮತ್ತು ಸ್ಟಾಕ್‌ಹೋಲ್ಮ್ ಹುಡುಕುವುದು ಮುಂತಾದ ಮ факт ಶರ್ತೀಯ ನ್ಯಾವಿಗೇಶನ್ ಕಾರ್ಯಗಳನ್ನು ನಿರ್ವಹಿಸುತ್ತದೆ.
3. ಸಕ್ರಿಯ ಪುಟವನ್ನು ಸಂರಚಿತ ಪೈಡ್ಯಾಂಟಿಕ್ ಸ್ಕೆಮಾ ಮೂಲಕ ಪರಿಶೀಲಿಸಿ ಲಿಸ್ಟಿಂಗ್ ಶೀರ್ಷಿಕೆಗಳು, ರಾತ್ರಿ ಬೆಲೆಗಳು, ರೇಟಿಂಗ್‌ಗಳು ಮತ್ತು URLಗಳನ್ನು ಹೊರತೆಗೆಯುತ್ತದೆ.
4. ಪೈಥಾನ್ ಲಾಜಿಕ್ ಹೊರತೆಗೆಯಲಾದ ಲಿಸ್ಟಿಂಗ್‌ಗಳನ್ನು ಹೋಲಿಸಿ ಅತ್ಯಂತ ತಗ್ಗಾದ ಫಲಿತಾಂಶವನ್ನು ಜೋತೆಗುಪ್ಪಿಸುತ್ತದೆ.

ಈ ವಿಧಾನವು ಬ್ರೌಸರ್-ಬಳಕೆ ನಲ್ಲಿ ಉತ್ತಮವಾಗಿ ಸಾಧ್ಯವಿರುವ ನಿಬಂಧನ ಗತಿಸುತ್ತಿರುವ ದೃಷ್ಟಿ ಆಧಾರಿತ ನಿರ್ಣಯವನ್ನು ಉಳಿಸುತ್ತದೆ ಮತ್ತು ನೀವು ಬೇಕಾದಾಗ ನಿಗದಿತ ಬ್ರೌಸರ್ ನಿಯಂತ್ರಣ ನೀಡುತ್ತದೆ.

## ಮುಖ್ಯ ಪಾಠಗಳು ಮತ್ತು ಉತ್ತಮ ಅಭ್ಯಾಸಗಳು

### ಏಜೆಂಟ್ ಮತ್ತು ನಟವನ್ನು ಯಾವಾಗ ಬಳಸುವುದು

| ಸ್ಥಿತಿ | ಏಜೆಂಟ್ ಬಳಸು | ನಟ ಬಳಸು |
|----------|-----------|-----------|
| ಚಾಲಕ ವಿನ್ಯಾಸಗಳು | ಹೌದು, AI ಪುಟ ಬದಲಾವಣೆಗಳಿಗೆ ಹೊಂದಿಕೊಳ್ಳಬಹುದು | ಇಲ್ಲ, ಮುರಿದ ಸಿಲೆಕ್ಟರ್ ಗಳು ಮುರಿಯಬಹುದು |
| ತಿಳಿದ ರಚನೆ | ಇಲ್ಲ, ಏಜೆಂಟ್ ನೇರ ನಿಯಂತ್ರಣಕ್ಕಿಂತ ನಿಧಾನವಾಗಿದೆ | ಹೌದು, ವೇಗ ಮತ್ತು ನಿಖರತೆ |
| ಅಂಶಗಳನ್ನು ಹುಡುಕುವುದು | ಹೌದು, ಸ್ವಾಭಾವಿಕ ಭಾಷೆ ಚೆನ್ನಾಗಿ ಕೆಲಸ ಮಾಡುತ್ತದೆ | ಇಲ್ಲ, ನಿಖರ ಸಿಲೆಕ್ಟರ್ ಗಳು ಅಗತ್ಯವಿದೆ |
| ಸಮಯ ನಿಯಂತ್ರಣ | ಇಲ್ಲ, ಕಡಿಮೆ ಊಹಿಸಲಾಗುವುದು | ಹೌದು, ನಿರೀಕ್ಷೆ ಮತ್ತು ಮರುಪ್ರಯತ್ನಗಳ ಮೇಲೆ ಪೂರ್ಣ ನಿಯಂತ್ರಣ |
| ಜಟಿಲ ಕಾರ್ಯಪ್ರವಾಹಗಳು | ಹೌದು, ಅನಿರೀಕ್ಷಿತ UI ಸ್ಥಿತಿಗಳನ್ನು ನಿರ್ವಹಿಸುತ್ತದೆ | ಇಲ್ಲ, ಸ್ಪಷ್ಟ ಶಾಖಾವಳಿ ಬೇಕಾಗುತ್ತದೆ |

### ಬ್ರೌಸರ್-ಬಳಕೆ ಉತ್ತಮ ಅಭ್ಯಾಸಗಳು

1. ಅನ್ವೇಷಣೆ ಮತ್ತು ಚಾಲಕ ನ್ಯಾವಿಗೇಶನ್ ಗೆ ಏಜೆಂಟ್ ಆಗಿ ಪ್ರಾರಂಭಿಸಿ.
2. ಸಂವಹನ ನಿಗದಿತವಾಗುತ್ತಿದ್ದರೆ ನೇರ ಪುಟ ನಿಯಂತ್ರಣಕ್ಕೆ ಬದಲಾಯಿಸಿ.
3. ಹೊರತೆಗೆಯಲಾದ ಡೇಟಾ ಪ್ರಮಾಣಿತಮಾಡಲು ಸಂರಚಿತ ಔಟ್‌ಪುಟ್ ಮಾದರಿಗಳನ್ನು ಬಳಸಿ ಮತ್ತು ಟೈಪ್-ಸುರಕ್ಷಿತವಾಗಿರಲಿ.
4. ಕಾಣಿಸುವ UI ಬದಲಾವಣೆಗಳಿಗೆ ಕಾರಣವಾಗುವ ಕ್ರಿಯೆಗಳ ನಂತರ ತಾಳಮೇಳವಾಗಿ ವಿಳಂಬಗಳನ್ನು ಸೇರಿಸಿ.
5. ವಿಫಲತೆಗಳನ್ನು ಸುಲಭವಾಗಿ ಡಿಬಗ್ ಮಾಡಿಕೊಳ್ಳಲು ಪುಟ ಸೆರೆಹಿಡಿದಿಡಿ.
6. ವೆಬ್‌ಸೈಟ್‌ಗಳು ಬದಲಾಗಬಹುದು ಎಂದು ನಿರೀಕ್ಷಿಸಿ ಮತ್ತು ಪಾಪ್-ಅಪ್‌ಗಳ ಮತ್ತು ವಿನ್ಯಾಸ ಬದಲಾವಣೆಗಳಿಗಾಗಿ ಬ್ಯಾಕ್‌ಅಪ್ ತಂತ್ರಜ್ಞಾನಗಳನ್ನು ವಿನ್ಯಾಸಗೊಳಿಸಿ.
7. ಫ್ಲೆಕ್ಸಿಬಿಲಿಟಿ ಮತ್ತು ನಿಖರತೆ ಎರಡನ್ನೂ ಪಡೆಯಲು ಏಜೆಂಟ್ ಮತ್ತು ನಟ ಮಾದರಿಗಳನ್ನು ಮಿಶ್ರಣ ಮಾಡಿ.

### ನೈಜ ಜಗತ್ತಿನ ಅನ್ವಯಿಕೆಗಳು

- ಪ್ರಯಾಣ বুকಿಂಗ್ ಮತ್ತು ಬೆಲೆ ಮೇಲ್ವಿಚಾರಣೆ
- ಇ-ಕಾಮರ್ಸ್ ಬೆಲೆ ಹೋಲಿಕೆ ಮತ್ತು ಲಭ್ಯತೆ ಪರಿಶೀಲನೆ
- ಡೈನಾಮಿಕ್ ವೆಬ್‌ಸೈಟ್‌ಗಳಿಂದ ಸಂರಚಿತ ಹೊರತೆಗೆಯುವುದು
- ದೃಷ್ಟಿ-ಜ್ಞಾನದ UI ಪರೀಕ್ಷೆ ಮತ್ತು ದೃಢೀಕರಣ
- ವೆಬ್‌ಸೈಟ್ ಮೇಲ್ವಿಚಾರಣೆ ಮತ್ತು ಎಚ್ಚರಿಕೆ
- ಬಹು-ಹಂತದ ಚಾಲಕಗಳಾಗಿರುವ ಬುದ್ಧಿವಂತ ಫಾರ್ಮ್ ಭರ್ತಿಗೆಂದು

## ನೈಜ ಉದಾಹರಣೆ: ಮೈಕ್ರೋಸಾಫ್ಟ್ ಪ್ರಾಜೆಕ್ಟ್ Opal

ಈ ಪಾಠದಲ್ಲಿ ನೀವು ಕಟ್ಟಿದ ಏಜೆಂಟ್ ಒಂದು ಸಣ್ಣ, ಸ್ಥಳೀಯ ಆವೃತ್ತಿಯ **ಕಂಪ್ಯೂಟರ್ ಬಳಕೆ ಏಜೆಂಟ್ (CUA)** — ವ್ಯಕ್ತಿಯಂತೆ ಬ್ರೌಸರ್ ಅನ್ನು ಚಾಲನೆ ಮಾಡುವ ಪ್ರೋಗ್ರಾಂ. ಮೈಕ್ರೋಸಾಫ್ಟ್ 365 ಕೋಪಿಲಟ್‌ನಲ್ಲಿ **[ಪ್ರಾಜೆಕ್ಟ್ Opal (Frontier)](https://support.microsoft.com/en-us/microsoft-365-copilot/get-started-with-project-opal-frontier)** ಎಂಬ ಇಷ್ಟು ಯುಕ್ತಿ ನಡಿಸುತ್ತದೆ.

ಪ್ರಾಜೆಕ್ಟ್ Opal ನಲ್ಲಿ, ನೀವು ಕಾರ್ಯವನ್ನು ವಿವರಿಸುತ್ತೀರಿ ಮತ್ತು ಏಜೆಂಟ್ **Windows 365 ಕ್ಲೌಡ್ PC ಯಲ್ಲಿ ಸುರಕ್ಷಿತ ಕಂಪ್ಯೂಟರ್ ಬಳಕೆಯನ್ನು ಉಪಯೋಗಿಸಿ** ನಿಮ್ಮ ಪರ ಕೆಲಸ ಮಾಡುತ್ತದೆ, ನಿಮ್ಮ ಸಂಸ್ಥೆಯ ಬ್ರೌಸರ್ ಆಧಾರಿತ ಅಪ್ಲಿಕೇಶನ್, ಸೈಟ್‌ಗಳು ಮತ್ತು ಡೇಟಾ ನಡುವೆ ಕಾರ್ಯನಿರ್ವಹಿಸುತ್ತದೆ. ಇದು **ಹಿನ್ನೆಲೆ ನಲ್ಲಿ ಅಸಿಂಕ್ರೋನಸ್ ಆಗಿ ಕಾರ್ಯನಿರ್ವಹಿಸುತ್ತದೆ**, ಮತ್ತು ನೀವು ಯಾವಾಗ ಬೇಕಾದರೂ ಕೆಲಸವನ್ನು ಮಾರ್ಗದರ್ಶನ ಮಾಡಬಹುದು ಅಥವಾ ನಿಯಂತ್ರಣ ತೆಗೆದುಕೊಳ್ಳಬಹುದು. ಉದಾಹರಣೆ ಕೆಲಸಗಳು ಸೇರಿವೆ:

- ಭದ್ರತಾ ಗುಂಪು ಸದಸ್ಯತ್ವ ವಿನಂತಿಗಳನ್ನು ನಿರ್ವಹಿಸುವುದು
- ಅನುಕೂಲತೆಯ ಪರಿಶೀಲನೆಯಿಗಾಗಿ ಆಡಿಟ್ ಸಾಕ್ಷ್ಯ ಸಂಗ್ರಹಣೆ ಮತ್ತು ದೃಢೀಕರಣ
- ಐಟಿ ಘಟನೆಗಳ ತ್ರೈಯಾಜ್ (ಟಿಕೆಟ್ ಸ್ಥಿತಿಯನ್ನು ನವೀಕರಿಸುವುದು, ಮಾಲೀಕರ ನಿಯೋಜನೆ, ನಕಲಿ ವ್ಯವಸ್ಥೆ ಮುಚ್ಚುವುದು)
- ಆರ್ಥಿಕ ಸಮಾರೋಪ ಡೆಕ್ ಗೆ Excel ಡೇಟಾವನ್ನು ಸಂಗ್ರಹಿಸುವುದು

Opal ಒಂದು **ಉತ್ಪಾದನಾ-ಗೇಡ್, ವಿಶ್ವಾಸಾರ್ಹ** ಕಂಪ್ಯೂಟರ್ ಬಳಕೆ ಏಜೆಂಟ್ ಹೇಗಿರಬೇಕು ಎಂಬುದರ ಉಪಯುಕ್ತ ಉಲ್ಲೇಖವಾಗಿದೆ ಮತ್ತು ಹಳೆಯ ಪಾಠಗಳ ಕಲ್ಪನೆಗಳನ್ನು ಬಲಪಡಿಸುತ್ತದೆ:

| ಈ ಪಾಠದ ಕಲ್ಪನೆ | ಪ್ರಾಜೆಕ್ಟ್ Opal ಹೇಗೆ ಅದನ್ನು ಅನ್ವಯಿಸುತ್ತದೆ |
|------------------------|-----------------------------|
| **ಮಾನವ-ನಡೆರಲಾಗು (Lesson 06)** | Opal ಲಾಗಿನ್ ಕ್ರೆಡೆನ್ಷಿಯಲ್ಸ್, ಸಂವೇದನಶೀಲ ಡೇಟಾ ಅಥವಾ ಸ್ಪಷ್ಟವಲ್ಲದ ಸೂಚನೆಗಾಗಿ ವಿರಾಮವನ್ನು ತೆಗೆದುಕೊಳ್ಳುತ್ತದೆ, ಮತ್ತು ಪಾಸ್ವರ್ಡ್‌ಗಳನ್ನು ಅಥವಾ ಫಾರ್ಮ್‌ಗಳನ್ನು ಸ್ಪಷ್ಟ ಅನುಮೋದನೆಯಿಲ್ಲದೆ ಎಂದಿಗೂ ಕೊಡುವುದಿಲ್ಲ. ನೀವು ಮಧ್ಯಕಾಲಕ್ಕೆ *ನಿಯಂತ್ರಣವನ್ನು ತೆಗೆದುಕೊಳ್ಳಬಹುದು* ಮತ್ತು *ನಿಯಂತ್ರಣವನ್ನು ಮರಳಿಸಬಹುದು*. |
| **ವಿಶ್ವಾಸಾರ್ಹ & ಸುರಕ್ಷಿತ ಏಜೆಂಟ್ ಗಳು (ಪಾಠಗಳು 06 & 18)** | ವಿಭಜಿತ Windows 365 ಕ್ಲೌಡ್ PC ನಲ್ಲಿ ಕಾರ್ಯನಿರ್ವಹಿಸುತ್ತದೆ, ಡಿಫಾಲ್ಟ್ ಬ್ರೌಸರ್ ಮಾತ್ರ (ಇತರೆ ಕಂಪ್ಯೂಟರ್ ಪ್ರವೇಶ ತಡೆಯಲ್ಪಟ್ಟಿದೆ, Intune ಮೂಲಕ ಜಾರಿಗೆ), ನಿಮ್ಮ ಸತ್ವವನ್ನು ಬಳಸಿಕೊಂಡು, ನೀವು ಅನುಮೋದಿತಿರುವುದನ್ನಷ್ಟೇ ಪ್ರವೇಶಿಸುತ್ತದೆ ಮತ್ತು ಆಡಿಟ್ ನೋಂದಣಿ ಪ್ರತಿಯೊಂದು ಕ್ರಿಯೆಯನ್ನು ದಾಖಲಿಸುತ್ತದೆ. |
| **পরিকল্পನೆ & ಮेटಾಕಾಗ್ನಿಷನ್ (ಪಾಠಗಳು 07 & 09)** | Opal ಮೊದಲಿಗೆ ಕೆಲಸದ ಯೋಜನೆಯನ್ನು ಸೃಷ್ಟಿಸಿ, ನಂತರ ಪ್ರತಿಯೊಂದು ಹಂತದಲ್ಲಿ ತನ್ನ ತर्कವನ್ನು ಮೇಲ್ವಿಚಾರಣೆ ಮಾಡುತ್ತದೆ ಮತ್ತು ಸಂಶಯಾಸ್ಪದ ಚಟುವಟಿಕೆ ಕಂಡುಬಂದರೆ ವಿರಾಮ ಪಡೆಯುತ್ತದೆ. |
| **ಮರುಬಳಕೆ ಸೂಕ್ತ ಸಾಮರ್ಥ್ಯಗಳು / ಸಾಧನಗಳು (ಪಾಠ 04)** | **ಹುಡುಗಲುಗಳು** ನಿಮಗೆ ಪುನರಾವರ್ತಿತ ಕೆಲಸಗಳಿಗಾಗಿ ಸೂಚನೆಗಳನ್ನು ಬರೆಯಲು ( .md ಕಡತದಿಂದ ಆಮದು ಮಾಡಿಕೊಳ್ಳುವುದು ಅಥವಾ Opal ಮೂಲಕ ರಚಿಸುವುದು) ಮತ್ತು ಸಂವಾದಗಳಲ್ಲಿ ಅವುಗಳನ್ನು ಮರುಬಳಕೆ ಮಾಡಲು ಅವಕಾಶ ನೀಡುತ್ತವೆ. |

> **ಲಭ್ಯತೆ:** ಪ್ರಾಜೆಕ್ಟ್ Opal ಪ್ರಸ್ತುತ [Frontier ಮೊದಲಿಗರ ಪ್ರವೇಶ ಕಾರ್ಯಕ್ರಮ](https://adoption.microsoft.com/copilot/frontier-program/) ನಲ್ಲಿ ಬಳಕೆದಾರರಿಗೆ ಲಭ್ಯವಿದ್ದು, Microsoft 365 Copilot ಚಂದಾದಾರಿಕೆ ಹೊಂದಿರಬೇಕು ಮತ್ತು ನಿಮ್ಮ ನಿರ್ವಾಹಕರು ಸ್ಥಾಪನೆಯನ್ನು ಪೂರ್ಣಗೊಳಿಸಬೇಕು. ಇದು ಪ್ರಯೋಗಾತ್ಮಕ Frontier ವೈಶಿಷ್ಟ್ಯವಾಗಿರುವುದರಿಂದ, ಸಾಮರ್ಥ್ಯಗಳು ಕಾಲಕಾಲಕ್ಕೆ ಬದಲಾಗಬಹುದು.
