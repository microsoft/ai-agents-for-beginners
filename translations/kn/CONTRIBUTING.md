# ಕೊಡುಗೆ ನೀಡುವುದು

ಈ ಯೋಜನೆ ಕೊಡುಗೆಗಳು ಮತ್ತು ಸಲಹೆಗಳನ್ನು ಸ್ವಾಗತಿಸುತ್ತದೆ. ಹೆಚ್ಚಿನ ಕೊಡುಗೆಗಳಿಗೆ ನೀವು Contributor License Agreement (CLA)ಗೆ ಒಪ್ಪಿಗೆ ನೀಡಬೇಕು, ಇದರಲ್ಲಿ ನೀವು ನಿಮ್ಮ ಕೊಡುಗೆಯನ್ನು ಬಳಸಲು ಹಕ್ಕು ಹೊಂದಿದ್ದೀರಿ ಮತ್ತು ವಾಸ್ತವವಾಗಿ ನಾವುಗಳಲ್ಲಿ ಆ ಹಕ್ಕುಗಳನ್ನು ನೀಡುತ್ತೀರಿ ಎಂದು ಘೋಷಿಸಲಾಗುತ್ತದೆ. ವಿವರಗಳಿಗೆ, ವಿ‌ಜಿಟ್ ಮಾಡಿ <https://cla.opensource.microsoft.com>.

ನೀವು ಪಲ್ ರಿಕ್ವೆಸ್ಟ್ ಸಲ್ಲಿಸುವಾಗ, CLA ಬಾಟ್ ಸ್ವಯಂಚಾಲಿತವಾಗಿ ನೀವು CLA ಒದಗಿಸುವುದೇ ಆಗಬೇಕೇ ಎಂಬುದನ್ನು ನಿರ್ಧರಿಸಿ, ಪಲ್ ರಿಕ್ವೆಸ್ಟನ್ನು ಅನುಕೂಲವಾಗಿ ಚಿಹ್ನಿತ ಮಾಡುತ್ತದೆ. ಬಾಟ್ನಿಂದ ನೀಡಲಾದ ಸೂಚನೆಗಳನ್ನು ಅನುಸರಿಸಿ. ಮೈಕ್ರೋಸಾಫ್ಟ್ CLA ಬಳಸುವ ರೆಪೊಗಳಾದ್ಯಂತರ ನೀವು ಇದನ್ನು ಒಮ್ಮೆ ಮಾತ್ರ ಮಾಡಲು ಅಗತ್ಯವಿದೆ.

## ವರ್ತನೆ ನಿಯಮಾವಳಿ

ಈ ಯೋಜನೆ [Microsoft Open Source Code of Conduct](https://opensource.microsoft.com/codeofconduct/) ಅನ್ನು ಅಳವಡಿಸಿಕೊಂಡಿದೆ. ಹೆಚ್ಚಿನ ಮಾಹಿತಿಗೆ, [Code of Conduct FAQ](https://opensource.microsoft.com/codeofconduct/faq/) ವೀಕ್ಷಿಸಿ ಅಥವಾ ಹೆಚ್ಚುವರಿ ಪ್ರಶ್ನೆಗಳು ಅಥವಾ ಟಿಪ್ಪಣಿಗಳಿಗೆ [opencode@microsoft.com](mailto:opencode@microsoft.com) ಅನ್ನು ಸಂಪರ್ಕಿಸಿ.

## ಪಲ್ ರಿಕ್ವೆಸ್ಟ್ ಮಾರ್ಗನಿರ್ದೇಶನಗಳು

- ಪ್ರತಿ ಪಲ್ ರಿಕ್ವೆಸ್ಟ್ ಒಂದೇ ತಾರ್ಕಿಕ ಬದಲಾವಣೆಗೆ ಕೇಂದ್ರಿತವಾಗಿರಲಿ.
- ಸಲ್ಲಿಸುವ ಮೊದಲು ಪ್ರಭಾವಿತ ನೋಟ್ಬುಕ್ಕುಗಳು ಮತ್ತು ಕೋಡ್ ಮಾದರಿಗಳನ್ನು ಪರೀಕ್ಷಿಸಿ.
- ಉದಾಹರಣೆ ಸೇರಿಸುವಾಗ ಅಥವಾ ಬದಲಾಯಿಸುವಾಗ ಸಂಬಂಧಿಸಿದ ಪಾಠದ ದಸ್ತಾವೇಜನ್ನು ನವೀಕರಿಸಿ.
- ಇಂಗ್ಲಿಷ್ ಮೂಲ ವಿಷಯ ಮಾತ್ರ ಸಂಪಾದಿಸಿ. ಅನುವಾದಗಳನ್ನು ಸ್ವಯಂಚಾಲಿತ ಅನುವಾದ ಕಾರ್ಯವಾಹಿಕೆಯಿಂದ ನಿರ್ವಹಿಸಲಾಗುತ್ತದೆ.
- ಪ್ರಮಾಣಪತ್ರಗಳು, `.env` ಫೈಲ್‌ಗಳು, ತಾತ್ಕಾಲಿಕ ಫೈಲ್‌ಗಳು ಅಥವಾ ಸೃಷ್ಟಿಸಲಾದ ಅಭಿವೃದ್ಧಿ ಕಲಾಕೃತಿಗಳನ್ನು ಕಮಿಟ್ ಮಾಡಬೇಡಿ.

## ಸಂಪಾದಕೀಯ ವ್ಯಾಪ್ತಿ ಮತ್ತು ಮೂರನೇ ಪಕ್ಷದ ಉತ್ಪನ್ನಗಳು

ಈ ಪಾಠಕ್ರಮ ಮೈಕ್ರೋಸಾಫ್ಟ್ ತಂತ್ರಜ್ಞಾನಗಳು ಮತ್ತು ವែន್ಡರ್-ನ್ಯೂಟ್ರಲ್ ಮುಕ್ತ ಸ್ಟ್ಯಾಂಡರ್ಡುಗಳ ಮೇಲೆ ಕೇಂದ್ರೀಕರಿಸಿದೆ. ಕೊಡುಗೆಗಳು ಸ್ಪಷ್ಟ ಶೈಕ್ಷಣಿಕ ಉದ್ದೇಶ ಹೊಂದಿರಬೇಕು ಮತ್ತು ಮೂರನೇ ಪಕ್ಷದ ವಾಣಿಜ್ಯ ಉತ್ಪನ್ನ, ಆತಿಥ್ಯ ಸೇವೆ, ಮಾದರಿ ರೂಟರ್, SDK, MCP ಸರ್ವರ್ ಅಥವಾ ಇತರ ವೇವಂದರ್-ನಿರ್ದಿಷ್ಟ ಆಫರಿಂಗ್ ಪರಿಚಯಿಸುವ ಅಥವಾ ಪ್ರಚಾರ ಮಾಡುವನ್ನು ಪ್ರಧಾನವಾಗಿ ಉದ್ದೇಶಿಸಬಾರದು.

ಮುಕ್ತ-ಮೂಲ ಸಾಫ್ಟ್‌ವೇರ್ ಮತ್ತು ಮೂರನೇ ಪಕ್ಷದ ಅವಲಂಬನೆಗಳನ್ನು ಆಯ್ದಿರುವಾಗ ಅವು ಮುಕ್ತ ಸ್ಟ್ಯಾಂಡರ್ಡ್ ಅಥವಾ ಪರಸ್ಪರ ಕಾರ್ಯಗತಾಯಿಕೆ ದೃಶ್ಯವನ್ನು ವಿವರಿಸಲು ಅಗತ್ಯವಿದ್ದಾಗ ಮಾತ್ರ ಉಲ್ಲೇಖಿಸಲಾಗಬಹುದು, ಅವು ತಟಸ್ಥವಾಗಿ ಪ್ರದರ್ಶಿಸಲಾಗುತ್ತಿದ್ದು, ವಿತರಣೆಯ ಉತ್ಪನ್ನ ಅಥವಾ ಆತಿಥ್ಯ ಅಂತಿಮ ಅಂಕವನ್ನು ಕೇಂದ್ರದಲ್ಲಿ ಇರಿಸಲು ಬಾರದು. ನಿಮ್ಮ ಪ್ರಸ್ತಾವಿತ ಕೊಡುಗೆಯಲ್ಲಿ ವಂದ್ರರ-ನಿರ್ದಿಷ್ಟ ಉತ್ಪನ್ನ ಅಥವಾ ಸೇವೆಯನ್ನು ಒಳಗೊಂಡಿದ್ದರೆ, ಸಮಸ್ಯೆಯನ್ನು ತೆರೆಯಿರಿ ಮತ್ತು ಪಲ್ ರಿಕ್ವೆಸ್ಟ್ ಸಲ್ಲಿಸುವ ಮೊದಲು ನಿರ್ವಹಣಾಧಿಕಾರಿಯ ಅನುಮತಿಯನ್ನು ಪಡೆಯಿರಿ.

ಕೊಡುಗಿದಾರರು ತಮ್ಮ ಕೊಡುಗೆಯಲ್ಲಿ ಉಲ್ಲೇಖಿತ ಉತ್ಪನ್ನ ಅಥವಾ ಸೇವೆಯೊಂದಿಗೆ ಸಂಬಂಧಿಸಿದ ಉದ್ಯೋಗ, ಮಂಡಳಿಕೆ, ಪ್ರಾಯೋಜನೆ ಅಥವಾ ಇತರ ಸಂಬಂಧವನ್ನು ಬಹಿರಂಗಪಡಿಸಬೇಕು. ಬೆಂಬಲಿಸದ ಬೆಲೆ, ಕಾರ್ಯಕ್ಷಮತೆ, ಭದ್ರತೆ, ಗುಪ್ತತೆ ಅಥವಾ ಹೋಲಿಕೆದ ಆರೋಪಗಳನ್ನು ಸೇರಿಸಬೇಡಿ. ಚಾಲಿತ ಉದಾಹರಣೆಗಳು ಡಾಟಾ ಕಲಿಯುವವರನ್ನು ಕಳುಹಿಸಬಾರದು ಅಥವಾ ಡಿಫಾಲ್ಟ್ ಮೂಲಕ ಹೊರಗಿನ ಮೂರನೇ ಪಕ್ಷದ ಸೇವೆಯ ಮೂಲಕ ಸಾರ್ವಜನಿಕ ಕ್ರಿಯೆಗಳನ್ನು ಮಾಡಬಾರದು.
