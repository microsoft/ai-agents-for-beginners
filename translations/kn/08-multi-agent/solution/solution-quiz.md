# ಜ್ಞಾನ ಪರಿಶೀಲನೆ ಉತ್ತರಗಳು

## ಪ್ರಶ್ನೆ 1

**ಉತ್ತರ: A2.** ಬಹು ಏಜೆಂಟ್‌ಗಳು ತಯಾರಾಗುತ್ತವೆ ಅವರುಗಳ ಪ್ರಾಥಮಿಕ ತಂತ್ರಗಾರಿಕ ಪಾತ್ರಗಳಿರುವ ಕಾರ್ಯಕ್ಕಾಗಿ ಉಪಯುಕ್ತವಾಗಿವೆ, ಬೇರೆ ಬೇರೆ ಉಪಕರಣಗಳು ಅಥವಾ ಅನುಮತಿಗಳು ಮತ್ತು ಸ್ಪಷ್ಟ ಹಸ್ತಾಂತರಗಳ ಸಂಯೋಜನೆ ಅಗತ್ಯವಿದೆ. ಸರಳ ಬೆಂಬಲ ಬಾಟ್ ಸಾಮಾನ್ಯವಾಗಿ ಒಂದು ಏಜೆಂಟ್ ಮಾತ್ರವಾಗಿರಬಹುದು. ಒಂದೇ ರೀತಿಯ ಹೆಚ್ಚಿನ ವಿನಂತಿಗಳ ಹಣತೆ ಮುಖ್ಯವಾಗಿ ಮಾಪನದ ಸಮಸ್ಯೆಯಾಗಿರುತ್ತದೆ ಮತ್ತು ಅದರಿಂದಲೇ ಬಹು ಏಜೆಂಟ್ ವಿನ್ಯಾಸ ಅಗತ್ಯವಿಲ್ಲ.

## ಪ್ರಶ್ನೆ 2

**ಉತ್ತರ: A1.** ಒಂದು ಏಜೆಂಟ್ ಸಾಮಾನ್ಯವಾಗಿ ಪರೀಕ್ಷಿಸಲು, ಗಮನಿಸಲು ಮತ್ತು ಕಾರ್ಯಾಚರಿಸಲು ಸುಲಭವಾಗಿರುತ್ತದೆ, ಒಂದು ಸೂಚನಾ ಮತ್ತು ಉಪಕರಣಗಳ ಸರಣಿಯು ಕಾರ್ಯವನ್ನು ನಿರ್ವಹಿಸಬಲ್ಲಾಗಿರುವಾಗ. ಹಲವಾರು ಉಪಕರಣಗಳ ಪ್ರವೇಶವು ಸ್ವತಃ ಹಲವಾರು ಏಜೆಂಟ್‌ಗಳನ್ನು ಅಗತ್ಯವಿಲ್ಲ ಮಾಡುತ್ತದೆ. ಬೇರೆ ಬೇರೆ ಅನುಮತಿಗಳ ಮತ್ತು ಖಚಿತಪರೀಕ್ಷೆಯ ಅವಶ್ಯಕತೆಗಳಿರುವ ವಿಭಿನ್ನ ಪಾತ್ರಗಳು ಬಹು ಏಜೆಂಟ್ ವಿನ್ಯಾಸಕ್ಕೆ ನ್ಯಾಯಸಮ್ಮತವಾಗಬಹುದು.
