## 💻 ಕೋಡ್ ಕೂಡಲೇ ನಡೆಯಿಸುವುದು

ಸಂಪೂರ್ಣ ಅನುಷ್ಠಾನವು `03.dotnet-agent-framework-workflow-ghmodel-concurrent.cs` ನಲ್ಲಿ ಲಭ್ಯವಿದ್ದು, ಇದು ಗಡಿಬಿಡಿ ಕಾಯ್ದುಕೊಳ್ಳುವ **ಫ್ಯಾನ್-ಔಟ್/ಫ್ಯಾನ್-ಇನ್ ಸಮಕಾಲೀನ ವರ್ಕ್‌ಫ್ಲೋ** ಅನ್ನು ತೋರಿಸುತ್ತದೆ:

### 🏗️ **ವರ್ಕ್‌ಫ್ಲೋ ನಿಲ್ಲವಣಿಗೆ**

```
User Request → ConcurrentStartExecutor → [Researcher Agent || Planner Agent] → ConcurrentAggregationExecutor → Final Output
```

**ಮುಖ್ಯ ಘಟಕಗಳು:**

1. **ConcurrentStartExecutor**: ಎಲ್ಲಾ ಏಜೆಂಟ್‌ಗಳಿಗೆ ಬಳಕೆದಾರ ವಿನಂತಿಯನ್ನು ಒಂದೇ ಸಮಯದಲ್ಲಿ ಪ್ರಸಾರ ಮಾಡುತ್ತದೆ
2. **ಸೇರಿದಾರ ಏಜೆಂಟ್**: ಗಮ್ಯಸ್ಥಾನಗಳ ಮತ್ತು ಆಕರ್ಷಣೆಗಳ ಸಮಕಾಲೀನ ವಿಶ್ಲೇಷಣೆ
3. **ಯೋಜನೆಗಾರ ಏಜೆಂಟ್**: ವಿವರವಾದ ಪ್ರಯಾಣ ಯೋಜನೆಗಳನ್ನು ಸಮಕಾಲೀನವಾಗಿ ರಚಿಸುತ್ತದೆ
4. **ConcurrentAggregationExecutor**: ಇಬ್ಬರು ಏಜೆಂಟ್‌ಗಳಿಂದ ಫಲಿತಾಂಶಗಳನ್ನು ಸಂಗ್ರಹಿಸಿ ಮಿಶ್ರಣ ಮಾಡುತ್ತದೆ

- **ಸಮಕಾಲೀನ ಸಂಸ್ಕರಣೆ**: ಅನೇಕ ಏಜೆಂಟ್‌ಗಳು ಒಂದೇ ಕೆಲಸದಲ್ಲಿ ಸಮಾಂತರವಾಗಿ ಕಾರ್ಯನಿರ್ವಹಿಸುತ್ತವೆ

### 🎯 ನೈಜ-ಜಗತ್ತಿನ ಅನ್ವಯಿಕೆಗಳು

ಈ ಸಮಕಾಲೀನ ಮಾದರಿ ಈ ಕೆಳಗಿನವರಿಗೆ ಸೂಕ್ತವಾಗಿದೆ:
- **ವಿಷಯ ರಚನೆ**: ಅನೇಕ ಲೇಖಕರು ವಿಭಿನ್ನ ವಿಭಾಗಗಳನ್ನು ಒಂದೇ ಸಮಯದಲ್ಲಿ ರಚಿಸುತ್ತಾರೆ
- **ಕೋಡ್ ವಿಮರ್ಶೆ**: ಅನೇಕ ವಿಮರ್ಶಕರು ವಿಭಿನ್ನ ದೃಷ್ಟಿಕೋನಗಳಿಂದ ಕೋಡ್ ವಿಮರ್ಶಿಸುತ್ತಾರೆ
- **ಬಜಾರ್ ಸಂಶೋಧನೆ**: ವಿಭಿನ್ನ ಮಾರುಕಟ್ಟೆ ವಿಭಾಗಗಳ ಸಮಾಂತರ ವಿಶ್ಲೇಷಣೆ
- **ಡಾಕ್ಯುಮೆಂಟ್ ಸಂಸ್ಕರಣೆ**: ಸಮಕಾಲೀನ ಆವೃತ್ತಿ, ವಿಶ್ಲೇಷಣೆ ಮತ್ತು ಮಾನ್ಯತೆ
- **ಬಹು ದೃಷ್ಟಿಕೋನ ವಿಶ್ಲೇಷಣೆ**: ಒಂದೇ ಇನ್‌ಪುಟ್ ಮೇಲಿನ ವೈವಿಧ್ಯಮಯ ದೃಷ್ಟಿಕೋನಗಳು

### 🔍 ಕಸ್ಟಮ್ ಕಾರ್ಯಗತಗೊಳಿಸುವವರನ್ನು ಅರ್ಥಮಾಡಿಕೊಳ್ಳುವುದು

**ConcurrentStartExecutor:**
- `IMessageHandler<string>` ಅನ್ನು ಅನುಷ್ಠಾನಗೊಳಿಸುತ್ತದೆ, כדי ಸ್ಟ್ರಿಂಗ್ ಇನ್‌ಪುಟ್ ಸ್ವೀಕರಿಸಲು
- 모든 ಸಂಪರ್ಕ된 ಏಜೆಂಟ್‌ಗಳಿಗೆ ಸಂದೇಶಗಳನ್ನು ಪ್ರಸಾರ ಮಾಡುತ್ತದೆ
- ಸಮಕಾಲೀನ ಕಾರ್ಯಾಚರಣೆ ಪ್ರಾರಂಭಿಸಲು `TurnToken` ಅನ್ನು ಕಳುಹಿಸುತ್ತದೆ

**ConcurrentAggregationExecutor:**
- `IMessageHandler<ChatMessage>` ಅನ್ನು ಅನುಷ್ಠಾನಗೊಳಿಸಿ ಏಜೆಂಟ್ ಪ್ರತಿಕ್ರಿಯೆಗಳನ್ನು ಸ್ವೀಕರಿಸುತ್ತದೆ
- ಸಂದೇಶಗಳನ್ನು ಧಾರ್ಮಿಕವಾಗಿ ಸಂಗ್ರಹಿಸುತ್ತದೆ
- ಎಲ್ಲಾ ನಿರೀಕ್ಷಿತ ಪ್ರತಿಕ್ರಿಯೆಗಳು ಬಂದಾಗ ಸಂಯೋಜಿಸುತ್ತದೆ
- `context.YieldOutputAsync()` ಬಳಸಿ ಅಂತಿಮ ಔಟ್‌ಪುಟ್ ನೀಡುತ್ತದೆ

### ⚡ ಕಾರ್ಯಕ್ಷಮತಾ ಪ್ರಯೋಜನಗಳು

**ಸಮಕಾಲೀನ vs ಕ್ರಮಬದ್ಧ:**
- ಕ್ರಮಬದ್ಧ: ಏಜೆಂಟ್1 (30ಸೆ) → ಏಜೆಂಟ್2 (30ಸೆ) = **ಒಟ್ಟು 60 ಸೆಕೆಂಡುಗಳು**
- ಸಮಕಾಲೀನ: ಏಜೆಂಟ್1 (30ಸೆ) || ಏಜೆಂಟ್2 (30ಸೆ) = **ಒಟ್ಟು 30 ಸೆಕೆಂಡುಗಳು**

**ಉತ್ಪಾದಕತೆಯ ಸುಧಾರಣೆ**: N ಸಮಕಾಲೀನ ಏಜೆಂಟ್‌ಗಳಿಗೆ N× ವೇಗವಾಗಿ (ಕಾರ್ಯಭಾರ ಮತ್ತು ವನಸಂಪತ್ತು ಅವಲಂಬಿಸಿದೆ)
