# ⚡ ಏಝುರ್ ಓಪನ್‌ಎಐ (ಪ್ರತಿಕ್ರಿಯೆಗಳು API) (.NET) ಸಹಿತ ಸಂಯುಕ್ತ ಏಜೆಂಟ್ ವರ್ಕ್‌ಫ್ಲೋಗಳು

## 📋 ಅತ್ಯುತ್ತಮ ಕಾರ್ಯಕ್ಷಮತೆ ಹೊಂದಿದ ಪ್ಯಾರಲಲ್ ಪ್ರಾಸೆಸಿಂಗ್ ಟ್ಯುಟೋರಿಯಲ್

ಈ ನೊಟ್‌ಬುಕ್ ಗಳು Microsoft Agent Framework for .NET ಮತ್ತು ಏಝುರ್ ಓಪನ್‌ಎಐ (ಪ್ರತಿಕ್ರಿಯೆಗಳು API) ಬಳಸಿ **ಸಂಯುಕ್ತ ವರ್ಕ್‌ಫ್ಲೋ ಮಾದರಿಗಳನ್ನು** ಪ್ರದರ್ಶಿಸುತ್ತದೆ. ನೀವು ಹಲವು AI ಏಜೆಂಟ್‌ಗಳನ್ನು ಒಟ್ಟಿಗೆ ಕಾರ್ಯಗತಗೊಳಿಸುವ ಮೂಲಕ ಗರಿಷ್ಟ ಥ್ರೂಪ್‌ಪುಟ್ ಹೆಚ್ಚಿಸುವ ಮತ್ತು ಸಂಯೋಜನೆ ಮತ್ತು ಡೇಟಾ ಅನುಕೂಲತೆ ಕಾಪಾಡಲು ಹೈ-ಪರ್ಫಾರ್ಮೆನ್ಸ್, ಪ್ಯಾರಲಲ್ ಪ್ರಾಸೆಸಿಂಗ್ ವರ್ಕ್‌ಫ್ಲೋಗಳನ್ನು ನಿರ್ಮಿಸುವ ವಿಧಾನವನ್ನು ಕಲಿತೀರಿ.

- **ಆಸಿಂಕ್/ಅವೈಟ್ ಮಾದರಿಗಳು**: .NET ನ ಆಸಿಂಕ್ ಪ್ರೋಗ್ರಾಮಿಂಗ್ ಮಾದರಿಯನ್ನು ಪರಿಣಾಮಕಾರಿ ಸಂಯುಕ್ತತೆಗೆ ಉಪಯೋಗಿಸಿ

### 🏢 **ಎಂಟರ್ಪ್ರೈಸ್ ಸಂಯುಕ್ತ ಅಪ್ಲಿಕೆಯಶನ್‌ಗಳು**

- **ಮಲ್ಟಿ-ಮೋಡಲ್ ವಿಶ್ಲೇಷಣೆ**: ವಿಭಿನ್ನ ವಿಷಯ ಪ್ರಕಾರಗಳು ಮತ್ತು ಸ್ವರೂಪಗಳ ಪ್ಯಾರಲಲ್ ಪ್ರಾಸೆಸಿಂಗ್

### 📦 **ಅವಶ್ಯಕ NuGet ಪ್ಯಾಕೇಜುಗಳು**

ಅತ್ಯುತ್ತಮ ಕಾರ್ಯಕ್ಷಮತೆಯ ಸಂಯುಕ್ತ ವರ್ಕ್‌ಫ್ಲೋಗಳಿಗೆ ಅಗತ್ಯ ಪ್ಯಾಕೇಜುಗಳು:

```xml

<!-- Azure OpenAI (Responses API) -->

<!-- Azure Identity and Async LINQ for Advanced Operations -->
<PackageReference Include="Azure.Identity" Version="1.15.0" />
<PackageReference Include="System.Linq.Async" Version="6.0.3" />

<!-- Local Agent Framework References -->
<!-- Microsoft.Agents.AI.dll - Core agent abstractions with async support -->
<!-- Microsoft.Agents.AI.OpenAI.dll - Azure OpenAI (Responses API) integration with concurrency -->
```

1. **ConcurrentStartExecutor**: ಬಳಕೆದಾರ ವಿನಂತಿಯನ್ನು ಎಲ್ಲ ಏಜೆಂಟ್‌ಗಳಿಗೆ ಒಟ್ಟಿಗೆ ಪ್ರಸಾರ ಮಾಡುತ್ತದೆ
2. **Researcher Agent**: ಗಂತವ್ಯಗಳು ಮತ್ತು ಆಕರ್ಷಣೆಗಳನ್ನು ಸಂಯುಕ್ತವಾಗಿ ವಿಶ್ಲೇಷಿಸುತ್ತದೆ
3. **Planner Agent**: ವಿವರವಾದ ಪ್ರವಾಸ ಯೋಜನೆಗಳನ್ನು ಸಂಯುಕ್ತವಾಗಿ ರಚಿಸುತ್ತದೆ
4. **ConcurrentAggregationExecutor**: ಎರಡೂ ಏಜೆಂಟ್‌ಗಳಿಂದ ಫಲಿತಾಂಶಗಳನ್ನು ಸಂಗ್ರಹಿಸಿ ಮಿಶ್ರಣ ಮಾಡುತ್ತದೆ

### 🎯 ವಾಸ್ತವ ಜಗತ್ತಿನ ಅಪ್ಲಿಕೆಯಶನ್‌ಗಳು

- **ಮಾರ್ಕೆಟ್ ಸಂಶೋಧನೆ**: ವಿಭಿನ್ನ ಮಾರುಕಟ್ಟೆ ವಿಭಾಗಗಳ ಪ್ಯಾರಲಲ್ ವಿಶ್ಲೇಷಣೆ
- **ದಸ್ತಾವೇಜು ಪ್ರಾಸೆಸಿಂಗ್**: ಸಂಯುಕ್ತ ಎಕ್ಸ್ಟ್ರಾಕ್ಷನ್, ವಿಶ್ಲೇಷಣೆ ಮತ್ತು ಮಾನ್ಯತೆ
- **ಬಹು-ಕನ್ನಡೃಷ್ಟ ದೃಷ್ಟಿಕೋಣಗಳು**: ಒಂದೇ ಇನ್‌ಪುಟ್ ಮೇಲೆ ವಿಭಿನ್ನ ದೃಷ್ಟಿಕೋಣಗಳನ್ನು ಪಡೆಯುವುದು

**ConcurrentStartExecutor:**
- `IMessageHandler<string>` ಅನ್ನು ಅನುಷ್ಠಾನಗೊಳಿಸುತ್ತದೆ, ಸ್ಟ್ರಿಂಗ್ ಇನ್‌ಪುಟ್ ಅನ್ನು ಸ್ವೀಕರಿಸಲು
- ಸಂಪರ್ಕಗೊಂಡ ಎಲ್ಲಾ ಏಜೆಂಟ್‌ಗಳಿಗೆ ಸಂದೇಶಗಳನ್ನು ಪ್ರಸಾರ ಮಾಡುತ್ತದೆ
- ಸಂಯುಕ್ತ ಪ್ರಾಸೆಸಿಂಗ್ ಪ್ರಾರಂಭಿಸಲು `TurnToken` ಕಳುಹಿಸುತ್ತದೆ

- ಎಲ್ಲ ನಿರೀಕ್ಷಿತ ಪ್ರತಿಕ್ರಿಯೆಗಳು ಬಂದಾಗ ಸಂಯೋಜನೆ ಮಾಡುತ್ತದೆ
- `context.YieldOutputAsync()` ಬಳಸಿ ಅಂತಿಮ ಔಟ್‌ಪುಟ್ ನೀಡುತ್ತದೆ
