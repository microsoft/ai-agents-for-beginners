# ⚡ ಅಜುರ್ OpenAI (Responses API) (.NET) ಬಳಸಿ ಸಮಕಾಲೀನ ಏಜೆಂಟ್ ಕಾರ್ಯಪ್ರवाहಗಳು

## 📋 ಹೆಚ್ಚಿನ ಕಾರ್ಯಕ್ಷಮತೆಯ ಪ್ಯಾರಲೆಲ್ ಪ್ರಕ್ರಿಯೆ ಪಾಠದಾರಿಕೆ

ಈ ನೋಟ್‌ಬುಕ್ Microsoft Agent Framework for .NET ಮತ್ತು ಅಜುರ್ OpenAI (Responses API) ಬಳಸಿ **ಸಮಕಾಲೀನ ಕಾರ್ಯಪ್ರवाह ಮಾದರಿಗಳನ್ನು** ಪ್ರದರ್ಶಿಸುತ್ತದೆ. ಸಮ್ಮೇಳನ ಮತ್ತು ಡೇಟಾ ಸಮ್ಮಿತಿ ಕಾಯ್ದುಕೊಳ್ಳುವಾಗ ಹಲವು AI ಏಜೆಂಟ್‌ಗಳನ್ನು ಸಮಕಾಲೀನವಾಗಿ ಕಾರ್ಯಗತಗೊಳಿಸುವ ಮೂಲಕ ತಲುಪುವಿಕೆ ಗರಿಷ್ಠಮಾಡುವ ಹೆಚ್ಚಿನ ಕಾರ್ಯಕ್ಷಮತೆಯ ಪ್ಯಾರಲೆಲ್ ಪ್ರಕ್ರಿಯೆ ಕಾರ್ಯಪ್ರವಾಹಗಳನ್ನು ನೀವು ನಿರ್ಮಿಸುವುದನ್ನು ಕಲಿಯುತ್ತೀರಿ.

## 🎯 ಅಧ್ಯಯನ ಉದ್ದೇಶಗಳು

### 🚀 **ಸಮಕಾಲೀನ ಪ್ರಕ್ರಿಯೆ ಮೂಲಭೂತಗಳು**
- **ಪ್ಯಾರಲೆಲ್ ಏಜೆಂಟ್ ಕಾರ್ಯಗತಗೊಳಿಸುವಿಕೆ**: ಗರಿಷ್ಠ ಕಾರ್ಯಕ್ಷಮತೆಯಿಗಾಗಿ ಹಲವಾರು AI ಏಜೆಂಟ್‌ಗಳನ್ನು ಸಮಕಾಲೀನವಾಗಿ ಚಾಲನೆ ಮಾಡುವುದು
- **ಆಸಿಂಕ್/ಅವೇಟ್ ಮಾದರಿಗಳು**: ಪರಿಣಾಮಕಾರಿಯಾದ ಸಮಕಾಲೀನತೆಗಾಗಿ .NET ನ ಆಸಿಂಕ್ ಪ್ರೋಗ್ರಾಮಿಂಗ್ ಮಾದರಿಯನ್ನು ಉಪಯೋಗಿಸುವುದು
- **ಅಜುರ್ OpenAI (Responses API)**: ಅಜುರ್ OpenAI ಪ್ರತಿಕ್ರಿಯೆಗಳು API ಗೆ ಒಂದುಗೂಡಿದ ಸಾಮಾನ್ಯ ಕರೆಗಳನ್ನು ಸಂಯೋಜಿಸುವುದು
- **ಸಂಪನ್ಮೂಲ ನಿರ್ವಹಣೆ**: ಸಮಕಾಲೀನ ಕಾರ್ಯಾಚರಣೆಗಳ ನಡುವೆ AI ಮಾದರಿ ಸಂಪನ್ಮೂಲಗಳನ್ನು ಪರಿಣಾಮಕಾರಿಯಾಗಿ ನಿರ್ವಹಿಸುವುದು

### 🏗️ **ಅಗತ್ಯವಿರುವ ಸಮಕಾಲೀನ ಆರ್ಕಿಟೆಕ್ಚರ್**
- **ಟಾಸ್ಕ್ ಆಧಾರಿತ ಪ್ಯಾರಲೆಲಿಸಮ್**: ಗರಿಷ್ಠ ಸಮಕಾಲೀನ ಕಾರ್ಯಗತಗೊಳಿಸುವಿಕೆಗೆ .NET Task Parallel Library ಬಳಸದಿಕೊಳ್ಳುವುದು
- **ಸಂಯೋಜನೆ ಮಾದರಿಗಳು**: ಸಾಮರಸ್ಯದಲ್ಲಿನ ಏಜೆಂಟ್‌ಗಳನ್ನು ಸಂಯೋಜಿಸುವುದು ಮತ್ತು ರೇಸ್ ಪರಿಸ್ಥಿತಿಗಳನ್ನು ತಪ್ಪಿಸುವುದು
- **ಲೋಡ್ ಎಲ್ಲೋಕೆಷನ್**: ಲಭ್ಯವಿರುವ ಸಮಕಾಲೀನ ಪ್ರಕ್ರಿಯೆ ಸಾಮರ್ಥ್ಯದ ಮೇಲೆ ಕೆಲಸವನ್ನು ಪರಿಣಾಮಕಾರಿಯಾಗಿ ವಿತರಿಸುವುದು
- **ದೋಷ ಸಹನಶೀಲತೆ**: ಸಂಪೂರ್ಣ ಕಾರ್ಯಪ್ರವಾಹ ನಿಲ್ಲಿಸುವದೇನು, ಪ್ರತ್ಯೇಕ ಏಜೆಂಟ್ ವೈಫಲ್ಯಗಳನ್ನು ನಿರ್ವಹಿಸುವುದು

### 🏢 **ಸಂಸ್ಥೆಯ ಸಮಕಾಲೀನ ಅನ್ವಯಿಕೆಗಳು**
- **ಹೆಚ್ಚಿನ ಪ್ರಮಾಣದ ದಸ್ತಾವೇಜು ಪ್ರಕ್ರಿಯೆ**: ಒಂದೇ ಸಮಯದಲ್ಲಿ ಹಲವಾರು ದಸ್ತಾವೇಜುಗಳನ್ನು ಪ್ರಕ್ರಿಯೆ ಮಾಡುವುದು


**ಪ್ರಮುಖ ಘಟಕಗಳು:**

1. **ConcurrentStartExecutor**: ಬಳಕೆದಾರ ವಿನಂತಿಯನ್ನು ಎಲ್ಲ ಏಜೆಂಟ್‌ಗಳಿಗೆ ಒಂದೇ ಸಮಯದಲ್ಲಿ ಪ್ರಸಾರ ಮಾಡುತ್ತದೆ
2. **Researcher Agent**: ಗಮ್ಯದ ಸ್ಥಳಗಳು ಮತ್ತು ಆಕರ್ಷಣೆಗಳನ್ನು ಸಮಕಾಲೀನವಾಗಿ ವಿಶ್ಲೇಷಿಸುತ್ತಾನೆ
3. **Planner Agent**: ವಿವರವಾದ ಪ್ರವಾಸ ಯೋಜನೆಗಳನ್ನು ಸಮಕಾಲೀನವಾಗಿ ರಚಿಸುತ್ತದೆ
4. **ConcurrentAggregationExecutor**: ಎರಡೂ ಏಜೆಂಟ್‌ಗಳಿಂದ ಫಲಿತಾಂಶಗಳನ್ನು ಸಂಗ್ರಹಿಸಿ ಒಗ್ಗೂಡಿಸುತ್ತದೆ

- **ದಸ್ತಾವೇಜು ಪ್ರಕ್ರಿಯೆ**: ಸಮಕಾಲೀನವಾಗಿ ಹೊರತೆಗೆಯುವಿಕೆ, ವಿಶ್ಲೇಷಣೆ, ಮತ್ತು ಮಾನ್ಯತೆ

### 🔍 ಕಸ್ಟಮ್ Executors ಅರ್ಥ ಮಾಡಿಕೊಳ್ಳುವುದು

**ConcurrentStartExecutor:**
- ಸ್ಟ್ರಿಂಗ್ ಇನ್ಪುಟ್ ಸ್ವೀಕರಿಸಲು `IMessageHandler<string>` ಅನ್ನು ಅನುಷ್ಠಾನಗೊಳಿಸುತ್ತದೆ
- ಎಲ್ಲಾ ಜೋಡಿಸಲಾದ ಏಜೆಂಟ್‌ಗಳಿಗೆ ಸಂದೇಶಗಳನ್ನು ಪ್ರಸಾರ ಮಾಡುತ್ತದೆ
- ಸಮಕಾಲೀನ ಪ್ರಕ್ರಿಯೆ ಪ್ರಾರಂಭಿಸಲು `TurnToken` ಕಳುಹಿಸುತ್ತದೆ

**ConcurrentAggregationExecutor:**
- ಏಜೆಂಟ್ ಪ್ರತಿಕ್ರಿಯೆಗಳನ್ನು ಸ್ವೀಕರಿಸಲು `IMessageHandler<ChatMessage>` ಅನ್ನು ಅನುಷ್ಠಾನಗೊಳಿಸುತ್ತದೆ
- ಥ್ರೆಡ್-ಸೇಫ್ ರೀತಿಯಲ್ಲಿ ಸಂದೇಶಗಳನ್ನು ಸಂಗ್ರಹಿಸುತ್ತದೆ
- ನಿರೀಕ್ಷಿತ ಫಲಿತಾಂಶಗಳು ಎಲ್ಲ ಬಂದಾಗ ಒಗ್ಗೂಡಿಸುತ್ತದೆ
- `context.YieldOutputAsync()` ಮೂಲಕ ಅಂತಿಮ ಫಲಿತಾಂಶ ನೀಡುತ್ತದೆ

### ⚡ ಕಾರ್ಯಕ್ಷಮತಾ ಲಾಭಗಳು

**ಸಮಕಾಲೀನ vs ಕ್ರಮಬದ್ಧ:**
- ಕ್ರಮಬದ್ಧ: Agent1 (30s) → Agent2 (30s) = **ಒಟ್ಟು 60 ಸೆಕೆಂಡುಗಳು**
- ಸಮಕಾಲೀನ: Agent1 (30s) || Agent2 (30s) = **ಒಟ್ಟು 30 ಸೆಕೆಂಡುಗಳು**

**ತಲುಪುವಿಕೆ ಸುಧಾರಣೆ**: N ಸಮಕಾಲೀನ ಏಜೆಂಟ್‌ಗಳಿಗೆ N× ವೇಗವಾಗಿ (ಕೆಲಸದ ಭಾರ ಮತ್ತು ಸಂಪನ್ಮೂಲಗಳ ಮೇಲೆ ಅವಲಂಬಿತ)
