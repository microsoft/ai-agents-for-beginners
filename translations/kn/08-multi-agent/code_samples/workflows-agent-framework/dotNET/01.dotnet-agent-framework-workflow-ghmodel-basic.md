# 🔄 ಅಜುರ್ ಓಪನ್‌ಎಐ (ಪ್ರತಿಕ್ರಿಯೆಗಳು API) ಜೊತೆಗೆ ಮೂಲಭೂತ ಏಜೆಂಟ್ ಕೆಲಸದ ಪ್ರವಾಹಗಳು (.NET)

## 📋 ಕೆಲಸದ ಪ್ರವಾಹ ಸಂಯೋಜನೆ ಪಾಠક્રમ

ಈ ನೋಟುಬುಕ್ ಮೈಕ್ರೋಸಾಫ್ಟ್ ಏಜೆಂಟ್ ಫ್ರೇಮುರ್ಕ್ ಫಾರ್ .NET ಮತ್ತು ಅಜುರ್ ಓಪನ್‌ಎಐ (ಪ್ರತಿಕ್ರಿಯೆಗಳು API) ಬಳಸಿ ಸಂಯೋಜಿತ **ಏಜೆಂಟ್ ಕೆಲಸದ ಪ್ರವಾಹಗಳನ್ನು** ಹೇಗೆ ನಿರ್ಮಿಸುವುದೆಂದು ಪ್ರದರ್ಶಿಸುತ್ತದೆ. AI ಏಜೆಂಟ್ಗಳು ಜಟಿಲ ಕಾರ್ಯಗಳನ್ನು ಪೂರೈಸಲು ರಚಿತ ಸಂಯೋಜನಾ ಮಾದರಿಗಳ ಮೂಲಕ ಸಹಕಾರ ಮಾಡುವ ಬಹುಹಂತ ವ್ಯವಹಾರ ಪ್ರಕ್ರಿಯೆಗಳನ್ನು ರಚಿಸುವುದನ್ನು ನೀವು ಕಲಿಯುತ್ತೀರಿ.

## 🎯 ಕಲಿಕೆ ಗುರಿಗಳು

### 🏗️ **ಕೆಲಸದ ಪ್ರವಾಹ ವಿನ್ಯಾಸ ಶಿಸ್ತಿನ ಅಂಶಗಳು**
- **ಕೆಲಸದ ಪ್ರವಾಹ ನಿರ್ಮಾಪಕ**: ಜಟಿಲ ಬಹುಹಂತ AI ಪ್ರಕ್ರಿಯೆಗಳನ್ನು ವಿನ್ಯಾಸಗೊಳಿಸಿ ಸಂಯೋಜಿಸಿ
- **ಏಜೆಂಟ್ ಸಂಯೋಜನೆ**: ಕೆಲಸದ ಪ್ರವಾಹಗಳಲ್ಲಿ ಬಹು ವಿಶೇಷಿತ ಏಜೆಂಟ್‌ಗಳನ್ನು ಸಂಯೋಜಿಸಿ
- **ಅಜುರ್ ಓಪನ್‌ಎಐ (ಪ್ರತಿಕ್ರಿಯೆಗಳು API)**: ಕೆಲಸದ ಪ್ರವಾಹಗಳಲ್ಲಿ ಅಜುರ್ ಓಪನ್‌ಎಐ ಪ್ರತಿಕ್ರಿಯೆಗಳು API ಉಪಯೋಗಿಸಿ
- **ದೃಶ್ಯ ಕೆಲಸದ ಪ್ರವಾಹ ವಿನ್ಯಾಸ**: ಉತ್ತಮ ಅರ್ಥಮಾಡಿಕೊಳ್ಳಲು ಕೆಲಸದ ಪ್ರವಾಹ ರಚನೆಗಳನ್ನು ಸೃಷ್ಟಿಸಿ ಮತ್ತು ದೃಶ್ಯೀಕರಿಸಿ

### 🔄 **ಪ್ರಕ್ರಿಯೆ ಸಂಯೋಜನಾ ಮಾದರಿಗಳು**
- **ಕ್ರಮಬದ್ಧ ಪ್ರಕ್ರಿಯೆ**: ತಾರ್ಕಿಕ ಕ್ರಮದಲ್ಲಿ ಬಹು ಏಜೆಂಟ್ ಕಾರ್ಯಗಳನ್ನು ಸರಪಳಿ ಮಾಡುವುದು
- **ಸ್ಥಿತಿ ನಿರ್ವಹಣೆ**: ಕೆಲಸದ ಪ್ರವಾಹ ಹಂತಗಳಲ್ಲಿ ಸನ್ನಿವೇಶ ಮತ್ತು ಡೇಟಾ ಹರಿವನ್ನು ನಿರ್ವಹಿಸಿ
- **ದೋಷ ನಿರ್ವಹಣೆ**: ಬಲಿಷ್ಠ ದೋಷ ಪುನರಾದಾಯವಾಗಿಸುವಿಕೆ ಮತ್ತು ಕೆಲಸದ ಪ್ರವಾಹ ಸ್ಥೈರ್ಯವನ್ನು ಜಾರಿಗೆ ತರುವುದು
- **ಕಾರ್ಯಕ್ಷಮತೆ ಸುಧಾರಣೆ**: ಉದ್ಯಮಮಟ್ಟದ ಆಪರೇಶನ್‌ಗಳಿಗೆ ಪರಿಣಾಮಕಾರಿ ಕೆಲಸದ ಪ್ರವಾಹ ವಿನ್ಯಾಸಗೊಳಿಸಿ

### 🏢 **ಉದ್ಯಮ ಕೆಲಸದ ಪ್ರವಾಹ ಅನ್ವಯಿಕೆಗಳು**
- **ವ್ಯವಹಾರ ಪ್ರಕ್ರಿಯಾ ಸ್ವಯಂಚಾಲನೆ**: ಜಟಿಲ ಸಂಘಟನೆಯ ಕೆಲಸದ ಪ್ರವಾಹಗಳನ್ನು ಸ್ವಯಂಚಾಲಿತಗೊಳಿಸಿ
- **ವಿಷಯ ನಿರ್ಮಾಣ ಪೈಪ್ಲೈನ್**: ವಿಮರ್ಶಾ ಮತ್ತು ಅನುಮೋದನೆ ಹಂತಗಳೊಂದಿಗೆ ಸಂಪಾದಕೀಯ ಕೆಲಸದ ಪ್ರವಾಹಗಳು
- **ಗ್ರಾಹಕ ಸೇವೆ ಸ್ವಯಂಚಾಲನೆ**: ಬಹು ಹಂತ ಗ್ರಾಹಕ ವಿಚಾರಣೆ ಪರಿಹಾರ
- **ಡೇಟಾ ಪ್ರಕ್ರಿಯೆ ಕಾರ್ಯ ಪ್ರವಾಹಗಳು**: AI ನಿಂದ ಚಲಿತ ರೂಪಾಂತರಗಳೊಂದಿಗೆ ETL ಕಾರ್ಯ ಪ್ರವಾಹ

## ⚙️ ಪೂರ್ವಾಪೇಕ್ಷೆಗಳು ಮತ್ತು ಸ್ಥಾಪನೆ

### 📦 **ಅವಶ್ಯಕ NuGet ಪ್ಯಾಕೇಜ್‌ಗಳು**

ಈ ಕೆಲಸದ ಪ್ರವಾಹ ಪ್ರದರ್ಶನದಲ್ಲಿ ಹಲವು ಮುಖ್ಯ .NET ಪ್ಯಾಕೇಜ್‌ಗಳನ್ನು ಬಳಸಲಾಗಿದೆ:

```xml
<!-- Core AI Framework -->
<PackageReference Include="Microsoft.Extensions.AI" Version="9.9.0" />

<!-- Azure OpenAI (Responses API) -->
<PackageReference Include="Azure.AI.OpenAI" Version="2.1.0" />
<PackageReference Include="Azure.Identity" Version="1.13.1" />

<!-- Agent Framework (Local Development) -->
<!-- Microsoft.Agents.AI.dll - Core agent abstractions -->
<!-- Microsoft.Agents.AI.OpenAI.dll - Azure OpenAI (Responses API) integration -->

<!-- Configuration and Environment -->
<PackageReference Include="DotNetEnv" Version="3.1.1" />
```

### 🔑 **ಅಜುರ್ ಓಪನ್‌ಎಐ ಕಾನ್ಫಿಗರೇಶನ್**

**ಪರಿಸರ ಸ್ಥಾಪನೆ (.env ಫೈಲ್):**
```env
AZURE_OPENAI_ENDPOINT=https://<your-resource>.openai.azure.com
AZURE_OPENAI_DEPLOYMENT=gpt-4o-mini
```

**ಅಜುರ್ ಓಪನ್‌ಎಐ ಪ್ರವೇಶ:**
1. ಅಜುರ್ ಪೋರ್ಟಲ್‌ನಲ್ಲಿ ಅಜುರ್ ಓಪನ್‌ಎಐ ಸಂಪನ್ಮೂಲವನ್ನು ರಚಿಸಿ
2. ಮಾದರಿಯನ್ನು ನಿಯೋಜಿಸಿ (ಉದಾಹರಣೆಗೆ, `gpt-4o-mini`) ಮತ್ತು ನಿಯೋಜನೆ ಹೆಸರನ್ನು ಗಮನಿಸಿ
3. `az login` ಮೂಲಕ ಸೈನ್ ಇನ್ ಮಾಡಿ ಮತ್ತು ಮೇಲ್ಕಾಣಿಸಿದಂತೆ ಪರಿಸರ ಚರಗಳನ್ನು ಕಾನ್ಫಿಗರ್ ಮಾಡಿ

### 🏗️ **ಕೆಲಸದ ಪ್ರವಾಹ ವಿನ್ಯಾಸ ಅವಲೋಕನ**

```mermaid
graph TD
    A[ಕಾರ್ಯಪ್ರವಾಹ ನಿರ್ಮಾಪಕ] --> B[ಏಜೆಂಟ್ నೊಂದಣಿ]
    B --> C[ಕಾರ್ಯಪ್ರವಾಹ ಕಾರ್ಯಗತಗೊಳಿಸುವ ಎಂಜಿನ್]
    C --> D[Agent 1: ವಿಷಯ ರಚನೆಕর্তೆ]
    C --> E[Agent 2: ವಿಷಯ ಪರಿಶೀಲಕ] 
    D --> F[ಕಾರ್ಯಪ್ರವಾಹ ಫಲಿತಾಂಶಗಳು]
    E --> F
    G[ಅಜೂರ್ ಓಪನ್‌ಎಐ (ಪ್ರತಿಸ್ಪಂದನೆಗಳ API)] --> D
    G --> E
```

**ಪ್ರಮುಖ घटಕಗಳು:**
- **WorkflowBuilder**: ಕೆಲಸದ ಪ್ರವಾಹಗಳನ್ನು ವಿನ್ಯಾಸಗೊಳಿಸುವ ಮುಖ್ಯ ಸಂಯೋಜನಾ ಎಂಜಿನ್
- **AIAgent**: ನಿರ್ದಿಷ್ಟ ಸಾಮರ್ಥ್ಯಗಳೊಂದಿಗೆ ವೈಯಕ್ತಿಕ ವಿಶೇಷಿತ ಏಜೆಂಟ್‌ಗಳು
- **ಅಜುರ್ ಓಪನ್‌ಎಐ ಕ್ಲೈಯಂಟ್**: ಅಜುರ್ ಓಪನ್‌ಎಐ ಪ್ರತಿಕ್ರಿಯೆಗಳು API ಏಕೀಕರಣ
- **ಕಾರ್ಯಕ್ಷಮತೆ ಸನ್ನಿವೇಶ**: ಕೆಲಸದ ಪ್ರವಾಹ ಹಂತಗಳ ನಡುವೆ ಸ್ಥಿತಿ ಮತ್ತು ಡೇಟಾ ಹರಿವನ್ನು ನಿರ್ವಹಿಸುತ್ತದೆ

## 🎨 **ಉದ್ಯಮ ಕೆಲಸದ ಪ್ರವಾಹ ವಿನ್ಯಾಸ ಮಾದರಿಗಳು**

## 🏢 **ಉದ್ಯಮದ ಪ್ರಯೋಜನಗಳು**

### 🎯 **ನಂಬಿಕೆ ಮತ್ತು ವ್ಯాప్తಿ**
- **ನಿಶ್ಚಿತ ಕ್ರಮಾತ್ಮಕ ಕಾರ್ಯಗತಗೊಳಿಕೆ**: ಸತತ, ಪುನರಾವರ್ತಿತ ಕೆಲಸದ ಪ್ರವಾಹ ಫಲಿತಾಂಶಗಳು
- **ದೋಷ ಪುನರಾದಾಯವಾಗಿಸುವಿಕೆ**: ಯಾವುದೇ ಕೆಲಸದ ಪ್ರವಾಹ ಹಂತದಲ್ಲಿ ವೈಫಲ್ಯಗಳ ಸೌಮ್ಯ ನಿರ್ವಹಣೆ
- **ಕಾರ್ಯಕ್ಷಮತೆ ನಿಗಮಣ**: ಕಾರ್ಯಗತಗೊಳಿಕೆಯ ಅಳತೆ ಹಾಗೂ ಸುಧಾರಣಾ ಅವಕಾಶಗಳ ಟ್ರ್ಯಾಕ್ ಮಾಡಲು
- **ಸಂಪನ್ಮೂಲ ನಿರ್ವಹಣೆ**: AI ಮಾದರಿ ಸಂಪನ್ಮೂಲಗಳ ಪರಿಣಾಮಕಾರಿ ಹಂಚಿಕೆ ಮತ್ತು ಬಳಕೆ

### 🔒 **ಭದ್ರತೆ ಮತ್ತು ಅನುಕೂಲತೆ**
- **ಭದ್ರತನಾದ ಪ್ರಾಮಾಣಿಕರಣ**: `az login` ಮೂಲಕ ಮೈಕ್ರೋಸಾಫ್ಟ್ ಎಂಟ್ರಾ ಐಡಿ ಪ್ರಾಮಾಣಿಕತೆ (AzureCliCredential)
- **ಪರಿಶೋಧನಾ ಹಾದಿಗಳು**: ಕೆಲಸದ ಪ್ರವಾಹ ಕಾರ್ಯಗತಗೊಳಿಸುವಿಕೆ ಮತ್ತು ನಿರ್ಣಯ ಬಿಂದುಗಳ ಸಂಪೂರ್ಣ ಲಾಗಿಂಗ್
- **ಪ್ರವೇಶ ನಿಯಂತ್ರಣ**: ಕೆಲಸದ ಪ್ರವಾಹ ಕಾರ್ಯಗತಗೊಳಿಸುವಿಕೆ ಮತ್ತು ನಿಗಮಣಕ್ಕಾಗಿ ಸೂಕ್ಷ್ಮ ಅನುಮತಿಗಳು
- **ಡೇಟಾ ಗೌಪ್ಯತೆ**: ಕೆಲಸದ ಪ್ರವಾಹಗಳಲ್ಲಿ ಸಂವೇದನಾಶೀಲ ಮಾಹಿತಿಯ ಭದ್ರತೆಯೊಂದಿಗೆ ನಿರ್ವಹಣೆ

### 📊 **ಗ್ರಹಣೀಯತೆ ಮತ್ತು ನಿರ್ವಹಣೆ**
- **ದೃಶ್ಯ ಕೆಲಸದ ಪ್ರವಾಹ ವಿನ್ಯಾಸ**: ಪ್ರಕ್ರಿಯೆ ಹರಿವುಗಳು ಮತ್ತು ಅವಲಂಬನೆಗಳ ಸ್ಪಷ್ಟ ಪ್ರದರ್ಶನ
- **ಕಾರ್ಯಗತಗೊಳಿಕೆ ನಿಗಮಣ**: ರಿಯಲ್‌ಟೈಂ ಕೆಲಸದ ಪ್ರವಾಹ ಪ್ರಗತಿ ಮತ್ತು ಕಾರ್ಯಕ್ಷಮತೆಯ ಟ್ರ್ಯಾಕಿಂಗ್
- **ದೋಷ ವರದಿ**: ವಿವರವಾದ ದೋಷ ವಿಶ್ಲೇಷಣೆ ಮತ್ತು ದೋಷ ತಡೆಗಾರಿಕೆ ಸಾದ್ಯತೆಗಳು
- **ಕಾರ್ಯಕ್ಷಮತೆ ವಿಶ್ಲೇಷಣೆ**: ಸುಧಾರಣೆ ಹಾಗೂ ಸಾಮರ್ಥ್ಯ ಯೋಜನೆಗೆ ಅಳತೆಗಳು
