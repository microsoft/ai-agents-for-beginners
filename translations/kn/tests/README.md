# ಏಜೆಂಟ್ ಸ್ವೋಕ್ ಟೆಸ್ಟ್‌ಗಳು

ಈ ಫೋಲ್ಡರ್‌ನಲ್ಲಿ ನೀವು ಕೋರ್ಸ್‌ನಲ್ಲಿ ನಿರ್ಮಿಸುವ ಏಜೆಂಟ್‌ಗಳ **ಸ್ವೋಕ್-ಟೆಸ್ಟ್ ಕ್ಯಾಟಲॉग‌ಗಳು** ಇರುತ್ತವೆ.
ಸ್ವೋಕ್ ಟೆಸ್ಟ್ ಎಂದರೆ **ಪ್ರಯೋಜಿತ Microsoft Foundry ಆತಿಥ್ಯ ಮೋಡಿಸಲಾದ
ಏಜೆಂಟ್** ಆಗಿದೆ ಎಂದು ತಲುಪಬಹುದಾದ, ಪ್ರತಿಕ್ರಿಯಿಸುವ ಮತ್ತು ಅದರ ಅತಿ ಮೂಲಭೂತ ಪ್ರಾಂಪ್ಟ್ ನಿರೀಕ್ಷೆಗಳನ್ನು ಅನುಸರಿಸುತ್ತಿರುವುದನ್ನು ತಾತ್ಕಾಲಿಕ, ವೇಗವಾಗಿ ಪರಿಶೀಲಿಸುವ cheap ಪರೀಕ್ಷೆ. ಇದು ಮೊದಲ ನಿಲ್ದಾಣ — [ಪಾಠ 10](../10-ai-agents-production/README.md) ಮತ್ತು
[ಪಾಠ 16](../16-deploying-scalable-agents/README.md) ನಲ್ಲಿ ನೀವು ಕಲಿಯುವ ಪೂರ್ಣ ಮೌಲ್ಯಮಾಪನ
ಪೈಪ್ಲೈನ್‌ಗೆ ಬದಲಾವಣೆ ಅಲ್ಲ.


ಈ ಕ್ಯಾಟಲॉग‌ಗಳನ್ನು [AI Smoke Test](https://github.com/marketplace/actions/ai-smoke-test)
GitHub ಕಾರ್ಯವನ್ನು [`.github/workflows/smoke-test.yml`](../../../.github/workflows/smoke-test.yml)
ವರ್ಕ್‌ಫ್ಲೋ ಮೂಲಕ ಬಳಕೆಮಾಡಲಾಗುತ್ತದೆ.

## ನಡೆದುಕೊಳ್ಳುವ ವಿಧಾನ

1. ಪಾಠದ ಏಜೆಂಟ್ ಅನ್ನು Microsoft Foundry ನಲ್ಲಿ ಆತಿಥ್ಯ ಮೋಡಿಸಲಾದ ಏಜೆಂಟ್ ಆಗಿ ನಿಯೋಜಿಸಿ (ನಿಯೋಜನೆ ವರ್ಕ್‌ಫ್ಲೋಗಾಗಿ ಪಾಠ 16 ನೋಡಿ). **ಏಜೆಂಟ್ ಹೆಸರು** ಮತ್ತು ನಿಮ್ಮ
**Foundry ಯೋಜನೆ ಎಂಡ್ಪಾಯಿಂಟ್** ಗಮನಿಸಿಕೊಳ್ಳಿ.
2. ಈ ಸಂಗ್ರಹ ಗುಪ್ತಾಂಶಗಳನ್ನು ಸೇರಿಸಿ (ಸೆಟ್ಟಿಂಗ್ಸ್ → ಸಿಕ್ರೆಟ್ ಮತ್ತು ಮಾರ್ಗಸೂಚಿಗಳು → ಕ್ರಿಯೆಗಳು):
`AZURE_CLIENT_ID`, `AZURE_TENANT_ID`, `AZURE_SUBSCRIPTION_ID`. ಫೆಡರೇಟೆಡ್ ಗುರುತಿನುವು
**Foundry ಯೋಜನಾ ವ್ಯಾಪ್ತಿಯಲ್ಲಿ** **ಅಜುರೆ AI ಬಳಕೆದಾರ** ಪಾತ್ರವನ್ನು ಅಗತ್ಯವಿದೆ.
3. **ಕ್ರಿಯೆಗಳು** ಟ್ಯಾಬ್‌ನಿಂದ, **ಸ್ವೋಕ್-ಟೆಸ್ಟ್ ಆತಿಥ್ಯ ಏಜೆಂಟ್‌ಗಳು** ಅನ್ನು ಚಲಾಯಿಸಿ ಮತ್ತು ಪಾಠಕ್ಕೆ ತಕ್ಕ `tests_file` ಆಯ್ಕೆಮಾಡಿ, ನಂತರ ಹೊಂದುವ `agent_name` ಮತ್ತು
`project_endpoint` ಒದಗಿಸಿ.

| [`lesson-04-smoke-tests.json`](../../../tests/lesson-04-smoke-tests.json) | [04 – Tool Use](../04-tool-use/README.md) | `TravelToolAgent` |

| [`lesson-16-smoke-tests.json`](../../../tests/lesson-16-smoke-tests.json) | [16 – Deploying Scalable Agents](../16-deploying-scalable-agents/README.md) | `ContosoSupportAgent` |




ವಿರುದ್ಧವಾಗಿ ಖಚಿತಪಡಿಸಬಹುದಾದ ಪಾಠಗಳಿಗೆ ಅನ್ವಯಿಸುತ್ತವೆ. ತಾತ್ವಿಕ, ಸ್ಥಳೀಯವಾಗಿ ಮಾತ್ರ ಚಾಲನೆಯಲ್ಲಿರುವ
ಅಥವಾ ಗಾತ್ರ-ನಿರ್ಧಾರಾತ್ಮಕವಲ್ಲದ ಸೃಜನಾತ್ಮಕ ಔಟ್‌ಪುಟ್ ಉತ್ಪಾದಿಸುವ ಪಾಠಗಳನ್ನು ಉದ್ದೇಶಪೂರ್ವಕವಾಗಿ ಹೊರತುಗೊಳಿಸಲಾಗಿದೆ:


- **ಪಾಠ 17 (ಸ್ಥಳೀಯ AI ಏಜೆಂಟ್‌ಗಳನ್ನು ರಚಿಸುವುದು)** ನಿಮ್ಮ ವರ್ಕ್‌ಸ್ಟೇಷನ್‌ನಲ್ಲಿ ಸಂಪೂರ್ಣವಾಗಿ
  Foundry Local ಜೊತೆಗೆ ಚಲಿಸುತ್ತದೆ ಮತ್ತು Foundry Responses ಎಂಡ್‌ಪಾಯಿಂಟ್ ಅನ್ನು ಒದಗಿಸುವುದಿಲ್ಲ.
  ಆದ್ದರಿಂದ ಈ ಕ್ರಿಯೆ ಅನ್ವಯಿಸುವುದಿಲ್ಲ. ನೋಟ್‌ಬುಕ್ ಅನ್ನು ಸ್ಥಳೀಯವಾಗಿ ಚಲಾಯಿಸಿ ಪರಿಶೀಲಿಸಿ.
- ವಿನ್ಯಾಸ ಮಾದರಿ ಮತ್ತು ಸಿದ್ಧಾಂತ ಪಾಠಗಳು (02, 03, 06, 07, 09, 12) ಯಾವುದೇ ನಿಯೋಜನೆ ಮಾಡಬಹುದಾದ ಏಜೆಂಟ್ ಅನ್ನು ಸ್ವೋಕ್-ಟೆಸ್ಟ್‌ಗೆ ಕಳುಹಿಸವುದು ಇಲ್ಲ.

## ಕ್ಯಾಟಲಾಗ್ ಸ್ಕೀಮಾ (ತ್ವರಿತ ಉಲ್ಲೇಖ)

ಪ್ರತಿ ಕ್ಯಾಟಲಾಗ್ ಒಂದು JSON ಡಾಕ್ಯುಮೆಂಟ್ ಆಗಿದ್ದು, ಮೇಲ್ಮಟ್ಟದ `tests` ಅರೆ ನುಡಿ ಹೊಂದಿದೆ. ಪ್ರತಿ പ്രവേശನವು


| ಕ್ಷೇತ್ರ | ಅರ್ಥ |
|-------|---------|
| `id` | ಲಾಗ್‌ನಲ್ಲಿ ಮುದ್ರಿಸಿದ ವಿಶಿಷ್ಟ ಹಂತದ ಗುರುತು. |
| `description` | ಮಾನವ-ಓದಲುಗೊಳ್ಳಬಹುದಾದ ಉದ್ದೇಶ. |
| `prompt` | ಏಜೆಂಟ್‌ಗೆ ಕಳುಹಿಸಲಾದ ಸಂದೇಶ. |
| `assertions.status` | ನಿರೀಕ್ಷಿತ HTTP ಸ್ಥಿತಿ (ಡೀಫಾಲ್ಟ್ 200). |
| `assertions.contains_any` | ಪ್ರತಿಕ್ರಿಯೆಯಲ್ಲಿ ಈ ಉಪಸರಣುಗಳು ಯಾವುದು ಇಲ್ಲಿದ್ದು ಇದ್ದರೂ ಪಾಸ್. |
| `assertions.contains_all` | ಪ್ರತಿಕ್ರಿಯೆಯಲ್ಲಿ ಪ್ರತಿಯೊಂದು ಉಪಸರಣುಗಳೂ ಇದ್ದರೆ ಪಾಸ್. |
| `assertions.contains_none` | ಪ್ರತಿಕ್ರಿಯೆಯಲ್ಲಿ ಈ ಉಪಸರಣುಗಳು ಯಾವುದೂ ಇರದಿದ್ದರೆ ಪಾಸ್. |
| `save_response_id_as` | ನಂತರದ ಬಹು-ಟರ್ನ್ ಹಂತಕ್ಕೆ ಉತ್ತರ ಐಡಿ ಸಂಗ್ರಹಿಸಿ. |
| `use_previous_response_id` | ಉಳಿಸಿದ ಉತ್ತರ ಐಡಿಗೆ ಸರಪಳಿಯಾಗಿ ಈ ತಿರುವನ್ನು ಕಳುಹಿಸಿ. |

Assertions ದೊಡ್ಡಕ್ಷರ ಮತ್ತು ಸಣ್ಣಕ್ಷರಗಳ ವ್ಯತ್ಯಾಸವನ್ನು ಪರಿಗಣಿಸದ ಉಪಸ್ಟ್ರಿಂಗ್ ಪರಿಶೀಲನೆಗಳಾಗಿವೆ. ಪೂರ್ಣ ಸ್ಕೀಮಾದಕ್ಕಾಗಿ

ಇದರಲ್ಲಿ Foundry-ನಿಲ್ಲಿಸಿದ ಸಂಭಾಷಣೆ ಸಂಪನ್ಮೂಲಗಳೂ ಸೇರಿವೆ.
ಸಂಪೂರ್ಣ ಯೋಜನೆಗಾಗಿ [ಕ್ರಿಯಾ ಡಾಕ್ಯುಮೆಂಟೇಶನ್](https://github.com/marketplace/actions/ai-smoke-test), ಫೌಂಡ್ರೀ ನಿರ್ವಹಿಸುವ ಸಂಭಾಷಣೆ ಸಂಪನ್ಮೂಲಗಳನ್ನು ಒಳಗೊಂಡಿದೆ.
