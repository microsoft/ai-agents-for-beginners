# ಮಾದರಿ ರಸೀದಿ ಫಿಕ್ಚರ್ಸ್

ನೋಟ್‌ಬುಕ್ ಓಡಿಸದೇ ಪರೀಕ್ಷೆಗಾಗಿ ಮೂರೊಂದು ಪೂರ್ವ-ಉತ್ಪಾದಿತ ರಸೀದಿ ಕಡತಗಳು.

| ಫೈಲು | ಇದು ಏನು |
|---|---|
| `01_valid_receipt.json` | `lookup_flights` ಟೂಲ್ ಕರೆಗಾಗಿ ಒಂದು ಮಾನ್ಯವಾದ ಸಹಿ ಹಾಕಲಾದ ರಸೀದಿ. ಪರಿಶೀಲನೆ True ಅನ್ನು ಹಿಂತಿರುಗಿಸುತ್ತದೆ. |
| `02_tampered_receipt.json` | ಸಹಿ ಹಾಕಿದ ನಂತರ ಒಂದೆಷ್ಟು ಕ್ಷೇತ್ರ ಬದಲಾವಣೆ ಮಾಡಲಾದ ಅದೇ ರಸೀದಿ. ಪರಿಶೀಲನೆ False ಅನ್ನು ಹಿಂತಿರುಗಿಸುತ್ತದೆ. |
| `03_chain_three_receipts.json` | ಮೂರು ಮಾನ್ಯವಾದ ರಸೀದಿಗಳ ಸರಪಳಿ (search, hold, book) `previous_receipt_hash` ಮೂಲಕ ಪ್ರತಿ ರಸೀದಿಯನ್ನು ಹಿಂದಿನದಕ್ಕೆ ಲಿಂಕ್ ಮಾಡಲಾಗಿದೆ. |

ಫಿಕ್ಚರ್ಸ್ ಸರಿಯಾದ JCS ಬೈಟ್‌ಗಳನ್ನು ನೇರವಾಗಿ Ed25519 ನೊಂದಿಗೆ ಸಹಿ ಮಾಡುತ್ತವೆ.
ವಿಷಯದ ಡೈಜೆಸ್ಟ್‌ಗಳು ಮತ್ತು ರಸೀದಿ-ಚೈನ್ ಲಿಂಕ್‌ಗಳಿಗೆ SHA-256 ಬಳಸಲ್ಪಡುತ್ತದೆ, ಸಹಿ ಹಾಕುವುದಕ್ಕಿಂತ ಮುಂಚಿನ ಹೆಚ್ಚುವರಿ ಪೂರ್ವ-ಹ್ಯಾಷ್ ಆಗಿ ಅಲ್ಲ.


## ಮಾದರಿಗಳನ್ನು ಪರಿಶೀಲಿಸುವುದು

ನೋಟ್‌ಬುಕ್ ನಿರೂಪಣೆಯ ನಾಲ್ಕು ವಿಭಾಗಗಳಲ್ಲಿ ಪರಿಶೀಲನೆಯನ್ನೇ ಅಂಶಿಸಲಾಗಿದೆ. 
ಈ ಫಿಕ್ಚರ್ಸ್ ಅನ್ನು ನೇರವಾಗಿ ಪರಿಶೀಲಿಸಲು, ನೋಟ್‌ಬುಕ್ ಕಥನ ಓಡಿಸದೆ:

```python
import json
from pathlib import Path

# Assumes you have completed the imports and helper functions
# from sections 1 and 2 of 18-signed-receipts.ipynb.

valid = json.loads(Path("01_valid_receipt.json").read_text())
print(f"Valid receipt: {verify_receipt(valid)}")        # True

tampered = json.loads(Path("02_tampered_receipt.json").read_text())
print(f"Tampered receipt: {verify_receipt(tampered)}")  # False

chain = json.loads(Path("03_chain_three_receipts.json").read_text())
for r in verify_chain(chain):
    print(f"  Receipt {r['index']} ({r['tool']}): {'VALID' if r['overall_valid'] else 'INVALID'}")
```

## ವಿದ್ಯಾರ್ಥಿಗಳು ಕಚ್ಚಾ JSON ಪರಿಶೀಲಿಸುವಾಗ ಏನೆಲ್ಲಾ ಕಲಿಯುತ್ತಾರೆ

ಕಚ್ಚಾ ರಸೀದಿ ಸ್ವರೂಪ ಓದುವುದರಿಂದ ನೋಟ್‌ಬುಕ್‌ನಲ್ಲಿನ ಸೆಲ್‌ಗಳು ನೀಡದ ಅನುಭಾವ ದೊರಕುತ್ತದೆ. JSON ತ್ವರಿತವಾಗಿ ಓದುವವರು ಸಾಮಾನ್ಯವಾಗಿ ಗಮನಿಸುತ್ತಾರೆ:


1. ಸಹಿ ಒಂದು ಅಸ್ಪಷ್ಟ base64url ಸ್ಟ್ರಿಂಗ್ ಆಗಿದ್ದು, ಆದರೆ ಇತರ ಪ್ರತಿ ಕ್ಷೇತ್ರವು ಸರಳ ಓದಲುಸಾಧ್ಯ JSON ಆಗಿದೆ.
   ಸಹಿ ವಿಷಯವನ್ನು mãಕಾರ್ಪಣೆ ಮಾಡುತ್ತಿಲ್ಲ; ಅದು ಅದಕ್ಕೆ ಪ್ರಮಾಣ ನೀಡುತ್ತದೆ.
2. ರಶೀದಿಯಲ್ಲಿ `public_key` ಪ್ರತಿಷ್ಠಾಪಿಸಲಾಗಿದೆ. ಪರಿಶೀಲಕನು ಇನ್ನೇನೂ ಬೇಕಾಗಿಲ್ಲ
   ಪರಿಶೀಲಿಸಲು (ತಾವಾದ ಕೀವು ವಾಸ್ತವವಾಗಿ ಹೇಳబడಿರುವ
   ಪ್ರಕಟಕರಿಗೆ ಸೇರಿದದ್ದೋ ಎಂದು ನಂಬುವುದಕ್ಕೆ ಅಧೀನವಾಗಿ; ಗುರುತು ಮೂಲಸೌಲಭ್ಯ ವಿಷಯ README ನೋಡಿ).
3. ಯಾವುದೇ ಕ್ಷೇತ್ರದ ಒಬ್ಬಾ ಅಕ್ಷರವನ್ನು ತಿದ್ದುಪಡಿ ಮಾಡಿ, ನಂತರ ಈ ಕಡತವನ್ನು
   `02_tampered_receipt.json` ನೊಂದಿಗೆ ಪುನಃ ಹೋಲಿಸಿದರೆ, ಬೈಟ್-ಮಟ್ಟದ ಕ್ರಮವು ಸ್ಪಷ್ಟವಾಗುತ್ತದೆ.
