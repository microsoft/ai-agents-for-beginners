## ಸ್ಥಾಪನೆ ಆದೇಶಗಳು

### ಪೂರ್ವಾಪೇಕ್ಷಿತಗಳು
- ಪೈಥಾನ್ 3.12 ಅಥವಾ ಹೆಚ್ಚಿನ ಆವೃತ್ತಿ
- ಅಜ್ಯೂರ್ ಸಬ್‌ಸ್ಕ್ರಿಪ್ಶನ್ (ಮೈಕ್ರೋಸಾಫ್ಟ್ ಫೌಂಡ್ರಿಗಾಗಿ)
- ಅಜ್ಯೂರ್ CLI ಸ್ಥಾಪನೆ ಮತ್ತು ಪರಿಶೀಲನೆ (`az login`)

### ಪ್ರಾಥಮಿಕ ಸ್ಥಾಪನೆ

1. **ರೆಪೊಸಿಟರಿಯನ್ನು ಕ್ಲೋನ್ ಮಾಡುವಿರಿ ಅಥವಾ ಫೋರ್ಕ್ ಮಾಡಿರಿ:**
   ```bash
   gh repo fork microsoft/ai-agents-for-beginners --clone
   # ಅಥವಾ
   git clone https://github.com/microsoft/ai-agents-for-beginners.git
   cd ai-agents-for-beginners
   ```

2. **ಪೈಥಾನ್ ವರ್ಚುವಲ್ ಎನ್ವಯಿರನ್ಮೆಂಟ್ ರಚಿಸಿ ಮತ್ತು ಸಕ್ರಿಯಗೊಳಿಸಿ:**
   ```bash
   python3 -m venv venv
   source venv/bin/activate  # ವಿಂಡೋಸ್‌ನಲ್ಲಿ: venv\Scripts\activate
   ```

3. **ಆವಶ್ಯಕತೆಗಳನ್ನು ಸ್ಥಾಪಿಸಿ:**
   ```bash
   pip install -r requirements.txt
   ```

4. **ಪರಿಸರ ಚರಗಳನ್ನು ಸೆಟ್ ಅಪ್ ಮಾಡಿರಿ:**
   ```bash
   cp .env.example .env
   # ನಿಮ್ಮ API ಕೀಗಳು ಮತ್ತು ಎಂಡ್ಪಾಯಿಂಟ್‌ಗಳೊಂದಿಗೆ .env ಅನ್ನು ಸಂಪಾದಿಸಿ
   ```

### ಅಗತ್ಯವಿರುವ ಪರಿಸರ ಚರೆಗಳಿವಿವೆ

**ಮೈಕ್ರೋಸಾಫ್ಟ್ ಫೌಂಡ್ರಿಗಾಗಿ** (ಅಗತ್ಯವಿದೆ):
- `AZURE_AI_PROJECT_ENDPOINT` - ಮೈಕ್ರೋಸಾಫ್ಟ್ ಫೌಂಡ್ರಿ ಪ್ರಾಜೆಕ್ಟ್ ಎಂಡ್ಪಾಯಿಂಟ್
- `AZURE_AI_MODEL_DEPLOYMENT_NAME` - ಮಾದರಿ ನಿಯೋಜನೆ ಹೆಸರು (ಉದಾಹರಣೆ: gpt-4o)

**ಅಜ್ಯೂರ್ AI ಸರ್ಚ್** (ಪಾಠ 05 - RAG):
- `AZURE_SEARCH_SERVICE_ENDPOINT` - ಅಜ್ಯೂರ್ AI ಸರ್ಚ್ ಎಂಡ್ಪಾಯಿಂಟ್
- `AZURE_SEARCH_API_KEY` - ಅಜ್ಯೂರ್ AI ಸರ್ಚ್ API ಕೀ

ಪರಿಶೀಲನೆ: ನೋಟ್ಬುಕ್‌ಗಳನ್ನು ಚಲಿಸುವ ಮುನ್ನ `az login` ರನ್ ಮಾಡಿ (`AzureCliCredential` ಬಳಸುತ್ತದೆ).

## ಹೆಚ್ಚುವರಿ ಟಿಪ್ಪಣಿಗಳು

### ಸಾಮಾನ್ಯ ಸಮಸ್ಯೆಗಳು

1. **ಪೈಥಾನ್ ಆವೃತ್ತಿ ವ್ಯತ್ಯಾಸಗಳು:**
   - Python 3.12+ ನ್ನು ಬಳಸಿರುವುದು ಖಚಿತಪಡಿಸಿಕೊಳ್ಳಿ
   - ಕೆಲವು ಪ್ಯಾಕೇಜುಗಳು ಹಳೆಯ ಆವೃತ್ತಿಗಳಲ್ಲಿ ಕಾರ್ಯನಿರ್ವಹಿಸದಿರಬಹುದು
   - Python ಆವೃತ್ತಿ ಸ್ಪಷ್ಟಪಡಿಸಲು `python3 -m venv` ಬಳಸಿ

2. **ಪರಿಸರ ಚರೆಗಳು:**
   - ಸದಾ `.env.example` ನಿಂದ `.env` ರಚಿಸಿ
   - `.env` ಫೈಲ್ ಅನ್ನು ಸಮರ್ಪಿಸಬೇಡಿ (ಇದು `.gitignore` ನಲ್ಲಿ ಇದೆ)
   - ಕೀಲೀರಹಿತ Entra ID ಪರಿಶೀಲನೆಗಾಗಿ `az login` ನಲ್ಲಿ ಸೈನ್ ಇನ್ ಮಾಡಿ

3. **ಪ್ಯಾಕೇಜು ಸಂಘರ್ಷಗಳು:**
   - ಹೊಸ ವರ್ಚುವಲ್ ಎನ್ವಯಿರನ್ಮೆಂಟ್ ಬಳಸಿ
   - `requirements.txt` ನಿಂದ ಸ್ಥಾಪಿಸಿ, ಪ್ರತ್ಯೇಕ ಪ್ಯಾಕೇಜುಗಳನ್ನು ಅಲ್ಲ
   - ಕೆಲವು ನೋಟ್ಬುಕ್‌ಗಳಿಗೆ ಅವರ ಮಾರ್ಕ್‌ಡೌನ್ ಸೆಲ್‌ಗಳಲ್ಲಿ ಉಲ್ಲೇಖಿಸಿರುವ ಹೆಚ್ಚಿನ ಪ್ಯಾಕೇಜುಗಳ ಅಗತ್ಯವಿರಬಹುದು

4. **ಅಜ್ಯೂರ್ ಸೇವೆಗಳು:**
   - ಅಜ್ಯೂರ್ AI ಸೇವೆಗಳಿಗೆ ಸಕ್ರಿಯ ಸಬ್‌ಸ್ಕ್ರಿಪ್ಶನ್ ಅಗತ್ಯವಿದೆ
   - ಕೆಲ ವೈಶಿಷ್ಟ್ಯಗಳು ಪ್ರದೇಶಕ್ಕೆ ವಿಶೇಷ
   - ನಿಮ್ಮ ಅಜ್ಯೂರ್ OpenAI ಮಾದರಿ ನಿಯೋಜನೆ Responses API ನ ಬೆಂಬಲ ನೀಡುತ್ತದೆ ಎಂಬುದು ಖಚಿತಪಡಿಸಿಕೊಳ್ಳಿ

### ಅಧ್ಯಯನ ಮಾರ್ಗ
