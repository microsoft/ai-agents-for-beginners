# AGENTS.md

## ಪ್ರಾಜೆಕ್ಟ್ ಅವಲೋಕನ

ಈ ರೆಪೊಸಿಟರಿ "ಬಿಗಿನರ್ಸ್‌ಗಾಗಿ AI ಏಜೆಂಟ್ಸ್" ಅನ್ನು ಹೊಂದಿದೆ - AI ಏಜೆಂಟ್ಸ್ ನಿರ್ಮಿಸಲು ಅಗತ್ಯವಿರುವ ಎಲ್ಲಾ ವಿಷಯಗಳನ್ನು ಕಲಿಸುವ ಸಮಗ್ರ ಶೈಕ್ಷಣಿಕ ಕೋರ್ಸ್. ಈ ಕೋರ್ಸ್‌ನಲ್ಲಿ 18 ಪಾಠಗಳಿವೆ (ಸಂಖ್ಯೆ 00-18) ಇವುಗಳಲ್ಲಿ ಮೂಲಭೂತಗಳು, ವಿನ್ಯಾಸ ಮಾದರಿಗಳು, ಫ್ರೇಮ್ವರ್ಕ್‌ಗಳು, ಉತ್ಪಾದನಾ ನಿಯೋಜನೆ, ಸ್ಥಳೀಯ/ಉಪಕರಣದಲ್ಲಿ ಏಜೆಂಟ್‌ಗಳು ಮತ್ತು AI ಏಜೆಂಟ್‌ಗಳ ಭದ್ರತೆಗಳ ವಿಷಯಗಳಿವೆ.

**ಮುಖ್ಯ ತಂತ್ರಜ್ಞಾನಗಳು:**
- Python 3.12+
- ಇಂಟರಾಕ್ಟಿವ್ ಕಲಿಕೆಗಾಗಿ ಜುಪಿಟರ್ ನೋಟ್ಬುಕ್‌ಗಳು
- AI ಫ್ರೇಮ್ವರ್ಕ್‌ಗಳು: ಮೈಕ್ರೋಸಾಫ್ಟ್ ಏಜೆಂಟ್ ಫ್ರೇಮ್ವರ್ಕ್ (MAF)
- ಅಜ್ಯೂರ್ AI ಸೇವೆಗಳು: ಮೈಕ್ರೋಸಾಫ್ಟ್ ಫೌಂಡ್‌ರಿ, ಮೈಕ್ರೋಸಾಫ್ಟ್ ಫೌಂಡ್‌ರಿ ಏಜೆಂಟ್ ಸರ್ವೀಸ್ V2

**ವಾಸ್ತುಶಿಲ್ಪ:**
- ಪಾಠ ಆಧಾರಿತ ರಚನೆ (00-18 ಡೈರೆಕ್ಟರಿಗಳು)
- ಪ್ರತಿ ಪಾಠದಲ್ಲಿ ಇರುವವು: README ಡಾಕ್ಯುಮೆಂಟೇಶನ್, ಕೋಡ್ ಮಾದರಿಗಳು (ಜುಪಿಟರ್ ನೋಟ್ಬುಕ್‌ಗಳು), ಮತ್ತು ಚಿತ್ರಗಳು
- ಸ್ವಯಂಚಾಲಿತ ಅನುವಾದ ವ್ಯವಸ್ಥೆಯ ಮೂಲಕ ಬಹುಭಾಷಾ ಬೆಂಬಲ
- ಮೈಕ್ರೋಸಾಫ್ಟ್ ಏಜೆಂಟ್ ಫ್ರೇಮ್ವರ್ಕ್ ಬಳಸಿ ಪ್ರತಿ ಪಾಠಕ್ಕೆ ಒಂದು Python ನೋಟ್ಬುಕ್

## ಸೆಟಪ್ ಕಮಾಂಡ್‌ಗಳು

### ಪೂರ್ವಾಪೇಕ್ಷಿತವುಗಳು
- Python 3.12 ಅಥವಾ ಅದಕ್ಕಿಂತ ಮೇಲಿನ ಆವೃತ್ತಿ
- ಅಜ್ಯೂರ್ ಸಬ್ಸ್ಕ್ರಿಪ್‌ಷನ್ (ಮೈಕ್ರೋಸಾಫ್ಟ್ ಫೌಂಡ್‌ರಿಗೆ)
- ಅಜ್ಯೂರ್ CLI ಅನ್ನು ಇನ್‌ಸ್ಟಾಲ್ ಮಾಡಿ ಮತ್ತು ಪ್ರಾಮಾಣೀಕರಿಸಿ (`az login`)

### ಪ್ರಾಥಮಿಕ ಸೆಟಪ್

1. **ರೆಪೊನನ್ನು ಕ್ಲೋನ್ ಅಥವಾ ಫೋರ್ಕ್ ಮಾಡಿ:**
   ```bash
   gh repo fork microsoft/ai-agents-for-beginners --clone
   # OR
   git clone https://github.com/microsoft/ai-agents-for-beginners.git
   cd ai-agents-for-beginners
   ```

2. **Python ವರ್ಚುಯಲ್ ಎನ್ವಿರಾನ್‌ಮೆಂಟ್ ರಚಿಸಿ ಮತ್ತು ಸಕ್ರಿಯ ಮಾಡಿ:**
   ```bash
   python3 -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   ```

3. **ಅವಲಂಬನೆಗಳನ್ನು ಇನ್‌ಸ್ಟಾಲ್ ಮಾಡಿ:**
   ```bash
   pip install -r requirements.txt
   ```

4. **ಪರಿಸರ ಚರಗಳನ್ನು ಹೊಂದಿಸಿ:**
   ```bash
   cp .env.example .env
   # Edit .env with your API keys and endpoints
   ```

### ಅಗತ್ಯವಿರುವ ಪರಿಸರ ಚರಗಳು

**Microsoft Foundry**ಗಾಗಿ (ಅಗತ್ಯವಿದೆ):
- `AZURE_AI_PROJECT_ENDPOINT` - ಮೈಕ್ರೋಸಾಫ್ಟ್ ಫೌಂಡ್‌ರಿ ಪ್ರಾಜೆಕ್ಟ್ ಎಂಡ್ಪಾಯಿಂಟ್
- `AZURE_AI_MODEL_DEPLOYMENT_NAME` - ಮಾದರಿ ನಿಯೋಜನೆ ಹೆಸರು (ಉದಾ: gpt-5-mini)

**ಅಜ್ಯೂರ್ AI ಸರ್ಚ್** (ಪಾಠ 05 - RAG):
- `AZURE_SEARCH_SERVICE_ENDPOINT` - ಅಜ್ಯೂರ್ AI ಸರ್ಚ್ ಎಂಡ್ಪಾಯಿಂಟ್
- `AZURE_SEARCH_API_KEY` - ಅಜ್ಯೂರ್ AI ಸರ್ಚ್ API ಕೀ

ಪ್ರಾಮಾಣೀಕರಣ: ನೋಟ್ಬುಕ್‌ಗಳು chạy ಮೊದಲಿಗೆ `az login` ಅನ್ನು ಚಲಾಯಿಸಿ (ಇದು `AzureCliCredential` ಅನ್ನು ಬಳಸುತ್ತದೆ).

   ```bash
   python --version  # Should be 3.12+
   ```

### ವೈಯಕ್ತಿಕ ನೋಟ್ಬುಕ್‌ಗಳು ಕಾರ್ಯಾಚರಣೆ

ಜುಪಿಟರ್‌ನಲ್ಲಿ ನೋಟ್ಬುಕ್ ತೆರೆಯಿರಿ ಮತ್ತು ಕೊಠಡಿಗಳನ್ನು ಕ್ರಮವಾಗಿ ನಿರ್ವಹಿಸಿ. ಪ್ರತಿ ನೋಟ್ಬುಕ್ ಸ್ವಯಂ ಸೇವಕವಾಗಿದೆ ಮತ್ತು ಒಳಗೊಂಡಿದೆ:

- ಉದಾಹರಣಾ ಏಜೆಂಟ್ ಅನುಷ್ಠಾನಗಳು
- ನಿರೀಕ್ಷಿತ ಔಟ್‌ಪುಟ್‌ಗಳು ಮಾರ್ಕ್‌ಡೌನ್ ಕೊಠಡಿಗಳಲ್ಲಿ

### ನಿಯೋಜಿಸಿದ ಏಜೆಂಟ್‌ಗಳ ಧೂಮಪಾನ ಪರೀಕ್ಷೆ

Microsoft Foundry ಆಧಾರಿತ ಏಜೆಂಟ್‌ಗಳ ನಿಯೋಜನೆ ಇರುವ ಪಾಠಗಳಿಗೆ (01, 04, 05, 16), ರೆಪೊ ಎಡಿಜೆಟ್ ಗ್ರಂಥಾಲಯಗಳನ್ನು `tests/` ಅಡಿಯಲ್ಲಿ ಸಾಗಿಸುತ್ತದೆ, ಇವು `.github/workflows/smoke-test.yml` ಕಾರ್ಯಪಟು ಮೂಲಕ [AI Smoke Test](https://github.com/marketplace/actions/ai-smoke-test) ಕ್ರಿಯೆಯನ್ನು ರನ್ ಮಾಡುತ್ತದೆ. ಇವು ತೂಕ ರಹಿತ ಪೋಸ್ಟ್-ನಿಯೋಜನಾ ಗೇಟ್ ಆಗಿದ್ದು (ಏಜೆಂಟ್ ತಲುಪಬಹುದೇ ಮತ್ತು ಮೂಲ ಪ್ರಾಂಪ್ಟ್ ನಿರೀಕ್ಷೆಗಳನು ಪಾಲಿಸುತ್ತಿದೆಯೇ?), ಪಾಠಗಳು 10 ಮತ್ತು 16 ರಲ್ಲಿ ಮೌಲ್ಯಮಾಪನ ಪೈಪ್‌ಲೈನ್‌ಗಳಿಗೆ ಪೂರ್ಣತೆ ನೀಡುತ್ತದೆ. ಗ್ರಂಥಾಲಯದಿಂದ ಪಾಠಕ್ಕೆ, ಮತ್ತು ಏಜೆಂಟ್‌ಗೆ ಹೊಂದಾಣಿಕೆಯ ವಿವರಗಳಿಗಾಗಿ [tests/README.md](./tests/README.md) ನೋಡಿ. ಪಾಠ 17 ಸ್ಥಳೀಯವಾಗಿ ಫೌಂಡ್‌ರಿ ಲೋಕಲ್‌ನೊಂದಿಗೆ ಕಾರ್ಯನಿರ್ವಹಿಸುತ್ತದೆ ಮತ್ತು ಯಾವುದೇ ಹೋಸ್ಟಿಂಗ್ ಎಂಡ್ಪಾಯಿಂಟ್ ಇಲ್ಲ, ಆದ್ದರಿಂದ ನೇರವಾಗಿ ತನ್ನ ನೋಟ್ಬುಕ್ ಚಾಲನೆ ಮೂಲಕ ಪರಿಶೀಲಿಸಲಾಗುತ್ತದೆ.

   - ಔಟ್‌ಪುಟ್들은 ಸೂಕ್ತವಾಗಿವೆ ಎಂದು ಪರಿಶೀಲಿಸಿ

   - ಸಂಕೀರ್ಣ ಕೋಡಿಗೆ ನೋಟ್ಬುಕ್‌ನಲ್ಲಿ ಕಾಮೆಂಟ್‌ಗಳನ್ನು ಸೇರಿಸಿ
   - ಮಾರ್ಕ್‌ಡೌನ್ ಕೊಠಡಿಗಳು ಉದ್ದೇಶವನ್ನು ವಿವರಿಸುತ್ತಿವೆ ಎಂದು ಖಚಿತಪಡಿಸಿ

3. **ಫೈಲ್ ಬದಲಾವಣೆಗಳು:**
   - `.env` ಫೈಲ್‌ಗಳನ್ನು ಕಮಿಟ್ ಮಾಡದಿರಲಿ (ಬದಲಾಗಿ `.env.example` ಬಳಸಿ)

   - ತತ್ತ್ವಗಳನ್ನು ಪ್ರದರ್ಶಿಸುವಾಗ ನೋಟ್ಬುಕ್ ಔಟ್‌ಪುಟ್‌ಗಳನ್ನು ಉಳಿಸಿ
