# ಏಜೆಂಟಿಕ ಪ್ರೋಟೋಕಾಲ್‌ಗಳ ಬಳಕೆ (MCP, A2A ಮತ್ತು NLWeb)

[![Agentic Protocols](../../../translated_images/kn/lesson-11-thumbnail.b6c742949cf1ce2a.webp)](https://youtu.be/X-Dh9R3Opn8)

> _(ಈ ಪಾಠದ ವೀಡಿಯೊವನ್ನು ವೀಕ್ಷಿಸಲು ಮೇಲಿನ ಚಿತ್ರವನ್ನು ಕ್ಲಿಕ್ ಮಾಡಿ)_

AI ಏಜೆಂಟ್‌ಗಳ ಬಳಕೆ ಹೆಚ್ಚುವುದರಿಂದ, ಮಾನಕೀಕರಣ, ಭದ್ರತೆ ಮತ್ತು ತೆರವುವ inovação ಅನ್ನು ಬೆಂಬಲಿಸುವ ಪ್ರೋಟೋಕಾಲ್‌ಗಳ ಅಗತ್ಯವೂ ಹೆಚ್ಚಾಗಿದೆ. ಈ ಪಾಠದಲ್ಲಿ, ನಾವು ಈ ಅಗತ್ಯವನ್ನು ಪೂರೈಸಲು 3 ಪ್ರೋಟೋಕಾಲ್‌ಗಳನ್ನು ನೋಡೋಣ - ಮಾದರಿ ಸನ್ನಿವೇಶ ಪ್ರೋಟೋಕಾಲ್ (MCP), ಏಜೆಂಟ್-ಟು-ಏಜೆಂಟ್ (A2A) ಮತ್ತು ನೈಸರ್ಗಿಕ ಭಾಷೆ ವೆಬ್ (NLWeb).

## ಪರಿಚಯ

ಈ ಪಾಠದಲ್ಲಿ, ನಾವು ನೋಡೋವು:

• **MCP** ಹೇಗೆ AI ಏಜೆಂಟ್‌ಗಳಿಗೆ ಬಳಕೆದಾರ ಕಾರ್ಯಗಳನ್ನು ಪೂರ್ಣಗೊಳಿಸಲು ಹೊರಗಿನ ಸಾಧನಗಳು ಮತ್ತು ಡೇಟಾವನ್ನು ಪ್ರವೇಶಿಸಲು ಅವಕಾಶ ಕಲ್ಪಿಸುತ್ತದೆ.

• **A2A** ಹೇಗೆ ವಿಭಿನ್ನ AI ಏಜೆಂಟ್‌ಗಳ ನಡುವಿನ ಸಂವಹನ ಮತ್ತು ಸಹಕಾರವನ್ನು ಸಾಧ್ಯಮಾಡುತ್ತದೆ.

• **NLWeb** ಹೇಗೆ ಯಾವುದೇ ವೆಬ್‌ಸೈಟ್‌ಗೆ ನೈಸರ್ಗಿಕ ಭಾಷೆ ಇಂಟರ್ಫೇಸ್‌ಗಳನ್ನು ತರಿಸುತ್ತದೆ ಮತ್ತು AI ಏಜೆಂಟ್‌ಗಳಿಗೆ ವಿಷಯವನ್ನು ಅನ್ವೇಷಿಸಿ ಸಂವಹನ ಮಾಡಲು ಅವಕಾಶ ನೀಡುತ್ತದೆ.

## ಕಲಿಕೆ ಗುರಿಗಳು

• AI ಏಜೆಂಟ್‌ಗಳ ದೃಷ್ಟಿಕೋನದಲ್ಲಿ MCP, A2A ಮತ್ತು NLWeb ಗಳ ಮುಖ್ಯ ಉದ್ದೇಶ ಮತ್ತು ಲಾಭಗಳನ್ನು **ಗುರುತಿಸುವುದು**.

• ಪ್ರತಿ ಪ್ರೋಟೋಕಾಲ್ ಎಲ್‌ಎಲ್‌ಎಂಗಳು, ಸಾಧನಗಳು ಮತ್ತು ಇತರ ಏಜೆಂಟ್‌ಗಳ ನಡುವಿನ ಸಂವಹನ ಮತ್ತು ಪರಸ್ಪರಕ್ರಿಯೆಗಳನ್ನು ಹೇಗೆ ಅನುಕೂಲಗೊಳಿಸುತ್ತದೆ ಎಂಬುದನ್ನು **ವಿವರಿಸುವುದು**.

• ಸಂಕೀರ್ಣ ಏಜೆಂಟಿಕ್ ವ್ಯವಸ್ಥೆಗಳ ನಿರ್ಮಾಣದಲ್ಲಿ ಪ್ರತಿ ಪ್ರೋಟೋಕಾಲ್‌ಗಳ ವಿಭಿನ್ನ ಪಾತ್ರಗಳನ್ನು **ಪರಿಚಯಿಸುವುದು**.

## ಮಾದರಿ ಸನ್ನಿವೇಶ ಪ್ರೋಟೋಕಾಲ್

**ಮಾದರಿ ಸನ್ನಿವೇಶ ಪ್ರೋಟೋಕಾಲ್ (MCP)** ಒಂದು ತೆರೆಯಲಾದ ಮಾನಕವಾಗಿದ್ದು, ಅನ್ವಯಿಕೆಗಳಿಗೆ ಎಲ್‌ಎಲ್‌ಎಂಗಳಿಗೆ ಸನ್ನಿವೇಶ ಮತ್ತು ಸಾಧನಗಳನ್ನು ಒದಗಿಸುವ ಮಾನಕೀಕೃತ ರೀತಿಯನ್ನು ನೀಡುತ್ತದೆ. ಇದು AI ಏಜೆಂಟ್‌ಗಳು ಸुसಂಗತವಾದ ರೀತಿಯಲ್ಲಿ ಸಂಪರ್ಕಿಸಬಹುದಾದ ವಿಭಿನ್ನ ಡೇಟಾ ಮೂಲಗಳು ಮತ್ತು ಸಾಧನಗಳಿಗೆ "ವಿಶ್ವವ್ಯಾಪಿ ಅಡಾಪ್ಟರ್" ಆಗಿ ಕಾರ್ಯನಿರ್ವಹಿಸುತ್ತದೆ.

MCP ನ ಅಂಶಗಳು, ನೇರ API ಬಳಕೆಯಿಗಿಂತಲೂ ಇರುವ ಲಾಭಗಳು ಮತ್ತು AI ಏಜೆಂಟ್‌ಗಳು MCP ಸರ್ವರ್ ಅನ್ನು ಹೇಗೆ ಬಳಸಬಹುದು ಎಂಬ ಉದಾಹರಣೆಯನ್ನು ನೋಡೋಣ.

### MCP ಮುಖ್ಯ ಅಂಶಗಳು

MCP ಒಂದು **ಖಾತರಿ-ಸರ್ವರ್ ವಾಸ್ತುಶಿಲ್ಪ** ಮೇಲೆ ಕಾರ್ಯ ನಿರ್ವಹಿಸುತ್ತದೆ ಮತ್ತು ಮೂಲ ಅಂಶಗಳು:

• **ಹೋಸ್ಟ್‌ಗಳು** ಎಲ್‌ಎಲ್‌ಎಂ ಅನ್ವಯಿಕೆಗಳು (ಉದಾಹರಣೆಗೆ VSCode ಹೀಗೆ ಕೋಡ್ ಸಂಪಾದಕ) ಆಗಿದ್ದು, MCP ಸರ್ವರ್‌ಗೆ ಸಂಪರ್ಕ ಪ್ರಾರಂಭಿಸುತ್ತವೆ.

• **ಕ್ಲೈಂಟ್‌ಗಳು** ಹೋಸ್ಟ್ ಅನ್ವಯಿಕೆಯಲ್ಲಿ ಇದ್ದು ಸರ್ವರ್‌ಗಳೊಂದಿಗೆ ಒಂದು-ಮತ್ತೊಂದು ಸಂಪರ್ಕವನ್ನು ನಿರ್ವಹಿಸುತ್ತವೆ.

• **ಸರ್ವರ್‌ಗಳು** ಇದೊಂದು ಲಘು ಕಾರ್ಯಕ್ರಮಗಳಾಗಿದ್ದು ವಿಶೇಷ ಸಾಮರ್ಥ್ಯಗಳನ್ನು ತೆರೆದಿಡುತ್ತವೆ.

ಪ್ರೋಟೋಕಾಲ್‌ನಲ್ಲಿ ಮೂರು ಪ್ರಾಥಮಿಕ ಅಂಶಗಳಿವೆ, ಅವು MCP ಸರ್ವರ್‌ನ ಸಾಮರ್ಥ್ಯಗಳಾಗಿವೆ:

• **ಸಾಧನಗಳು**: AI ಏಜೆಂಟ್ ಕಾರ್ಯನಿರ್ವಹಿಸಲು ಕರೆಮಾಡಬಹುದಾದ ವಿಭಿನ್ನ ಕ್ರಿಯೆಗಳು ಅಥವಾ ಫಂಕ್ಷನ್‌ಗಳು. ಉದಾ: ವಾತಾವರಣ ಸೇವೆ "ಹವಾಮಾನ ಪಡೆಯಿರಿ" ಸಾಧನವನ್ನು ನೀಡಬಹುದು, ಅಥವಾ ಇ-ಕಾಮರ್ಸ್ ಸರ್ವರ್ "ಉತ್ಪನ್ನ ಖರೀದಿಸಿ" ಸಾಧನವನ್ನು ನೀಡಬಹುದು. MCP ಸರ್ವರ್ ಪ್ರತಿ ಸಾಧನದ ಹೆಸರು, ವಿವರಣೆ, ಮತ್ತು ಇನ್‌ಪುಟ್/ಔಟ್‌ಪುಟ್ ಸ್ಕೀಮಾವನ್ನು ತನ್ನ ಸಾಮರ್ಥ್ಯಗಳ ಪಟ್ಟಿ ನೀಡುತ್ತದೆ.

• **ಸಂಪನ್ಮೂಲಗಳು**: MCP ಸರ್ವರ್ ಒದಗಿಸಬಹುದಾದ ಓದಲು ಮಾತ್ರ ಇರುವ ಡೇಟಾ ಅಥವಾ ದಾಖಲೆಗಳು, ಮತ್ತು ಕ್ಲೈಂಟ್ ಅವುಗಳನ್ನು ಅಗತ್ಯವಿರುವಾಗ ಪಡೆದಿಕೊಳ್ಳಬಹುದು. ಉದಾಹರಣೆಗೆ, ಕಡತ ವಿಷಯಗಳು, ದತ್ತಾಂಶ ದಾಖಲೆಗಳು, ಲಾಗ್ ಫೈಲ್‌ಗಳು. ಸಂಪನ್ಮೂಲಗಳು ಪಠ್ಯ (ಕೋಡ್ ಅಥವಾ JSON) ಅಥವಾ ದ್ವಿಮಾನ (ಚಿತ್ರಗಳು ಅಥವಾ PDF ಗಳು) ಆಗಿರಬಹುದು.

• **ಪ್ರಾಂಪ್ಟ್‌ಗಳು**: ಮೊದಲು ಇರಿತ್ತರಿಸಲಾಗಿರುವ ಟೆಂಪ್ಲೇಟುಗಳು, ಸجھಾವಿಡಿ ಪ್ರಾಂಪ್ಟ್‌ಗಳೊಂದಿಗೆ ಹೆಚ್ಚು ಸಂಕೀರ್ಣ ವರ್ಕ್‌ಫ್ಲೋಗಳನ್ನು ಸಾಧ್ಯಮಾಡುತ್ತವೆ.

### MCP ಲಾಭಗಳು

MCP AI ಏಜೆಂಟ್‌ಗಳಿಗೆ ಪ್ರಮುಖ ಪ್ರಯೋಜನಗಳನ್ನು ನೀಡುತ್ತದೆ:

• **ಡೈನಾಮಿಕ್ ಸಾಧನ ಪತ್ತೆ**: ಏಜೆಂಟ್‌ಗಳು ಸರ್ವರ್‌ನಿಂದ ಲಭ್ಯವಿರುವ ಸಾಧನಗಳ ಪಟ್ಟಿ ಮತ್ತು ಅವುಗಳ ವಿವರಣಾ ಸಹಿತ ಸ್ವಯಂಚಾಲಿತವಾಗಿ ಪಡೆಯಬಹುದು. ಇದು ನಿಯಮಿತ API ಗಳಿಗೆ ಹೋಲಿಕೆ, ಅವು ಸಾಮಾನ್ಯವಾಗಿ ಸಂಯೋಜನೆಗಾಗಿ ಸ್ಥಿರ ಕೋಡಿಂಗ್ ಅವಶ್ಯಕತೆಯನ್ನು ಹೊಂದಿರುತ್ತವೆ, ಮತ್ತು API ಯಾವುದೇ ಬದಲಾವಣೆ ರಾತ್ರಿ ಕೋಡ್ ನವೀಕರಣ ಅಗತ್ಯಪಡಿಸುವುದು. MCP "ಒಂದು ಬಾರಿ ಸಂಯೋಜಿಸಿ" ಗಳಿಕೆಯೊಂದಿಗೆ ಹೆಚ್ಚು ಹೊಂದಿಕೊಳ್ಳುವಿಕೆಯನ್ನು ನೀಡುತ್ತದೆ.

• **ವಿಭಿನ್ನ ಎಲ್‌ಎಲ್‌ಎಂ‌ಗಳ ನಡುವೆ ಪರಸ್ಪರ ಚಾಲನೆಯ ಸಮರ್ಥತೆ**: MCP ಹಲವಾರು ಎಲ್‌ಎಲ್‌ಎಂಗಳಲ್ಲಿ ಕೆಲಸ ಮಾಡುತ್ತದೆ, ಉತ್ತಮ ಕಾರ್ಯಕ್ಷಮತೆಗಾಗಿ ನೇರ ಮಾದರಿಗಳನ್ನು ಬದಲಾಯಿಸುವ ಅನುಕೂಲತೆ ನೀಡುತ್ತದೆ.

• **ಮಾನಕೀಕೃತ ಭದ್ರತೆ**: MCP ಒಂದು ಮಾನಕ ಪ್ರಾಮಾಣೀಕರಣ ವಿಧಾನವನ್ನು ಒಳಗೊಂಡಿದೆ, ಹೆಚ್ಚುವರಿ MCP ಸರ್ವರ್ಗಳ ಪ್ರವೇಶವನ್ನು ಸೇರಿಸುವಾಗ ಈತ scalability ಅನ್ನು ಸುಲಭಮಾಡುತ್ತದೆ. ಇದು ವಿಭಿನ್ನ ನಿಯಮಿತ API ಗಳಿಗೆ ವಿಭಿನ್ನ ಕೀಲಿಗಳು ಮತ್ತು ಪ್ರಾಮಾಣೀಕರಣವನ್ನು ನಿರ್ದೇಶಿಸುವುದಕ್ಕಿಂತ ಸುಲಭ.

### MCP ಉದಾಹರಣೆ

![MCP Diagram](../../../translated_images/kn/mcp-diagram.e4ca1cbd551444a1.webp)

ಒಂದು ಬಳಕೆದಾರನು MCP ಪವರ್ಧಿತ AI ಸಹಾಯಕ ಬಳಸಿ ವಿಮಾನ ಟಿಕೆಟ್ ಬುಕ್ ಮಾಡಬೇಕೆಂದು ಊಹಿಸಿಕೊಳ್ಳಿ.

1. **ಸಂಪರ್ಕ**: AI ಸಹಾಯಕ (MCP ಕ್ಲೈಂಟ್) ವಿಮಾನ ಸಂಸ್ಥೆ ಒದಗಿಸಿದ MCP ಸರ್ವರ್‌ಗೆ ಸಂಪರ್ಕ ಮಾಡುತ್ತದೆ.

2. **ಸಾಧನ ಪತ್ತೆ**: ಕ್ಲೈಂಟ್ ವಿಮಾನ ಸಂಸ್ಥೆಯ MCP ಸರ್ವರ್‌ನಿಂದ "ನೀವು ಯಾವ ಸಾಧನಗಳನ್ನು ಹೊಂದಿದ್ದೀರಿ?" ಎಂದು ಕೇಳುತ್ತದೆ. ಸರ್ವರ್ "ಯಾತ್ರೆ ಹುಡುಕಿ" ಮತ್ತು "ಯಾತ್ರೆ ಬುಕ್ ಮಾಡಿ" ಇತ್ಯಾದಿ ಸಾಧನಗಳನ್ನು ಪ್ರತಿಕ್ರಿಯಿಸುತ್ತದೆ.

3. **ಸಾಧನ ಉಪಯೋಗ**: ಪೂರ್ವಾಹ್ನ "ಪೋರ್‌ಟ್ಲ್ಯಾಂಡ್‌ನಿಂದ ಹೊನೊಲುಲು ವಿಮಾನ ಹುಡುಕಿ" ಎಂದು AI ಸಹಾಯಕರಿಗೆ ಕೇಳುತ್ತೀರಿ. AI ಸಹಾಯಕ ತನ್ನ ಎಲ್‌ಎಲ್‌ಎಂ ಬಳಸಿ "ಯಾತ್ರೆ ಹುಡುಕಿ" ಸಾಧನವನ್ನು ಕರೆಮಾಡಬೇಕು ಎಂದು ಗುರುತಿಸಿ ಸಂಬಂಧಿತ ಪ್ಯಾರಾಮিটার‌ಗಳನ್ನು (ಆರಂಭ, ಗಮ್ಯಸ್ಥಾನ) MCP ಸರ್ವರ್‌ಗೆ ಕಳುಹಿಸುತ್ತದೆ.

4. **ಕಾರ್ಯಗತಗೊಳಿಸುವಿಕೆ ಮತ್ತು ಪ್ರತಿಕ್ರಿಯೆ**: MCP ಸರ್ವರ್, ವ್ರೇಪರ್ ಆಗಿ ಕಾರ್ಯನಿರ್ವಹಿಸಿ, ವಿಮಾನ ಸಂಸ್ಥೆಯ ಆಂತರಿಕ ಬುಕ್ಕಿಂಗ್ API ಗೆ ಕರೆಮಾಡುತ್ತದೆ. ನಂತರ ವಿಮಾನ ಮಾಹಿತಿಯನ್ನು (ಉದಾ: JSON ಡೇಟಾ) ಪಡೆದ ನಂತರ AI ಸಹಾಯಕಿಗೆ ಹಿಂದಿರುಗಿಸುತ್ತದೆ.

5. **ಮುಂದಿನ ಪರಸ್ಪರಕ್ರಿಯೆ**: AI ಸಹಾಯಕ ವಿಮಾನ ಆಯ್ಕೆಗಳನ್ನು ಪ್ರದರ್ಶಿಸುತ್ತದೆ. ನೀವು ಒಂದನ್ನು ಆಯ್ಕೆ ಮಾಡಿದ ಮೇಲೆ, ಸಹಾಯಕವು ಅದೇ MCP ಸರ್ವರ್‌ನಲ್ಲಿ "ಯಾತ್ರೆ ಬುಕ್ ಮಾಡಿ" ಸಾಧನವನ್ನು ಕರೆ ಮಾಡಿ ಬುಕ್ಕಿಂಗ್ ಪೂರ್ಣಗೊಳಿಸುತ್ತದೆ.

## ಏಜೆಂಟ್-ಟು-ಏಜೆಂಟ್ ಪ್ರೋಟೋಕಾಲ್ (A2A)

MCP LLM ಗಳನ್ನು ಸಾಧನಗಳಿಗೆ ಸಂಪರ್ಕಿಸುವದರಲ್ಲಿ ಕೇಂದ್ರೀಕರಿಸುವಾಗ, **ಏಜೆಂಟ್-ಟು-ಏಜೆಂಟ್ (A2A) ಪ್ರೋಟೋಕಾಲ್** ವಿಭಿನ್ನ AI ಏಜೆಂಟ್‌ಗಳ ನಡುವೆ ಸಂವಹನ ಮತ್ತು ಸಹಕಾರವನ್ನು ಸಾಧ್ಯಮಾಡುತ್ತದೆ. A2A ವಿಭಿನ್ನ ಸಂಸ್ಥೆಗಳು, ಪರಿಸರಗಳು ಮತ್ತು ತಂತ್ರಜ್ಞಾನ ಸ್ಟ್ಯಾಕ್‌ಗಳ AI ಏಜೆಂಟ್‌ಗಳನ್ನು ಸಂಪರ್ಕಿಸುತ್ತವೆ ಒಂದೇ ಸಹಾಯಕ ಕಾರ್ಯವನ್ನು ಪೂರ್ಣಗೊಳಿಸಲು.

ನಾವು A2A ಯ ಅಂಶಗಳು ಮತ್ತು ಲಾಭಗಳನ್ನು ಪರಿಶೀಲಿಸುವ ಜೊತೆಗೆ ನಮ್ಮ ಪ್ರಯಾಣ ಅನ್ವಯಿಕೆಯಲ್ಲಿ ಅದನ್ನು ಹೇಗೆ ಅನ್ವಯಿಸಬಹುದು ಎಂಬ ಉದಾಹರಣೆಯನ್ನು ನೋಡೋಣ.

### A2A ಮುಖ್ಯ ಅಂಶಗಳು

A2A ಏಜೆಂಟ್‌ಗಳ ನಡುವಿನ ಸಂವಹನ ಮತ್ತು ಬಳಕೆದಾರರ ಉಪಕಾರ್ಯವನ್ನು ಪೂರ್ಣಗೊಳಿಸಲು ಅವರ ಸಹಕಾರವನ್ನು ಮುಟ್ಟುಮಾಡುತ್ತದೆ. ಪ್ರೋಟೋಕಾಲ್‌ನ ಪ್ರತಿಯೊಂದು ಅಂಶವು ಇದಕ್ಕೆ ಸಹಕಾರ ನೀಡುತ್ತದೆ:

#### ಏಜೆಂಟ್ ಕಾರ್ಡ್

MCP ಸರ್ವರ್ ಸಾಧನಗಳ ಪಟ್ಟಿಯನ್ನು ಹಂಚಿಕೊಳ್ಳುವಂತೆ, ಏಜೆಂಟ್ ಕಾರ್ಡ್ ಇದನ್ನು ಹೊಂದಿದೆ:
- ಏಜೆಂಟ್‌ನ ಹೆಸರು.
- ಅದು ಪೂರ್ಣಗೊಳಿಸುವ ಸಾಮಾನ್ಯ ಕಾರ್ಯಗಳ **ವಿವರಣೆ**.
- ಇತರ ಏಜೆಂಟ್‌ಗಳು (ಕಿತ್ತಡಿದಿಗಿ ಕೂಡ ಮಾನವರು) ಯಾವಾಗ ಮತ್ತು ಏಕೆ ಆ ಏಜೆಂಟ್ ಅನ್ನು ಕರೆಮಾಡಬೇಕೆಂದು ತಿಳಿದಿಕೊಳ್ಳಲು ಸಹಾಯ ಮಾಡುವ **ವಿಶೇಷ ಕೌಶಲ್ಯಗಳ ಪಟ್ಟಿ** ಹಾಗೂ ವಿವರಣೆ.
- ಏಜೆಂಟ್‌ನ **ಪ್ರಸ್ತುತ ಎಂಡ್‌ಪಾಯಿಂಟ್ URL**
- ಸ್ಟ್ರೀಮಿಂಗ್ ಪ್ರತಿಕ್ರಿಯೆ ಮತ್ತು ಪುಷ್ ಸೂಚನೆಗಳಂತಹ ಏಜೆಂಟ್‌ನ **ಆವೃತ್ತಿ ಮತ್ತು ಸಾಮರ್ಥ್ಯಗಳು**.

#### ಏಜೆಂಟ್ ಕಾರ್ಯನಿರ್ವಹಿಸಿ

ಏಜೆಂಟ್ ಕಾರ್ಯನಿರ್ವಹಿಸಿ **ಬಳಕೆದಾರ ಚಾಟ್ ಸನ್ನಿವೇಶವನ್ನು ದೂರದ ಏಜೆಂಟ್‌ಗೆ ಹಂಚುವುದು** ಜವಾಬ್ದಾರಿಯಾಗಿದೆ; ದೂರದ ಏಜೆಂಟ್ ಇದನ್ನು ಕಾರ್ಯ ಪೂರ್ಣಗೊಳಿಸಲು ಅವಶ್ಯಕತೆಯಾಗಿ ನೋಡಿಕೊಳ್ಳುತ್ತದೆ. A2A ಸರ್ವರ್‌ನಲ್ಲಿ, ಏಜೆಂಟ್ ತನ್ನದೇ ಲಾರ್ಜ್ ಲ್ಯಾಂಗ್ವೇಜ್ ಮಾದರಿಯನ್ನು (LLM) ಬಳಸಿ ವಿನಂತಿಗಳನ್ನು ವಿಶ್ಲೇಷಿಸಿ, ತನ್ನ ಅಂತರ್ಮುಖ ಸಾಧನಗಳನ್ನು ಬಳಸಿ ಕಾರ್ಯಗಳನ್ನು ನಿರ್ವಹಿಸುತ್ತದೆ.

#### ಕಲೆಫಲ

ಒಂದು ದೂರದ ಏಜೆಂಟ್ ವಿನಂತಿತ ಎಡವನ್ನು ಪೂರ್ಣಗೊಳಿಸಿದ ಮೇಲೆ, ಅದರ ಕಟುವುಳಿವು artefact ರೂಪದಲ್ಲಿ ಸೃಷ್ಟಿಸಲಾಗುತ್ತದೆ. artefact ಏಜೆಂಟ್ ಕೆಲಸದ ಫಲವನ್ನು, ಪೂರ್ಣಗೊಂಡTask ವಿವರಣೆಯನ್ನು ಮತ್ತು ಪ್ರೋಟೋಕಾಲ್ ಮೂಲಕ ಕಳುಹಿಸಲಾದ ಪಠ್ಯ ಸನ್ನಿವೇಶವನ್ನು ಒಳಗೊಂಡಿರುತ್ತದೆ. artefact ಕಳುಹಿಸಿದ ನಂತರ ಸಂಪರ್ಕವು ಮುಚ್ಚಲ್ಪಡುತ್ತದೆ ಮತ್ತೆ ಅವಶ್ಯಕತೆಯಾದಾಗ ಮತ್ತೆ ತೆರೆಯಲಾಗುತ್ತದೆ.

#### ಘಟನೆ ಸರಣಿ

ಇದು **ನವೀಕರಣಗಳನ್ನು ನಿರ್ವಹಿಸುವುದು ಮತ್ತು ಸಂದೇಶಗಳನ್ನು ಹಂಚಿಕೊಳ್ಳಲು** ಬಳಸಲಾಗುತ್ತದೆ. ಕಾರ್ಯ ಪೂರ್ಣಗೊಳಿಸುವ ಮೊದಲು ಏಜೆಂಟ್‌ಗಳ ನಡುವೆ ಸಂಪರ್ಕ ಮುಚ್ಚಲ್ಪಡುವುದನ್ನು ತಪ್ಪಿಸಲು, ವಿಶೇಷವಾಗಿ ಕಾರ್ಯ ಪೂರ್ಣಗೊಳ್ಳುವ ಸಮಯ ಹೆಚ್ಚು ಯಾವಾಗಲಾದರೂ ಇದು ಉತ್ಪಾದನಾ ಏಜೆಂಟಿಕ್ ವ್ಯವಸ್ಥೆಗಳಿಗಾಗಿ ಅತ್ಯಂತ ಮುಖ್ಯವಾಗಿದೆ.

### A2A ಲಾಭಗಳು

• **ಮೆಚ್ಚುಗೆಯಾದ ಸಹಕಾರ**: ವಿವಿಧ ಮಾರಾಟದವರು ಮತ್ತು ಪ್ಲಾಟ್‌ಫಾರ್ಮ್‌ಗಳ ಏಜೆಂಟ್‌ಗಳು ಪರಸ್ಪರ ಸಂವಹನ ಮಾಡಿ, ಸನ್ನಿವೇಶ ಹಂಚಿಕೊಳ್ಳಿ, ಮತ್ತು ಸಹಕರಿಸಿ ಪ್ರಾಸಂಗಿಕವಾಗಿ ಸ್ವಯಂಚಾಲನೆನವನ್ನು ಸಿಗುಗೊಳಿಸುತ್ತವೆ.

• **ಮಾದರಿ ಆಯ್ಕೆ ಅನುವು**: ಪ್ರತಿ A2A ಏಜೆಂಟ್ ತನ್ನ ಕೋರಿ ಸೇವೆಗೆ ಬಳಸುವ ಎಲ್‌ಎಲ್‌ಎಂ ಅನ್ನು ಸ್ವತಃ ನಿರ್ಧರಿಸಬಹುದು, MCP ಪರಿಸ್ಥಿತಿಗಳಲ್ಲಿ ಕಂಡುಬರುವ ಒಂದೇ ಎಲ್‌ಎಲ್‌ಎಂ ಸಂಪರ್ಕದೊಂದಿಗೆ ಭಿನ್ನತೆಯಾಗಿ ಹೆಚ್ಚುವರಿ ಸುಧಾರಿತ ಅಥವಾ ಸೂಕ್ಷ್ಮೀಕೃತ ಮಾದರಿಗಳನ್ನು ಬಳಸಬಹುದು.

• **ನಿರ್ದಿಷ್ಟತೆಯುಳ್ಳ ಪ್ರಾಮಾಣೀಕರಣ**: A2A ಪ್ರೋಟೋಕಾಲ್‌ಗೆ ಪ್ರಾಮಾಣೀಕರಣ ನೇರವಾಗಿ ಒಳಗೊಂಡಿದೆ, ಏಜೆಂಟ್ ಸಂವಹನಗಳಿಗಾಗಿ ಬಲವಾದ ಭದ್ರತಾ ಜಾಲವನ್ನು ನೀಡುತ್ತದೆ.

### A2A ಉದಾಹರಣೆ

![A2A Diagram](../../../translated_images/kn/A2A-Diagram.8666928d648acc26.webp)

ನಮ್ಮ ಪ್ರಯಾಣ ಬುಕ್ಕಿಂಗ್ ಸನ್ನಿವೇಶವನ್ನು A2A ಬಳಸಿಕೊಂಡು ವಿಸ್ತರಿಸೋಣ.

1. **ಬಳಕೆದಾರ ಮನವಿ ಬಹುಏಜೆಂಟ್‌ಗೆ**: ಬಳಕೆದಾರನು "ಪ್ರಯಾಣ ಏಜೆಂಟ್" A2A ಕ್ಲೈಂಟ್/ಏಜೆಂಟ್‌ ಜೊತೆಗೆ ಸಂವಹನ ಮಾಡುತ್ತಾನೆ, ಉದಾಹರಣೆಗೆ "ಮುಂದಿನ ವಾರ ಹೊನೊಲುಲುಗೆ ಪೂರ್ಣ ಪ್ರಯಾಣ, ಹವಾನಿಲೆಯುಳ್ಳ ಹೋಟೆಲ್ ಮತ್ತು ರೆಂಟಲ್ ಕಾರಿನ ಸೇರಿ ಬುಕ್ ಮಾಡಿ" ಎಂದು ಹೇಳಬಹುದು.

2. **ಪ್ರಯಾಣ ಏಜೆಂಟ್‌ ನೇತೃತ್ವದಲ್ಲಿ ಸಂಯೋಜನೆ**: ಪ್ರಯಾಣ ಏಜೆಂಟ್ ಈ ಸಂಕೀರ್ಣ ವಿನಂತಿಯನ್ನು ಸ್ವೀಕರಿಸಿ, ತನ್ನ ಎಲ್‌ಎಲ್‌ಎಂ ಬಳಸಿ ಕಾರ್ಯದ ಬಗ್ಗೆ ವಿಶ್ಲೇಷಿಸಿ, ಇನ್ನಿತರ ವಿಶಿಷ್ಟ ಏಜೆಂಟ್‌ಗಳೊಂದಿಗೆ ಸಂವಹನ ಅಗತ್ಯವಿವೆಂದು ನಿರ್ಧರಿಸುತ್ತದೆ.

3. **ಏಜೆಂಟ್‌ಗಳ ನಡುವಿನ ಸಂವಹನ**: ನಂತರ ಪ್ರಯಾಣ ಏಜೆಂಟ್ A2A ಪ್ರೋಟೋಕಾಲ್ ಮೂಲಕ ವಿವಿಧ ಏಜೆಂಟ್‌ಗಳಿಗೆ ಸಂಪರ್ಕ ಮಾಡುತ್ತದೆ, ಉದಾ: "ವಿಮಾನ ಏಜೆಂಟ್", "ಹೋಟೆಲ್ ಏಜೆಂಟ್", ಮತ್ತು "ಕಾರು ರೆಂಟಲ್ ಏಜೆಂಟ್" ಇವು ವಿಭಿನ್ನ ಕಂಪನಿಗಳಿಂದ ನಿರ್ಮಿತವಾಗಿವೆ.

4. **ಹೊಂದಿಸಿದ ಕಾರ್ಯ ನಿರ್ವಹಣೆ**: ಪ್ರಯಾಣ ಏಜೆಂಟ್ ನಿರ್ದಿಷ್ಟ ಕಾರ್ಯಗಳನ್ನು ಈ ವಿಶೇಷ ಏಜೆಂಟ್‌ಗಳಿಗೆ ಕಳುಹಿಸುತ್ತದೆ (ಉದಾ: "ಹೊನೊಲುಲುಗೆ ವಿಮಾನ ಹುಡುಕಿ", "ಹೋಟೆಲ್ ಬುಕ್ ಮಾಡಿ", "ಕಾರು ಬಾಡಿಗೆಗೆ ತೆಗೆ"). ಈ ಏಜೆಂಟ್‌ಗಳು ತಮ್ಮದೇ ಎಲ್‌ಎಲ್‌ಎಂಗಳನ್ನೂ ಮತ್ತು ಸಾಧನಗಳನ್ನೂ (MCP ಸರ್ವರ್‌ಗಳನ್ನೂ ಒಳಗೊಂಡಂತೆ) ಉಪಯೋಗಿಸುತ್ತವೆ, ಬುಕ್ಕಿಂಗ್‌ನ ತಮ್ಮ ಭಾಗವನ್ನು ಕಾರ್ಯಗತಗೊಳಿಸುತ್ತವೆ.

5. **ಒಟ್ಟಾರೆ ಪ್ರತಿಕ್ರಿಯೆ**: ಎಲ್ಲಾ ಏಜೆಂಟ್‌ಗಳು ಕಾರ್ಯಗಳು ಪೂರ್ಣಗೊಳಿಸಿದ ನಂತರ, ಪ್ರಯಾಣ ಏಜೆಂಟ್ ವಿವರಗಳನ್ನು (ವಿಮಾನ ವಿವರ, ಹೋಟೆಲ್ ದೃಢೀಕರಣ, ಕಾರು ಬಾಡಿಗೆ) ಸಂಗ್ರಹಿಸಿ ಚಾಟ್ ಶೈಲಿಯ ಪ್ರತಿಕ್ರಿಯೆಯನ್ನು ಬಳಕೆದಾರರಿಗೆ ಕಳುಹಿಸುತ್ತದೆ.

## ನೈಸರ್ಗಿಕ ಭಾಷೆ ವೆಬ್ (NLWeb)

ವೆಬ್‌ಸೈಟ್‌ಗಳು ದೀರ್ಘಕಾಲದಿಂದ ಬಳಕೆದಾರರು ಇಂಟರ್ನೆಟ್ ಮೂಲಕ ಮಾಹಿತಿ ಮತ್ತು ಡೇಟಾವನ್ನು ಪ್ರವೇಶಿಸುವ ಪ್ರಮುಖ ಮಾರ್ಗವಾಗಿವೆ.

NLWeb ನ ವಿಭಿನ್ನ ಅಂಶಗಳು, NLWeb ಲಾಭಗಳು ಮತ್ತು ನಮ್ಮ ಪ್ರಯಾಣ ಅನ್ವಯಿಕೆಯಲ್ಲಿ NLWeb ಹೇಗೆ ಕೆಲಸ ಮಾಡುತ್ತದೆ ಎಂಬ ಉದಾಹರಣೆಗಳನ್ನು ನೋಡೋಣ.

### NLWeb ಅಂಶಗಳು

- **NLWeb ಅನ್ವಯಿಕೆ (ಮುಖ್ಯ ಸೇವಾ ಕೋಡ್)**: ನೈಸರ್ಗಿಕ ಭಾಷೆಯ ಪ್ರಶ್ನೆಗಳನ್ನು ಪ್ರಕ್ರಿಯೆ ಮಾಡುವ ವ್ಯವಸ್ಥೆ. ಇದು ಪ್ಲಾಟ್‌ಫಾರ್ಮ್ನ ವಿಭಿನ್ನ ಭಾಗಗಳನ್ನು ಸಂಪರ್ಕಿಸಿ ಪ್ರತಿಕ್ರಿಯೆ ರಚಿಸುತ್ತದೆ. ನೀವು ಇದನ್ನು ವೆಬ್‌ಸೈಟ್ ನ ನೈಸರ್ಗಿಕ ಭಾಷೆ ವೈಶಿಷ್ಟ್ಯಗಳಿಗೆ ಶಕ್ತಿದಾಯಕ ಎಂಜಿನ್ ಎಂದು ಭಾವಿಸಬಹುದು.

- **NLWeb ಪ್ರೋಟೋಕಾಲ್**: ಇದು ವೆಬ್‌ಸೈಟ್ ಜೊತೆ ನೈಸರ್ಗಿಕ ಭಾಷೆ ಸಂವಹನಕ್ಕೆ **ಸಾಧಾರಣ ನಿಯಮಗಳ ಸರಣಿ**. ಇದು JSON ಸ್ವರೂಪದಲ್ಲಿ ಪ್ರತಿಕ್ರಿಯೆಯನ್ನು ಕಳುಹಿಸುತ್ತದೆ (ಸಾಮಾನ್ಯವಾಗಿ Schema.org ಬಳಸಿ). ಇದರ ಉದ್ದೇಶವೆಂದರೆ “AI ವೆಬ್”ಗಾಗಿ ಸರಳ ಮೂಲಭೂತ ರಚನೆ ಸೃಷ್ಟಿಸುವುದು, HTML ಲೆರಂತೆ ಆನ್ಲೈನ್ ದಾಖಲೆ ಹಂಚಿಕೆಯನ್ನು ಸಾಧ್ಯ ಮಾಡಿತು.

- **MCP ಸರ್ವರ್ (ಮಾದರಿ ಸನ್ನಿವೇಶ ಪ್ರೋಟೋಕಾಲ್ ಎಂಡ್‌ಪಾಯಿಂಟ್)**: ಪ್ರತಿ NLWeb ವ್ಯವಸ್ಥೆಯು MCP ಸರ್ವರ್ ಆಗಿಯೂ ಕೆಲಸ ಮಾಡುತ್ತದೆ. ಅಂದರೆ ಅದು AI ವ್ಯವಸ್ಥೆಗಳಿಗೆ “ಕೇಳಿ” ವಿಧಾನ ಮತ್ತು ಡೇಟಾ ಹಂಚಿಕೊಳ್ಳಬಹುದು. ಆದ್ದರಿಂದ ವೆಬ್‌ಸೈಟ್‌ನ ವಿಷಯ ಮತ್ತು ಸಾಮರ್ಥ್ಯಗಳು AI ಏಜೆಂಟ್‌ಗಳಿಗೆ ಬಳಸಲಾಯ್ತು, ಮತ್ತು ತಾಣ “ಏಜೆಂಟ್ ಪರಿಸರ” ಭಾಗವಾಗುವುದು.

- **ಎಂಬೆಡ್ಡಿಂಗ್ ಮಾದರಿಗಳು**: ಇವು ವೆಬ್‌ಸೈಟ್ ವಿಷಯವನ್ನು ಸಂಖ್ಯಾತ್ಮಕ ಪ್ರತಿನಿಧಿಗಳಾದ ವೆಕ್ಟರ್‌ಗಳಾಗಿ ಪರಿವರ್ತಿಸಲು ಉಪಯೋಗಿಸುತ್ತವೆ. ಈ ವೆಕ್ಟರ್‌ಗಳು ಗಣಕ ಯಂತ್ರಗಳು ಹೋಲಿಕೆ ಮತ್ತು ಹುಡುಕಲು ಬಳಸದ ಅರ್ಥವನ್ನು ಸೆರೆಹಿಡಿಯುತ್ತವೆ. ಇವೆ ವಿಶಿಷ್ಟ ಡೇಟಾಬೇಸ್‌ನಲ್ಲಿ ಸಂರಕ್ಷಿಸಲಾಗುತ್ತದೆ, ಮತ್ತು ಬಳಕೆದಾರರು ತಮ್ಮ ಬಯಸಿದ ಎಂಬೆಡ್ಡಿಂಗ್ ಮಾದರಿಯನ್ನು ಆಯ್ಕೆ ಮಾಡಿಕೊಂಡು ಬಳಸಬಹುದು.

- **ವೆಕ್ಟರ್ ಡೇಟಾಬೇಸ್ (ಪುನಃಪಡೆಸುವ ವ್ಯವಸ್ಥೆ)**: ಇದು ವೆಬ್‌ಸೈಟಿನ ವಿಷಯದ ಎಂಬೆಡ್ಡಿಂಗ್‌ಗಳನ್ನು ಸಂರಕ್ಷಿಸುತ್ತದೆ. ಯಾರು ಪ್ರಶ್ನೆ ಕೇಳಿದರೆ, NLWeb ವೇಗವಾಗಿ ಅತ್ಯಂತ ಸಂಬಂಧಿತ ಮಾಹಿತಿಯನ್ನು ತಲುಪಲು ತುಂಬಿ ಡೇಟಾಬೇಸನ್ನು ಪರಿಶೀಲಿಸುತ್ತದೆ. ಅದು ಅವಲಂಬಿತ ಸರಣಿಯಲ್ಲಿ ಸಾಧ್ಯವಾದ ಉತ್ತರಗಳ ಪಟ್ಟಿಯನ್ನು ನೀಡುತ್ತದೆ. NLWeb ವಿವಿಧ ವೆಕ್ಟರ್ ಸಂಗ್ರಹಣಾ ವ್ಯವಸ್ಥೆಗಳಾದ Qdrant, Snowflake, Milvus, Azure AI Search ಮತ್ತು Elasticsearch ಗಳೊಂದಿಗೆ ಕಾರ್ಯ ನಿರ್ವಹಿಸುತ್ತದೆ.

### NLWeb ಉದಾಹರಣೆ

![NLWeb](../../../translated_images/kn/nlweb-diagram.c1e2390b310e5fe4.webp)

ಮತ್ತೆ ನಮ್ಮ ಪ್ರಯಾಣ ಬುಕ್ಕಿಂಗ್ ವೆಬ್‌ಸೈಟ್ ಅನ್ನು ಪರಿಗಣಿಸಿ, ಆದರೆ ಈ ಬಾರಿ ಅದು NLWeb ಯಿಂದ ಶಕ್ತಿಮಂತವಾಗಿದೆ.

1. **ಡೇಟಾ ಅವಗಾಹನೆ**: ಪ್ರಯಾಣ ವೆಬ್‌ಸೈಟಿನ ಇರುವುದು ಉತ್ಪನ್ನ ಕ್ಯಾಟಲಾಗುಗಳು (ವಿಮಾನ ಪಟ್ಟಿ, ಹೋಟೆಲ್ ವಿವರಣೆಗಳು, ಪ್ರವಾಸ ಪ್ಯಾಕೇಜುಗಳು) Schema.org ಬಳಸಿ ಅಥವಾ RSS ಫೀಡಿನಿಂದ ಲೋಡ್ ಮಾಡಲಾಗುತ್ತದೆ. NLWeb ಸಾಧನಗಳು ಈ ರಚಿಸಿದ ಡೇಟಾವನ್ನು ಪಡೆದಿಟ್ಟು, ಎಂಬೆಡ್ಡಿಂಗ್‌ಗಳನ್ನು ಸೃಷ್ಟಿಸಿ ಸ್ಥಳೀಯ ಅಥವಾ ದೂರದ ವೆಕ್ಟರ್ ಡೇಟಾಬೇಸ್‌ನಲ್ಲಿ ಸಂರಕ್ಷಿಸುತ್ತವೆ.

2. **ನೈಸರ್ಗಿಕ ಭಾಷೆ ಪ್ರಶ್ನೆ (ಮನುಷ್ಯ)**: ಬಳಕೆದಾರರು ವೆಬ್‌ಸೈಟ್‌ಗೆ ಭೇಟಿ ನೀಡಿ, ಮೆನುಗಳ ಮೂಲಕ ನ್ಯಾವಿಗೇಟ್ ಮಾಡುವ ಬದಲು, ಚಾಟ್ ಇಂಟರ್ಫೇಸ್‌ನಲ್ಲಿ "ಮುಂದಿನ ವಾರ ಹೊನೊಲುಲುದಲ್ಲಿ ಕೊಳ ಇರುವ ಕುಟುಂಬ ಸ್ನೇಹಿ ಹೋಟೆಲ್ ಹುಡುಕಿ" ಎಂದು ಟೈಪ್ ಮಾಡುತ್ತಾರೆ.

3. **NLWeb ಪ್ರಕ್ರಿಯೆ**: NLWeb ಅನ್ವಯಿಕೆ ಈ ಪ್ರಶ್ನೆಯನ್ನು ಸ್ವೀಕರಿಸುತ್ತದೆ. ಅದನ್ನು ಅನುವಾದಿಸಲು ಎಲ್‌ಎಲ್‌ಎಂಗೆ ಕಳುಹಿಸುತ್ತದೆ ಮತ್ತು ಸಮಾನಾಂತರವಾಗಿ ಸಂಬಂಧಿತ ಹೋಟೆಲ್ ಪಟ್ಟಿ ಹುಡುಕಲು ವೆಕ್ಟರ್ ಡೇಟಾಬೇಸನ್ನು ತಪಾಸಣೆ ಮಾಡುತ್ತೆ.

4. **ನಿಖರ ಫಲಿತಾಂಶಗಳು**: ಎಲ್‌ಎಲ್‌ಎಂ ಡೇಟಾಬೇಸ್‌ನ ಹುಡುಕಿದ ಫಲಿತಾಂಶಗಳನ್ನು ವ್ಯಾಖ್ಯಾನಿಸಿ, "ಕುಟುಂಬ ಸ್ನೇಹಿ", "ಕೊಳ" ಮತ್ತು "ಹೊನೊಲುಲು" ಮಾನದಂಡಗಳ ಆಧಾರದ ಮೇಲೆ ಉತ್ತಮ ಹೊಂದಾಣಿಕೆಯನ್ನು ಗುರುತಿಸಿ, ನೈಸರ್ಗಿಕ ಭಾಷೆ ಉತ್ತರವನ್ನು ರೂಪಿಸುತ್ತಿದೆ. ಮುಖ್ಯವಾಗಿ, ಉತ್ತರವು ವೆಬ್‌ಸೈಟ್‌ನ ಕ್ಯಾಟಲೋಗಿನ ನಿಜವಾದ ಹೋಟೆಲ್ ಮಾಹಿತಿಯೊಂದಿಗಿಂತೆ ಮತ್ತು ಕಲ್ಪಿತ ಮಾಹಿತಿಯನ್ನು ತಪ್ಪಿಸುತ್ತದೆ.

5. **AI ಏಜೆಂಟ್ ಸಂವಹನ**: NLWeb MCP ಸರ್ವರ್ ಆಗಿ ಸೇವೆ ನೀಡುವುದರಿಂದ, ಹೊರಗಿನ AI ಪ್ರಯಾಣ ಏಜೆಂಟ್ ಸಹ ಈ ವೆಬ್‌ಸೈಟ್‌ನ NLWeb ಘಟಕದೊಂದಿಗೆ ಸಂಪರ್ಕ ಮಾಡಬಹುದು. AI ಏಜೆಂಟ್ ನೇರವಾಗಿ ವೆಬ್‌ಸೈಟ್‌ಗೆ `ask` MCP ವಿಧಾನ ಬಳಸಿ ಪ್ರಶ್ನೆ ಕೇಳಬಹುದು: `ask("ಹೊನೊಲುಲು ಪ್ರದೇಶದಲ್ಲಿ ಹೋಟೆಲ್ ಶಿಫಾರಸ್ಯಾದ ವಿಗನ್ ಸ್ನೇಹಿ ರೆಸ್ಟೋರೆಂಟ್‌ಗಳಿವೆ吗?")`. NLWeb ಘಟಕ ಇದನ್ನು ಪ್ರಕ್ರಿಯೆ ಮಾಡಿ ರೆಸ್ಟೋರೆಂಟ್ ಮಾಹಿತಿ (ಲೋಡ್ ಆಗಿದ್ದರೆ) ಡೇಟಾಬೇಸ್ ಬಳಸಿಕೊಂಡು ರಚಿಸಿದ JSON ಪ್ರತಿಕ್ರಿಯೆಯನ್ನು ನೀಡುತ್ತದೆ.

### MCP/A2A/NLWeb ಬಗ್ಗೆ ಇನ್ನಷ್ಟು ಪ್ರಶ್ನೆಗಳಿವೆಯೇ?

ಇನ್ನಷ್ಟು ಕಲಿಯುವವರನ್ನು ಭೇಟಿಯಾಗಲು, ಆಫೀಸ್ ಕಲಿಕೆಯಲ್ಲಿ ಹಾಜರಾಗಲು ಮತ್ತು ನಿಮ್ಮ AI ಏಜೆಂಟ್ ಪ್ರಶ್ನೆಗಳಿಗೆ ಉತ್ತರ ಪಡೆಯಲು [Microsoft Foundry Discord](https://discord.com/invite/ATgtXmAS5D) ಗೆ ಸೇರಿ.
