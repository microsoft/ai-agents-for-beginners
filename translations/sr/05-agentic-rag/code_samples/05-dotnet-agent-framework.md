# 🔍 Enterprise RAG са Microsoft Foundry (.NET)

## 📋 Циљеви учења

Овај нотебоок демонстрира како изградити системе за генерацију уз подршку претраге (Retrieval-Augmented Generation, RAG) за ентерпрајс коришћење користећи Microsoft Agent Framework у .NET-у са Microsoft Foundry. Научићете како да креирате производне агенте који могу претраживати кроз документе и пружати тачне, контекстно свесне одговоре са ентерпрајс безбедношћу и скалабилношћу.

**Карактеристике Enterprise RAG које ћете изградити:**
- 📚 **Интелигенција докумената**: Напредна обрада докумената уз Azure AI сервисе
- 🔍 **Семантичка претрага**: Високоперформантна претрага вектора са ентерпрајс карактеристикама
- 🛡️ **Интеграција безбедности**: Приступ заснован на улогама и шаблони за заштиту података
- 🏢 **Скалабилна архитектура**: Производни RAG системи са мониторингом

## 🎯 Enterprise RAG архитектура

### Основне ентерпрајс компоненте
- **Microsoft Foundry**: Управљана ентерпрајс AI платформа са безбедношћу и усклађеношћу
- **Перзистентни агенти**: Агенте са стањем, историјом разговора и управљањем контекстом
- **Управљање векторским складиштем**: Индексирање и претрага докумената ентерпрајс квалитета
- **Интеграција идентитета**: Аутентификација Azure AD и контролa приступа заснована на улогама

### Предности .NET ентерпрајса
- **Безбедност типова**: Валидација у време компајлирања за RAG операције и структуре података
- **Асинхрона перформанса**: Некопирајућа обрада докумената и претрага
- **Управљање меморијом**: Ефикасна употреба ресурса за велике колекције докумената
- **Интеграциони шаблони**: Нативна интеграција Azure сервиса са dependency injection

## 🏗️ Техничка архитектура

### Enterprise RAG pipeline
```
Document Upload → Security Validation → Vector Processing → Index Creation
                      ↓                    ↓                  ↓
User Query → Authentication → Semantic Search → Context Ranking → AI Response
```

### Основне .NET компоненте
- **Azure.AI.Agents.Persistent**: Управљање ентерпрајс агентима са перзистентношћу стања
- **Azure.Identity**: Интегрисана аутентификација за безбедан приступ Azure сервисима
- **Microsoft.Agents.AI.AzureAI**: Имплементација агентског оквира оптимизованог за Azure
- **System.Linq.Async**: Високоперформантне асинхроне LINQ операције

## ⚙️ Предуслови и подешавање

**Развојно окружење:**
- .NET 9.0 SDK или новији
- Visual Studio 2022 или VS Code са C# екстензијом
- Azure претплата са приступом Microsoft Foundry

**Потребни NuGet пакети:**
```xml
<PackageReference Include="Microsoft.Extensions.AI" Version="9.9.0" />
<PackageReference Include="Azure.AI.Agents.Persistent" Version="1.2.0-beta.5" />
<PackageReference Include="Azure.Identity" Version="1.15.0" />
<PackageReference Include="System.Linq.Async" Version="6.0.3" />
<PackageReference Include="DotNetEnv" Version="3.1.1" />
```

**Подешавање Azure аутентификације:**
```bash
# Инсталирајте Azure CLI и аутентификујте се
az login
az account set --subscription "your-subscription-id"
```

**Конфигурација окружења:**
* Конфигурација Microsoft Foundry (аутоматски путем Azure CLI)
* Обавезно сте аутентификовани на исправну Azure претплату
