# AGENTS.md

## Преглед пројекта

Овај репозиторијум садржи "AI Агенте за почетнике" - свеобухватни едукативни курс који учи све што је потребно за израду AI агената. Курс се састоји од 18 лекција које покривају основе, дизајнерске шаблоне, фрејмворке и продукцијско постављање AI агената.

**Кључне технологије:**
- Python 3.12+
- Jupyter нотебоокови за интерактивно учење
- AI фрејмворкови: Microsoft Agent Framework (MAF)
- Azure AI сервисе: Microsoft Foundry, Microsoft Foundry Agent Service V2

**Архитектура:**
- Структура заснована на лекцијама (директоријуми 00-15+)
- Свака лекција садржи: README документацију, примере кода (Jupyter нотебоокови) и слике
- Подршка за више језика преко система аутоматског превођења
- Један Python нотебоок по лекцији користећи Microsoft Agent Framework

## Команде за подешавање

### Захтеви
- Python 3.12 или новији
- Azure претплата (за Microsoft Foundry)
- Инсталиран и аутентификован Azure CLI (`az login`)

### Почетно подешавање

1. **Клонирајте или форкујте репозиторијум:**
   ```bash
   gh repo fork microsoft/ai-agents-for-beginners --clone
   # ИЛИ
   git clone https://github.com/microsoft/ai-agents-for-beginners.git
   cd ai-agents-for-beginners
   ```

2. **Направите и активирајте Python виртуелно окружење:**
   ```bash
   python3 -m venv venv
   source venv/bin/activate  # На Windows-у: venv\Scripts\activate
   ```

3. **Инсталирајте зависности:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Подесите променљиве окружења:**
   ```bash
   cp .env.example .env
   # Измените .env са вашим API кључевима и крајњим тачкама
   ```

### Потребне променљиве окружења

За **Microsoft Foundry** (обавезно):
- `AZURE_AI_PROJECT_ENDPOINT` - крајња тачка Microsoft Foundry пројекта
- `AZURE_AI_MODEL_DEPLOYMENT_NAME` - име постављања модела (нпр. gpt-4o)

За **Azure AI Search** (Лекција 05 - RAG):
- `AZURE_SEARCH_SERVICE_ENDPOINT` - крајња тачка Azure AI Search-а
- `AZURE_SEARCH_API_KEY` - Azure AI Search API кључ

Аутентификација: Покрените `az login` пре покретања нотебоокова (користи `AzureCliCredential`).

- Спремно за продукцију са уграђеном опсервабилношћу
- Шаблон датотеке: `*-python-agent-framework.ipynb`

## Додатне напомене

### Чести проблеми

1. **Неусаглашеност верзије Python-а:**
   - Обавезно користите Python 3.12+
   - Неки пакети не раде са старијим верзијама
   - Користите `python3 -m venv` да експлицитно одредите верзију Python-а

2. **Променљиве окружења:**
   - Увек направите `.env` из `.env.example`
   - Не commit-ујте `.env` фајл (налази се у `.gitignore`)
   - Пријавите се са `az login` за аутентификацију без кључа преко Entra ID

3. **Конфликти пакета:**
   - Користите свеже виртуелно окружење
   - Инсталирајте из `requirements.txt` уместо појединачних пакета
   - Неки нотебоокови могу захтевати додатне пакете наведене у markdown ћелијама

4. **Azure сервисе:**
   - Azure AI сервисима је потребна активна претплата
   - Неке функције су специфичне за регију
   - Обезбедите да ваше Azure OpenAI постављање модела подржава Responses API

## Контекст специфичан за пројекат

### Подршка за више језика

Овај репозиторијум користи аутоматизовани систем превођења:
- Подржано преко 50 језика
- Преводи у директоријумима `/translations/<lang-code>/`
- GitHub Actions покреће ажурирања превода
- Изворни фајлови су на енглеском у корену репозиторијума

### Структура лекција

Свака лекција прати доследан образац:
1. Видео сличица са линком
2. Писани садржај лекције (README.md)
3. Примери кода у више фрејмворка
4. Циљеви учења и претпоставке
5. Повезани додатни ресурси за учење

### Номенклатура примера кода

Формат: `<lesson-number>-python-agent-framework.ipynb`
- `01-python-agent-framework.ipynb` - Лекција 1, MAF Python
- `14-sequential.ipynb` - Лекција 14, MAF напредни шаблони

### Специјални директоријуми

- `translated_images/` - Локализоване слике за преводе
- `images/` - Оригиналне слике за енглески садржај
- `.devcontainer/` - Конфигурација VS Code окружења за развој
- `.github/` - GitHub Actions пипелине и шаблони

### Зависности

Кључни пакети из `requirements.txt`:
- `agent-framework` - Microsoft Agent Framework
- `a2a-sdk` - Подршка за протокол Agent-to-Agent
- `azure-ai-inference`, `azure-ai-projects` - Azure AI сервисе
- `azure-identity` - Azure аутентификација (AzureCliCredential)
- `azure-search-documents` - Интеграција Azure AI Search-а
- `mcp[cli]` - Подршка за Model Context Protocol
