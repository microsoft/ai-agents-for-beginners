# AGENTS.md

## Преглед пројекта

Овај репозиторијум садржи "AI Агенти за почетнике" - обухватан едукативни курс који учи све што је потребно за израду AI агената. Курс се састоји од 18 лекција које покривају основе, дизајн шаблоне, оквире и производно постављање AI агената.

**Кључне технологије:**
- Python 3.12+
- Jupyter свеске за интерактивно учење
- AI оквири: Microsoft Agent Framework (MAF)
- Azure AI сервиси: Microsoft Foundry, Azure AI Foundry Agent Service V2

**Архитектура:**
- Структура заснована на лекцијама (фасцикле 00-15+)
- Свaka лекција садржи: README документацију, примерке кода (Jupyter свеске), и слике
- Подршка за више језика путем аутоматизованог система за превођење
- Једна Python свеска по лекцији која користи Microsoft Agent Framework

## Команде за постављање

### Захтеви
- Python 3.12 или новији
- Azure претплата (за Azure AI Foundry)
- Инсталиран и аутентификован Azure CLI (`az login`)

### Почетно постављање

1. **Клонирајте или форкните репозиторијум:**
   ```bash
   gh repo fork microsoft/ai-agents-for-beginners --clone
   # ИЛИ
   git clone https://github.com/microsoft/ai-agents-for-beginners.git
   cd ai-agents-for-beginners
   ```

2. **Направите и активирајте Python виртуелно окружење:**
   ```bash
   python3 -m venv venv
   source venv/bin/activate  # На Windows: venv\Scripts\activate
   ```

3. **Инсталирајте зависности:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Поставите променљиве окружења:**
   ```bash
   cp .env.example .env
   # Уреди .env са својим API кључевима и крајњим тачкама
   ```

### Потребне променљиве окружења

За **Azure AI Foundry** (обавезно):
- `AZURE_AI_PROJECT_ENDPOINT` - крајња тачка Azure AI Foundry пројекта
- `AZURE_AI_MODEL_DEPLOYMENT_NAME` - име deployment-а модела (нпр. gpt-4o)

За **Azure AI Search** (лекција 05 - RAG):
- `AZURE_SEARCH_SERVICE_ENDPOINT` - крајња тачка Azure AI претраге
- `AZURE_SEARCH_API_KEY` - API кључ Azure AI претраге

Аутентификација: Покрените `az login` пре покретања свески (користи `AzureCliCredential`).

## Ток рада у развоју

### Покретање Jupyter свески

Свaka лекција садржи више Jupyter свески за различите оквире:

1. **Покрените Jupyter:**
   ```bash
   jupyter notebook
   ```

2. **Идите у фасциклу лекције** (нпр. `01-intro-to-ai-agents/code_samples/`)

3. **Отворите и покрените свеске:**
   - `*-python-agent-framework.ipynb` - Користећи Microsoft Agent Framework (Python)
   - `*-dotnet-agent-framework.ipynb` - Користећи Microsoft Agent Framework (.NET)

### Рад са Microsoft Agent Framework

**Microsoft Agent Framework + Azure AI Foundry:**
- Потребна Azure претплата
- Користи `AzureAIProjectAgentProvider` за Agent Service V2 (агенти видљиви у Foundry порталу)
- Спреман за производњу са уграђеном уочљивошћу
- Образац имена датотека: `*-python-agent-framework.ipynb`

## Контекст специфичан за пројекат

### Подршка за више језика

Овај репозиторијум користи аутоматизован систем превођења:
- Подржано 50+ језика
- Преводи у фасциклама `/translations/<lang-code>/`
- GitHub Actions workflow управља ажурирањима превода
- Изворне датотеке су на енглеском у корену репозиторијума

### Структура лекције

Свaka лекција следи конзистентан образац:
1. Видео минијатура са линком
2. Писана лекција (README.md)
3. Примери кода у више оквира
4. Циљеви учења и предуслови
5. Додатни ресурси за учење уз линкове

### Именовање примера кода

Формат: `<lesson-number>-python-agent-framework.ipynb`
- `01-python-agent-framework.ipynb` - Лекција 1, MAF Python
- `14-sequential.ipynb` - Лекција 14, напредни MAF шаблони

### Специјалне фасцикле

- `translated_images/` - Локализоване слике за преводе
- `images/` - Оригиналне слике за енглески садржај
- `.devcontainer/` - Конфигурација развојног контејнера за VS Code
- `.github/` - GitHub Actions workflows и шаблони

### Зависности

Кључни пакети из `requirements.txt`:
- `agent-framework` - Microsoft Agent Framework
- `a2a-sdk` - Подршка за Agent-to-Agent протокол
- `azure-ai-inference`, `azure-ai-projects` - Azure AI сервиси
- `azure-identity` - Azure аутентификација (AzureCliCredential)
- `azure-search-documents` - Интеграција Azure AI претраге
- `mcp[cli]` - Подршка за Model Context Protocol
