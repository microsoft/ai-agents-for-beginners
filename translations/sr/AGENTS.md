# AGENTS.md

## Преглед пројекта

Овај репозиторјум садржи "AI агенте за почетнике" - свеобухватан образовни курс који учи све што је потребно за изградњу AI агената. Курс се састоји од 18 лекција (бројаних од 00 до 18) које покривају основе, дизајнерске шаблоне, фрејмворке, продукцијско имплементирање, локалне/уређајне агенте и безбедност AI агената.

**Кључне технологије:**
- Python 3.12+
- Јупитер нотебоокови за интерактивно учење
- AI фрејмворци: Microsoft Agent Framework (MAF)
- Azure AI услуге: Microsoft Foundry, Microsoft Foundry Agent Service V2

**Архитектура:**
- Структура заснована на лекцијама (директоријуми 00-18)
- Свакa лекција садржи: README документацију, пример кода (Јупитер нотебоокове) и слике
- Подршка за више језика путем аутоматизованог система превода
- Један Python нотебоок по лекцији који користи Microsoft Agent Framework

## Команде за подешавање

### Захтеви
- Python 3.12 или новији
- Azure претплата (за Microsoft Foundry)
- Azure CLI инсталиран и аутентификован (`az login`)

### Почетно подешавање

1. **Клонирајте или форкујте репозиторјум:**
   ```bash
   gh repo fork microsoft/ai-agents-for-beginners --clone
   # OR
   git clone https://github.com/microsoft/ai-agents-for-beginners.git
   cd ai-agents-for-beginners
   ```

2. **Направите и активирајте Python виртуелно окружење:**
   ```bash
   python3 -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   ```

3. **Инсталирајте зависности:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Подесите променљиве окружења:**
   ```bash
   cp .env.example .env
   # Edit .env with your API keys and endpoints
   ```

### Потребне променљиве окружења

За **Microsoft Foundry** (потребно):
- `AZURE_AI_PROJECT_ENDPOINT` - Microsoft Foundry крајња тачка пројекта
- `AZURE_AI_MODEL_DEPLOYMENT_NAME` - Име модела за имплементацију (нпр. gpt-5-mini)

За **Azure AI Search** (лекција 05 - RAG):
- `AZURE_SEARCH_SERVICE_ENDPOINT` - Azure AI Search крајња тачка
- `AZURE_SEARCH_API_KEY` - Azure AI Search API кључ

Аутентификација: Покрените `az login` пре покретања нотебоокова (користи `AzureCliCredential`).

## Радни ток развоја

### Покретање Јупитер нотебоокова

Свакa лекција садржи више Јупитер нотебоокова за различите фрејмворке:

3. **Отворите и покрените нотебоокове:**
   - `*-python-agent-framework.ipynb` - Користећи Microsoft Agent Framework (Python)
   - `*-dotnet-agent-framework.ipynb` - Користећи Microsoft Agent Framework (.NET)

### Рад са Microsoft Agent Framework

**Microsoft Agent Framework + Microsoft Foundry:**
- Захтева Azure претплату
- Користи `FoundryChatClient` за Agent Service V2 (агенти видљиви у Foundry порталу)
- Спремно за продукцију са уграђеним посматрањем
- Образац имена фајлова: `*-python-agent-framework.ipynb`

### Smoke-тестирање применених агената

За лекције где је агент имплементиран као Microsoft Foundry хостирани агент (01, 04, 05, 16), репо садржи smoke-тест каталоге у `tests/` који се покрећу помоћу `.github/workflows/smoke-test.yml` workflow кроз [AI Smoke Test](https://github.com/marketplace/actions/ai-smoke-test) акцију. Погледајте [tests/README.md](./tests/README.md) за мапирање каталога-преко-лекције-до-агента. Лекција 17 ради локално са Foundry Local и нема хостирану крајњу тачку, па се валидира директним покретањем свог нотебоока.

## Додатне напомене

### Чести проблеми

1. **Неслагање верзије Python-а:**
   - Убедите се да користите Python 3.12+
   - Неки пакети можда неће радити на старијим верзијама
   - Користите `python3 -m venv` да јасно одредите Python верзију

2. **Променљиве окружења:**
   - Увек креирајте `.env` од `.env.example`
   - Не комитујте `.env` фајл (налази се у `.gitignore`)
   - Пријавите се са `az login` за безкључну Entra ID аутентификацију

3. **Конфликти пакета:**
   - Користите свеже виртуелно окружење
   - Инсталирајте из `requirements.txt` уместо појединачних пакета
   - Неки нотебоокови могу захтевати додатне пакете поменуте у њиховим markdown ћелијама

4. **Azure услуге:**
   - Azure AI услуге захтевају активну претплату
   - Неки функционалности зависе од региона
   - Убедите се да ваша Azure OpenAI имплементација подржава Responses API

1. Видео минијатура са линком
