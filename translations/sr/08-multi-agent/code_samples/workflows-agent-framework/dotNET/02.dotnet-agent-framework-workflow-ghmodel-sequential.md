# ⏩ Секвенцијални радни токови агената са Azure OpenAI (Responses API) (.NET)

## 📋 Напредни туторијал секвенцијалне обраде

Овај нотебук демонстрира **шаблоне секвенцијалних радних токова** користећи Microsoft Agent Framework за .NET и Azure OpenAI (Responses API). Научићете како да изградите сложене, корак по корак цевоводе за обраду у којима агенти извршавају задатке у одређеном редоследу, при чему сваки корак надограђује резултате претходног.

## 🎯 Циљеви учења

### 🔄 **Архитектура секвенцијалне обраде**
- **Линеарни дизајн радног тока**: Креирање корак по корак цевовода са јасним зависностима
- **Управљање стањем**: Одржавање контекста и протока података кроз секвенцијалне фазе радног тока
- **Azure OpenAI (Responses API)**: Коришћење Azure OpenAI модела у вишестепеним .NET радним токовима
- **Шаблони предузећа**: Изградња продукцијски спремних секвенцијалних система обраде

### 🏗️ **Напредни секвенцијални шаблони**
- **Обрада са контролном тачком**: Имплементација валидационих чекпоинтова између фаза радног тока
- **Сачување контекста**: Одржавање стања и акумулираног знања кроз све фазе
- **Пропагација грешака**: Љубазно руковање отказима у ланцима секвенцијалне обраде
- **Оптимизација перформанси**: Ефикасно секвенцијално извршавање са минималним трошковима

### 🏢 **Пословне секвенцијалне апликације**
- **Цевовод за обраду докумената**: Вишестепена анализа, трансформација и валидација докумената
- **Радни токови за осигурање квалитета**: Секвенцијални преглед, валидација и процесе одобрења
- **Цевовод за производњу садржаја**: Истраживање → Писање → Уређивање → Преглед → Објава
- **Аутоматизација пословних процеса**: Многоступне пословне радне токове са јасним фазним зависностима

## ⚙️ Захтеви и подешавање

### 📦 **Потребни NuGet пакети**

Есенцијални пакети за .NET секвенцијалне радне токове:

```xml
<!-- Core AI Framework -->
<PackageReference Include="Microsoft.Extensions.AI" Version="9.9.0" />

<!-- Azure OpenAI (Responses API) -->
<PackageReference Include="Azure.AI.OpenAI" Version="2.1.0" />

<!-- Azure Identity and Async LINQ Support -->
<PackageReference Include="Azure.Identity" Version="1.15.0" />
<PackageReference Include="System.Linq.Async" Version="6.0.3" />

<!-- Local Agent Framework References -->
<!-- Microsoft.Agents.AI.dll - Core agent abstractions -->
<!-- Microsoft.Agents.AI.OpenAI.dll - Azure OpenAI (Responses API) integration -->
```

### 🔑 **Конфигурација Azure OpenAI**

**Подешавање окружења (.env фајл):**
```env
AZURE_OPENAI_ENDPOINT=https://<your-resource>.openai.azure.com
AZURE_OPENAI_DEPLOYMENT=gpt-4o-mini
```

**Управљање конфигурацијом:**
```csharp
// Load environment variables securely
Env.Load("../../../.env");
var azureEndpoint = Environment.GetEnvironmentVariable("AZURE_OPENAI_ENDPOINT");
var deployment = Environment.GetEnvironmentVariable("AZURE_OPENAI_DEPLOYMENT");
```

### 🏗️ **Архитектура секвенцијалног радног тока**

```mermaid
graph TD
    A[Initial Input] --> B[Stage 1: Аналитички агент]
    B --> C[Контролна тачка 1]
    C --> D[Stage 2: Обрадни агент]
    D --> E[Контролна тачка 2]
    E --> F[Stage 3: Валидациони агент]
    F --> G[Коначни резултат]
    
    H[Контекст стања] --> B
    H --> D
    H --> F
    
    I[Azure OpenAI (Responses API)] --> B
    I --> D
    I --> F
```

**Кључне компоненте:**
- **Секвенцијални агенти**: Специјализовани агенти за сваку фазу обраде
- **Контекст стања**: Одржава акумулиране податке и одлуке кроз фазе
- **Контролне тачке**: Валидациони чекпоинти између фаза за осигурање квалитета и конзистентности
- **Azure OpenAI клијент**: Конзистентан приступ AI моделу кроз све фазе радног тока

## 💻 Покретање кода

Комплетна имплементација је доступна у `02.dotnet-agent-framework-workflow-ghmodel-sequential.cs`. Овај фајл демонстрира **тростепени радни ток за анализу намештаја**:

1. **Фаза 1 - Продајни агент**: Анализира слике намештаја и даје предлоге за куповину
2. **Фаза 2 - Агент за цену**: Пружа детаљне цене и опције буџета
3. **Фаза 3 - Агент за понуде**: Генерише професионални документ понуде у Markdown формату

### 🏗️ **Архитектура радног тока**

```
Image Input → Sales Analysis → Price Estimation → Quote Generation → Final Output
```

Сваки агент:
- Прима излаз претходне фазе као контекст
- Надограђује претходну анализу својом специјализованом експертизом
- Одржава континуитет радног тока кроз управљање стањем

### 🚀 Покретање примера

**Захтеви:**
- Ставите слику намештаја у `../imgs/home.png` (или ажурирајте променљиву `imgPath`)
- Конфигуришите `.env` фајл са вашим Azure OpenAI ендпоинтом и деплојментом, затим пријавите се са `az login`

```bash
# Учините скрипт извршним (Unix/Linux/macOS)
chmod +x 02.dotnet-agent-framework-workflow-ghmodel-sequential.cs

# Покрените секвенцијални ток рада
./02.dotnet-agent-framework-workflow-ghmodel-sequential.cs
```

Или на Windows-у:
```powershell
dotnet run 02.dotnet-agent-framework-workflow-ghmodel-sequential.cs
```

### 📝 Очекивани резултат

Радни ток ће:
1. **Продајни агент**: Идентификовати ставке намештаја са слике и дати препоруке
2. **Агент за цену**: Додати детаљну анализу цена са категоријама буџета и препоруке за куповину
3. **Агент за понуде**: Генерисати форматски документ понуде са свим синтетисаним информацијама

Коначни излаз биће свеобухватна, професионална понуда за намештај базирана на анализи слике.

### 🎯 Примена у стварном свету

Овај секвенцијални шаблон је идеалан за:
- **Е-трговину**: Анализа производа → Цене → Генерисање понуде
- **Непокретности**: Анализа некретнина → Процена → Креирање листинга
- **Осигурање**: Анализа потраживања → Процена → Генерисање понуде
- **Креирање садржаја**: Истраживање → Писање → Уређивање → Објављивање

### 🔍 Разумевање протока стања

Сваки агент у низу прима:
- **Оригинални улаз**: Почетну поруку корисника (слика + текст)
- **Излазе претходних агената**: Све одговоре претходних агената у историји разговора
- **Акумулирани контекст**: Потпуно стање одржавано током свих фаза радног тока

Ово омогућава софистицирану вишестепену обраду где сваки агент надограђује свеобухватни контекст из претходних фаза.
