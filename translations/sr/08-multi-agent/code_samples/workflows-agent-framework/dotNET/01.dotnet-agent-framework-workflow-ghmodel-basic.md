# 🔄 Основни токови рада агената са Azure OpenAI (Responses API) (.NET)

## 📋 Туторијал за оркестрацију токова рада

Овај нотебоок демонстрира како изградити софистициране **токове рада агената** користећи Microsoft Agent Framework за .NET и Azure OpenAI (Responses API). Научићете како да креирате вишестепене пословне процесе где AI агенти сарађују како би извршили сложене задатке кроз структуиране обрасце оркестрације.

## 🎯 Циљеви учења

### 🏗️ **Основе архитектуре токова рада**
- **Креатор токова рада**: Дизајнирајте и оркестрирајте сложене вишестепене AI процесе
- **Координација агената**: Координирајте више специјализованих агената у оквиру токова рада
- **Azure OpenAI (Responses API)**: Искористите Azure OpenAI Responses API у токовима рада
- **Визуелни дизајн токова рада**: Креирајте и визуелизујте структуре токова рада ради бољег разумевања

### 🔄 **Обрасци оркестрације процеса**
- **Секвенцијална обрада**: Повежите више задатака агената у логичном редоследу
- **Управљање стањем**: Одржавање контекста и протока података кроз фазе токова рада
- **Обрада грешака**: Имплементирајте робусно опорављање од грешака и отпорност токова рада
- **Оптимизација перформанси**: Дизајнирајте ефикасне токове рада за пословне операције на великој скали

### 🏢 **Пословне апликације токова рада**
- **Аутоматизација пословних процеса**: Аутоматизујте сложене организационе токове рада
- **Пипелин продукције садржаја**: Уређивачки токови рада са прегледом и фазама одобрења
- **Аутоматизација корисничке службе**: Вишестепено решавање корисничких упита
- **Токови рада за обраду података**: ETL токови рада са AI покретаном трансформацијом

## ⚙️ Захтеви и подешавање

### 📦 **Потребне NuGet библиотеке**

Ова демонстрација токова рада користи неколико кључних .NET пакета:

```xml
<!-- Core AI Framework -->
<PackageReference Include="Microsoft.Extensions.AI" Version="9.9.0" />

<!-- Azure OpenAI (Responses API) -->
<PackageReference Include="Azure.AI.OpenAI" Version="2.1.0" />
<PackageReference Include="Azure.Identity" Version="1.13.1" />

<!-- Agent Framework (Local Development) -->
<!-- Microsoft.Agents.AI.dll - Core agent abstractions -->
<!-- Microsoft.Agents.AI.OpenAI.dll - Azure OpenAI (Responses API) integration -->

<!-- Configuration and Environment -->
<PackageReference Include="DotNetEnv" Version="3.1.1" />
```

### 🔑 **Конфигурација Azure OpenAI**

**Подешавање окружења (.env фајл):**
```env
AZURE_OPENAI_ENDPOINT=https://<your-resource>.openai.azure.com
AZURE_OPENAI_DEPLOYMENT=gpt-4o-mini
```

**Приступ Azure OpenAI:**
1. Креирајте Azure OpenAI ресурс у Azure порталу
2. Деплујујте модел (на пример, `gpt-4o-mini`) и запишите име деплоја
3. Пријавите се са `az login` и конфигуришите променљиве окружења као што је приказано горе

### 🏗️ **Преглед архитектуре токова рада**

```mermaid
graph TD
    A[Креатор радних токова] --> B[Регистар агената]
    B --> C[Покретач извршења радних токова]
    C --> D[Agent 1: Генератор садржаја]
    C --> E[Agent 2: Рецензент садржаја] 
    D --> F[Резултати радних токова]
    E --> F
    G[Azure OpenAI (Responses API)] --> D
    G --> E
```

**Кључне компоненте:**
- **WorkflowBuilder**: Главни мотор за оркестрацију и дизајнирање токова рада
- **AIAgent**: Појединачни специјализовани агенти са специфичним способностима
- **Azure OpenAI Клијент**: Интеграција са Azure OpenAI Responses API-јем
- **Context извршења**: Управљањe стањем и протоком података између фаза токова рада

## 🏢 **Пословне предности**

### 🎯 **Поузданост и скалабилност**
- **Детерминистичко извршење**: Консистентни и понављани резултати токова рада
- **Опоравак од грешака**: Грациозно руковање кваровима у било којој фази токова рада
- **Праћење перформанси**: Прати мерење извршења и могућности оптимизације
- **Управљање ресурсима**: Ефикасна расподела и коришћење AI ресурса моделa

### 🔒 **Безбедност и усклађеност**
- **Сигурна аутентикација**: Microsoft Entra ID аутентикација преко `az login` (AzureCliCredential)
- **Аудит трагови**: Потпуна евиденција извршења токова рада и тачака одлучивања
- **Контрола приступа**: Грануларне дозволе за извршење и праћење токова рада
- **Приватност података**: Безбедно руковање осетљивим информацијама током целих токова рада

### 📊 **Опсервација и управљање**
- **Визуелни дизајн токова рада**: Јасан приказ токова процеса и зависности
- **Праћење извршења**: Праћење напретка и перформанси токова рада у реалном времену
- **Извештавање о грешкама**: Детаљна анализа грешака и могућности за дебаговање
- **Аналитика перформанси**: Метрике за оптимизацију и планирање капацитета

Хајде да изградимо ваш први AI ток рада спреман за предузеће! 🚀

## 💻 Покретање кода

Комплетна имплементација доступна је у `01.dotnet-agent-framework-workflow-ghmodel-basic.cs`. Овај фајл демонстрира:

1. **Конфигурацију окружења** - Учитавање конфигурације Azure OpenAI из `.env` фајла
2. **Подешавање Azure OpenAI клијента** - Конфигурација клијента за коришћење Azure OpenAI Responses API-ја
3. **Креирање агената** - Дефинисање специјализованих агената (Front Desk и Concierge)
4. **Креатор токова рада** - Креирање тока рада са више агената и секвенцијална обрада
5. **Извршење токова рада** - Покретање тока рада са стриминг резултатима

### 🚀 Покретање примера

```bash
# Означите скрипт као извршни (Unix/Linux/macOS)
chmod +x 01.dotnet-agent-framework-workflow-ghmodel-basic.cs

# Покрените ток рада
./01.dotnet-agent-framework-workflow-ghmodel-basic.cs
```

Или на Windows-у:
```powershell
dotnet run 01.dotnet-agent-framework-workflow-ghmodel-basic.cs
```

### 📝 Очекујани излаз

Ток рада ће:
1. Примити ваш захтев за путовање ("Желео бих да идем у Париз")
2. Front Desk агент даје први предлог
3. Concierge агент прегледа и унапређује предлог
4. Коначни излаз приказује цео ток разговора

- Додавати више агената за креирање сложених вишестепених токова рада
- Мењати поруку корисника да тестирате различите сценарије
