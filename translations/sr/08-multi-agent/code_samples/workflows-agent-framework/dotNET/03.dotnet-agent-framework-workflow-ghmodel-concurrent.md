## 💻 Покретање кода

Комплетна имплементација доступна је у `03.dotnet-agent-framework-workflow-ghmodel-concurrent.cs`. Овај фајл демонстрира **Fan-Out/Fan-In истовремени ток рада** за планирање путовања:

### 🏗️ **Архитектура тока рада**

```
User Request → ConcurrentStartExecutor → [Researcher Agent || Planner Agent] → ConcurrentAggregationExecutor → Final Output
```

**Кључне компоненте:**

1. **ConcurrentStartExecutor**: Истовремено шаље кориснички захтев свим агентима
2. **Researcher Agent**: Анализира дестинације и атракције истовремено
3. **Planner Agent**: Паралелно креира детаљне планове путовања
4. **ConcurrentAggregationExecutor**: Прикупља и спаја резултате обоје агената

### 🎯 **Fan-Out/Fan-In образац**

Овај ток рада демонстрира класичан **Fan-Out/Fan-In** образац:
- **Fan-Out**: Једна улазна порука се истовремено емитује више агената
- **Истовремена обрада**: Више агената ради паралелно на истом задатку
- **Fan-In**: Резултати свих агената се прикупљају и агрегирају у један излаз

### 🔍 Разумевање прилагођених извршилаца

**ConcurrentStartExecutor:**
- Имплементира `IMessageHandler<string>` за прихват улаза у виду низа
- Шаље поруке свим повезаним агентима
- Шаље `TurnToken` да покрене истовремену обраду

**ConcurrentAggregationExecutor:**
- Имплементира `IMessageHandler<ChatMessage>` за примање одговора агената
- Сакупља поруке на безбедан начин за више нитова
- Агрегира када стигну сви очекивани одговори
- Враћа коначан резултат користећи `context.YieldOutputAsync()`

### ⚡ Предности перформанси

**Истовремени у односу на секвенцијални:**
- Секвенцијални: Агент1 (30с) → Агент2 (30с) = **укупно 60 секунди**
- Истовремени: Агент1 (30с) || Агент2 (30с) = **укупно 30 секунди**

**Побољшање пропусности**: До N пута брже за N истовремених агената (у зависности од оптерећења и ресурса)

### 🛡️ Руководење грешкама

Ток рада љубазно управља појединачним кваровима агената:
- Ако један агент не успе, други настављају са обрадом
- Агрегатор може имплементирати логику тајмаута
- Део резултата може бити враћен ако је потребно
