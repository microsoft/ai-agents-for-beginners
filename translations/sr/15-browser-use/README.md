# Израда агената за коришћење рачунара (CUA)

Агенти за коришћење рачунара могу комуницирати са веб страницама исто као и људи: отварањем прегледача, прегледањем странице и предузимањем најбоље следеће акције на основу онога што виде. У овој лекцији направићете агента за аутоматизацију прегледача који претражује Airbnb, извлачи структуиране податке о огласима и идентификује најјефтинији смештај у Стокхолму.

Лекција комбинује Browser-Use за навигацију покретану вештачком интелигенцијом, Playwright и Chrome DevTools Protocol (CDP) за контролу прегледача, Azure OpenAI за закључивање омогућено видео утицајем и Pydantic за структуирано извртање.

## Увод

Ова лекција обухвата:

- Разумевање када су агенти за коришћење рачунара боља опција од аутоматизације искључиво преко API-ја
- Комбинацију Browser-Use са Playwright и CDP за поуздано управљање животним циклусом прегледача
- Коришћење Azure OpenAI видео и структуиране Pydantic излаза за извлачење података о огласима са динамичких веб страница
- Одлучивање када користити агента, актерa или хибридни радни ток аутоматизације прегледача

## Циљеви учења

Након завршетка ове лекције знаћете како да:

- Конфигуришете Browser-Use са Azure OpenAI и Playwright
- Изградите радни ток аутоматизације прегледача који навигује кроз праву веб страницу и рукује динамичким UI елементима
- Извлачите типизиране резултате из видљивог садржаја странице и претварате их у пословну логику
- Одаберете између агената и актера у зависности од предвидивости задатка прегледача

## Пример кода

Ова лекција укључује један туторијал у забележници:

- [15-browser-user.ipynb](./15-browser-user.ipynb): Покреће Chrome сесију преко CDP-а, претражује Airbnb за огласе у Стокхолму, извлачи цене помоћу Browser-Use видеа, и враћа најјефтинију опцију као структуиране податке.

## Предуслови

- Python 3.12+
- Конфигурисана Azure OpenAI имплементација у вашем окружењу
- Локално инсталиран Chrome или Chromium
- Инсталиране Playwright зависности
- Основно познавање асинхроног Python-а

## Постављање

Инсталирајте пакете коришћене у забележници:

```bash
pip install browser_use playwright python-dotenv
playwright install chromium
```

Подесите Azure OpenAI променљиве окружења које користи забележница:

```bash
AZURE_OPENAI_ENDPOINT=...
AZURE_OPENAI_API_KEY=...
AZURE_OPENAI_CHAT_DEPLOYMENT_NAME=...
# Опционо: подразумева се најновија верзија API-ја када се прескочи
AZURE_OPENAI_API_VERSION=...
```

## Преглед архитектуре

Забележница демонстрира хибридни радни ток аутоматизације прегледача:

1. Chrome се покреће са омогућеним CDP-ом тако да и Playwright и Browser-Use могу делити исту сесију прегледача.
2. Browser-Use агент рукује отвореним навигационим задацима као што су отварање Airbnb-а, одбацивање искачућих прозора и претраживање Стокхолма.
3. Активна страница се прегледа са структурираним Pydantic шемама ради извлачења наслова огласа, цена по ноћи, ранговања и URL-ова.
4. Python логика упоређује извучене огласе и издваја најјефтинији резултат.

Овај приступ задржава флексибилно, видео-уметнуто закључивање које Browser-Use добро ради, а истовремено вам даје одређену контролу прегледача када вам је потребна.

## Кључни закључци и најбоље праксе

### Када користити агента уместо актера

| Сценарио | Користити агента | Користити актера |
|----------|-----------------|-----------------|
| Динамички распореди | Да, AI се може прилагодити променама странице | Не, крти селектори могу пуцати |
| Позната структура | Не, агент је спорији од директне контроле | Да, брзо и прецизно |
| Проналажење елемената | Да, природни језик добро функционише | Не, потребни су прецизни селектори |
| Контрола времена | Не, мање предвидиво | Да, пуна контрола преко чекања и покушаја |
| Комплексни радни токови | Да, рукује неочекиваним стањима UI-ја | Не, захтева експлицитно гранујење |

### Најбоље праксе за Browser-Use

1. Започните са агентом за истраживање и динамичку навигацију.
2. Пребаците на директну контролу странице када интеракција постане предвидива.
3. Користите структуиране моделе излаза како би извучени подаци били валидациони и типско безбедни.
4. Додајте кашњења стратешки након радњи које покрећу видљиве промене UI-ја.
5. Снимајте снимке екрана током итерирања како би грешке било лакше открити.
6. Очекивајте промене веб сајтова и осмислите резервне стратегије за искачуће прозоре и промене распореда.
7. Комбинујте агент и актер обрасце да бисте добили и флексибилност и прецизност.

### Примери из стварног света

- Резервација путовања и праћење цена
- Поређење цена и провера доступности у е-трговини
- Структурирано извлачење са динамичких веб сајтова
- Тестирање UI-ја осетљиво на видео и проверу
- Надгледање и узбуњивање веб сајтова
- Интелигентно попуњавање формулара кроз мулти-степене токове

## Пример из стварног света: Microsoft Project Opal

Агент који правите у овој лекцији је мала, локална верзија **агента за коришћење рачунара (CUA)** — програма који управља прегледачем као човек. Microsoft доноси ову исту идеју у предузеће са **[Project Opal (Frontier)](https://support.microsoft.com/en-us/microsoft-365-copilot/get-started-with-project-opal-frontier)**, могућношћу у Microsoft 365 Copilot-у.

Са Project Opal, описујете задатак, а агент ради у ваше име користећи **коришћење рачунара на безбедном Windows 365 Cloud PC-ју**, функционишући преко прегледачких апликација, сајтова и података ваше организације. Ради **асинхроно у позадини**, а ви можете усмеравати посао или преузети контролу у било ком тренутку. Примери послова укључују:

- Управљање захтевима за учешће у безбедносним групама
- Прикупљање и валидацију ревизијских доказа за прегледе усаглашености
- Тријажа IT инцидената (ажурирање статуса тикета, додела власника, затварање дупликата)
- Састављање Excel података у финансијски закључни извештај

Opal је користан референтни пример шта изгледа **агент за коришћење рачунара производног нивоа, коме се може веровати** — и потврђује концепте из претходних лекција:

| Концепт у овом курсу | Како се Project Opal примењује |
|-----------------------|----------------------------|
| **Људски у петљи** (Лекција 06) | Opal застаје због уноса креденцијала за пријаву, осетљивих података или неодређених инструкција, и никада не уноси лозинке или не шаље формуларе без изричите потврде. Можете *преузети контролу* или *вратити контролу* у току задатка. |
| **Поверљиви и безбедни агенти** (Лекције 06 и 18) | Ради у изолованом Windows 365 Cloud PC-ју, подразумевано је само прегледач (доступ другим приступима рачунару је блокиран, примењује се преко Intune-а), користи *ваш* идентитет тако да приступа само овлашћеном, и бележи све акције ради ревизије. |
| **Планирање и метакогниција** (Лекције 07 и 09) | Opal прво генерише план за посао, затим надгледа сопствено закључивање у сваком кораку и зауставља се ако детектује сумњиве активности. |
| **Поновно употребљиве способности / алати** (Лекција 04) | **Вештине** вам омогућавају да пишете инструкције за понављане послове (импортоване из `.md` фајла или ауторисане помоћу Opal-а) и да их користите у различитим разговорима. |

> **Доступност:** Project Opal је тренутно доступан корисницима у [Frontier прогаму раног приступа](https://adoption.microsoft.com/copilot/frontier-program/) уз претплату на Microsoft 365 Copilot, а ваш администратор мора да заврши подешавање. Због тога што је експериментална Frontier функција, могућности могу временом да се мењају.
