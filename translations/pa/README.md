## 🌱 ਸ਼ੁਰੂਆਤ

ਇਸ ਕੋਰਸ ਵਿੱਚ ਏਆਈ ਏਜੰਟ ਬਨਾਉਣ ਦੇ ਮੂਲ ਤੱਤਾਂ 'ਤੇ ਪਾਠ ਸ਼ਾਮਲ ਹਨ। ਹਰ ਪਾਠ ਆਪਣਾ ਵਿਸ਼ਾ ਸਮਝਾਉਂਦਾ ਹੈ, ਇਸ ਲਈ ਜਿੱਥੇ ਮਰਜ਼ੀ ਉੱਥੇ ਸ਼ੁਰੂ ਕਰੋ!

ਇਸ ਕੋਰਸ ਲਈ ਬਹੁ-ਭਾਸ਼ਾ ਸਹਾਇਤਾ ਹੈ। ਸਾਡੇ ਕੋਲ ਉਪਲਬਧ ਭਾਸ਼ਾਵਾਂ ਲਈ ਜਾਓ [available languages here](#-multi-language-support). 

ਜੇ ਇਹ ਤੁਹਾਡਾ ਪਹਿਲਾ ਵਾਰ ਜਨਰੇਟਿਵ ਏਆਈ ਮਾਡਲਾਂ ਨਾਲ ਕੰਮ ਕਰਨਾ ਹੈ, ਤਾਂ ਸਾਡਾ [Generative AI For Beginners](https://aka.ms/genai-beginners) ਕੋਰਸ ਦੇਖੋ, ਜਿਸ ਵਿੱਚ ਜਨਏਆਈ ਨਾਲ ਬਨਾਉਣ ਬਾਰੇ 21 ਪਾਠ ਹਨ।

ਇਹ ਰਿਪੋ ਨੂੰ [ਸਟਾਰ (🌟) ਦੇਣਾ ਨਾ ਭੁੱਲੋ](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst) ਅਤੇ ਕੋਡ ਚਲਾਉਣ ਲਈ [ਰਿਪੋ ਫੋਰਕ ਕਰੋ](https://github.com/microsoft/ai-agents-for-beginners/fork)।

### ਦੂਜੇ ਸਿੱਖਣ ਵਾਲਿਆਂ ਨਾਲ ਮਿਲੋ, ਆਪਣੇ ਸਵਾਲਾਂ ਦੇ ਜਵਾਬ ਲਵੋ

ਜੇ ਤੁਸੀਂ ਫਸ ਜਾਂਦੇ ਹੋ ਜਾਂ ਏਆਈ ਏਜੰਟ ਬਣਾਉਣ ਬਾਰੇ ਕੋਈ ਸਵਾਲ ਹੈ, ਤਾਂ ਸਾਡੀ ਮੱਨਰਥ ਕੀਤਾ Discord ਚੈਨਲ ਵਿੱਚ ਸ਼ਾਮਲ ਹੋਵੋ [Microsoft Foundry Discord](https://aka.ms/ai-agents/discord).

### ਤੁਹਾਨੂੰ ਕੀ ਚਾਹੀਦਾ ਹੈ

ਇਸ ਕੋਰਸ ਦੇ ਹਰ ਪਾਠ ਵਿੱਚ ਕੋਡ ਉਦਾਹਰਨਾਂ ਹਨ, ਜੋ code_samples ਫੋਲਡਰ ਵਿੱਚ ਮਿਲ ਸਕਦੀਆਂ ਹਨ। ਤੁਸੀਂ ਆਪਣੀ ਨਕਲ ਬਣਾਉਣ ਲਈ [ਰਿਪੋ ਫੋਰਕ ਕਰ ਸਕਦੇ ਹੋ](https://github.com/microsoft/ai-agents-for-beginners/fork).  

ਇਹਨਾਂ ਅਭਿਆਸਾਂ ਵਿੱਚ ਕੋਡ ਉਦਾਹਰਨਾਂ Microsoft Agent Framework ਨਾਲ Microsoft Foundry Agent Service V2 ਦੀ ਵਰਤੋਂ ਕਰਦੀਆਂ ਹਨ:

- [Microsoft Foundry](https://aka.ms/ai-agents-beginners/ai-foundry) - ਐਜ਼ੂਰ ਖਾਤਾ ਲੋੜੀਂਦਾ

ਇਹ ਕੋਰਸ Microsoft ਤੋਂ ਹੇਠਲਿਖੇ ਏਆਈ ਏਜੰਟ ਫਰੇਮਵਰਕ ਅਤੇ ਸਰਵਿਸز ਵਰਤਦਾ ਹੈ:

- [Microsoft Agent Framework (MAF)](https://learn.microsoft.com/agent-framework/overview/)
- [Microsoft Foundry Agent Service V2](https://aka.ms/ai-agents-beginners/ai-agent-service)

ਕੁਝ ਕੋਡ ਉਦਾਹਰਨਾਂ ਦਿੱਤੇ ਗਏ OpenAI-ਮੁਕਾਬਲਤ ਪ੍ਰਭਾਵਕਾਂ ਦੀ ਵੀ ਸਹਾਇਤਾ ਕਰਦੀਆਂ ਹਨ, ਜਿਵੇਂ ਕਿ [MiniMax](https://platform.minimaxi.com/), ਜੋ ਵੱਡੇ ਸੰਦਰਭ ਮਾਡਲ (204K ਟੋਕਨ ਤੱਕ) ਪੇਸ਼ ਕਰਦਾ ਹੈ। ਵਿਵਰਣ ਲਈ [Course Setup](./00-course-setup/README.md) ਵੇਖੋ।

ਇਸ ਕੋਰਸ ਲਈ ਕੋਡ ਚਲਾਉਣ ਬਾਰੇ ਹੋਰ ਜਾਣਕਾਰੀ ਲਈ [Course Setup](./00-course-setup/README.md) 'ਤੇ ਜਾਓ।
