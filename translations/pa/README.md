## 🌱 ਸ਼ੁਰੂਆਤ ਕਰਨਾ

ਇਸ ਕੋਰਸ ਵਿੱਚ AI ਏਜੰਟ ਬਣਾਉਣ ਦੇ ਮੁਢਲੇ ਸੁਤਰ ਸਿੱਖਾਇਆ ਜਾਂਦਾ ਹੈ। ਹਰੇਕ ਪਾਠ ਵਿੱਚ ਅਪਣਾ ਵਿਸ਼ਾ ਹੁੰਦਾ ਹੈ, ਇਸ ਲਈ ਜਿੱਥੇ ਚਾਹੋ ਸ਼ੁਰੂ ਕਰੋ!

ਇਸ ਕੋਰਸ ਲਈ ਬਹੁਭਾਸ਼ੀ ਸਹਾਇਤਾ ਉਪਲਬਧ ਹੈ। ਸਾਡੇ [ਉਪਲਬਧ ਭਾਸ਼ਾਵਾਂ ਇਥੇ](#-multi-language-support) ਵੇਖੋ।

ਜੇ ਤੁਸੀਂ ਜਨਰੇਟਿਵ AI ਮਾਡਲਾਂ ਨਾਲ ਪਹਿਲਾ ਵਾਰ ਕੰਮ ਕਰ ਰਹੇ ਹੋ, ਤਾਂ ਸਾਡੇ [ਸ਼ੁਰੂਆਤੀ ਲਈ ਜਨਰੇਟਿਵ AI](https://aka.ms/genai-beginners) ਕੋਰਸ ਨੂੰ ਦੇਖੋ, ਜਿਸ ਵਿੱਚ GenAI ਨਾਲ ਬਣਾਉਣ ਦੇ 21 ਪਾਠ ਹਨ।

ਇਹ repo [ਸਟਾਰ (🌟)](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst) ਅਤੇ [ਫੋਰਕ](https://github.com/microsoft/ai-agents-for-beginners/fork) ਕਰਨਾ ਨਾ ਭੁੱਲੋ ਤਾਂ ਜੋ ਤੁਸੀਂ ਕੋਡ ਚਲਾ ਸਕੋ।

### ਹੋਰ ਸਿੱਖਣ ਵਾਲਿਆਂ ਨਾਲ ਮਿਲੋ, ਆਪਣੇ ਸਵਾਲਾਂ ਦੇ ਜਵਾਬ ਲਵੋ

ਜੇ ਤੁਸੀਂ ਫਸ ਜਾਂਦੇ ਹੋ ਜਾਂ AI ਏਜੰਟ ਬਣਾਉਣ ਬਾਰੇ ਕੋਈ ਸਵਾਲ ਹੈ, ਸਾਡੀ ਮੁਕ਼ਰਰ ਡਿਸਕੋਰਡ ਚੈਨਲ ਵਿੱਚ ਸ਼ਾਮਲ ਹੋਵੋ [Microsoft Foundry Discord](https://aka.ms/ai-agents/discord)।

### ਤੁਹਾਨੂੰ ਕੀ ਚਾਹੀਦਾ ਹੈ

ਇਸ ਕੋਰਸ ਵਿੱਚ ਹਰ ਪਾਠ ਕੋਡ ਉਦਾਹਰਣਾਂ ਸਮੇਤ ਹੈ, ਜੋ code_samples ਫੋਲਡਰ ਵਿੱਚ ਮਿਲ ਸਕਦੇ ਹਨ। ਤੁਸੀਂ ਇਸ repo ਨੂੰ [ਫੋਰਕ](https://github.com/microsoft/ai-agents-for-beginners/fork) ਕਰਕੇ ਆਪਣੀ ਕਾਪੀ ਬਣਾ ਸਕਦੇ ਹੋ।

ਇਹ ਉਦੇਹਾਂਸ਼ ਵਿੱਚ ਕੋਡ ਉਦਾਹਰਣਾਂ Microsoft Agent Framework ਅਤੇ Microsoft Foundry Agent Service V2 ਦੀ ਵਰਤੋਂ ਕਰਦੀਆਂ ਹਨ:

- [Microsoft Foundry](https://aka.ms/ai-agents-beginners/ai-foundry) - Azure ਖਾਤਾ ਲੋੜੀਂਦਾ ਹੈ

ਇਸ ਕੋਰਸ ਵਿੱਚ Microsoft ਵੱਲੋਂ ਹੇਠਾਂ ਦਿੱਤੇ AI ਏਜੰਟ ਫਰੇਮਵਰਕਾਂ ਅਤੇ ਸੇਵਾਵਾਂ ਦੀ ਵਰਤੋਂ ਕੀਤੀ ਗਈ ਹੈ:

- [Microsoft Agent Framework (MAF)](https://learn.microsoft.com/agent-framework/overview/)
- [Microsoft Foundry Agent Service V2](https://aka.ms/ai-agents-beginners/ai-agent-service)

ਕੁਝ ਕੋਡ ਉਦਾਹਰਣਾਂ OpenAI-ਸਪੋਰਟ ਪਾਏ ਜਾਂਦੇ ਹੋਰ ਪ੍ਰਦਾਤਾਵਾਂ ਜਿਵੇਂ [MiniMax](https://platform.minimaxi.com/) ਜੋ ਵੱਡੇ ਸੰਦਰਭ ਮਾਡਲ (204K ਟੋਕਨ ਤੱਕ) ਪ੍ਰਦਾਨ ਕਰਦਾ ਹੈ, ਨੂੰ ਵੀ ਸਮਰਥਨ ਕਰਦੀਆਂ ਹਨ। ਵਿਸਥਾਰਾਂ ਲਈ [ਕੋਰਸ ਸੈਟਅੱਪ](./00-course-setup/README.md) ਵੇਖੋ।

ਇਸ ਕੋਰਸ ਲਈ ਕੋਡ ਚਲਾਉਣ ਬਾਰੇ ਹੋਰ ਜਾਣਕਾਰੀ ਲਈ, [ਕੋਰਸ ਸੈਟਅੱਪ](./00-course-setup/README.md) ਤੇ ਜਾਓ।
