>

>
> **Bash / macOS / Linux:**
> ```bash
> git clone --filter=blob:none --sparse https://github.com/microsoft/ai-agents-for-beginners.git
> cd ai-agents-for-beginners
> git sparse-checkout set --no-cone '/*' '!translations' '!translated_images'
> ```
>
> **CMD (Windows):**
> ```cmd
> git clone --filter=blob:none --sparse https://github.com/microsoft/ai-agents-for-beginners.git
> cd ai-agents-for-beginners
> git sparse-checkout set --no-cone "/*" "!translations" "!translated_images"
> ```
>
> ਇਹ ਤੁਹਾਨੂੰ ਕੋਰਸ ਨੂੰ ਪੂਰਾ ਕਰਨ ਲਈ ਸਭ ਕੁਝ ਦੇਦਾ ਹੈ ਤੇ ਬਹੁਤ ਤੇਜ਼ ਡਾਉਨਲੋਡ ਹੋਵੇਗਾ।

## 🌱 ਸ਼ੁਰੂਆਤ ਕਰਨਾ

ਇਸ ਕੋਰਸ ਵਿੱਚ AI ਏਜੰਟਸ ਬਣਾਉਣ ਦੀਆਂ ਬੁਨਿਆਦੀ ਜਾਂਚਾਂ ਸਮੇਤ ਸਬਕ ਹਨ। ਹਰ ਸਬਕ ਆਪਣੇ ਵਿਸ਼ੇ ਨੂੰ ਕਵਰ ਕਰਦਾ ਹੈ, ਇਸ ਲਈ ਜਿੱਥੇ ਤੂੰ ਚਾਹੁੰਦਾ ਹੈਂ ਉਥੇ ਸ਼ੁਰੂ ਕਰੋ!

ਇਸ ਕੋਰਸ ਲਈ ਬਹੁਭਾਸ਼ੀ ਸਹਾਇਤਾ ਉਪਲੱਬਧ ਹੈ। ਸਾਡੀਆਂ [ਉਪਲੱਬਧ ਭਾਸ਼ਾਈਆਂ ਇੱਥੇ ਦੇਖੋ](#-multi-language-support).

ਜੇ ਇਹ ਪਹਿਲੀ ਵਾਰੀ ਹੈ ਜਦੋਂ ਤੁਸੀਂ ਜੈਨੇਰੇਟਿਵ AI ਮਾਡਲਾਂ ਨਾਲ ਕੰਮ ਕਰ ਰਹੇ ਹੋ, ਤਾਂ ਸਾਡਾ [ਨਵੀਂਆਂ ਲਈ ਜੈਨੇਰੇਟਿਵ AI](https://aka.ms/genai-beginners) ਕੋਰਸ ਵੇਖੋ, ਜਿਸ ਵਿੱਚ 21 ਸਬਕ ਹਨ GenAI ਨਾਲ ਬਣਾਉਣ ਬਾਰੇ।

ਭੁੱਲੋ ਨਾ ਕਿ [ਇਸ ਰਿਪੋ (🌟) ਨੂੰ ਸਟਾਰ ਕਰੋ](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst) ਅਤੇ [ਇਸ ਰਿਪੋ ਨੂੰ ਫੋਰਕ ਕਰੋ](https://github.com/microsoft/ai-agents-for-beginners/fork) ਤਾਂ ਜੋ ਕੋਡ ਚਲਾ ਸਕੋ।

### ਹੋਰ ਸਿੱਖਣ ਵਾਲਿਆਂ ਨਾਲ ਮਿਲੋ, ਆਪਣੇ ਸਵਾਲਾਂ ਦੇ ਜਵਾਬ ਲਵੋ

ਜੇ ਤੁਸੀਂ ਫਸ ਗਏ ਹੋ ਜਾਂ AI ਏਜੰਟਸ ਬਣਾਉਣ ਬਾਰੇ ਕੋਈ ਸਵਾਲ ਹੈ, ਤਾਂ ਸਾਡੀ ਸਮਰਪਿਤ Discord ਚੈਨਲ ਵਿੱਚ ਸ਼ਾਮਲ ਹੋਵੋ [Microsoft Foundry Discord](https://aka.ms/ai-agents/discord).

### ਤੁਹਾਨੂੰ ਕੀ ਚਾਹੀਦਾ ਹੈ

ਹਰ ਸਬਕ ਵਿੱਚ ਕੋਡ ਉਦਾਹਰਣਾਂ ਸ਼ਾਮਲ ਹਨ, ਜੋ code_samples ਫੋਲਡਰ ਵਿੱਚ ਮਿਲਦੀਆਂ ਹਨ। ਤੁਸੀਂ [ਇਸ ਰਿਪੋ ਨੂੰ ਫੋਰਕ ਕਰ ਸਕਦੇ ਹੋ](https://github.com/microsoft/ai-agents-for-beginners/fork) ਆਪਣੀ ਕਾਪੀ ਬਣਾਉਣ ਲਈ।  

ਇਹ ਕੋਡ ਉਦਾਹਰਣ Microsoft Agent Framework ਨੂੰ Microsoft Foundry Agent Service V2 ਨਾਲ ਵਰਤਦੇ ਹਨ:

- [Microsoft Foundry](https://aka.ms/ai-agents-beginners/ai-foundry) - Azure ਖਾਤਾ ਲਾਜ਼ਮੀ

ਇਹ ਕੋਰਸ Microsoft ਤੋਂ ਹੇਠ ਲਿਖੇ AI ਏਜੰਟ ਫਰੇਮਵਰਕ ਅਤੇ ਸੇਵਾਵਾਂ ਵਰਤਦਾ ਹੈ:

- [Microsoft Agent Framework (MAF)](https://learn.microsoft.com/agent-framework/overview/)
- [Microsoft Foundry Agent Service V2](https://aka.ms/ai-agents-beginners/ai-agent-service)

ਕੁਝ ਕੋਡ ਉਦਾਹਰਣ ਵਿਅਕਲਪਿਕ OpenAI-ਅਨੁਕੂਲ ਪ੍ਰਦਾਤਾ ਜਿਵੇਂ [MiniMax](https://platform.minimaxi.com/) ਦਾ ਵੀ ਸਹਾਰਾ ਲੈਂਦੇ ਹਨ, ਜੋ ਵੱਡੇ-ਸੰਦਰਭ ਮਾਡਲ (204K ਟੋਕਨ ਤੱਕ) ਦਿੰਦਾ ਹੈ। ਵਿਸਥਾਰ ਲਈ [ਕੋਰਸ ਸੈਟਅਪ](./00-course-setup/README.md) ਵੇਖੋ।

ਇਸ ਕੋਰਸ ਦਾ ਕੋਡ ਚਲਾਉਣ ਬਾਰੇ ਵਧੇਰੇ ਜਾਣਕਾਰੀ ਲਈ, [ਕੋਰਸ ਸੈਟਅਪ](./00-course-setup/README.md) 'ਤੇ ਜਾਓ।
