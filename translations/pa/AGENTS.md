## ਸੈਟਅੱਪ ਕਮਾਂਡਾਂ

### ਜ਼ਰੂਰੀ ਸ਼ਰਤਾਂ
- ਪਾਈਥਨ 3.12 ਜਾਂ ਉੱਚਾ
- ਐਜ਼ਯੂਰ ਸਬਸਕ੍ਰਿਪਸ਼ਨ (ਮਾਇਕ੍ਰੋਸਾਫਟ ਫਾਊਡਰੀ ਲਈ)
- ਐਜ਼ਯੂਰ CLI ਇੰਸਟਾਲਡ ਅਤੇ ਪ੍ਰਮਾਣਿਤ (`az login`)

### ਸ਼ੁਰੂਆਤੀ ਸੈਟਅੱਪ

1. **ਰਿਪੋਜ਼ਟਰੀ ਕਲੋਨ ਜਾਂ ਫੋਰਕ ਕਰੋ:**
   ```bash
   gh repo fork microsoft/ai-agents-for-beginners --clone
   # OR
   git clone https://github.com/microsoft/ai-agents-for-beginners.git
   cd ai-agents-for-beginners
   ```

2. **ਪਾਈਥਨ ਵਰਚੁਅਲ ਵਾਤਾਵਰਨ ਬਣਾਓ ਅਤੇ ਐਕਟੀਵੇਟ ਕਰੋ:**
   ```bash
   python3 -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   ```

3. **ਡਿਪੈਂਡੇਨਸੀਜ਼ ਇੰਸਟਾਲ ਕਰੋ:**
   ```bash
   pip install -r requirements.txt
   ```

4. **ਵਾਤਾਵਰਨ ਵਾਲੇ ਚਰ (environment variables) ਸੈੱਟ ਕਰੋ:**
   ```bash
   cp .env.example .env
   # Edit .env with your API keys and endpoints
   ```

### ਲੋੜੀਂਦੇ ਵਾਤਾਵਰਨ ਵਾਲੇ ਚਰ

**ਮਾਇਕ੍ਰੋਸਾਫਟ ਫਾਊਡਰੀ** ਲਈ (ਜ਼ਰੂਰੀ):
- `AZURE_AI_PROJECT_ENDPOINT` - ਮਾਇਕ੍ਰੋਸਾਫਟ ਫਾਊਡਰੀ ਪ੍ਰੋਜੈਕਟ ਏਂਡਪੌਇੰਟ
- `AZURE_AI_MODEL_DEPLOYMENT_NAME` - ਮਾਡਲ ਡਿਪਲੋਇਮੈਂਟ ਦਾ ਨਾਮ (ਉਦਾਹਰਨ: gpt-5-mini)

**ਐਜ਼ਯੂਰ AI ਸਰਚ** ਲਈ (ਪਾਠ 05 - RAG):
- `AZURE_SEARCH_SERVICE_ENDPOINT` - ਐਜ਼ਯੂਰ AI ਸਰਚ ਏਂਡਪੌਇੰਟ
- `AZURE_SEARCH_API_KEY` - ਐਜ਼ਯੂਰ AI ਸਰਚ ਏਪੀਆਈ ਕੀ

ਪ੍ਰਮਾਣੀਕਰਨ: ਨੋਟਬੁਕ ਚਲਾਉਣ ਤੋਂ ਪਹਿਲਾਂ `az login` ਚਲਾਓ (ਜਿਸ ਵਿੱਚ `AzureCliCredential` ਦੀ ਵਰਤੋਂ ਹੁੰਦੀ ਹੈ).

## ਟੈਸਟਿੰਗ ਨਿਰਦੇਸ਼

ਇਹ ਇਕ ਸਿੱਖਣ ਵਾਲਾ ਰਿਪੋਜ਼ਟਰੀ ਹੈ ਜਿਸ ਵਿੱਚ ਉਦਾਹਰਨੀ ਕੋਡ ਹੈ ਬਜਾਏ ਉਤਪਾਦਕ ਕੋਡ ਦੇ ਜਿਸ ਵਿੱਚ ਸੁਚਾਲੂ ਟੈਸਟ ਹਨ। ਆਪਣੀ ਸੈਟਅੱਪ ਅਤੇ ਬਦਲਾਅ ਦੀ ਪੁਸ਼ਟੀ ਕਰਨ ਲਈ:

### ਹੱਥੋਂ ਟੈਸਟਿੰਗ

1. **ਪਾਈਥਨ ਵਾਤਾਵਰਨ ਟੈਸਟ ਕਰੋ:**
   ```bash
   python --version  # Should be 3.12+
   pip list | grep -E "(agent-framework|azure-ai|azure-identity)"
   ```

2. **ਨੋਟਬੁਕ ਚਲਾਣ ਦੀ ਜਾਂਚ ਕਰੋ:**
   ```bash
   # Convert notebook to script and run (tests imports)
   jupyter nbconvert --to script <lesson-folder>/code_samples/<notebook>.ipynb --stdout | python
   ```

3. **ਵਾਤਾਵਰਨ ਵਾਲੇ ਚਰ ਦੀ ਪੁਸ਼ਟੀ ਕਰੋ:**
   ```bash
   python -c "import os; from dotenv import load_dotenv; load_dotenv(); print('✓ AZURE_AI_PROJECT_ENDPOINT' if os.getenv('AZURE_AI_PROJECT_ENDPOINT') else '✗ AZURE_AI_PROJECT_ENDPOINT missing')"
   ```

### ਵੱਖਰੇ ਨੋਟਬੁਕ ਚਲਾਉਣਾ

ਜੂਪੀਟਰ ਵਿੱਚ ਨੋਟਬੁਕ ਖੋਲ੍ਹੋ ਅਤੇ ਸੈੱਲ ਕ੍ਰਮਵਾਰ ਚਲਾਓ। ਹਰ ਨੋਟਬੁਕ ਸਵੈ-ਸੰਪੂਰਨ ਹੁੰਦਾ ਹੈ ਅਤੇ ਸ਼ਾਮਿਲ ਹੁੰਦਾ ਹੈ:
- ਆਯਾਤ ਬਿਆਨ
- ਸੰਰਚਨਾ ਲੋਡ ਕਰਨਾ
- ਉਦਾਹਰਨੀ ਏਜੰਟ ਲਾਗੂਆਈਆਂ
- ਮਾਰਕਡਾਊਨ ਸੈੱਲਾਂ ਵਿੱਚ ਉਮੀਦ ਕੀਤੀ ਨਿਕਾਸ

### ਤਾਇਨਾਤ ਕੀਤੇ ਏਜੰਟਾਂ ਲਈ ਸਮੋਕੇ-ਟੈਸਟਿੰਗ

ਜਿੱਥੇ ਏਜੰਟ Microsoft Foundry ਮੇਜ਼ਬਾਨ ਏਜੰਟ ਵਜੋਂ ਤਾਇਨਾਤ ਹੁੰਦਾ ਹੈ (01, 04, 05, 16), ਰਿਪੋ ਸਮੋਕੇ-ਟੈਸਟ ਕੈਟਾਲੌਗ ਵੀ ਭੇਜਦਾ ਹੈ `tests/` ਹੇਠਾਂ ਜੋ `.github/workflows/smoke-test.yml` ਕਾਰਜ ਪ੍ਰਵਾਹ ਰਾਹੀਂ [AI Smoke Test](https://github.com/marketplace/actions/ai-smoke-test) ਕਾਰਵਾਈ ਦੁਆਰਾ ਚਲਾਏ ਜਾਂਦੇ ਹਨ। ਇਹ ਹਲਕੇ-ਫੁਲਕੇ ਬਾਅਦ-ਤਾਇਨਾਤ ਗੇਟ ਹਨ (ਕੀ ਏਜੰਟ ਪਹੁੰਚਯੋਗ ਹੈ ਅਤੇ ਮੂਲ ਭਾਸ਼ਾ-ਅਨੁਸਾਰ ਨਿਰਦੇਸ਼ਾਂ ਦੀ ਪਾਲਣਾ ਕਰ ਰਿਹਾ ਹੈ?), ਜੋ ਪਾਠ 10 ਅਤੇ 16 ਵਿੱਚ ਮੁੱਲਾਂਕਣ ਪਾਈਪਲਾਈਨ ਦੀ ਪੂਰੀ ਕਰਦੇ ਹਨ। ਕੈਟਾਲੌਗ-ਤੋਂ-ਪਾਠ-ਤੋਂ-ਏਜੰਟ ਨਕਸ਼ੇ ਲਈ [tests/README.md](./tests/README.md) ਵੇਖੋ। ਪਾਠ 17 ਸਥਾਨਕ Foundry Local ਨਾਲ ਚੱਲਦਾ ਹੈ ਅਤੇ ਕੋਈ ਮੇਜ਼ਬਾਨ ਐਂਡਪੌਇੰਟ ਨਹੀਂ ਹੈ, ਇਸ ਲਈ ਇਹ ਨੂੰ ਸਿੱਧੇ ਆਪਣੇ ਨੋਟਬੁਕ ਚਲਾਉਣ ਨਾਲ ਸੱਚਿਤ ਕੀਤਾ ਜਾਂਦਾ ਹੈ।
