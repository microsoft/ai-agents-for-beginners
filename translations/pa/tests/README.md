# ਏਜੰਟ ਸ్మੋਕ ਟੈਸਟ

ਇਹ ਫੋਲਡਰ ਕੋਰਸ ਵਿੱਚ ਤੁਸੀਂ ਬਣਾਉਂਦੇ ਏਜੰਟਾਂ ਲਈ **ਸਮੋਕ-ਟੈਸਟ ਕੈਟਾਲੋਗ** ਨੂੰ ਰੱਖਦਾ ਹੈ।
ਸ్మੋਕ ਟੈਸਟ ਇੱਕ ਸਸਤਾ, ਤੇਜ਼ ਜਾਂਚ ਹੈ ਜੋ ਇਹ ਯਕੀਨੀ ਬਣਾਉਂਦਾ ਹੈ ਕਿ ਇੱਕ **ਤਾਇਨਾਤ ਮਾਈਕ੍ਰੋਸੌਫਟ ਫਾਊਂਡਰੀ ਹੋਸਟ ਕੀਤੀ
ਏਜੰਟ** ਪਹੁੰਚ ਯੋਗ ਹੈ, ਜਵਾਬ ਦੇ ਰਿਹਾ ਹੈ, ਅਤੇ ਆਪਣੇ ਸਭ ਤੋਂ ਬੁਨਿਆਦੀ ਪ੍ਰੰਪਟ ਦੀਆਂ ਉਮੀਦਾਂ ਦੀ ਪਾਲਣਾ ਕਰ ਰਿਹਾ ਹੈ।
ਇਹ ਪਹਿਲਾ ਦਰਵਾਜ਼ਾ ਹੈ — [Lesson 10](../10-ai-agents-production/README.md) ਅਤੇ
[Lesson 16](../16-deploying-scalable-agents/README.md) ਵਿੱਚ ਤੁਸੀਂ ਸਿੱਖਦੇ ਹੋ ਪੂਰੀ ਮੁਲਾਂਕਣ ਪ੍ਰਭੰਧ ਲਈ ਕੋਈ ਬਦਲ ਨਹੀਂ ਹੈ।


ਕੈਟਾਲੋਗ [AI Smoke Test](https://github.com/marketplace/actions/ai-smoke-test)
ਗਿਟਹੱਬ ਐਕਸ਼ਨ ਦੁਆਰਾ [`.github/workflows/smoke-test.yml`](../../../.github/workflows/smoke-test.yml)
ਵਰਕਫਲੋ ਵਿੱਚ ਵਰਤੇ ਜਾਂਦੇ ਹਨ।

## ਕਿਵੇਂ ਚਲਾਇਆ ਜਾਵੇ

1. **ਪਾਠ ਦਾ ਏਜੰਟ** ਨੂੰ ਮਾਈਕ੍ਰੋਸੌਫਟ ਫਾਊਂਡਰੀ ਵਿੱਚ ਇੱਕ ਹੋਸਟ ਕੀਤੇ ਏਜੰਟ ਵਜੋਂ ਤਾਇਨਾਤ ਕਰੋ (ਤਾਇਨਾਤ ਵਰਕਫਲੋ ਲਈ Lesson 16 ਵੇਖੋ)। **ਏਜੰਟ ਨਾਮ** ਅਤੇ ਤੁਹਾਡੇ
**ਫਾਊਂਡਰੀ ਪ੍ਰੋਜੈਕਟ ਐਂਡਪੌਇੰਟ** ਨੂੰ ਨੋਟ ਕਰੋ।
2. ਇਹ ਰਿਪਾਜ਼ਿਟਰੀ ਸੀਕ੍ਰੇਟਸ (Settings → Secrets and variables → Actions) ਸ਼ਾਮਿਲ ਕਰੋ:
   `AZURE_CLIENT_ID`, `AZURE_TENANT_ID`, `AZURE_SUBSCRIPTION_ID`। ਫੈਡਰੇਟਿਡ
   ਪਹਿਚਾਣ ਨੂੰ **Azure AI User** ਰੋਲ ਦੀ ਲੋੜ ਹੈ ਜੋ **ਫਾਊਂਡਰੀ ਪ੍ਰੋਜੈਕਟ ਸਕੋਪ** 'ਤੇ ਹੈ।
3. **Actions** ਟੈਬ ਤੋਂ, **Smoke-test hosted agents** ਚਲਾਓ ਅਤੇ ਪਾਠ ਲਈ
   `tests_file` ਚੁਣੋ, ਫਿਰ ਮਿਲਦੇ-ਜੁਲਦੇ `agent_name` ਅਤੇ
   `project_endpoint` ਪ੍ਰਦਾਨ ਕਰੋ।

ਸਿਰਫ ਸਥਾਨਕ ਚੱਲਦੇ ਹਨ, ਜਾਂ ਗੈਰ-ਨਿਧਾਰਤਾਤਮਕ ਰਚਨਾਤਮਕ ਉਤਪਾਦਨ ਕਰਦੇ ਹਨ ਉਹ ਜਾਣ-ਬੁਝ ਕੇ ਬਾਹਰ ਰੱਖੇ ਗਏ ਹਨ:

- **Lesson 17 (ਸਥਾਨਕ AI ਏਜੰਟਸ ਬਣਾਉਣਾ)** ਪੂਰੀ ਤਰ੍ਹਾਂ ਤੁਹਾਡੇ ਕੰਪਿਊਟਰ 'ਤੇ Foundry Local ਨਾਲ ਚੱਲਦਾ ਹੈ ਅਤੇ ਕੋਈ Foundry Responses ਐਂਡਪੌਇੰਟ ਨਹੀਂ ਦਿਖਾਉਂਦਾ, ਇਸ ਲਈ ਇਹ ਕੰਮ ਲਾਗੂ ਨਹੀਂ ਹੁੰਦਾ। ਇਸਦੀ ਪੁਸ਼ਟੀ ਸਥਾਨਕ ਟੈਸਟਿੰਗ ਨਾਲ ਕਰੋ।

- ਡਿਜ਼ਾਈਨ-ਪੈਟਰਨ ਅਤੇ ਸਿਧਾਂਤ ਦੇ ਪਾਠ (02, 03, 06, 07, 09, 12) ਕੋਈ ਇਕਲੌਤਾ
  ਡਿਪਲੋਏ ਕਰਨ ਯੋਗ ਏਜੰਟ ਧੂੰਆ ਪਰਖ ਲਈ ਨਹੀਂ ਭੇਜਦੇ।

## ਕੈਟਾਲੌਗ ਸਕੀਮਾ (ਤੇਜ਼ ਹਵਾਲਾ)

ਹਰ ਇਕ ਕੈਟਾਲੌਗ ਇੱਕ JSON ਦਸਤਾਵੇਜ਼ ਹੁੰਦਾ ਹੈ ਜਿਸ ਵਿੱਚ ਸਿਖਰਲੇ ਪੱਧਰ ਦਾ `tests` ਐਰੇ ਹੁੰਦਾ ਹੈ। ਹਰ ਦਾਖਲਾ ਇੱਕ ਪ੍ਰੰਪਟ POST ਕਰਦਾ ਹੈ ਅਤੇ ਜਵਾਬ ਤੇ ਦਾਵਾ ਕਰਨਦਾ ਹੈ:


| ਫੀਲਡ | ਮਤਲਬ |
|-------|---------|
| `id` | ਲੌਗ ਵਿੱਚ ਛਾਪਿਆ ਗਿਆ ਵਿਲੱਖਣ ਕਦਮ ਪਹਿਚਾਨ-ਸੂਚਕ। |
| `description` | ਮਨੁੱਖ-ਪੜ੍ਹਨਯੋਗ ਮਕਸਦ। |
| `prompt` | ਏਜੰਟ ਨੂੰ ਭੇਜਿਆ ਗਿਆ ਸੁਨੇਹਾ। |
| `assertions.status` | ਉਮੀਦ ਕੀਤੀ HTTP ਸਥਿਤੀ (ਡਿਫੋਲਟ 200)। |
| `assertions.contains_any` | ਜੇ ਜਵਾਬ ਵਿੱਚ ਇਹਨਾਂ ਵਿਚੋਂ ਕੋਈ ਵੀ ਸਬਸਟ੍ਰਿੰਗ ਹੋਵੇ ਤਾਂ ਪਾਸ। |
| `assertions.contains_all` | ਜੇ ਜਵਾਬ ਵਿੱਚ ਹਰ ਸਬਸਟ੍ਰਿੰਗ ਹੋਵੇ ਤਾਂ ਪਾਸ। |
| `assertions.contains_none` | ਜੇ ਜਵਾਬ ਵਿੱਚ ਇਹਨਾਂ ਵਿੱਚੋਂ ਕੋਈ ਵੀ ਸਬਸਟ੍ਰਿੰਗ ਨਾ ਹੋਵੇ ਤਾਂ ਪਾਸ। |
| `save_response_id_as` | ਬਾਅਦ ਦੇ ਬਹੁ-ਮੁੜ ਕਦਮ ਲਈ ਜਵਾਬ id ਸੰਗ੍ਰਹਿਤ ਕਰੋ। |
| `use_previous_response_id` | ਇਹ ਵਾਰੀ ਸੁਰੱਖਿਅਤ ਜਵਾਬ id ਨਾਲ ਜੜੀ ਹੋਈ ਭੇਜੋ। |

ਦਾਵੇ ਕੇਸ-ਅਣਸਕਾਰਕ ਸਬਸਟ੍ਰਿੰਗ ਜਾਂਚਾਂ ਹਨ। ਪੂਰਾ ਸਕੀਮਾ ਵੇਖਣ ਲਈ
[ਕਾਰਵਾਈ ਦਸਤਾਵੇਜ਼](https://github.com/marketplace/actions/ai-smoke-test) ਨੂੰ ਵੇਖੋ,
ਜਿਸ ਵਿੱਚ Foundry-ਸੰਚਾਲਤ ਗੱਲਬਾਤ ਸਰੋਤ ਸ਼ਾਮਲ ਹਨ।
