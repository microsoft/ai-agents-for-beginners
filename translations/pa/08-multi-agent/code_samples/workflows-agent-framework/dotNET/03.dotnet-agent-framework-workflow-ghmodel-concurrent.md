# ⚡ ਏਜ਼ਿਊਰ OpenAI (Responses API) ਨਾਲ ਸਾਂਝੇ ਏਜੰਟ ਵਰਕਫਲੋਜ਼ (.NET)

## 📋 ਉੱਚ-ਕਾਰਗੁਜ਼ਾਰੀ ਸਮਾਂਤਰ ਪ੍ਰੋਸੈਸਿੰਗ ਟਿਊਟੋਰਿਅਲ

ਇਹ ਨੋਟਬੁੱਕ Microsoft Agent Framework for .NET ਅਤੇ ਏਜ਼ਿਊਰ OpenAI (Responses API) ਦੀ ਵਰਤੋਂ ਕਰਦਿਆਂ **ਸਾਂਝੇ ਵਰਕਫਲੋ ਪੈਟਰਨ** ਡੈਮੋਨਸਟ੍ਰੇਟ ਕਰਦਾ ਹੈ। ਤੁਸੀਂ ਸਿੱਖੋਗੇ ਕਿ ਕਿਵੇਂ ਉੱਚ-ਕਾਰਗੁਜ਼ਾਰੀ, ਸਮਾਂਤਰ ਪ੍ਰੋਸੈਸਿੰਗ ਵਰਕਫਲੋਜ਼ ਬਣਾਈਆਂ ਜਾਣ ਜੋ ਅਨੇਕ AI ਏਜੰਟਾਂ ਨੂੰ ਇਕੱਠੇ ਚਲਾਕੇ ਥਰੂਪੁੱਟ ਵਧਾਉਂਦੀਆਂ ਹਨ ਅਤੇ ਸਹਿ-ਸੰਯੋਜਨ ਅਤੇ ਡਾਟਾ ਸਹੀਤਾਈ ਨੂੰ ਬਣਾਈ ਰੱਖਦੀਆਂ ਹਨ।

## 🎯 ਸਿੱਖਣ ਦੇ ਲਕੜੀਆ

### 🚀 **ਸਾਂਝੇ ਪ੍ਰੋਸੈਸਿੰਗ ਦੇ ਮੁਢਲੀਆਂ ਸਿਧਾਂਤ**
- **ਸਮਾਂਤਰ ਏਜੰਟ ਚਲਾਉਣਾ**: ਵੱਧ ਤੋਂ ਵੱਧ ਕਿਰਿਆਸ਼ੀਲਤਾ ਲਈ ਬਹੁਤ ਸਾਰੇ AI ਏਜੰਟ ਸਮੇਂ 'ਚ ਚਲਾਓ
- **Async/Await ਪੈਟਰਨ**: ਕੁਸ਼ਲ ਸਾਂਝੇ ਕਾਰਜ ਲਈ .NET ਦੇ async ਪ੍ਰੋਗ੍ਰਾਮਿੰਗ ਮਾਡਲ ਦੀ ਵਰਤੋਂ ਕਰੋ
- **ਏਜ਼ਿਊਰ OpenAI (Responses API)**: ਏਜ਼ਿਊਰ OpenAI Responses API ਨੂੰ ਬਹੁਤ ਸਾਰੇ ਸਾਂਝੇ ਕਾਲਾਂ ਨਾਲ ਸਹਿ-ਸੰਯੋਜਿਤ ਕਰੋ
- **ਸੰਸਾਧਨ ਪ੍ਰਬੰਧਨ**: ਸਾਂਝੇ ਓਪਰੇਸ਼ਨਾਂ ਦੌਰਾਨ AI ਮਾਡਲ ਦੇ ਸੰਸਾਧਨਾਂ ਦਾ ਕੁਸ਼ਲ ਪ੍ਰਬੰਧਨ ਕਰੋ

### 🏗️ **ਉੱਨਤ ਸਾਂਝੇ ਢਾਂਚਾ**
- **ਟਾਸਕ-ਅਧਾਰਿਤ ਸਮਾਂਤਰਤਾ**: ਉਤਮ ਸਾਂਝੇ ਕਾਰਜਾਂ ਲਈ .NET Task Parallel Library ਦੀ ਵਰਤੋਂ ਕਰੋ
- **ਸਮਨ્વਯ ਪੈਟਰਨ**: ਰੇਸ ਸਥਿਤੀਆਂ ਤੋਂ ਬਚਦਿਆਂ ਸਾਂਝੇ ਏਜੰਟਾਂ ਨੂੰ ਸਹਿਮਤ ਕਰੋ

## 💻 ਕੋਡ ਚਲਾਉਣਾ

ਪੂਰੀ ਐਪਲੀਕੇਸ਼ਨ `03.dotnet-agent-framework-workflow-ghmodel-concurrent.cs` ਵਿੱਚ ਉਪਲੱਬਧ ਹੈ। ਇਹ ਫਾਇਲ ਇੱਕ **ਫੈਨ-ਆਉਟ/ਫੈਨ-ਇਨ ਸਾਂਝੇ ਵਰਕਫਲੋ** ਦਿਖਾਉਂਦੀ ਹੈ ਜੋ ਯਾਤਰਾ ਯੋਜਨਾ ਬਣਾਉਣ ਲਈ ਹੈ:

### 🏗️ **ਵਰਕਫਲੋ ਢਾਂਚਾ**

```
User Request → ConcurrentStartExecutor → [Researcher Agent || Planner Agent] → ConcurrentAggregationExecutor → Final Output
```

**ਮੁੱਖ ਘਟਕ:**

1. **ConcurrentStartExecutor**: ਯੂਜ਼ਰ ਬੇਨਤੀ ਸਾਰਿਆਂ ਏਜੰਟਾਂ ਨੂੰ ਸਮੇਂ ਬਰਾਬਰ ਭੇਜਦਾ ਹੈ
2. **Researcher Agent**: ਗੰਤੀ-ਸਥਾਨਾਂ ਅਤੇ ਆਕਰਸ਼ਣਾਂ ਦੀ ਸਾਂਝੀ ਵਿਸ਼ਲੇਸ਼ਣਾ ਕਰਦਾ ਹੈ
3. **Planner Agent**: ਸਮਾਂਤਰ ਤੌਰ 'ਤੇ ਵਿਸਥਾਰਸ਼ੀਲ ਯਾਤਰਾ ਯੋਜਨਾਵਾਂ ਬਣਾਉਂਦਾ ਹੈ
4. **ConcurrentAggregationExecutor**: ਦੋਹਾਂ ਏਜੰਟਾਂ ਦੇ ਨਤੀਜੇ ਇਕੱਠੇ ਕਰਦਾ ਹੈ ਅਤੇ ਮਿਲਾ ਕੇ ਦਿੰਦਾ ਹੈ

2. **ਸਾਂਝੀ ਪ੍ਰੋਸੈਸਿੰਗ**: ਦੋਹਾਂ ਏਜੰਟ ਇਕੱਠੇ ਕੰਮ ਕਰਦੇ ਹਨ:
   - ਖੋਜਕਰਤਾ ਆਕਰਸ਼ਣਾਂ ਅਤੇ ਵਿਸਥਾਰਾਂ ਦੀ ਪਛਾਣ ਕਰਦਾ ਹੈ
   - ਯੋਜਨਾਕਾਰ ਯਾਤਰਾ ਅਤੇ ਲੋਜਿਸਟਿਕਸ ਬਣਾਉਂਦਾ ਹੈ
3. **ਏਕਠੇ ਕਰਨਾ**: ਦੋਹਾਂ ਜਵਾਬਾਂ ਨੂੰ ਵਿਆਪਕ ਆਉਟਪੁੱਟ ਵਿੱਚ ਮਿਲਾਉਂਦਾ ਹੈ
4. **ਨਤੀਜੇ ਦਿਖਾਉਣਾ**: ਸਾਰੀ ਜਾਣਕਾਰੀ ਨਾਲ ਇੱਕਜੁੱਟ ਯਾਤਰਾ ਯੋਜਨਾ ਵੇਖਾਓ

### 🔧 ਕਸਟਮਾਈਜ਼ੇਸ਼ਨ ਵਿਕਲਪ

- **ਕੋਡ ਸਮੀਖਿਆ**: ਵੱਖ-ਵੱਖ ਨਜ਼ਰੀਆਂ ਤੋਂ ਕਈ ਸਮੀਖਿਆਕਾਰ ਕੋਡ ਦਾ ਵਿਸ਼ਲੇਸ਼ਣ ਕਰਦੇ ਹਨ

### 🔍 ਕਸਟਮ ਐਗਜ਼ੈਕਿਊਟਰਾਂ ਨੂੰ ਸਮਝਣਾ

**ConcurrentStartExecutor:**
- `IMessageHandler<string>` ਨੂੰ ਕਾਰਜਾਨਵਿਤ ਕਰਦਾ ਹੈ ਤਾਂ ਜੋ ਸਟਰਿੰਗ ਇਨਪੁਟ ਮਿਲ ਸਕੇ
- ਸਾਰੇ ਜੁੜੇ ਏਜੰਟਾਂ ਤੱਕ ਸੁਨੇਹੇ ਪ੍ਰਸਾਰਿਤ ਕਰਦਾ ਹੈ
- ਸਾਂਝੇ ਕਾਰਜ ਨੂੰ ਚਾਲੂ ਕਰਨ ਲਈ `TurnToken` ਭੇਜਦਾ ਹੈ

**ConcurrentAggregationExecutor:**
- `IMessageHandler<ChatMessage>` ਨੂੰ ਕਾਰਜਾਨਵਿਤ ਕਰਦਾ ਹੈ ਤਾਂ ਕਿ ਏਜੰਟ ਜਵਾਬ ਮਿਲ ਸਕਣ
- ਸੁਨੇਹੇ ਥ੍ਰੇਡ-ਸੁਰੱਖਿਅਤ ਤਰੀਕੇ ਨਾਲ ਇਕੱਠੇ ਕਰਦਾ ਹੈ
- ਸਾਰੇ ਉਮੀਦਵਾਰ ਜਵਾਬ ਪਹੁੰਚਣ 'ਤੇ ਸੰਪੂਰਨ ਏਕਠਾ ਕਰਦਾ ਹੈ
- `context.YieldOutputAsync()` ਦੀ ਵਰਤੋਂ ਕਰ ਕੇ ਅੰਤਿਮ ਆਉਟਪੁੱਟ ਦਿੰਦਾ ਹੈ

### ⚡ ਪ੍ਰਦਰਸ਼ਨ ਦੇ ਲਾਭ

**ਸਾਂਝੇ ਵਿਰੁੱਧ ਲੜੀਵਾਰ:**
- ਲੜੀਵਾਰ: Agent1 (30ਸ) → Agent2 (30ਸ) = **ਕੁੱਲ 60 ਸਪਟ**
- ਸਾਂਝੇ: Agent1 (30ਸ) || Agent2 (30ਸ) = **ਕੁੱਲ 30 ਸਪਟ**

**ਥਰੂਪੁੱਟ ਸੁਧਾਰ**: N ਸਾਂਝੇ ਏਜੰਟਾਂ ਲਈ N× ਤੱਕ ਤੇਜ਼ (ਕੰਮ ਦੇ ਬੋਝ ਅਤੇ ਸੰਸਾਧਨਾਂ ਮੁਤਾਬਕ)
