## 💻 ਕੋਡ ਚਲਾਉਣਾ

ਪੂਰਾ ਇੰਪਲੀਮੇੰਟੇਸ਼ਨ `03.dotnet-agent-framework-workflow-ghmodel-concurrent.cs` ਵਿੱਚ ਉਪਲਬਧ ਹੈ। ਇਹ ਫਾਇਲ ਯਾਤਰਾ ਯੋਜਨਾ ਲਈ ਇਕ **Fan-Out/Fan-In ਸਮਕਾਲੀ ਵਰਕਫਲੋ** ਦਿਖਾਉਂਦੀ ਹੈ:

### 🏗️ **ਵਰਕਫਲੋ ਢਾਂਚਾ**

```
User Request → ConcurrentStartExecutor → [Researcher Agent || Planner Agent] → ConcurrentAggregationExecutor → Final Output
```

**ਮੁੱਖ ਹਿੱਸੇ:**

1. **ConcurrentStartExecutor**: ਸਭ ਏਜੰਟਾਂ ਨੂੰ ਇੱਕ ਸਮੇਂ ਉਪਭੋਗਤਾ ਦੀ ਬੇਨਤੀ ਭੇਜਦਾ ਹੈ
2. **Researcher Agent**: ਇੱਕੱਠੇ ਤੁਰਿਸਟ ਸਥਾਨਾਂ ਅਤੇ ਆਕਰਸ਼ਣਾਂ ਦਾ ਵਿਸ਼ਲੇਸ਼ਣ ਕਰਦਾ ਹੈ
3. **Planner Agent**: ਇੱਕੱਠੇ ਦੀ ਯਾਤਰਾ ਯੋਜਨਾਵਾਂ ਬਣਾਉਂਦਾ ਹੈ
4. **ConcurrentAggregationExecutor**: ਦੋਹਾਂ ਏਜੰਟਾਂ ਦੇ ਨਤੀਜੇ ਇਕੱਠੇ ਕਰਦਾ ਅਤੇ ਜੋੜਦਾ ਹੈ

### 🎯 **Fan-Out/Fan-In ਪੈਟਰੰਸ**

ਇਹ ਵਰਕਫਲੋ ਕਲਾਸਿਕ **Fan-Out/Fan-In** ਪੈਟਰੰਨ ਨੂੰ ਦਰਸਾਉਂਦੀ ਹੈ:
- **Fan-Out**: ਇੱਕ ਇਨਪੁੱਟ ਸੁਨੇਹਾ ਕਈ ਏਜੰਟਾਂ ਨੂੰ ਇੱਕ ਸਮੇਂ ਭੇਜਿਆ ਜਾਂਦਾ ਹੈ
- **ਸਮਕਾਲੀ ਪ੍ਰੋਸੈਸਿੰਗ**: ਕਈ ਏਜੰਟ ਇੱਕ ਹੀ ਕੰਮ ‘ਤੇ ਬਰਾਬਰ ਚਲਦੇ ਹਨ
- **Fan-In**: ਸਾਰੇ ਏਜੰਟਾਂ ਦੇ ਨਤੀਜੇ ਇਕੱਠੇ ਕੀਤੇ ਜਾਂਦੇ ਹਨ ਅਤੇ ਇਕੋ ਨਿਕਾਸ ਵਿੱਚ ਜੋੜੇ ਜਾਂਦੇ ਹਨ

   - ਰਿਸਰਚਰ ਆਕਰਸ਼ਣ ਅਤੇ ਵਿਸਥਾਰ ਪਛਾਣਦਾ ਹੈ
   - ਪਲੈਨਰ ਰੁਟ ਅਤੇ ਯੋਜਨਾ ਬਣਾਉਂਦਾ ਹੈ
3. **ਇਕੈਠਾ ਕਰਨਾ**: ਦੋਹਾਂ ਜਵਾਬਾਂ ਨੂੰ ਇੱਕ ਵਿਸਥਾਰਤ ਨਤੀਜੇ ਵਿੱਚ ਜੋੜਨਾ
4. **ਨਤੀਜੇ ਦਿਖਾਓ**: ਸਭ ਜਾਣਕਾਰੀ ਸਮੇਤ ਮਿਲੀ ਜੁਲੀ ਯਾਤਰਾ ਯੋਜਨਾ ਦਿਖਾਓ

### 🔧 ਅਨੁਕੂਲ ਕਰਨ ਦੇ ਵਿਕਲਪ

### 🎯 ਅਸਲੀ ਜ਼ਿੰਦਗੀ ਦੇ ਐਪਲੀਕੇਸ਼ਨ

ਇਹ ਸਮਕਾਲੀ ਪੈਟਰੰਨ ਲਈ ਵਧੀਆ ਹੈ:
- **ਸਮੱਗਰੀ ਸਿਰਜਣਾ**: ਕਈ ਲੇਖਕ ਵੱਖ-ਵੱਖ ਭਾਗ ਇੱਕ ਸਮੇਂ ਲਿਖ ਰਹੇ ਹੋਣ
- **ਕੋਡ ਸਮੀਖਿਆ**: ਕਈ ਵਿੱਦਵਾਨ ਵੱਖਰੇ ਕੋਡ ਦੇ ਪਹਲੂਆਂ ਦਾ ਵਿਸ਼ਲੇਸ਼ਣ ਕਰਦੇ ਹਨ
- **ਬਜ਼ਾਰ ਅਨੁਸੰਧਾਨ**: ਵੱਖ-ਵੱਖ ਬਜ਼ਾਰ ਹਿੱਸਿਆਂ ਦੀ ਪੈਰਾਲਲ ਵਿਸ਼ਲੇਸ਼ਣ
- **ਡੌਕਯੂਮੈਂਟ ਪ੍ਰੋਸੈਸਿੰਗ**: ਸਮਕਾਲੀ ਤੌਰ ‘ਤੇ ਡਾਟਾ ਕੱਢਣਾ, ਵਿਸ਼ਲੇਸ਼ਣ ਅਤੇ ਜਾਂਚ
- **ਵੱਖ-ਵੱਖ ਨਜ਼ਰੀਆਂ ਨਾਲ ਵਿਸ਼ਲੇਸ਼ਣ**: ਇੱਕੋ ਇਨਪੁੱਟ ‘ਤੇ ਵੱਖ-ਵੱਖ ਨਜ਼ਰੀਏ ਪ੍ਰਾਪਤ ਕਰਨਾ

### 🔍 ਕਸਟਮ ਏਗਜ਼ਿਕਿਊਟਰਜ਼ ਨੂੰ ਸਮਝਣਾ

**ConcurrentStartExecutor:**
- `IMessageHandler<string>` ਨੂੰ ਲਾਗੂ ਕਰਦਾ ਹੈ ਤਾਂ ਜੋ ਸਟਰਿੰਗ ਇਨਪੁੱਟ ਲਿਆ ਜਾ ਸਕੇ
- ਜੁੜੇ ਸਮੂਹ ਏਜੰਟਾਂ ਨੂੰ ਸੁਨੇਹੇ ਭੇਜਦਾ ਹੈ
- ਸਮਕਾਲੀ ਪ੍ਰੋਸੈਸਿੰਗ ਸ਼ੁਰੂ ਕਰਨ ਲਈ `TurnToken` ਭੇਜਦਾ ਹੈ

**ConcurrentAggregationExecutor:**
- `IMessageHandler<ChatMessage>` ਨੂੰ ਲਾਗੂ ਕਰਦਾ ਹੈ ਤਾਂ ਜੋ ਏਜੰਟ ਜਵਾਬ ਪ੍ਰਾਪਤ ਹੋਣ
- ਸੁਨੇਹਿਆਂ ਨੂੰ ਥਰੇਡ-ਸੁਰੱਖਿਅਤ ਢੰਗ ਨਾਲ ਇਕੱਠਾ ਕਰਦਾ ਹੈ
- ਜਦੋਂ ਸਾਰੇ ਉਮੀਦਵਾਰ ਜਵਾਬ ਮਿਲ ਜਾਣ, ਉਹ ਇੱਕਠਾ ਕਰਦਾ ਹੈ
- ਅੰਤਿਮ ਨਿਕਾਸ `context.YieldOutputAsync()` ਦੁਆਰਾ ਦਿੰਦਾ ਹੈ

### ⚡ ਪ੍ਰਦਰਸ਼ਨ ਦੇ ਫਾਇਦੇ

**ਸਮਕਾਲੀ ਬਨਾਮ ਕ੍ਰਮਵਾਰ:**
- ਕ੍ਰਮਵਾਰ: Agent1 (30s) → Agent2 (30s) = **ਕੁੱਲ 60 ਸੇਕਿੰਡ**
- ਸਮਕਾਲੀ: Agent1 (30s) || Agent2 (30s) = **ਕੁੱਲ 30 ਸੇਕਿੰਡ**

**ਥਰੂਪੁੱਟ ਸੁਧਾਰ**: N ਸਮਕਾਲੀ ਏਜੰਟਾਂ ਲਈ N× ਗਤੀ ਵਿੱਚ ਵਾਧਾ (ਕਾਰਜਭਾਰ ਅਤੇ ਸਰੋਤਾਂ ਦੇ ਅਨੁਸਾਰ)
