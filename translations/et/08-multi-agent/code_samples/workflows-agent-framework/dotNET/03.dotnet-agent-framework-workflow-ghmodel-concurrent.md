# ⚡ Kaasadöötlevad agentide töövood Azure OpenAI-ga (Responses API) (.NET)

## 📋 Suoritusvõimelise paralleeltöötluse juhend

See märkmik demonstreerib **kaasadöötlemise töövoo mustreid** Microsoft Agent raamistiku abil .NET-is ja Azure OpenAI (Responses API). Õpid looma suure jõudlusega, paralleelselt töötavaid töövooge, mis maksimeerivad läbilaskevõimet, täites mitut tehisintellekti agenti samaaegselt, hoides samal ajal koordineerimist ja andmete järjepidevust.

## 🎯 Õpieesmärgid

### 🚀 **Kaasadöötlemise põhialused**
- **Paralleelne komisjonide täitmine**: Käita mitut AI agenti samaaegselt maksimaalseks jõudluseks
- **Async/Await mustrid**: Kasuta .NET asünkroonse programmeerimise mudelit tõhusa kaasadöötlemise jaoks
- **Azure OpenAI (Responses API)**: Koordineeri mitut samaaegset Azure OpenAI Responses API kõnet
- **Ressursside haldus**: Haldada tõhusalt AI mudelite ressursse kaasadöötleval tasemel

### 🏗️ **Täpsem kaasadöötlemise arhitektuur**
- **Ülesandepõhine paralleelsus**: Kasuta .NET Task Parallel Libraryt optimaalsete kaasadööde täitmiseks
- **Sünkroniseerimise mustrid**: Koordineeri samaaegseid agente, vältides olukordi, kus toimuvad võistlusolukorrad
- **Koormuse tasakaalustamine**: Jaota töö tõhusalt kättesaadava kaasadöötlemisvõime vahel
- **Veakindlus**: Käitle individuaalseid agendi tõrkeid ilma töövoo peatamiseta

### 🏢 **Ettevõtte kaasadöötlevad rakendused**
- **Suurte dokumentide paralleeltöötlus**: Töötle mitut dokumenti samaaegselt
- **Reaalajas sisu analüüs**: Kaasadöötlev analüüs saabuvatele andmevoogudele
- **Pakkide töötlemise optimeerimine**: Maksimeeri läbilaskevõime suuremahuliseks andmetöötluseks
- **Mitmemodaalne analüüs**: Paralleeltöötlus erinevat tüüpi ja formaadis sisule

### 🏗️ **Töövoo arhitektuur**

```
User Request → ConcurrentStartExecutor → [Researcher Agent || Planner Agent] → ConcurrentAggregationExecutor → Final Output
```

**Peamised komponendid:**

1. **ConcurrentStartExecutor**: Edastab kasutaja päringu kõigile agentidele samaaegselt
2. **Researcher Agent**: Analüüsib sihtkohti ja vaatamisväärsusi paralleelselt
3. **Planner Agent**: Koostab üksikasjalikke reisiplaane samaaegselt
4. **ConcurrentAggregationExecutor**: Kogub ja ühendab mõlema agendi tulemused

### 🎯 **Fan-Out/Fan-In muster**

See töövoog demonstreerib klassikalist **Fan-Out/Fan-In** mustrit:
- **Fan-Out**: Üks sissetulev sõnum levitatakse mitmele agendile samaaegselt
- **Kaasadöötlemine**: Mitmed agentid töötavad sama ülesande kallal paralleelselt
- **Fan-In**: Kõigi agentide vastuseid kogutakse ja koondatakse üheks väljundiks

### 🔍 Kohandatud täitjate mõistmine

**ConcurrentStartExecutor:**
- Rakendab `IMessageHandler<string>`, et vastu võtta stringi sisendit
- Edastab sõnumeid kõigile ühendatud agentidele
- Saadetakse `TurnToken` kaasadöötlemise käivitamiseks

**ConcurrentAggregationExecutor:**
- Rakendab `IMessageHandler<ChatMessage>`, et vastu võtta agentide vastuseid
- Kogub sõnumeid niitohutult (thread-safe)
- Koondab kõik oodatud vastused saabumisel
- Tagastab lõpliku väljundi kasutades `context.YieldOutputAsync()`

### ⚡ Jõudluse eelised

**Kaasadöötlus vs järeljärjestikune:**
- Järeljärjestikune: Agent1 (30s) → Agent2 (30s) = **kokku 60 sekundit**
- Kaasadöötlev: Agent1 (30s) || Agent2 (30s) = **kokku 30 sekundit**

**Läbilaskevõime paranemine**: Kuni N korda kiirem N kaasadöötleva agendi puhul (sõltuvalt töökoormusest ja ressurssidest)
