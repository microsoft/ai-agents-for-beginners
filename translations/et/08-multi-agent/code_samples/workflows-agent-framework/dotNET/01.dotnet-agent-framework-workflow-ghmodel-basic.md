# 🔄 Põhilised agendi töövood Azure OpenAI-ga (Responses API) (.NET)

## 📋 Töövoo orkestrimise juhend

See märkmik näitab, kuidas luua keerukaid **agendi töövooge** Microsoft Agent Frameworki .NET-i jaoks ja Azure OpenAI (Responses API) abil. Õpid looma mitmeastmelisi äriprotsesse, kus tehisintellekti agendid teevad koostööd keerukate ülesannete täitmiseks struktureeritud orkestrimismeetodite kaudu.

## 🎯 Õpieesmärgid

### 🏗️ **Töövoo arhitektuuri alused**
- **Workflow Builder**: Kavanda ja orkestreeri keerukaid mitmeastmelisi tehisintellekti protsesse
- **Agendi koordinatsioon**: Koordineeri mitut spetsialiseerunud agenti töövoogudes
- **Azure OpenAI (Responses API)**: Kasuta Azure OpenAI Responses API-d töövoogudes
- **Visuaalne töövoo disain**: Loo ja visualiseeri töövoo struktuure paremaks mõistmiseks

### 🔄 **Protsessi orkestrimise mustrid**
- **Järjestikune töötlemine**: Järjesta mitut agendi ülesannet loogilises järjekorras
- **Oleku haldamine**: Säilita konteksti ja andmevoogu töövoo etappide vahel
- **Vigade käsitlemine**: Rakenda töökindlat vigade taastumist ja töövoo vastupidavust
- **Tõhususe optimeerimine**: Kujunda efektiivseid töövooge ettevõtte suuruse operatsioonide jaoks

### 🏢 **Ettevõtte töövoo rakendused**
- **Äriprotsesside automatiseerimine**: Automatiseeri keerukaid organisatsioonilisi töövooge
- **Sisuloome torujuhe**: Toimetuslikud töövood koos ülevaatus- ja kinnitusetappidega
- **Klienditeeninduse automatiseerimine**: Mitmeastmeline kliendipäringute lahendamine
- **Andmetöötluse töövood**: ETL töövood tehisintellekti abil toimuva transformatsiooniga

## ⚙️ Eeltingimused ja seadistamine

### 📦 **Nõutavad NuGet paketid**

Selle töövoo demo jaoks kasutatakse mitmeid võtmetähtsusega .NET pakette:

```xml
<!-- Core AI Framework -->
<PackageReference Include="Microsoft.Extensions.AI" Version="9.9.0" />

<!-- Azure OpenAI (Responses API) -->
<PackageReference Include="Azure.AI.OpenAI" Version="2.1.0" />
<PackageReference Include="Azure.Identity" Version="1.13.1" />

<!-- Agent Framework (Local Development) -->
<!-- Microsoft.Agents.AI.dll - Core agent abstractions -->
<!-- Microsoft.Agents.AI.OpenAI.dll - Azure OpenAI (Responses API) integration -->

<!-- Configuration and Environment -->
<PackageReference Include="DotNetEnv" Version="3.1.1" />
```

### 🔑 **Azure OpenAI konfiguratsioon**

**Keskkonna seadistamine (.env fail):**
```env
AZURE_OPENAI_ENDPOINT=https://<your-resource>.openai.azure.com
AZURE_OPENAI_DEPLOYMENT=gpt-4o-mini
```

**Azure OpenAI ligipääs:**
1. Loo Azure portaalis Azure OpenAI ressurss
2. Käivita mudel (näiteks `gpt-4o-mini`) ja märgi üles juurutuse nimi
3. Logi sisse `az login` abil ja seadista keskkonnamuutujad nagu eespool näidatud

### 🏗️ **Töövoo arhitektuuri ülevaade**

```mermaid
graph TD
    A[Töövoo koostaja] --> B[Agendi register]
    B --> C[Töövoo täitmise mootor]
    C --> D[Agent 1: Sisu generaator
    C --> E[Agent 2: Sisu ülevaataja 
    D --> F[Töövoo tulemused]
    E --> F
    G[Azure OpenAI (vastuste API)] --> D
    G --> E
```

**Põhikomponendid:**
- **WorkflowBuilder**: Peamine orkestreerimismootor töövoogude kavandamiseks
- **AIAgent**: Individuaalsed spetsialiseerunud agendid konkreetsete võimetega
- **Azure OpenAI klient**: Azure OpenAI Responses API integreerimine
- **Täitmise kontekst**: Halda olekut ja andmevoogu töövoo etappide vahel

## 🎨 **Ettevõtte töövoo disainimustrid**

### 📝 **Sisuloome töövoog**
```
User Request → Content Generation → Quality Review → Final Output
```

### 🔍 **Dokumenditöötluse torujuhe**
```
Document Input → Analysis → Extraction → Validation → Structured Output
```

### 💼 **Ärianalüütika töövoog**
```
Data Collection → Processing → Analysis → Report Generation → Distribution
```

### 🤝 **Klienditeeninduse automatiseerimine**
```
Customer Inquiry → Classification → Processing → Response Generation → Follow-up
```

## 💻 Koodi käivitamine

Täielik rakendus on saadaval failis `01.dotnet-agent-framework-workflow-ghmodel-basic.cs`. See fail demonstreerib:

1. **Keskkonna konfiguratsiooni** – Azure OpenAI seadistamine `.env` failist laadides
2. **Azure OpenAI kliendi seadistamine** – kliendi konfiguratsioon Azure OpenAI Responses API kasutamiseks
3. **Agendi loomine** – spetsialiseerunud agentide (Front Desk ja Concierge) defineerimine
4. **Töövoo koostaja** – mitme agendi töövoo loomine järjestikuse töötlemisega
5. **Töövoo täitmine** – töövoo käivitamine voogedastusega tulemustega

### 🚀 Näite käivitamine

```bash
# Muuda skript käivitatavaks (Unix/Linux/macOS)
chmod +x 01.dotnet-agent-framework-workflow-ghmodel-basic.cs

# Käivita töövoog
./01.dotnet-agent-framework-workflow-ghmodel-basic.cs
```

Või Windowsis:
```powershell
dotnet run 01.dotnet-agent-framework-workflow-ghmodel-basic.cs
```

### 📝 Eeldatav väljund

Töövoog teeb järgmist:
1. Võtab vastu sinu reisisihtkoha palve ("Ma sooviksin minna Pariisi")
2. Front Desk agent annab esmase soovituse
3. Concierge agent vaatab üle ja täiustab soovitust
4. Lõplik väljund kuvab kogu vestluse voo
