Agendi koostöö LangGraphiga struktureeritud mõtlemiseks
Reaalajas vestlussalvestus Azure Cosmos DB abil – sama andmebaas, mis toetab ChatGPT vestlusajalugu, mis on ajaloo kiiremini kasvav AI-agentide rakendus
Vektoripõhine otsing teadmiste hankimiseks Cosmos DB natiivse manuste toe abil
FastAPI asünkroonsed võimed interaktsioonide responsiivseks ja skaleeritavaks hoidmiseks
Selle sessiooni lõpuks on sul selge plaan oma skaleeritavate, pilvepõhiste mitmeagendiliste rakenduste ehitamiseks ja juurutamiseks, mis kasutavad moodsat AI-d ja pilveinfrastruktuuri. Olenemata sellest, kas oled AI-insener, pilvearhitekt või Python-arendaja, varustab see ettekandega sind praktiliste teadmiste ja testitud mustritega, et ehitada järgmise põlvkonna AI-võimelisi rakendusi.
