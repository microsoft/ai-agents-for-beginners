## 🌱 Alustamine

See kursus sisaldab õppetunde, mis katavad AI-agentide loomise aluseid. Iga õppetund käsitleb oma teemat, nii et alusta sealt, kus soovid!

Sellel kursusel on mitmekeelne tugi. Vaata [saadaval olevaid keeli siit](#-multi-language-support).

Kui ehitad Generatiivseid AI mudeleid esimest korda, vaata meie kursust [Generative AI For Beginners](https://aka.ms/genai-beginners), mis sisaldab 21 õppetundi GenAI-ga ehitamisest.

Ära unusta [märgata (🌟) seda hoidlat](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst) ja [forkida see hoidla](https://github.com/microsoft/ai-agents-for-beginners/fork), et koodi jooksutada.

### Kohtu teiste õppuritega, saa vastused oma küsimustele

Kui jääd hätta või sul on küsimusi AI-agentide loomise kohta, liitu meie pühendatud Discordi kanaliga [Microsoft Foundry Discord](https://aka.ms/ai-agents/discord).

### Mida vajad

Igas selle kursuse õppetunnis on koodinäited, mis asuvad kaustas code_samples. Sa võid [forkida selle hoidla](https://github.com/microsoft/ai-agents-for-beginners/fork), et luua oma eksemplar.

Nendes harjutustes kasutatavad koodinäited kasutavad Microsoft Agent Frameworki koos Microsoft Foundry Agent Service V2-ga:

- [Microsoft Foundry](https://aka.ms/ai-agents-beginners/ai-foundry) - Azure konto on vajalik

See kursus kasutab järgmisi Microsofti AI-agentide raamistikke ja teenuseid:

- [Microsoft Agent Framework (MAF)](https://learn.microsoft.com/agent-framework/overview/)
- [Microsoft Foundry Agent Service V2](https://aka.ms/ai-agents-beginners/ai-agent-service)

Mõned koodinäited toetavad ka muid OpenAI-ga ühilduvaid teenusepakkujaid nagu [MiniMax](https://platform.minimaxi.com/), mis pakub suure konteksti mudeleid (kuni 204K tokenit). Vaata [Course Setup](./00-course-setup/README.md) konfiguratsioonideks.

Lisateabe saamiseks selle kursuse koodi kasutamise kohta vaata [Course Setup](./00-course-setup/README.md).
