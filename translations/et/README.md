## 🌱 Alustamine

See kursus sisaldab tunde, mis käsitlevad AI Agentide loomise aluseid. Iga tund käsitleb oma teemat, nii et alusta sealt, kus soovid!

Sellel kursusel on mitmekeelne tugi. Vaata meie [saadaval olevaid keeli siin](#-multi-language-support).

Kui see on sinu esimene kord generatiivsete AI mudelitega töötada, vaata meie kursust [Generatiivne AI algajatele](https://aka.ms/genai-beginners), mis sisaldab 21 tundi generatiivse AI kasutamisest.

Ära unusta [märgista seda hoidlat tärniga (🌟)](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst) ja [kloonida see hoidla](https://github.com/microsoft/ai-agents-for-beginners/fork), et koodi käivitada.

### Tutvu teiste õppijatega, saa oma küsimustele vastused

Kui jääd hätta või tekivad küsimused AI Agentide loomise kohta, liitu meie spetsiaalse Discord kanaliga [Microsoft Foundry Discord](https://aka.ms/ai-agents/discord).

### Mida vajad

Iga selle kursuse tund sisaldab koodinäiteid, mis asuvad kaustas code_samples. Sa võid [klonida selle hoidla](https://github.com/microsoft/ai-agents-for-beginners/fork), et luua oma koopia.

Nendes harjutustes kasutatavad koodinäited tuginevad Microsoft Agent Frameworkile koos Microsoft Foundry Agent Service V2-ga:

- [Microsoft Foundry](https://aka.ms/ai-agents-beginners/ai-foundry) - nõutav Azure konto

See kursus kasutab järgmisi Microsofti AI Agent raamistikud ja teenuseid:

- [Microsoft Agent Framework (MAF)](https://learn.microsoft.com/agent-framework/overview/)
- [Microsoft Foundry Agent Service V2](https://aka.ms/ai-agents-beginners/ai-agent-service)

Mõned koodinäited toetavad ka alternatiivseid OpenAI-kompatible pakkujaid nagu [MiniMax](https://platform.minimaxi.com/), mis pakub suurtekstimudelite tuge (kuni 204K tokenit). Vaata konfiguratsioonide detaile [Kursuse seadistusest](./00-course-setup/README.md).

Lisainfo saamiseks selle kursuse koodi käivitamise kohta, vaata [Kursuse seadistust](./00-course-setup/README.md).
