## 🌱 Alustamine

See kursus sisaldab õppetunde, mis käsitlevad AI Agentide loomise põhitõdesid. Iga õppetund käsitleb konkreetset teemat, nii et alusta sealt, kus soovid!

Sellel kursusel on mitmekeelne tugi. Vaata meie [saadaval keeli siit](#-multi-language-support).

Kui see on su esimene kord, kui ehitad generatiivsete AI mudelitega, vaata meie [Generative AI Algajatele](https://aka.ms/genai-beginners) kursust, mis sisaldab 21 õppetundi GenAI-ga ehitamise kohta.

Ära unusta [märkida seda repositooriumi tärniga (🌟)](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst) ja [harutada see repositoorium](https://github.com/microsoft/ai-agents-for-beginners/fork), et käivitada kood.

### Kohtu teiste õppuritega, saa vastused oma küsimustele

Kui jääd hätta või on AI Agentide loomise kohta küsimusi, liitu meie pühendatud Discord kanaliga aadressil [Microsoft Foundry Discord](https://aka.ms/ai-agents/discord).

### Mida vajad

Igas kursuse õppetunnis on koodinäited, mis asuvad code_samples kaustas. Sa võid [harutada selle repositooriumi](https://github.com/microsoft/ai-agents-for-beginners/fork), et luua oma koopia.

Nendes harjutustes kasutatavad koodinäited kasutavad Microsoft Agent Framework'i koos Microsoft Foundry Agent Service V2-ga:

- [Microsoft Foundry](https://aka.ms/ai-agents-beginners/ai-foundry) - Azure konto nõutud

See kursus kasutab järgmisi Microsofti AI Agent raamistikke ja teenuseid:

- [Microsoft Agent Framework (MAF)](https://learn.microsoft.com/agent-framework/overview/)
- [Microsoft Foundry Agent Service V2](https://aka.ms/ai-agents-beginners/ai-agent-service)

Mõned koodinäited toetavad ka alternatiivseid OpenAI-ga ühilduvaid pakkujaid nagu [MiniMax](https://platform.minimaxi.com/), mis pakub suuri kontekstimudeleid (kuni 204K tokenit). Vaata konfiguratsiooni üksikasju [Kursuse seadistamine](./00-course-setup/README.md).

Lisainfo jaoks selle kursuse koodi käivitamiseks vaata [Kursuse seadistamine](./00-course-setup/README.md).
