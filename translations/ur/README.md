## 🌱 شروع کریں

یہ کورس AI ایجنٹس بنانے کی بنیادی باتوں کو سکھاتا ہے۔ ہر سبق اپنے موضوع کو کور کرتا ہے اس لیے جہاں چاہیں شروع کریں!

اس کورس کے لیے کثیرالزبانی حمایت موجود ہے۔ ہمارے [دستیاب زبانیں یہاں](#-multi-language-support) دیکھیں۔

اگر یہ آپ کا جنریٹو AI ماڈلز کے ساتھ پہلا تجربہ ہے، تو ہمارا [Generative AI For Beginners](https://aka.ms/genai-beginners) کورس دیکھیں، جس میں GenAI کے ساتھ بنانے پر 21 اسباق شامل ہیں۔

[اس مخزن کو ستارے (🌟) دیں](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars?WT.mc_id=academic-105485-koreyst) اور [اس مخزن کو فورک کریں](https://github.com/microsoft/ai-agents-for-beginners/fork) تاکہ کوڈ چلایا جا سکے۔

### دوسرے سیکھنے والوں سے ملیں، اپنے سوالات کے جواب حاصل کریں

اگر آپ کو مشکل پیش آئے یا AI ایجنٹس بنانے کے بارے میں کوئی سوال ہو، تو ہمارے مختص Discord چینل میں شامل ہوں [Microsoft Foundry Discord](https://aka.ms/ai-agents/discord) پر۔

### آپ کو کیا چاہیے

اس کورس کے ہر سبق میں کوڈ مثالیں شامل ہیں، جو code_samples فولڈر میں پائی جا سکتی ہیں۔ آپ [اس مخزن کو فورک کریں](https://github.com/microsoft/ai-agents-for-beginners/fork) تاکہ اپنی کاپی بنا سکیں۔

ان مشقوں میں کوڈ کی مثالیں Microsoft Agent Framework اور Microsoft Foundry Agent Service V2 استعمال کرتی ہیں:

- [Microsoft Foundry](https://aka.ms/ai-agents-beginners/ai-foundry) - Azure اکاؤنٹ ضروری ہے

یہ کورس مندرجہ ذیل AI ایجنٹ فریم ورکس اور خدمات مائیکروسافٹ کی طرف سے استعمال کرتا ہے:

- [Microsoft Agent Framework (MAF)](https://learn.microsoft.com/agent-framework/overview/)
- [Microsoft Foundry Agent Service V2](https://aka.ms/ai-agents-beginners/ai-agent-service)

کچھ کوڈ نمونے متبادل OpenAI-مطابقت رکھنے والے فراہم کنندگان کو بھی سپورٹ کرتے ہیں جیسے [MiniMax](https://platform.minimaxi.com/)، جو بڑے کانٹیکسٹ ماڈلز فراہم کرتا ہے (204K ٹوکنز تک)۔ ترتیب کی تفصیلات کے لیے [Course Setup](./00-course-setup/README.md) دیکھیں۔

اس کورس کے کوڈ چلانے کی مزید معلومات کے لیے، [Course Setup](./00-course-setup/README.md) پر جائیں۔
