# کمپیوٹر یوز ایجنٹس (CUA) بنانے کا طریقہ

کمپیوٹر یوز ایجنٹس ویب سائٹس کے ساتھ اسی طرح انٹریکٹ کر سکتے ہیں جیسے ایک انسان کرتا ہے: ایک براؤزر کھول کر، صفحہ کا معائنہ کر کے، اور جو کچھ وہ دیکھتا ہے اس میں سے اگلا بہترین عمل کرنا۔ اس سبق میں، آپ ایک براؤزر آٹومیشن ایجنٹ بنائیں گے جو Airbnb پر تلاش کرے گا، منظم کردہ لسٹنگ ڈیٹا نکالے گا، اور اسٹاک ہوم میں سب سے سستا قیام تلاش کرے گا۔

یہ سبق AI کے ذریعے نیویگیشن کے لیے Browser-Use، براؤزر کنٹرول کے لیے Playwright اور Chrome DevTools Protocol (CDP)، وژن فعال استدلال کے لیے Azure OpenAI، اور منظم استخراج کے لیے Pydantic کو یکجا کرتا ہے۔

## تعارف

اس سبق میں شامل موضوعات:

- سمجھنا کہ کب کمپیوٹر یوز ایجنٹس API-صرف آٹومیشن سے بہتر ہیں
- قابل اعتماد براؤزر لائف سائیکل مینجمنٹ کے لیے Browser-Use کو Playwright اور CDP کے ساتھ جوڑنا
- متحرک ویب صفحات سے لسٹنگ ڈیٹا نکالنے کے لیے Azure OpenAI وژن اور منظم Pydantic آؤٹ پٹ کا استعمال
- فیصلہ کرنا کہ کب ایجنٹ-فرسٹ، ایکٹر-فرسٹ، یا ہائبریڈ براؤزر آٹومیشن ورک فلو استعمال کرنا ہے

## تعلیمی مقاصد

اس سبق کو مکمل کرنے کے بعد، آپ جانیں گے کہ کیسے:

- Browser-Use کو Azure OpenAI اور Playwright کے ساتھ ترتیب دینا
- ایک براؤزر آٹومیشن ورک فلو بنانا جو ایک حقیقی ویب سائٹ پر نیویگیٹ کرے اور متحرک UI عناصر کو ہینڈل کرے
- نظر آنے والے صفحہ کے مواد سے ٹائپ کیے گئے نتائج نکالنا اور انہیں کاروباری منطق میں تبدیل کرنا
- براؤزر کے ٹاسک کی پیش بینی کی بنیاد پر ایجنٹ اور ایکٹر پیٹرنز میں انتخاب کرنا

## کوڈ کا نمونہ

یہ سبق ایک نوٹ بک ٹیوٹوریل پر مشتمل ہے:

- [15-browser-user.ipynb](./15-browser-user.ipynb): CDP پر کروم سیشن شروع کرتا ہے، اسٹاک ہوم لسٹنگز کے لیے Airbnb تلاش کرتا ہے، Browser-Use وژن سے قیمتیں نکالتا ہے، اور سب سے سستی آپشن کو منظم ڈیٹا کی صورت میں واپس کرتا ہے۔

## پیشگی ضروریات

- Python 3.12+
- آپ کے ماحول میں Azure OpenAI کی ڈپلائمنٹ کنفیگر کی گئی ہو
- کروم یا کرومیم مقامی طور پر نصب ہو
- Playwright کی dependencies نصب ہوں
- async Python سے بنیادی واقفیت ہو

## ترتیب

نوٹ بک میں استعمال ہونے والے پیکجز انسٹال کریں:

```bash
pip install browser_use playwright python-dotenv
playwright install chromium
```

نوٹ بک میں استعمال ہونے والے Azure OpenAI ماحول کے متغیرات سیٹ کریں:

```bash
AZURE_OPENAI_ENDPOINT=...
AZURE_OPENAI_API_KEY=...
AZURE_OPENAI_CHAT_DEPLOYMENT_NAME=...
# اختیاری: چھوڑنے پر جدید ترین API ورژن کو بطور ڈیفالٹ لیا جاتا ہے
AZURE_OPENAI_API_VERSION=...
```

## فن تعمیر کا جائزہ

نوٹ بک ایک ہائبریڈ براؤزر آٹومیشن ورک فلو دکھاتی ہے:

1. کروم CDP کے ساتھ شروع ہوتا ہے تاکہ Playwright اور Browser-Use دونوں ایک ہی براؤزر سیشن شیئر کر سکیں۔
2. Browser-Use ایجنٹ کھلے ہوئے نیویگیشن کے کام انجام دیتا ہے جیسے کہ Airbnb کھولنا، پاپ اپس کو بند کرنا، اور اسٹاک ہوم کی تلاش کرنا۔
3. فعال صفحہ کو منظم Pydantic اسکیمہ کے ذریعے معائنہ کیا جاتا ہے تاکہ لسٹنگ ٹائٹلز، روزانہ کی قیمتیں، درجہ بندیاں، اور URLs نکالے جا سکیں۔
4. Python منطق نکالی گئی لسٹنگز کا موازنہ کرتی ہے اور سب سے سستا نتیجہ نمایاں کرتی ہے۔

یہ طریقہ وہ لچکدار، وژن پر مبنی استدلال برقرار رکھتا ہے جس میں Browser-Use ماہر ہے، جبکہ جب ضرورت ہو تو آپ کو قطعی براؤزر کنٹرول بھی دیتا ہے۔

## اہم نکات اور بہترین طریقے

### ایجنٹ بمقابلہ ایکٹر کب استعمال کریں

| منظرنامہ | ایجنٹ استعمال کریں | ایکٹر استعمال کریں |
|----------|-----------|-----------|
| متحرک لے آؤٹس | جی ہاں، AI صفحہ کی تبدیلیوں کے مطابق ڈھل سکتا ہے | نہیں، توڑنے والے سلیکٹرز مختلف ہو سکتے ہیں |
| معروف ساخت | نہیں، ایجنٹ براہ راست کنٹرول سے آہستہ ہوتا ہے | جی ہاں، تیز اور درست |
| عناصر کی تلاش | جی ہاں، قدرتی زبان اچھی کام کرتی ہے | نہیں، صحیح سلیکٹرز چاہیے ہوتے ہیں |
| وقت کا کنٹرول | نہیں، کم پیش بینی کی جا سکتی ہے | جی ہاں، انتظار اور دوبارہ کوششوں پر مکمل کنٹرول |
| پیچیدہ ورک فلو | جی ہاں، غیر متوقع UI حالتوں کو سنبھالتا ہے | نہیں، واضح شاخ بندی کی ضرورت ہے |

### Browser-Use کے بہترین طریقے

1. تلاش اور متحرک نیویگیشن کے لیے ایجنٹ کے ساتھ شروع کریں۔
2. جب تعامل پیش بینی کے قابل ہو تو براہ راست صفحہ کنٹرول پر سوئچ کریں۔
3. منظم آؤٹ پٹ ماڈلز استعمال کریں تاکہ نکالا گیا ڈیٹا تصدیق شدہ اور ٹائپ-سیف ہو۔
4. ایسے عمل کے بعد جو نظر آنے والے UI تبدیلیوں کو متحرک کرتے ہیں، حکمت عملی کے تحت تاخیرات شامل کریں۔
5. پھیرنے کے دوران اسکرین شاٹس لیں تاکہ ناکامیوں کو آسانی سے ڈیبگ کیا جا سکے۔
6. یہ توقع کریں کہ ویب سائٹس تبدیل ہوں گی اور پاپ اپس اور لے آؤٹ شفٹس کے لیے بیک اپ حکمت عملی بنائیں۔
7. لچک اور درستگی دونوں کے لیے ایجنٹ اور ایکٹر پیٹرنز کو ملا کر استعمال کریں۔

### براؤزر ایجنٹس کے لیے حفاظتی گارڈریل

براؤزر ایجنٹس زندہ ویب سائٹس پر کام کرتے ہیں، لہٰذا انہیں اسکرپٹ کی نسبت زیادہ سخت حد بندی کی ضرورت ہوتی ہے جو صرف ایک جانا پہچانا API کال کرتا ہے۔ نوٹ بک ڈیمو سے حقیقی ورک فلو میں جانے سے پہلے، یہ طے کریں کہ ایجنٹ کیا دیکھ سکتا ہے، کلک کر سکتا ہے، اور جمع کر سکتا ہے۔

1. **براؤزنگ ماحول کا دائرہ کار مقرر کریں۔** ایجنٹ کو مخصوص براؤزر پروفائل یا سینڈباکس میں چلائیں، اور اسے اس ٹاسک کے ضروری ڈومینز تک محدود کریں۔
2. **مشاہدہ کو عمل سے جدا کریں۔** پہلے ایجنٹ کو تلاش کرنے دیں، پڑھنے دیں، اور ڈیٹا نکالنے دیں؛ فارم جمع کروانے، پیغامات بھیجنے، سفر کی بکنگ کرنے، خریداری کرنے، ریکارڈز حذف کرنے، یا اکاؤنٹ کی ترتیبات بدلنے سے پہلے واضح منظوری کا مرحلہ لازمی بنائیں۔
3. **خفیہ معلومات کو پرامپٹ اور ٹریس سے باہر رکھیں۔** ماڈل کے کانٹیکسٹ میں پاس ورڈز، ادائیگی کی تفصیلات، سیشن کوکیز، یا ذاتی ڈیٹا شامل نہ کریں۔ تصدیق کے لیے صارف کو ذمہ داری دیں اور حساس فیلڈز کو لاگز سے خارج کریں۔
4. **صفحہ کے مواد کو غیر معتبر ان پٹ سمجھیں۔** ایک ویب سائٹ میں ایسی ہدایات ہو سکتی ہیں جو ایجنٹ کے لیے ہوں، صارف کے لیے نہیں۔ ایجنٹ کو ایسے صفحہ متن کی نظربندی کرنی چاہیے جو اپنا مقصد بدلنے، ڈیٹا ظاہر کرنے، حفاظتی اقدامات غیر فعال کرنے، یا غیر متعلقہ سائٹس پر جانے کو کہے۔
5. **خطرناک مراحل کے گرد قطعی چیکز استعمال کریں۔** کوڈ کے ذریعے موجودہ URL، صفحہ کا عنوان، منتخب شے، قیمت، وصول کنندہ، اور عمل کا خلاصہ تصدیق کریں اس سے پہلے کہ صارف کو آخری اقدام کی منظوری کے لیے کہا جائے۔
6. **بجٹ اور رکنے کی شرائط مقرر کریں۔** ایکشنز، دوبارہ کوششوں، ٹیبز، اور منٹوں کی تعداد پر حد لگائیں جو ایجنٹ استعمال کر سکتا ہے۔ جب صفحہ کی حالت غیر واضح ہو تو کلک کرنا بند کر دیں۔
7. **مفید ثبوت ریکارڈ کریں، سب کچھ نہیں۔** ایکشن خلاصے، ٹائم اسٹیمپس، URLs، منتخب عنصر کی وضاحتیں، اور اسکرین شاٹ حوالہ جات محفوظ کریں تاکہ ناکامیوں کا جائزہ لیا جا سکے بغیر غیر ضروری حساس مواد محفوظ کرنے کے۔

Airbnb کے نمونے میں، محفوظ ڈیفالٹ یہ ہے کہ لسٹنگز تلاش کریں اور قیمتیں نکالیں۔ سائن ان کرنا، ہوسٹ سے رابطہ کرنا، یا بکنگ مکمل کرنا ایک الگ صارف کی منظوری والا عمل ہونا چاہیے۔

## حقیقی دنیا کی مثال: Microsoft Project Opal

اس سبق میں آپ جو ایجنٹ بنائیں گے وہ ایک چھوٹا، مقامی ورژن ہے **کمپیوٹر یوز ایجنٹ (CUA)** کا — ایک پروگرام جو براؤزر کو اسی طرح چلاتا ہے جیسے انسان کرتا ہے۔ مائیکروسافٹ اسی خیال کو ادارے میں لا رہا ہے **[Project Opal (Frontier)](https://support.microsoft.com/en-us/microsoft-365-copilot/get-started-with-project-opal-frontier)** کے ذریعے، جو Microsoft 365 Copilot کی ایک صلاحیت ہے۔

Project Opal کے ساتھ، آپ ایک کام بیان کرتے ہیں اور ایجنٹ آپ کی جانب سے **کمپیوٹر یوز کو ایک محفوظ Windows 365 Cloud PC پر استعمال کرتے ہوئے** کام کرتا ہے، آپ کی تنظیم کی براؤزر پر مبنی ایپلیکیشنز، سائٹس، اور ڈیٹا کے درمیان کام کرتا ہے۔ یہ **پس منظر میں غیر متحرک طریقے سے کام کرتا ہے**، اور آپ کام کی رہنمائی کر سکتے ہیں یا کسی بھی وقت کنٹرول سنبھال سکتے ہیں۔ مثال کے کاموں میں شامل ہیں:

- سیکیورٹی گروپ ممبرشپ درخواستوں کا انتظام
- تعمیل جائزوں کے لیے آڈٹ ثبوت جمع کرنا اور تصدیق کرنا
- IT حادثات کی تقسیم (ٹکٹ کی حیثیت کو اپ ڈیٹ کرنا، مالکان تفویض کرنا، نقول بند کرنا)
- ایکسل ڈیٹا کو مالیاتی کلوز ڈیک میں مرتب کرنا

Opal اس بات کے لیے ایک مفید حوالہ ہے کہ ایک **پروڈکشن گریڈ، قابل اعتماد** کمپیوٹر یوز ایجنٹ کیسا ہوتا ہے — اور یہ پہلے کے اسباق کے تصورات کو مضبوط کرتا ہے:

| اس کورس کا تصور | Project Opal اس پر کیسے عمل کرتا ہے |
|------------------------|-----------------------------|
| **انسانی شمولیت** (سبق 06) | Opal لاگ ان کے لیے رکتا ہے، حساس معلومات یا مبہم ہدایات کے لیے توقف کرتا ہے، اور بغیر واضح تصدیق کے پاس ورڈ داخل نہیں کرتا یا فارم جمع نہیں کرتا۔ آپ عمل کے دوران *کنٹرول سنبھال* اور *کنٹرول واپس کر* سکتے ہیں۔ |
| **قابل اعتماد اور محفوظ ایجنٹس** (اسباق 06 اور 18) | ایک علیحدہ Windows 365 Cloud PC میں چلتا ہے، براؤزر-صرف ہے (دوسرے کمپیوٹر رسائی بلاک، Intune کے ذریعے نافذ)، آپ کی شناخت استعمال کرتا ہے تاکہ صرف مجاز چیزوں تک رسائی حاصل کی جا سکے، اور ہر عمل کو آڈٹ کے لیے لاگ کرتا ہے۔ |
| **منصوبہ بندی اور میٹا کوگنیشن** (اسباق 07 اور 09) | Opal پہلے کام کا منصوبہ بناتا ہے، پھر ہر قدم پر اپنی استدلال کی نگرانی کرتا ہے اور اگر مشکوک سرگرمی محسوس کرے تو رکتا ہے۔ |
| **دوبارہ استعمال ہونے والی صلاحیتیں / اوزار** (سبق 04) | **Skills** آپ کو تکراری کاموں کے لیے ہدایات لکھنے دیتی ہے (جو `.md` فائل سے درآمد یا Opal کے ساتھ تیار کی گئی ہوں) اور انہیں گفتگو کے دوران دوبارہ استعمال کریں۔ |

> **دستیابی:** Project Opal اس وقت [Frontier ابتدائی رسائی پروگرام](https://adoption.microsoft.com/copilot/frontier-program/) میں Microsoft 365 Copilot سبسکرپشن کے ساتھ صارفین کے لیے دستیاب ہے، اور آپ کے ایڈمنسٹریٹر کو ترتیب مکمل کرنا ضروری ہے۔ چونکہ یہ ایک تجرباتی Frontier کی خصوصیت ہے، صلاحیتیں وقت کے ساتھ تبدیل ہو سکتی ہیں۔
